# 竞争ELISA

Competitive ELISA（竞争 ELISA，竞争酶联免疫吸附试验）是一类利用“样本目标物”和“标记目标物/固定目标物”竞争抗体结合位点的 [ELISA](ELISA.md)。它常用于小分子、激素、药物、毒素、[半抗原](<../番外/补充知识/半抗原.md>) 等难以被两只抗体同时夹住的目标。

## 核心逻辑

竞争 ELISA 的核心不是“捕获越多，信号越强”，而是“样本目标物越多，能结合到板上或抗体上的标记物越少”。很多竞争 ELISA 的信号与目标物浓度呈负相关。

常见逻辑之一：

```text
板面固定抗原或抗体
-> 样本目标物与酶标/固定竞争物竞争结合
-> 洗板
-> 加底物
-> 目标物越多，保留的酶标物越少
-> 信号越低
```

Bio-Rad 的 ELISA types guide 将 competitive ELISA 归为常见 ELISA 类型之一，并强调它常用于小分子等不能方便形成 sandwich 的分析物。参考：[Bio-Rad ELISA types guide](https://www.bio-rad-antibodies.com/elisa-types-direct-indirect-sandwich-competitive-elisa.html)。

## 适合什么时候用

| 场景 | 是否适合 | 原因 |
| --- | --- | --- |
| 小分子药物检测 | 适合 | 小分子通常只有一个主要表位 |
| 激素检测 | 常用 | 很多激素不适合夹心结构 |
| 毒素或代谢物检测 | 常用 | 可通过竞争关系定量 |
| 细胞因子蛋白定量 | 通常不首选 | 夹心 ELISA 更直接 |
| 抗体滴度检测 | 不常作为首选 | 间接 ELISA 更常见 |

竞争 ELISA 最适合回答：“样本中这个小目标物有多少，它能竞争掉多少标记结合？”

## 为什么小分子常用竞争法

[夹心ELISA](夹心ELISA.md) 需要目标分子同时被捕获抗体和检测抗体结合。较大蛋白通常有多个表位，能被两只抗体同时识别；但 [小分子](<../番外/补充知识/小分子.md>) 或半抗原太小，常常无法形成稳定夹心结构。

竞争法绕开这个限制：它不要求目标物被两只抗体夹住，而是利用目标物和标记物之间对同一抗体位点的竞争。

## 实验操作

具体竞争模式很多，以下写通用判断逻辑。

### 竞争体系设计

**怎么做**：选择固定抗原、固定抗体、酶标抗原或酶标抗体等组合，使样本目标物能与标记物竞争同一结合位点。

**为什么重要**：竞争 ELISA 的方向和曲线形状取决于体系设计。不同 kit 的“信号高低”和“浓度高低”关系可能不同。

**注意事项**：

- 读说明书确认信号和浓度是正相关还是负相关。
- 竞争物必须和样本目标物有可比较的结合能力。
- 抗体亲和力过高或过低都会影响动态范围。

**替代方案**：对较大蛋白，若有合适抗体对，优先用夹心 ELISA；对小分子可考虑 LC-MS 或其他化学分析方法。

**出错后果**：把负相关曲线当正相关解读，会完全反向解释结果。

### 标准曲线准备

**怎么做**：用已知浓度标准品建立竞争曲线。竞争 ELISA 的标准曲线常表现为浓度越高，OD 越低。

**为什么重要**：竞争 ELISA 很难靠直觉读结果，必须依赖标准曲线换算。

**注意事项**：

- 标准品浓度范围要覆盖样本。
- 低浓度端和高浓度端都可能接近平台。
- 曲线拟合常用 4PL/5PL，需要确认软件设置方向。

**替代方案**：样本未知时做多个稀释倍数，确保至少一个稀释度落在曲线中段。

**出错后果**：样本超过曲线范围时，信号可能看似“很低”或“很高”，但无法可靠定量。

### 样本处理

**怎么做**：根据 kit 要求稀释、提取或预处理样本，降低基质对竞争反应和酶反应的影响。

**为什么重要**：竞争 ELISA 常用于血清、尿液、食品、环境或复杂提取物，[基质效应](<../番外/补充知识/基质效应.md>) 很常见。

**注意事项**：

- 样本溶剂、盐、pH、蛋白和脂质都可能影响竞争结合。
- 有机溶剂残留可能抑制 HRP 或影响抗体。
- 标准品最好在与样本相近的基质中稀释。

**替代方案**：做 spike-and-recovery、稀释线性或使用 matrix-matched standard（基质匹配标准品）。

**出错后果**：回收率差、不同稀释倍数结果不一致、假高或假低。

### 孵育、洗板和显色

**怎么做**：按 kit 要求加入样本、竞争物和抗体，孵育后洗板，再加入底物显色并读板。

**为什么重要**：竞争反应对孵育时间、温度和平衡状态敏感。微小操作差异可能改变竞争比例。

**注意事项**：

- 加样时间差要小。
- 洗板要一致，但不要破坏结合物。
- 底物显色时间固定。

**替代方案**：使用多道移液枪或自动化平台减少时间差。

**出错后果**：列间差异、重复孔 CV 高、曲线斜率异常。

## 结果解释

竞争 ELISA 最容易出错的是方向理解：

| 样本目标物 | 可结合标记物 | 常见信号 |
| --- | --- | --- |
| 少 | 多 | 高 |
| 多 | 少 | 低 |

所以竞争 ELISA 的图常常是下降曲线。结果报告时应明确：

- 曲线方向。
- 拟合方式。
- 样本稀释倍数。
- 是否做基质匹配。
- 是否在曲线可靠范围内。

## 优点和局限

| 维度 | 竞争ELISA |
| --- | --- |
| 适合目标 | 小分子、半抗原、激素、药物 |
| 曲线方向 | 常与浓度负相关 |
| 抗体需求 | 可只需一个关键抗体 |
| 解读难度 | 高于夹心 ELISA |
| 基质影响 | 常见且需要验证 |
| 灵敏度 | 取决于竞争体系和抗体亲和力 |

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 把高 OD 解释为高浓度 | 忘记竞争 ELISA 常为负相关 | 重新查看标准曲线方向 |
| 曲线很平 | 抗体/竞争物浓度不合适，亲和力不匹配 | 优化竞争物和抗体浓度 |
| 样本回收率差 | 基质效应 | 做 spike recovery 和基质匹配标准 |
| 重复孔 CV 高 | 加样时间差、混匀不足、洗板不一致 | 使用多道移液枪，固定孵育节奏 |
| 高浓度样本超范围 | 曲线低端平台 | 进一步稀释或换更合适范围 kit |
| 所有孔信号低 | 酶标物失活、底物问题或竞争物过量 | 检查阳性/阴性控制和底物 |

## 总结

竞争 ELISA 的核心是“竞争”，不是“夹心捕获”。它特别适合小分子、激素、药物和半抗原，但结果方向常常与浓度相反，且对基质效应和曲线解释更敏感。使用竞争 ELISA 时，必须先确认标准曲线方向，再解释样本浓度。
