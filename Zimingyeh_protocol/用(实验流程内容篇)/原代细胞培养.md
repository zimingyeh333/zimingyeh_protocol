# 原代细胞培养

Primary cell culture（原代细胞培养）是指从组织、血液或其他生物样本中直接分离，或从供应商购买后在体外短期培养的非无限增殖细胞培养体系。相比永生化细胞系，原代细胞更接近体内状态，但也更脆弱、更昂贵、更依赖专用条件和批次记录。

## 应用场景

- 建立更接近 in vivo（体内）生理状态的模型。
- 研究特定组织来源细胞，例如内皮细胞、成纤维细胞、上皮细胞、神经细胞、免疫细胞、平滑肌细胞、肝细胞等。
- 验证细胞系结果是否能在更接近真实组织的系统中重现。
- 药物敏感性、毒性、炎症反应、分化、屏障功能或功能性 assay。
- 个体化医学、疾病模型、患者来源细胞和转化研究。

ATCC 的 primary cell culture guide 指出，primary cells（原代细胞）更接近体内生理状态，能产生更相关的数据，但也面临供体组织有限、分离纯化难、质量一致性和污染风险等挑战。[参考：ATCC Primary Cell Culture Guide](https://www.atcc.org/resources/culture-guides/primary-cell-culture-guide)

## 实验目的

原代细胞培养的目标不是无限扩增，而是在有限时间内尽量保留来源组织相关特征，并获得足够稳定、可解释的实验窗口：

- 维持细胞身份和功能表型。
- 控制 donor variability（供体差异）和 batch variability（批次差异）。
- 减少过度传代、应激、污染和选择压力。
- 在合适 passage window（传代窗口）内完成实验。
- 记录来源、伦理、供应商、批号、传代数和质量控制。

## 简要实验原理

原代细胞通常没有细胞系那样的无限增殖能力。ATCC 指出，原代细胞适应体外培养后，会经历有限且预定的细胞分裂次数，随后进入 senescence（衰老）；可传代次数受 Hayflick limit（海弗利克极限）、营养需求、培养条件和操作技术影响。[参考：ATCC Primary Cell Culture Guide](https://www.atcc.org/resources/culture-guides/primary-cell-culture-guide)

这意味着原代细胞培养的核心不是“尽量传下去”，而是：

- 在最少传代和最短时间内获得可用实验数据。
- 使用供应商或文献验证过的培养基、补充剂和基质。
- 避免让培养条件选择出不代表原组织的亚群。
- 把供体、批次、传代数和功能状态纳入实验设计。

## 与细胞系的区别

| 维度 | 原代细胞 | 常规细胞系 |
| --- | --- | --- |
| 生理相关性 | 通常更接近体内状态 | 可能偏离原组织，尤其高传代 |
| 增殖能力 | 有限，容易衰老 | 通常可长期传代 |
| 批次差异 | 供体和分离批次差异明显 | 相对稳定，但仍会漂移 |
| 培养难度 | 高，依赖专用条件 | 较低，耐受性更强 |
| 成本 | 高 | 通常较低 |
| 实验设计 | 强调 donor、passage、功能验证 | 强调身份、污染、传代窗口 |

Lonza 的 primary cell culture tips 也提醒，原代细胞是 finite（有限寿命）的，传代过多会衰老；如果使用错误培养基、错误解离试剂或错误流程，很容易导致状态变差。[参考：Lonza Primary Cell Culture Common Errors](https://bioscience.lonza.com/lonza_bs/CH/en/tech-tips-for-primary-cell-culture-common-errors)

## 实验前设计

### 明确细胞来源

**怎么做**：记录物种、组织、供体、年龄、性别、疾病背景、分离方法、供应商、货号、批号、冻存 passage、伦理或授权信息。

**为什么**：原代细胞的来源就是实验变量。不同供体可能比处理效应差异还大；如果来源不清，后续数据很难解释。

**注意事项**：

- 商业原代细胞要保存 COA（certificate of analysis，检测报告）。
- 患者来源样本要符合伦理和隐私要求。
- 不要把不同供体简单当作技术重复。

**替代方案**：若供体差异很大，应把 donor 作为 biological replicate（生物学重复）纳入设计。

**出错后果**：把供体差异误认为处理效应，或无法追溯异常批次。

### 确定传代窗口

**怎么做**：查供应商说明或预实验数据，确定可用 passage range（传代范围）。很多原代细胞只建议低传代使用，例如 P2-P5 或供应商规定窗口。

**为什么**：原代细胞传代越多，越可能衰老、增殖变慢、marker 改变或功能下降。PromoCell FAQ 也区分 passage（传代过程）和 population doubling（群体倍增），提醒相同传代数不一定代表相同倍增历史。[参考：PromoCell FAQ](https://promocell.com/us_en/frequently-asked-questions/)

**注意事项**：

- 传代数和倍增次数都重要。
- 不同供应商的 P0/P1 定义可能不同。
- 高传代原代细胞不应和低传代混合比较。

**替代方案**：关键实验尽量一次性复苏足够细胞，缩短体外扩增时间。

**出错后果**：细胞衰老、功能丢失、结果不可重复。

### 选择培养体系

**怎么做**：优先使用供应商配套培养基、补充剂和包被流程。不要随意用常规 DMEM + FBS 替代专用体系。

**为什么**：原代细胞对营养、生长因子、基质和血清成分更敏感。ATCC primary cell culture guide 也把不同原代细胞的培养基、补充剂和处理流程作为标准化系统的一部分。[参考：ATCC Primary Cell Culture Guide](https://www.atcc.org/resources/culture-guides/primary-cell-culture-guide)

**注意事项**：

- 生长因子可能不稳定，避免反复冻融。
- 血清批次变化可能影响分化、增殖和功能。
- 包被浓度、时间和储存条件要记录。

**替代方案**：如果要改培养体系，应先做并行比较，而不是直接替换。

**出错后果**：细胞不贴壁、不增殖、分化状态改变或功能 assay 失败。

## 实验操作

### 复苏或初始接种

**怎么做**：按供应商说明复苏，使用预平衡培养基和预处理培养容器。接种密度通常不能太低，复苏早期避免剧烈吹打和频繁移动。

**为什么**：原代细胞复苏后恢复能力较弱，低密度、错误表面或 DMSO 暴露过久都会显著降低存活。

**注意事项**：

- 复苏后第一天观察贴壁和死细胞，不要急于做实验。
- 是否离心去除 DMSO 要按细胞类型判断。
- 某些原代细胞需要专用 recovery supplement。

**替代方案**：极珍贵细胞可先复苏小量测试条件，但要权衡浪费风险。

**出错后果**：复苏率低、贴壁差、细胞进入长期应激状态。

### 日常维护

**怎么做**：按细胞类型和供应商 protocol 换液、观察和记录。重点记录形态、密度、漂浮细胞、培养基颜色、包被条件和 passage。

**为什么**：原代细胞变化快，很多问题只能通过连续记录发现。Lonza 提醒原代细胞常见错误包括使用不合适培养基、错误传代试剂和过度传代。[参考：Lonza Primary Cell Culture Common Errors](https://bioscience.lonza.com/lonza_bs/CH/en/tech-tips-for-primary-cell-culture-common-errors)

**注意事项**：

- 不要为了“省培养基”延长换液间隔。
- 不要频繁完全换液移除关键分泌因子，除非 protocol 要求。
- 不同供体不要在记录中混为同一批。

**替代方案**：敏感细胞可半量换液、使用条件化培养基或降低机械扰动。

**出错后果**：细胞逐渐死亡、表型漂移、实验窗口错过。

### 传代

**怎么做**：在推荐汇合度或密度范围内传代，使用指定解离试剂和时间。传代后按推荐密度接种到合适包被表面。

**为什么**：原代细胞比常规细胞系更怕过度消化、过低密度和过度传代。传代窗口太晚会导致衰老和应激，太早又可能恢复不良。

**注意事项**：

- 显微镜下判断解离，而不是机械等固定时间。
- 表面 marker 或功能 assay 相关细胞要避免损伤关键蛋白。
- 传代后不要立刻做高压力处理。

**替代方案**：

- 对脆弱细胞使用 Accutase 或非酶解离。
- 对贴壁困难细胞优化包被。
- 对有限寿命细胞减少传代次数，优先扩大冻存和实验计划。

**出错后果**：活率下降、增殖变慢、marker 丢失、功能消失。

### 实验前质控

**怎么做**：确认支原体阴性、细胞形态正常、传代数在窗口内、供体和批次记录完整。根据细胞类型检测 marker 或功能指标。

**为什么**：原代细胞即使活着，也不一定处于正确功能状态。实验前的身份、污染和功能确认比普通细胞系更重要。

**注意事项**：

- marker 选择要和细胞类型匹配。
- 不要用单一 marker 判断复杂细胞群纯度。
- 供体差异应在统计设计中体现。

**替代方案**：需要高度纯度时，可使用流式分选、磁珠分选或选择性培养，但这些步骤也可能改变状态。

**出错后果**：数据来自混杂细胞群、污染细胞或已经衰老的细胞。

## 常见原代细胞类型

| 类型 | 培养重点 |
| --- | --- |
| 原代内皮细胞 | 基质、专用生长因子、低传代和功能 marker |
| 原代成纤维细胞 | 相对耐受，但高传代后衰老和表型改变明显 |
| 原代上皮细胞 | 对基质、极性和分化状态敏感 |
| 原代神经细胞 | 机械扰动、基质和成熟时间非常关键 |
| PBMC / 原代免疫细胞 | 供体差异、激活状态和细胞因子条件关键 |
| 原代肝细胞 | 极易去分化，培养窗口通常短 |
| 间充质干细胞 | 关注分化潜能、传代数和供体差异 |

## 与细胞系实验设计的区别

| 问题 | 原代细胞设计建议 |
| --- | --- |
| 重复怎么定义 | 不同 donor 通常是生物学重复；同一 donor 多孔是技术重复 |
| 传代数 | 严格限制并记录，不同 passage 不轻易混用 |
| 对照 | 尽量同 donor 配对处理，减少供体差异 |
| 批次 | 记录供应商、lot、COA、培养基和补充剂批号 |
| 统计 | 应考虑 donor effect（供体效应） |
| 结论 | 更接近生理，但样本量和批次差异必须透明 |

## 常见异常结果与 troubleshooting

| 异常结果         | 可能原因                     | 处理策略                      |
| ------------ | ------------------------ | ------------------------- |
| 复苏率低         | 冻存质量、DMSO 处理、接种密度低、表面不合适 | 按供应商 protocol，使用包被，提高密度   |
| 不贴壁          | 包被错误、培养基不匹配、细胞受损         | 核对包被和培养基，减少机械扰动           |
| 生长慢          | 原代特性、低密度、供体差异、培养基因子不足    | 使用推荐密度和补充剂，增加 donor 数     |
| 很快衰老         | 传代过多、过度汇合、应激             | 限定 passage window，复苏低传代库存 |
| marker 下降    | 培养体系不合适、传代过多、分化状态改变      | 优化培养基和基质，缩短体外培养           |
| 批次差异大        | 供体差异、分离方法不同、供应商批号不同      | 记录 donor/lot，增加生物学重复      |
| 污染风险高        | 原始组织来源、处理步骤多、抗生素掩盖       | 严格无菌，隔离培养，定期支原体检测         |
| 功能 assay 不稳定 | 状态、密度、传代、供体差异未控制         | 固定实验窗口，按 donor 配对设计       |

## 小结

原代细胞培养的价值在于更接近真实生物状态，难点也正来自这种真实性：供体差异、有限寿命、培养条件敏感和批次不可忽略。做原代细胞时，不要追求像细胞系一样无限扩增，而要围绕来源、传代窗口、专用培养体系、质量控制和供体重复来设计实验。
