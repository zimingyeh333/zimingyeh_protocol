# 细胞复苏

Cell thawing / cell recovery（细胞复苏）是把冻存在液氮或超低温条件下的细胞快速恢复到可培养状态的操作。它不是简单地“把冻存管融化”，而是在最短时间内完成解冻、稀释冻存保护剂、降低渗透压冲击，并让细胞重新进入适合的 [细胞培养](细胞培养.md) 环境。

## 应用场景

- 从液氮库启用新一批细胞，用于日常培养或实验。
- 从 master cell bank（主细胞库）或 working cell bank（工作细胞库）恢复低传代细胞。
- 接收 ATCC、DSMZ、JCRB、公司或合作实验室寄来的冻存细胞。
- 复苏原代细胞、干细胞、免疫细胞或类器官等特殊样本。
- 验证 [细胞冻存](细胞冻存.md) 是否成功，例如冻存后抽检一管复苏率。

Thermo Fisher 的 Gibco thawing protocol 明确说，thawing procedure（复苏/解冻过程）对冻存细胞是有压力的，推荐快速操作并优先遵循细胞来源方说明书。[参考：Thermo Fisher Thawing Cells](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/cell-culture-protocols/thawing-cells.html)

## 实验目的

细胞复苏的目标不是让冻存管“化开”，而是让尽可能多的细胞在复苏后存活、贴壁或恢复增殖，并保持后续实验需要的状态。一个合格的复苏流程应该做到：

- 降低冰晶和温度冲击造成的死亡。
- 尽快稀释或去除 [DMSO](<../材(实验耗材工具篇)/DMSO.md>) 等 cryoprotectant（冻存保护剂）。
- 用正确 [培养基](<../材(实验耗材工具篇)/培养基.md>)、血清和补充剂帮助细胞恢复。
- 避免复苏过程中引入细菌、真菌、[支原体](支原体检测.md) 或交叉污染。
- 记录冻存批次、传代数、复苏条件和复苏后状态。

## 简要实验原理

冻存时，细胞处在低温、渗透压变化和冻存保护剂共同作用下。复苏时主要面对三类压力：

| 压力 | 来源 | 结果 |
| --- | --- | --- |
| 冰晶损伤 | 解冻太慢或冻存过程不佳 | 细胞膜破裂、复苏率低 |
| DMSO 毒性 | 融化后细胞长时间暴露在 DMSO 中 | 细胞死亡、贴壁差、恢复慢 |
| 渗透压冲击 | 冻存液突然被大量培养基稀释，或细胞被粗暴离心/吹打 | 细胞肿胀、破裂、应激 |

因此复苏的经典原则是：**快速解冻，缓慢稀释，尽快进入培养条件**。Thermo Fisher 建议冻存管从液氮取出后立即进入 37°C 水浴，快速融化到只剩少量冰晶，再在安全柜中把细胞滴加到预温完全培养基中。[参考：Thermo Fisher Thawing Cells](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/cell-culture-protocols/thawing-cells.html)

## 实验操作

### 复苏前确认

**怎么做**：在取出冻存管之前，先确认细胞名称、来源、冻存日期、传代数、冻存密度、冻存液配方、支原体检测状态、培养基配方和目标接种容器。把完全培养基预温到 37°C，并准备好标签和废液。

**为什么**：冻存管一旦从液氮取出，时间压力很大。复苏前没有准备好培养基、容器或安全柜，会让细胞在半融化状态下等待，增加死亡和污染风险。

**注意事项**：

- 不要在不确定细胞身份或污染状态时直接进入公共培养箱。
- 外来细胞优先隔离培养，并尽快做 [支原体检测](支原体检测.md) 和 [细胞系鉴定](细胞系鉴定.md)。
- 先预温培养基，不要预温 DMSO 冻存管。

**替代方案**：如果复苏的是极珍贵细胞，建议先用一管低价值库存演练流程，或请熟悉该细胞的人一起操作。

**出错后果**：复苏时间拖长、DMSO 暴露过久、接种容器错误、细胞身份混乱。

### 取出冻存管

**怎么做**：戴好低温防护，从液氮罐中取出冻存管，核对标签后立刻进入解冻步骤。冻存管外壁有液氮残留时应注意爆管风险。

**为什么**：液氮相或液氮渗入冻存管后，升温可能导致压力骤增。Thermo Fisher 也提醒，从液相液氮储存取出的 cryovial（冻存管）解冻时有爆裂风险，需要佩戴面罩或护目镜。[参考：Thermo Fisher Thawing Cells](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/cell-culture-protocols/thawing-cells.html)

**注意事项**：

- 不要把冻存管长时间拿在室温下找信息。
- 标签模糊或冻存记录不完整时，不要把它作为关键实验来源。
- 复苏多个细胞系时，一次只处理一管，避免混淆。

**出错后果**：细胞半融化后又回冻，复苏率显著下降；更严重时发生冻存管爆裂。

### 快速解冻

**怎么做**：把冻存管下半部放入 37°C 水浴或加热珠中，轻轻晃动，直到只剩很小冰晶。通常应在约 1-2 分钟内完成，具体以冻存体积和设备为准。

**为什么**：快速通过冰晶形成和重结晶温区，可以减少冰晶对细胞膜的机械损伤。ATCC animal cell culture guide 和 Thermo Fisher thawing protocol 都推荐快速解冻，并在仅剩少量冰晶时进入后续步骤。[参考：ATCC Animal Cell Culture Guide](https://www.atcc.org/resources/culture-guides/animal-cell-culture-guide)；[参考：Thermo Fisher Thawing Cells](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/cell-culture-protocols/thawing-cells.html)

**注意事项**：

- 不要让水浴液面接触管盖，减少污染风险。
- 不要等到完全温热才拿出，融化到少量冰晶即可。
- 不要剧烈摇晃或涡旋。

**替代方案**：干式加热珠可减少水浴污染风险，但解冻速度和接触均匀性要验证。

**出错后果**：解冻太慢导致复苏率低；水浴污染可能通过管盖或外壁带入安全柜。

### 酒精擦拭与转入安全柜

**怎么做**：冻存管外壁用 70%-75% 乙醇彻底擦拭，转入 BSC 生物安全柜后再开盖。

**为什么**：冻存管外壁可能接触液氮罐、冻存盒、水浴或手套表面。开盖前擦拭是为了降低外部污染进入培养体系的概率。

**注意事项**：

- 乙醇需要有接触时间，不是“喷一下立刻开盖”。
- 开盖时间越短越好。
- 不要让管盖内侧接触台面或手套。

**替代方案**：对极高洁净要求的细胞，可使用无菌套管、干浴解冻和隔离安全柜。

**出错后果**：复苏后 24-72 小时出现细菌或真菌污染，通常很难挽救。

### 稀释 DMSO

**怎么做**：将融化的细胞悬液缓慢滴加到含有预温完全培养基的离心管或培养容器中，边滴加边轻柔混匀。Thermo Fisher 的通用 protocol 推荐把 thawed cells dropwise（逐滴）加入预温完全培养基，再根据细胞类型决定离心条件。[参考：Thermo Fisher Thawing Cells](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/cell-culture-protocols/thawing-cells.html)

**为什么**：DMSO 在低温下保护细胞，但融化后会逐渐表现出毒性；同时，冻存液和培养基渗透压不同，突然大量稀释会让细胞承受渗透压冲击。

**注意事项**：

- 不要把大量培养基猛地冲入冻存管。
- 对脆弱细胞，稀释速度比“洗得干净”更重要。
- 稀释后尽快进入离心或接种，不要在室温长时间放置。

**替代方案**：

- 对 DMSO 敏感细胞：离心去除 DMSO 后再接种。
- 对离心敏感细胞：直接稀释后接种，次日换液去除 DMSO。
- 对原代细胞或干细胞：优先遵循供应商说明，不要照搬肿瘤细胞系流程。

**出错后果**：细胞复苏后大量漂浮、贴壁差、24 小时内死亡增加。

### 是否离心去除 DMSO

**怎么做**：如果选择离心，常见做法是低速离心形成细胞沉淀，弃上清后用新鲜完全培养基轻柔重悬。Thermo Fisher 给出的通用示例约为 200 x g、5-10 分钟，但强调实际速度和时间取决于细胞类型。[参考：Thermo Fisher Thawing Cells](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/cell-culture-protocols/thawing-cells.html)

**为什么**：离心可以快速去除 DMSO，但也会带来机械应力和细胞损失。是否离心不是绝对规则，而是要看细胞对 DMSO 和离心的相对敏感性。

**注意事项**：

- 不要用过高离心力“追求干净沉淀”。
- 小细胞沉淀可能不明显，弃上清时不要吸走细胞。
- 重悬时避免产生泡沫。

**替代方案**：

- 直接接种：适合部分耐受细胞系，第二天换液。
- 半量换液：复苏后数小时或次日换掉含 DMSO 培养基。
- 梯度稀释：对极敏感细胞逐步加入培养基。

**出错后果**：离心过猛导致死亡；不去除 DMSO 则可能导致恢复慢或细胞状态差。

### 接种与恢复培养

**怎么做**：把细胞接种到预先准备好的培养容器中，加入足够完全培养基，轻轻摇匀，放入 CO2 培养箱。贴壁细胞通常需要 12-24 小时评估贴壁和形态；悬浮细胞则看细胞密度、团聚和活率。

**为什么**：复苏后细胞需要恢复膜完整性、代谢和贴壁/增殖能力。过低密度会让细胞缺少旁分泌支持，过高密度会导致恢复后很快营养不足。

**注意事项**：

- 复苏早期不要频繁拿出观察，避免温度和 CO2 波动。
- 贴壁细胞刚接种后不要剧烈移动培养瓶或培养板。
- 第二天换液时动作轻柔，避免把刚贴壁的细胞冲掉。

**替代方案**：

- 对贴壁困难细胞，可使用包被培养容器。
- 对干细胞，可加入 ROCK 抑制剂并使用合适基质。
- 对类器官，复苏流程通常要进入 [类器官培养](类器官培养.md) 的三维基质流程。

**出错后果**：细胞贴壁不均、局部密度过高、恢复慢、实验起点不一致。

### 复苏后观察与记录

**怎么做**：复苏当天记录接种容器、培养基、冻存管信息和复苏方式；次日记录贴壁率、漂浮细胞、培养基颜色、形态、是否换液。必要时做活率、支原体检测或短期扩增观察。

**为什么**：复苏质量会影响后续很多天的细胞状态。没有记录时，很难判断某次实验异常是处理造成的，还是从复苏开始就有问题。

**注意事项**：

- 复苏后前 1-3 天不建议直接做关键实验，除非该细胞 protocol 明确允许。
- 不要用状态差的复苏细胞建立长期库存。
- 一旦发现污染，优先隔离而不是继续培养观察。

**替代方案**：关键项目可复苏两管平行比较，选择恢复更好的一管进入扩增。

**出错后果**：后续实验用到未恢复稳定的细胞，结果波动大且难以解释。

## 特殊细胞注意事项

| 细胞类型 | 复苏重点 |
| --- | --- |
| 贴壁细胞 | 接种密度足够，次日轻柔换液；贴壁差时考虑包被 |
| 悬浮细胞 | 维持推荐密度窗口，避免复苏后过度稀释 |
| 原代细胞 | 优先按供应商说明；通常更怕离心、吹打和错误培养基 |
| 干细胞 | 关注基质、克隆形态、ROCK 抑制剂和温和操作 |
| 类器官 | 重点是基质胶温度、三维包埋和组织块/细胞团完整性 |
| 免疫细胞 | 关注细胞因子、激活状态、密度和恢复时间 |

## 常见异常结果与 troubleshooting

| 异常结果 | 可能原因 | 处理策略 |
| --- | --- | --- |
| 复苏后大量死亡 | 冻存质量差、解冻太慢、DMSO 暴露过久、离心过猛 | 检查冻存记录，快速解冻，优化 DMSO 去除方式 |
| 贴壁细胞不贴壁 | 接种密度太低、培养容器不适、消化/冻存损伤、培养基错误 | 提高接种密度，换包被容器，核对培养基 |
| 复苏后生长慢 | 细胞尚未恢复、传代过高、血清/补充剂不合适、支原体污染 | 延长恢复期，做支原体检测，复苏低传代库存 |
| 培养基很快变黄 | 细胞太多、污染、CO2 或培养基缓冲不匹配 | 观察污染，调整接种密度，检查培养箱 |
| 漂浮细胞多但部分贴壁正常 | 复苏损伤、冻存细胞中死细胞多 | 次日轻柔换液，不要过早判死刑 |
| 离心后看不到沉淀 | 细胞数量少、离心力太低、沉淀松散 | 降低弃上清速度，使用合适离心条件 |
| 复苏后污染 | 冻存管外壁、水浴、安全柜或原始库存污染 | 隔离废弃，清洁设备，回查同批冻存管 |
| 复苏状态每次差异很大 | 冻存批次不一致、冻存密度不一致、操作时间不一致 | 标准化冻存和复苏记录，抽检冻存批次 |

关于 passage number（传代数）的记录，建议实验室内部统一规则。常见做法是：冻存管标签写冻存时的传代数，复苏接种后第一次正式传代时再增加一次；也可以在复苏当天标记为 “P冻存数 + thaw”，但不要不同人用不同规则。

## 小结

细胞复苏的核心是：准备充分、快速解冻、缓慢稀释、合理处理 DMSO、给足恢复时间，并完整记录。复苏失败时，不要只怪细胞“娇气”，要回查冻存质量、解冻速度、DMSO 暴露、离心强度、培养基、接种密度和污染状态。
