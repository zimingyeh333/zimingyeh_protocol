# 集落形成单位实验

Colony-forming unit assay（CFU assay，集落形成单位实验；在造血领域也常称 colony-forming cell assay，CFC assay）是一种把 hematopoietic progenitor cells（HPC，[造血祖细胞](<../番外/补充知识/造血祖细胞.md>)）接种到 semi-solid medium（半固体培养基）中，通过形成的 colony（集落）数量和形态来评估祖细胞功能与谱系潜能的实验。

## 发明历史与方法背景

CFU assay 的核心来自造血生物学中“一个祖细胞在合适半固体环境中形成一个可观察集落”的思想。半固体环境限制细胞迁移，使不同祖细胞形成的集落在空间上相对独立，从而可以根据 colony number（集落数量）和 colony morphology（集落形态）估算功能性祖细胞。STEMCELL Technologies 的 MethoCult 资料将其描述为用于体外检测和定量 hematopoietic progenitor cells 的 CFU/CFC assay 的 methylcellulose-based media。参考：[STEMCELL Technologies MethoCult](https://www.stemcell.com/products/brands/methocult.html)。

这个实验不是普通“细胞增殖实验”，也不是肿瘤细胞 clonogenic assay（克隆形成实验）的简单替代。它更关注造血祖细胞是否还能产生不同谱系的集落。

## 应用场景

| 场景 | 目的 |
| --- | --- |
| 骨髓、脐血、动员外周血样本 | 评估造血祖细胞功能 |
| CD34+细胞制备后质控 | 检查富集或处理后是否保留集落形成能力 |
| iPSC/ESC造血分化 | 作为造血分化后功能 readout |
| 药物、基因编辑或毒性处理 | 判断处理是否损伤造血祖细胞 |
| 冻存/复苏条件比较 | 比较复苏后功能恢复 |
| 细胞治疗或转化研究 | 作为功能和质量控制指标之一 |

## 实验目的

CFU assay 通常用于回答：

- 样本中是否存在功能性造血祖细胞？
- 不同处理是否改变 colony-forming capacity（集落形成能力）？
- 细胞是否偏向 granulocyte/macrophage（粒细胞/巨噬细胞）、erythroid（红系）或 mixed lineage（混合谱系）？
- 冻存、扩增、分选或分化流程是否损伤祖细胞功能？
- 不同 donor（供体）、批次或处理组之间功能差异是否明显？

## 简要实验原理

造血祖细胞被接种到 methylcellulose（甲基纤维素）为基础的半固体培养基中。培养基中通常包含 serum（血清）或 defined supplements（定义化补充剂）、cytokines/growth factors（细胞因子/生长因子）和营养成分。由于半固体基质限制细胞扩散，具有增殖和分化能力的祖细胞会在局部形成可见集落。

常见读数包括：

| 集落类型 | 英文全称 | 中文解释 |
| --- | --- | --- |
| CFU-GM | Colony-Forming Unit-Granulocyte/Macrophage | 粒细胞/巨噬细胞集落形成单位 |
| BFU-E | Burst-Forming Unit-Erythroid | 红系爆发集落形成单位 |
| CFU-GEMM | Colony-Forming Unit-Granulocyte/Erythrocyte/Macrophage/Megakaryocyte | 粒/红/巨噬/巨核混合集落形成单位 |
| CFU-G | Colony-Forming Unit-Granulocyte | 粒细胞集落形成单位 |
| CFU-M | Colony-Forming Unit-Macrophage | 巨噬细胞集落形成单位 |

不同 MethoCult 或其他 CFU medium 的 cytokine cocktail 会影响能检测到的集落类型，因此结果必须和培养基版本绑定解释。

## 实验操作

### 样本准备和计数

**怎么做**：获得目标细胞样本，检测活率和细胞浓度；必要时先做 CD34+ 细胞富集、死细胞去除或样本清洁。

**为什么**：CFU assay 对起始细胞活率和接种密度非常敏感。死亡细胞和碎片会影响培养环境，也会增加集落识别难度。

**注意事项**：记录样本来源、donor、冻存/新鲜状态、分选方式、起始 marker 和活率。

**替代方案**：对未知样本可设置多个接种密度，避免集落过密或过少。

**出错后果**：接种细胞数不准会让组间比较失效；起始活率低会导致集落数量偏低。

### MethoCult 平衡与混匀

**怎么做**：按厂家说明处理 [MethoCult](<../材(实验耗材工具篇)/MethoCult.md>)，让半固体培养基达到适合操作的状态；加入细胞后充分但温和混匀，避免气泡。

**为什么**：MethoCult 黏稠，细胞很容易分布不均。混匀质量直接决定每个 dish 的集落分布。

**注意事项**：不要用普通快速吹打方式处理黏稠培养基；使用大口径吸头或说明书推荐工具；同一实验统一混匀时间和静置时间。

**替代方案**：如果实验室没有熟练经验，先用对照样本练习铺板和集落识别。

**出错后果**：气泡、细胞分布不均或培养基体积不准，会导致局部集落拥挤或空白。

### 接种和培养

**怎么做**：按设计把细胞-半固体培养基混合物均匀接种到指定培养皿中，放入湿润 CO2 incubator（CO2 培养箱）培养。STEMCELL 的 CFU assay 设置视频/流程也把准备 MethoCult、准备细胞、加入细胞、铺板培养和分析作为主要步骤。参考：[STEMCELL CFU assay setup](https://www.stemcell.cn/procedure-for-setting-up-the-cfu-assay.html)。

**为什么**：培养环境稳定性决定集落能否正常成熟。蒸发、震动、培养皿倾斜都会影响集落分布。

**注意事项**：培养期间尽量不要频繁移动培养皿；保持湿度，减少边缘蒸发；固定培养天数。

**替代方案**：某些体系可以使用预混 cytokine 的商品化 medium，也可使用 serum-free 版本，但必须和历史数据分开比较。

**出错后果**：培养皿震动或蒸发会导致集落聚集、边缘效应或计数不稳定。

### 集落计数与分类

**怎么做**：在规定天数用倒置显微镜观察并计数不同类型集落，记录 CFU-GM、BFU-E、CFU-GEMM 等类型。必要时保存代表性图像。

**为什么**：CFU assay 的主要误差来自人为识别差异。集落边界、大小、颜色和细胞形态都需要训练。

**注意事项**：计数者最好 blinded（盲法）处理样本；同一实验固定计数者或进行交叉校准；不要把碎片、气泡或小细胞团误判成集落。

**替代方案**：可使用图像辅助计数或培训课程，但仍需人工确认。

**出错后果**：分类标准不一致会让谱系倾向结论不可靠。

## 结果解析

| 结果 | 代表含义 | 注意事项 |
| --- | --- | --- |
| 总CFU数增加 | 祖细胞集落形成能力增强或输入有效祖细胞更多 | 需要校正接种细胞数和活率 |
| CFU-GM增加 | 粒/巨噬方向祖细胞功能或比例增加 | 受 cytokine cocktail 影响 |
| BFU-E减少 | 红系祖细胞功能受损或分化条件不合适 | 需结合红系 marker |
| CFU-GEMM存在 | 多谱系祖细胞潜能 | 数量通常较少，识别需谨慎 |
| 集落形态异常 | 细胞压力、培养基问题、药物效应或计数时间不合适 | 保存图像并复核 |

CFU 结果必须按“每多少起始细胞”或“每多少 CD34+ 细胞”标准化。只报每个 dish 多少集落，往往无法比较不同样本。

## 异常结果与可能原因

| 异常 | 可能原因 | 处理 |
| --- | --- | --- |
| 无集落 | 起始细胞无功能、活率低、培养基失效、接种数太低 | 设置阳性对照，检查 MethoCult 批号和培养条件 |
| 集落太多融合 | 接种密度过高 | 降低接种细胞数，做梯度 |
| 集落分布不均 | 混匀不足、气泡、铺板操作不稳定 | 优化混匀和铺板流程 |
| 不同重复差异大 | 接种体积误差、细胞沉降、培养皿边缘效应 | 统一操作节奏，增加重复 |
| 谱系分类不一致 | 计数者经验不足或标准不同 | 建立图像参考库，盲法复核 |
| 处理组集落小 | 药物/基因编辑影响增殖，或培养时间不足 | 同时记录集落大小和成熟度 |

## 小结

集落形成单位实验是造血祖细胞功能检测，而不是普通增殖实验。它最关键的变量是起始细胞质量、接种密度、半固体培养基版本、细胞因子组合、培养天数和计数标准。只要其中一个变量没记录，CFU 数量和谱系结论就很难复现。
