# 磁性细胞分选

Magnetic cell separation（磁性细胞分选/磁性细胞分离）是利用 antibody（抗体）或 ligand（配体）识别细胞表面 marker（标志物），再通过 magnetic particles/beads（磁性颗粒/磁珠）和 magnetic field（磁场）把目标细胞富集、保留或去除的细胞分离方法。它常用于 PBMC（Peripheral Blood Mononuclear Cells，[外周血单个核细胞](<../番外/补充知识/外周血单个核细胞.md>)）、T 细胞、B 细胞、NK 细胞、单核细胞、骨髓细胞和组织消化细胞的预处理。

## 发明历史与方法背景

磁性细胞分选的核心思想是 immunomagnetic separation（免疫磁性分离）：用抗体把特定细胞表面抗原和磁性颗粒连接起来，再利用磁场改变被标记细胞的位置。今天常见商业体系包括 column-free（无柱式）磁性分离和 column-based（柱式）磁性分离。STEMCELL Technologies 的 EasySep 资料强调其无柱式体系可用于 positive selection（阳性选择）、negative selection（阴性选择）和 depletion（去除）；Miltenyi 的 autoMACS 资料也把 positive selection 和 negative fraction（阴性流出组分）作为磁性分离的基本模式。参考：[STEMCELL EasySep](https://www.stemcell.com/products/brands/easysep.html)；[Miltenyi autoMACS Pro Separator document](https://static.miltenyibiotec.com/asset/150655405641/document_e22flq5qot02t33getf076vh0h?content-disposition=inline)。

磁性分选通常不是为了得到“绝对纯”的最终群体，而是为了在尽量温和、快速、低设备门槛的条件下富集目标细胞，或为后续 [流式细胞术](流式细胞术.md)、培养、刺激、测序、冻存和功能实验提供更可控的输入样本。

## 应用场景

| 场景 | 目的 | 常见后续实验 |
| --- | --- | --- |
| PBMC中分离T细胞 | 获得 CD3+、CD4+ 或 CD8+ T cells | T细胞活化、细胞因子刺激、流式 |
| PBMC中分离NK细胞 | 富集 CD56+ NK cells | 杀伤实验、扩增培养、表型分析 |
| B细胞/单核细胞分离 | 获得特定免疫亚群 | 抗体反应、炎症模型、转录组 |
| 去除死细胞或非目标细胞 | 降低背景、提高样本质量 | 单细胞测序、流式 panel |
| FACS前预富集 | 减少流式分选时间和细胞压力 | 稀有细胞分选、高纯度亚群 |
| 细胞治疗/转化研究前处理 | 标准化输入细胞 | 扩增、冻存、质量检测 |

## 实验目的

磁性细胞分选的目的通常包括：

- enrich target cells（富集目标细胞）。
- deplete unwanted cells（去除不需要的细胞）。
- improve downstream assay sensitivity（提高下游检测灵敏度）。
- reduce sample complexity（降低样本复杂度）。
- prepare viable cells（制备较高活率细胞）用于培养或功能实验。

它不是单纯追求“纯度越高越好”。如果后续是功能实验，目标细胞是否被抗体/磁珠直接标记、是否被激活、是否经历过过强离心或长时间处理，同样重要。

## 简要实验原理

磁性细胞分选依赖三件事：

| 组成             | 作用            | 关键变量               |
| -------------- | ------------- | ------------------ |
| 抗体或抗体 cocktail | 识别细胞表面 marker | marker 是否特异、是否影响功能 |
| 磁性颗粒/磁珠        | 让被识别细胞可被磁场操控  | 颗粒大小、结合方式、是否可释放    |
| 磁体/分离装置        | 保留或移除被标记细胞    | 无柱式/柱式、磁体型号、处理体积   |

positive selection（阳性选择）是直接标记目标细胞并回收被磁场保留的组分；negative selection（阴性选择）是标记非目标细胞，把未被标记的目标细胞留在上清或流出液中。STEMCELL 的 EasySep 资料也把这两种策略作为选择 kit 时的重要区别。参考：[STEMCELL EasySep Magnetic Cell Separation](https://cdn.stemcell.com/products/brands/easysep-cell-separation.html)。

## 实验操作

### 样本准备

**怎么做**：把起始样本制备成均匀单细胞悬液，去除 clumps（细胞团块）和明显碎片；根据 kit 要求调整细胞浓度、体积和缓冲液。PBMC 通常可由 [Ficoll](<../材(实验耗材工具篇)/Ficoll.md>) 等密度梯度方法获得，再进入磁性分选。

**为什么**：细胞团块、血小板、红细胞残留、黏液或死亡细胞都会增加非特异吸附，导致纯度和回收率下降。

**注意事项**：细胞计数要基于活细胞；样本不要超出 kit 推荐细胞数；冷操作可以降低代谢和非特异结合，但某些细胞对低温敏感，要按说明书执行。

**替代方案**：如果样本太脏，可先做红细胞裂解、死细胞去除或过滤；如果目标细胞稀有，可先粗富集再精分选。

**出错后果**：样本质量差会造成磁体分层不清、纯度低、回收率差、流式背景升高。

### 选择阳性或阴性策略

**怎么做**：根据后续用途选择 positive selection、negative selection 或 depletion。

**为什么**：阳性选择通常更直接、纯度较高，但可能让目标细胞表面残留抗体/磁颗粒；阴性选择得到 untouched cells（未直接标记目标细胞），更适合功能实验。

**注意事项**：不要只按“纯度”选择策略。T cell activation、NK cell killing assay、单细胞测序或长期培养对细胞状态非常敏感，阴性选择常更稳妥。

**替代方案**：先磁性富集再 FACS sorting，可以在纯度和细胞状态之间折中。

**出错后果**：错误策略可能导致目标细胞被激活、受体被占据、下游功能 readout 偏移。

### 抗体与磁颗粒孵育

**怎么做**：按说明书加入 Fc block、antibody cocktail 和 magnetic particles，轻柔混匀并控制孵育时间。

**为什么**：抗体结合不足会降低分选效率；过度孵育、剧烈吹打或温度不合适会影响细胞活率和状态。

**注意事项**：Fc receptor（Fc 受体）丰富的细胞容易非特异结合；细胞数、体积和试剂比例不要随意压缩或放大。

**替代方案**：对非特异高的样本，可优化 blocking、洗涤或 marker 组合。

**出错后果**：非特异结合会让污染细胞被带入目标组分；标记不足则目标细胞留在非目标组分中。

### 磁场分离

**怎么做**：把样本放入磁体或通过磁柱，按规定时间分离；收集目标组分，并根据策略保留磁性组分或未标记组分。

**为什么**：磁体类型、分离时间和管型会直接影响磁性颗粒的迁移和细胞回收。

**注意事项**：不要扰动磁体中的细胞层；吸液或倒液动作要稳定；同一实验尽量使用同型号磁体和统一体积。

**替代方案**：高纯度需求可重复分离或接 FACS；高回收率需求则避免过度重复磁分离。

**出错后果**：操作扰动会把污染细胞带入目标组分，或导致目标细胞损失。

### 分选后验证

**怎么做**：计数回收细胞并检测活率；用流式检测目标 marker、污染 marker 和死活染。

**为什么**：磁性分选没有“肉眼成功”的可靠判断。每个样本的 purity（纯度）、yield（回收率）和 viability（活率）都应该量化。

**注意事项**：流式验证抗体不要和分选抗体互相遮挡同一 epitope；阳性选择后 marker 可能被占位，必要时换 clone 或检测替代 marker。

**替代方案**：如果后续没有流式条件，至少做细胞计数、活率和形态观察，但这不能替代纯度验证。

**出错后果**：没有验证就进入下游实验，可能把污染细胞造成的现象误认为目标细胞生物学。

## 结果解析

| 指标 | 计算/含义 | 解读 |
| --- | --- | --- |
| 纯度 | 目标细胞 / 总活细胞 | 反映分选是否有效 |
| 回收率 | 回收目标细胞 / 起始目标细胞估计数 | 反映损失程度 |
| 活率 | 活细胞 / 总细胞 | 反映操作损伤 |
| 污染细胞比例 | 非目标细胞 marker 阳性比例 | 判断是否需要二次分选 |
| 功能状态 | activation marker、细胞因子、增殖或杀伤 | 判断分选是否改变细胞功能 |

纯度、回收率和活率常常互相拉扯。高纯度不一定代表最适合功能实验；高回收率也不一定代表样本足够纯。

## 异常结果与可能原因

| 异常 | 可能原因 | 处理 |
| --- | --- | --- |
| 纯度低 | marker选择不合适、样本太脏、细胞数超载、孵育不足 | 重新确认 marker，降低负载，优化过滤和 blocking |
| 回收率低 | 目标细胞比例本来低、离心/洗涤损失、磁分离过度 | 做起始流式估计，减少洗涤损失 |
| 活率低 | 样本放置太久、温度/离心不当、操作时间过长 | 缩短流程，优化离心和缓冲液 |
| 分选后细胞不增殖 | 阳性选择影响受体、细胞应激、培养条件不匹配 | 换阴性选择，给恢复时间，优化培养基 |
| 流式验证marker变弱 | 分选抗体占位或内吞 | 换检测 clone 或 marker panel |
| 批次差异大 | donor差异、kit批号、磁体型号或操作者差异 | 固定关键变量并记录 lot 和操作者 |

## 小结

磁性细胞分选是一个快速、温和、适合大量样本预处理的细胞富集方法。关键不是“用了磁珠”，而是样本质量、marker 选择、阳性/阴性策略、磁体型号、纯度、回收率和活率。对于功能实验，细胞状态往往和纯度一样重要。
