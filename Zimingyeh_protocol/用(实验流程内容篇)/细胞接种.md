# 细胞接种

Cell seeding / cell plating（细胞接种/铺板）是把确定数量或密度的细胞加入培养容器，让细胞在指定表面、体积和环境中开始恢复、贴壁、增殖或进入实验处理的操作。它是 [细胞培养](细胞培养.md) 中最容易被低估的变量之一。

## 应用场景

- [细胞传代](细胞传代.md) 后重新接种到 [细胞培养瓶](<../材(实验耗材工具篇)/细胞培养瓶.md>)、[细胞培养皿](<../材(实验耗材工具篇)/细胞培养皿.md>) 或 [细胞培养板](<../材(实验耗材工具篇)/细胞培养板.md>)。
- 为药物处理、转染、感染、成像、克隆形成、流式、RT-qPCR 等实验铺板。
- [细胞复苏](细胞复苏.md) 后让细胞恢复生长。
- 建立细胞密度梯度，寻找最佳实验窗口。
- 接种悬浮细胞、免疫细胞、原代细胞、干细胞或类器官。

Thermo Fisher 把 cell seeding 定义为把细胞放入培养容器或表面，让其贴附、生长和增殖；接种前通常需要制备单细胞悬液并计数，以确定合适 seeding density（接种密度）。[参考：Thermo Fisher Seeding, Subculturing, and Maintaining Cells](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/maintaining-cultured-cells.html)

## 实验目的

细胞接种的目标是让每个实验单位从可比较的起点开始：

- 控制初始细胞数或细胞密度。
- 获得均匀分布，减少孔内和孔间差异。
- 让细胞在处理开始时处于合适 confluence（汇合度）或 density（密度）。
- 避免过稀导致恢复慢，或过密导致营养不足、接触抑制和状态改变。
- 为后续实验提供可重复的时间窗口。

## 简要实验原理

接种密度会影响细胞增殖曲线、营养可用性、空间、旁分泌信号、药物敏感性和转染效率。Thermo Fisher 明确指出，adherent culture（贴壁培养）中接种密度通常按 cells/cm2 表示；suspension culture（悬浮培养）中接种密度通常按 cells/mL 表示，错误密度会造成过密或稀疏生长并影响实验结果。[参考：Thermo Fisher Seeding Density](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/maintaining-cultured-cells.html)

ATCC 的贴壁细胞传代指南也提醒，不要把浓缩细胞悬液直接加入空培养容器，因为这会导致细胞贴壁和生长不均；多数培养物的初始接种可从约 10^3-10^4 cells/cm2 或更高范围开始，但具体细胞应遵循产品说明。[参考：ATCC Guide to Subculturing Cell Line Monolayers](https://www.atcc.org/resources/technical-documents/guide-to-subculturing-cell-line-monolayers)

## 接种密度怎么决定

### 按实验目的决定

| 目的 | 接种思路 |
| --- | --- |
| 日常传代 | 让细胞在下一次操作前达到合适汇合度 |
| 药物处理 | 处理开始时密度要一致，避免过密影响药物反应 |
| 转染 | 通常需要在转染时达到适合转染试剂的汇合度 |
| 免疫染色/成像 | 密度要让细胞形态清晰，避免重叠 |
| RT-qPCR/蛋白提取 | 密度要能提供足够样本量，同时避免过度汇合 |
| 克隆形成 | 接种密度极低，重点是单克隆分散 |
| 干细胞/原代细胞 | 按专用 protocol，过稀可能分化或死亡 |

### 贴壁细胞按面积

贴壁细胞建议按 cells/cm2 记录。不同 [细胞培养板](<../材(实验耗材工具篇)/细胞培养板.md>) 和 [细胞培养瓶](<../材(实验耗材工具篇)/细胞培养瓶.md>) 表面积不同，同样“每孔加 1 mL”并不代表细胞密度相同。比如同样 1 x 10^5 cells，在 6 孔板和 12 孔板上的密度完全不同。

### 悬浮细胞按体积

悬浮细胞建议按 cells/mL 记录。ATCC 指出，悬浮培养常见起始密度范围因细胞而异，过低可能进入 lag phase（滞后期）、生长很慢或死亡，过高则可能营养耗竭并突然死亡。[参考：ATCC Animal Cell Culture Guide](https://www.atcc.org/resources/culture-guides/animal-cell-culture-guide)

## 基本计算

常用公式：

```text
需要细胞总数 = 目标接种密度 × 接种面积或终体积
需要细胞悬液体积 = 需要细胞总数 / 当前细胞浓度
需要补加培养基体积 = 目标终体积 - 细胞悬液体积
```

例子：

```text
目标：6 孔板每孔接种 2.0 × 10^5 cells，终体积 2 mL
当前细胞浓度：1.0 × 10^6 cells/mL
每孔需要细胞悬液：2.0 × 10^5 / 1.0 × 10^6 = 0.2 mL
每孔补加培养基：2.0 - 0.2 = 1.8 mL
```

如果细胞悬液体积太小，移液误差会变大；可以先稀释细胞悬液，让每孔加入体积更容易准确操作。

## 实验操作

### 接种前准备

**怎么做**：确认实验设计、目标密度、培养容器、终体积、培养基配方和处理时间。预温培养基，准备好无菌耗材和标签。

**为什么**：接种后很难补救设计错误。比如目标处理时间是 24 h 后 70% 汇合，如果接种密度错了，后面处理、转染或成像都会偏离。

**注意事项**：

- 不要只写“接种一板”，要写细胞数、面积、终体积和处理时间。
- 多组实验尽量使用同一细胞悬液母液。
- 细胞状态差时不要硬铺关键实验。

**替代方案**：不确定密度时，先做小规模 seeding density titration（接种密度梯度）。

**出错后果**：处理时过密或过稀，实验窗口错过，重复实验。

### 制备均一细胞悬液

**怎么做**：贴壁细胞经消化终止后轻柔吹打成单细胞悬液；悬浮细胞充分混匀；必要时过滤去除团块。随后进行细胞计数和活率评估。

**为什么**：接种均匀的前提是细胞悬液均匀。团块会造成计数偏差、孔间密度不均和局部过密。

**注意事项**：

- 吹打要足够均匀，但不要过度损伤细胞。
- 细胞很快沉降，计数和分装之间要反复轻柔混匀。
- 对脆弱细胞可用宽口吸头或低剪切操作。

**替代方案**：

- 团块明显时，可用 [细胞过滤器](<../材(实验耗材工具篇)/细胞过滤器.md>)。
- 黏性强或死细胞多时，可能需要优化消化、加入 DNase I 或换用更温和流程。

**出错后果**：某些孔细胞多、某些孔细胞少；显微镜下出现团块，数据离散度变大。

### 配制接种混悬液

**怎么做**：根据目标总孔数和额外损耗量，配制统一的接种混悬液。通常多配 5%-10% 以补偿移液损耗。配好后轻柔颠倒或移液混匀。

**为什么**：逐孔单独计算和混合容易造成误差；统一母液可以减少孔间差异。

**注意事项**：

- 不要剧烈涡旋细胞。
- 母液容器要足够大，避免细胞集中在底部。
- 接种过程中每隔数孔轻柔混匀一次。

**替代方案**：高通量实验可使用多道移液枪、储液槽或自动化液体处理系统，但要验证细胞沉降和剪切影响。

**出错后果**：后接种孔细胞偏少或偏多，板内出现梯度差异。

### 加入培养容器

**怎么做**：先在容器中加入部分培养基，再加入计算好的细胞悬液，或加入已混好的接种混悬液。ATCC 特别提醒，不要把浓缩细胞悬液直接加入空培养容器，因为这会造成细胞贴附和生长不均。[参考：ATCC Guide to Subculturing Cell Line Monolayers](https://www.atcc.org/resources/technical-documents/guide-to-subculturing-cell-line-monolayers)

**为什么**：细胞需要均匀分散在培养表面或培养体积中。浓缩液滴直接接触底部，会让细胞局部集中。

**注意事项**：

- 贴壁细胞避免气泡，气泡下方没有细胞贴壁。
- 多孔板加样时枪头贴壁，避免飞溅和交叉污染。
- 接种小体积孔时，蒸发和边缘效应更明显。

**替代方案**：

- 对 96 孔板，可先加培养基再加细胞母液，或直接使用均一细胞混悬液加样。
- 对极低密度克隆形成实验，可增加终体积或使用条件化培养基支持存活。

**出错后果**：细胞成团、局部过密、孔内分布不均、边缘孔差异。

### 摇匀和放入培养箱

**怎么做**：接种后轻轻前后、左右十字方向晃动 [细胞培养板](<../材(实验耗材工具篇)/细胞培养板.md>) 或 [细胞培养瓶](<../材(实验耗材工具篇)/细胞培养瓶.md>)，使细胞均匀分布；不要画圈。随后平稳放入 [CO2培养箱](<../材(实验耗材工具篇)/CO2培养箱.md>)。

**为什么**：画圈容易让细胞集中到中央或边缘，造成分布不均。放入培养箱后的最初数小时是贴壁和恢复关键期。

**注意事项**：

- 不要剧烈晃动，避免细胞堆积到边缘。
- 多孔板放入培养箱时保持水平。
- 刚接种后尽量减少移动，特别是贴壁弱细胞。

**替代方案**：对要求高度均匀的成像或药筛，可使用低蒸发板、预平衡培养箱和固定板位。

**出错后果**：孔内细胞分布呈漩涡状、边缘密度高、成像区域不可比。

### 接种后检查

**怎么做**：贴壁细胞通常在数小时或次日观察贴壁、分布和形态；悬浮细胞观察密度、团聚和碎片。记录实际接种密度和观察结果。

**为什么**：接种后检查能及时发现加错孔、细胞不均、气泡、污染或贴壁失败。

**注意事项**：

- 不要太频繁拿出 [细胞培养板](<../材(实验耗材工具篇)/细胞培养板.md>)，避免温度和 CO2 波动。
- 成像或处理实验前确认细胞密度已经达到预期。
- 如果发现某些孔明显异常，记录并考虑剔除。

**替代方案**：高通量实验可用板扫描或自动显微成像做均一性评估。

**出错后果**：异常孔进入统计，造成假阳性、假阴性或重复性差。

## 常见异常结果与 troubleshooting

| 异常结果 | 可能原因 | 处理策略 |
| --- | --- | --- |
| 孔间细胞数差异大 | 细胞沉降、母液未混匀、加样时间太长 | 接种中定期混匀，缩短加样时间，多配母液 |
| 孔内分布不均 | 画圈摇板、气泡、浓缩细胞液直接落底 | 十字轻晃，去除气泡，使用均一混悬液 |
| 处理时细胞过密 | 接种密度太高、细胞增殖太快、处理时间太晚 | 做密度梯度，提前处理或降低接种密度 |
| 处理时细胞过稀 | 接种密度太低、复苏/传代损伤、活率低 | 提高密度，延长恢复，检查活率 |
| 细胞不贴壁 | 培养表面不合适、细胞受损、培养基错误 | 换包被表面，优化消化，核对培养基 |
| 边缘孔异常 | 蒸发、温度梯度、外圈孔体积变化 | 避免使用边缘孔，外圈加 PBS/培养基作缓冲 |
| 药物曲线漂移 | 初始密度不同、加药时间不同、细胞状态不同 | 固定接种密度、处理时间和 passage window |
| 转染效率差 | 接种过稀/过密、处理时汇合度不合适 | 按转染试剂说明优化处理时汇合度 |

## 小结

细胞接种是把细胞培养从“养活”转向“可实验”的关键步骤。真正要控制的是细胞状态、接种密度、分布均匀性、终体积和处理时间。日常维护可以用经验传代比例，定量实验则应尽量按细胞数、面积或体积精确接种，并记录实际密度。
