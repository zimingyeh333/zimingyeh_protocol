# 悬浮细胞培养

Suspension cell culture（悬浮细胞培养）是指细胞主要在培养液中悬浮生长，而不是依赖培养表面贴壁生长的培养方式。常见对象包括血液来源细胞、淋巴细胞样细胞、杂交瘤、部分白血病/淋巴瘤细胞系、PBMC、T 细胞、B 细胞和一些适应悬浮培养的生产细胞。

## 应用场景

- 免疫细胞、造血系统细胞、杂交瘤和悬浮肿瘤细胞系维护。
- 抗体生产、病毒扩增、蛋白表达或细胞治疗相关体外扩增。
- 需要按 cells/mL 控制密度的药物处理、激活、感染和流式实验。
- 从小体积静置培养逐步扩大到摇瓶、生物反应器或其他悬浮系统。

ATCC 的动物细胞培养指南指出，一些细胞天然在悬浮中生长，也有一些细胞系可以适应悬浮培养；悬浮细胞传代通常通过稀释到合适细胞浓度来完成，而不是像贴壁细胞那样先消化。[参考：ATCC Animal Cell Culture Guide](https://www.atcc.org/resources/culture-guides/animal-cell-culture-guide)

## 实验目的

悬浮细胞培养的核心目标是维持合适 viable cell density（活细胞密度）和 viability（活率）：

- 让细胞处于推荐密度窗口，而不是过稀或过密。
- 维持足够营养、pH 和代谢废物控制。
- 减少团聚、碎片、死细胞和污染。
- 为实验提供一致的活细胞输入量。
- 根据细胞类型控制激活状态、分化状态或生产状态。

## 简要实验原理

悬浮细胞没有“汇合度”这个概念，不能用“铺满几成”判断是否传代。它们的核心指标是：

| 指标 | 意义 |
| --- | --- |
| Viable cell density（活细胞密度） | 决定是否需要稀释、补液、换液或收集 |
| Viability（活率） | 判断细胞健康程度和是否适合实验 |
| Doubling time（倍增时间） | 决定传代频率和接种密度 |
| Clumping（团聚） | 影响计数、营养交换和实验均一性 |
| Medium color / pH | 反映代谢和培养环境 |

Thermo Fisher 的 maintaining cultured cells 页面也强调，悬浮培养的 seeding density（接种密度）通常按 cells/mL 表示；过稀或过密都会影响生长和实验结果。[参考：Thermo Fisher Maintaining Cultured Cells](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/maintaining-cultured-cells.html)

## 关键判断

### 细胞密度窗口

每种悬浮细胞都有推荐密度窗口。ATCC 的动物细胞培养指南提醒，悬浮细胞若稀释到推荐最低密度以下，可能进入 lag phase（滞后期），生长很慢甚至死亡；如果密度过高，则会因为营养耗尽和代谢废物积累而快速死亡。[参考：ATCC Animal Cell Culture Guide](https://www.atcc.org/resources/culture-guides/animal-cell-culture-guide)

因此悬浮细胞不能只问“几天换一次液”，而要问：当前 cells/mL、活率、培养基颜色、倍增速度和实验时间点是什么。

### 团聚

悬浮细胞团聚可能来自细胞本身特性、DNA 黏连、死亡增加、钙镁离子、细胞密度过高或操作刺激。轻微团聚有时是正常特征，严重团聚会影响计数、营养交换和实验均一性。

### 静置 vs 动态悬浮

一些悬浮细胞适合静置 [细胞培养瓶](<../材(实验耗材工具篇)/细胞培养瓶.md>) 或 [细胞培养板](<../材(实验耗材工具篇)/细胞培养板.md>)，一些生产细胞适合摇瓶或反应器。摇动可以改善混合和气体交换，但也带来 shear stress（剪切应力）。不要把静置培养条件直接套到摇瓶，也不要把摇瓶转速当成越高越好。

## 实验操作

### 日常观察与计数

**怎么做**：轻柔混匀培养物，取样做细胞计数和活率测定，同时观察团聚、碎片、培养基颜色和污染迹象。

**为什么**：悬浮细胞沉降或团聚会让取样不代表整体。没有计数，仅凭颜色和肉眼浑浊度判断密度很不可靠。

**注意事项**：

- 取样前必须混匀，但不要产生大量泡沫。
- 记录活细胞密度，而不仅是总细胞密度。
- 死细胞碎片多时，[自动细胞计数仪](<../材(实验耗材工具篇)/自动细胞计数仪.md>) 可能误判。

**替代方案**：高密度生产培养可使用在线细胞密度或代谢指标，但日常小规模仍需要显微和计数复核。

**出错后果**：传代密度错误、实验输入量不一致、过密后突然大量死亡。

### 稀释传代

**怎么做**：根据当前活细胞密度和目标起始密度，计算需要保留的细胞悬液体积，再加入新鲜完全培养基到目标总体积。

```text
需要保留细胞悬液体积 = 目标活细胞密度 × 目标总体积 / 当前活细胞密度
```

**为什么**：悬浮细胞最常见的传代方式就是 dilution split（稀释传代）。它保留细胞分泌因子和部分条件化环境，操作温和。

**注意事项**：

- 目标密度不要低于该细胞推荐最低密度。
- 如果旧培养基已经很酸或死细胞多，单纯稀释可能不够。
- 每次传代记录当前密度、目标密度和最终体积。

**替代方案**：状态好但密度略高时补加培养基；状态差或酸化严重时离心换液。

**出错后果**：细胞太稀不恢复，或太密导致短时间内酸化死亡。

### 离心换液

**怎么做**：将细胞悬液转入离心管，低速离心形成细胞沉淀，弃上清后用新鲜培养基轻柔重悬，并调整到目标密度。

**为什么**：离心换液可以去除酸化培养基、死细胞碎片、小分子处理物或残余刺激物，但也会给细胞带来机械压力。

**注意事项**：

- 离心力和时间按细胞类型优化，免疫细胞和原代悬浮细胞通常更敏感。
- 弃上清时不要吸走松散沉淀。
- 重悬时避免剧烈吹打和泡沫。

**替代方案**：

- 半量换液：沉降或轻柔离心后只换部分上清。
- 密度调整：直接补液稀释，减少离心损伤。
- 死细胞多时可用专用死细胞去除方法，但要评估偏倚。

**出错后果**：离心损伤、活率下降、细胞沉淀丢失、重悬不均。

### 接种和扩增

**怎么做**：按目标 cells/mL 接种到合适体积和容器中。小体积实验注意蒸发，大体积培养注意气体交换、混合和容器通气。

**为什么**：悬浮培养的“空间”不是底面积，而是培养体积、气体交换和细胞密度。过高体积或密封不良会影响 pH 和氧气；过低体积易蒸发和浓缩。

**注意事项**：

- 使用透气盖或合适瓶盖状态，避免完全密闭导致气体交换不足。
- 摇瓶培养要控制转速、装液体积和细胞对剪切的耐受。
- 多孔板悬浮细胞实验要防止边缘孔蒸发。

**替代方案**：从小规模静置培养放大到摇瓶前，先做密度、转速和装液体积梯度。

**出错后果**：pH 漂移、氧不足、剪切损伤、细胞密度不可控。

### 处理团聚

**怎么做**：先判断团聚是否影响实验。轻微团聚可通过温和吹打和充分混匀改善；严重团聚需要回查细胞死亡、密度、培养基离子、DNA 黏连和细胞类型特性。

**为什么**：团聚不是单纯“吹散”就结束。粗暴吹打会伤细胞，过滤可能丢失某些细胞群，DNase I 只能解决 DNA 黏连相关问题。

**注意事项**：

- 记录团聚程度，特别是流式、药物处理和计数前。
- 自动计数前严重团聚会导致结果不可靠。
- 对本来以团聚生长的细胞，不要强行打成单细胞而损伤状态。

**替代方案**：

- 优化密度窗口，避免过密。
- 使用宽口吸头、细胞过滤器或温和酶处理。
- DNA 黏连明显时考虑 DNase I。

**出错后果**：计数错误、药物暴露不均、流式堵管、细胞死亡增加。

## 与贴壁细胞的关键区别

| 问题 | 贴壁细胞 | 悬浮细胞 |
| --- | --- | --- |
| 状态判断 | 汇合度 + 形态 | 活细胞密度 + 活率 + 团聚 |
| 传代方式 | 解离后重新接种 | 稀释、补液或离心换液 |
| 接种单位 | cells/cm2 或每孔细胞数 | cells/mL |
| 换液方式 | 吸走旧液，加新培养基 | 稀释、离心换液或部分换液 |
| 主要风险 | 过度消化、贴壁差、冲掉细胞 | 过稀、过密、团聚、离心损伤 |

## 特殊悬浮细胞

| 类型 | 培养重点 |
| --- | --- |
| Jurkat / Raji 等淋巴样细胞 | 密度窗口和活率比形态更重要 |
| THP-1 等单核样细胞 | 可能有半贴壁或团聚倾向，处理刺激会改变状态 |
| 杂交瘤 | 关注抗体产量、密度和培养基酸化 |
| PBMC / T 细胞 | 供体差异大，激活状态和细胞因子很关键 |
| CHO / HEK293 悬浮生产细胞 | 摇瓶、转速、补料和剪切应力是重点 |

## 常见异常结果与 troubleshooting

| 异常结果 | 可能原因 | 处理策略 |
| --- | --- | --- |
| 细胞生长慢 | 起始密度太低、培养基不合适、复苏未恢复、支原体 | 提高起始密度，核对培养基，检测支原体 |
| 活率下降 | 过密、酸化、离心过猛、剪切过强、污染 | 降低密度，换液，优化离心和转速 |
| 团聚严重 | 死细胞 DNA、密度高、细胞特性、培养条件不合适 | 温和吹散，过滤，优化密度，必要时 DNase I |
| 培养基很快变黄 | 密度过高、代谢快、污染、CO2 异常 | 计数，稀释或换液，检查培养箱和污染 |
| 计数差异大 | 混匀不足、团聚、碎片多、自动识别错误 | 重新混匀，手动复核，过滤或优化阈值 |
| 传代后大量死亡 | 稀释过低、离心损伤、培养基温度/pH 冲击 | 维持最低密度，降低离心强度，预温培养基 |
| 流式堵管 | 团块、DNA 黏连、碎片多 | 过滤，加入 EDTA 或 DNase I，优化收集流程 |

## 小结

悬浮细胞培养的核心不是汇合度，而是活细胞密度窗口。最常见错误是把悬浮细胞当贴壁细胞理解，忽视过稀、过密、团聚和离心损伤。稳定的悬浮培养应该固定计数频率、目标密度、换液方式、活率阈值和培养容器条件。
