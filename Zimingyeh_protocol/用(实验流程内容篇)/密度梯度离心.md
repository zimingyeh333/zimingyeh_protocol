# 密度梯度离心

密度梯度离心（density gradient centrifugation）是利用细胞或颗粒在特定 density medium（密度介质）中的 buoyant density（浮力密度）差异，通过离心形成分层，从而分离目标细胞群的方法。在细胞实验中，它最常见的用途之一是用 [Ficoll](<../材(实验耗材工具篇)/Ficoll.md>) 或类似密度介质从全血、buffy coat（白膜层）或骨髓样本中分离 [外周血单个核细胞](<../番外/补充知识/外周血单个核细胞.md>)（Peripheral Blood Mononuclear Cells，PBMC）。

## 实验发明历史

密度梯度分离的思想来自离心技术和胶体/高分子密度介质的发展：当样本被置于密度介质上方并离心时，不同密度和沉降特性的细胞会分布到不同层。Ficoll-Paque、Lymphoprep、Histopaque 等介质把这个原理标准化为血液单个核细胞分离 workflow。

在现代免疫学和血液学实验里，密度梯度离心常被当作 PBMC 分离的经典前处理步骤。STEMCELL Technologies 的 PBMC isolation 资料也将密度梯度分离列为从人血样本获得 PBMC 的常见方法。参考：[STEMCELL PBMC Isolation](https://www.stemcell.com/peripheral-blood-mononuclear-cell-isolation.html)。

## 应用场景

| 场景 | 目标 | 关键变量 |
| --- | --- | --- |
| 全血分离 PBMC | 去除大部分红细胞和粒细胞，获得单个核细胞层 | 抗凝剂、稀释比例、分层、离心制动 |
| Buffy coat 分离 PBMC | 从浓缩白膜层获得更多 PBMC | 样本黏稠度、稀释充分性、界面扰动 |
| 骨髓单个核细胞分离 | 富集骨髓 mononuclear cells | 样本异质性更高，红细胞残留更常见 |
| 分选前预处理 | 为 [磁性细胞分选](磁性细胞分选.md) 或 [流式细胞术](流式细胞术.md) 提供输入 | 活率、团聚、血小板残留 |
| 冻存前样本制备 | 获得较干净的 PBMC 或 MNC 输入 | Ficoll 残留、细胞损伤、冻存密度 |

## 实验目的

密度梯度离心的目的不是获得“绝对纯”的某一种细胞，而是把复杂血液样本初步分成几个层次：plasma（血浆）、mononuclear cell layer（单个核细胞层）、density medium（密度介质层）、granulocyte/erythrocyte pellet（粒细胞/红细胞沉淀）。对于 PBMC 实验，它的核心价值是用相对温和、成本可控的方式获得免疫细胞混合群，为后续培养、分选、流式、转录组或功能实验提供输入。

## 简要实验原理

常用 PBMC 分离介质的密度约为 1.077 g/mL。离心时，红细胞和多数粒细胞密度较高，会穿过密度介质沉到底部；PBMC 密度较低，通常停留在血浆和密度介质的界面形成白色云雾状 ring；血小板和血浆蛋白主要留在上层或在洗涤中去除。

这里最容易误解的一点是：离心不是单纯“越快越好”。如果相对离心力（relative centrifugal force，RCF，常写作 x g）、时间、温度、制动方式或分层手法不合适，界面会混乱，PBMC 回收率、纯度和活率都会下降。

## 实验操作

下面是 PBMC 分离的通用理解框架。不同品牌密度介质和管型的推荐 RCF、时间和体积比例可能不同，正式实验应优先遵循对应产品说明书和本实验室 SOP。

### 样本准备与稀释

通常将抗凝全血或 buffy coat 用 PBS/DPBS 或合适缓冲液稀释，使样本黏稠度下降、细胞更容易在离心中形成清晰界面。

**为什么重要**：血液太黏会导致分层困难，PBMC ring 不清楚，红细胞和粒细胞污染增加。

**注意事项**：记录抗凝剂类型、采血时间、室温/冷藏运输、处理开始时间。PBMC 对处理延迟很敏感，采血后放置过久会改变活率和激活状态。

**替代方案**：如果样本是 buffy coat，通常需要更充分稀释；如果后续做功能实验，洗涤液中是否加 EDTA、BSA 或血清要按下游实验验证。

**出错后果**：样本凝块、黏稠或细胞团聚会造成 PBMC 回收率低、流式背景高、细胞计数不准。

### 分层到密度介质上方

将稀释后的样本缓慢加到 Ficoll 或类似密度介质上方，目标是形成清楚的上下两层，而不是把血液和密度介质混匀。

**为什么重要**：清晰界面是后续 PBMC ring 清楚的前提。分层失败会让细胞在整个管内混杂，最终得到的界面宽、脏、难吸。

**注意事项**：加样动作要慢，管壁缓慢加入或使用移液管贴壁加入。不要让枪头直接冲击 Ficoll 层。样本体积和密度介质体积要按产品说明控制。

**替代方案**：可以使用 SepMate 管等带隔离结构的耗材降低分层难度；但这类耗材的离心条件和回收方式要按厂家说明执行。

**出错后果**：如果两层混合，常见结果是 PBMC 层不清晰、红细胞污染增加、回收量不稳定。

### 离心

按密度介质说明书设置 RCF、时间、温度和制动。经典 Ficoll-Paque 类分离通常会强调使用较温和的制动或关闭 brake（刹车），避免离心结束时界面被扰动。

**为什么重要**：PBMC ring 是一个脆弱的界面层，急刹会把各层重新搅动。RCF 不足会分离不完全，RCF 过强或时间过长可能增加细胞应激。

**注意事项**：记录 RCF 而不是只写 rpm。rpm 和真实离心力取决于转子半径，不同离心机之间不能直接照抄。温度也要记录，因为密度介质和细胞状态都可能受温度影响。

**替代方案**：不同品牌介质、管型和样本来源的离心条件不同。全血、buffy coat、骨髓样本不能机械套同一条件。

**出错后果**：刹车太强会导致界面消失；RCF/时间不足会残留大量红细胞或粒细胞；条件过强可能导致活率下降。

### 吸取 PBMC 界面层

离心后可见上层血浆、界面 PBMC ring、下方 Ficoll 层和底部红细胞/粒细胞沉淀。用移液器或巴斯德吸管小心吸取界面层，尽量减少带入 Ficoll 和底部细胞。

**为什么重要**：PBMC 的纯度和活率很大程度取决于这一步。带入太多 Ficoll 会影响后续培养和计数，吸到底部沉淀会增加红细胞/粒细胞污染。

**注意事项**：宁愿少吸一点界面，也不要为了追求回收率把下层 Ficoll 和沉淀一起吸上来。记录界面是否清晰、是否有红细胞污染、是否有凝块。

**替代方案**：如果下游只需要高回收量，可以接受略低纯度再通过洗涤、过滤或红细胞裂解补救；如果下游是敏感功能实验，优先保持样本干净。

**出错后果**：吸取太深会造成红细胞、粒细胞和 Ficoll 污染；吸取太浅会损失 PBMC。

### 洗涤与去除血小板/Ficoll

将 PBMC 层转移到新管中，用 PBS/DPBS 或培养基补足体积后离心洗涤。通常需要至少一次洗涤，某些对血小板敏感的实验需要增加低速洗涤步骤。

**为什么重要**：Ficoll 残留、血小板和血浆蛋白会影响计数、流式背景、细胞培养和功能读数。

**注意事项**：洗涤时重悬要温和但充分。PBMC 容易沉降，取样计数前要混匀。避免过度离心导致细胞损伤或团聚。

**替代方案**：如果细胞团聚明显，可过滤或在合适情况下加入低浓度 EDTA；如果红细胞残留明显，可短时间使用红细胞裂解液，但要评估对目标细胞的影响。

**出错后果**：洗涤不足会造成 Ficoll/血小板残留；洗涤过度或条件太强会降低活率和回收率。

### 计数、活率与下游处理

使用台盼蓝或自动细胞计数仪记录总细胞数和活率。根据下游用途选择立即培养、流式检测、磁性细胞分选、冻存或功能刺激。

**为什么重要**：PBMC 是混合群，只有总数不够，还应根据实验需要记录亚群比例、活率、红细胞残留和处理时间。

**注意事项**：冻存前应控制细胞密度和冻存液；功能实验前是否需要 rest（休整）要按实验目的验证。

**替代方案**：如果样本状态差，优先做活率和基础表型判断，再决定是否进入昂贵或关键下游实验。

**出错后果**：输入细胞状态差会导致流式背景高、刺激反应弱、RNA 质量差或分选回收率低。

## 结果解析

| 观察结果 | 说明 | 下一步 |
| --- | --- | --- |
| PBMC ring 清楚、白色云雾状 | 分层较成功 | 小心吸取并充分洗涤 |
| PBMC 层很宽、很浑浊 | 分层扰动或血小板/杂细胞多 | 洗涤和过滤，复盘分层与刹车 |
| 红细胞残留多 | 吸取过深、样本处理差或分离条件不合适 | 必要时红细胞裂解，优化下一次操作 |
| 细胞活率低 | 采血后延迟、离心过强、温度或冻融问题 | 记录并评估是否适合下游功能实验 |
| 回收率低 | PBMC 界面吸取不足、洗涤损失或样本本身少 | 比较 input/output，优化吸取和洗涤 |

## 可能出现异常结果及对应原因

| 异常 | 常见原因 | 处理策略 |
| --- | --- | --- |
| 看不到清晰 PBMC ring | 样本与 Ficoll 混合、刹车太强、血液凝固 | 重新练习分层，关闭/降低 brake，检查抗凝和处理时间 |
| 底部沉淀松散上浮 | 离心条件不足或制动扰动 | 复核 RCF、时间、转子和 brake |
| 红细胞污染严重 | 吸取太深、密度介质选择不合适、样本异常 | 吸取时保守，必要时做红细胞裂解 |
| 血小板很多 | 洗涤不足或离心速度不合适 | 增加合适的洗涤步骤，避免过度重悬泡沫 |
| 细胞团聚 | 死细胞多、DNA 释放、血小板残留 | 过滤、温和吹打，必要时使用 EDTA 或 DNase 条件 |
| 后续流式背景高 | Fc 受体、死细胞、血小板、非特异结合 | 加死活染、Fc block，优化洗涤和 gating |

## Ficoll、Lymphoprep、Histopaque、Percoll 的区别

| 介质 | 核心用途 | 常见特点 | 选择提醒 |
| --- | --- | --- | --- |
| [Ficoll](<../材(实验耗材工具篇)/Ficoll.md>) / Ficoll-Paque | PBMC/MNC 分离 | 经典、文献多、品牌版本多 | 记录具体产品和密度 |
| [Lymphoprep](<../材(实验耗材工具篇)/Lymphoprep.md>) | PBMC 分离 | 常见密度 1.077 g/mL，临床/研究常用 | 与 Ficoll-Paque 类似但不可只写“Ficoll”代替 |
| [Histopaque](<../材(实验耗材工具篇)/Histopaque.md>) | 单个核细胞或特定血细胞分离 | Sigma-Aldrich 产品线，常见 1077/1119 | 不同密度版本用途不同 |
| [Percoll](<../材(实验耗材工具篇)/Percoll.md>) | 自制连续/不连续密度梯度 | 可调密度，适合更灵活分离 | 配制和渗透压控制更复杂 |

## 小结

密度梯度离心的关键不是“把血一离心”，而是样本状态、密度介质、分层、RCF、制动、界面吸取和洗涤共同决定结果。写实验记录时要避免只写“Ficoll 分离 PBMC”，应至少写清产品名、密度、货号/批号、样本来源、处理时间、离心条件、brake 设置、细胞数和活率。
