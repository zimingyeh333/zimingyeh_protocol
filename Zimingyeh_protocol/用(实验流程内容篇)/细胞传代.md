# 细胞传代

Subculture / passage（细胞传代）是把正在培养的细胞从原培养体系转移到新的培养体系中，使其继续增殖或维持状态的操作。它包括贴壁细胞的解离、悬浮细胞的稀释或重悬、细胞计数、重新接种和传代数记录。

## 应用场景

- 维持常规 [细胞培养](细胞培养.md)，避免细胞过密或营养耗竭。
- 为实验铺板、扩增细胞或建立冻存库存。
- 在药物处理、转染、感染、成像、[RT-qPCR](RT-qPCR.md) 或蛋白实验前，把细胞调整到合适状态。
- 通过固定传代窗口减少批次差异。

Thermo Fisher 把 subculturing（传代）定义为从原培养物移除培养基并把细胞转移到新鲜培养基中的过程，其目的是让 cell line（细胞系）或 cell strain（细胞株）继续繁殖。[参考：Thermo Fisher Maintaining Cultured Cells](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/maintaining-cultured-cells.html)

## 实验目的

细胞传代的目的不是“细胞满了就分一下”，而是让细胞保持在适合实验的生长窗口中：

- 维持对数生长期，避免过度汇合、接触抑制和营养耗竭。
- 保持可控 passage number（传代数），减少长期培养造成的状态漂移。
- 获得均一单细胞悬液或稳定细胞群，用于接种、计数或冻存。
- 根据实验需求调整接种密度、传代比例和恢复时间。

## 简要实验原理

细胞在培养中通常经历 lag phase（滞后期）、log phase（对数生长期）和 stationary phase（平台期）。传代过早，细胞可能还没有恢复；传代过晚，细胞可能已经过度拥挤、代谢改变或进入接触抑制。Thermo Fisher 提醒，反复传代可能改变细胞关键特征和基因组稳定性，因此需要跟踪传代次数并保持详细记录。[参考：Thermo Fisher Maintaining Cultured Cells](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/maintaining-cultured-cells.html)

| 变量 | 对传代的影响 |
| --- | --- |
| 汇合度/密度 | 决定是否需要传代，以及传代比例 |
| 细胞形态 | 判断是否健康、污染、分化或应激 |
| 解离方式 | 影响细胞活率、表面蛋白和下游实验 |
| 接种密度 | 决定恢复速度、增殖曲线和实验窗口 |
| 传代数 | 影响遗传稳定性、表型和实验可重复性 |

## 什么时候传代

### 贴壁细胞

贴壁细胞通常根据 confluence（汇合度）决定传代。很多常规细胞系在约 70%-90% 汇合度时传代比较合适，但这不是硬规则。ATCC 的贴壁细胞传代指南强调，不同细胞系的传代比例和培养条件应以具体细胞页面或说明书为准。[参考：ATCC Guide to Subculturing Cell Line Monolayers](https://www.atcc.org/resources/technical-documents/guide-to-subculturing-cell-line-monolayers)

太早传代会导致细胞恢复慢；太晚传代会让细胞进入高密度应激、接触抑制或状态漂移。干细胞、内皮细胞、原代细胞尤其不适合长期过度汇合。

### 悬浮细胞

悬浮细胞通常根据 viable cell density（活细胞密度）和活率决定传代。它们没有“汇合度”，重点是维持合适密度窗口：太稀可能缺少旁分泌支持，太密则营养耗竭、死亡增加和代谢废物积累。

### 实验前传代

关键实验前应固定传代窗口，例如“传代后 24 h 铺板”或“铺板后 18-24 h 处理”。如果每次实验使用不同恢复时间、不同传代数或不同密度，后续结果很难比较。

## 实验操作

### 传代前检查

**怎么做**：显微镜观察细胞形态、密度、漂浮死细胞、污染迹象和培养基颜色。确认培养基、洗液、解离试剂和新培养容器已经准备好。

**为什么**：状态差、污染可疑或过度汇合的细胞不适合直接用于关键实验。传代前观察可以避免把问题扩散到更多培养瓶。

**注意事项**：

- 发现污染时不要继续传代扩增。
- 细胞形态异常时先判断原因，再决定是否传代、丢弃或复苏新库存。
- 重要实验前记录显微镜照片。

**替代方案**：不确定污染时，先隔离培养并做 [细胞污染](细胞污染.md) 或 [支原体检测](支原体检测.md)。

**出错后果**：把污染或异常细胞扩增，导致后续多批实验失败。

### 贴壁细胞传代

**怎么做**：

1. 吸去旧培养基。
2. 用不含钙镁的 PBS/DPBS 轻洗，去除血清。
3. 加入足够覆盖细胞层的解离试剂。
4. 观察细胞变圆、间隙增大、轻敲后脱落。
5. 用含血清培养基或专用终止液终止解离。
6. 轻柔吹打成均一细胞悬液。
7. 取样计数，按目标密度重新接种。

Thermo Fisher 的 adherent cell culture protocol 也采用类似逻辑：洗涤、加入 trypsin 或 TrypLE 等 dissociation reagent（解离试剂）、观察脱落、加入完全培养基并转移细胞。[参考：Thermo Fisher Adherent Cell Culture Protocol](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/cell-culture-protocols/subculturing-adherent-cells.html)

**为什么**：洗去血清是为了避免血清抑制胰酶；控制解离时间是为了既让细胞脱落，又尽量减少膜蛋白损伤和死亡。

**注意事项**：

- 不要机械等待固定分钟数，应该显微镜下看细胞状态。
- 不要过度吹打，尤其是原代细胞、干细胞或神经细胞。
- 不同细胞对胰酶、TrypLE、Accutase 的耐受不同。

**替代方案**：

- 表面 marker 敏感时，使用 Accutase、EDTA-only 或非酶解离。
- 贴壁很强时，可延长解离时间、提高温度一致性或轻敲培养瓶，但不要粗暴刮。
- 需要保留细胞外基质或细胞片时，不适合常规胰酶传代。

**出错后果**：

- 解离不足：细胞团块多，计数不准，接种不均。
- 解离过度：细胞死亡、贴壁差、表面蛋白受损。
- 洗涤太粗暴：细胞提前脱落或局部损伤。

### 悬浮细胞传代

**怎么做**：充分轻柔混匀细胞悬液，取样计数活细胞密度，再按目标密度补加新鲜培养基或离心后重悬。传代可以是 dilution split（稀释传代），也可以是离心收集后换液。

**为什么**：悬浮细胞的核心是密度窗口，而不是贴壁面积。细胞太稀恢复慢，太密会出现营养耗竭、酸化、碎片增加和活率下降。

**注意事项**：

- 计数前混匀很重要，悬浮细胞沉降会造成取样误差。
- 团聚细胞需要判断是否为正常聚团、DNA 黏连或死亡增加。
- 离心条件要温和，避免把细胞压成难重悬沉淀。

**替代方案**：

- 密度略高但状态好时，可直接补加培养基。
- 代谢废物或死细胞多时，离心换液更合适。
- 团聚明显时，可优化吹打、过滤、加入 [DNase I](<../材(实验耗材工具篇)/DNase I.md>) 或调整培养条件。

**出错后果**：密度漂移、活率下降、实验处理时细胞状态不一致。

### 计数与接种

**怎么做**：传代得到细胞悬液后，取代表性样本进行 [细胞计数](细胞计数.md)，并根据目标 vessel（培养容器）面积或体积计算接种量。贴壁细胞按 cells/cm2，悬浮细胞按 cells/mL 更清楚。

**为什么**：传代比例只是一种经验表达，接种密度才是决定后续状态的直接变量。Thermo Fisher 也强调，seeding density（接种密度）会影响营养可用性、生长空间和实验结果。[参考：Thermo Fisher Maintaining Cultured Cells](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/maintaining-cultured-cells.html)

**注意事项**：

- 不要只写“1:3 传代”，最好同时记录细胞数或接种密度。
- 接种板时要持续轻柔混匀，避免细胞沉降导致前后孔密度不同。
- 多孔板铺板后可轻轻十字方向晃匀，不要画圈造成细胞集中到边缘。

**替代方案**：不做精确实验时可用固定 split ratio；做定量实验时应优先按细胞数接种。

**出错后果**：孔间差异、边缘效应、转染效率不稳定、药物曲线漂移。

### 传代后观察

**怎么做**：贴壁细胞在传代后数小时或次日观察贴壁、形态和均匀性；悬浮细胞观察密度、团聚、碎片和活率。必要时换液或调整密度。

**为什么**：传代本身就是一次扰动。传代后观察可以判断解离是否过度、接种是否均匀、培养基是否合适。

**注意事项**：

- 不要在细胞刚贴壁时频繁移动培养容器。
- 传代后短时间内形态略圆不一定异常，但持续不恢复需要追查。
- 关键实验前最好让细胞恢复到稳定窗口。

**替代方案**：敏感细胞可传代后使用条件化培养基、包被表面或专用恢复补充剂。

**出错后果**：把传代损伤误认为处理效应，或者在细胞尚未稳定时开始实验。

### 传代数记录

**怎么做**：每次传代都记录 passage number（传代数）、split ratio（传代比例）、接种密度、培养基批号、解离方法和形态。Thermo Fisher 建议记录 feeding/subculture schedule（换液/传代计划）、培养基、解离流程、传代比例、形态、接种浓度、产量和抗生素使用。[参考：Thermo Fisher Maintaining Cultured Cells](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/maintaining-cultured-cells.html)

**为什么**：细胞长期传代会出现遗传和表型漂移。没有传代数和操作记录，就很难判断实验差异来自处理还是细胞历史。

**注意事项**：

- 同一实验项目尽量限定 passage window，例如 P5-P20。
- 不同来源细胞的 passage number 不一定可直接比较。
- 复苏、冻存和传代的加一规则要在实验室内部统一。

**替代方案**：对关键细胞建立 master stock 和 working stock，定期从低传代库存重新启动。

**出错后果**：高传代漂移、不同批次不可比、发表或复现实验时无法说明细胞历史。

## 常见异常结果与 troubleshooting

| 异常结果 | 可能原因 | 处理策略 |
| --- | --- | --- |
| 细胞传代后不贴壁 | 消化过度、接种太稀、培养表面不合适、培养基错误 | 缩短解离时间，提高接种密度，使用包被容器 |
| 细胞团块多 | 解离不足、吹打不足、DNA 来自死亡细胞 | 延长解离或优化试剂，轻柔吹匀，必要时过滤 |
| 细胞大量死亡 | 解离过度、离心过猛、培养基温度/pH 不合适 | 降低操作强度，核对培养基和培养箱 |
| 生长越来越慢 | 高传代、支原体、密度长期不合适、血清批次变化 | 复苏低传代库存，做支原体检测，固定传代窗口 |
| 传代后形态变了 | 过度汇合后传代、解离方式改变、培养基或血清改变 | 回退到原 SOP，记录所有变量 |
| 多孔板接种不均 | 细胞沉降、混匀不足、摇板方式不对 | 接种过程中持续混匀，十字轻晃 |
| 悬浮细胞碎片增多 | 密度过高、营养耗竭、离心损伤、污染 | 降低密度，换液，检查污染 |
| 实验批次差异大 | 传代数、接种密度、恢复时间不同 | 固定 passage window、seeding density 和处理时间 |

## 小结

细胞传代的关键是维持细胞在合适生长窗口，而不是机械地“满了就分”。贴壁细胞要控制汇合度、解离方式和接种密度；悬浮细胞要控制密度窗口、活率和换液节奏。所有传代都要记录传代数、传代比例、接种密度和细胞形态，因为这些信息会直接影响后续实验解释。
