# 细胞冻存

Cell cryopreservation（细胞冻存）是用冻存保护剂和控制降温策略，把活细胞保存到超低温状态，以便未来复苏使用的技术。它是细胞培养体系的保险库：没有可靠冻存库，细胞系一旦污染、漂移或丢失，整个项目都会变得脆弱。

## 应用场景

- 为新到细胞建立 master stock（主细胞库）和 working stock（工作细胞库）。
- 保存低传代、[支原体](支原体检测.md) 阴性、身份明确的细胞。
- 在大规模实验前统一细胞起点。
- 保存稀有原代细胞、干细胞、免疫细胞或基因编辑克隆。
- 备份重要实验材料，防止污染、培养箱故障或长期传代漂移。

Thermo Fisher 的 cell freezing protocols 把冻存视为维持细胞库存、防止 genetic drift（遗传漂移）、senescence（衰老）、微生物污染和设备故障风险的重要方法。[参考：Thermo Fisher Cell Freezing Protocols](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/cell-culture-protocols/freezing-cells.html)

## 实验目的

细胞冻存的目标是让细胞在未来复苏时仍然具有足够高的活率、正确身份和稳定状态。一个好的冻存流程应该：

- 使用健康、对数生长期、无污染的细胞。
- 选择合适冻存液和冻存密度。
- 使用可控降温，减少冰晶损伤。
- 长期储存在足够低温条件下。
- 记录冻存批次、传代数、冻存位置和质量控制结果。

## 简要实验原理

冷冻过程中，水结冰会改变细胞内外溶质浓度，冰晶可直接损伤细胞膜和细胞器。Cryoprotectant（冻存保护剂）如 [DMSO](<../材(实验耗材工具篇)/DMSO.md>) 或 glycerol（[甘油](<../材(实验耗材工具篇)/甘油.md>)）可以降低冰晶损伤，但融化后又会产生毒性或渗透压压力。

冻存的核心平衡是：**降温不能太快，也不能太慢**。太快会让细胞内形成冰晶；太慢会让细胞长时间暴露在高溶质环境中。ATCC 的动物细胞低温保存说明指出，多数动物细胞通常适合约 -1 到 -3°C/min 的控制降温，并建议长期储存温度低于 -130°C。[参考：ATCC Cryogenic Storage of Animal Cells](https://www.atcc.org/resources/technical-documents/cryogenic-storage-of-animal-cells)

## 冻存前判断

### 选择合适细胞

**怎么做**：选择形态正常、活率高、无污染、处于 log phase（对数生长期）的细胞。避免使用刚复苏未稳定、过度汇合、明显应激或污染可疑的细胞。

**为什么**：冻存会叠加额外压力。已经受损的细胞很难再承受解离、离心、DMSO 和降温过程。Thermo Fisher 也把 log-phase cultured cells（对数生长期细胞）列为冻存材料。[参考：Thermo Fisher Cell Freezing Protocols](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/cell-culture-protocols/freezing-cells.html)

**注意事项**：

- 冻存前最好确认支原体阴性。
- 关键细胞冻存前记录形态照片。
- 不要用“快死的一瓶细胞”建立库存。

**替代方案**：如果细胞状态一般但样本珍贵，可先少量冻存作为应急，同时继续优化培养并建立更高质量库存。

**出错后果**：复苏率低、恢复慢、冻存库从一开始就携带污染或异常状态。

### 设计冻存库

**怎么做**：把冻存分为 master stock 和 working stock。主库来自早期、身份明确、污染阴性的细胞，尽量少动；工作库用于日常复苏和实验。

**为什么**：主库提供稳定源头，工作库减少频繁打开主库的风险。长期项目中，这比每次从正在培养的高传代细胞继续分下去更可靠。

**注意事项**：

- 冻存管数量要能覆盖未来实验和意外损失。
- 冻存位置要记录到液氮罐、架、盒、格。
- 同一批冻存后建议抽检一管做 [细胞复苏](细胞复苏.md) 验证。

**替代方案**：小项目可只建立 working stock，但也应至少保留一批低传代备份。

**出错后果**：细胞污染后无低传代库存可回退；不同实验使用来源不一致的细胞。

## 冻存液选择

常见冻存液包括：

| 配方类型 | 适合场景 | 注意事项 |
| --- | --- | --- |
| 完全培养基 + 10% DMSO | 常规细胞系 | 简单常见，但不同细胞耐受不同 |
| FBS + 10% DMSO | 某些细胞系传统方案 | 血清批次差异大，成本高 |
| 商业 [细胞冻存液](<../材(实验耗材工具篇)/细胞冻存液.md>) | 稳定性和便利性更好 | 需记录品牌、货号、批号 |
| [无血清冻存液](<../材(实验耗材工具篇)/无血清冻存液.md>) | 干细胞、原代细胞、临床转化相关体系 | 不同产品适用范围不同 |

Thermo Fisher 介绍的冻存介质通常包含基础培养基、冻存保护剂和蛋白来源，并列出含 10% DMSO 或 10% glycerol 的常见方案；同时也提醒应优先遵循细胞和产品说明书。[参考：Thermo Fisher Cell Freezing Protocols](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/cell-culture-protocols/freezing-cells.html)

## 实验操作

### 收集细胞

**怎么做**：贴壁细胞按 [细胞传代](细胞传代.md) 或 [细胞消化](细胞消化.md) 流程解离收集；悬浮细胞充分混匀后取样。离心后去除旧培养基，准备重悬于冻存液。

**为什么**：冻存前的收集过程会影响细胞损伤程度。ATCC 也提醒，收集时应尽可能 gentle（温和），因为收集损伤会叠加到冻存和复苏损伤上。[参考：ATCC Cryogenic Storage of Animal Cells](https://www.atcc.org/resources/technical-documents/cryogenic-storage-of-animal-cells)

**注意事项**：

- 贴壁细胞不要过度消化。
- 悬浮细胞不要用过高离心力。
- 冻存前做 [细胞计数](细胞计数.md) 和活率评估。

**替代方案**：对细胞团或类器官，可按专用 protocol 保留团块结构，而不是完全打成单细胞。

**出错后果**：冻存前已经损伤的细胞在复苏时会表现为大量死亡、贴壁差或恢复慢。

### 配制或准备冻存液

**怎么做**：冻存液通常预冷，现配含 DMSO 的冻存液时应混匀后尽快使用。商业冻存液按说明书解冻、混匀和保存。

**为什么**：DMSO 在室温下对细胞有毒性，加入细胞后应尽快分装并开始降温。低温可以降低代谢和 DMSO 毒性，但不能无限延长操作时间。

**注意事项**：

- DMSO 可促进有机物进入皮肤，操作时戴手套并避免接触。
- DMSO 应使用 cell culture grade（细胞培养级）并避免反复吸水。
- 冻存液配方变更会影响复苏率，不能随意替换。

**替代方案**：对敏感细胞使用商业无血清冻存液，减少血清批次影响。

**出错后果**：冻存液配方错误、DMSO 老化或浓度不准会导致复苏率下降。

### 重悬与分装

**怎么做**：按目标冻存密度用冻存液轻柔重悬细胞，分装到冻存管中，常见每管 1 mL。冻存密度因细胞不同而变化，必须按细胞说明书或实验室验证值执行。

**为什么**：密度太低，复苏后恢复慢；密度太高，冻存液保护不足、复苏后死细胞和代谢压力增加。

**注意事项**：

- 分装前持续轻柔混匀，避免细胞沉降导致前后管密度不同。
- 冻存管不要装太满，要留有安全空间。
- 标签应写在管身并能耐液氮，不能只写管盖。

**替代方案**：珍贵细胞可分成不同密度冻存，复苏后比较最佳条件。

**出错后果**：同批冻存管复苏率差异大，或标签脱落后无法追溯。

### 控制降温

**怎么做**：把冻存管放入程序降温盒或程序降温仪，通常先放入 -80°C 冰箱过夜，使温度以接近 -1°C/min 的速度下降；随后转入液氮长期保存。

**为什么**：ATCC 和 Thermo Fisher 都推荐用 controlled-rate freezer（程序降温仪）或 freezing container（程序降温盒）实现接近 -1°C/min 的降温，以减少冰晶损伤。[参考：ATCC Cryogenic Storage](https://www.atcc.org/resources/technical-documents/cryogenic-storage-of-animal-cells)；[参考：Thermo Fisher Cell Freezing Protocols](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/cell-culture-protocols/freezing-cells.html)

**注意事项**：

- 不要把细胞直接丢进液氮作为常规冻存方式。
- 程序降温盒需要按说明维护；异丙醇式降温盒要注意液体状态。
- -80°C 只是过渡，不适合长期保存多数细胞。

**替代方案**：高价值细胞可使用真正的程序降温仪，并记录降温曲线。

**出错后果**：降温过快或过慢都会造成复苏率下降；长期放在 -80°C 可能导致活率和状态逐渐变差。

### 转入液氮与库存管理

**怎么做**：冻存过夜后，把冻存管快速转入液氮罐气相或液相储存，并更新库存表。ATCC 建议长期低温保存保持低于 -130°C，以获得最佳存活率。[参考：ATCC Cryogenic Storage of Animal Cells](https://www.atcc.org/resources/technical-documents/cryogenic-storage-of-animal-cells)

**为什么**：低于玻璃化转变相关温区后，细胞内分子运动极低，更适合长期保存。库存表则保证未来能找到、能追溯、能判断是否可用。

**注意事项**：

- 转移过程要快，避免冻存管局部升温。
- 液氮操作需要面罩、防寒手套和合适工具。
- 重要库存应分散到不同盒位或罐位，降低单点故障。

**替代方案**：无液氮条件下可短期 -80°C 保存，但不应作为长期细胞库策略。

**出错后果**：冻存位置不明、标签脱落、液氮罐故障或反复升温导致整批细胞损失。

### 复苏验证

**怎么做**：新建冻存批次后，抽取至少一管进行复苏验证，记录 24 h 贴壁/活率、3-7 天恢复增殖情况，以及支原体检测结果。

**为什么**：冻存成功与否最终要靠复苏表现验证。只把管子放进液氮，不代表建立了可用库存。

**注意事项**：

- 验证用的复苏流程应与未来实际使用流程一致。
- 不要等到关键实验前才第一次复苏某批冻存管。
- 验证结果应写入冻存库表。

**替代方案**：极珍贵细胞可先小规模条件优化，再大批量冻存。

**出错后果**：多年后发现库存无法复苏，项目失去细胞来源。

## 特殊细胞注意事项

| 细胞类型 | 冻存重点 |
| --- | --- |
| 常规贴壁细胞系 | 健康对数期、温和消化、合适密度、-1°C/min 降温 |
| 悬浮细胞 | 活细胞密度和离心条件很关键，避免过度稀释 |
| 原代细胞 | 通常更依赖专用冻存液和高质量起始状态 |
| 干细胞 | 可能需要单细胞或细胞团冻存策略、ROCK 抑制剂和专用冻存液 |
| 类器官 | 常保留小团块或基质相关结构，按 [类器官培养](类器官培养.md) 专用方案 |
| 免疫细胞 | PBMC、T 细胞等对冻存密度、血清/蛋白来源和复苏后休整时间敏感 |

## 常见异常结果与 troubleshooting

| 异常结果      | 可能原因                      | 处理策略                   |
| --------- | ------------------------- | ---------------------- |
| 复苏率低      | 冻存前细胞状态差、降温不受控、DMSO 配方不合适 | 用健康对数期细胞，使用程序降温盒，优化冻存液 |
| 复苏后不贴壁    | 消化损伤、冻存密度低、培养表面不合适        | 缩短消化，增加密度，使用包被容器       |
| 同批管差异大    | 分装时细胞沉降、冻存液未混匀、降温盒位置差异    | 分装中持续混匀，规范降温盒使用        |
| 冻存管破裂或漏液  | 冻存管质量差、装液过满、液氮渗入          | 使用合格冻存管，留空间，避免不适合液氮的管  |
| 标签丢失      | 标签不耐低温、只写管盖               | 使用低温标签，管身和库存表双记录       |
| 长期库存复苏变差  | -80°C 长期保存、液氮罐升温、反复转移     | 长期低于 -130°C，监控液氮罐，减少暴露 |
| 冻存批次污染    | 冻存前已有污染、无菌操作失败            | 冻存前做污染检查，污染批次不要入主库     |
| DMSO 相关毒性 | 加入 DMSO 后停留太久、复苏后未及时稀释    | 加快分装降温，复苏时快速解冻并稀释      |

## 小结

细胞冻存的关键是“冻存前状态 + 冻存液 + 控制降温 + 长期低温 + 复苏验证”。最常见的失败不是某一步神秘出错，而是用状态差的细胞冻存、DMSO 暴露过久、降温不受控、长期放在 -80°C、标签和库存记录混乱。一个可靠的细胞项目，应该永远能从低传代、检测阴性、记录完整的冻存库重新开始。
