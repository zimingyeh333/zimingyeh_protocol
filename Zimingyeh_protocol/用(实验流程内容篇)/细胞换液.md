# 细胞换液

Medium change / medium replacement（细胞换液）是在 [细胞培养](细胞培养.md) 过程中移除旧培养基并补入新鲜培养基的操作。它看起来只是“吸掉旧液、加新液”，但实际是在调节营养、代谢废物、pH、渗透压、细胞分泌因子和污染风险之间的平衡。

## 应用场景

- 日常维持贴壁细胞或悬浮细胞。
- [细胞复苏](细胞复苏.md) 后去除 DMSO（Dimethyl sulfoxide，二甲基亚砜）和死细胞。
- 药物处理、转染、感染或刺激实验前更换到指定培养基。
- 实验处理中去除旧试剂、血清、抗生素或残余处理物。
- 细胞代谢导致培养基变酸、颜色变黄、营养不足时恢复环境。

Corning 的 media change protocol 提醒，细胞培养基提供氨基酸、碳水化合物、无机盐、pH 缓冲和生长因子；换液频率可以按固定计划，也可以根据细胞类型、代谢速度和培养基颜色调整。[参考：Corning Cell Culture Media Change Protocol](https://www.corning.com/cala/es/products/life-sciences/resources/stories/at-the-bench/cell-culture-media-change-protocol.html)

## 实验目的

细胞换液的目标不是让培养基“看起来新鲜”，而是让细胞维持在适合实验的状态：

- 补充葡萄糖、氨基酸、维生素、血清和生长因子等营养。
- 移除乳酸、氨、死细胞碎片、脱落细胞和残余试剂。
- 恢复或稳定 pH、渗透压和缓冲体系。
- 降低某些污染扩增或代谢产物积累的风险。
- 为下游实验提供一致的处理起点。

## 简要实验原理

培养中的细胞持续消耗营养并释放代谢废物。培养基中的 [酚红](<../材(实验耗材工具篇)/酚红.md>) 可作为 pH indicator（pH 指示剂）：常见培养条件下偏红/橙红通常较正常，明显变黄提示酸化，偏紫可能提示 pH 偏高或 CO2 平衡异常。Corning 也指出，细胞释放酸性代谢废物后，培养基 pH 会下降，酚红颜色会向橙色或黄色变化。[参考：Corning Cell Culture Media Change Protocol](https://www.corning.com/cala/es/products/life-sciences/resources/stories/at-the-bench/cell-culture-media-change-protocol.html)

但换液不是越频繁越好。某些细胞依赖 autocrine/paracrine factors（自分泌/旁分泌因子），完全换液可能让细胞短期应激；干细胞和原代细胞还可能依赖特定生长因子和基质信号。因此换液策略要同时看细胞类型、细胞密度、培养基颜色、实验目的和 SOP。

## 什么时候需要换液

| 判断依据 | 说明 | 处理思路 |
| --- | --- | --- |
| 固定 schedule（计划） | 例如每 2-3 天换液 | 适合稳定细胞系和常规维护 |
| 培养基颜色 | 明显变黄提示酸化；偏紫提示 pH 偏高或 CO2 问题 | 先检查细胞密度、污染和培养箱 |
| 细胞密度 | 细胞越密，营养消耗和废物积累越快 | 可能需要换液或 [细胞传代](细胞传代.md) |
| 漂浮死细胞 | 死细胞和碎片多时影响健康细胞 | 轻柔换液，必要时降低密度 |
| 实验处理 | 换到处理培养基、撤药、换无血清条件等 | 组间换液节奏必须一致 |
| 特殊细胞 | 干细胞、原代细胞、类器官对因子和基质更敏感 | 遵循专用 protocol |

ATCC 的动物细胞培养指南也提醒，悬浮细胞通常不需要完全换液，除非密度很高或培养基因酚红变黄而酸化；完全换液时可轻柔离心并用新鲜培养基重悬。[参考：ATCC Animal Cell Culture Guide](https://www.atcc.org/resources/culture-guides/animal-cell-culture-guide)

## 实验操作

### 换液前观察

**怎么做**：从培养箱取出细胞前先确认标签；换液前用 [倒置显微镜](<../材(实验耗材工具篇)/倒置显微镜.md>) 观察细胞密度、形态、漂浮细胞、污染颗粒和培养基颜色。

**为什么**：换液前观察能判断“该换液、该传代、该丢弃还是该隔离”。如果已经污染，继续常规换液会把污染带入安全柜和其他细胞。

**注意事项**：

- 不要只看培养基颜色，必须看细胞形态。
- 真菌、细菌、酵母污染可能有颗粒、浑浊或运动微粒；支原体污染可能肉眼看不出来。
- 记录异常形态比换完液后再回忆更可靠。

**替代方案**：不确定是否污染时，先隔离培养并查看 [细胞污染](细胞污染.md)，必要时做 [支原体检测](支原体检测.md)。

**出错后果**：污染扩散、异常细胞继续用于实验、后续无法判断问题发生时间。

### 预温培养基

**怎么做**：将新鲜培养基预温到细胞适合的温度，常见为 37°C；不需要长时间过度预温。进入安全柜前擦拭瓶身。

**为什么**：冷培养基可能造成温度冲击，尤其是原代细胞、干细胞、神经细胞或刚复苏细胞。Corning 也提示，加入冷培养基可能 shock cells（冲击细胞），水浴可预温但也是潜在污染来源。[参考：Corning Cell Culture Media Change Protocol](https://www.corning.com/cala/es/products/life-sciences/resources/stories/at-the-bench/cell-culture-media-change-protocol.html)

**注意事项**：

- 培养基不要在 37°C 放太久，避免不稳定成分降解。
- 含光敏成分或生长因子的培养基应避光并缩短室温暴露。
- 不同培养基是否需要预温，要按细胞类型和产品说明判断。

**替代方案**：部分敏感培养基可室温回温而不是水浴加热，减少污染和成分降解风险。

**出错后果**：细胞短期收缩、脱落、增殖变慢；或因水浴污染导致培养物污染。

### 贴壁细胞换液

**怎么做**：在生物安全柜中打开培养容器，倾斜瓶/皿，使旧培养基汇集到一侧；用无菌移液管或吸引系统从边缘轻柔吸走旧液；沿侧壁加入预温新鲜培养基，避免直接冲击细胞层。

**为什么**：贴壁细胞依赖培养表面。吸液或加液过猛会把细胞从表面冲掉，尤其是刚复苏、刚接种、低密度或贴壁弱的细胞。

**注意事项**：

- 不要让细胞层长时间干燥。
- 吸头不要刮到细胞层。
- [细胞培养板](<../材(实验耗材工具篇)/细胞培养板.md>) 换液时，枪头靠孔壁，不要对着中央细胞层猛冲。
- 多孔板不同孔换液速度尽量一致，避免时间差造成处理差异。

**替代方案**：

- 对贴壁弱细胞，可以只换一半或三分之二培养基。
- 对处理实验，可以先轻轻加入新培养基再缓慢吸走旧液，减少干扰。
- 对严重漂浮死细胞，可轻洗一次 PBS/DPBS，但要评估是否会增加应激。

**出错后果**：细胞成片脱落、局部密度不均、边缘孔状态不同、实验组受机械刺激影响。

### 悬浮细胞换液

**怎么做**：悬浮细胞不能直接吸走培养基而留下细胞。常见策略是计数后按目标密度稀释补加新培养基；如果需要完全换液，则轻柔离心收集细胞，弃上清后用新鲜培养基重悬。

**为什么**：悬浮细胞的“换液”本质是控制细胞密度、营养和代谢废物。ATCC 指出，悬浮细胞完全换液通常只有在细胞密度很高或培养基酸化时才需要；过度稀释到推荐密度以下会导致生长慢或死亡。[参考：ATCC Animal Cell Culture Guide](https://www.atcc.org/resources/culture-guides/animal-cell-culture-guide)

**注意事项**：

- 换液前充分但轻柔混匀，避免取样和离心不代表整体。
- 离心力和时间要按细胞类型优化。
- 不要把悬浮细胞稀释到低于推荐密度窗口。

**替代方案**：

- 密度略高且状态好：直接补加新鲜培养基稀释。
- 死细胞和代谢废物多：离心后完全换液。
- 对离心敏感细胞：低速离心或部分换液。

**出错后果**：细胞被吸走、离心损伤、密度太低恢复慢、密度太高继续酸化。

### 是否使用 PBS/DPBS 洗涤

**怎么做**：如果需要去除血清、残余药物、残余转染试剂或死细胞，可以用预温 PBS/DPBS 轻轻洗一次；常规日常换液不一定需要洗。

**为什么**：洗涤可以去除残留物，但也会暂时移除营养和保护性蛋白，增加机械扰动。含钙镁与不含钙镁的 DPBS 对细胞贴附和后续消化也可能有影响。

**注意事项**：

- 洗涤动作要轻，尤其是低密度贴壁细胞。
- 洗后不要让细胞干燥。
- 准备进行胰酶消化时，通常用无钙镁 PBS/DPBS 洗去血清更合适。

**替代方案**：对敏感细胞可不洗，直接部分换液；对药物残留要求高的实验可增加洗涤次数，但要设置一致流程。

**出错后果**：细胞脱落、应激、处理残留未去除，或因为组间洗涤不一致产生假差异。

### 换液后恢复与记录

**怎么做**：换液后轻轻晃匀培养容器，放回 [CO2培养箱](<../材(实验耗材工具篇)/CO2培养箱.md>)；必要时 1-2 小时后观察细胞是否脱落、收缩或污染。记录换液时间、培养基批号、换液比例和异常情况。

**为什么**：换液本身是一次实验变量。对于药物处理、转染、分化诱导和干细胞培养，换液时间和方式会直接影响结果。

**注意事项**：

- 培养箱门打开时间尽量短。
- 多孔板放回培养箱时避免剧烈晃动。
- 如果培养箱有固定位置差异，重要实验板位置要记录。

**替代方案**：对时间敏感处理，可使用计时器分批换液，保持每组暴露时间一致。

**出错后果**：换液批次效应、处理时间不一致、边缘孔蒸发加重。

## 特殊场景

| 场景 | 建议 |
| --- | --- |
| 复苏次日换液 | 轻柔换掉含 DMSO 和死细胞的培养基；贴壁弱时可半量换液 |
| 转染后换液 | 按转染试剂说明决定是否换液；换液时间组间一致 |
| 药物处理 | 换到含药培养基时，所有组的溶剂浓度和换液节奏一致 |
| 无血清饥饿 | 控制饥饿时间；注意无血清本身也是刺激 |
| 干细胞培养 | 因子稳定性和分化状态很关键，常需要更严格换液计划 |
| 原代细胞培养 | 尽量减少机械扰动，优先按供应商 protocol |
| 类器官培养 | 换液常和基质胶 dome 稳定性相关，避免破坏三维结构 |

## 常见异常结果与 troubleshooting

| 异常结果 | 可能原因 | 处理策略 |
| --- | --- | --- |
| 换液后细胞脱落 | 吸液/加液太猛、细胞贴壁弱、培养基太冷 | 沿壁操作，预温培养基，改半量换液 |
| 换液后细胞变圆 | 温度/pH 冲击、机械刺激、培养基配方错误 | 检查培养基、CO2、温度和批号 |
| 培养基很快变黄 | 细胞太密、污染、换液量不足、培养箱 CO2 异常 | 观察污染，传代或降低密度，检查培养箱 |
| 换液后孔间差异大 | 多孔板加液不均、细胞被冲散、边缘孔蒸发 | 使用一致加液角度和速度，避免边缘孔或加防蒸发液 |
| 悬浮细胞换液后死亡 | 离心太猛、密度太低、培养基不适 | 降低离心强度，维持密度窗口，核对培养基 |
| 药物处理结果波动 | 换液时间不一致、残留药物不同、溶剂不一致 | 固定处理流程，设置 vehicle control（溶剂对照） |
| 反复污染 | 水浴、培养基瓶口、吸引系统或安全柜操作污染 | 清洁水浴和安全柜，分装培养基，检查吸引管路 |

## 小结

细胞换液的本质是调节细胞微环境，而不是机械地“换新培养基”。换液频率要看细胞类型、密度、培养基颜色、实验目的和细胞对分泌因子的依赖。贴壁细胞要避免冲掉细胞层，悬浮细胞要避免把细胞稀释到过低密度，敏感细胞则要优先考虑半量换液和专用 protocol。
