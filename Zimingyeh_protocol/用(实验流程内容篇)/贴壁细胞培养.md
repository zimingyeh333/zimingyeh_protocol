# 贴壁细胞培养

Adherent cell culture（贴壁细胞培养）是指细胞依赖培养表面附着、铺展、增殖和维持状态的体外培养方式。它是 [细胞培养](细胞培养.md) 中最常见的分支之一，常见细胞包括 HEK293T、HeLa、A549、MCF-7、HUVEC、成纤维细胞、上皮细胞和许多原代细胞。

## 应用场景

- 常规肿瘤细胞系、永生化细胞系和部分原代细胞维护。
- 药物处理、转染、感染、细胞成像、免疫染色、迁移/侵袭实验。
- 下游 [RT-qPCR](RT-qPCR.md)、[Western blot](<Western blot.md>)、流式、测序或代谢实验。
- 需要观察细胞形态、极性、铺展、细胞连接或单层结构的实验。
- 需要按培养表面积控制 density（密度）的实验。

Thermo Fisher 的 adherent cell culture protocol 把贴壁细胞传代描述为：去除旧培养基、洗涤、加入 trypsin 或 TrypLE 等解离试剂、观察细胞脱落，再用完全培养基重悬并接种到新容器。[参考：Thermo Fisher Adherent Cell Culture Protocol](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/cell-culture-protocols/subculturing-adherent-cells.html)

## 实验目的

贴壁细胞培养的目标不是让细胞“铺满瓶底”，而是在合适表面、合适密度和合适传代窗口中维持可重复的细胞状态：

- 维持健康形态和稳定增殖。
- 避免过度汇合、接触抑制、营养耗竭和长期高密度应激。
- 控制解离损伤，避免传代本身改变细胞状态。
- 让下游实验在接近一致的 confluence（汇合度）和 passage number（传代数）下开始。

## 简要实验原理

贴壁细胞通常通过 integrin（整合素）等黏附分子与 extracellular matrix（细胞外基质）或 tissue culture-treated plastic（组织培养处理塑料）相互作用。细胞是否能贴附、铺展和保持表型，受培养表面、血清/基质蛋白、细胞密度、机械扰动和解离方式影响。

ATCC 的动物细胞培养指南指出，贴壁细胞在培养容器表面生长，需要达到合适汇合度后再通过 proteolytic enzymes（蛋白水解酶，如胰酶）或其他方式解离并传代。[参考：ATCC Animal Cell Culture Guide](https://www.atcc.org/resources/culture-guides/animal-cell-culture-guide)

| 核心变量 | 影响 |
| --- | --- |
| Confluence（汇合度） | 决定是否换液、传代或进入实验 |
| Culture surface（培养表面） | 影响贴附、铺展、分化和形态 |
| Dissociation method（解离方式） | 影响活率、表面蛋白和后续贴壁 |
| Seeding density（接种密度） | 影响恢复速度、增殖曲线和实验起点 |
| Passage number（传代数） | 影响遗传稳定性、表型和实验重复性 |

## 关键判断

### 汇合度

Confluence（汇合度）是贴壁细胞覆盖培养表面的比例。很多常规细胞系会在约 70%-90% 汇合度传代，但这不是通用硬标准。ATCC 的贴壁细胞传代指南强调，不同细胞系的 recommended subcultivation ratio（推荐传代比例）和条件应参考具体细胞说明。[参考：ATCC Guide to Subculturing Cell Line Monolayers](https://www.atcc.org/resources/technical-documents/guide-to-subculturing-cell-line-monolayers)

过低汇合度传代可能导致恢复慢；过高汇合度会造成接触抑制、营养不足、酸化和表型改变。对干细胞、内皮细胞、原代细胞，过度汇合尤其容易改变状态。

### 形态

贴壁细胞形态比“是否活着”更有信息量。上皮样细胞通常铺展较平、边界明显；成纤维样细胞更长梭形；神经样细胞可能有突起；部分细胞在低密度和高密度时形态不同。形态突然改变时，优先考虑污染、过度汇合、传代损伤、培养基/血清批次变化或细胞漂移。

### 表面和包被

多数常规细胞系可在组织培养处理塑料上生长，但原代细胞、神经细胞、内皮细胞、干细胞或贴壁弱细胞可能需要特殊包被。包被不是装饰，它会改变细胞黏附信号、形态和分化状态。

## 实验操作

### 日常观察

**怎么做**：每天或按生长速度观察细胞汇合度、形态、漂浮细胞、培养基颜色、颗粒和污染迹象。关键实验前拍照记录。

**为什么**：贴壁细胞状态很大程度可以从形态看出来。很多问题在检测结果异常前已经有形态信号。

**注意事项**：

- 不同细胞的健康形态不同，要建立本实验室自己的参考图。
- 培养基颜色只是辅助，不要只凭颜色判断。
- 高密度、边缘区域和瓶口附近可能状态不同，观察要覆盖多个视野。

**替代方案**：高通量实验可用自动显微成像或板扫描做汇合度记录。

**出错后果**：使用过度汇合、污染或应激细胞进入实验，后续结果不可解释。

### 换液

**怎么做**：按 [细胞换液](细胞换液.md) 逻辑移除旧培养基，沿侧壁加入预温新鲜培养基。贴壁弱、刚接种或刚复苏细胞可选择半量换液。

**为什么**：换液补充营养并移除代谢废物，但过猛的液流会冲掉细胞层，过频繁完全换液也可能移除细胞分泌因子。

**注意事项**：

- 不要让细胞层干燥。
- 不要用吸头刮到细胞层。
- 多孔板换液要保持组间动作和时间一致。

**替代方案**：敏感细胞可半量换液、条件化培养基或低剪切操作。

**出错后果**：细胞片状脱落、局部密度不均、换液本身成为实验刺激。

### 传代与解离

**怎么做**：吸去旧培养基，用 PBS/DPBS 洗去血清，加入适量解离试剂；显微镜下观察细胞变圆、松动或脱落后，用含血清培养基或专用终止液终止，轻柔吹打成细胞悬液，再计数并接种。

**为什么**：血清会抑制胰酶；解离时间决定细胞是否能完整脱落以及是否受损。ATCC 的 dissociation method 技术提示强调，解离方式应匹配细胞特性，弱贴壁细胞可能轻敲即可脱落，而强贴壁细胞可能需要更充分的酶解。[参考：ATCC Tips for Successful Subculturing: Dissociation Method](https://www.atcc.org/resources/application-notes/tips-for-successful-sub-culturing-dissociation-method)

**注意事项**：

- 不要机械等待固定分钟数，要看显微镜下状态。
- 消化过度会伤害表面蛋白、降低活率和贴壁能力。
- 消化不足会形成团块，影响计数和接种均匀性。
- 对表面 marker 或流式实验敏感时，胰酶可能影响检测。

**替代方案**：

- 贴壁弱细胞：轻敲、EDTA-only 或更短消化。
- 敏感细胞：Accutase、TrypLE 或专用 dissociation kit。
- 需要保留表面结构：细胞刮刀或非酶方式，但机械损伤可能更大。

**出错后果**：团块、死亡、贴壁差、marker 丢失、转染或药物反应异常。

### 接种与铺板

**怎么做**：根据目标实验按 cells/cm2 或每孔细胞数接种。接种后轻轻前后、左右十字方向晃匀，不要画圈；放入培养箱后尽量减少移动。

**为什么**：贴壁细胞最终会固定在培养表面，初始分布不均会持续影响后续实验。ATCC 提醒，不要把浓缩细胞悬液直接加入空培养容器，因为会造成贴壁和生长不均。[参考：ATCC Guide to Subculturing Cell Line Monolayers](https://www.atcc.org/resources/technical-documents/guide-to-subculturing-cell-line-monolayers)

**注意事项**：

- 接种密度要按处理时间倒推。
- 气泡下方没有细胞贴壁。
- 多孔板边缘孔容易蒸发，关键实验可避免使用边缘孔。

**替代方案**：成像、药筛或转染实验可先做 seeding density titration（接种密度梯度）。

**出错后果**：孔间差异大、局部过密、转染效率不稳定、药物曲线漂移。

### 收集贴壁细胞用于实验

**怎么做**：根据下游实验选择收集方式。RNA/蛋白可直接在板上裂解；流式或计数需要解离成单细胞悬液；免疫染色通常直接固定在板上。

**为什么**：收集方式会改变样本组成。只收集悬浮细胞可能漏掉贴壁细胞；只收集贴壁细胞可能漏掉死亡或脱落细胞。不同实验对“是否包含死细胞”有不同要求。

**注意事项**：

- 药物毒性实验中，漂浮细胞可能是关键信号，不应随手倒掉。
- 表面蛋白检测时选择温和解离。
- 细胞刮刀适合某些蛋白/RNA 收集，但不适合需要高活率单细胞的场景。

**替代方案**：收集旧培养基中的漂浮细胞后与解离贴壁细胞合并，可更完整反映死亡或脱落情况。

**出错后果**：低估细胞死亡、样本组成偏倚、流式或蛋白数据不一致。

## 特殊贴壁类型

| 类型 | 培养重点 |
| --- | --- |
| 贴壁弱细胞 | 换液和吹打要轻，传代可缩短消化或轻敲脱落 |
| 强贴壁细胞 | 解离时间、酶浓度和机械辅助要优化 |
| 上皮样细胞 | 关注细胞连接、极性和过度汇合 |
| 成纤维样细胞 | 关注过度增殖、形态拉长和高传代漂移 |
| 内皮细胞 | 常依赖专用培养基和基质，传代上限较重要 |
| 神经细胞 | 通常对机械扰动和表面包被敏感 |
| 干细胞 | 不只看贴壁，还要看克隆形态和分化状态 |

## 常见异常结果与 troubleshooting

| 异常结果 | 可能原因 | 处理策略 |
| --- | --- | --- |
| 细胞不贴壁 | 表面不合适、接种太低、消化过度、复苏损伤 | 使用包被表面，提高密度，缩短消化 |
| 换液后脱落 | 液流太猛、细胞贴壁弱、培养基太冷 | 沿壁加液，半量换液，预温培养基 |
| 传代后团块多 | 解离不足、吹打不足、DNA 黏连 | 优化解离，轻柔吹匀，必要时过滤 |
| 细胞越来越扁或变大 | 高传代、衰老、过度汇合 | 复苏低传代库存，缩短培养窗口 |
| 细胞变圆但不脱落 | 解离开始但未完成、温度不足、试剂失效 | 延长观察，确认试剂和温度 |
| 细胞大量死亡 | 消化过度、离心过猛、培养基错误、污染 | 降低操作强度，核对培养基，检查污染 |
| 边缘孔状态异常 | 蒸发、温度梯度、加样不均 | 避免边缘孔或加防蒸发液 |
| 实验重复性差 | 汇合度、传代数、接种密度、恢复时间不一致 | 固定 passage window 和处理时汇合度 |

## 小结

贴壁细胞培养的核心是“表面 + 汇合度 + 解离 + 接种密度”。不要把贴壁细胞当成只要铺满就健康；过度汇合、过度消化、加液太猛、表面不合适和接种不均都会改变实验结果。真正稳定的贴壁细胞培养，应该固定传代窗口、处理时汇合度和接种密度，并记录形态照片。
