# IDT

IDT（Integrated DNA Technologies，整合 DNA 技术公司）是常见 oligonucleotide（寡核苷酸）和核酸工具供应商，常用于订购 PCR/qPCR 引物、探针、gBlock、siRNA、CRISPR 相关寡核苷酸等。

## 使用建议

在 protocol 中记录 IDT 产品时，应写清 oligo name、sequence、modification、scale、purification、delivery format、lot/order ID 和复溶浓度。对于 [qPCR引物](<../../材(实验耗材工具篇)/qPCR引物.md>) 和 [TaqMan探针](<../../材(实验耗材工具篇)/TaqMan探针.md>)，还应记录扩增片段、荧光基团、quencher（淬灭基团）和设计版本。
