# Bio-Techne

Bio-Techne（Bio-Techne Corporation，Bio-Techne 公司）是一家生命科学试剂、蛋白、抗体、免疫检测、空间生物学和分析仪器相关公司。对本知识库最重要的是：它是 [R&D Systems](<R&D Systems.md>) 的母公司体系，同时还包含 Novus Biologicals、Tocris、ProteinSimple、Advanced Cell Diagnostics 等多个生命科学品牌。

## 核心定位

Bio-Techne 不应被简单理解为一个单独产品品牌。更准确地说，它是多个专业品牌的上层公司和产品生态。Bio-Techne 官方品牌页列出 R&D Systems、Novus Biologicals、Tocris、ProteinSimple、Advanced Cell Diagnostics 等品牌，覆盖 proteins（蛋白）、antibodies（抗体）、assays（检测）、small molecules（小分子）、automated western blot（自动化 Western blot）和 spatial biology（空间生物学）等方向。参考：[Bio-Techne Brands](https://www.bio-techne.com/brands)。

在 protocol 里，通常不建议只写“Bio-Techne 试剂”。更推荐写具体品牌和产品线，例如 R&D Systems recombinant human EGF、Novus antibody、Tocris inhibitor 或 ProteinSimple Jess/Wes reagent。

## 在本知识库中的常见连接

| 子品牌/方向 | 常见用途 | 记录重点 |
| --- | --- | --- |
| [R&D Systems](<R&D Systems.md>) | 重组蛋白、ELISA、抗体、细胞因子检测 | 品牌、货号、批号、靶点、活性/检测范围 |
| Novus Biologicals | 抗体和部分蛋白试剂 | clone、应用验证、物种反应性 |
| Tocris | 小分子抑制剂、激动剂和神经科学/信号通路化合物 | 纯度、溶剂、储液浓度、批号 |
| ProteinSimple | 自动化蛋白分析平台和耗材 | 仪器型号、试剂盒版本、芯片/板卡批号 |
| Advanced Cell Diagnostics | RNAscope 等 RNA 原位杂交体系 | probe、样本类型、检测平台和批号 |

## 什么时候优先记录 Bio-Techne

- 供应商系统、采购系统或发票显示 Bio-Techne，但产品页实际品牌是 R&D Systems、Novus、Tocris 等。
- 写综述式供应商比较，需要说明 R&D Systems 的母公司和相邻品牌。
- 同一实验中同时使用 Bio-Techne 体系下多个品牌，例如 R&D Systems protein + Tocris inhibitor + ProteinSimple automated western。

## 小结

Bio-Techne 是母公司和平台生态，不是实验记录里最精确的产品身份。写 protocol 时优先记录具体品牌、货号和批号；Bio-Techne 可以作为母公司字段补充。
