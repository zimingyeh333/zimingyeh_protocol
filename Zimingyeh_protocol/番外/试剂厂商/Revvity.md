# Revvity

Revvity（Revvity, Inc.，Revvity 公司）是生命科学、诊断、检测和分析工具相关公司。对本知识库最重要的是：它是 [BioLegend](BioLegend.md) 所属的上层公司体系之一，因此在采购、发票、供应商系统或品牌页中可能和 BioLegend 同时出现。

## 核心定位

Revvity 更像上层公司和产品生态入口，而不是实验记录里最具体的试剂品牌。BioLegend 官网将 BioLegend 作为 Revvity 旗下品牌呈现，并继续面向 immunology（免疫学）、flow cytometry（流式细胞术）、antibodies（抗体）和相关 reagent（试剂）应用。参考：[BioLegend About Us](https://www.biolegend.com/en-us/about-us)。

实际实验中，如果使用的是 BioLegend 抗体，不建议只写 Revvity。更推荐写：

```text
anti-human CD3, clone UCHT1, PE, BioLegend, Cat. No. xxxxx, Lot No. xxxxx
```

Revvity 可以记录在公司或采购来源字段里，但不能替代 clone（克隆号）、fluorophore（荧光染料）、货号和批号。

## 小结

Revvity 是公司层级入口。对日常 protocol 来说，真正关键的是它旗下具体品牌和产品，尤其是 BioLegend 抗体的 clone、fluorophore、货号和批号。
