# STEMCELL Technologies

STEMCELL Technologies（STEMCELL Technologies Canada Inc.，中文常直写 STEMCELL Technologies 或译作“干细胞科技公司”）是一家以 specialized cell culture systems（专门细胞培养体系）、cell separation（细胞分离）、stem cell research（干细胞研究）和免疫/血液相关实验工具为核心的生命科学试剂公司。它的价值不在于替代所有通用试剂商，而在于为特定细胞类型提供相对完整的培养、分选、冻存和检测 workflow。

## 品牌定位

STEMCELL Technologies 官方将自己定位为支持 life sciences research（生命科学研究）的 biotechnology company（生物技术公司），产品覆盖 cell culture media（细胞培养基）、cell separation products（细胞分离产品）、instruments（仪器）和 technical resources（技术资源）等。参考：[STEMCELL Technologies About Us](https://www.stemcell.com/about-us.html)。

在这个知识库里，STEMCELL Technologies 最适合放在“专门细胞体系供应商”这一类：当普通 [Gibco](Gibco.md) 培养基、[FBS](<../../材(实验耗材工具篇)/FBS.md>) 和通用缓冲液不够定义化，或者实验涉及 human pluripotent stem cells（hPSC，人多能干细胞）、hematopoietic cells（造血细胞）、immune cells（免疫细胞）、organoids（类器官）和 primary cells（原代细胞）时，它的产品和资料更有参考价值。

## 核心优势：专门细胞系统，而不是单品堆叠

STEMCELL Technologies 的强项是把“细胞类型 + 培养基 + 分离工具 + 操作资料 + 技术支持”打包成较完整的应用体系。例如：

| 方向 | 代表产品族 | 典型价值 |
| --- | --- | --- |
| hPSC 培养 | [mTeSR](<../../材(实验耗材工具篇)/mTeSR.md>)、TeSR-E8 等 | 定义化、无血清或 xeno-free 方向的人多能干细胞维持和扩增 |
| 免疫/血液细胞分离 | [EasySep](<../../材(实验耗材工具篇)/EasySep.md>)、RosetteSep、SepMate | 让 PBMC、T 细胞、B 细胞、NK 细胞等分离流程更标准化 |
| 造血祖细胞检测 | [MethoCult](<../../材(实验耗材工具篇)/MethoCult.md>) | colony-forming unit（CFU，集落形成单位）实验常见体系 |
| 冻存与复苏 | [CryoStor](<../../材(实验耗材工具篇)/CryoStor.md>) | serum-free（无血清）、defined（成分明确）冻存体系，适合敏感细胞 |
| 类器官/原代细胞 | organoid/primary cell media and supplements | 支持特定组织模型的培养和传代 |

这种体系化的好处是：当实验不是“让细胞活着”这么简单，而是要求状态稳定、分化能力可控、细胞亚群准确或结果能长期复现时，STEMCELL 的应用资料通常比通用试剂目录更接近实验者真正需要的 SOP。

## 代表性产品族

### mTeSR

mTeSR 是 human embryonic stem cell（hESC，人胚胎干细胞）和 induced pluripotent stem cell（iPSC，诱导多能干细胞）培养中非常有代表性的 feeder-free（无饲养层）培养基产品族。STEMCELL 的 mTeSR 产品资料将其定位为用于 hPSC maintenance（人多能干细胞维持）的培养基体系。参考：[STEMCELL Technologies mTeSR](https://www.stemcell.com/products/brands/mtesr.html)。

实验记录中不要只写“STEMCELL 培养基”，而要写清 mTeSR1、mTeSR Plus、TeSR-E8 等具体版本，因为这些版本在成分定义、换液频率、xeno-free 声明和适用场景上可能不同。

### EasySep

EasySep 是 magnetic cell separation（磁性细胞分离）产品族，用于从血液、PBMC（Peripheral Blood Mononuclear Cells，外周血单个核细胞）或组织样本中分离特定细胞群。STEMCELL 的 EasySep 页面将其定位为快速、无柱式的免疫磁性细胞分离系统。参考：[STEMCELL Technologies EasySep](https://www.stemcell.com/products/brands/easysep.html)。

EasySep 的关键变量不是“用了磁珠”四个字，而是 positive selection（阳性选择）还是 negative selection（阴性选择）、目标细胞、样本类型、起始细胞数、抗体 cocktail、磁珠体系和纯度/回收率检测方式。

### MethoCult

MethoCult 是 methylcellulose-based medium（甲基纤维素半固体培养基）产品族，常用于 hematopoietic progenitor cells（造血祖细胞）的 CFU assay（colony-forming unit assay，集落形成单位实验）。STEMCELL 的 MethoCult 产品资料将其用于造血祖细胞的 colony-forming unit assays。参考：[STEMCELL Technologies MethoCult](https://www.stemcell.com/products/brands/methocult.html)。

这类产品的实验读数不是普通细胞增殖，而是不同类型集落的数量、形态和谱系倾向，因此更像功能检测体系，而不是普通培养基。

### CryoStor

CryoStor 是 serum-free（无血清）和 defined（成分明确）方向的冻存液产品族，用于敏感细胞、原代细胞、干细胞或转化研究相关细胞的 cryopreservation（冻存）。STEMCELL 的 CryoStor 页面将其描述为用于 cell preservation（细胞保存）的冻存解决方案。参考：[STEMCELL Technologies CryoStor](https://www.stemcell.com/products/brands/cryostor.html)。

它适合和 [细胞冻存液](<../../材(实验耗材工具篇)/细胞冻存液.md>)、[无血清冻存液](<../../材(实验耗材工具篇)/无血清冻存液.md>) 和 [细胞复苏](<../../用(实验流程内容篇)/细胞复苏.md>) 放在一起理解。记录时要写清 CryoStor CS10、CS5、CS2 或其他版本，以及 DMSO（Dimethyl sulfoxide，二甲基亚砜）含量。

## 什么时候优先考虑 STEMCELL Technologies

- hPSC、类器官、原代细胞、免疫细胞和造血细胞这类对培养体系敏感的项目。
- protocol 原文明确指定 STEMCELL 产品，例如 mTeSR、EasySep、MethoCult、CryoStor。
- 希望使用 chemically defined（化学成分明确）、serum-free（无血清）、xeno-free（无异种成分）或更标准化的培养/冻存体系。
- 需要细胞分离、细胞培养和下游检测工具配套，而不是只买一个孤立试剂。
- 长期项目中需要固定货号、批号、版本和技术资料，减少实验室内部操作差异。

## 什么时候不必迷信 STEMCELL Technologies

- 通用培养基、PBS、常规盐溶液或基础耗材，不一定需要优先选择 STEMCELL。
- 对普通永生化细胞系，Gibco、Corning、HyClone、Sigma/Merck 等通用供应商往往已经足够。
- STEMCELL 的专用体系价格通常较高，如果实验目标只是粗略扩增细胞，可能不是最经济选择。
- 专用培养基和分选 kit 不能随意替换同名产品：不同版本、不同选择策略和不同样本类型可能导致细胞状态和群体组成变化。
- 厂家推荐 protocol 是起点，不等于本实验室最佳 SOP。敏感细胞仍然需要批号桥接和本地优化。

## 与其他供应商的区别

| 供应商 | 更像什么 | 什么时候优先 |
| --- | --- | --- |
| [STEMCELL Technologies](<STEMCELL Technologies.md>) | 专门细胞体系供应商 | 干细胞、免疫/血液细胞、类器官、原代细胞、定义化培养和分离流程 |
| [Gibco](Gibco.md) | 细胞培养主干试剂体系 | DMEM/RPMI/FBS/PBS/DPBS/解离试剂等常规培养流程 |
| [ATCC](ATCC.md) | 生物资源中心和材料身份标准化入口 | 细胞系、菌株、资源来源和材料身份可追踪 |
| [PeproTech](PeproTech.md) / [R&D Systems](<R&D Systems.md>) | 重组蛋白和细胞因子供应商 | 需要特定 cytokine/growth factor 刺激 |
| [BioLegend](BioLegend.md) / [BD Biosciences](<BD Biosciences.md>) | 流式抗体和流式平台生态 | 免疫表型、多色 panel、flow cytometry |

一句话：Gibco 更像“细胞培养基础设施”，ATCC 更像“材料来源和身份”，PeproTech/R&D 更像“功能蛋白信号输入”，而 STEMCELL 更像“特定细胞系统的 workflow 供应商”。

## 小结

STEMCELL Technologies 的核心价值是“专门细胞体系”。当实验涉及 hPSC、原代细胞、类器官、免疫细胞、造血祖细胞、细胞分离或无血清/定义化冻存时，它往往比普通通用试剂商更值得优先查看。但使用时仍要记录具体产品族、版本、货号、批号、适用细胞和操作条件，不能只写“STEMCELL 试剂”。
