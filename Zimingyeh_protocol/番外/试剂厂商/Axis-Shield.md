# Axis-Shield

Axis-Shield 在本知识库中主要作为 density gradient media（密度梯度介质）相关品牌入口使用，尤其与 [Lymphoprep](<../../材(实验耗材工具篇)/Lymphoprep.md>)、[OptiPrep](<../../材(实验耗材工具篇)/OptiPrep.md>) 和 [Nycodenz](<../../材(实验耗材工具篇)/Nycodenz.md>) 等产品相关。它不是一个“通用试剂大超市”式供应商，而是更适合放在血液细胞分离、PBMC/MNC 分离和密度梯度介质选择的上下文中理解。

图源：Image2 生成的供应商记录示意图。Axis-Shield 的记录重点是产品名、密度、批号和 protocol 一致性；不要只写“用了 Lymphoprep”而不记录供应商和货号。

## 品牌身份

Axis-Shield 名称常见于 Lymphoprep、OptiPrep、Nycodenz 等密度梯度介质资料中。其官方密度梯度介质网站将 Lymphoprep 描述为用于分离 human mononuclear cells（人单个核细胞）的即用型介质，并列出 density（密度）为 1.077 g/mL。参考：[Axis-Shield Lymphoprep](https://www.axis-shield-density-gradient-media.com/products/lymphoprep)。

在实际采购和记录里，Axis-Shield、[Alere Technologies AS](<Alere Technologies AS.md>)、[Abbott](Abbott.md) 或经销商名称可能因地区和供应链而出现在不同文件上。为了避免混乱，实验记录应以瓶身标签、COA、发票和说明书上的 product name（产品名）、catalog number（货号）、lot number（批号）为准。

## 核心优势

| 优势 | 实验中的意义 |
| --- | --- |
| 密度梯度介质定位清楚 | Lymphoprep、OptiPrep、Nycodenz 等产品围绕分离介质展开 |
| 经典 PBMC/MNC 分离场景 | Lymphoprep 1.077 g/mL 是常见 PBMC/MNC 分离选择 |
| 产品名和密度对应明确 | 适合在 protocol 中精确记录 density 和 formulation |
| 适合和专用管型组合 | 可与 Leucosep/SepMate 等前处理管型形成 workflow |

Axis-Shield 的优势不是“产品多”，而是专注于密度介质这一类实验变量。对于 PBMC 分离，密度、渗透压、批号和离心条件比品牌声量更重要。

## 相关产品入口

| 产品 | 主要用途 | 知识库关系 |
| --- | --- | --- |
| Lymphoprep | PBMC/MNC 分离，常见密度 1.077 g/mL | [Lymphoprep](<../../材(实验耗材工具篇)/Lymphoprep.md>) |
| OptiPrep | iodixanol-based density gradient medium，常用于更灵活梯度 | [OptiPrep](<../../材(实验耗材工具篇)/OptiPrep.md>) |
| Nycodenz | 密度梯度介质，常用于细胞/颗粒分离 | [Nycodenz](<../../材(实验耗材工具篇)/Nycodenz.md>) |

Lymphoprep 和 [Ficoll](<../../材(实验耗材工具篇)/Ficoll.md>)/Ficoll-Paque、[Histopaque](<../../材(实验耗材工具篇)/Histopaque.md>) 属于相邻选择，但不能只因为都是 1.077 g/mL 就不做验证直接替换。

## 特别适合的场景

| 场景 | 适合原因 |
| --- | --- |
| 标准 PBMC/MNC 分离 | Lymphoprep 1.077 g/mL 对应经典单个核细胞密度窗口 |
| 需要和历史 SOP 保持一致 | 如果实验室一直使用 Lymphoprep，延续同品牌同货号更稳 |
| 比较不同密度介质 | 可作为 Ficoll-Paque、Histopaque 的对照之一 |
| 需要记录密度介质变量 | 产品名、密度、批号和说明书版本清楚 |

## 不要过度信任的地方

| 风险 | 解释 |
| --- | --- |
| 不能只写 Lymphoprep | 必须记录供应商、货号、批号、密度和说明书版本 |
| 不要默认等同 Ficoll-Paque | 即便用途相似，也应验证回收率、活率和污染细胞残留 |
| 不要忽略管型 | 普通离心管、[SepMate管](<../../材(实验耗材工具篇)/SepMate管.md>) 和 [Leucosep管](<../../材(实验耗材工具篇)/Leucosep管.md>) 的流程不同 |
| 供应链名称可能变化 | 记录时以实际标签和 COA 为准 |

## 小结

Axis-Shield 在这个知识库里主要是密度梯度介质入口，尤其关联 Lymphoprep。它的使用价值来自产品密度和 SOP 一致性，而不是品牌名本身。任何 PBMC/MNC 分离记录都应该落到 Lymphoprep 的货号、批号、密度、管型、离心条件和下游结果。
