# 准确质量

Accurate mass（准确质量）指质谱测得的离子质量与真实或理论质量的接近程度，常用 ppm（parts per million，百万分之一）表示 [质量误差](质量误差.md)。它回答的问题不是“峰能不能分开”，而是“这个峰的 m/z 测得有多准”。

## 为什么准确质量重要

在 [蛋白质谱](<../../用(实验流程内容篇)/蛋白质谱.md>) 中，准确质量可以帮助判断前体离子和碎片离子是否与理论肽段匹配；在小分子或代谢组中，准确质量可以缩小分子式候选范围。Thermo Fisher 的 Orbitrap LC-MS 页面将 Orbitrap 系统定位为 high-resolution accurate-mass（高分辨准确质量，HRAM）平台，强调其适用于未知和已知化合物解析。参考：[Thermo Fisher Orbitrap LC-MS](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/liquid-chromatography-mass-spectrometry-lc-ms/lc-ms-systems/orbitrap-lc-ms.html)

常见质量误差表达：

```text
ppm error = (measured m/z - theoretical m/z) / theoretical m/z × 1,000,000
```

例如理论 m/z 为 500.0000，实测为 500.0025，则误差为 5 ppm。

## 准确质量 vs 精确质量 vs 名义质量

| 名称 | 英文 | 含义 | 用途 |
| --- | --- | --- | --- |
| 准确质量 | accurate mass | 实验测得质量与真实/理论质量的接近程度 | 判断仪器测量是否准 |
| 精确质量 | exact mass | 按同位素精确质量计算得到的理论质量 | 计算分子式、理论肽段质量 |
| 单同位素质量 | monoisotopic mass | 使用最主要同位素组成计算的质量 | 蛋白质谱肽段搜索常用 |
| 名义质量 | nominal mass | 近似整数质量 | 粗略解释，不适合高分辨判定 |

中文里“准确质量”和“精确质量”容易混用。建议在笔记中把 accurate mass 理解为“测得准不准”，把 exact mass 理解为“理论怎么算”。

## 准确质量能解决什么

| 场景 | 作用 |
| --- | --- |
| 肽段鉴定 | 减少错误候选肽段 |
| PTM 鉴定 | 判断修饰造成的质量偏移是否合理 |
| 小分子筛查 | 缩小分子式和候选结构范围 |
| 同位素分布解析 | 判断同位素峰是否符合预期 |
| QC 监控 | 判断仪器校准和质量轴是否漂移 |

## 影响准确质量的因素

| 因素 | 可能影响 |
| --- | --- |
| [质量校准](质量校准.md) | 校准不良会造成系统性偏差 |
| lock mass / internal calibration | 可改善运行过程中的质量轴稳定 |
| 信号强度 | 低信噪比峰质量误差可能更大 |
| 共洗脱干扰 | 多个峰叠加会拉偏峰中心 |
| 电荷态判断 | 电荷态错会导致质量解释错误 |
| 同位素峰选择 | 选错单同位素峰会造成明显误差 |

## 常见误解

| 误解 | 更准确的理解 |
| --- | --- |
| ppm 越小结果一定越对 | 还需要 MS/MS、保留时间、同位素分布和数据库支持 |
| 高准确质量能单独确定结构 | 对小分子只能缩小候选，通常不能单独确认结构 |
| 准确质量等于高分辨 | 准确质量是测得准，分辨率是峰分得开 |
| 质量误差只和仪器有关 | 样本污染、峰重叠、信号弱和数据处理也会影响 |

## 小结

准确质量是高分辨质谱解释中的“质量可信度”。它可以显著提高肽段鉴定、修饰判断和小分子候选筛选的可信度，但不能替代碎片谱、保留时间、同位素分布和实验设计。看 accurate mass 时，最好同时看 ppm 误差、峰形、信噪比和校准状态。
