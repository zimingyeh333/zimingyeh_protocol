# 选择反应监测

Selected reaction monitoring（SRM，选择反应监测）是一种 [串联质谱](串联质谱.md) 靶向采集方式，通常在 [三重四极杆质谱仪](<../../材(实验耗材工具篇)/三重四极杆质谱仪.md>) 上使用。它监测一个特定 [前体离子](前体离子.md) 到一个特定 [产物离子](产物离子.md) 的 transition（离子转变），用于高选择性检测和定量已知目标。

![蛋白质组学常用质谱仪类型概览](../../z_asset/材/质谱仪器/mass-spectrometry-instrument-types-reference.png)

图源：Image2 生成的质谱仪器类型参考图。三重四极杆模块中的 Q1、Q2、Q3 正是 SRM/MRM 的硬件基础。

## 核心逻辑

```text
Q1：只让目标前体离子通过
Q2：碰撞池中碎裂
Q3：只让目标产物离子通过
检测器：记录这一个 transition 的信号
```

Thermo Fisher 的 Triple Quadrupole LC-MS 页面把三重四极杆系统定位为 targeted compound detection and quantitation（靶向化合物检测和定量）平台，并强调 SRM assay table、high sensitivity（高灵敏度）、selectivity（选择性）和 linear dynamic range（线性动态范围）。参考：[Thermo Fisher Triple Quadrupole LC-MS](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/liquid-chromatography-mass-spectrometry-lc-ms/lc-ms-systems/triple-quadrupole-lc-ms.html)

## SRM 和 MRM 的关系

| 名称 | 英文 | 通常含义 |
| --- | --- | --- |
| SRM | selected reaction monitoring | 监测一个或少数特定 transition |
| [MRM](多反应监测.md) | multiple reaction monitoring | 同一方法中监测多个 transition |
| [SRM-MRM](SRM-MRM.md) | SRM/MRM 总称 | 实际文献和软件中常混用 |

严格来说，SRM 更强调“一个选择反应”，MRM 更强调“多个选择反应”。实际使用中二者经常混用，很多人说 MRM 泛指三重四极杆靶向 transition 定量。

## 适合什么

| 场景 | 为什么适合 |
| --- | --- |
| 已知小分子定量 | transition 明确，灵敏度和线性好 |
| 药代/毒理/食品环境检测 | 方法可验证，重复性强 |
| 靶向蛋白质谱 | 监测特定肽段 transition |
| 生物标志物验证 | 适合候选目标从发现走向验证 |

SRM 不适合从未知复杂样本里“发现所有可能目标”。它的前提是目标、transition、保留时间和定量策略已经相对明确。

## 方法开发要点

| 要点 | 为什么重要 |
| --- | --- |
| 选择合适前体离子 | 决定目标入口是否特异 |
| 选择合适产物离子 | 决定 transition 是否抗干扰 |
| 优化 collision energy（碰撞能量） | 影响碎片强度 |
| 设置 retention time window（保留时间窗口） | 降低错误峰和提高通量 |
| 使用 internal standard（内标） | 提高定量稳定性 |
| 验证 ion ratio（离子比） | 帮助判断峰是否真实目标 |

## 常见问题

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 有峰但不是真目标 | transition 不够特异或基质干扰 | 增加确认 transition，检查离子比和保留时间 |
| 信号弱 | CE 不合适、离子源状态差、样本损失 | 优化 CE、源参数和前处理 |
| 定量不线性 | 基质效应、浓度超范围、内标不合适 | 重做标曲和稀释线性 |
| 重复性差 | 进样、积分、内标加入不稳定 | 固定操作和积分规则 |

## 小结

SRM 是“盯住一个前体-产物离子转变”的靶向质谱策略。它牺牲了发现未知物的能力，换来高选择性、高灵敏和稳定定量。适合用在目标已经明确的验证和检测阶段。
