# 吸光度

Absorbance（吸光度）是描述样品吸收光的程度的无量纲读数，常用于分光光度法、核酸/蛋白定量、酶活检测和 [ELISA](<../../用(实验流程内容篇)/ELISA.md>) 等实验。

## 一句话理解

吸光度回答的是：“有多少光被样品吸收或阻挡了？”

如果入射光进入样品后，透射出来的光变少，仪器就会给出更高的吸光度。IUPAC Gold Book 对 absorbance 的定义基于 incident spectral radiant power（入射光功率）与 transmitted spectral radiant power（透射光功率）的比值。参考：[IUPAC Gold Book: absorbance](https://goldbook.iupac.org/terms/view/A00028)。

## 基本概念

| 概念 | 英文 | 含义 |
| --- | --- | --- |
| 入射光 | Incident light | 进入样品前的光 |
| 透射光 | Transmitted light | 穿过样品后的光 |
| [透光率](透光率.md) | Transmittance | 透射光占入射光的比例 |
| 吸光度 | Absorbance | 光被样品吸收/衰减后的对数化读数 |
| 波长 | Wavelength | 仪器选择的检测光颜色或能量 |
| [光程校正](光程校正.md) | Pathlength correction | 对不同液柱高度造成的读数差异做校正 |

吸光度越高，通常表示样品吸收的光越多；但吸光度本身不直接等于浓度，必须结合波长、光程、摩尔吸光系数、标准曲线或校准方法解释。

## 和比尔-朗伯定律的关系

[比尔-朗伯定律](比尔-朗伯定律.md) 描述了吸光度与浓度、光程和吸收能力之间的关系。简化理解：

```text
吸光度 ∝ 浓度 × 光程
```

所以同一种有色物质，在光程固定时，浓度越高，吸光度越高；但如果光程变长，即使浓度不变，吸光度也会升高。这就是为什么比色皿通常使用固定 1 cm 光程，而微孔板读数有时要考虑液体体积和光程差异。

## OD、Absorbance 和 A 的关系

| 写法 | 常见含义 | 注意事项 |
| --- | --- | --- |
| Absorbance | 吸光度 | 最标准的通用说法 |
| A450 | 450 nm 吸光度 | 强调波长 |
| [OD450](OD450.md) | optical density at 450 nm | ELISA 中常用说法 |
| OD | Optical density | 历史和习惯用语，具体要写明波长 |

在许多实验记录中，OD450、A450 和 absorbance at 450 nm 经常被混用。为了减少歧义，正式记录最好写成 “OD450” 或 “absorbance at 450 nm”，并记录是否使用参考波长扣除。

## 在不同实验中的意义

| 实验 | 吸光度读数代表什么 |
| --- | --- |
| ELISA | 底物显色强度，间接代表目标物浓度 |
| BCA/Bradford 蛋白定量 | 显色反应强度，代表蛋白浓度 |
| 核酸 A260 | 260 nm 吸收，代表核酸含量 |
| 细菌 OD600 | 600 nm 光散射/浊度，近似反映细菌密度 |
| 酶活检测 | 底物或产物在特定波长的变化 |

不同实验的 OD 不是同一个物理含义。OD600 常包含散射成分，不应和 ELISA 的 OD450 简单类比。

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 吸光度超出仪器线性范围 | 样品过浓或显色过强 | 稀释样品或缩短显色时间 |
| 复孔差异大 | 气泡、液面不一致、移液误差 | 检查孔内气泡和加样体积 |
| 空白读数高 | 空白液污染、底物背景高、板脏 | 更换空白和耗材 |
| 同一样品不同体积读数不同 | 光程变化 | 固定体积或使用光程校正 |
| 波长选错 | 读数与目标吸收峰不匹配 | 按底物或试剂说明书设置波长 |

## 小结

吸光度是“光被样品吸收后留下的读数”，但它只有在波长、光程、空白、线性范围和标准曲线都明确时才有实验意义。看到 OD 数字时，第一反应应是问：什么波长、什么体积、什么空白、是否在范围内。
