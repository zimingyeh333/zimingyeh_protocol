# 艾里斑

## 一句话定义

Airy disk（艾里斑）是光通过圆形孔径成像一个理想点光源时形成的衍射斑图案，中央亮斑及其周围环纹体现了显微镜受 diffraction（衍射）限制的成像本质。

在显微镜中，一个无限小的点不会被成像成无限小的点，而会形成 Airy pattern（艾里图样）。艾里斑与显微镜分辨率、[数值孔径](数值孔径.md)、波长、共聚焦 pinhole（针孔）设置和 [点扩散函数](点扩散函数.md) 密切相关。Nikon MicroscopyU 和 Leica 的显微资料都将 Airy disk / Airy unit 作为理解显微分辨率和共聚焦针孔的重要概念。[参考：Nikon MicroscopyU Airy Disk](https://www.microscopyu.com/tutorials/airydisk)；[参考：Leica Confocal Pinhole](https://www.leica-microsystems.com/science-lab/life-science/confocal-microscopy/)

## 它为什么重要

显微镜的分辨率受到光的衍射限制。两个很近的点如果它们的艾里斑重叠太多，就无法被可靠分开。

```text
一个理想点
→ 通过物镜成像
→ 形成中央亮斑 + 周围衍射环
→ 这就是 Airy pattern
```

因此，显微镜分辨率不是由“放大倍率”单独决定，而由波长和 NA 共同决定。

## 与分辨率的关系

常见简化关系：

```text
艾里斑越小
→ 点像越集中
→ 越容易分辨相邻结构

波长越短、NA越高
→ 艾里斑越小
→ 理论分辨率越好
```

这也是为什么高 NA 物镜和较短波长能提高分辨率，但实际还要考虑信噪比、样本制备和像差。

## Airy disk vs PSF

| 概念 | 中文 | 说明 |
| --- | --- | --- |
| Airy disk | 艾里斑 | 理想点在二维焦平面上的衍射斑 |
| Airy pattern | 艾里图样 | 中央亮斑和环纹整体 |
| PSF | 点扩散函数 | 点在三维成像系统中的扩散形状 |
| Airy unit | 艾里单位 | 共聚焦 pinhole 大小常用单位 |

艾里斑可以理解为点扩散函数在焦平面上的一个核心表现。

## 共聚焦中的Airy unit

在 [共聚焦显微镜](<../../材(实验耗材工具篇)/共聚焦显微镜.md>) 中，pinhole 常用 Airy unit（AU，艾里单位）描述。常见起点是 1 AU：

| Pinhole | 影响 |
| --- | --- |
| 小于 1 AU | 光学切片更薄，但信号更弱 |
| 约 1 AU | 分辨率和信号的常见平衡 |
| 大于 1 AU | 信号更强，但焦外背景增加 |

不同波长和物镜下，1 AU 对应的实际 pinhole 尺寸不同。软件通常会根据物镜和波长计算。

## 常见误区

| 误区 | 解释 |
| --- | --- |
| 倍率越高分辨率越高 | 如果 NA 不高，只是把模糊放大 |
| 图像锐化等于分辨率提高 | 后处理不能创造丢失信息 |
| pinhole 越小越好 | 太小会损失信号并增加噪声 |
| 蓝光一定最好 | 短波长分辨率好，但光毒性和染料选择也重要 |

## 与实验的关系

| 实验问题 | 艾里斑提供的理解 |
| --- | --- |
| 两个点能否分开 | 受艾里斑大小和重叠影响 |
| 为什么高 NA 物镜更清楚 | 艾里斑更小、收光更多 |
| 为什么共聚焦 pinhole 影响图像 | 改变收集的焦内/焦外信号 |
| 为什么不能无限放大 | 衍射限制和采样限制 |

## 小结

艾里斑是理解显微镜分辨率的基础概念。它说明点在显微镜里不会成为完美点，而会受到衍射限制形成扩散图案。理解艾里斑，就能更好理解 NA、pinhole、PSF、反卷积和“放大不等于分辨率”。
