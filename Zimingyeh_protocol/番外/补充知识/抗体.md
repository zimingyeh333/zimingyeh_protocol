# 抗体

Antibody（抗体，常缩写为 Ab）也称 immunoglobulin（免疫球蛋白，常缩写为 Ig），是机体由 B 细胞及浆细胞产生、能够特异性识别 [抗原](抗原.md) 的蛋白分子；在实验中，抗体是 ELISA、Western blot、免疫荧光、流式细胞术和免疫组化等方法的核心识别工具。

图：抗体识别基础示意。抗体通过抗原结合区识别表位，实验信号同时受 [表位](表位.md)、[亲和力](亲和力.md)、[特异性](特异性.md) 和 [交叉反应](交叉反应.md) 影响。本图为项目内本地图片，用于个人学习笔记示意。

## 一句话理解

抗体的本质是“可被实验利用的特异性识别分子”：它把一个复杂样本中的目标抗原挑出来，并把这种识别转化为沉淀、显色、荧光、化学发光或分选信号。

Janeway Immunobiology 对抗体识别的描述强调，抗体和抗原的结合主要依赖氢键、静电相互作用、疏水作用和范德华力等非共价相互作用，因此抗体识别不是“锁死”，而是可逆、受条件影响的结合过程。参考：[NCBI Bookshelf: Antigen recognition by B-cell and T-cell receptors](https://www.ncbi.nlm.nih.gov/books/NBK27160/)。

## 基本结构

典型抗体由两条 heavy chain（重链）和两条 light chain（轻链）组成，整体常被简化理解为 Y 形结构。

| 结构 | 英文 | 主要意义 |
| --- | --- | --- |
| 抗原结合区 | Antigen-binding site | 真正接触抗原表位的位置 |
| 可变区 | Variable region | 决定识别哪一个表位 |
| 恒定区 | Constant region | 决定抗体类别和部分效应功能 |
| [Fab片段](Fab片段.md) | Fragment antigen-binding | 保留抗原结合能力的片段 |
| [Fc片段](Fc片段.md) | Fragment crystallizable | 参与二抗识别、Fc 受体结合和效应功能 |

实验中经常说的“抗体识别抗原”，更精确地说，是抗体的抗原结合区识别抗原上的某个表位。一个蛋白可以有多个表位，因此不同抗体即使都针对同一个蛋白，实验表现也可能完全不同。

## 抗体在实验中的角色

| 角色 | 常见场景 | 关键要求 |
| --- | --- | --- |
| [一抗](<../../材(实验耗材工具篇)/一抗.md>) | Western blot、免疫荧光、免疫组化 | 识别目标抗原，要求特异性和应用验证 |
| [二抗](<../../材(实验耗材工具篇)/二抗.md>) | 信号放大、荧光或酶标检测 | 识别一抗宿主种属和 Ig 类型，避免交叉吸附问题 |
| [捕获抗体](<../../材(实验耗材工具篇)/捕获抗体.md>) | 夹心 ELISA | 能稳定固定并捕获目标抗原 |
| [检测抗体](<../../材(实验耗材工具篇)/检测抗体.md>) | 夹心 ELISA、竞争 ELISA | 与捕获抗体识别不同表位或不互相遮挡 |
| [配对抗体](<../../材(实验耗材工具篇)/配对抗体.md>) | ELISA kit 开发 | 需要验证 pair compatibility 和动态范围 |

BioLegend 的 sandwich ELISA protocol 体现了夹心 ELISA 的典型抗体逻辑：先用捕获抗体包被板面，再加入样本抗原，随后用检测抗体和酶标体系把识别事件转化为显色信号。参考：[BioLegend sandwich ELISA protocol](https://www.biolegend.com/en-us/protocols/sandwich-elisa-protocol)。

## 常见抗体类型

| 类型 | 英文 | 优点 | 局限 |
| --- | --- | --- | --- |
| [单克隆抗体](单克隆抗体.md) | Monoclonal antibody | 批间一致性好，识别单一表位，适合标准化实验 | 如果表位被固定、变性或突变破坏，信号可能消失 |
| [多克隆抗体](多克隆抗体.md) | Polyclonal antibody | 识别多个表位，信号强，对抗原构象变化更宽容 | 批间差异更大，背景和交叉反应风险更高 |
| [重组抗体](重组抗体.md) | Recombinant antibody | 序列可定义，长期供应和工程改造更稳定 | 价格可能较高，仍需应用验证 |
| 片段抗体 | Antibody fragment | 分子更小，组织渗透性或工程改造更灵活 | 可能缺少 Fc 功能或半衰期较短 |
| 偶联抗体 | Conjugated antibody | 可直接带荧光、酶或生物素标签 | 偶联物可能影响亲和力、背景或储存稳定性 |

Thermo Fisher 的 ELISA overview 也强调，ELISA 的不同格式依赖不同抗体配置，例如直接法、间接法、夹心法和竞争法。参考：[Thermo Fisher Overview of ELISA](https://www.thermofisher.com/us/en/home/life-science/protein-biology/protein-biology-learning-center/protein-biology-resource-library/pierce-protein-methods/overview-elisa.html)。

## 选择抗体时看什么

| 维度 | 为什么重要 | 实际记录建议 |
| --- | --- | --- |
| 目标抗原 | 决定你到底在检测什么 | 记录 gene/protein name、isoform、species reactivity |
| 免疫原 | 影响抗体识别区域 | 记录 [免疫原](免疫原.md) 是全长蛋白、片段还是肽段 |
| 克隆号 | 决定抗体身份 | 单克隆和重组抗体必须记录 clone |
| 宿主种属 | 决定二抗选择 | 例如 rabbit、mouse、goat |
| 应用验证 | 同一抗体不一定适合所有实验 | 记录 WB、IF、IHC、flow、ELISA 等验证证据 |
| 稀释比例或浓度 | 直接影响信号和背景 | 做 [抗体滴度](抗体滴度.md) 或小范围梯度 |
| 批号 | 批间差异排查关键 | 商业抗体记录 lot number |
| 储存条件 | 影响活性和背景 | 记录温度、冻融次数、开封日期 |

选择抗体时不要只看品牌和标题，也不要只看“anti-target”。真正重要的是：这个抗体是否在你的样本、物种、处理方式和检测平台中被验证过。

## 和相关概念的区别

| 概念 | 关注点 | 和抗体的关系 |
| --- | --- | --- |
| 抗原 | 被识别的目标结构 | 抗体识别抗原上的表位 |
| 表位 | 抗体实际接触的局部结构 | 同一抗原可有多个表位 |
| 免疫原 | 能诱导免疫反应的物质 | 用于制备抗体，但不一定等同于实验中的天然抗原 |
| [半抗原](半抗原.md) | 太小、单独免疫原性不足的小分子 | 常需连接载体蛋白后诱导抗体 |
| 亲和力 | 抗体和表位结合强度 | 影响信号保留和低丰度检测 |
| 特异性 | 是否只识别目标 | 决定信号是否可信 |

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 信号弱 | 抗体亲和力不足、目标表达低、表位被破坏 | 增加抗体浓度，优化孵育条件，换验证过应用的抗体 |
| 背景高 | 抗体浓度过高、封闭不足、二抗交叉反应 | 做滴度，优化 [封闭液](<../../材(实验耗材工具篇)/封闭液.md>) 和洗涤 |
| 多条带 | 非特异性结合、降解、同源蛋白识别 | 加入 KO/KD 对照或换抗体 |
| 批次更换后结果改变 | 多克隆批间差异或生产变更 | 记录批号，必要时桥接验证 |
| IF/IHC 无定位 | 抗体不适合固定样本或抗原修复不足 | 查看应用验证，优化固定和修复条件 |
| ELISA 曲线差 | 捕获和检测抗体不匹配 | 换配对抗体或优化浓度、洗涤、孵育时间 |

## 小结

抗体不是“买来就能用”的黑箱试剂，而是一个由抗原、表位、免疫原、亲和力、特异性、样本处理和检测体系共同决定表现的识别工具。实验记录中把抗体身份、应用验证、批号和使用条件写清楚，往往比只记录“用了某某抗体”重要得多。
