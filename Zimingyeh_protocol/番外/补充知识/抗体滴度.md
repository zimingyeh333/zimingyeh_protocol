# 抗体滴度

Antibody titer（抗体滴度）是指抗体在连续稀释后仍能产生可检测特异信号的稀释程度；在实验优化中，“做滴度”通常指用抗体浓度或稀释比例梯度寻找信号强、背景低、线性范围合适的工作条件。

## 一句话理解

抗体滴度不是单纯追求“信号最强”，而是找“真信号和背景最舒服的平衡点”。

BioLegend 的 sandwich ELISA protocol 会分别使用捕获抗体和检测抗体，并在洗涤、封闭和显色之间建立信号体系。实际开发或优化时，捕获抗体、检测抗体和酶标物都可能需要滴定。参考：[BioLegend sandwich ELISA protocol](https://www.biolegend.com/en-us/protocols/sandwich-elisa-protocol)。

## 为什么要做抗体滴度

| 目的 | 说明 |
| --- | --- |
| 降低背景 | 抗体过浓常导致非特异性结合 |
| 保持真信号 | 抗体过稀会让目标信号下降 |
| 扩大动态范围 | 过强信号容易饱和，影响定量 |
| 节约试剂 | 找到足够而不过量的工作浓度 |
| 提高重复性 | 固定合理浓度后更容易跨批次比较 |

## 常见滴定对象

| 对象 | 常见场景 | 观察指标 |
| --- | --- | --- |
| 一抗 | WB、IF、IHC、flow | 目标信号、背景、定位或条带 |
| 二抗 | WB、IF、IHC | 背景、串色、曝光时间 |
| 捕获抗体 | ELISA | 最大信号、低端灵敏度、背景 |
| 检测抗体 | ELISA | 标准曲线斜率、背景、Hook 风险 |
| 酶标链霉亲和素 | ELISA | 显色速度、空白孔背景 |

## 怎么判断最佳浓度

| 观察 | 解释 |
| --- | --- |
| 真信号高、阴性低 | 理想区间 |
| 真信号高、阴性也高 | 抗体可能过浓或非特异性结合明显 |
| 真信号低、阴性低 | 抗体可能过稀或孵育不足 |
| 所有条件都高 | 背景来源可能不只抗体浓度 |
| 高浓度反而下降 | 可能出现 Hook 效应或体系饱和/干扰 |

定量实验中，最佳浓度通常要结合 [LOD](LOD.md)、[LOQ](LOQ.md)、标准曲线线性或 4PL 拟合质量来判断。

## 滴度 vs 亲和力

| 项目 | 抗体滴度 | [亲和力](亲和力.md) |
| --- | --- | --- |
| 关注点 | 稀释到什么程度仍有信号 | 抗体和表位结合强度 |
| 是否受检测体系影响 | 很受影响 | 测量平台相关但更偏分子互作 |
| 可否代表抗体质量 | 只能部分代表 | 也只能部分代表 |
| 常见读数 | OD、荧光、条带、阳性率 | Kd、kon、koff |

滴度高不等于特异性好。一个非特异性强的抗体也可能“滴度很高”，所以必须结合阴性对照和特异性验证。

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 高浓度背景严重 | 抗体过量或封闭不足 | 降低抗体浓度，优化封闭和洗涤 |
| 低浓度信号消失 | 目标低丰度或亲和力不足 | 延长孵育，提高浓度或换抗体 |
| 标准曲线高端饱和 | 检测抗体或酶标物过量 | 降低检测体系浓度 |
| 批次更换后最佳稀释变了 | 批号差异或储存状态改变 | 重新做小范围滴定 |
| 不同样本最佳浓度不同 | 基质或目标丰度差异 | 按样本类型分别优化 |

## 小结

抗体滴度是把抗体从“说明书推荐”变成“适合自己体系”的关键步骤。它不是越浓越好，而是让目标信号、背景信号、动态范围和成本达到平衡。
