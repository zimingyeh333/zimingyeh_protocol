# 引物二聚体

Primer dimer（引物二聚体）是 PCR 或 qPCR 反应中引物之间互相退火并被 DNA polymerase（DNA 聚合酶）延伸形成的短双链 DNA 产物；在 [RT-qPCR](<../../用(实验流程内容篇)/RT-qPCR.md>) 中，它会消耗反应组分、产生非目标荧光，并让 [Cq值](Cq值.md) 失去解释力。

## 一句话理解

引物二聚体就是“引物自己和自己扩增起来了”，尤其会骗过 SYBR 这类双链 DNA 染料。

MIQE 指南强调 qPCR 需要报告引物信息、扩增效率和特异性验证；引物二聚体正是 qPCR 特异性验证中最常见、也最容易被忽略的问题之一。参考：[MIQE guidelines, Clinical Chemistry 2009](https://academic.oup.com/clinchem/article/55/4/611/5631762)。

## 为什么会形成

| 原因 | 机制 |
| --- | --- |
| 引物 3' 端互补 | 3' 端一旦互补，聚合酶容易延伸 |
| 引物浓度过高 | 增加引物互相碰撞和退火机会 |
| 退火温度过低 | 低特异性结合更容易发生 |
| Mg2+ 或反应体系过强 | 非特异扩增也被支持 |
| 目标模板很少 | 引物更容易彼此结合，而不是结合模板 |
| 循环数过多 | 后期非特异产物累积 |

IDT 的 qPCR primer design 资料强调，引物设计需要关注 Tm、GC 含量、扩增片段长度和二聚体风险，尤其要避免正反向引物 3' 端互补。参考：[IDT qPCR Primer Design](https://www.idtdna.com/pages/education/decoded/article/designing-qpcr-assays)。

## 如何识别引物二聚体

| 证据 | 典型表现 |
| --- | --- |
| [无模板对照](无模板对照.md) 出现扩增 | NTC 有晚 Cq |
| [熔解曲线](熔解曲线.md) 低温小峰 | Tm 通常低于目标产物 |
| 胶图出现很短条带 | 常见小于目标 [扩增子](扩增子.md) |
| 低模板样本更明显 | 目标少时二聚体竞争更强 |
| Cq 很晚且重复性差 | 常见非特异背景 |

在 SYBR Green 体系中，引物二聚体会像目标双链 DNA 一样发光；在 TaqMan 体系中，引物二聚体不一定产生探针信号，但仍会消耗引物、dNTP 和聚合酶，影响扩增效率。

## 对结果有什么影响

| 影响 | 后果 |
| --- | --- |
| 消耗引物和反应组分 | 目标扩增效率下降 |
| 增加背景荧光 | NTC 或低表达样本出现假阳性 |
| 干扰熔解曲线 | 多峰或低温峰 |
| 改变扩增效率 | 标准曲线斜率异常 |
| 影响低丰度目标 | 弱目标更容易被二聚体信号掩盖 |

## 预防策略

| 策略 | 说明 |
| --- | --- |
| 优化 [qPCR引物](<../../材(实验耗材工具篇)/qPCR引物.md>) 设计 | 避免 3' 端互补、长连续 G/C 和明显 hairpin |
| 提高退火温度 | 增加结合特异性 |
| 降低引物浓度 | 减少引物互相结合机会 |
| 使用 hot-start polymerase | 降低低温配液阶段非特异延伸 |
| 缩短过度循环 | 减少后期非特异产物积累 |
| 改用探针法 | 对关键低丰度目标提高特异性 |
| 做 NTC 和熔解曲线 | 每次实验都要检查 |

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| NTC 有晚 Cq 且熔解曲线低温峰 | 典型引物二聚体 | 降低引物浓度，提高退火温度 |
| 样本和 NTC Tm 相同 | 可能主要扩增的是二聚体 | 不纳入定量，重新设计引物 |
| 目标峰和低温峰并存 | 目标扩增和二聚体竞争 | 优化引物和体系，再确认效率 |
| 标准曲线低浓度点偏离 | 低模板时二聚体竞争明显 | 提高模板质量或换引物 |
| 多次优化仍存在 | 引物设计根本不佳 | 重新设计引物对 |

## 和污染的区别

| 项目 | 引物二聚体 | 污染 |
| --- | --- | --- |
| NTC Cq | 常较晚 | 可早可晚 |
| 熔解曲线 | 常为低温小峰 | 可能和目标产物 Tm 一样 |
| 胶图大小 | 很短条带 | 可能是目标大小 |
| 处理方式 | 优化引物和退火条件 | 更换水、mix、分区操作 |
| 对低表达样本 | 影响很大 | 也会造成假阳性 |

如果 NTC 的熔解峰和真实样本目标峰位置相同，要优先怀疑污染；如果是明显低温短产物，更像引物二聚体。

## 小结

引物二聚体是 qPCR 中最常见的假信号来源之一。判断它不要只看有没有 Cq，要同时看 NTC、熔解曲线、产物大小和目标样本的表达强弱。
