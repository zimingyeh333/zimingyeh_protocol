# 空白对照

Blank control（空白对照）是指不含目标分析物、通常也不含真实样本的对照，用于估计实验体系本身的本底信号、试剂空白、仪器背景或板面背景。

## 一句话理解

空白对照回答的是：“什么都不该有时，这个系统自己会读出多少？”

ICH M10 生物分析方法验证指南要求校准曲线和质控样本用于评价方法表现，其中 blank sample（空白样本）用于检查干扰和背景。参考：[ICH M10 Bioanalytical Method Validation](https://database.ich.org/sites/default/files/M10_Guideline_Step4_2022_0524.pdf)。

## 空白对照常见形式

| 场景 | 空白对照例子 | 主要用途 |
| --- | --- | --- |
| ELISA | 只加 buffer/底物，不加样本或标准品 | 扣除板面和底物背景 |
| 标准曲线 | blank 或 zero standard | 确定低端背景 |
| qPCR | 水孔或无模板体系 | 更接近 NTC，检查体系本底 |
| 分光光度法 | 溶剂或 buffer blank | 仪器调零和背景扣除 |
| 荧光检测 | 无染料或无样本孔 | 自发荧光和板背景 |

不同实验里 blank 的具体配方不完全一样。写 protocol 时不能只写“blank”，要写清楚空白孔包含哪些组分。

## 空白对照 vs 阴性对照

| 项目 | 空白对照 | [阴性对照](阴性对照.md) |
| --- | --- | --- |
| 是否有真实样本基质 | 通常没有 | 通常有 |
| 主要检查 | 试剂/仪器/板面背景 | 假阳性和样本基质背景 |
| 用途 | 背景扣除、LOD 估算 | 结果判读和假阳性控制 |
| 风险 | 低估真实样本背景 | 需要真正阴性样本 |

空白很低不代表阴性样本也低。真实血清、血浆、细胞裂解液或组织提取物可能有明显 [基质效应](基质效应.md)。

## 空白读数异常意味着什么

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 空白 OD/荧光高 | 底物污染、板面背景、洗涤不足 | 更换底物，优化洗涤 |
| 空白孔差异大 | 气泡、孔位蒸发、移液误差 | 检查板图和操作 |
| 空白随时间升高 | 底物自发反应或显色过久 | 缩短反应时间 |
| 空白边缘高 | 边缘效应 | 避免边缘孔或加强湿盒 |
| 空白扣除后负值 | 背景扣除方式不合适 | 检查原始读数和 blank 设置 |

## 小结

空白对照用于测系统本底，但不等于真实阴性样本。定量实验中要同时关注 blank、阴性样本和低浓度标准品，才能判断低端信号是否可信。
