# 背景信号

Background signal（背景信号）是指实验读数中不来自目标分子、目标细胞或目标反应的基础信号；它会降低 [信噪比](信噪比.md)，使弱阳性难以判断，并可能造成假阳性。

## 一句话理解

背景信号就是“没有真正目标时也亮起来的那部分信号”。

Thermo Fisher 的 ELISA overview 强调，不同 ELISA 格式都依赖抗体识别、洗涤和检测体系把目标结合转化为读数；这些步骤中的非目标结合、残留酶标物或基质影响，都可能成为背景来源。参考：[Thermo Fisher Overview of ELISA](https://www.thermofisher.com/us/en/home/life-science/protein-biology/protein-biology-learning-center/protein-biology-resource-library/pierce-protein-methods/overview-elisa.html)。

## 常见来源

| 来源 | 机制 | 常见场景 |
| --- | --- | --- |
| [非特异性结合](非特异性结合.md) | 抗体、蛋白或探针粘到非目标位置 | ELISA、WB、IF、IHC |
| 封闭不足 | 板面、膜或组织空位点没有被充分占据 | ELISA、Western blot |
| 洗涤不足 | 未结合抗体或酶标物残留 | ELISA、免疫染色 |
| 样本基质 | 血清、血浆、裂解液等影响读数 | ELISA、多重因子检测 |
| 自发荧光 | 细胞、组织或材料本身发光 | IF、IHC、流式 |
| 仪器本底 | 光学、电化学或板读仪噪声 | 各类定量读数 |
| 交叉反应 | 抗体识别相似目标 | 抗体实验和免疫检测 |

## 背景信号 vs 真信号

| 项目 | 真信号 | 背景信号 |
| --- | --- | --- |
| 来源 | 目标结合或目标反应 | 非目标结合、基质、仪器或残留试剂 |
| 是否随目标浓度变化 | 通常有规律变化 | 可能不随目标变化 |
| 是否被阴性对照揭示 | 阴性应低 | 阴性也会偏高 |
| 对结果影响 | 提供生物学信息 | 压缩动态范围或制造假阳性 |

## 分层排查思路

| 先看什么 | 判断逻辑 |
| --- | --- |
| [空白对照](空白对照.md) | 没有样本和目标时是否也有读数 |
| [阴性对照](阴性对照.md) | 没有目标的真实样本是否偏高 |
| [阳性对照](阳性对照.md) | 体系是否仍有检测能力 |
| 梯度稀释 | 背景是否随样本稀释下降 |
| 只去掉一抗或检测抗体 | 判断背景来自哪一层抗体 |
| 换封闭液或洗涤条件 | 判断是否为表面非特异吸附 |

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 所有孔都偏高 | 洗涤不足、底物污染或酶标物过量 | 增加洗涤，缩短显色，稀释检测抗体 |
| 阴性样本偏高 | 基质效应或非特异性结合 | 做基质匹配、稀释线性和封闭优化 |
| 边缘孔偏高 | 蒸发或温度不均 | 避免边缘孔或加强湿盒孵育 |
| IF 背景弥散 | 封闭不足或抗体浓度过高 | 做抗体滴度并优化封闭 |
| WB 膜整体发黑 | 二抗过浓或曝光过长 | 稀释二抗，降低曝光时间 |

## 小结

背景信号不是单一问题，而是“非目标读数”的总称。排查时不要直接换试剂，要先用空白、阴性、去除某一步试剂和梯度稀释把背景来源定位清楚。
