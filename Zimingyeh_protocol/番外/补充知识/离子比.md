# 离子比

Ion ratio（离子比）是在靶向质谱中用于确认目标峰身份的重要指标，通常指 qualifier transition（确认离子对）与 quantifier transition（定量离子对）峰面积或峰高之间的比例。它常用于 MRM/SRM、小分子检测和靶向肽段定量。

## 为什么要看离子比

在 MRM/SRM 中，一个目标通常会设置多个 [transition](transition.md)。其中最强、最稳定的一个用于定量，另一个或几个用于确认。如果某个样本中定量 transition 有峰，但确认 transition 的相对比例不对，就说明这个峰可能不是目标，或者受到了基质干扰。

```text
目标标准品中：
定量 transition 峰面积 = 100000
确认 transition 峰面积 = 35000
离子比 = 0.35

未知样本中：
定量 transition 峰面积 = 100000
确认 transition 峰面积 = 5000
离子比 = 0.05
=> 需要警惕假阳性或积分错误
```

Thermo Fisher 的 Triple Quadrupole LC-MS 页面强调三重四极杆用于靶向检测和定量，并突出 selectivity（选择性）。离子比就是把这种选择性从“有峰”推进到“峰的碎片比例也像目标”的关键确认指标。参考：[Thermo Fisher Triple Quadrupole LC-MS](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/liquid-chromatography-mass-spectrometry-lc-ms/lc-ms-systems/triple-quadrupole-lc-ms.html)

## 离子比在方法中的位置

| 元素 | 作用 |
| --- | --- |
| 定量 transition | 用于计算浓度或丰度 |
| 确认 transition | 用于确认目标身份 |
| 保留时间窗口 | 限制目标峰出现的时间范围 |
| 离子比 | 判断多个 transition 是否按预期共同出现 |
| 内标 | 修正样本处理和离子化差异 |

可靠的靶向峰通常不是“一个 transition 有峰”就够，而是多个证据同时吻合。

## 离子比异常说明什么

| 表现 | 可能原因 |
| --- | --- |
| 确认 transition 太低 | 假阳性、离子抑制、低信噪比 |
| 确认 transition 太高 | 共洗脱干扰或积分错误 |
| 离子比随浓度变化 | 低浓度接近噪声，或 detector/积分问题 |
| 标准品正常、样本异常 | 基质效应或共洗脱干扰 |
| 批次间漂移 | 仪器状态、碰撞能量或色谱变化 |

## 使用注意

- 离子比阈值应来自方法验证、标准品或法规/平台 SOP，而不是随意设定。
- 低浓度接近定量下限时，离子比可能更不稳定。
- 离子比合格也不代表完全确认结构，还要看保留时间、峰形和标准品。
- 肽段 MRM 中应选择特异性较好的碎片离子，避免常见低 m/z 背景碎片。

## 常见错误

| 错误 | 后果 |
| --- | --- |
| 只看定量 transition | 假阳性风险高 |
| 确认 transition 太弱仍强行使用 | 离子比不稳定 |
| 不用标准品建立参考比例 | 无法判断样本峰是否合理 |
| 自动积分不复核 | 错峰会让离子比看起来异常 |
| 忽略保留时间 | 离子比相似的背景峰仍可能误判 |

## 小结

离子比是靶向质谱中确认目标峰的重要证据。它把判断从“这个 transition 有信号”推进到“多个 transition 的相对关系也符合目标”。在 MRM/SRM 中，离子比、保留时间、峰形和内标应一起看。
