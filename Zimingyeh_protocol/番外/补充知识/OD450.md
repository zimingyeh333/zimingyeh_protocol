# OD450

OD450（optical density at 450 nm，450 nm 光密度/吸光度）是在 450 nm 波长下读取的吸光度，在 HRP-TMB 显色型 [ELISA](<../../用(实验流程内容篇)/ELISA.md>) 中非常常见。

![Absorbance OD450 pathlength](../../z_asset/番外/吸光度与OD450/absorbance-od450-pathlength.png)

图：吸光度、OD450 和光程的关系。TMB endpoint 加酸终止后形成黄色读数状态，通常在 450 nm 读取。本图由 Image2 / image-generation model 生成，用于个人学习笔记示意。

## 一句话理解

OD450 回答的是：“这孔在 450 nm 下有多黄？”

在常见 horseradish peroxidase（HRP，辣根过氧化物酶）+ [TMB](<../../材(实验耗材工具篇)/TMB.md>) 体系中，TMB 显色后加入 [终止液](<../../材(实验耗材工具篇)/终止液.md>)，颜色由蓝色转为黄色，随后用 [酶标仪](<../../材(实验耗材工具篇)/酶标仪.md>) 读取 450 nm 吸光度。BioLegend 的 sandwich ELISA protocol 也在加入 stop solution 后读取 450 nm 吸光度。参考：[BioLegend sandwich ELISA protocol](https://www.biolegend.com/en-us/protocols/sandwich-elisa-protocol)。

## 为什么是 450 nm

TMB 被 HRP 氧化后，在酸性终止条件下形成黄色产物，适合在 450 nm 附近读取。因此 OD450 是 HRP-TMB endpoint ELISA 的常见终点读数。

这并不代表所有 ELISA 都读 450 nm。不同底物和酶标体系的读数波长不同：

| 底物/体系 | 常见读出 | 说明 |
| --- | --- | --- |
| HRP + TMB + stop solution | OD450 | 最常见 ELISA endpoint |
| HRP + TMB 未终止 | 约 650 nm | 蓝色产物，具体按说明书 |
| HRP + ABTS | 约 405/415 nm | 取决于产品和 protocol |
| AP + pNPP | 约 405 nm | 碱性磷酸酶体系 |
| 化学发光 ELISA | Luminescence | 不读 OD450 |

所以记录时不能只写“读板”，必须写清波长和底物体系。

## OD450 和标准曲线

OD450 本身不是浓度。它只是 TMB 黄色产物的读数，需要通过 [标准曲线](标准曲线.md) 换算为目标物浓度。

```text
样本 OD450
→ 放到标准曲线
→ 插值得到浓度
→ 检查是否在 LOQ 范围内
→ 乘以样本稀释倍数
```

如果 OD450 低于背景附近，可能低于 [LOD](LOD.md)；如果 OD450 接近高端平台，可能超过 [LOQ](LOQ.md) 或需要稀释样本重测。

## 参考波长

[参考波长](参考波长.md) 是用于扣除板底划痕、指纹、气泡、液体浑浊或非特异光学背景的辅助波长。ELISA 中常见做法是读取 450 nm，同时用 570 nm、590 nm 或 620 nm 等参考波长做 correction，具体按 kit 和仪器说明书。

常见记录方式：

```text
OD450
OD450-570
OD450-620
Absorbance at 450 nm with 570 nm reference
```

如果使用了参考波长，必须在记录和图注里写清，否则不同实验之间无法直接比较。

## 读数时间

加入终止液后，OD450 相对稳定，但不是无限稳定。不同 kit 会规定终止后多久内读板。延迟太久、不同板读数时间不一致，或加终止液顺序与读板顺序差异太大，都可能造成技术误差。

关键做法：

- 加 TMB 和加终止液顺序保持一致。
- 使用多道移液枪减少孔间时间差。
- 终止后按说明书时间窗口读板。
- 读板前检查明显气泡。
- 记录显色时间、终止时间和读板时间。

## 常见异常与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 全板 OD450 很高 | 显色过久、洗板不足、HRP 过量 | 缩短显色，优化 [洗涤缓冲液](<../../材(实验耗材工具篇)/洗涤缓冲液.md>) |
| 阳性孔 OD450 很低 | HRP/TMB 失效、抗体漏加、目标物低 | 检查阳性对照和底物 |
| 复孔差异大 | 气泡、移液节奏、边缘效应 | 检查板图和读板前孔面 |
| 标准曲线高端平台 | 样本/标准品太浓或显色饱和 | 缩短显色或稀释 |
| 结果被软件外推 | OD450 不在标准曲线可靠范围 | 标记为范围外并重测 |

## 小结

OD450 是 HRP-TMB endpoint ELISA 最常见的读数，但它只是信号，不是浓度。解释 OD450 时必须同时看底物、终止液、读数时间、参考波长、标准曲线和样本稀释倍数。
