# 佐剂

Adjuvant（佐剂）是与 antigen（抗原）或 [免疫原](免疫原.md) 一起使用、用于增强或调节免疫反应的辅助物质；在抗体制备中，佐剂常用于提高抗体滴度、延长抗原暴露或改变免疫反应类型。

## 一句话理解

佐剂不是目标本身，而是“提醒免疫系统认真回应这个目标”的辅助信号。

Oxford Vaccine Knowledge Project 对疫苗成分的说明中提到，aluminium salts（铝盐）可作为 adjuvants（佐剂），用于加强并延长机体对疫苗的免疫反应，并列出了 aluminium hydroxide、aluminium phosphate 和 potassium aluminium sulphate 等例子。参考：[Oxford Vaccine Knowledge Project: Vaccine ingredients](https://vaccineknowledge.ox.ac.uk/vaccine-ingredients)。

## 佐剂为什么有用

| 作用 | 解释 |
| --- | --- |
| 增强免疫刺激 | 让免疫系统更容易识别免疫原并启动反应 |
| 延长抗原暴露 | 某些佐剂可形成 depot effect，使抗原缓慢释放 |
| 促进抗原呈递 | 帮助抗原被抗原呈递细胞处理 |
| 调节免疫偏向 | 不同佐剂可能偏向不同类型的免疫反应 |
| 提高抗体滴度 | 在抗体制备中常用于获得更强血清反应 |

佐剂的作用不是“让抗体更特异”，而是增强或改变免疫反应。抗体最终是否特异，仍然取决于免疫原设计、动物反应、筛选策略和验证方法。

## 常见佐剂类型

| 类型 | 例子 | 常见用途 | 注意 |
| --- | --- | --- | --- |
| 油包水乳剂 | [完全弗氏佐剂](<../../材(实验耗材工具篇)/完全弗氏佐剂.md>)、[不完全弗氏佐剂](<../../材(实验耗材工具篇)/不完全弗氏佐剂.md>) | 研究用动物免疫 | 刺激性强，必须遵守动物伦理和机构 SOP |
| 铝盐类 | [氢氧化铝佐剂](<../../材(实验耗材工具篇)/氢氧化铝佐剂.md>)、磷酸铝 | 疫苗和部分免疫实验 | 偏向某些免疫反应类型 |
| 皂苷类 | QS-21 等 | 疫苗佐剂系统 | 配方复杂，通常不自行配制 |
| TLR 激动剂 | CpG DNA 等 | 强化先天免疫刺激 | 需要明确应用和安全规范 |
| 乳剂系统 | MF59、AS03 等 | 疫苗或研究系统 | 商业体系居多 |

## 在抗体制备中的选择逻辑

| 选择问题 | 思考方向 |
| --- | --- |
| 目标是多克隆抗体还是单克隆抗体 | 多克隆更关注血清滴度，单克隆还要考虑后续筛选 |
| 免疫原本身强不强 | 小肽、半抗原和保守蛋白通常更依赖佐剂和载体蛋白 |
| 动物福利和伦理要求 | 佐剂刺激性必须纳入 IACUC 或机构动物伦理审查 |
| 后续检测应用 | 过强或复杂免疫反应可能增加非目标抗体比例 |
| 是否使用商业服务 | 委托抗体制备时要记录服务商方案和佐剂类型 |

## 和载体蛋白的区别

| 项目 | 佐剂 | [载体蛋白](载体蛋白.md) |
| --- | --- | --- |
| 主要作用 | 增强或调节免疫反应 | 给小分子或短肽提供免疫原性 |
| 是否成为抗体识别对象 | 可能诱导抗佐剂相关反应，但通常不是目标 | 可能产生大量抗载体蛋白抗体 |
| 使用对象 | 蛋白、肽、小分子偶联物等 | 半抗原、小肽等 |
| 排错重点 | 炎症强度、动物反应、免疫偏向 | 抗体是否识别 carrier 而不是目标 |

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 抗体滴度低 | 免疫原弱、佐剂不足或免疫路线不合适 | 优化免疫原、载体蛋白或委托服务方案 |
| 背景抗体多 | 免疫体系过复杂或筛选不足 | 加强阴性筛选和交叉反应筛选 |
| 动物局部反应严重 | 佐剂刺激性过强或操作不符合规范 | 停止自行调整，按动物伦理和兽医建议处理 |
| 抗体更像识别载体蛋白 | 半抗原或肽段暴露不足 | 使用不同载体或不同偶联方向筛选 |

## 小结

佐剂负责增强或塑造免疫反应，但不能替代好的免疫原设计和后续筛选。用于动物免疫时，佐剂选择必须同时考虑抗体质量、动物福利和机构规范。
