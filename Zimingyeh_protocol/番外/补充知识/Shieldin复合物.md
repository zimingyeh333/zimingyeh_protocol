# Shieldin复合物

Shieldin complex（Shieldin 屏蔽蛋白复合物）由 REV7、SHLD1、SHLD2 与 SHLD3 组成，是 [53BP1](53BP1.md)–[RIF1](RIF1.md) 轴下游的 single-stranded DNA-binding complex（单链 DNA 结合复合物）。它限制 DNA 末端进一步切除，并可连接 CST–Pol α 回填系统，使断端更适合末端连接。

Shieldin 缺失可在部分 BRCA1 缺陷背景中恢复切除和 RAD51 装载，但不保证同源重组的全部阶段、复制叉保护或基因组稳定性完全恢复。
