# 碰撞池

Collision cell（碰撞池）是 [串联质谱](串联质谱.md) 中让 [前体离子](前体离子.md) 与碰撞气体发生碰撞并产生 [碎片离子](碎片离子.md) 的区域。它是 [碰撞诱导解离](碰撞诱导解离.md)（CID/CAD）和许多靶向定量方法中的关键硬件环节。

## 在仪器中的位置

在 [三重四极杆质谱仪](<../../材(实验耗材工具篇)/三重四极杆质谱仪.md>) 中，碰撞池通常对应 Q2 区域：

```text
Q1：选择前体离子
Q2：碰撞池，前体离子与气体碰撞并碎裂
Q3：选择产物离子
检测器：记录 transition 信号
```

Thermo Fisher 的 Triple Quadrupole LC-MS 页面展示了三重四极杆用于靶向检测和定量的 SRM/MRM 逻辑；其中 Q2 碰撞/碎裂环节是前体离子转化为产物离子的关键。参考：[Thermo Fisher Triple Quadrupole LC-MS](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/liquid-chromatography-mass-spectrometry-lc-ms/lc-ms-systems/triple-quadrupole-lc-ms.html)

## 碰撞池做什么

| 功能 | 说明 |
| --- | --- |
| 引入碰撞气体 | 常见为氮气、氩气等，具体依仪器而定 |
| 激活前体离子 | 离子碰撞后内部能量升高 |
| 产生碎片离子 | 化学键断裂，形成可解释的产物离子 |
| 支持 transition | MRM/SRM 中形成 precursor -> product 关系 |
| 控制碎裂程度 | 通过碰撞能量、气体、驻留时间等影响碎片谱 |

## 和 collision energy 的关系

Collision energy（CE，碰撞能量）是碰撞池相关参数中最常被优化的变量。CE 不是越高越好，而是要让目标碎片离子稳定、强度足够、背景不过高。

| CE 状态 | 结果 |
| --- | --- |
| 太低 | 前体离子碎裂不足，产物离子弱 |
| 合适 | 目标碎片强，谱图可解释，定量稳定 |
| 太高 | 过度碎裂，目标碎片减少，低质量噪声增加 |
| 未按仪器优化 | 方法转移后 transition 表现可能改变 |

## 影响碰撞池表现的因素

| 因素 | 影响 |
| --- | --- |
| 碰撞气体种类和压力 | 影响碰撞频率和碎裂效率 |
| 碰撞能量 | 决定碎裂强弱 |
| 前体离子电荷态 | 不同电荷态碎裂行为不同 |
| 分子结构 | 肽段序列、修饰、小分子骨架都会影响碎片 |
| 仪器设计 | Q-TOF、三重四极杆、Orbitrap 平台碎裂条件不可简单照搬 |

## 常见问题

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| product ion 弱 | CE 太低或前体信号弱 | 优化 CE，提高样本/离子源状态 |
| 碎片谱噪声多 | CE 太高、共隔离或背景污染 | 降低 CE，改善 LC 和样本清洁 |
| MRM 方法不稳定 | 碰撞池参数或 transition 选择不佳 | 重筛 product ion 和 CE |
| 不同仪器结果不一致 | CE 标尺、气体和碰撞池设计不同 | 在目标平台重新优化 |

## 小结

碰撞池是 MS/MS 中“把前体离子变成碎片离子”的反应区。它不只是一个硬件位置，而是决定碎片谱质量、MRM transition 稳定性和结构证据强弱的重要环节。排查 MS/MS 问题时，碰撞能量和碰撞池条件永远值得检查。
