# 参考波长

Reference wavelength（参考波长）是在吸光度读数中用于估计和扣除非目标光学背景的辅助波长，常见于 [OD450](OD450.md) 等 ELISA 读数记录中。

![Absorbance OD450 pathlength](../../z_asset/番外/吸光度与OD450/absorbance-od450-pathlength.png)

图：吸光度、OD450 和光程的关系。ELISA 读数中，450 nm 是目标检测波长；参考波长是辅助校正，不等同于光程校正。本图由 Image2 / image-generation model 生成，用于个人学习笔记示意。

## 一句话理解

参考波长回答的是：“这块板的划痕、浑浊、指纹、气泡或板底背景，有多少可以从目标波长读数里扣掉？”

在 HRP-TMB endpoint [ELISA](<../../用(实验流程内容篇)/ELISA.md>) 中，目标读数常是 450 nm，因为酸性终止后的 TMB 黄色产物适合在 450 nm 附近读取。部分 protocol 会同时读取 570 nm、590 nm 或 620 nm 作为参考波长，再报告 OD450-reference。BioLegend 的 sandwich ELISA protocol 使用 stop solution 后读 450 nm；不同 kit 是否要求参考波长要看说明书。参考：[BioLegend sandwich ELISA protocol](https://www.biolegend.com/en-us/protocols/sandwich-elisa-protocol)。

## 为什么需要参考波长

参考波长主要用于降低非目标光学干扰。理想情况下，目标产物在参考波长处吸收较少，而板底、气泡、液面差异、指纹和浑浊等背景可能在两个波长上都有影响。

常见计算方式：

```text
OD450 corrected = OD450 - OD570
OD450 corrected = OD450 - OD620
```

具体使用哪个参考波长，要按试剂盒说明书、仪器滤光片和实验室 SOP 决定。

## 参考波长能校正什么

| 干扰 | 参考波长是否有帮助 | 说明 |
| --- | --- | --- |
| 板底划痕 | 有时有帮助 | 两个波长都受影响时可部分扣除 |
| 指纹/灰尘 | 有时有帮助 | 最好还是保持板底清洁 |
| 气泡 | 有时有限 | 大气泡会造成复杂光路问题 |
| 液体浑浊 | 有时有帮助 | 散射可能不完全等比例 |
| 显色过强 | 不能真正解决 | 应缩短显色或稀释样本 |
| 光程差异 | 不是主要用途 | 应考虑 [光程校正](光程校正.md) 或固定体积 |

参考波长不是万能清洁工。它能减少一部分光学背景，但不能替代规范加样、去气泡、洗板和板底清洁。

## 和空白扣除的区别

| 项目 | 参考波长 | Blank subtraction（空白扣除） |
| --- | --- | --- |
| 处理对象 | 同一孔的非目标光学背景 | 空白孔/零标准的体系背景 |
| 数据来源 | 同一孔不同波长 | 不同孔或同板空白 |
| 主要用途 | 扣板底、浑浊、气泡等光学背景 | 扣底物、缓冲液、非特异背景 |
| 是否可同时用 | 可以 | 可以 |

常见流程可能是先做 OD450-reference，再减去 blank；也可能由软件自动处理。正式记录要写清楚。

## 和光程校正的区别

参考波长校正和 [光程校正](光程校正.md) 不是一回事。

| 项目 | 参考波长校正 | 光程校正 |
| --- | --- | --- |
| 英文 | Reference wavelength correction | Pathlength correction |
| 核心变量 | 波长 | 光穿过样本的距离 |
| 常见表达 | OD450-570 | 1 cm pathlength equivalent |
| 主要场景 | ELISA endpoint 读数 | 微孔板直接吸收、核酸/蛋白、酶活 |
| 能否互相替代 | 不能 | 不能 |

如果实验记录写 “OD450-570”，这说明使用了参考波长扣除；不说明做了光程校正。

## 使用注意

- 先看试剂盒说明书是否推荐参考波长。
- 记录检测波长和参考波长。
- 保持同一项目中参考波长策略一致。
- 不要混用 OD450 和 OD450-570 做同一组统计。
- 如果参考波长读数异常高，要检查气泡、浑浊和板底污染。
- 输出图表和方法部分要写清读数格式。

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| OD450 和 OD450-570 差异很大 | 板底背景、浑浊或气泡明显 | 检查板底和孔内状态 |
| 参考波长扣除后出现负值 | 背景高、目标信号低或空白处理不当 | 检查空白、低端样本和读数流程 |
| 不同批数据不可比 | 有的用了参考波长，有的没用 | 固定 SOP 并记录读数格式 |
| 仍然复孔差异大 | 气泡或移液误差不能完全扣除 | 读板前检查气泡，重做异常孔 |
| 高 OD 饱和 | 显色过强 | 参考波长不能解决饱和，应稀释或缩短显色 |

## 小结

参考波长是 ELISA 吸光度读数里的辅助背景校正工具。它能帮助减少一部分光学背景，但不能替代正确的波长选择、统一读数格式、良好移液、去气泡和合理标准曲线。
