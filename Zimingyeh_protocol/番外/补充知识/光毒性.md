# 光毒性

## 一句话定义

Phototoxicity（光毒性）是指光照、荧光染料或光敏反应对活细胞、组织或生物过程造成的损伤或干扰，是活细胞荧光成像中必须控制的变量。

在活细胞 [荧光显微镜](<../../材(实验耗材工具篇)/荧光显微镜.md>) 成像中，激发光可能引发 reactive oxygen species（ROS，活性氧）生成、细胞应激、增殖改变、形态改变甚至死亡。Leica、Thermo Fisher 和显微成像资料都强调降低光剂量、优化染料和控制成像条件可减少光毒性。[参考：Leica Live Cell Imaging](https://www.leica-microsystems.com/science-lab/life-science/live-cell-imaging/)；[参考：Thermo Fisher Fluorescence Microscopy](https://www.thermofisher.com/us/en/home/life-science/cell-analysis/cell-imaging/fluorescence-microscopy.html)

## 光毒性来自哪里

| 来源 | 说明 |
| --- | --- |
| 高强度激发光 | 尤其是 UV、405 nm 和短波长光 |
| 长时间曝光 | 累积光剂量增加 |
| 荧光染料/探针 | 某些染料在激发后产生 ROS |
| 培养基成分 | 某些成分在光照下产生光化学副产物 |
| 温度/CO2不稳定 | 与光照压力叠加，影响细胞状态 |

光毒性不一定表现为立刻死亡。更隐蔽的问题是细胞迁移、分裂、信号通路或形态被成像过程改变。

## 与光漂白的关系

| 维度 | 光毒性 | [光漂白](光漂白.md) |
| --- | --- | --- |
| 主要影响 | 细胞状态和生物过程 | 荧光信号 |
| 发生样本 | 活细胞/活组织最关键 | 固定样本和活样本都会 |
| 共同诱因 | 光强、曝光、染料 | 光强、曝光、染料 |
| 结果 | 数据可能不再代表真实生理状态 | 信号变暗、定量失真 |

活细胞成像的目标不是“拍到最亮”，而是在尽量低扰动下获得足够信息。

## 降低光毒性的策略

| 策略 | 说明 |
| --- | --- |
| 降低光强 | 尽量用最低可用激发光 |
| 缩短曝光 | 用灵敏相机、合适染料弥补 |
| 降低成像频率 | 不需要每秒拍就不要高频拍 |
| 使用长波长染料 | 远红光通常比短波长更温和 |
| 优化培养环境 | 控制温度、CO2、湿度和培养基 |
| 减少预览 | 找视野也会给细胞光剂量 |
| 设置未照射对照 | 判断成像本身是否改变细胞 |

## 常见高风险场景

| 场景 | 风险点 |
| --- | --- |
| 长时间延时成像 | 累积光剂量高 |
| 405 nm/DAPI 活细胞成像 | 短波长光毒性高 |
| ROS/线粒体探针 | 探针本身可能影响状态 |
| 共聚焦反复扫描 | 局部激光剂量高 |
| TIRF 单分子高功率激发 | 近膜区域局部光压力大 |

## 判断是否有光毒性

| 观察 | 可能提示 |
| --- | --- |
| 细胞停止迁移或分裂 | 成像条件过强 |
| 细胞圆缩、 blebbing | 细胞应激或死亡 |
| 荧光强度改变伴随形态异常 | 光照或染料影响 |
| 未拍摄区域细胞正常，拍摄区域异常 | 光毒性可能性高 |
| 加密采集组和低频采集组结果不同 | 成像本身在干扰过程 |

## 注意事项

- 活细胞实验应记录完整成像光剂量相关参数。
- 不要用固定细胞优化出的强光条件直接套活细胞。
- 弱信号不一定要靠强光解决，可能需要更亮探针或更灵敏相机。
- HEPES、核黄素等培养基成分在某些光照条件下可能影响 ROS 背景。
- 光毒性评估应和生物学终点一起设计，而不是最后补救。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 活细胞成像后大量死亡 | 光强高、曝光长、温控差 | 降低光剂量，优化环境控制 |
| 细胞迁移变慢 | 成像频率太高或光毒性 | 降低采集频率，设置未照射对照 |
| 信号强但细胞异常 | 探针或光照干扰 | 降低染料浓度，换更温和染料 |
| 只有拍摄区域异常 | 局部光毒性 | 减少预览和重复扫描 |
| 实验重复性差 | 每次光剂量不同 | 固定曝光、光强、频率和时间 |

## 小结

光毒性是活细胞成像中最容易被低估的变量。图像越亮、帧率越高，不一定数据越好。真正可靠的活细胞荧光实验应在最低可用光剂量下成像，并用对照证明成像过程没有明显改变细胞行为。
