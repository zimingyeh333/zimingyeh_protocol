# 内标法

Internal standard method（内标法）是定量分析中常用的校正方法：向每个样本、标准品和质控样本中加入固定量 internal standard（内标），再用目标物信号与内标信号的比值建立 [标准曲线](标准曲线.md) 或计算浓度。

## 为什么要用内标

LC-MS、HPLC 和 GC-MS 等仪器分析中，样本前处理、进样体积、离子源状态和色谱波动都会改变峰面积。内标法的逻辑是：如果目标物和内标经历相似的误差，那么目标物/内标比值会比目标物单独峰面积更稳定。

最基本的计算思想是：

```text
Response ratio = analyte peak area / internal standard peak area
```

然后用 response ratio 对浓度作图，而不是只用目标物峰面积作图。

## 内标类型

| 类型 | 例子 | 优点 | 限制 |
| --- | --- | --- | --- |
| 同位素标记内标 | D、13C、15N 标记目标物 | 最接近目标物，是 LC-MS 理想内标 | 成本高，不一定买得到 |
| 结构类似物 | 同类药物、类似代谢物 | 容易获得 | 保留时间和基质效应可能不一致 |
| 同系物 | 碳链长度相近的小分子 | 适合部分化学分析 | 不能完全模拟目标物 |
| 标记肽段 | 重标肽段 | 适合靶向蛋白质组学 | 加入时机影响能校正的步骤 |
| 外源蛋白或过程内标 | 蛋白质组前处理内标 | 可监控流程 | 不一定能精确校正单个目标物 |

[同位素稀释](同位素稀释.md) 可以理解为内标法中最严格的一类：内标本身就是同位素标记的目标物或高度匹配物。

## 能校正什么

| 误差来源 | 内标能否校正 | 条件 |
| --- | --- | --- |
| 进样体积波动 | 通常可以 | 内标和目标物同次进样 |
| 离子源短期波动 | 通常可以 | 两者保留时间接近 |
| 样本前处理损失 | 取决于加入时间 | 内标必须在损失发生前加入 |
| [LC-MS基质效应](LC-MS基质效应.md) | 部分可以 | 内标与目标物共流出、离子化相似 |
| 标准品配错 | 不能 | 校准体系本身错误无法被内标修复 |
| 目标物降解 | 取决于加入时间 | 内标加入前的降解无法校正 |

## 和外标法、标准加入法的区别

| 方法 | 怎么定量 | 适合场景 | 风险 |
| --- | --- | --- | --- |
| [外标法](外标法.md) | 标准品峰面积直接建曲线 | 基质简单、流程稳定 | 难校正前处理和仪器波动 |
| 内标法 | 目标物/内标比值建曲线 | LC-MS 靶向定量常用 | 内标不匹配时会产生假安全感 |
| [标准加入法](标准加入法.md) | 真实样本中加入不同量标准品 | 空白基质难获得 | 操作量大，通量低 |
| 同位素稀释 | 同位素内标 + 比值定量 | 高准确度绝对定量 | 内标成本和可获得性限制 |

## 实际设置要点

| 步骤 | 要点 |
| --- | --- |
| 选择内标 | 保留时间、离子化行为、提取行为尽量接近目标物 |
| 设定浓度 | 内标峰面积应稳定，最好接近样本目标物响应区间 |
| 加入时机 | 尽量在能覆盖主要误差的最早步骤加入 |
| 标准曲线 | 所有标准品、QC 和未知样本加入相同量内标 |
| 质控 | 设置低、中、高 QC，观察 accuracy 和 precision |
| 数据检查 | 同时看目标物峰、内标峰和比值，不只看最终浓度 |

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整 |
| --- | --- | --- |
| 内标峰面积波动很大 | 进样不稳定、内标降解或基质干扰 | 检查进样系统、内标溶液和保留时间 |
| 目标物正常但比值异常 | 内标受局部基质效应影响 | 换更匹配内标或优化色谱分离 |
| 曲线线性差 | 内标浓度不合适、响应饱和或配标错误 | 重新配制标准品并检查线性范围 |
| 空白中有目标峰 | carryover 或污染 | 加强洗针、检查溶剂和耗材 |
| QC 总是偏低 | 前处理回收差或基质抑制 | 优化提取，考虑同位素内标或基质匹配 |

## 小结

内标法的价值在于把“只看目标物峰面积”改成“看目标物相对内标的变化”。它能显著提高定量稳定性，但前提是内标足够匹配、加入时机合理，并且方法验证证明它确实能校正主要误差。
