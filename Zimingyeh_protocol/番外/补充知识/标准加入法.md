# 标准加入法

Standard addition method（标准加入法）是把已知量标准品直接加入真实样本中，通过样本本身背景下的响应变化外推原始浓度的定量方法。它特别适合 matrix effect（基质效应）明显、但又找不到合适空白基质的分析场景。

图源：Image2 生成的 LC-MS 定量策略示意图。标准加入法不是图中的主流程，但它和内标法、同位素稀释一样，都是为了解决真实样本基质和校准体系不一致的问题。

## 核心逻辑

标准加入法不是把标准品放在干净溶剂里建曲线，而是在同一个真实样本里加入不同量的标准品：

```text
原始样本
原始样本 + 低量标准品
原始样本 + 中量标准品
原始样本 + 高量标准品
-> 测信号
-> 外推回 x 轴截距
-> 得到原始样本浓度
```

因为所有点都处在同一个样本基质中，所以它能部分抵消基质对检测信号的影响。

## 什么时候值得用

| 场景 | 为什么适合 |
| --- | --- |
| 空白基质难获得 | 例如复杂组织、胆汁、特殊培养基、环境样本 |
| [LC-MS基质效应](LC-MS基质效应.md) 明显 | 标准品在溶剂中和样本中响应不同 |
| 样本数量少但准确性要求高 | 可以牺牲通量换准确性 |
| 方法开发阶段 | 用于判断外标法是否受基质干扰 |
| 特殊样本验证 | 用于确认某类样本是否可直接套用标准曲线 |

## 和外标法、内标法的区别

| 方法 | 校准环境 | 优势 | 限制 |
| --- | --- | --- | --- |
| [外标法](外标法.md) | 标准品单独配制 | 简单、通量高 | 基质效应校正弱 |
| [内标法](内标法.md) | 样本和标准品都加内标 | 校正进样和部分损失 | 内标必须足够匹配 |
| 标准加入法 | 标准品加入真实样本 | 能处理复杂基质 | 操作量大，消耗样本多 |
| [同位素稀释](同位素稀释.md) | 同位素内标跟随目标物 | LC-MS 中准确性高 | 成本高，内标不一定可得 |

## 操作注意事项

| 要点 | 原因 |
| --- | --- |
| 加标点要覆盖合理范围 | 太低看不出斜率，太高可能超出线性范围 |
| 每个加标点基质比例一致 | 稀释比例不同会重新引入基质差异 |
| 保证响应线性 | 非线性时 x 轴外推不可靠 |
| 加标标准品要准确 | 标准品浓度错误会直接扭曲结果 |
| 样本量要足够 | 每个样本都要多个加标点和复孔 |

## 结果怎么理解

标准加入法常用线性外推理解：

```text
y = k(x + Csample)
```

其中 x 是加入的标准品浓度，Csample 是原始样本中的目标物浓度。把直线外推到 y = 0 时，x 轴负截距的绝对值就是样本原始浓度。

这也是它的局限：如果检测响应不是线性的，或者加标改变了样本基质，外推就会变得不可靠。

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 加标曲线不线性 | 超出线性范围、基质改变、仪器饱和 | 缩小加标范围或稀释样本 |
| 外推浓度为负值 | 背景扣除错误或信号太低 | 检查空白、LOD 和标准品 |
| 复孔差异大 | 加标体积小、混匀不足 | 增大加标体积或改进混匀 |
| 和外标结果差很多 | 明显基质效应 | 优先相信经验证的标准加入或内标结果 |
| 样本消耗过大 | 方法本身通量低 | 只用于关键样本或方法确认 |

## 小结

标准加入法的价值在于把校准曲线“搬进真实样本里”。它不适合高通量常规检测，但在空白基质不可得、基质效应明显或方法开发阶段非常有用，能帮助判断外标法给出的浓度是否可信。
