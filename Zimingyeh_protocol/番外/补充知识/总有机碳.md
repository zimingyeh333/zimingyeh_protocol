# 总有机碳

Total organic carbon（TOC，总有机碳）是水或样品中有机物所含碳元素总量的综合指标。它不是某一种具体污染物，而是用一个总量信号提示 organic contamination（有机污染）水平，常用于 [超纯水](<../../材(实验耗材工具篇)/超纯水.md>) 系统、制药用水、色谱/质谱用水和 [清洁验证](<../../用(实验流程内容篇)/清洁验证.md>)。

## 核心定义

TOC 关注的是 organic carbon（有机碳），通常以 ppb C、μg/L C、ppm C 或 mg/L C 表示。实验室水系统里常见的是 ppb 级 TOC；普通环境水、清洗液或复杂样品则可能是 ppm 级。

TOC 的关键点是“总量”。它能告诉你样品里有机物背景是否升高，但不能直接告诉你具体是哪一种有机物。比如塑化剂、清洗剂残留、培养基成分、微生物代谢物、管路析出物和溶剂残留都可能推高 TOC。

ASTM D1193 将 reagent water（试剂水）的分类与电导率、电阻率、TOC、钠、氯、硅、微生物等指标关联起来；这说明 TOC 是水质判断的一条独立轴，而不是 [电导率](电导率.md) 的替代指标。参考：[ASTM D1193](https://www.astm.org/d1193-06r18.html)。

## 为什么 TOC 重要

### 超纯水可以低离子但有有机污染

18.2 MΩ·cm 的超纯水说明离子背景很低，但不代表有机污染一定低。有机污染物如果不带电，可能对电导率影响很小，却仍然影响细胞、色谱、质谱或痕量检测。

### 色谱和质谱背景

[高效液相色谱](<../../用(实验流程内容篇)/高效液相色谱.md>) 和 [液相色谱-质谱联用](<../../用(实验流程内容篇)/液相色谱-质谱联用.md>) 对有机背景非常敏感。TOC 偏高可能带来基线漂移、鬼峰、离子抑制、空白污染或定量下限变差。

### 细胞和免疫实验

TOC 本身不是“细胞毒性指标”，但升高可能提示水系统、容器或试剂中存在有机污染。对于长期培养、原代细胞、类器官和免疫刺激实验，TOC 异常应该和 [内毒素](内毒素.md)、无菌、渗透压、pH 一起排查。

### 清洁验证和残留控制

在制药、洁净生产和部分平台型实验室中，TOC 常用于评估清洗后是否仍有有机残留。它适合做总量筛查，但如果要确认特定残留物，仍需要特异性方法。

## TOC 测量原理

常见 TOC 测量思路是先去除或校正 inorganic carbon（IC，无机碳），再把有机碳氧化成 CO2，最后检测生成的 CO2 或由 CO2 引起的电导变化。

| 步骤 | 目的 | 常见方式 |
| --- | --- | --- |
| 去除/区分无机碳 | 避免碳酸盐、CO2 干扰有机碳读数 | 酸化吹扫、差减法、仪器算法 |
| 氧化有机物 | 把有机碳转化为 CO2 | UV oxidation、persulfate oxidation、高温燃烧 |
| 检测 CO2 | 得到 TOC 信号 | NDIR、conductivity detection 等 |

[TOC分析仪](<../../材(实验耗材工具篇)/TOC分析仪.md>) 的具体原理、量程、样品兼容性和维护要求差异很大。超纯水在线 TOC 监测和复杂样品离线 TOC 测定不是同一个难度。

## TOC vs 其他水质指标

| 指标 | 主要反映 | 不能替代什么 |
| --- | --- | --- |
| TOC | 有机污染总量 | 不能说明具体污染物身份 |
| 电导率 / 电阻率 | 离子污染水平 | 不能充分反映非离子有机物 |
| [内毒素](内毒素.md) | 革兰阴性菌相关热原污染 | 不能用 TOC 推断 |
| bioburden（生物负载） | 可培养微生物数量 | 不能说明有机物残留类型 |
| particles（颗粒） | 不溶性颗粒污染 | 不能说明溶解有机物 |
| RNase/DNase | 核酸酶污染 | 不能由 TOC 直接判断 |

一个水样可能电阻率很好、TOC 也很好，但不是无菌；也可能无菌，却 TOC 偏高。因此实验用水不能只看一个数字。

## 常见污染来源

| 来源 | 可能表现 |
| --- | --- |
| 水系统滤芯或树脂老化 | TOC 缓慢升高，电阻率可能同时变化 |
| 管路和储水箱生物膜 | TOC、微生物和颗粒可能一起异常 |
| 塑料容器析出物 | 新瓶、劣质瓶或长时间储存后背景升高 |
| 清洗剂残留 | TOC 明显升高，可能伴随泡沫或色谱背景 |
| 空气和操作污染 | 开盖暴露、移液污染、瓶口接触 |
| 有机溶剂残留 | LC-MS 或 HPLC 空白异常 |

## 结果解释

### TOC 低

说明有机污染背景低，但不能证明样品无菌、无核酸酶或无内毒素。对于 RNA 和细胞实验，仍要看对应应用等级。

### TOC 升高

提示有机污染增加。需要结合取样点、容器、系统维护记录、使用时间和其他水质指标判断。不要立刻把所有实验异常都归因于 TOC；它是线索，不是完整答案。

### TOC 波动

波动可能来自水系统刚维护、管路冲洗不足、取样容器不一致、环境暴露、仪器校准或样品本身不均一。长期项目更适合看趋势，而不是只看一次读数。

## 实验选择建议

| 场景 | TOC 关注程度 | 建议 |
| --- | --- | --- |
| 普通清洗 | 低到中 | DI water 或普通纯水通常足够 |
| 常规 buffer 配制 | 中 | 使用新鲜超纯水或合适等级水 |
| 细胞培养 | 中到高 | 同时看无菌、内毒素和细胞培养级 |
| HPLC/LC-MS | 高 | 使用 HPLC/LC-MS 级水和洁净容器 |
| 制药/平台清洁验证 | 高 | 按 SOP 和标准方法做 TOC 测定 |
| 痕量分析 | 高 | 关注容器、管路、空白和批次 |

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 超纯水电阻率正常但 LC-MS 空白高 | 非离子有机污染、瓶子或管路析出物 | 换 LC-MS 级水和瓶子，检查 TOC |
| TOC 突然升高 | 刚换耗材、系统维护、取样容器污染 | 重新冲洗系统，换新容器复测 |
| 细胞状态差但 TOC 正常 | 内毒素、无菌、渗透压、培养基批次等其他因素 | 不要只盯 TOC，做多指标排查 |
| TOC 读数不稳定 | 仪器未稳定、样品有气泡、取样不一致 | 按仪器 SOP 重新测定 |
| 清洁验证不过 | 清洗剂、产品残留或取样覆盖不足 | 检查清洗流程和取样位置 |

## 总结

TOC 是判断有机污染背景的总量指标。它特别适合水系统、色谱/质谱背景和清洁验证，但不能告诉你污染物身份，也不能替代无菌、无核酸酶、内毒素或电导率检测。看到 TOC，要把它理解为“有机污染维度的一盏灯”，而不是水质的全部答案。
