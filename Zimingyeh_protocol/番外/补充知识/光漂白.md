# 光漂白

## 一句话定义

Photobleaching（光漂白）是指 [荧光染料](<../../材(实验耗材工具篇)/荧光染料.md>) 或荧光蛋白在光照激发过程中发生不可逆化学损伤，导致荧光信号逐渐减弱或消失的现象。

光漂白是 [免疫荧光](<../../用(实验流程内容篇)/免疫荧光.md>)、活细胞成像、共聚焦和 TIRF 成像中常见问题。Thermo Fisher、Leica 和显微成像资料都强调降低激发光强、缩短曝光、使用 [抗淬灭封片剂](<../../材(实验耗材工具篇)/抗淬灭封片剂.md>) 和选择更光稳定染料可减少光漂白。[参考：Thermo Fisher Fluorescence Microscopy](https://www.thermofisher.com/us/en/home/life-science/cell-analysis/cell-imaging/fluorescence-microscopy.html)；[参考：Leica Fluorescence Microscopy](https://www.leica-microsystems.com/science-lab/life-science/fluorescence-microscopy/)

## 为什么发生

荧光团被激发后会进入高能状态。反复激发、氧气、自由基或局部化学环境可能导致荧光团结构被破坏：

```text
反复激发
→ 荧光团进入激发态
→ 发生光化学反应
→ 荧光能力下降
→ 信号变暗
```

光漂白是不可逆的。已经漂白的信号不能靠后期调亮恢复真实信息。

## 影响因素

| 因素 | 影响 |
| --- | --- |
| 激发光强 | 光越强，漂白越快 |
| 曝光时间 | 时间越长，累计光剂量越高 |
| 染料种类 | 光稳定性差异很大 |
| 氧气和自由基 | 可加速漂白 |
| 封片剂 | 抗淬灭封片剂可减缓漂白 |
| 扫描次数 | 共聚焦多次扫描增加光剂量 |

## 与光毒性的区别

| 维度 | 光漂白 | [光毒性](光毒性.md) |
| --- | --- | --- |
| 影响对象 | 荧光染料/荧光蛋白信号 | 活细胞和生物过程 |
| 表现 | 信号变暗 | 细胞状态改变、死亡或应激 |
| 是否只发生在活细胞 | 否，固定样本也会 | 主要关注活细胞 |
| 共同原因 | 高光强、长曝光、反复扫描 | 高光强、长曝光、光敏反应 |

固定样本主要担心光漂白；活细胞同时担心光漂白和光毒性。

## 降低策略

| 策略 | 说明 |
| --- | --- |
| 降低光强 | 用更低激发光找视野和采集 |
| 缩短曝光 | 用更灵敏相机或更亮染料补偿 |
| 减少重复扫描 | 避免反复找同一视野 |
| 使用抗淬灭封片剂 | 固定样本中非常有帮助 |
| 选择光稳定染料 | 如某些 Alexa Fluor 染料更稳定 |
| 先拍弱/易漂白通道 | 防止被其他通道预照射漂白 |

## 注意事项

- 自动对焦和预览也会消耗光剂量。
- 共聚焦 averaging 能降噪，但会增加光照次数。
- 图像变暗不一定是表达下降，可能只是漂白。
- 定量实验中，不同样本接受不同光剂量会造成假差异。
- 长时间成像要记录光强、曝光、帧率和总时长。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 信号越拍越暗 | 光漂白 | 降低光强，缩短曝光，使用抗淬灭 |
| 最后一组样本更暗 | 前面找图时间太长 | 固定成像流程，减少预览 |
| Z-stack 上层亮下层暗 | 上层被反复照射 | 优化扫描顺序和光强 |
| 弱信号消失 | 染料不稳定或光照过强 | 换更稳定染料，降低光剂量 |
| 重复实验强度不可比 | 曝光/光强/扫描次数不同 | 固定参数并记录元数据 |

## 小结

光漂白是荧光信号被光照逐渐破坏的过程。它会直接影响定量和图像解释。降低光强、缩短曝光、减少预览、使用抗淬灭封片剂和选择稳定染料，是控制光漂白的基本策略。
