# 反卷积

## 一句话定义

Deconvolution（反卷积）是一类显微图像计算处理方法，尝试利用显微系统的 [点扩散函数](点扩散函数.md)（Point spread function, PSF）把模糊扩散的光信号重新分配回更接近真实结构的位置，从而提高图像对比度和分辨感。

在 [宽场荧光显微镜](<../../材(实验耗材工具篇)/宽场荧光显微镜.md>)、共聚焦和三维荧光成像中，样本中一个理想点并不会在图像中显示成完美点，而会被光学系统扩散成一个三维斑点。反卷积就是基于这种扩散规律进行计算恢复。Nikon MicroscopyU、Leica 和 ZEISS 的显微资料都将 deconvolution 作为荧光显微图像改善和三维成像分析的重要工具。[参考：Nikon MicroscopyU Deconvolution](https://www.microscopyu.com/techniques/deconvolution)；[参考：Leica Deconvolution](https://www.leica-microsystems.com/science-lab/life-science/deconvolution/)；[参考：ZEISS Deconvolution](https://www.zeiss.com/microscopy/en/resources/insights-hub/life-sciences/deconvolution-microscopy.html)

## 为什么需要反卷积

显微镜成像可以简化成：

```text
真实结构
→ 被显微镜点扩散函数模糊
→ 加上噪声
→ 得到图像
```

反卷积尝试做相反方向：

```text
图像 + PSF + 算法
→ 估计更接近真实结构的图像
```

它不是“AI 修图”，也不是凭空创造信息。反卷积依赖成像系统、采样质量、噪声模型和算法假设。

## 核心概念

| 概念 | 英文 | 说明 |
| --- | --- | --- |
| 点扩散函数 | Point spread function, PSF | 一个点在显微镜中变成什么形状 |
| 卷积 | Convolution | 真实结构被光学系统模糊 |
| 反卷积 | Deconvolution | 尝试从模糊图像恢复结构 |
| 迭代算法 | Iterative algorithm | 多轮计算逼近结果 |
| Richardson-Lucy | Richardson-Lucy algorithm | 常见迭代反卷积算法 |
| 尼奎斯特采样 | Nyquist sampling | 采样间隔必须足够小才能保留信息 |

反卷积质量的天花板由原始数据决定。曝光饱和、采样不足、信噪比太低的图像，反卷积也不能可靠拯救。

## 适合用途

| 场景 | 价值 |
| --- | --- |
| 宽场 Z-stack | 去除焦外模糊，改善三维结构 |
| 共聚焦图像 | 提高对比度和边界清晰度 |
| 弱结构观察 | 在合适信噪比下改善可见性 |
| 三维重构 | 改善 Z 方向分辨感 |
| 定量前预处理 | 需谨慎，必须保持参数一致 |

## 不适合或需要谨慎的情况

| 情况 | 风险 |
| --- | --- |
| 图像饱和 | 反卷积会产生伪影 |
| 信噪比太低 | 噪声可能被放大 |
| Z-step 太大 | 采样不足，不能恢复丢失信息 |
| PSF 不匹配 | 恢复结果不可信 |
| 只展示处理图 | 读者无法判断原始数据质量 |

## 反卷积 vs 共聚焦

| 维度 | 反卷积宽场 | 共聚焦 |
| --- | --- | --- |
| 本质 | 计算处理 | 光学切片采集 |
| 对原始数据要求 | 高，需良好采样和信噪比 | 采集时抑制焦外光 |
| 光毒性 | 宽场可低光剂量 | 激光扫描可能更高 |
| 厚样本 | 有帮助但受限 | 通常更稳 |
| 伪影风险 | 算法参数不当会有 | 也有但类型不同 |

反卷积和共聚焦不是互斥关系。共聚焦图像也可以做反卷积，但必须谨慎记录处理参数。

## 使用 protocol

1. 采集未饱和原始图像。
2. 按 [尼奎斯特采样](尼奎斯特采样.md) 原则设置 XY 像素和 Z-step。
3. 记录物镜 NA、折射率、波长、像素大小、Z-step 和显微镜类型。
4. 使用实测 PSF 或软件理论 PSF。
5. 选择算法，例如 constrained iterative deconvolution 或 [Richardson-Lucy算法](Richardson-Lucy算法.md)。
6. 统一所有样本的参数。
7. 同时保存原始图、处理图和处理参数。

## 注意事项

- 反卷积前图像不能饱和。
- 算法参数不同会改变结果，不能只保存最终图。
- 定量分析要验证反卷积是否改变强度关系。
- 处理后图像更清楚不等于更真实。
- 发表或共享时应说明反卷积软件、算法、迭代次数和 PSF 来源。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 出现环状伪影 | PSF 不匹配或迭代过度 | 调整 PSF 和迭代次数 |
| 噪声被增强 | 信噪比太低 | 提高采集质量或正则化 |
| 结构变得不自然 | 处理参数过强 | 与原始图对照 |
| 不同组差异被放大 | 参数不一致或原始图质量不同 | 固定参数，检查原始数据 |
| 结果不可复现 | 未记录软件/参数 | 保存处理 workflow |

## 小结

反卷积是显微图像恢复的重要工具，尤其适合良好采样的宽场和三维荧光图像。它能改善模糊和对比度，但不能修复饱和、采样不足或信噪比太差的原始数据。使用反卷积时必须保存原始图和处理参数。
