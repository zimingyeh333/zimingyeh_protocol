# 诱导多能干细胞

诱导多能干细胞（induced pluripotent stem cell，iPSC）是由 somatic cells（体细胞）经 cellular reprogramming（细胞重编程）获得的多能干细胞，属于 [人多能干细胞](人多能干细胞.md)（human pluripotent stem cells，hPSC）的一类。人源 iPSC 通常写作 hiPSC（human induced pluripotent stem cell，人诱导多能干细胞）。

## 核心定位

iPSC 的核心价值是：它让实验者可以从患者、健康供体或特定基因型个体的体细胞出发，建立具有多能性的细胞系，再分化为神经元、心肌细胞、肝细胞、免疫细胞、类器官等模型。和 [人胚胎干细胞](人胚胎干细胞.md) 相比，iPSC 更适合 disease modeling（疾病建模）、patient-specific model（患者特异模型）、drug screening（药物筛选）和遗传背景比较。

NIH Stem Cell Basics 将 iPSC 描述为由成熟细胞经 reprogramming 获得的 embryonic stem cell-like state（胚胎干细胞样状态）。参考：[NIH Stem Cell Basics](https://stemcells.nih.gov/info/basics/stc-basics)。

## 发明与历史背景

2006 年，Takahashi 和 Yamanaka 报道小鼠成纤维细胞可通过定义因子诱导为多能干细胞，这些因子后来常被称为 Yamanaka factors（山中因子），经典组合包括 OCT4、SOX2、KLF4 和 c-MYC。参考：[Takahashi and Yamanaka, 2006, Cell, DOI: 10.1016/j.cell.2006.07.024](https://pubmed.ncbi.nlm.nih.gov/16904174/)。

2007 年，Takahashi 等报道成人成纤维细胞可被重编程为人 iPSC。PubMed 摘要指出，human iPS cells 在形态、增殖、表面抗原、基因表达、表观遗传状态和端粒酶活性等方面与 human embryonic stem cells 相似。参考：[Takahashi et al., 2007, Cell, DOI: 10.1016/j.cell.2007.11.019](https://pubmed.ncbi.nlm.nih.gov/18035408/)。

## 常见来源与重编程方式

| 来源细胞 | 优点 | 注意事项 |
| --- | --- | --- |
| 皮肤成纤维细胞 | 经典来源，文献多 | 取样侵入性较高，扩增耗时 |
| 外周血细胞 | 取样方便，临床队列常用 | 亚群组成和起始状态会影响效率 |
| 尿液来源细胞 | 非侵入性 | 建系成功率和污染控制要关注 |
| 商业或细胞库 iPSC line | 标准化程度较高 | 仍需复核来源、传代数和 QC |

| 重编程方式 | 特点 | 风险点 |
| --- | --- | --- |
| 整合型病毒载体 | 效率高，历史上常用 | 可能残留外源序列或插入突变风险 |
| Sendai virus（仙台病毒） | 非整合，常用于 hiPSC 建系 | 需要确认病毒清除 |
| episomal plasmid（游离质粒） | 非整合，成本相对可控 | 效率可能较低，需要克隆筛选 |
| mRNA/蛋白方法 | 非整合，理论上更干净 | 操作复杂，成本和重复性要评估 |

## 与 hESC 的关键区别

| 项目 | iPSC | hESC |
| --- | --- | --- |
| 来源 | 体细胞重编程 | 早期囊胚内细胞团 |
| 个体遗传背景 | 可保留供体背景 | 通常是已有标准细胞系 |
| 疾病建模 | 很强，尤其适合患者来源模型 | 更常作为标准参考或开发模型 |
| 克隆差异 | 常见，需要多克隆比较 | 也存在 line-to-line 差异，但来源逻辑不同 |
| 主要风险 | 重编程记忆、克隆变异、遗传/表观遗传异常 | 伦理来源、长期培养漂移和 line 差异 |

做疾病模型时，iPSC 的优势也是风险来源：供体差异和克隆差异可能被误认为疾病效应。因此最好使用 isogenic control（同基因背景对照）、多个 clone（克隆）和多个 donor（供体）来支撑结论。

## 关键 QC 指标

| 指标 | 代表什么 | 注意事项 |
| --- | --- | --- |
| 克隆形态 | 未分化状态和培养质量 | 边缘分化、克隆松散、细胞间隙增大都要记录 |
| OCT4、SOX2、NANOG | pluripotency marker（多能性标志物） | marker 阳性不等于分化能力稳定 |
| SSEA-4、TRA-1-60、TRA-1-81 | 常见 hPSC 表面 marker | 不同 clone 之间要统一检测平台 |
| 三胚层分化潜能 | 功能性多能性证据 | 分化效率受 clone 和 passage 影响 |
| 重编程载体残留 | 建系安全性和解释可靠性 | Sendai 或 episomal 方法也要确认残留 |
| 核型/基因组完整性 | 长期培养和克隆筛选后的稳定性 | 建系后、长期培养后都应复核 |
| [支原体检测](<../../用(实验流程内容篇)/支原体检测.md>) | 排除隐性污染 | 对分化和转录组影响很大 |

## 常见用途

| 场景 | iPSC 的优势 | 风险点 |
| --- | --- | --- |
| 患者来源疾病模型 | 保留患者遗传背景 | 供体差异、clone 差异和成熟度不足 |
| 基因编辑模型 | 可构建 isogenic pair | 编辑脱靶、克隆筛选压力 |
| 药物筛选 | 可扩增并分化为特定细胞类型 | 分化批次差异会影响读数 |
| 类器官 | 可构建人源复杂组织模型 | 成熟度、批次一致性和形态评价困难 |
| 细胞治疗前研究 | 理论上来源可扩展 | 安全性、残留未分化细胞和法规要求高 |

## 常见错误与 troubleshooting

| 现象/误区 | 可能原因 | 处理思路 |
| --- | --- | --- |
| 一个 clone 代表整个疾病 | 克隆差异被当成疾病效应 | 使用多个 clone、多个 donor 和 isogenic control |
| 分化效率波动大 | 起始状态、传代数、基质或培养基批次不同 | 固定 passage window，分化前做形态和 marker QC |
| 重编程后状态不稳定 | 部分重编程、遗传异常或表观遗传记忆 | 建系后做多维 QC，不只看形态 |
| 复苏后死亡多 | hPSC 对单细胞和冻融应激敏感 | 优化密度、matrix、[ROCK抑制剂](<../../材(实验耗材工具篇)/ROCK抑制剂.md>) 和复苏流程 |
| 只记录“iPSC” | 缺少供体、clone 和重编程方法 | 写清 donor、clone ID、reprogramming method 和 passage |

## 小结

iPSC 的强项是“带着供体遗传背景进入多能状态”，因此非常适合疾病建模、药物筛选和基因编辑模型。但它不是天然稳定的万能细胞：clone 差异、重编程质量、遗传/表观遗传异常、起始状态和分化批次都必须严肃记录和控制。
