# 报告离子

Reporter ion（报告离子）是在同位素标签定量质谱中用于读出样本来源或相对丰度的小质量 [碎片离子](碎片离子.md)。在 [TMT](TMT.md) 或 iTRAQ 等 isobaric labeling（[同重异位标签](同重异位标签.md)）方法中，不同样本的肽段在 MS1 中看起来质量相同，但在 MS/MS 或 MS3 中释放出不同 m/z 的报告离子，用于比较样本间相对丰度。

图源：Image2 生成的 MS/MS 碎裂方式示意图。HCD 模块中标注了 reporter ion，表示高能碰撞碎裂常用于读取 TMT/iTRAQ 等标签的报告离子信号。

## 一句话理解

报告离子回答的是：“这个肽段信号来自哪个样本，比例是多少？”

同重异位标签的设计逻辑是：

```text
不同样本肽段分别加不同标签
-> 混合成一个样本上机
-> MS1 中这些肽段质量相同，像一个峰
-> MS/MS 碎裂后释放不同 m/z 的报告离子
-> 根据报告离子强度计算各样本相对丰度
```

Thompson 等在提出 tandem mass tags（TMT）时，就是利用这种标签在 MS/MS 中产生 reporter ions 的特性实现多重相对定量。参考：[Thompson et al., Analytical Chemistry, 2003](https://doi.org/10.1021/ac0262560)

## 报告离子在哪里出现

| 方法 | 报告离子作用 |
| --- | --- |
| TMT | 读取每个通道的相对丰度 |
| iTRAQ | 类似 TMT，用报告离子做多重相对定量 |
| TMTpro | 更多通道数，报告离子间质量差更小，对分辨率要求更高 |
| SPS-MS3 TMT | 通过 MS3 降低共隔离干扰对报告离子的影响 |

报告离子通常位于较低 m/z 区域，因此采集方法必须覆盖这些 m/z。若 MS2 扫描范围没有包含报告离子区域，TMT 定量就无法正常读取。

## 为什么 HCD 常用于报告离子

[HCD](HCD.md)（higher-energy collisional dissociation，高能碰撞解离）常用于 TMT/iTRAQ，因为它能有效产生低 m/z reporter ions，并且适合 Orbitrap 平台上的高分辨 MS/MS 检测。Olsen 等关于 HCD 的经典论文也展示了 higher-energy C-trap dissociation 对肽段修饰分析和碎片离子检测的价值。参考：[Olsen et al., Nature Methods, 2007](https://doi.org/10.1038/nmeth1060)

## 报告离子定量的关键风险

| 风险 | 解释 | 结果 |
| --- | --- | --- |
| 共隔离干扰 | isolation window 中混入其他肽段 | 报告离子比例被污染 |
| ratio compression（比例压缩） | 多个肽段共同碎裂导致差异被拉小 | 真正差异被低估 |
| reporter ion 信号弱 | 碰撞能量、样本量或采集范围不合适 | 定量不稳定 |
| 通道泄漏/同位素杂质 | 标签同位素纯度有限 | 需要软件校正 |
| 标记不完全 | 肽段未完全加标签 | 造成定量偏差 |

## 报告离子 vs 碎片离子

| 项目 | 报告离子 | 普通肽段碎片离子 |
| --- | --- | --- |
| 主要用途 | 样本间相对定量 | 肽段鉴定和序列解释 |
| 来源 | 同位素标签碎裂 | 肽段主链或侧链碎裂 |
| 典型方法 | TMT、iTRAQ | DDA、DIA、PRM、MRM |
| 关注点 | 通道强度和比例 | 离子系列、覆盖和匹配 |

同一张 MS/MS 谱图中可能同时有肽段碎片离子和报告离子。前者帮助回答“它是谁”，后者帮助回答“各样本有多少”。

## 常见错误

| 错误 | 后果 |
| --- | --- |
| 只看 TMT 通道结果，不看共隔离干扰 | 容易出现比例压缩 |
| MS2 范围不覆盖 reporter ion | 无法定量 |
| 忽略标签纯度校正 | 通道间串扰增加 |
| 用太宽 isolation window | 增加共碎裂风险 |
| 混样前蛋白/肽段定量不准 | 通道上样量不一致 |

## 小结

报告离子是 TMT/iTRAQ 这类同重异位标签定量的读数核心。它不是用来确定肽段序列的主证据，而是用来读出不同样本通道的相对丰度。理解报告离子，也就理解了为什么 TMT 强在多样本相对定量，同时又容易受到共隔离干扰和比例压缩影响。
