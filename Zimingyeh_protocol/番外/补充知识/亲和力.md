# 亲和力

Affinity（亲和力）是指单个抗体结合位点与单个 [表位](表位.md) 之间结合的强弱，反映抗体和抗原形成复合物的稳定程度；在抗体实验中，亲和力会影响灵敏度、洗涤后保留、低丰度目标检测和背景控制。

## 一句话理解

亲和力回答的是：“抗体抓住这个表位后，容易不容易松手？”

Janeway Immunobiology 对抗体-抗原结合的解释强调，这种结合主要依赖非共价相互作用，包括氢键、静电相互作用、疏水作用和范德华力。结合越稳定，通常亲和力越高。参考：[NCBI Bookshelf: Antigen recognition by B-cell and T-cell receptors](https://www.ncbi.nlm.nih.gov/books/NBK27160/)。

## Kd 怎么理解

[解离常数](解离常数.md)（dissociation constant，Kd）常用于描述亲和力。简单理解：

```text
Kd 越低 → 亲和力越高 → 抗体越不容易从抗原上解离
Kd 越高 → 亲和力越低 → 抗体越容易被洗掉
```

常见抗体资料可能不会给出 Kd，但会给出应用验证、推荐稀释、滴定曲线或 IC50/EC50 等间接信息。实验选择时，不能只看“high affinity”这种宣传词，最好看实际应用数据。

## 亲和力 vs 亲合力

Affinity（亲和力）和 avidity（亲合力/多价结合强度）容易混淆。

| 概念 | 英文 | 重点 |
| --- | --- | --- |
| 亲和力 | Affinity | 单个结合位点与单个表位的结合强度 |
| 亲合力 | Avidity | 多价抗体与多价抗原整体结合强度 |
| 解离常数 | Kd | 常用于量化单点亲和力 |
| 解离速率 | off-rate | 抗体从抗原上脱离的速度 |

IgM 因为多价结构，即使单个位点亲和力不一定很高，整体亲合力也可以很强。

## 在实验中的影响

| 实验场景 | 亲和力的影响 |
| --- | --- |
| [ELISA](<../../用(实验流程内容篇)/ELISA.md>) | 影响低浓度目标捕获、洗涤后保留和灵敏度 |
| Western blot | 影响条带强度和洗膜耐受性 |
| Flow cytometry | 影响表面抗原低表达细胞识别 |
| IHC/IF | 影响固定组织或细胞中目标识别 |
| 竞争实验 | 高亲和力抗体可能需要更强竞争物才能置换 |

高亲和力不总是绝对更好。亲和力太高的抗体有时会带来难以洗脱、背景较高或动态范围窄的问题；亲和力不足则容易信号弱和重复性差。

## 和特异性的区别

| 项目 | 亲和力 | [特异性](特异性.md) |
| --- | --- | --- |
| 关注点 | 结合强不强 | 是否只结合目标 |
| 问题 | 抓得稳不稳 | 会不会抓错对象 |
| 可同时高吗 | 可以 | 可以 |
| 可同时低吗 | 可以 | 可以 |
| 实验风险 | 信号弱或洗掉 | 交叉反应和假阳性 |

一个抗体可以对错误目标有高亲和力，这种情况会带来强烈假阳性。因此亲和力必须和特异性一起看。

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 低浓度样本信号弱 | 亲和力不足或 off-rate 高 | 延长孵育，降低洗涤强度，换高亲和力抗体 |
| 洗涤后信号丢失 | 抗体-抗原复合物不稳定 | 减少洗涤强度或优化抗体浓度 |
| 背景高 | 抗体浓度过高或非目标结合也强 | 做抗体滴定并验证特异性 |
| 标准曲线低端差 | 捕获或检测抗体亲和力不足 | 优化 [配对抗体](<../../材(实验耗材工具篇)/配对抗体.md>) |
| 竞争实验不灵敏 | 抗体亲和力过高或竞争物弱 | 调整抗体浓度和竞争物范围 |

## 小结

亲和力决定抗体抓住表位的稳定性，但不等于实验一定可靠。好抗体需要同时满足合适亲和力、足够特异性、低背景和目标应用验证。
