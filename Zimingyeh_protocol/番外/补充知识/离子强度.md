# 离子强度

Ionic strength（离子强度）描述溶液中 ions（离子）浓度和电荷共同造成的 electrostatic environment（静电环境）。它不是简单的“盐浓度”，也不等同于 [电导率](电导率.md) 或 [渗透压](渗透压.md)。在蛋白质、核酸、酶反应、抗体结合、细胞培养和电泳体系中，离子强度会显著影响分子间相互作用。

图源：Image2 生成的溶液酸碱与离子参数概念图。离子强度强调“浓度 × 电荷平方”的综合作用；Mg2+ 这类二价离子对离子强度的贡献明显大于同浓度的一价离子。

## 定义与公式

IUPAC Gold Book 将 ionic strength 定义为溶液中各离子 molality（质量摩尔浓度）与电荷平方乘积之和的一半。参考：[IUPAC Gold Book ionic strength](https://goldbook.iupac.org/terms/view/I03180)。

实际生物实验里常用 molarity（摩尔浓度，mol/L）近似计算：

```text
I = 1/2 Σ ci zi^2
```

其中：

| 符号 | 含义 |
| --- | --- |
| I | ionic strength（离子强度） |
| ci | 第 i 种离子的浓度 |
| zi | 第 i 种离子的电荷数 |

注意 z 是平方项，所以二价离子贡献不是一价离子的两倍，而是按 z² 放大。

## 直觉例子

| 溶液 | 主要离子 | 近似离子强度 |
| --- | --- | --- |
| 0.1 M [氯化钠](<../../材(实验耗材工具篇)/氯化钠.md>) | 0.1 M Na+ + 0.1 M Cl- | 0.1 M |
| 0.05 M [氯化镁](<../../材(实验耗材工具篇)/氯化镁.md>) | 0.05 M Mg2+ + 0.1 M Cl- | 0.15 M |
| 0.1 M 非离子溶质 | 不解离 | 约 0 M |

这说明“总浓度一样”不代表离子强度一样；“电导率类似”也不代表离子强度完全相同，因为不同离子的迁移率不同。

## 为什么影响生物实验

| 实验对象 | 离子强度影响 |
| --- | --- |
| 蛋白质 | 改变电荷屏蔽、溶解性、聚集和结合 |
| 抗体反应 | 影响特异性结合和非特异背景 |
| 核酸 | 影响杂交、退火、二级结构和迁移 |
| 酶反应 | 改变底物结合、构象稳定和活性 |
| 细胞 | 影响膜电位、离子通道和渗透环境 |
| 电泳 | 影响电流、发热和迁移行为 |

在低离子强度下，带电分子之间的长程静电相互作用更明显；在高离子强度下，离子屏蔽会削弱这些相互作用。这个屏蔽效应是很多 buffer 优化和洗涤条件调整的底层原因。

## 常见实验场景

| 场景 | 离子强度为什么重要 |
| --- | --- |
| [PBS](<../../材(实验耗材工具篇)/PBS.md>) / [DPBS](<../../材(实验耗材工具篇)/DPBS.md>) | 提供接近生理盐环境，影响细胞和蛋白相互作用 |
| [HEPES](<../../材(实验耗材工具篇)/HEPES.md>) 缓冲液 | HEPES 本身主要缓冲 pH，盐组分决定离子环境 |
| 抗体孵育/洗涤 | 盐浓度影响背景和结合强度 |
| [SDS-PAGE](<../../用(实验流程内容篇)/SDS-PAGE.md>) / [转膜缓冲液](<../../材(实验耗材工具篇)/转膜缓冲液.md>) | 离子组成影响电流、发热和迁移 |
| [琼脂糖凝胶电泳](<../../用(实验流程内容篇)/琼脂糖凝胶电泳.md>) | [TAE缓冲液](<../../材(实验耗材工具篇)/TAE缓冲液.md>) / [TBE缓冲液](<../../材(实验耗材工具篇)/TBE缓冲液.md>)离子环境影响核酸迁移和发热 |
| 酶反应 | Mg2+、Na+、K+ 等影响酶活和结构 |
| 细胞培养 | 无机盐、碳酸氢盐和补充剂共同决定细胞环境 |

离子强度经常和 pH 一起被优化。例如改变 NaCl 浓度可能不改变 pH，却明显改变蛋白结合背景；改变 pH 也可能通过加入酸碱改变离子组成。

## 离子强度 vs pH/电导率/渗透压

| 参数 | 主要回答什么 | 容易误解的地方 |
| --- | --- | --- |
| [pH](pH.md) | 酸碱状态 | pH 正常不代表离子环境合适 |
| 电导率 | 溶液导电能力 | 同离子强度不一定同电导率 |
| 渗透压 | 渗透活性粒子总数 | 非离子溶质贡献渗透压但不贡献离子强度 |
| 离子强度 | 离子浓度和电荷造成的静电屏蔽 | 不是总溶质浓度 |
| [折光率](折光率.md) | 光学性质/浓度或密度线索 | 不能告诉你电荷屏蔽强度 |

举例：[蔗糖](<../../材(实验耗材工具篇)/蔗糖.md>)可以增加渗透压，但因为不解离成离子，几乎不增加离子强度；MgCl2 浓度不高，但 Mg2+ 是二价离子，对离子强度贡献很明显。

## 如何计算和记录

对简单盐溶液，可以用配方近似计算离子强度。对复杂培养基、血清、蛋白液或细胞裂解液，离子强度往往只能作为估算或配方变量记录。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 抗体背景高 | 盐浓度或洗涤离子强度不合适 | 优化 NaCl、detergent 和洗涤时间 |
| 酶反应活性差 | Mg2+、K+、Na+ 或 pH 条件不合适 | 单独优化离子组成和 pH |
| 电泳发热严重 | 缓冲液浓度过高或重复使用 | 重新稀释或更换缓冲液 |
| 细胞状态异常 | 盐、渗透压和 pH 多变量变化 | 同时测 pH、渗透压和电导率 |
| 只按总盐浓度比较配方 | 忽略离子电荷 | 计算离子强度，尤其注意二价离子 |

## 小结

离子强度是理解“盐为什么改变实验结果”的关键概念。它解释的是离子浓度和电荷对静电相互作用的综合影响，尤其影响蛋白、核酸、抗体、酶反应和电泳体系。记录时不要只写“盐浓度”，而应尽量写清离子种类、浓度、pH、电导率、渗透压和温度。
