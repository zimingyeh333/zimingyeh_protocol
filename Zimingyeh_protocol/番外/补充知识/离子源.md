# 离子源

Ion source（离子源）是 [质谱仪](<../../材(实验耗材工具篇)/质谱仪.md>) 中把样本分子转化为气相离子的部件。质谱不能直接测“中性分子”，必须先让分子带电，再按 mass-to-charge ratio（[质荷比](质荷比.md)，m/z）进入 [质量分析器](质量分析器.md) 分离和检测。

## 基本作用

Thermo Fisher 的 mass spectrometry technology overview 将质谱核心功能概括为 ionization（离子化）、separation/filtering（分离/过滤）、detection（检测）和 analysis（分析）；其中 ion source（离子源）负责使分析物发生 ionization（离子化），再将离子送入质量分析器。参考：[Thermo Fisher Mass Spectrometry Technology Overview](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/mass-spectrometry-learning-center/mass-spectrometry-technology-overview.html)

离子源要解决三个问题：

| 问题 | 解释 |
| --- | --- |
| 让分子带电 | 中性分子不能被质量分析器有效操控 |
| 让离子进入气相 | 质谱分析通常在真空或近真空环境中进行 |
| 尽量保持可解释性 | 离子化过强会碎裂，过弱会没有信号 |

## 常见离子源

| 离子源 | 英文全称 | 典型联用 | 适合对象 |
| --- | --- | --- | --- |
| [ESI](ESI.md) | electrospray ionization，电喷雾电离 | LC-MS / nanoLC-MS | 肽段、蛋白、小分子、代谢物 |
| [MALDI](MALDI.md) | matrix-assisted laser desorption/ionization，基质辅助激光解吸电离 | [MALDI-TOF](<../../材(实验耗材工具篇)/MALDI-TOF.md>) | 微生物、肽指纹、组织成像、聚合物 |
| APCI | atmospheric pressure chemical ionization，大气压化学电离 | LC-MS | 较低极性小分子 |
| EI | electron ionization，电子电离 | GC-MS | 挥发性小分子，谱库匹配成熟 |
| CI | chemical ionization，化学电离 | GC-MS | 需要较软离子化的小分子 |

## ESI vs MALDI

| 项目 | ESI | MALDI |
| --- | --- | --- |
| 进样方式 | 连续液流喷雾，常接 LC | 靶板点样，激光激发 |
| 常见电荷态 | 常出现多电荷离子 | 多为单电荷离子 |
| 典型平台 | [纳升液相色谱仪](<../../材(实验耗材工具篇)/纳升液相色谱仪.md>) + Orbitrap/Q-TOF/三重四极杆 | MALDI-TOF / MALDI imaging |
| 优势 | 适合复杂混合物在线分离 | 快速、高通量、空间定位能力强 |
| 风险 | 对盐、去污剂、流动相和喷雾状态敏感 | 对基质、结晶和靶板均一性敏感 |

## 离子源会影响什么结果

| 结果表现 | 可能与离子源有关 |
| --- | --- |
| 总信号低 | 喷雾不稳、基质不合适、离子源污染 |
| 背景高 | 溶剂、管路、基质或离子源污染 |
| 重复性差 | 喷雾状态、靶板结晶、温度或电压不稳定 |
| 离子抑制 | 样本中盐、去污剂或共洗脱污染物抑制目标离子化 |
| 碎片异常 | 源内碎裂过强或离子源条件不合适 |

## 使用和排查思路

遇到质谱信号问题时，不要只怀疑质量分析器。可以按顺序看：

```text
样本是否干净
-> LC/靶板是否正常
-> 离子源是否稳定
-> 质量分析器和检测器是否正常
-> 软件参数是否匹配
```

对于 ESI，优先检查流动相、盐/去污剂残留、喷针、喷雾电压、气体和源污染。对于 MALDI，优先检查基质、点样方式、结晶、靶板清洁和激光能量。

## 小结

离子源是质谱的入口。它决定分子能否从样本体系变成可被操控和检测的离子。很多“仪器不灵敏”“鉴定数低”“背景高”的问题，其实都先发生在离子源或更前端的样本/色谱/点样环节。
