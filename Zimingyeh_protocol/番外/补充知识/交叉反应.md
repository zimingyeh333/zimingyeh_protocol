# 交叉反应

Cross-reactivity（交叉反应）是指抗体、探针或检测体系除了识别目标对象之外，也识别了结构相似的非目标对象；在抗体实验中，交叉反应是造成假阳性和结果误读的重要原因。

![Antibody recognition basics](../../z_asset/番外/补充知识/抗体识别基础/antibody-recognition-basics-reference.png)

图：抗体识别基础示意。交叉反应通常来自目标表位和非目标分子上的相似结构。本图复用项目内 Image2 / image-generation model 生成图，用于个人学习笔记示意。

## 一句话理解

交叉反应回答的是：“抗体是不是把长得像目标的东西也抓住了？”

抗体识别依赖 [表位](表位.md) 的结构互补。Janeway Immunobiology 对抗体识别的解释说明，抗体结合位点与抗原表面结构之间的互补性来自多种非共价相互作用；如果非目标分子具有相似结构，就可能被同一抗体识别。参考：[NCBI Bookshelf: Antigen recognition by B-cell and T-cell receptors](https://www.ncbi.nlm.nih.gov/books/NBK27160/)。

## 常见来源

| 来源 | 例子 | 结果 |
| --- | --- | --- |
| 蛋白家族同源性 | 同一家族细胞因子或受体 | ELISA 或 WB 假阳性 |
| 保守结构域 | kinase domain、SH2 domain 等 | 多条带或非目标定位 |
| 修饰相似 | 相似磷酸化 motif | 修饰抗体识别多个蛋白 |
| 标签相同 | His-tag、FLAG-tag | 抗标签抗体识别所有带标签蛋白 |
| 物种相近 | mouse/rat/human 蛋白高度同源 | 跨物种样本解释错误 |
| 二抗交叉 | 二抗识别非目标宿主 IgG | IF/IHC 背景和串色 |

交叉反应不一定来自“抗体质量差”。如果目标表位本来就和其他分子很像，抗体再好也可能需要额外验证。

## 和非特异性结合的区别

| 项目 | 交叉反应 | [非特异性结合](非特异性结合.md) |
| --- | --- | --- |
| 英文 | Cross-reactivity | Nonspecific binding |
| 主要原因 | 非目标分子有相似表位 | 抗体或试剂随机吸附 |
| 是否有结构基础 | 通常有 | 不一定 |
| 常见解决 | 换抗体、换表位、做相关蛋白测试 | 封闭、洗涤、降低浓度 |
| 结果风险 | 假阳性或错误目标归因 | 背景升高、信噪比下降 |

实际实验里两者可能同时存在。背景高时，先用阴性对照、相关蛋白对照和封闭/洗涤优化区分来源。

## 在 ELISA 中的交叉反应

[ELISA](<../../用(实验流程内容篇)/ELISA.md>) 里的交叉反应会直接影响定量结果。尤其是检测细胞因子、激素、小分子、蛋白家族成员时，相关分子可能让样本读数偏高。

购买 [ELISA试剂盒](<../../材(实验耗材工具篇)/ELISA试剂盒.md>) 或 [配对抗体](<../../材(实验耗材工具篇)/配对抗体.md>) 时，应查看：

- 是否测试了相关蛋白 panel。
- 是否说明 cross-reactivity 低于某一比例。
- 是否验证目标物种。
- 是否区分 total、free、active 或 mature form。
- 是否适用于当前样本类型。

夹心 ELISA 虽然需要两支抗体共同识别，通常能降低部分交叉反应风险，但如果相似蛋白同时保留两处表位，仍然可能被检测到。

## 如何验证

| 方法 | 作用 |
| --- | --- |
| 相关蛋白加样测试 | 直接看相似蛋白是否产生信号 |
| KO/KD 阴性样本 | 目标不存在时信号应消失 |
| 竞争实验 | 用目标抗原或表位肽竞争信号 |
| 多抗体克隆比较 | 不同表位抗体是否得到一致结果 |
| 正交方法验证 | 用 PCR、质谱或另一平台验证 |
| 二抗 only 对照 | 判断二抗交叉或背景 |

正式结果中，如果目标所在蛋白家族高度相似，交叉反应验证比单纯重复实验更重要。

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 阴性样本也高 | 相关蛋白交叉反应 | 用相关蛋白 panel 或换抗体 |
| WB 多条带且分子量相近 | 同源蛋白被识别 | 做 KO/KD 或选择更独特表位抗体 |
| 物种切换后结果异常 | 跨物种同源性不同 | 查看物种反应性和序列同源性 |
| ELISA 值高但生物学不合理 | 相关分子干扰 | 做稀释线性、回收率和正交验证 |
| 多重荧光串色 | 二抗或荧光通道交叉 | 做单染和二抗 only 对照 |

## 小结

交叉反应是“识别错了相似对象”，不是简单背景。做抗体实验时，尤其是蛋白家族、跨物种、小分子和多重染色场景，必须把交叉反应当作方法学风险来验证。
