# 产物离子

Product ion（产物离子）是在 [串联质谱](串联质谱.md) 中由 [前体离子](前体离子.md) 碎裂后产生的离子，也常被称为 fragment ion（[碎片离子](碎片离子.md)）。产物离子谱图提供分子结构、肽段序列或靶向定量的证据。

![蛋白质组学常用质谱仪类型概览](../../z_asset/材/质谱仪器/mass-spectrometry-instrument-types-reference.png)

图源：Image2 生成的质谱仪器类型参考图。三重四极杆图中 Q2 碰撞池后进入 Q3 的离子，就是被选择和检测的产物离子。

## 在 MS/MS 中的作用

Thermo Fisher 的 mass spectrometry technology overview 描述 MS/MS 时指出，先选择离子并使其 fragmentation（碎裂），然后分析产生的 fragments（碎片）。这些碎片在三重四极杆和许多 MS/MS 语境中就是 product ions（产物离子）。参考：[Thermo Fisher Mass Spectrometry Technology Overview](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/mass-spectrometry-learning-center/mass-spectrometry-technology-overview.html)

```text
前体离子
-> 碰撞诱导解离 / HCD / ETD
-> 产物离子
-> MS2 谱图、谱库匹配、数据库搜索或 transition 定量
```

## 为什么产物离子重要

| 场景 | 产物离子的意义 |
| --- | --- |
| 肽段鉴定 | b/y 离子系列支持氨基酸序列推断 |
| PTM 定位 | 修饰相关碎片帮助定位修饰位点 |
| 小分子结构解析 | 特征碎片帮助判断候选结构 |
| SRM/MRM | 产物离子与前体离子组成 transition |
| PRM | 采集一个前体对应的多个产物离子全谱 |
| DIA | 通过多个产物离子和保留时间识别目标 |

## 肽段产物离子常见类型

| 类型 | 说明 |
| --- | --- |
| b ions | 从肽段 N 端方向形成的碎片离子 |
| y ions | 从肽段 C 端方向形成的碎片离子 |
| immonium ions | 氨基酸特征小碎片，有时辅助判断氨基酸组成 |
| neutral loss ions | 中性丢失峰，例如水、氨或某些修饰相关丢失 |
| reporter ions | TMT/iTRAQ 等标记定量中的报告离子 |

不同碎裂方式会偏向不同产物离子类型。例如 CID/HCD 常产生 b/y 离子，ETD 更常用于保留某些易碎修饰并产生 c/z 离子系列。

## 产物离子 vs 碎片离子

| 名称 | 常见语境 | 关系 |
| --- | --- | --- |
| Product ion（产物离子） | 三重四极杆、MS/MS 定义、transition | 强调来自某个前体离子 |
| Fragment ion（碎片离子） | 谱图解释、肽段测序、结构解析 | 强调碎裂后的片段 |

很多时候二者可以近似理解为同一类东西，但在 MRM/SRM 里“product ion”更常用于描述被 Q3 监测的目标离子。

## 产物离子选择原则

| 原则 | 为什么重要 |
| --- | --- |
| 强度足够 | 弱碎片不利于定量和确认 |
| 特异性好 | 避免被背景或同类分子干扰 |
| 稳定重复 | 方法转移和批量检测更可靠 |
| 不在噪声区 | 低 m/z 区域可能背景多 |
| 与保留时间一致 | 有助于确认峰身份 |

在 MRM 中，通常选择一个 quantifier transition（定量离子对）和一个或多个 qualifier transition（确认离子对）来提高可信度。

## 常见误解

| 误解 | 更准确的理解 |
| --- | --- |
| 产物离子越多越好 | 关键是可解释、特异且信噪比好 |
| 最强产物离子一定最适合定量 | 还要看背景干扰和线性范围 |
| 看到某个产物离子就能确定结构 | 需要前体、多个碎片、保留时间和标准品/谱库支持 |
| 不同仪器产物离子完全一致 | 碰撞能量、碎裂方式和仪器设计会改变碎片模式 |

## 小结

产物离子是 MS/MS 中前体离子被拆解后的证据片段。它让质谱从“测到一个质量”变成“看到结构线索”。在靶向定量中，产物离子选择是否特异、稳定、强度合适，直接决定 transition 方法是否可靠。
