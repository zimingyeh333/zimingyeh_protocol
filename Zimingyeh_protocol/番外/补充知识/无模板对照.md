# 无模板对照

NTC（no-template control，无模板对照）是在 qPCR 或 [RT-qPCR](<../../用(实验流程内容篇)/RT-qPCR.md>) 中用水或无核酸模板溶液替代样本模板的阴性对照，用于检查反应体系是否存在污染、[引物二聚体](引物二聚体.md) 或非特异扩增。

## 一句话理解

NTC 问的是：“没有任何模板时，这套 qPCR 体系会不会自己亮起来？”

MIQE 指南要求 qPCR 实验报告阴性对照，NTC 是其中最基本的一类。参考：[MIQE guidelines, Clinical Chemistry 2009](https://academic.oup.com/clinchem/article/55/4/611/5631762)。

## NTC 里有什么

NTC 应包含除了模板以外的所有 qPCR 组分：

- qPCR master mix。
- forward primer（正向引物）。
- reverse primer（反向引物）。
- 探针或染料体系。
- 无核酸酶水。

它不包含 cDNA、DNA、RNA 或标准品模板。

## NTC 能发现什么

| 问题 | NTC 表现 |
| --- | --- |
| 模板污染 | NTC 出现与样本相同 Tm 或相同探针信号 |
| 引物二聚体 | NTC 晚 Cq，熔解曲线低温峰 |
| 试剂污染 | 多个引物对或多板同时 NTC 阳性 |
| 气溶胶污染 | 特定区域或特定批次 NTC 阳性 |
| 非特异扩增 | NTC 或阴性样本出现异常曲线 |

## NTC 阳性怎么判断

| 现象 | 更像什么 | 调整方向 |
| --- | --- | --- |
| NTC 很早扩增 | 严重污染 | 重新配体系，清洁区域，更换水和 mix |
| NTC 很晚扩增，低温峰 | 引物二聚体 | 优化引物和退火温度 |
| NTC 峰和样本主峰 Tm 一样 | 目标模板污染 | 检查气溶胶和分区操作 |
| 只有某个引物对 NTC 阳性 | 引物二聚体或该引物污染 | 重配引物工作液 |
| 所有 NTC 都阳性 | 公共试剂污染 | 更换水、master mix 或操作区域 |

## NTC vs no-RT

| 对照 | 中文 | 检查什么 |
| --- | --- | --- |
| NTC | 无模板对照 | qPCR 反应体系污染和引物二聚体 |
| [无逆转录对照](无逆转录对照.md) | no-RT control | RNA 样本中的基因组 DNA 污染 |

NTC 干净不代表没有基因组 DNA 污染；no-RT 干净也不代表 qPCR 配液过程没有污染。两者检查的问题不同。


## 小结

NTC 是 qPCR 每次都应该设置的底线对照。只要 NTC 出现扩增，就必须判断是污染还是引物二聚体，不能简单忽略。
