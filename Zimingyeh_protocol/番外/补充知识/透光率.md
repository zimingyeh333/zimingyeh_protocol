# 透光率

Transmittance（透光率）是指 transmitted light（透射光）相对于 incident light（入射光）的比例，用来描述光穿过样品后还剩多少。

图：吸光度、OD450 和光程的关系。透光率关注“光剩多少”，吸光度关注“光被衰减多少”。本图由 Image2 / image-generation model 生成，用于个人学习笔记示意。

## 一句话理解

透光率越高，说明穿过样品的光越多；透光率越低，说明样品吸收、散射或阻挡的光越多。

常见关系：

```text
T = transmitted light / incident light
A = -log10(T)
```

其中 T 是 transmittance（透光率），A 是 [吸光度](吸光度.md)。IUPAC 对 absorbance 的定义基于入射光和透射光功率之比，因此透光率和吸光度是同一个光学过程的两个表达方式。参考：[IUPAC Gold Book: absorbance](https://goldbook.iupac.org/terms/view/A00028)。

## 透光率和吸光度的区别

| 项目 | 透光率 | 吸光度 |
| --- | --- | --- |
| 英文 | Transmittance | Absorbance |
| 关注点 | 透过了多少光 | 光被衰减了多少 |
| 数学形式 | 比例 | 对数 |
| 常见范围 | 0-1 或 0-100% | 0 到较高正值 |
| 和浓度关系 | 不是线性 | 在合适条件下可近似线性 |
| 实验记录 | 较少直接使用 | ELISA、蛋白定量、核酸定量常用 |

直观理解：

```text
100% 透光率 → 吸光度约 0
10% 透光率 → 吸光度约 1
1% 透光率 → 吸光度约 2
```

这也是为什么高吸光度区域容易不稳定：当透射光已经很少时，仪器和噪音对最终读数影响会变大。

## 为什么实验更常记录吸光度

在 [比尔-朗伯定律](比尔-朗伯定律.md) 适用的条件下，吸光度和浓度、光程更容易呈线性关系：

```text
吸光度 ∝ 浓度 × 光程
```

透光率本身和浓度不是简单直线关系，因此做 [标准曲线](标准曲线.md) 或定量分析时，仪器通常显示 absorbance / OD，而不是直接用透光率。

## 在 ELISA 中的意义

在 HRP-TMB endpoint [ELISA](<../../用(实验流程内容篇)/ELISA.md>) 中，孔越黄，450 nm 透过的光越少，[OD450](OD450.md) 越高。读板器并不是“看颜色深浅”这么简单，而是在特定波长下比较入射光和透射光，然后给出吸光度读数。

如果孔底有气泡、划痕、沉淀或液体浑浊，透射光也会减少，OD450 可能虚高。这些并不一定代表目标物浓度升高。

## 透光率相关异常

| 异常 | 可能原因 | 对读数的影响 |
| --- | --- | --- |
| 气泡 | 光路被局部阻挡 | 吸光度虚高或复孔差异大 |
| 浑浊 | 光散射增加 | 吸光度升高但不一定是吸收 |
| 沉淀 | 光穿过不均匀 | 孔间差异变大 |
| 指纹/板底污染 | 非样本光学背景 | 参考波长可能部分校正 |
| 液体体积不同 | 光程不同 | 同浓度读数也不同 |

## 和参考波长的关系

[参考波长](参考波长.md) 的逻辑是：如果某些光学干扰同时影响检测波长和参考波长，就可以用参考波长读数扣除一部分非特异背景。它不能解决所有透光率问题，尤其不能完全纠正气泡、沉淀或强散射。

## 小结

透光率是吸光度背后的原始比例概念。实验里通常记录吸光度，是因为吸光度更适合和浓度建立线性或标准曲线关系；但排查异常读数时，回到“透过的光为什么变少了”这个问题，常常能快速找到气泡、浑浊、沉淀和板底污染。
