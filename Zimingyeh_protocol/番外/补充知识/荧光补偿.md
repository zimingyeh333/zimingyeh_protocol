# 荧光补偿

## 一句话定义

Fluorescence compensation（荧光补偿）是 [流式细胞术](<../../用(实验流程内容篇)/流式细胞术.md>) 中用于校正 spectral spillover（光谱溢出）的数学处理过程，目的是把一个荧光染料泄漏到其他检测通道中的信号从数据中扣除。

简单说，一个染料不会只在一个通道里发光。比如 [FITC](<../../材(实验耗材工具篇)/FITC.md>) 的绿色信号可能部分进入邻近通道，[PE](<../../材(实验耗材工具篇)/PE.md>) 或 PE-Cy7 等也可能影响多个检测器。BD、BioLegend 和 Thermo Fisher 的流式资料都把 compensation 作为多色流式分析的基本步骤。[参考：BD Spectrum Viewer](https://www.bdbiosciences.com/en-us/resources/bd-spectrum-viewer)；[参考：BioLegend Fluorophore Guide](https://www.biolegend.com/en-us/fluorophore-guide)；[参考：Thermo Fisher Flow Cytometry Compensation](https://www.thermofisher.com/us/en/home/life-science/cell-analysis/flow-cytometry/flow-cytometry-learning-center/flow-cytometry-resource-library/flow-cytometry-methods/compensation-flow-cytometry.html)

## 为什么需要补偿

每种 [荧光染料](<../../材(实验耗材工具篇)/荧光染料.md>) 都有一个发射光谱，而检测器收集的是一定波段范围内的光。发射光谱与检测窗口重叠，就会发生 spillover。

```text
染料A主要在A通道发光
但部分光进入B通道
如果不补偿
B通道会误以为样本有B染料信号
```

补偿不是“让图好看”，而是让每个通道尽可能反映对应染料的真实信号。

## 核心概念

| 概念 | 英文 | 说明 |
| --- | --- | --- |
| 光谱溢出 | Spectral spillover | 一个染料信号进入其他通道 |
| 补偿矩阵 | Compensation matrix | 记录各通道之间扣除比例的矩阵 |
| 单染对照 | Single-stain control | 每个染料单独染色，用于计算补偿 |
| 未染对照 | Unstained control | 确定自发荧光和阴性基线 |
| FMO 对照 | Fluorescence minus one control | 缺少某个染料，用于设门 |
| 扩散误差 | Spreading error | 补偿后阴性群变宽的现象 |

补偿能校正平均 spillover，但不能消除 spreading error。染料太亮、通道太重叠或 panel 设计太拥挤，补偿后仍可能分群困难。

## 单染补偿对照

理想单染对照应满足：

| 要求 | 原因 |
| --- | --- |
| 每个荧光染料一个单染 | 补偿矩阵需要每个染料的光谱表现 |
| 阳性和阴性群清楚 | 软件才能准确估算 spillover |
| 与实验样本同一染料 | 不同染料不能互相替代 |
| 串联染料同批号更好 | [串联染料](<../../材(实验耗材工具篇)/串联染料.md>) 光谱更易变 |
| 亮度不低于样本 | 太弱的补偿对照不可靠 |

补偿珠可以替代细胞作为单染材料，但必须确认它能结合对应抗体，并且自发荧光和光谱表现适合该仪器。

## 补偿 vs 设门

| 项目 | 补偿 | 设门 |
| --- | --- | --- |
| 英文 | Compensation | Gating |
| 目的 | 校正通道间光谱溢出 | 定义细胞群和阳性/阴性 |
| 所需对照 | 单染对照 | 未染、FMO、阴性/阳性对照 |
| 错误后果 | 假阳性、假阴性、群体斜线 | 群体选择错误 |
| 关系 | 补偿通常在设门前完成 | 设门建立在补偿后数据上 |

补偿不能替代 FMO。尤其在高维 panel 中，FMO 对照对判断弱阳性边界非常重要。

## 常见工作流

1. 设计 panel 时用光谱工具预估 spillover。
2. 给每个染料准备单染补偿对照。
3. 上机采集未染和单染对照。
4. 建立 compensation matrix。
5. 应用到实验样本。
6. 检查双参数图中阴性群是否合理。
7. 用 FMO 和生物学对照设门。

## 注意事项

- 不同仪器、电压/增益、滤光片设置都会影响补偿。
- 更换抗体批号、串联染料批号或固定条件后，补偿可能需要重做。
- 过度补偿和不足补偿都能制造假结果。
- Compensation control 必须足够亮，但不能饱和。
- 多色 panel 应从设计阶段减少不必要的光谱重叠，而不是寄希望于后期补偿。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 双参数图出现斜线 | 补偿不足或过度 | 重新检查单染对照 |
| 阴性群变宽 | Spreading error 高 | 调整 panel，把亮染料换给低表达 marker |
| 每次补偿不同 | 串联染料不稳定或仪器设置变化 | 当天做单染，固定仪器设置 |
| 单染对照太弱 | 抗体结合差或补偿珠不匹配 | 换更亮补偿材料 |
| 阳性群饱和 | 信号超出检测范围 | 降低电压/增益或抗体量 |

## 小结

荧光补偿是多色流式的基础数据处理步骤，用来校正染料之间的光谱溢出。它必须依赖合格单染对照，尤其是串联染料。补偿能校正 spillover，但不能消除 panel 设计不合理造成的 spreading error，所以好的补偿从好的染料选择开始。
