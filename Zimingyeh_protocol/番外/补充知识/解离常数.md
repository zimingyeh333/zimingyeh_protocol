# 解离常数

Dissociation constant（解离常数，常写作 Kd）是描述两个分子形成复合物后“倾向于解离到什么程度”的平衡参数；在 [抗体](抗体.md) 实验中，Kd 常用来量化抗体与 [抗原](抗原.md) 或 [表位](表位.md) 之间的 [亲和力](亲和力.md)。

![Antibody recognition basics](../../z_asset/番外/补充知识/抗体识别基础/antibody-recognition-basics-reference.png)

图：抗体识别基础示意。Kd 可以帮助理解抗体和表位结合得稳不稳，但实验结果还会同时受到特异性、样本基质、洗涤强度、抗体浓度和检测体系影响。

## 一句话理解

Kd 越低，通常表示抗体和抗原结合越紧；Kd 越高，通常表示复合物越容易解离。

可以用一个非常简化的关系理解：

```text
Ab + Ag <-> Ab-Ag
Kd = [Ab][Ag] / [Ab-Ag]
```

这里 Ab 表示 antibody（抗体），Ag 表示 antigen（抗原）。当 Kd 很低时，在相同条件下更多分子倾向于处在 Ab-Ag 复合物状态。

## 和 kon、koff 的关系

抗体结合不是静态事件，而是同时包含 association（结合）和 dissociation（解离）。

| 参数 | 常见写法 | 含义 | 直观理解 |
| --- | --- | --- | --- |
| 结合速率常数 | kon 或 ka | 抗体和抗原结合的速度 | 抓上去有多快 |
| 解离速率常数 | koff 或 kd | 抗体从抗原上脱离的速度 | 松手有多快 |
| 解离常数 | Kd | 平衡亲和力 | 整体抓得紧不紧 |

常见关系为：

```text
Kd = koff / kon
```

因此两个抗体即使 Kd 接近，实验表现也可能不同。一个抗体可能结合很快也解离很快，另一个可能结合慢但解离也慢；在短孵育、强洗涤或快速检测场景中，这种动力学差异会影响结果。

## 单位怎么读

Kd 的单位通常是 mol/L（M），抗体资料里常见 nM、pM 等单位。

| Kd 范围 | 粗略理解 | 注意 |
| --- | --- | --- |
| micromolar，uM | 较弱结合 | 可能需要高浓度或温和洗涤 |
| nanomolar，nM | 常见较好亲和力 | 很多实验抗体落在这个量级 |
| picomolar，pM | 很强结合 | 不一定总是更好，可能影响动态范围或洗脱 |

这些范围只能帮助建立直觉，不能直接替代实验验证。抗体是否好用，还要看 [特异性](特异性.md)、背景、应用验证和样本条件。

## Kd 在实验中的意义

| 场景 | Kd 影响 |
| --- | --- |
| [ELISA](<../../用(实验流程内容篇)/ELISA.md>) | 影响低浓度目标的捕获效率、洗涤后保留和标准曲线低端表现 |
| [Western blot](<../../用(实验流程内容篇)/Western blot.md>) | 影响洗膜后条带是否保留，尤其低丰度蛋白 |
| [免疫荧光](<../../用(实验流程内容篇)/免疫荧光.md>) | 影响低表达目标的定位信号和背景平衡 |
| [流式细胞术](<../../用(实验流程内容篇)/流式细胞术.md>) | 影响低表达细胞群体分辨率 |
| 竞争实验 | 高亲和力抗体可能更难被竞争物置换 |

BioLegend 的 sandwich ELISA protocol 中的多步孵育和洗涤逻辑，正体现了抗原抗体结合稳定性对信号保留的重要性。参考：[BioLegend sandwich ELISA protocol](https://www.biolegend.com/en-us/protocols/sandwich-elisa-protocol)。

## 常见测量方法

| 方法 | 英文全称 | 中文 | 特点 |
| --- | --- | --- | --- |
| [SPR](SPR.md) | Surface plasmon resonance | 表面等离子体共振 | 可实时测 kon、koff 和 Kd，常用于纯化分子互作 |
| [BLI](BLI.md) | Bio-layer interferometry | 生物层干涉 | 操作相对方便，也可实时测动力学 |
| ELISA 曲线估计 | Enzyme-linked immunosorbent assay based estimation | 基于 ELISA 的估算 | 更接近某些应用条件，但常不是严格动力学测量 |
| ITC | Isothermal titration calorimetry | 等温滴定量热 | 可测热力学参数，但样品消耗较大 |

如果资料中写“high affinity”，但没有说明测量方法、抗原形式、温度、缓冲液和拟合模型，就只能把它当作一般描述，不能当作可直接比较的定量结果。

## Kd 不能单独决定实验好坏

| 容易误解 | 更准确的理解 |
| --- | --- |
| Kd 越低越好 | 太强结合可能导致洗脱困难、背景高或动态范围变窄 |
| Kd 高就不能用 | 某些高抗原丰度或短流程实验中仍可用 |
| Kd 低说明特异性高 | Kd 只描述结合强度，不保证只结合目标 |
| ELISA EC50 等于 Kd | ELISA 曲线受包被、标记、洗涤、基质和几何因素影响 |
| 厂家给的 Kd 可跨实验直接比较 | 不同测量平台和抗原形式会产生差异 |

Janeway Immunobiology 对抗体-抗原结合的描述强调，这种结合来自多个非共价相互作用的总和。也就是说，Kd 是对某一组条件下复合物稳定性的量化，不是抗体“永久属性”。参考：[NCBI Bookshelf: Antigen recognition by B-cell and T-cell receptors](https://www.ncbi.nlm.nih.gov/books/NBK27160/)。

## 读厂家数据时看什么

| 项目 | 为什么重要 |
| --- | --- |
| 抗原形式 | 全长蛋白、片段、肽段、标签蛋白会改变结果 |
| 固定方向 | SPR/BLI 中谁被固定会影响可及性和表观亲和力 |
| 是否单价 | 多价结合会把 avidity 当成 affinity |
| 缓冲液和温度 | 盐、pH、表面活性剂和温度会影响非共价相互作用 |
| 拟合模型 | 1:1 binding 和复杂模型结果不可简单混比 |
| 重复和误差 | 单个漂亮曲线不代表稳定参数 |

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| Kd 很好但 ELISA 背景高 | 特异性不足或抗体浓度过高 | 做抗体滴定，检查交叉反应和封闭 |
| Kd 好但 WB 条带弱 | 表位在变性条件下被破坏或目标低丰度 | 换识别线性表位的抗体 |
| SPR 曲线拟合很差 | 固定过量、质量传递限制、异质抗原 | 降低固定量，优化流速和抗原纯度 |
| BLI 信号漂移 | 非特异吸附、传感器状态不稳 | 优化缓冲液，加入合适阻断剂 |
| ELISA 估算亲和力和 SPR 不一致 | 平台条件不同，ELISA 有多价和洗涤效应 | 不直接横向比较，回到应用验证 |

## 小结

解离常数是理解抗体亲和力的重要参数，但它只回答“在特定条件下复合物有多稳定”。真正选择抗体时，Kd 要和特异性、应用验证、样本类型、洗涤条件和背景控制一起判断。
