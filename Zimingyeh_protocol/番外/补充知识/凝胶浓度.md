# 凝胶浓度

凝胶浓度（gel percentage / agarose percentage）在 [琼脂糖凝胶电泳](<../../用(实验流程内容篇)/琼脂糖凝胶电泳.md>) 中通常指 agarose gel percentage（琼脂糖凝胶质量体积百分比，% w/v），也就是每 100 mL 电泳缓冲液中加入多少克琼脂糖。它决定凝胶孔径、DNA/RNA 片段分辨范围和电泳迁移表现。

![Agarose percentage and pore size reference](../../z_asset/番外/补充知识/凝胶浓度/agarose-percentage-pore-size-reference.png)

图源：Image2 生成的琼脂糖浓度、孔径和迁移率示意图；低浓度胶孔径大，适合大片段；高浓度胶孔径小，适合小片段。

## 计算方式

```text
Gel % (w/v) = agarose mass (g) / buffer volume (mL) x 100%
```

例如：

| 目标浓度 | 100 mL 1x TAE/TBE 中加入琼脂糖 |
| --- | --- |
| 0.8% | 0.8 g |
| 1.0% | 1.0 g |
| 1.5% | 1.5 g |
| 2.0% | 2.0 g |

Thermo Fisher 的核酸电泳 workflow 页面也用同样公式定义 gel percentage，并给出不同琼脂糖百分比对应的高效分离范围。参考：[Thermo Fisher Steps in Nucleic Acid Gel Electrophoresis](https://www.thermofisher.cn/cn/en/home/life-science/cloning/cloning-learning-center/invitrogen-school-of-molecular-biology/na-electrophoresis-education/na-electrophoresis-workflow.html)。

## 为什么浓度影响分离

琼脂糖冷却凝固后形成多孔网络。低浓度胶孔径较大，大 DNA 片段更容易进入并分开；高浓度胶孔径较小，能更好地区分小片段，但会让大片段迁移慢、条带压在上部或分不开。

Bio-Rad 的 nucleic acid electrophoresis 资料也说明，琼脂糖凝胶按 0.8%、1%、1.2% 等质量体积百分比配制，具体百分比取决于 expected fragment size（预期片段大小）和 desired separation（目标分离效果）。参考：[Bio-Rad Nucleic Acid Electrophoresis](https://www.bio-rad.com/pt-br/applications-technologies/nucleic-acid-electrophoresis?ID=LUSNS52B7)。

## 常用选择范围

| 琼脂糖浓度 | 更适合分离 | 常见场景 |
| --- | --- | --- |
| 0.5%-0.7% | 大片段 DNA | 长片段酶切、大片段质粒、PFGE 以外的粗略观察 |
| 0.8%-1.0% | 中大片段 DNA | 普通质粒、常规酶切、1 kb 以上 PCR |
| 1.2%-1.5% | 中小片段 DNA | 200 bp-3 kb PCR 产物 |
| 2.0%-3.0% | 小片段 DNA | 短 PCR、引物二聚体、几十到几百 bp 片段 |

Thermo Fisher 表格给出的范围示例包括：0.8% 胶适合约 800-10,000 bp，1.5% 胶适合约 200-3,000 bp，3.0% 胶适合约 25-1,000 bp。这个范围适合做选择起点，但实际还会受缓冲液、琼脂糖等级、电压、胶厚度和样本盐浓度影响。参考：[Thermo Fisher Steps in Nucleic Acid Gel Electrophoresis](https://www.thermofisher.cn/cn/en/home/life-science/cloning/cloning-learning-center/invitrogen-school-of-molecular-biology/na-electrophoresis-education/na-electrophoresis-workflow.html)。

## 与电泳迁移率的关系

[电泳迁移率](电泳迁移率.md) 是样本在电场中迁移快慢的表现。凝胶浓度越高，孔径越小，分子筛效应越强，大片段受到的阻力越明显；因此同样电压和时间下，高浓度胶通常让大片段跑得更慢。

选择凝胶浓度时不要只问“能不能跑出来”，更要问“目标片段附近能不能分开”。如果两个片段差距很小，提高胶浓度、降低电压并延长运行时间通常比盲目跑快更有用。

## 常见错误

| 错误 | 结果 | 建议 |
| --- | --- | --- |
| 所有 PCR 都用 1% 胶 | 小片段分不开，大片段可能还好 | 按片段大小选择浓度 |
| 高浓度胶跑大片段 | 大片段卡在上部或条带压缩 | 降低凝胶浓度 |
| 低浓度胶跑小片段 | 小片段跑太快、分辨率差 | 提高凝胶浓度 |
| 加热过度蒸发水分 | 实际浓度升高 | 控制加热，必要时补足体积 |
| 配胶 buffer 和 running buffer 不一致 | 条带歪、迁移异常 | 两者使用同一种 1x buffer |

## 小结

凝胶浓度是核酸电泳的“筛孔大小旋钮”。低浓度胶适合大片段，高浓度胶适合小片段；真正的选择要围绕目标片段大小、片段间距、成像需求和下游用途。
