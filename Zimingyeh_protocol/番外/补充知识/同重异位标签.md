# 同重异位标签

Isobaric tag（同重异位标签）是一类用于 [LC-MS](<../../用(实验流程内容篇)/液相色谱-质谱联用.md>) 定量的化学标记试剂：不同样本被标记后在 MS1 中具有相同总质量，但在 MS/MS 或 MS3 碎裂后释放不同质量数的 reporter ion（[报告离子](报告离子.md)），从而区分样本来源并进行相对定量。

## 核心思想

同重异位标签解决的是“多个样本如何在同一次质谱分析中比较丰度”的问题。典型流程是：

```text
样本 A/B/C...
-> 蛋白提取
-> 酶切成肽段
-> 每个样本用不同通道标签标记
-> 混合所有样本
-> LC-MS/MS 或 LC-MS3
-> 用报告离子强度计算样本间比例
```

这类方法的经典代表是 [TMT](TMT.md) 和 [iTRAQ](iTRAQ.md)。Thompson 等在 2003 年提出 tandem mass tags（串联质量标签），Ross 等在 2004 年提出 iTRAQ（isobaric Tags for Relative and Absolute Quantitation，同重异位相对与绝对定量标签），两者共同奠定了现代多重定量蛋白质组学的技术路线。参考：[Thompson et al., 2003](https://doi.org/10.1021/ac0262560)；[Ross et al., 2004](https://doi.org/10.1074/mcp.M400129-MCP200)。

## 标签结构

| 结构 | 英文 | 作用 |
| --- | --- | --- |
| 报告基团 | reporter group | 碎裂后释放不同 m/z 的报告离子，用于定量 |
| 平衡基团 | balance group | 补偿不同报告基团质量，使各通道总质量相同 |
| 反应基团 | reactive group | 通常与肽段 N 端和赖氨酸侧链氨基反应 |

真正用于“分组”的不是 MS1 中的母离子质量，而是碎裂后出现的报告离子强度。因此，同重异位标签特别依赖高质量的 MS/MS 采集、通道校正和数据归一化。

## 适合的场景

| 场景 | 为什么适合 |
| --- | --- |
| 多处理组蛋白质组学 | 多个样本混合上机，降低批间漂移 |
| 时间序列或剂量梯度 | 通道设计可以直接承载多个条件 |
| 磷酸化、泛素化等富集实验 | 富集步骤之后统一分析，减少批间差异 |
| 大队列分批实验 | 可加入 pooled reference channel（混合参考通道）做批次桥接 |
| 样本量有限但组数较多 | 混合后可提高上机效率 |

## 和其他定量方法的区别

| 方法 | 定量读数 | 优势 | 主要限制 |
| --- | --- | --- | --- |
| 同重异位标签 | 报告离子强度 | 多样本混合、通量高、批间差异较小 | 试剂成本高，易受共隔离干扰和比例压缩影响 |
| [SILAC](SILAC.md) | 轻/重同位素肽段峰面积比 | 细胞模型中误差小，混合可发生在早期 | 依赖细胞代谢标记，不适合多数临床样本 |
| [label-free定量](label-free定量.md) | 峰面积或谱图计数 | 便宜、流程简单、样本数灵活 | 批间效应、缺失值和仪器稳定性要求更高 |
| [内标法](内标法.md) | 目标物/内标信号比 | 适合靶向绝对定量 | 通常不是高通量全蛋白质组比较方案 |

## 关键风险

| 风险 | 原因 | 结果 |
| --- | --- | --- |
| Ratio compression（比例压缩） | 共隔离肽段一起进入碎裂窗口 | 真实差异被低估 |
| 标记不完全 | pH、盐、胺类缓冲物或肽段量问题 | 未标记肽段增加，通道比例偏差 |
| 通道不平衡 | 混样前肽段定量不准 | 某些通道整体偏高或偏低 |
| isotope impurity（同位素杂质） | 标签合成中不可避免的同位素分布 | 报告离子通道串扰，需要校正 |
| 批次桥接不足 | 多个 plex 之间缺少共同参考 | 大队列难以整合 |

## 操作理解

同重异位标签不是“标记了就一定更准”。它把多个样本放进同一次质谱运行中，降低了上机批次差异，但也引入了标记效率、通道设计、共隔离干扰和通道校正问题。做这类项目时，实验设计、混样前定量、QC 样本和数据校正往往比单个仪器参数更重要。

## 常见错误与 troubleshooting

| 异常 | 常见原因 | 调整方向 |
| --- | --- | --- |
| 通道整体偏高或偏低 | 混样前肽段定量不准 | 标记前后都做肽段定量，必要时 test mix |
| 差异倍数偏小 | 共隔离干扰导致比例压缩 | 窄 isolation window、延长梯度、分级或使用 MS3 |
| 标记效率低 | 缓冲液含胺、pH 不合适、盐太高 | 换兼容缓冲体系，脱盐后标记 |
| 批间数据难整合 | 没有共同参考通道 | 设计 pooled reference channel |
| 低丰度蛋白不稳定 | reporter ion 信号弱 | 增加样本量、优化分级或富集 |

## 小结

同重异位标签的核心价值是多样本相对定量，尤其适合复杂实验设计和高通量蛋白质组学。它的核心风险不是“能不能标上”，而是标记后如何控制通道平衡、共隔离干扰、比例压缩和批次整合。
