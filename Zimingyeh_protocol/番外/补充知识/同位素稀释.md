# 同位素稀释

Isotope dilution（同位素稀释）是一种利用同位素标记内标进行定量的方法。在 LC-MS 中，最常见形式是 stable isotope dilution LC-MS（稳定同位素稀释 LC-MS）：向样本中加入已知量的同位素标记目标物或同位素标记肽段，再用目标物/内标信号比计算浓度或含量。

## 核心原理

同位素标记内标和目标物化学性质几乎相同，但质量数不同，因此在 LC-MS 中可以被区分。理想情况下，它们具有相同或非常接近的：

| 性质 | 为什么重要 |
| --- | --- |
| 萃取行为 | 共同经历样本前处理损失 |
| 色谱保留时间 | 共同经历局部 [LC-MS基质效应](LC-MS基质效应.md) |
| 离子化效率 | 共同受到离子源状态影响 |
| 碎裂行为 | 靶向 MS/MS 中有可比 transition |

所以同位素稀释不是简单“加一个参照物”，而是尽可能让参照物陪目标物一起经历整个分析过程。

## 什么时候加入内标最关键

| 加入时间 | 能校正什么 | 不能校正什么 |
| --- | --- | --- |
| 样本处理前 | 提取损失、部分基质效应、进样波动 | 内标加入前已经发生的降解 |
| 蛋白酶切前 | 酶切后肽段损失、脱盐损失、进样波动 | 蛋白提取和酶切效率本身 |
| 酶切后 | 脱盐、进样、离子化波动 | 蛋白提取和酶切差异 |
| 上机前 | 进样和离子源波动 | 前处理全部误差 |

因此，内标越早加入，理论上可校正的流程误差越多；但越早加入，对内标形式和实验成本的要求也越高。

## 适合什么场景

| 场景 | 说明 |
| --- | --- |
| 小分子药物定量 | 血浆或组织中药物浓度检测 |
| 代谢物靶向定量 | 稳定同位素内标可校正基质差异 |
| 靶向蛋白质组学 | 同位素标记肽段常用于 MRM/PRM |
| 绝对定量方法开发 | 与标准曲线结合可得到实际浓度 |
| 方法验证 | 可提高 accuracy（准确度）和 precision（精密度） |

ICH M10 和 FDA 生物分析方法验证指南都强调内标、基质效应、准确度和精密度在定量方法验证中的重要性。参考：[ICH M10](https://database.ich.org/sites/default/files/M10_Guideline_Step4_2022_0524.pdf)；[FDA Bioanalytical Method Validation](https://www.fda.gov/regulatory-information/search-fda-guidance-documents/bioanalytical-method-validation-guidance-industry)。

## 和内标法、外标法、标准加入法的关系

| 方法 | 核心 | 区别 |
| --- | --- | --- |
| [内标法](内标法.md) | 用目标物/内标信号比校正波动 | 内标可以是同位素标记物，也可以是结构类似物 |
| 同位素稀释 | 内标是同位素标记目标物或高度匹配物 | 是内标法中最理想、最严格的一类 |
| [标准曲线](标准曲线.md) | 用已知浓度建立响应关系 | 可与同位素内标结合 |
| [外标法](外标法.md) | 只用外部标准曲线 | 对基质效应和前处理损失校正弱 |
| [标准加入法](标准加入法.md) | 向真实样本中加入不同量标准品 | 适合空白基质难获得的复杂样本 |

## 关键风险

| 风险 | 后果 | 处理 |
| --- | --- | --- |
| 内标纯度或浓度不准 | 所有结果系统偏差 | 使用有证书标准品，记录批号和有效期 |
| 内标和目标物不共流出 | 不能校正局部离子抑制 | 选择更匹配的同位素内标 |
| 同位素峰重叠 | 轻重通道互相污染 | 检查同位素纯度和 MRM transition |
| 内标加入过晚 | 前处理误差无法校正 | 尽量在可行的最早步骤加入 |
| 内标浓度不合适 | 低浓度不稳定或高浓度污染 | 让内标响应接近样本中目标物范围 |

## 小结

同位素稀释是 LC-MS 定量中最可靠的校正思想之一。它的关键不是“用了重标内标”这句话，而是内标是否足够匹配、加入时机是否合理、标准曲线是否覆盖样本范围，以及是否验证了基质效应和准确度。
