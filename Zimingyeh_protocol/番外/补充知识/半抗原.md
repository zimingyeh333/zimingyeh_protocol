# 半抗原

Hapten（半抗原）是指本身可以被 [抗体](抗体.md) 识别、但单独通常不能诱导完整免疫反应的小分子或小结构；半抗原常需要连接 [载体蛋白](载体蛋白.md) 后形成 hapten-carrier conjugate（半抗原-载体偶联物），才能作为有效 [免疫原](免疫原.md) 使用。

## 一句话理解

半抗原像一个“小标签”：抗体可以认出它，但免疫系统通常需要把它挂到更大的载体上，才会产生足够强的抗体反应。

Wikipedia 的 hapten 页面将半抗原描述为只有连接到较大 carrier（例如蛋白）后才会诱导免疫反应的小分子；这和抗体制备中“半抗原需要偶联载体蛋白”的实践逻辑一致。参考：[Wikipedia: Hapten](https://en.wikipedia.org/wiki/Hapten)。

## 半抗原、抗原、免疫原的区别

| 概念 | 英文 | 能被抗体识别 | 能单独诱导免疫反应 | 典型例子 |
| --- | --- | --- | --- | --- |
| 抗原 | Antigen | 可以 | 不一定 | 蛋白、多糖、小分子 |
| 免疫原 | Immunogen | 通常可以 | 可以 | 全长蛋白、偶联肽 |
| 半抗原 | Hapten | 可以 | 通常不可以 | 药物小分子、激素、毒素、DNP |

一个半抗原连接到 carrier 后，整体可以成为完整免疫原。最终筛选得到的抗体可能识别半抗原本身，也可能识别 linker、carrier 或偶联后的空间构象，因此筛选设计非常重要。

## 半抗原抗体为什么难

| 难点 | 原因 | 结果 |
| --- | --- | --- |
| 分子太小 | 表位面积有限 | 抗体选择空间小 |
| 需要偶联 | 必须连接 carrier | linker 和偶联方向会影响识别 |
| 易产生抗 carrier 抗体 | carrier 通常免疫原性很强 | 阳性信号可能不是目标半抗原 |
| 构象依赖强 | 小分子暴露方向决定识别面 | 不同偶联方式筛出的抗体可能不同 |
| 样本基质复杂 | 小分子检测常在血清、尿液、食品或环境样本中 | 需要特别关注基质效应 |

## 常见应用

| 应用 | 说明 |
| --- | --- |
| 小分子 ELISA | 药物、激素、毒素、农残等检测 |
| 竞争 ELISA | 半抗原太小，常不适合夹心 ELISA |
| 抗标签检测 | 生物素、荧光素、地高辛等小标签可作为识别对象 |
| 过敏和药物反应研究 | 某些小分子与体内蛋白形成加合物后诱导免疫反应 |
| 免疫化学基础研究 | 研究抗体如何识别小分子结构差异 |

## 设计半抗原免疫原时看什么

| 设计点 | 影响 |
| --- | --- |
| carrier 选择 | [KLH](<../../材(实验耗材工具篇)/KLH.md>)、[BSA](<../../材(实验耗材工具篇)/BSA.md>)、[OVA](<../../材(实验耗材工具篇)/OVA.md>) 等会影响免疫和筛选 |
| linker 长度 | 太短可能遮挡目标，太长可能让抗体识别 linker |
| 偶联位点 | 决定小分子暴露哪一面 |
| 偶联密度 | 影响免疫强度和抗体谱 |
| 筛选 antigen | 最好用不同 carrier 的偶联物排除抗 carrier 抗体 |
| 竞争物设计 | 竞争 ELISA 中游离半抗原或类似物决定特异性判断 |

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 免疫后滴度高但不识别游离小分子 | 抗体主要识别 carrier 或 linker | 换 carrier 筛选，加入 carrier-only 和 linker-only 对照 |
| 竞争曲线不明显 | 抗体识别偶联构象，不识别游离半抗原 | 改变偶联位点或筛选策略 |
| 类似物交叉反应高 | 半抗原暴露结构过于保守 | 重新设计免疫原和竞争筛选面板 |
| 批间差异大 | 偶联密度或纯化状态不同 | 记录偶联比和验证方法 |
| 背景高 | 样本基质或非特异吸附 | 做基质匹配标准曲线和封闭优化 |

## 小结

半抗原抗体开发的关键不是“把小分子接到蛋白上”这么简单，而是控制 carrier、linker、偶联方向和筛选体系，让最终抗体真正识别目标小分子，而不是识别偶联体系的副产物。
