# 碰撞诱导解离

Collision-induced dissociation（CID，碰撞诱导解离，也常称 collisionally activated dissociation，CAD，碰撞活化解离）是一种常见的 [串联质谱](串联质谱.md) 碎裂方式。它让被选中的 [前体离子](前体离子.md) 与碰撞气体发生碰撞，将动能转化为内能，使离子断裂并形成 [产物离子](产物离子.md)。

图源：Image2 生成的质谱仪器类型参考图。三重四极杆模块中的 Q2“碰撞池”就是 CID/CAD 逻辑最直观的位置。

## 基本流程

```text
Q1 或前级质量分析器选择前体离子
-> 前体离子进入碰撞池
-> 与氮气、氩气等碰撞气体碰撞
-> 离子内部能量升高
-> 化学键断裂
-> 形成产物离子 / 碎片离子
-> 进入后级质量分析器检测
```

Thermo Fisher 的 mass spectrometry technology overview 描述 MS/MS 时提到，先选择离子并使其 fragmentation（碎裂），随后分析 fragments（碎片）；三重四极杆页面则展示了靶向检测和定量中 SRM/MRM 的硬件逻辑。CID/CAD 是许多这类 MS/MS 方法中最常见的碎裂机制之一。参考：[Thermo Fisher Mass Spectrometry Technology Overview](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/mass-spectrometry-learning-center/mass-spectrometry-technology-overview.html)、[Thermo Fisher Triple Quadrupole LC-MS](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/liquid-chromatography-mass-spectrometry-lc-ms/lc-ms-systems/triple-quadrupole-lc-ms.html)

## CID 产生什么信息

| 场景 | CID 的作用 |
| --- | --- |
| 肽段鉴定 | 产生 b/y 离子，用于数据库搜索 |
| 小分子解析 | 产生特征碎片，支持结构候选 |
| SRM/MRM | 产生可监测的 product ions |
| PRM | 产生目标前体的碎片全谱 |
| DIA | 在窗口内碎裂多个前体离子，后续算法解析碎片 |

## 碰撞能量为什么重要

Collision energy（CE，碰撞能量）控制碎裂程度。能量太低，前体离子碎裂不足，产物离子弱；能量太高，碎裂过度，目标碎片可能减少，低质量噪声增加。

| CE 情况 | 可能结果 |
| --- | --- |
| 太低 | 前体残留多，碎片少，谱图信息不足 |
| 合适 | 目标产物离子强，谱图可解释 |
| 太高 | 过度碎裂，定量 transition 不稳定 |
| 不同仪器直接照搬 | 结果可能不可比，需要重新优化 |

## CID、HCD、ETD 的区别

| 方式 | 全称 | 特点 |
| --- | --- | --- |
| CID | collision-induced dissociation，碰撞诱导解离 | 经典碰撞碎裂，三重四极杆、离子阱等常见 |
| HCD | higher-energy collisional dissociation，高能碰撞解离 | Orbitrap 平台常见，TMT reporter ion 友好 |
| ETD | electron-transfer dissociation，电子转移解离 | 对某些易碎 PTM 更友好，常用于修饰肽段 |

不同碎裂方式不是“谁更高级”，而是适合不同目标。常规肽段鉴定常用 CID/HCD；如果关心糖基化、磷酸化等易碎修饰，有时会考虑 ETD 或 EThcD。

## 常见问题

| 问题 | 可能原因 | 处理思路 |
| --- | --- | --- |
| 碎片太少 | CE 太低，前体隔离不准，信号太弱 | 优化 CE、提高目标信号 |
| 谱图噪声高 | CE 太高或共隔离干扰 | 降低 CE，缩小隔离窗口，改善 LC |
| MRM 定量不稳定 | product ion 选择不佳或 CE 未优化 | 重新筛选 transition 和 CE |
| 修饰位点定位差 | 碎片不覆盖修饰区域 | 尝试不同碎裂方式或更高质量 MS/MS |
| 方法转移失败 | 不同仪器 CE 标尺不同 | 在新平台重新优化 CE |

## 小结

CID 是 MS/MS 中最常见的碎裂逻辑之一：把前体离子撞碎，再看产物离子。它是肽段鉴定、结构解析和 MRM/PRM/DIA 的基础。真正影响结果的不是“有没有 CID”，而是前体选择、碰撞能量、隔离窗口、共洗脱干扰和产物离子选择是否合理。
