# 非特异性结合

Non-specific binding（非特异性结合）是指抗体、探针、蛋白、核酸或小分子与非目标对象发生结合或吸附的现象；它是 [背景信号](背景信号.md)、假阳性和重复性差的常见来源。

## 一句话理解

非特异性结合就是“试剂抓到了不该抓的东西，或者粘到了不该粘的位置”。

BioLegend 的 sandwich ELISA protocol 中包含 blocking（封闭）和 washing（洗涤）步骤，本质上就是为了减少未占据表面和未结合检测组分带来的非特异信号。参考：[BioLegend sandwich ELISA protocol](https://www.biolegend.com/en-us/protocols/sandwich-elisa-protocol)。

## 常见类型

| 类型 | 例子 | 结果 |
| --- | --- | --- |
| 表面吸附 | 抗体粘到板、膜、管壁或细胞碎片 | 背景升高 |
| 交叉反应 | 抗体识别相似蛋白或同源家族 | 假阳性 |
| Fc 相关结合 | 免疫细胞 Fc 受体抓住抗体 Fc | 流式或组织染色背景高 |
| 电荷/疏水吸附 | 带电或疏水分子互相吸附 | 洗不干净、重复性差 |
| 基质干扰 | 血清、裂解液、脂质、异嗜性抗体干扰 | 标准曲线和样本不一致 |

## 和特异性的区别

| 项目 | 非特异性结合 | [特异性](特异性.md) |
| --- | --- | --- |
| 关注点 | 不该结合的结合 | 是否只识别目标 |
| 结果 | 背景高、假阳性 | 结果可信度 |
| 常见处理 | 封闭、洗涤、稀释、加竞争物 | 验证抗体或方法本身 |
| 是否一定能通过洗涤解决 | 不一定 | 不适用 |

如果抗体本身识别了错误目标，单纯增强洗涤可能只能降低一部分背景，不能真正解决特异性问题。

## 常见控制方法

| 方法 | 作用 |
| --- | --- |
| [封闭液](<../../材(实验耗材工具篇)/封闭液.md>) | 占据板面、膜或组织中的非目标结合位点 |
| [PBST](<../../材(实验耗材工具篇)/PBST.md>) 或 [TBST](<../../材(实验耗材工具篇)/TBST.md>) | 表面活性剂帮助洗掉弱非特异吸附 |
| 抗体滴度 | 找到信号和背景的平衡浓度 |
| Fc block | 降低 Fc 受体相关结合 |
| 交叉吸附二抗 | 降低二抗识别非目标 Ig |
| carrier-only 对照 | 半抗原实验中排除抗 carrier 反应 |
| 基质匹配 | 降低样本基质和标准品差异 |

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 增加洗涤后真信号也消失 | 目标结合本身较弱 | 优化抗体亲和力、孵育时间和洗涤强度 |
| 换封闭液后背景改善 | 原封闭体系不适合 | 固定使用改善后的封闭条件并记录 |
| 二抗 alone 也有信号 | 二抗非特异结合或交叉识别 | 换交叉吸附二抗，降低浓度 |
| 阴性样本仍高 | 基质干扰或特异性差 | 做样本稀释、竞争或换抗体 |
| 多重染色串扰 | 二抗交叉或荧光串色 | 使用直接标记抗体或优化通道设置 |

## 小结

非特异性结合是很多“看起来有信号”的假象来源。排查时要区分表面吸附、交叉反应、Fc 受体结合和基质干扰，不同来源对应的解决办法不一样。
