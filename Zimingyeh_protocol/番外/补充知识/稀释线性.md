# 稀释线性

Dilution linearity（稀释线性）是指样本经过系列稀释后，按稀释倍数回算得到的原始浓度应保持一致的性质；它用于判断样本是否处在可定量范围内，以及基质效应或高剂量效应是否影响检测。

## 一句话理解

稀释线性回答的问题是：“同一个样本稀释 2 倍、4 倍、8 倍以后，换算回原液浓度还一致吗？”

在 [ELISA](<../../用(实验流程内容篇)/ELISA.md>) 中，如果样本系列稀释后回算浓度不一致，说明样本可能受到 [基质效应](基质效应.md)、[Hook效应](Hook效应.md)、吸附损失、目标物复合物状态或曲线范围问题影响。

ICH M10 在 ligand binding assays（LBA，配体结合分析）中明确要求关注 dilution linearity and hook effect（稀释线性和钩状效应），尤其是高浓度样本稀释后进入校准范围的情况。参考：[ICH M10 Bioanalytical Method Validation](https://database.ich.org/sites/default/files/M10_Guideline_Step4_2022_0524.pdf)。

## 基本做法

常见设计：

```text
样本原液
→ 2× 稀释
→ 4× 稀释
→ 8× 稀释
→ 16× 稀释

每个稀释点测得浓度 × 稀释倍数
→ 回算原液浓度
→ 比较是否一致
```

稀释点必须落在 [LOQ](LOQ.md) 可定量范围内。低于 LLOQ 或高于 ULOQ 的点不能用来判断线性。

## 判断逻辑

| 结果 | 可能解释 |
| --- | --- |
| 回算浓度一致 | 样本稀释行为良好 |
| 稀释后回算浓度升高 | 原液可能受 Hook effect 或基质抑制 |
| 稀释后回算浓度降低 | 稀释导致目标物吸附损失或低于 LLOQ |
| 只有中间稀释点一致 | 最佳稀释范围在中间 |
| 各样本表现差异大 | 个体样本基质差异明显 |

稀释线性好的样本，通常更适合做绝对定量；稀释线性差的样本，即使单个 OD 落在曲线范围内，也要谨慎解释。

## 和平行性的关系

Parallelism（平行性）更强调样本稀释曲线是否和标准曲线形状平行。稀释线性更多关注回算浓度是否一致。两者常一起用于免疫检测方法验证。

| 项目 | 稀释线性 | 平行性 |
| --- | --- | --- |
| 重点 | 回算原液浓度是否一致 | 样本稀释曲线是否平行于标准曲线 |
| 常见用途 | 确定样本最佳稀释倍数 | 判断标准品是否代表真实样本 |
| 风险提示 | 基质效应、Hook effect | 标准品和样本抗原形态不同 |

## 实验设计建议

- 先预估样本浓度，避免全部点都出范围。
- 至少设置 3-4 个稀释倍数。
- 稀释液优先使用 kit 推荐的 [样本稀释液](<../../材(实验耗材工具篇)/样本稀释液.md>)。
- 使用低吸附管，尤其是低丰度蛋白。
- 每个稀释点做复孔。
- 记录实际稀释步骤，不只写最终倍数。
- 与 spike-and-recovery 一起解释。

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 原液低、稀释后高 | Hook effect 或基质抑制解除 | 增加预稀释，确认高剂量范围 |
| 稀释越多回算越低 | 目标物吸附损失或低于 LLOQ | 加载体蛋白，减少过度稀释 |
| 点间无规律 | 移液误差或样本不均一 | 重新混匀样本，增加复孔 |
| 标准曲线好但样本不线性 | 标准品和真实样本基质不同 | 做基质匹配或换稀释液 |
| 不同样本最佳稀释不同 | 个体基质差异 | 分样本类型建立稀释策略 |

## 小结

稀释线性是 ELISA 中判断样本“能不能被可靠稀释并回算”的关键检查。它能揭露 Hook effect、基质效应和曲线范围问题，是未知样本定量前非常值得做的小实验。
