# 溶剂对照

Vehicle control（溶剂对照，也称载体对照）是在小分子、药物或刺激物处理实验中，只加入与实验组相同体积和浓度的溶剂，而不加入有效小分子的对照；它用于判断观察到的效应是否来自溶剂本身。

## 一句话理解

溶剂对照回答的是：“细胞变化是药物造成的，还是溶剂造成的？”

在 [小分子](小分子.md) 处理实验中，很多化合物需要用 [DMSO](<../../材(实验耗材工具篇)/DMSO.md>)、乙醇、水或其他溶剂配制 stock。溶剂本身可能影响细胞活性、膜状态、基因表达、蛋白磷酸化或检测读数，因此必须设置 vehicle control。

## 溶剂对照怎么设置

原则：实验组和溶剂对照中的最终溶剂浓度必须完全一致。

例如：

```text
药物 stock：10 mM in DMSO
实验组：10 μM 药物，最终 DMSO 0.1%
溶剂对照：0 μM 药物，最终 DMSO 0.1%
```

如果不同药物组加入的 stock 体积不同，应把所有组的最终溶剂浓度统一到最高组，而不是让每组 DMSO 浓度不同。

## 常见场景

| 场景 | 溶剂对照 |
| --- | --- |
| 细胞药物处理 | DMSO-only |
| 激素处理 | ethanol-only 或 DMSO-only |
| 水溶性刺激物 | buffer-only 或 water-only |
| 多药比较 | matched vehicle for each solvent |
| 时间梯度 | 每个时间点都需要 vehicle |

## 和阴性对照的关系

| 项目 | 溶剂对照 | [阴性对照](阴性对照.md) |
| --- | --- | --- |
| 是否含溶剂 | 是，且与实验组匹配 | 不一定 |
| 主要问题 | 溶剂是否造成效应 | 没有目标/处理时是否假阳性 |
| 常见场景 | 小分子处理、药物实验 | 检测实验、染色、qPCR、ELISA |
| 是否可作为阴性对照 | 常常可以，但需说明 | 更广泛 |

溶剂对照不是“未处理对照”。未处理细胞完全不加溶剂，vehicle control 加了溶剂；如果溶剂有影响，两者结果会不同。

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 溶剂对照也影响细胞 | 溶剂浓度过高或细胞敏感 | 降低最终溶剂浓度 |
| 实验组和对照溶剂浓度不同 | stock 配制或加样体积不一致 | 重新计算并统一 vehicle |
| 未处理和 vehicle 差异大 | 溶剂本身有生物学效应 | 后续比较应以 vehicle 为主 |
| 多药比较不可比 | 不同溶剂或 vehicle 不匹配 | 分别设置匹配 vehicle |
| qPCR 结果全变 | DMSO/乙醇影响基因表达 | 记录 vehicle 效应，重新设计浓度 |

## 小结

溶剂对照是小分子处理实验的基本控制。比较药物效应时，应优先和匹配 vehicle control 比，而不是简单和未处理组比。
