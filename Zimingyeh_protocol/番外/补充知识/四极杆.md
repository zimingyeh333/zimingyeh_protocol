# 四极杆

Quadrupole（四极杆）是一类由四根电极产生振荡电场来选择或过滤特定 m/z 离子的 [质量分析器](质量分析器.md)。它可以作为单四极杆、三重四极杆中的 Q1/Q3，也可以和 TOF、Orbitrap 等组合成混合质谱平台。

## 基本原理

四极杆通过射频电压和直流电压形成电场。对于某一组电压条件，只有特定 m/z 范围内的离子能稳定通过，其余离子轨迹不稳定而被过滤掉。因此四极杆既可以扫描一段 m/z，也可以固定在某个 m/z 只让目标离子通过。

Thermo Fisher 的质谱技术概览把 quadrupoles（四极杆）列为常见质量分析器，并指出 quadrupoles 常用于 quantitative studies（定量研究）。参考：[Thermo Fisher Mass Spectrometry Technology Overview](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/mass-spectrometry-learning-center/mass-spectrometry-technology-overview.html)

## 四极杆能做什么

| 模式 | 做法 | 用途 |
| --- | --- | --- |
| Scan | 连续扫描 m/z 范围 | 获取目标范围内的谱图 |
| SIM | selected ion monitoring（选择离子监测） | 只监测少数目标 m/z，提高灵敏度 |
| Q1 selection | 在 MS/MS 前选择前体离子 | Q-TOF、三重四极杆、Orbitrap 混合平台 |
| Q3 filtering | 选择产物离子 | SRM/MRM 靶向定量 |
| Collision cell 前后选择 | Q1 选前体，Q2 碎裂，Q3 选碎片 | 三重四极杆定量核心 |

## 在不同仪器中的角色

| 仪器 | 四极杆角色 |
| --- | --- |
| [三重四极杆质谱仪](<../../材(实验耗材工具篇)/三重四极杆质谱仪.md>) | Q1 选前体，Q2 碰撞，Q3 选产物离子 |
| [Q-TOF](<../../材(实验耗材工具篇)/Q-TOF.md>) | 前端四极杆选择前体，TOF 测准确质量 |
| Quadrupole-Orbitrap | 前端四极杆选择前体，Orbitrap 高分辨检测 |
| 单四极杆 MS | 扫描或监测目标离子，常用于较简单定量/检测 |

## 和高分辨质量分析器的区别

| 项目 | 四极杆 | Orbitrap / TOF |
| --- | --- | --- |
| 核心能力 | 选择和过滤 m/z | 高分辨测量 m/z |
| 强项 | 靶向、速度、定量稳定 | 准确质量、全扫描、未知解析 |
| 数据形态 | 选定 m/z 或 transition | 全谱或高分辨 MS/MS |
| 常见用途 | SIM、SRM/MRM、前体选择 | HRMS、DDA、DIA、PRM |

四极杆不是“低级”的质量分析器。它的价值在于选择性和靶向能力，尤其在三重四极杆里能把复杂样本中的目标 transition 以很高重复性监测出来。

## 常见误解

| 误解 | 更准确的理解 |
| --- | --- |
| 四极杆只能做低端质谱 | 它也是 Q-TOF、Q-Orbitrap 和三重四极杆的关键模块 |
| 四极杆没有发现能力 | 可以扫描，但发现深度通常不如高分辨全扫描平台 |
| 三重四极杆就是三个普通四极杆 | Q2 通常作为碰撞池，功能与 Q1/Q3 不同 |
| MRM 有峰就一定确认结构 | 仍需 transition 特异性、离子比、保留时间和内标支持 |

## 小结

四极杆的关键词是“选择”和“过滤”。它不一定追求最高分辨率，却是靶向定量和混合质谱前体选择的核心。理解四极杆，就能更好理解 Q-TOF、三重四极杆和 Q-Orbitrap 的采集逻辑。
