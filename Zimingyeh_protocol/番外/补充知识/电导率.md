# 电导率

Conductivity（电导率）描述溶液传导电流的能力，常用单位是 µS/cm 或 mS/cm。在实验室里，它常用于判断水质、盐溶液浓度、缓冲液批间一致性和清洗残留，但它不能直接告诉你 pH、[渗透压](渗透压.md)、[离子强度](离子强度.md) 或溶液密度。

## 定义与命名

电导率的英文常写作 conductivity 或 electrolytic conductivity。IUPAC Gold Book 对 electrolytic conductivity 的定义强调它与 conductance（电导）和 cell constant（电导池常数）相关。参考：[IUPAC Gold Book electrolytic conductivity](https://goldbook.iupac.org/terms/view/E01927/pdf)。

常见单位：

| 单位 | 说明 |
| --- | --- |
| µS/cm | microsiemens per centimeter，常用于低电导样品 |
| mS/cm | millisiemens per centimeter，常用于缓冲液/盐溶液 |
| S/m | SI 单位，物理化学和工程资料常见 |
| MΩ·cm | 电阻率，常用于超纯水系统 |

电导率受 temperature（温度）强烈影响，所以读数必须和温度一起记录。

## 电导率来自哪里

溶液能导电，是因为离子可以移动。影响电导率的因素包括：

| 因素 | 影响 |
| --- | --- |
| 离子浓度 | 离子越多，通常导电能力越强 |
| 离子电荷 | 高价离子贡献更复杂，不只是数量问题 |
| 离子迁移率 | H+、OH-、Na+、Cl-、Mg2+ 等移动速度不同 |
| 温度 | 温度升高通常会提高离子迁移率 |
| 黏度/溶剂 | 高黏度或非水体系会影响迁移 |
| 离子缔合 | 高浓度下离子间相互作用会改变线性关系 |

因此，电导率不是“盐浓度”的完美同义词。它更像一个快速质控信号：如果某个固定配方的电导率突然偏离历史范围，说明配制、稀释、水质或污染可能出了问题。

## 常见实验场景

| 场景 | 电导率能告诉你什么 |
| --- | --- |
| [超纯水](<../../材(实验耗材工具篇)/超纯水.md>) | 是否有离子污染 |
| [PBS](<../../材(实验耗材工具篇)/PBS.md>) / [DPBS](<../../材(实验耗材工具篇)/DPBS.md>) | 盐浓度或稀释倍数是否明显异常 |
| 电泳缓冲液 | 使用次数、稀释错误或盐残留 |
| 清洗验证 | 最后冲洗液是否仍有离子残留 |
| 培养基 | 辅助发现无机盐异常，但不能替代渗透压 |
| [OptiPrep](<../../材(实验耗材工具篇)/OptiPrep.md>) / [Nycodenz](<../../材(实验耗材工具篇)/Nycodenz.md>) | 对非离子密度介质不是主要质控参数 |

对于非离子溶质，例如 [葡萄糖](<../../材(实验耗材工具篇)/葡萄糖.md>)、[蔗糖](<../../材(实验耗材工具篇)/蔗糖.md>)、[DMSO](<../../材(实验耗材工具篇)/DMSO.md>) 或碘化密度梯度介质，电导率可能变化不明显，但渗透压、折光率或密度可能已经明显改变。

## 电导率 vs 离子强度

电导率和离子强度都和离子有关，但不是同一个概念。

| 参数 | 取决于 | 关键差异 |
| --- | --- | --- |
| 电导率 | 离子浓度、电荷、迁移率、温度、黏度 | 强调“能不能导电、导电多快” |
| 离子强度 | 离子浓度和电荷平方 | 强调“电荷环境和静电屏蔽强度” |

例如 0.1 M NaCl 和 0.05 M MgCl2 的总溶质浓度不同、离子强度不同、电导率也不会简单按总浓度线性对应。二价离子对离子强度贡献更大，但不同离子的迁移率又会让电导率表现出另一套规律。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 超纯水电导率偏高 | 取样容器污染、CO2 溶入、系统污染 | 更换容器，缩短暴露，检查水系统 |
| PBS 电导率偏低 | 盐漏加、稀释过度、定容错误 | 复核配方和称量 |
| 电导率正常但细胞状态差 | 非离子溶质、pH、毒性或污染问题 | 同时检查 pH、渗透压和污染 |
| 同一样品读数波动 | 气泡、温度未平衡、探头污染 | 去泡、等温、清洁探头 |
| 用电导率推断所有溶质浓度 | 忽略非离子溶质 | 对糖、DMSO、蛋白等另用合适方法 |

## 小结

电导率是判断离子相关配制错误的快速参数，特别适合水质、盐溶液和缓冲液质控。但它不是 pH、渗透压、离子强度或折光率的替代品。可靠记录必须包含单位、温度、仪器、电导池常数、校准液和样品批号。
