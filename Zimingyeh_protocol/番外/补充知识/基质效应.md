# 基质效应

Matrix effect（基质效应）是指样本中除目标物以外的背景成分影响检测信号或定量结果的现象；在 ELISA 中，样本基质可能改变抗原-抗体结合、酶促显色、板面吸附、背景信号或标准曲线适用性。

图：ELISA 曲线拟合与基质验证。基质效应通常需要通过 spike-and-recovery 和 dilution linearity 这类实验来发现，而不是只看标准曲线。本图由 Image2 / image-generation model 生成，用于个人学习笔记示意。

## 一句话理解

基质效应回答的问题是：“标准品在缓冲液里测得很好，为什么真实样本不一定准？”

真实样本不是纯净缓冲液。血清、血浆、细胞培养上清、组织匀浆、尿液、裂解液中可能有高蛋白、脂质、盐、补体、异嗜性抗体、内源性酶、药物、去污剂或细胞碎片。这些东西会让同一个目标物在样本中表现得不像标准品。

ICH M10 在生物分析方法验证中把 matrix effects、selectivity、dilution linearity 和样本稳定性都视为影响方法可靠性的关键因素。参考：[ICH M10 Bioanalytical Method Validation](https://database.ich.org/sites/default/files/M10_Guideline_Step4_2022_0524.pdf)。

## 常见来源

| 样本基质 | 可能干扰 |
| --- | --- |
| Serum/plasma（血清/血浆） | 高蛋白、脂血、溶血、补体、异嗜性抗体 |
| Cell culture supernatant（细胞培养上清） | 血清、培养基成分、酚红、细胞代谢物 |
| Tissue homogenate（组织匀浆） | 蛋白酶、脂质、细胞碎片、裂解液 |
| Cell lysate（细胞裂解液） | 去污剂、盐、还原剂、核酸粘度 |
| Urine（尿液） | 盐度、pH、低蛋白背景差异 |

不同样本类型不能默认共用同一条解释逻辑。即使使用同一 kit，血清和细胞上清的结果也应分别验证。

## 表现形式

| 表现 | 可能含义 |
| --- | --- |
| 标准曲线正常但样本异常低 | 基质抑制结合或显色 |
| 样本稀释后回算浓度升高 | 基质抑制被稀释解除，或 Hook effect |
| 加标回收率低 | 加入目标物测不回来 |
| 加标回收率高 | 基质增强或背景扣除错误 |
| 不同样本批次差异大 | 基质组成不同 |
| 空白样本也有高信号 | 非特异性结合或交叉反应 |

## 如何验证

最常用三类检查：

| 方法 | 目的 |
| --- | --- |
| [Spike-and-recovery](Spike-and-recovery.md) | 检查已知加标能否被测回 |
| [稀释线性](稀释线性.md) | 检查系列稀释后回算是否一致 |
| 基质匹配标准曲线 | 让标准品和样本处在相似背景中 |

如果三者都提示问题，就不能只靠换拟合模型解决。模型只能拟合标准点，不能消除样本基质造成的系统偏差。

## 减少基质效应的策略

| 策略 | 适用场景 | 注意事项 |
| --- | --- | --- |
| 增加样本稀释倍数 | 基质抑制明显 | 不能稀释到低于 LLOQ |
| 使用专用 [样本稀释液](<../../材(实验耗材工具篇)/样本稀释液.md>) | 血清、血浆、复杂样本 | 优先按 kit 说明书 |
| 基质匹配标准品 | 样本基质稳定且可获得 | 需要确认空白基质无目标物 |
| 去除干扰成分 | 脂血、细胞碎片、沉淀 | 可能同时损失目标物 |
| 使用低吸附耗材 | 低丰度蛋白 | 防止稀释过程吸附损失 |
| 设置质控样本 | 长期项目 | 监控批间和板间漂移 |

## 和 Hook effect 的区别

| 项目 | 基质效应 | [Hook效应](Hook效应.md) |
| --- | --- | --- |
| 主要来源 | 样本背景成分 | 目标抗原过量 |
| 典型发现 | 加标回收差、稀释不线性 | 高浓度样本稀释后回算升高 |
| 解决方式 | 稀释、基质匹配、换稀释液 | 预稀释进入范围 |
| 是否只发生在夹心法 | 否 | 主要见于夹心免疫检测 |

实际实验中两者可以同时存在，所以未知高浓度复杂样本最好做稀释梯度。

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 样本全都偏低 | 基质抑制 | 增加稀释倍数，换样本稀释液 |
| 只有某些样本异常 | 个体基质差异、溶血、脂血 | 标记样本状态，必要时排除或复测 |
| 回收率高 | 背景扣除或交叉反应 | 检查空白基质和阴性对照 |
| 稀释线性差 | 基质效应、Hook effect 或吸附 | 做更多稀释点并观察趋势 |
| 不同样本类型不可比 | 基质不同 | 分样本类型建立验证和报告规则 |

## 小结

基质效应是 ELISA 中“标准曲线很好但样本不准”的核心原因之一。真实样本越复杂，越不能只相信缓冲液标准曲线；需要用回收率、稀释线性和质控样本证明结果能被解释。
