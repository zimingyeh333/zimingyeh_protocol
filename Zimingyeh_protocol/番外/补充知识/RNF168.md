# RNF168

RNF168（RING finger protein 168，RING 指蛋白 168）是 DNA double-strand break（DSB，DNA 双链断裂）染色质应答中的 RING-type ubiquitin E3 ligase（RING 型泛素 E3 连接酶）。它读取上游泛素信号，并在断裂邻近的 H2A/H2AX 上写入 H2AK13ub/H2AK15ub，形成可被 [53BP1](53BP1.md) 与 [BARD1](BARD1.md) 等蛋白识别的损伤地址。

RNF168 既是 writer（写入者），也是 amplifier（放大器），但它不是决定 HR 或 NHEJ 的单独开关。相同的 H2AK15ub 可在不同染色质与细胞周期背景中分别支持 53BP1 或 BRCA1–BARD1 募集。

## RNF8–RNF168 是分层级联，不是同一个酶

DSB 发生后，MRE11–RAD50–NBS1（MRN）复合物与 [ATM（ataxia-telangiectasia mutated，毛细血管扩张性共济失调突变蛋白）](ATM通路.md)启动染色质信号：

- ATM 磷酸化 histone H2A.X（组蛋白 H2AX），形成 γH2AX。
- MDC1（mediator of DNA damage checkpoint protein 1，DNA 损伤检查点介质蛋白 1）结合 γH2AX，并为 RNF8 募集提供平台。
- RNF8 与 E2 泛素结合酶建立 K63-linked ubiquitin（K63 连接型泛素）支架，其中 histone H1（组蛋白 H1）是重要上游底物之一。
- RNF168 通过 ubiquitin-dependent DSB recruitment modules（UDM，泛素依赖 DSB 募集模块）读取这些信号，进入损伤染色质。
- RNF168 RING domain（RING 结构域）将 ubiquitin（泛素）写到 H2A/H2AX 的 K13/K15，并通过结合自身产物继续放大局部信号。

早期工作首先建立了 RNF168 在 RNF8 下游结合并放大损伤染色质泛素信号的框架。参考：[Doil et al., Cell, 2009](https://doi.org/10.1016/j.cell.2008.12.041)。随后底物定位研究明确 RNF168 主要修饰 H2A/H2AX K13–K15，而不是 Polycomb 常用的 H2AK119。参考：[Mattiroli et al., Cell, 2012](https://doi.org/10.1016/j.cell.2012.08.005)。

## 关键结构与功能模块

| RNF168 模块 | 主要作用 | 实验解释 |
| --- | --- | --- |
| RING domain（RING 结构域） | 结合 E2 并催化 H2A/H2AX K13/K15 泛素化 | RING 突变可能保留部分募集，却丢失写入能力 |
| UDM1（ubiquitin-dependent DSB recruitment module 1，泛素依赖 DSB 募集模块 1） | 读取 RNF8 依赖的上游泛素支架 | 缺陷时 RNF168 难以有效进入初始损伤染色质 |
| UDM2（ubiquitin-dependent DSB recruitment module 2） | 结合 H2AK15ub 等 RNF168 相关产物，帮助信号扩增 | 影响损伤停留、扩散与放大，而非仅影响总蛋白量 |
| RING–核小体 acidic patch（酸性表面）界面 | 将 E2–ubiquitin 定位到 H2A K13/K15 | 解释了 RNF168 与其他 H2A E3 连接酶的位点选择差异 |

RNF168 RING domain 通过核小体 acidic patch 定位 H2A K13/K15 的结构证据见 [Horn et al., Nature Communications, 2019](https://doi.org/10.1038/s41467-019-09756-z)。

## H2AK15ub 是公共损伤地址

H2AK15ub 可被多个具有不同通路倾向的 reader（读取蛋白）识别：

| Reader | 与 H2AK15ub 协同读取的信号 | 主要通路结果 |
| --- | --- | --- |
| 53BP1 UDR | H4K20me2 | 募集 RIF1–Shieldin，限制 [DNA 末端切除](DNA末端切除.md)并支持 c-NHEJ |
| BARD1 BUDR | H4K20me0 | 募集 BRCA1–BARD1，在复制后染色质中促进 [homologous recombination（HR，同源重组）](同源重组.md) |

因此不能写成“RNF168 促进 NHEJ”或“RNF168 促进 HR”而不说明实验背景。RNF168 先建立共享地址，H4K20 状态、细胞周期、蛋白竞争、断端结构和下游效应网络再塑造结果。BARD1 读取 H2AK15ub 的直接证据见 [Becker et al., Nature, 2021](https://doi.org/10.1038/s41586-021-03776-w)。

## 信号必须被限制在合适的强度与空间

损伤染色质泛素化需要足够强，才能稳定募集 53BP1、BRCA1–BARD1 等因子；但过量或过度扩散也可能改变正常路径选择、扩大修复焦点或增加错误末端连接。

RNF168 的表达、募集与产物受多层调控：

- E3 连接酶与 deubiquitinase（DUB，去泛素化酶）共同决定 H2AK13/15ub 的建立和擦除。
- RNF168 自身蛋白稳定性与染色质停留时间影响信号阈值。
- RNF8、MDC1 或 γH2AX 缺陷可减少经典 RNF168 募集，但不同损伤与细胞背景可能保留替代性信号。
- 外源 RNF168 过表达可能产生比内源水平更广的泛素化和 53BP1 聚集，不能直接当作生理增益。

RNF168/53BP1 过表达可增加某些突变性 NHEJ，而不一定增强生理性末端连接。参考：[Zong et al., Nucleic Acids Research, 2015](https://doi.org/10.1093/nar/gkv336)。

## 遗传缺陷与 RIDDLE 综合征

双等位基因 RNF168 功能缺失可导致 RIDDLE syndrome（radiosensitivity, immunodeficiency, dysmorphic features and learning difficulties syndrome，放射敏感、免疫缺陷、畸形特征与学习困难综合征）。患者细胞可出现损伤染色质泛素信号和 53BP1/BRCA1 募集异常。参考：[Stewart et al., Cell, 2009](https://doi.org/10.1016/j.cell.2008.12.042)。

这一关系说明 RNF168 不是只在体外焦点实验中有意义，而是连接 DSB 信号、免疫受体重排、放射敏感性和基因组稳定性的生理节点。机制笔记不能代替罕见病诊断或临床变异解释。

## RNF8、RNF168、53BP1 与 BARD1 的区别

| 因子 | 核心动作 | 是否直接决定修复通路 | 典型误读 |
| --- | --- | --- | --- |
| RNF8 | 建立上游泛素支架并募集 RNF168 | 否 | 与 RNF168 是同一个 E3 |
| RNF168 | 写入/放大 H2AK13/15ub | 否 | H2AK15ub 只服务 53BP1 |
| 53BP1 | 读取 H2AK15ub+H4K20me2，组织末端保护 | 是重要偏置器，但不是连接酶 | 自己直接连接 DNA |
| BARD1 | 读取 H2AK15ub+H4K20me0，定位 BRCA1–BARD1 | 是 HR 环境的重要偏置器，但不是核酸酶 | 自己直接切除 DNA |

## 实验中如何观察 RNF168

| 问题 | 推荐读数 | 能回答什么 | 关键限制 |
| --- | --- | --- | --- |
| 蛋白是否表达 | [Western blot](<../../用(实验流程内容篇)/Western blot.md>) | RNF168 总量、截短和回补表达 | 过表达会改变焦点与泛素信号阈值 |
| 是否进入损伤染色质 | [免疫荧光](<../../用(实验流程内容篇)/免疫荧光.md>)、[激光微照射](<../../用(实验流程内容篇)/激光微照射.md>) | RNF168 focus/轨迹募集与时序 | 标签、表达量、损伤类型和预抽提可改变结果 |
| 是否写入 H2AK13/15ub | 修饰特异抗体、核小体泛素化 assay | 催化产物是否建立 | 抗体需区分 H2AK13/15ub 与 H2AK119ub |
| 下游 reader 是否到场 | 53BP1、BARD1/BRCA1 focus | 泛素地址是否可被读取 | 下游缺陷也可导致焦点低，不能只归因于 RNF168 |
| 通路输出如何变化 | HR/NHEJ [报告基因实验](<../../用(实验流程内容篇)/报告基因实验.md>)、RPA/RAD51 focus | 背景依赖的路径结果 | 单一 reporter 不能覆盖复杂断端与全基因组重排 |
| 是否影响生存 | 电离辐射、PARP 抑制剂、顺铂克隆形成 | 整合性损伤应答 | 药敏不能区分信号、复制叉和细胞死亡支路 |

### 推荐的最小证据组合

- 同时检测 RNF168 总量、RNF168 focus、H2AK13/15ub 和 53BP1/BARD1 下游募集。
- 使用 RNF168 缺失、野生型回补、RING-dead 与 UDM 招募突变体区分“到场”和“催化”。
- 严格匹配回补表达量，避免过表达把局部损伤信号变成全核泛素化。
- 解释 HR/NHEJ 时加入 [细胞周期](细胞周期.md)、H4K20 状态、RPA/RAD51 和修复产物证据。

## 常见误读与 troubleshooting

| 观察 | 不应立即得出的结论 | 优先排查 |
| --- | --- | --- |
| RNF168 focus 正常 | 泛素化功能一定正常 | RING 活性、H2AK13/15ub 与 reader 招募 |
| 53BP1 focus 减少 | RNF168 一定缺失 | RNF8、H4K20me2、53BP1 Tudor/UDR、抗体和细胞周期 |
| BRCA1 focus 减少 | HR 一定完全丧失 | BARD1、PALB2/RAD51、残余募集与 HR reporter |
| RNF168 过表达增加焦点 | 修复能力提高 | 异常泛素扩散、突变性 NHEJ 与基因组重排 |
| H2AK15ub 增加 | 修复方向已确定 | 53BP1/BARD1 比例、H4K20 状态与细胞周期 |

## 小结

RNF168 是 DSB 染色质泛素地址的写入与放大节点。它在 RNF8 下游将 H2A/H2AX K13/K15 泛素化，为 53BP1 和 BARD1–BRCA1 提供共享的损伤标记；实验上必须把 RNF168 招募、E3 活性、H2AK13/15ub、reader 募集和最终修复产物分层观察。
