# 紫外成像

紫外成像（UV imaging / ultraviolet transillumination）是在 UV 光源下激发核酸染料，使凝胶中的 DNA/RNA 条带发出荧光的成像方式。它是 [EB](<../../材(实验耗材工具篇)/EB.md>)、[GelRed](<../../材(实验耗材工具篇)/GelRed.md>) 和很多传统 [琼脂糖凝胶电泳](<../../用(实验流程内容篇)/琼脂糖凝胶电泳.md>) 系统的经典读出方式。

## 为什么 UV 成像仍然常见

UV 成像历史久、设备普及、与 EtBr/EtBr-like 红色染料兼容性好，因此很多实验室仍把它作为常规跑胶成像方式。对于只需要快速检查 PCR 是否有条带，UV 可以很方便；但对于需要胶回收和克隆的 DNA，UV 暴露会增加 DNA 损伤风险。

Thermo Fisher 的 Ethidium Bromide 页面将 EtBr 描述为用于 DNA/RNA gel visualization 的经典荧光染料，并给出 UV 激发和橙红发射信息，同时提醒 EtBr 是 potent mutagen，需要谨慎处理。参考：[Thermo Fisher Ethidium Bromide Stain](https://www.thermofisher.cn/cn/en/home/life-science/dna-rna-purification-analysis/nucleic-acid-gel-electrophoresis/dna-stains/etbr.html)。

## 适合场景

| 场景 | 为什么常用 UV |
| --- | --- |
| EB/EtBr 成像 | EtBr 在 UV 下橙红发光，老设备兼容 |
| GelRed 成像 | GelRed 常可用 UV 和 EtBr filter |
| 常规 PCR 检查 | 快速、设备普及 |
| 教学演示 | 条带容易观察，但必须强调防护 |

## 主要风险

| 风险 | 结果 | 控制方法 |
| --- | --- | --- |
| 眼睛/皮肤暴露 | 急性损伤风险 | 使用防护屏、护目镜、面罩和手套 |
| DNA 损伤 | 影响克隆、连接、测序或建库 | 缩短曝光，改用 [蓝光成像](蓝光成像.md) |
| EtBr 污染 | 危险废弃物和交叉污染 | 固定操作区，按 EHS/SDS 处理 |
| 图像饱和 | 条带强度不可半定量 | 降低曝光或增益 |

## 与蓝光成像对比

| 项目 | 紫外成像 | 蓝光成像 |
| --- | --- | --- |
| 优势 | 设备普及，适合 EtBr/GelRed 红色体系 | 对 DNA 和操作者更友好 |
| 劣势 | UV 损伤和安全压力更高 | 需要匹配蓝光染料和滤光片 |
| 胶回收 | 尽量缩短 UV 暴露 | 更推荐 |
| 记录重点 | UV 波长、曝光时间、防护和染料 | 光源、滤片和染料 |

## 小结

UV 成像是经典且好用的凝胶成像方式，但不是没有代价。凡是涉及胶回收、克隆、建库或长时间观察，都应优先考虑缩短 UV 暴露或改用蓝光体系。
