# 表位

Epitope（表位，也称 antigenic determinant，抗原决定簇）是 [抗原](抗原.md) 上被抗体、BCR 或 TCR 实际识别和结合的局部结构；它是抗体实验中决定“能不能识别、识别哪一种形态、能不能配对”的核心概念。

![Antibody recognition basics](../../z_asset/番外/补充知识/抗体识别基础/antibody-recognition-basics-reference.png)

图：抗体识别基础示意。夹心 ELISA 需要捕获抗体和检测抗体识别 non-overlapping epitopes（不重叠表位），否则两支抗体会相互竞争。本图复用项目内 Image2 / image-generation model 生成图，用于个人学习笔记示意。

## 一句话理解

抗原是“整个人”，表位是抗体真正握住的“局部特征”。

Janeway Immunobiology 解释抗体识别时强调，抗体抗原结合位点与抗原表面的具体结构结合；一个大分子抗原可以包含多个不同表位。参考：[NCBI Bookshelf: Antigen recognition by B-cell and T-cell receptors](https://www.ncbi.nlm.nih.gov/books/NBK27160/)。

## 表位类型

| 表位类型 | 英文 | 特点 | 常见实验影响 |
| --- | --- | --- | --- |
| 线性表位 | Linear epitope | 由连续氨基酸序列构成 | 变性 WB 中更容易保留 |
| 构象表位 | Conformational epitope | 由蛋白三维折叠形成，氨基酸可不连续 | IF、IHC、ELISA、流式中常重要 |
| 修饰表位 | Modification-specific epitope | 依赖磷酸化、乙酰化、糖基化等修饰 | 磷酸化抗体、修饰特异抗体 |
| 新生表位 | Neoepitope | 裂解、突变或构象变化后出现 | 活化、凋亡或疾病标志物检测 |

一支抗体能用于 Western blot，不代表它一定能用于免疫荧光；因为 WB 常检测变性蛋白，而 IF/流式更依赖天然构象。

## 表位和配对抗体

在 [夹心ELISA](<../../用(实验流程内容篇)/夹心ELISA.md>) 中，[捕获抗体](<../../材(实验耗材工具篇)/捕获抗体.md>) 和 [检测抗体](<../../材(实验耗材工具篇)/检测抗体.md>) 必须能同时结合目标抗原。也就是说，它们识别的表位不能互相遮挡。

| 配对情况 | 结果 |
| --- | --- |
| 两支抗体识别不重叠表位 | 可形成夹心复合物 |
| 两支抗体识别同一表位 | 检测抗体无法再结合 |
| 表位距离太近或空间冲突 | 信号弱或曲线差 |
| 抗原太小只有一个表位 | 更适合竞争 ELISA |

这就是为什么单独买两支“anti-X”抗体，不等于它们能组成 [配对抗体](<../../材(实验耗材工具篇)/配对抗体.md>)。

## 表位暴露

抗体只有在表位暴露时才能结合。实验处理可能改变表位暴露：

- 固定可能遮蔽表位。
- 变性可能破坏构象表位。
- 抗原修复可能重新暴露组织表位。
- 还原剂可能破坏二硫键依赖构象。
- 标签或融合蛋白可能遮挡附近表位。
- 包被到板面可能改变蛋白方向。

因此抗体说明书里的 validated application（验证应用）非常重要。同一抗体在 WB、IHC、IF、flow cytometry 和 ELISA 中表现可以完全不同。

## 表位映射

Epitope mapping（表位映射）是确定抗体识别抗原哪个区域的实验策略。常见方法包括肽阵列、截短突变、点突变、竞争结合、结构生物学和质谱相关方法。

表位映射的价值：

- 判断抗体是否识别目标功能区域。
- 设计夹心 ELISA 抗体配对。
- 判断不同克隆是否竞争同一表位。
- 解释交叉反应。
- 选择适合 WB 或天然构象检测的抗体。

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| WB 有信号，流式无信号 | 抗体识别线性表位，天然构象中不可及 | 换验证过流式的抗体 |
| 夹心 ELISA 无信号 | 捕获和检测抗体表位重叠 | 更换配对抗体 |
| IHC 信号弱 | 固定遮蔽表位 | 优化抗原修复 |
| 突变体检测不到 | 突变破坏表位 | 选择识别其他区域的抗体 |
| 重组蛋白能识别，天然样本不能 | 标签/构象/修饰差异 | 用真实样本验证 |

## 小结

表位是抗体识别的最小实验逻辑单位。抗体是否能用、是否能配对、是否会交叉反应，很多时候都不是由“抗原名称”决定，而是由表位决定。
