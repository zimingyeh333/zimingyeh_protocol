# 扩增效率

Amplification efficiency（扩增效率）是指 PCR 每个循环中模板被扩增的实际倍增程度；在 qPCR 和 [RT-qPCR](<../../用(实验流程内容篇)/RT-qPCR.md>) 中，它决定 [Cq值](Cq值.md) 能否可靠地反映起始模板量。

## 一句话理解

扩增效率回答的是：“每循环真的接近翻倍了吗？”

MIQE 指南要求报告 qPCR assay efficiency（实验体系扩增效率）和测定方法，因为扩增效率会直接影响定量结果和样本间比较。参考：[MIQE guidelines, Clinical Chemistry 2009](https://academic.oup.com/clinchem/article/55/4/611/5631762)。

## 扩增效率怎么计算

qPCR 中常用 [标准曲线](标准曲线.md) 的斜率估算扩增效率。用模板做系列稀释，绘制 log 起始量和 Cq 的关系，得到 slope（斜率）。

常用公式：

```text
Efficiency = 10^(-1/slope) - 1
```

如果 slope 约为 -3.32，则效率约为 100%，表示每个循环理论上扩增约 2 倍。

| 斜率 | 粗略效率 | 解释 |
| --- | --- | --- |
| -3.32 | 100% | 理想接近每循环翻倍 |
| 比 -3.32 更负 | <100% | 扩增效率偏低 |
| 比 -3.32 更不负 | >100% | 可能有抑制稀释效应、非特异扩增或标准曲线问题 |

## 常见可接受范围

很多实验室会把 90%-110% 作为常规 qPCR 扩增效率的经验范围，但具体接受标准应结合实验目的、试剂体系、重复性和 MIQE 报告要求。效率看起来合格，也不能替代熔解曲线、NTC 和 no-RT 对照。

| 效率范围 | 常见判断 |
| --- | --- |
| 90%-110% | 通常可接受 |
| <90% | 可能引物设计差、反应抑制或体系不佳 |
| >110% | 可能标准曲线错误、抑制物被稀释、非特异扩增 |
| R² 很高但效率异常 | 曲线线性好不等于体系正确 |

## 影响扩增效率的因素

| 因素 | 影响方式 |
| --- | --- |
| [qPCR引物](<../../材(实验耗材工具篇)/qPCR引物.md>) 设计 | Tm、GC、二聚体和扩增子长度影响效率 |
| [扩增子](扩增子.md) 长度 | 过长片段扩增较慢，尤其 RNA 质量差时 |
| 模板质量 | RNA 降解、cDNA 质量差会降低效率 |
| PCR 抑制剂 | 酚、盐、乙醇、血红素等会抑制聚合酶 |
| 退火温度 | 太低非特异，太高扩增不足 |
| Mg2+ 和 master mix | 影响聚合酶活性和特异性 |
| 标准曲线稀释 | 移液误差会扭曲斜率 |

Bio-Rad 的 real-time PCR 应用指南也把反应效率、标准曲线和特异性验证列为 qPCR 数据质量的重要指标。参考：[Bio-Rad Real-Time PCR Applications Guide](https://www.bio-rad.com/en-us/applications-technologies/real-time-pcr-applications-guide)。

## 为什么效率影响表达分析

2^-ΔΔCq 方法隐含一个重要前提：目标基因和 [内参基因](内参基因.md) 的扩增效率接近。如果两者效率差异明显，同样的 Cq 差异不再对应同样的模板倍数，归一化结果会被系统性扭曲。

| 情况 | 风险 |
| --- | --- |
| 目标基因效率低，内参效率高 | 目标表达变化可能被低估 |
| 目标基因效率高，内参效率低 | 目标表达变化可能被夸大 |
| 处理组有抑制剂残留 | 处理组 Cq 偏高，像表达降低 |
| 标准曲线只做一次 | 无法判断批间稳定性 |

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 效率 <90% | 引物差、扩增子太长、抑制剂残留 | 重设计引物，稀释模板，检查 RNA 纯度 |
| 效率 >110% | 稀释错误、抑制剂稀释效应、非特异扩增 | 重做标准曲线，看熔解曲线 |
| R² 低 | 移液误差、标准品降解、浓度范围不合适 | 重新配标准品，增加稀释点 |
| 低浓度点偏离 | 低拷贝随机性或吸附损失 | 去除异常点需有记录，增加复孔 |
| 不同批次效率变化 | 试剂批号、引物状态或仪器设置变化 | 固定 SOP 并记录批号 |

## 小结

扩增效率决定 Cq 是否能可靠换算为模板量。相对定量实验中，目标基因和内参基因的效率接近，比单独追求某个漂亮 Cq 更重要。
