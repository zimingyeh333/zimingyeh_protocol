# BARD1

BARD1（BRCA1-associated RING domain protein 1，BRCA1 相关 RING 结构域蛋白 1）是 [BRCA1](BRCA1.md) 的稳定结合伙伴。二者通过 N 端 RING 结构域形成异二聚体，并共同参与损伤染色质识别、泛素化、DNA 末端切除许可与同源重组。

BARD1 并非只用于“稳定 BRCA1”：其 ankyrin repeat domain（锚蛋白重复结构域）和 BRCT domains（BRCT 结构域）能够读取复制后染色质及 DNA 损伤相关标记，从而帮助 BRCA1–BARD1 选择合适的修复环境。
