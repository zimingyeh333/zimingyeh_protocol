# 标准曲线

Standard curve（标准曲线）是用一组已知浓度的 [标准品](<../../材(实验耗材工具篇)/标准品.md>) 建立“检测信号”和“目标物浓度”之间关系的曲线，用来把未知样本的 OD、荧光或发光信号换算成浓度。

图：ELISA 曲线拟合与基质验证。标准曲线负责把 OD450 转换为浓度，4PL/5PL 负责拟合 S 形响应，spike-and-recovery 和 dilution linearity 用于检查真实样本基质是否干扰定量。本图由 Image2 / image-generation model 生成，用于个人学习笔记示意。

## 一句话理解

标准曲线不是“画一条漂亮线”，而是把未知样本放进一个经过验证的定量坐标系。

在 [ELISA](<../../用(实验流程内容篇)/ELISA.md>) 中，标准品通常做系列稀释，得到一组浓度和 OD450 的对应关系。未知样本的 OD450 只有落在可靠曲线范围内，才适合换算为浓度。

ICH M10 在 bioanalytical method validation（生物分析方法验证）中要求 calibration curve（校准曲线）覆盖分析范围，并用 calibration standards（校准标准品）和 quality control samples（质控样本）评价方法表现。参考：[ICH M10 Bioanalytical Method Validation](https://database.ich.org/sites/default/files/M10_Guideline_Step4_2022_0524.pdf)。

## 标准曲线包含什么

| 组成 | 作用 | 常见问题 |
| --- | --- | --- |
| Blank（空白） | 估计背景 | 空白高会抬高 [LOD](LOD.md) |
| Zero standard（零标准） | 无目标物基质对照 | 不等于真正无背景 |
| Low standard（低浓度标准） | 决定低端灵敏度 | 容易受移液误差影响 |
| Mid standards（中间标准） | 决定曲线主体 | 是样本最理想落点 |
| High standard（高浓度标准） | 决定上限 | 可能饱和或出现 [Hook效应](Hook效应.md) |
| QC samples（质控样本） | 监控板间/天间稳定性 | 不应只依赖标准曲线漂亮 |

## 曲线模型

ELISA 的响应通常不是线性的，而是低端接近背景、高端接近平台的 S 形曲线。因此常用 [4PL曲线](4PL曲线.md) 或 [5PL曲线](5PL曲线.md)，而不是简单线性回归。

| 模型 | 适用情况 | 风险 |
| --- | --- | --- |
| Linear regression | 很窄的线性范围 | 容易错误外推低端和高端 |
| 4PL | 对称 S 形曲线，ELISA 常用 | 若曲线明显不对称会有系统偏差 |
| 5PL | 非对称 S 形曲线 | 参数更多，需要足够标准点和稳定数据 |

GraphPad Prism 的剂量反应曲线文档也将 variable slope dose-response model（可变斜率剂量反应模型）用于 S 形响应拟合；ELISA 软件常把这类模型实现为 4PL 或 5PL。参考：[GraphPad Prism dose-response model](https://www.graphpad.com/guides/prism/latest/curve-fitting/reg_dr_stim_variable.htm)。

## 判断曲线是否可用

一条标准曲线能不能用，不只看 R²。

更应该看：

- 标准点是否按浓度单调变化。
- 复孔 CV 是否可接受。
- 回算浓度是否接近标称浓度。
- 低端是否能稳定区别 blank。
- 高端是否进入平台或超过 [LOQ](LOQ.md) 范围。
- 样本是否落在 LLOQ 和 ULOQ 之间。
- 标准曲线是否和真实样本基质匹配。

很多 ELISA 曲线看起来很顺，但样本因为 [基质效应](基质效应.md) 或稀释不线性而不能直接解释。

## 样本外推的风险

如果未知样本 OD 低于最低可定量范围，软件仍然可能给出一个浓度，但这通常是外推值。高于最高标准品或超过 ULOQ 时也一样。

常见处理：

| 情况 | 建议 |
| --- | --- |
| 低于 LOD | 记录为 below LOD 或 not detected |
| 高于 LOD 但低于 LLOQ | 记录为 detected but below LLOQ |
| 高于 ULOQ | 稀释后重测 |
| 落在曲线平台区 | 谨慎解释，优先稀释进入中段 |
| 明显偏离复孔 | 检查气泡、移液和板位 |

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 曲线不单调 | 标准品配错、移液错误、孔位污染 | 重新配标准品并检查板图 |
| 低端点离散大 | 浓度太低、吸附损失、背景波动 | 增加复孔，使用低吸附耗材 |
| 高端点平台过早 | 样本/标准品太浓或显色过久 | 降低最高浓度或缩短显色 |
| R² 高但样本不可靠 | 曲线拟合好但基质不匹配 | 做 [Spike-and-recovery](Spike-and-recovery.md) 和 [稀释线性](稀释线性.md) |
| 板间差异大 | 标准品复溶、温度、孵育时间不同 | 固定 SOP，加入桥接质控 |

## 小结

标准曲线是 ELISA 定量的坐标系。真正可靠的曲线，不只是图形好看，而是标准点、复孔、回算、可定量范围和样本基质都能支持最终浓度解释。
