# 质量分析器

Mass analyzer（质量分析器）是 [质谱仪](<../../材(实验耗材工具篇)/质谱仪.md>) 的核心部件之一，负责按 mass-to-charge ratio（[质荷比](质荷比.md)，m/z）选择、分离、储存或解析离子。它决定了一台质谱仪更擅长发现未知物、做高分辨解析、做靶向定量，还是做快速指纹分析。

## 在质谱仪里的位置

Thermo Fisher 的 mass spectrometry technology overview 将质谱的核心功能概括为 ionization（离子化）、separation/filtering（分离/过滤）、detection（检测）和 analysis（分析），对应 ion source（[离子源](离子源.md)）、mass analyzer（质量分析器）、detector（检测器）和 software（软件）。该页面还指出，不同质量分析器擅长不同功能，例如 quadrupole（四极杆）常用于定量，ion trap（离子阱）常用于结构和定性工作。参考：[Thermo Fisher Mass Spectrometry Technology Overview](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/mass-spectrometry-learning-center/mass-spectrometry-technology-overview.html)

```text
样本
-> 离子源：把分子变成离子
-> 质量分析器：按 m/z 选择或分离离子
-> 检测器：把离子事件转成信号
-> 软件：生成谱图、搜索、定量和质控
```

## 常见质量分析器

| 类型 | 核心能力 | 常见仪器/用途 |
| --- | --- | --- |
| [四极杆](四极杆.md) | 选择特定 m/z，扫描或过滤离子 | [三重四极杆质谱仪](<../../材(实验耗材工具篇)/三重四极杆质谱仪.md>)、SIM、SRM/MRM |
| [飞行时间质量分析器](飞行时间质量分析器.md) | 根据离子飞行时间测 m/z，速度快 | [Q-TOF](<../../材(实验耗材工具篇)/Q-TOF.md>)、[MALDI-TOF](<../../材(实验耗材工具篇)/MALDI-TOF.md>) |
| [Orbitrap](<../../材(实验耗材工具篇)/Orbitrap.md>) | 通过离子振荡频率获得高分辨准确质量 | 发现型蛋白组学、修饰、小分子 HRAM |
| Ion trap（离子阱） | 储存离子并进行多级碎裂 | 结构解析、MSn |
| FT-ICR（傅里叶变换离子回旋共振） | 极高分辨率 | 超复杂混合物、石油组学等专门平台 |

## 选择时看什么

| 判断轴 | 关键问题 | 典型倾向 |
| --- | --- | --- |
| 分辨率 | 是否需要区分非常接近的 m/z 峰 | Orbitrap、FT-ICR、部分 Q-TOF |
| 准确质量 | 是否需要用 ppm 级误差辅助推断组成 | Orbitrap、Q-TOF |
| 扫描速度 | LC 峰是否很窄、DIA 窗口是否多 | Q-TOF、部分 Orbitrap |
| 靶向灵敏度 | 是否只测已知目标 | 三重四极杆 |
| 数据深度 | 是否要发现未知蛋白/修饰/代谢物 | 高分辨全扫描平台 |
| 稳健性和维护 | 是否是大队列、常规检测 | 三重四极杆或成熟 LC-MS 平台 |

## 常见误解

| 误解 | 更准确的理解 |
| --- | --- |
| 质量分析器越贵越适合所有实验 | 发现、验证、定量、指纹分析需要不同仪器逻辑 |
| 高分辨一定比三重四极杆定量好 | 高分辨适合发现和解析，三重四极杆常更适合成熟靶向定量 |
| 只看最高分辨率就能判断仪器好坏 | 还要看扫描速度、灵敏度、动态范围、软件和 LC 前端 |
| 质量分析器能弥补样本前处理差 | 盐、去污剂、污染和低回收会先破坏离子化与色谱 |

## 和蛋白质谱的关系

在 [蛋白质谱](<../../用(实验流程内容篇)/蛋白质谱.md>) 中，质量分析器决定数据采集策略：

- DDA（data-dependent acquisition，数据依赖采集）需要在 MS1 中发现前体离子，再选择一部分做 MS/MS。
- DIA（data-independent acquisition，数据非依赖采集）需要在设定 m/z 窗口内系统性碎裂并解析复杂谱图。
- PRM（parallel reaction monitoring，平行反应监测）常依赖高分辨质量分析器采集目标肽段碎片。
- SRM/MRM 常依赖三重四极杆，用 precursor/product transition 做靶向定量。

## 小结

质量分析器是质谱仪的“分辨和选择核心”。它决定仪器的数据形态：全扫描、高分辨、快速 MS/MS、靶向 transition 或板上指纹。真正选平台时，应从实验问题倒推，而不是只比较仪器参数。
