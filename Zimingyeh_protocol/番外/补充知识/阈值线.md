# 阈值线

Threshold line（阈值线）是 qPCR 软件在 [扩增曲线](扩增曲线.md) 上设置的一条荧光信号判定线；当样本扩增曲线越过阈值线时，软件计算对应循环数为 [Cq值](Cq值.md)。

## 一句话理解

阈值线决定软件“从第几个循环开始认为信号真正扩增起来了”。

Thermo Fisher 对 Ct 的说明中指出，Ct/Cq 是荧光信号超过设定阈值时的循环数，因此阈值设置会直接影响 Cq 读数。参考：[Thermo Fisher: Understanding Ct values](https://www.thermofisher.com/us/en/home/life-science/pcr/real-time-pcr/real-time-pcr-learning-center/real-time-pcr-basics/real-time-pcr-understanding-ct.html)。

## 阈值线应该放在哪里

理想阈值线应位于：

- 基线噪声以上。
- 指数扩增区域内。
- 平台期以下。
- 同一 assay 或同一批可比数据中设置逻辑一致。

| 位置 | 风险 |
| --- | --- |
| 太低 | 背景噪声被误判，Cq 偏早 |
| 太高 | 接近线性期或平台期，Cq 偏晚 |
| 不同板随意调整 | 板间 Cq 不可比 |
| 让异常曲线也强行过线 | 掩盖反应失败或非特异扩增 |

## 自动阈值 vs 手动阈值

| 设置方式 | 优点 | 风险 |
| --- | --- | --- |
| 自动阈值 | 快速、减少人为操作 | 软件可能受异常孔影响 |
| 手动阈值 | 可统一不同板或排除异常影响 | 容易人为偏置 |
| 固定阈值 | 适合严格比较同一 assay | 需要前期验证 |

正式记录中，应说明阈值线是 automatic（自动）还是 manual（手动），必要时记录具体阈值或软件算法。

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 同一数据换软件 Cq 不同 | 阈值和基线算法不同 | 记录软件版本和设置 |
| 异常孔影响整板自动阈值 | 软件自动判定被离群曲线影响 | 排查异常孔后重新分析 |
| 手动调阈值后结果更“好看” | 人为偏置 | 只按预先规则调整，不按结论调整 |
| 高背景孔 Cq 偏早 | 阈值线太低或基线不稳 | 重新看基线和扩增曲线 |

## 记录模板

中文记录：

```text
仪器/软件：
软件版本：
阈值设置：自动 / 手动 / 固定
阈值数值或算法：
是否排除异常孔后重算：
阈值是否位于指数期：
对 Cq 的影响：
备注：
```

English record:

```text
Instrument/software:
Software version:
Threshold setting: automatic / manual / fixed
Threshold value or algorithm:
Recalculated after excluding abnormal wells: yes / no
Threshold within exponential phase: yes / no
Effect on Cq:
Notes:
```

## 小结

阈值线不是图上的装饰线，而是 Cq 计算的核心参数。任何跨板、跨软件或重新分析的数据，都应该记录阈值设置，否则 Cq 可比性会变弱。
