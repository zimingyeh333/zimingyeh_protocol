# 信噪比

Signal-to-noise ratio（信噪比，常写作 S/N）是指目标信号相对于背景噪声或非目标波动的强弱比例；在 ELISA、qPCR、成像、流式和小分子检测中，信噪比决定结果是否容易区分、是否适合定量以及低丰度目标是否可信。

## 一句话理解

信噪比回答的是：“目标信号比背景高得够不够清楚？”

Thermo Fisher 的 ELISA overview 强调，ELISA 依赖抗体识别、洗涤和检测体系把目标转化为读数；如果背景高或特异性差，即使有信号也不一定可解释。参考：[Thermo Fisher Overview of ELISA](https://www.thermofisher.com/us/en/home/life-science/protein-biology/protein-biology-learning-center/protein-biology-resource-library/pierce-protein-methods/overview-elisa.html)。

## 信号和噪声分别是什么

| 概念 | 例子 |
| --- | --- |
| Signal（信号） | 目标抗原产生的 OD、目标基因扩增曲线、目标荧光 |
| Noise（噪声） | 空白背景、阴性样本背景、仪器波动、非特异结合 |
| Background（背景） | 系统性本底，可部分扣除 |
| Random noise（随机噪声） | 复孔波动、读数随机误差 |

信噪比高时，阳性和阴性分得开；信噪比低时，结果容易落在灰区。

## 常见判断方式

| 场景 | 常见做法 |
| --- | --- |
| ELISA | 阳性 OD 与空白/阴性 OD 比较 |
| qPCR | 目标扩增与 NTC/no-RT、熔解曲线一起判断 |
| 免疫荧光 | 目标区域荧光与背景区域荧光比较 |
| Western blot | 目标条带强度与膜背景比较 |
| 流式细胞术 | 阳性群体与阴性群体分离度 |

信噪比不是唯一指标。定量实验还要看 [LOD](LOD.md)、[LOQ](LOQ.md)、标准曲线、复孔 CV 和样本基质。

## 如何提高信噪比

| 方向 | 做法 |
| --- | --- |
| 提高真信号 | 增加目标捕获、优化抗体浓度、延长孵育 |
| 降低背景 | 优化封闭、洗涤、抗体滴度和曝光 |
| 降低非特异 | 换抗体、加竞争验证、用交叉吸附二抗 |
| 优化样本 | 减少抑制剂、降低自发荧光、稀释基质 |
| 优化读数 | 避免饱和，选择合适曝光或显色时间 |

提高信号和降低噪声都重要。单纯把曝光拉长、显色做久，可能同时放大背景，信噪比不一定变好。

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 阳性强但背景也强 | 抗体过浓或洗涤不足 | 做抗体滴度和洗涤优化 |
| 弱阳性分不出来 | 背景波动大或灵敏度不足 | 提高重复数，优化体系 |
| 空白低但阴性高 | 样本基质背景 | 使用基质匹配对照 |
| qPCR NTC 有晚扩增 | 引物二聚体或污染 | 看熔解曲线，优化引物 |
| 成像背景高 | 自发荧光或非特异染色 | 调整通道、封闭和曝光 |

## 小结

信噪比决定结果是否能被稳定区分。实验排错时，不要只问“信号够不够强”，还要问“背景有没有一起变强”。
