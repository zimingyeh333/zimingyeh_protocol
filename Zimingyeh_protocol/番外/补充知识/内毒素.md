# 内毒素

Endotoxin（内毒素）在实验语境中通常指 bacterial endotoxin（细菌内毒素），主要是 [革兰阴性菌](革兰阴性菌.md) 外膜中的 lipopolysaccharide（[LPS](脂多糖.md)，脂多糖）。它是典型 pyrogen（[热原](热原.md)）之一，能强烈刺激先天免疫反应；在细胞培养、免疫实验、重组蛋白、无菌水和注射相关材料中是非常关键的质量风险。

## 核心概念

内毒素不是“活细菌”，而是细菌结构成分。即使细菌被高压灭菌或裂解，LPS 仍可能残留并保持生物活性。因此 sterile（无菌）不等于 endotoxin-free（无内毒素）。

在哺乳动物免疫系统中，LPS 常通过 TLR4（Toll-like receptor 4，Toll 样受体 4）等通路触发炎症信号。对于巨噬细胞、单核细胞、树突状细胞、PBMC 和许多炎症因子检测体系，极低水平内毒素都可能造成明显背景。

FDA 的 pyrogen/endotoxin guidance 将 bacterial endotoxins test（细菌内毒素检查）作为药品、生物制品和医疗器械等场景的重要质量问题，并讨论了 LAL 方法、替代方法验证和限度计算等内容。参考：[FDA Pyrogen and Endotoxins Testing Questions and Answers](https://www.fda.gov/regulatory-information/search-fda-guidance-documents/pyrogen-and-endotoxins-testing-questions-and-answers)。

## 为什么内毒素比“普通污染”更麻烦

| 特点 | 实验后果 |
| --- | --- |
| 来源于革兰阴性菌外膜 | 水、试剂、玻璃器皿、塑料耗材、蛋白表达体系都可能带入 |
| 耐热性较强 | 高压灭菌能杀菌，但不一定去除内毒素 |
| 免疫活性强 | 免疫细胞、炎症因子和原代细胞实验容易假阳性 |
| 不能靠显微镜或浑浊判断 | 溶液清澈、无菌也可能内毒素偏高 |
| 单位和限度依赖用途 | 不能用一个通用阈值覆盖所有实验 |

## 常见单位

内毒素常用 EU/mL、EU/mg、EU/vial 等单位记录。EU 是 endotoxin unit（内毒素单位），表示生物活性相关的单位，不是单纯质量单位。

| 写法 | 常见含义 |
| --- | --- |
| EU/mL | 液体样品中每 mL 内毒素活性 |
| EU/mg | 蛋白或粉末每 mg 对应内毒素活性 |
| EU/vial | 每瓶总内毒素活性 |
| < 0.1 EU/mL | 常见产品 COA 上的低内毒素声明形式之一 |

不同实验能接受的内毒素水平差异很大。免疫细胞实验、细胞治疗相关材料、注射级材料和炎症因子检测通常更敏感；WB 封闭、普通化学清洗或非细胞体系可能不需要同一等级。

## 常见来源

| 来源 | 例子 | 风险点 |
| --- | --- | --- |
| 水 | [超纯水](<../../材(实验耗材工具篇)/超纯水.md>)、[无菌水](<../../材(实验耗材工具篇)/无菌水.md>)、[注射用水](<../../材(实验耗材工具篇)/注射用水.md>) | 无菌不等于低内毒素 |
| 玻璃器皿 | 试剂瓶、移液管、烧杯 | 清洗后残留、空气和水源污染 |
| 塑料耗材 | 离心管、吸头、培养瓶、冻存管 | 需看 non-pyrogenic/endotoxin tested 声明 |
| 重组蛋白 | E. coli 表达细胞因子、酶、抗原 | LPS 共纯化或去除不充分 |
| 血清和培养添加物 | FBS、BSA、生长因子 | 批次差异和等级差异明显 |
| 缓冲液 | PBS、HEPES、Tris、盐溶液 | 自配水源和容器容易被忽视 |

## 无菌、低内毒素、无热原的区别

| 术语 | 英文 | 主要含义 | 不能默认代表 |
| --- | --- | --- | --- |
| 无菌 | sterile | 没有可生长微生物 | 不等于无内毒素 |
| 低内毒素 | low endotoxin / endotoxin-tested | 内毒素低于特定检测限或规格 | 不等于完全无生物污染 |
| 无热原 | non-pyrogenic / pyrogen-free | 不引起热原反应，通常与内毒素风险相关 | 具体含义要看测试方法 |
| 无核酸酶 | nuclease-free | DNase/RNase 风险低 | 不等于低内毒素 |
| 低 TOC | low TOC | 有机碳背景低 | 不等于低内毒素 |

这也是为什么 [无菌水](<../../材(实验耗材工具篇)/无菌水.md>) 不能直接替代低内毒素水，普通 sterile PBS 也不能默认用于免疫刺激实验。

## 检测方法概览

### LAL 检测

[LAL检测](<../../用(实验流程内容篇)/LAL检测.md>) 来自 Limulus amebocyte lysate（鲎变形细胞裂解物，[鲎试剂](<../../材(实验耗材工具篇)/鲎试剂.md>)）。它是经典 bacterial endotoxins test（BET，细菌内毒素检查）体系。常见形式包括 gel-clot（凝胶法）、turbidimetric（浊度法）和 chromogenic（显色法）。

LAL 方法对样品基质、pH、螯合剂、表面活性剂、蛋白、高盐和有机溶剂等可能敏感。正式结果需要做 inhibition/enhancement control（抑制/增强控制），不能只看一个读数。

### rFC 检测

[rFC检测](<../../用(实验流程内容篇)/rFC检测.md>) 使用 recombinant Factor C（重组因子 C）识别内毒素。它不依赖天然鲎试剂，理论上可以减少对鲎资源的依赖，并降低某些非内毒素反应干扰。正式使用时仍要看法规、药典、平台 SOP 和方法验证要求。

### 去热原处理

[去热原](<../../用(实验流程内容篇)/去热原.md>) 是 depyrogenation（去除或灭活热原）的过程。玻璃器皿常见策略是经验证的干热处理；溶液则通常需要选择低内毒素原料、合格水源、专用耗材和合适过滤/吸附/纯化策略。普通 0.22 μm 无菌过滤不能可靠去除溶解状态内毒素。

## 哪些实验最需要关注内毒素

| 实验/材料 | 为什么敏感 |
| --- | --- |
| 免疫细胞培养 | LPS 本身就是强免疫刺激物 |
| 炎症因子检测 | IL-6、TNF-alpha、IL-1beta 等容易被 LPS 诱导 |
| 原代细胞和类器官 | 对微量污染和批次变化更敏感 |
| 干细胞分化 | 背景炎症信号可能改变分化轨迹 |
| 重组细胞因子/生长因子 | E. coli 表达产品尤其要看内毒素 |
| 细胞治疗或临床前材料 | 质量文件和放行标准更严格 |
| 注射、植入或动物给药 | 需要按法规和伦理平台要求执行 |

## 产品和 COA 怎么看

购买试剂或耗材时，建议记录：

- 是否写明 endotoxin-tested、low endotoxin、non-pyrogenic。
- 内毒素单位和限度，例如 EU/mL、EU/mg。
- 检测方法：LAL gel-clot、chromogenic、turbidimetric、rFC 等。
- 批号和 COA（Certificate of analysis，分析证书）。
- 产品用途等级：cell culture grade、GMP grade、clinical grade、molecular biology grade。
- 是否 E. coli expression（大肠杆菌表达），是否有去内毒素说明。

如果一个产品只写“sterile”，但没有内毒素数据，不能自动把它当作低内毒素产品。

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 免疫细胞阴性对照也高表达炎症因子 | 水、PBS、BSA、细胞因子或耗材有内毒素 | 逐一替换为低内毒素批次，检查 COA |
| 细胞无菌但状态很差 | 无菌污染已排除，但内毒素或化学残留存在 | 检查内毒素、TOC、渗透压和培养基批次 |
| 重组蛋白刺激效果异常强 | 蛋白中 LPS 共污染 | 使用 endotoxin-low 产品或做去内毒素处理 |
| LAL 结果不可信 | 样品抑制或增强 LAL 反应 | 做 spike recovery / inhibition-enhancement control |
| 高压灭菌后仍有反应 | 细菌被杀死但内毒素残留 | 使用去热原流程或低内毒素原料 |
| 同一产品不同批次差异大 | 原料和纯化批次差异 | 对敏感实验做批次筛选 |

## 实验选择建议

| 场景 | 建议 |
| --- | --- |
| 普通 WB、PCR 或化学试剂 | 通常不把内毒素作为第一指标，除非影响下游细胞 |
| 常规细胞培养 | 选择 cell culture grade，关键添加物看内毒素 |
| 免疫细胞和炎症实验 | 所有水、buffer、BSA、细胞因子、耗材都尽量低内毒素 |
| 重组蛋白刺激实验 | 优先选择 endotoxin-low 或 mammalian-expressed 产品 |
| 动物给药或临床相关材料 | 按平台、法规和伦理要求执行，不自行推断 |

## 总结

内毒素最容易被误解的地方是：它不是活菌，所以“无菌”并不能排除它；它又有很强免疫活性，所以在免疫细胞、炎症检测、重组蛋白和细胞治疗相关实验中非常关键。看到 sterile、cell culture grade、non-pyrogenic、low endotoxin、endotoxin-tested 这些词时，要分别理解它们的含义，并回到 COA 和实验用途上判断。
