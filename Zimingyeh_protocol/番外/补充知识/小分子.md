# 小分子

Small molecule（小分子）在生命科学和药理学中通常指相对低分子量的有机化合物，常见于药物、代谢物、激素、毒素、信号分子和实验处理试剂；在免疫检测中，小分子常常需要按 [半抗原](半抗原.md) 的逻辑来理解。

## 一句话理解

小分子不是“小一点的蛋白”，而是一类结构、扩散、检测和免疫原性都与蛋白大分子明显不同的化合物。

Wikipedia 的 small molecule 页面将小分子描述为低分子量有机化合物，并提到它们可作为药物、研究工具或调节生物过程的分子。参考：[Wikipedia: Small molecule](https://en.wikipedia.org/wiki/Small_molecule)。

## 小分子和大分子的区别

| 项目 | 小分子 | 蛋白/核酸等大分子 |
| --- | --- | --- |
| 分子量 | 通常较低 | 通常较高 |
| 结构 | 化学结构明确，构象较少 | 构象复杂，可折叠 |
| 免疫原性 | 单独常较弱 | 通常更容易成为免疫原 |
| 检测策略 | 常用竞争法、LC-MS、HPLC | 可用夹心 ELISA、WB、测序等 |
| 表位数量 | 识别面有限 | 可有多个表位 |
| 细胞通透性 | 部分可进入细胞 | 多数大分子不易直接进入细胞 |

## 在实验中的常见角色

| 角色 | 例子 | 注意 |
| --- | --- | --- |
| 药物或抑制剂 | kinase inhibitor、ROCK 抑制剂 | 关注溶剂、浓度、处理时间 |
| 代谢物 | glucose、lactate、ATP | 样本处理会影响稳定性 |
| 激素 | cortisol、estradiol | 免疫检测常有交叉反应 |
| 毒素或污染物 | LPS、mycotoxin | 低量即可影响结果 |
| 标签或探针 | biotin、fluorophore、hapten tag | 可能改变分子行为 |
| 标准品 | 小分子标准品 | 关注纯度、溶解度和储存 |

## 小分子检测为什么常用竞争法

很多小分子太小，无法同时被两支抗体夹住，因此不适合典型 sandwich ELISA。更常见的思路是 [竞争ELISA](<../../用(实验流程内容篇)/竞争ELISA.md>)：样本中的游离小分子和固定或标记的小分子竞争同一抗体结合位点。

| 检测逻辑 | 适合对象 | 读数特点 |
| --- | --- | --- |
| 夹心 ELISA | 蛋白、多表位大分子 | 目标越多，信号通常越强 |
| 竞争 ELISA | 小分子、半抗原、单表位目标 | 目标越多，信号常常越低 |
| [LC-MS](<../../用(实验流程内容篇)/液相色谱-质谱联用.md>) | 小分子定量和结构确认 | 特异性强，但仪器和方法要求高 |
| [HPLC](<../../用(实验流程内容篇)/高效液相色谱.md>) | 分离和定量 | 需要合适检测器和标准品 |

## 实验使用小分子时记录什么

| 记录项 | 为什么重要 |
| --- | --- |
| 分子名称和 CAS | 避免同名或盐型混淆 |
| 纯度 | 杂质可能影响细胞或检测 |
| 溶剂 | DMSO、乙醇、水等本身可能影响实验 |
| stock 浓度 | 影响稀释准确性 |
| final concentration | 最终处理浓度才是实验变量 |
| 处理时间 | 小分子效应常随时间变化 |
| 光/温度稳定性 | 某些小分子易降解 |
| 批号和开封日期 | 便于排查失效或批间差异 |

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 细胞死亡 | 小分子浓度过高或溶剂毒性 | 做剂量梯度和 [vehicle control](溶剂对照.md) |
| 效应不明显 | 溶解度差、降解或靶点不表达 | 检查 stock、处理时间和阳性对照 |
| 竞争 ELISA 曲线反向理解 | 竞争法中目标越多信号可能越低 | 明确曲线方向并标注 |
| 免疫检测交叉反应 | 小分子结构类似物被抗体识别 | 查看交叉反应数据 |
| 批次差异 | 纯度、盐型或水合状态不同 | 记录供应商、货号、批号和形式 |

## 小结

小分子实验最容易出问题的地方不是“概念难”，而是溶剂、浓度、稳定性、盐型、批号和检测策略没有记录清楚。涉及免疫检测时，小分子常要按半抗原和竞争法思路处理。
