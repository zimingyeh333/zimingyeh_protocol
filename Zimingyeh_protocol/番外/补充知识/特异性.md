# 特异性

Specificity（特异性）是指抗体、引物、探针或检测方法识别目标对象而不识别非目标对象的能力；在抗体实验中，特异性主要体现为抗体是否只识别目标 [抗原](抗原.md) 或目标 [表位](表位.md)。

图：抗体识别基础示意。特异性关注“是否只识别目标”，而亲和力关注“结合强不强”。本图复用项目内 Image2 / image-generation model 生成图，用于个人学习笔记示意。

## 一句话理解

特异性回答的是：“抗体抓到的到底是不是我想看的目标？”

Janeway Immunobiology 中对抗体识别的描述强调，抗体结合位点与抗原上的具体结构互补；这种互补性带来特异识别，但相似结构也可能导致 [交叉反应](交叉反应.md)。参考：[NCBI Bookshelf: Antigen recognition by B-cell and T-cell receptors](https://www.ncbi.nlm.nih.gov/books/NBK27160/)。

## 特异性不是只有“有/没有”

特异性是应用相关的。同一支抗体在一种实验里特异，在另一种实验里可能不特异。

| 应用 | 特异性验证重点 |
| --- | --- |
| Western blot | 条带分子量、敲除/敲低对照、过表达对照 |
| IF/IHC | 细胞或组织定位是否合理，阴性组织是否无信号 |
| Flow cytometry | 阴性群体、同型对照、FMO 对照、抗原表达模式 |
| ELISA | 空白、阴性样本、相关蛋白交叉反应 |
| 竞争实验 | 非目标竞争物是否影响信号 |

“说明书写了 specificity 高”不等于你的样本和实验条件下特异性一定足够。

## 特异性 vs 亲和力

| 项目 | [亲和力](亲和力.md) | 特异性 |
| --- | --- | --- |
| 核心问题 | 抓得稳不稳 | 抓得对不对 |
| 高亲和力风险 | 错目标也可能抓得很稳 | 造成强假阳性 |
| 低亲和力风险 | 目标抓不住 | 信号弱 |
| 验证方法 | Kd、滴定、洗涤耐受性 | KO/KD、阴性样本、竞争、交叉反应测试 |

一个抗体对目标有高亲和力，但如果也对相似蛋白有高亲和力，特异性仍然不好。

## 特异性的验证思路

| 验证策略 | 逻辑 |
| --- | --- |
| Knockout（敲除） | 目标不存在时信号应消失 |
| Knockdown（敲低） | 目标降低时信号应下降 |
| Overexpression（过表达） | 目标增加时信号应增强 |
| Peptide competition（肽竞争） | 表位肽竞争后信号应下降 |
| Orthogonal method（正交方法） | 用另一种方法验证同一目标变化 |
| Related protein panel（相关蛋白面板） | 检查是否识别同源蛋白 |

正式项目中，特异性证据比“抗体品牌”更重要。

## 在 ELISA 中的特异性

在 [ELISA](<../../用(实验流程内容篇)/ELISA.md>) 中，特异性不仅来自单支抗体，也来自整个体系：

- 捕获抗体是否只抓目标。
- 检测抗体是否只识别目标。
- 标准品是否代表真实样本目标物。
- 样本基质是否造成非特异性结合。
- 相关蛋白是否产生交叉反应。

夹心 ELISA 由于需要两支抗体同时识别目标，通常比单抗体检测更有特异性优势，但如果两支抗体都识别同一家族的相似蛋白，仍然可能出现交叉反应。

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 阴性样本也有信号 | 非特异性结合或交叉反应 | 增加阴性对照，换抗体或优化封闭 |
| WB 多条带 | 抗体识别多个蛋白或降解片段 | 做 KO/KD 对照并优化样本处理 |
| IF 定位不符合生物学 | 背景染色或抗体不适用 | 换验证过 IF 的抗体 |
| ELISA 相关蛋白也显色 | 交叉反应 | 查看厂家交叉反应数据，换 pair |
| 高背景被误认为表达升高 | 封闭/洗涤不足 | 优先排查背景和对照 |

## 小结

特异性是抗体实验可信度的底线。没有特异性，再强的信号也只是“有东西被识别了”，不能证明目标真的存在或升高。
