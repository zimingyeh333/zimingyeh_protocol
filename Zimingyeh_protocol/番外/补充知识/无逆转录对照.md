# 无逆转录对照

No-RT control（no reverse transcription control，无逆转录对照）是在 RT-qPCR 中省略 reverse transcriptase（逆转录酶）的对照，用于判断 RNA 样本中是否存在 [基因组DNA污染](基因组DNA污染.md) 或其他可被 qPCR 直接扩增的 DNA 模板。

## 一句话理解

no-RT 问的是：“如果不把 RNA 逆转录成 cDNA，qPCR 还能扩增出来吗？”

MIQE 指南强调 RT-qPCR 需要报告阴性对照和基因组 DNA 污染控制；no-RT 是检查 RNA 样本 DNA 污染的关键对照之一。参考：[MIQE guidelines, Clinical Chemistry 2009](https://academic.oup.com/clinchem/article/55/4/611/5631762)。

## no-RT 怎么设置

no-RT 对照通常在逆转录步骤中设置：

| 组分 | 正常 RT 反应 | no-RT 对照 |
| --- | --- | --- |
| RNA 样本 | 有 | 有 |
| 逆转录 buffer | 有 | 有 |
| dNTP | 有 | 有 |
| 逆转录引物 | 有 | 有 |
| 逆转录酶 | 有 | 无 |
| 后续 qPCR | 用 cDNA | 用 no-RT 产物 |

如果 no-RT 后续 qPCR 出现扩增，说明样本里可能有 DNA 模板，或者 qPCR 配液时发生污染。

## no-RT 能发现什么

| 问题 | no-RT 表现 |
| --- | --- |
| 基因组 DNA 残留 | no-RT 有扩增，尤其内含子少或无内含子基因明显 |
| 质粒或病毒 DNA 污染 | no-RT 对特定目标阳性 |
| qPCR 配液污染 | no-RT 和 NTC 可能同时阳性 |
| 引物设计不区分 cDNA/gDNA | no-RT 易出现目标样扩增 |

## no-RT vs NTC

| 对照 | 样本 RNA | 逆转录酶 | qPCR 模板 | 检查重点 |
| --- | --- | --- | --- | --- |
| NTC | 无 | 不涉及 | 水 | qPCR 配液污染和引物二聚体 |
| no-RT | 有 | 无 | no-RT 反应产物 | RNA 样本 DNA 污染 |
| 正常 RT | 有 | 有 | cDNA | 目标表达检测 |

二者都重要。NTC 不能替代 no-RT，因为 NTC 没有 RNA 样本，无法发现样本中残留的 DNA。

## 降低基因组 DNA 影响的方法

| 方法 | 说明 |
| --- | --- |
| [DNase I](<../../材(实验耗材工具篇)/DNase I.md>) 处理 | 直接消化 RNA 样本中的 DNA |
| 设计跨 exon-exon junction 的引物 | 优先扩增剪接后的 cDNA |
| 让引物跨较长 intron | gDNA 产物太长，不易扩增 |
| 设置 no-RT | 判断 DNA 残留是否影响结果 |
| 检查熔解曲线或胶图 | 区分 cDNA 产物和 gDNA 产物 |

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| no-RT 和样本 Cq 接近 | DNA 污染严重或目标为无内含子区域 | DNase 处理，重新设计引物 |
| no-RT 晚 Cq | 少量 DNA 残留 | 评估是否影响目标，必要时重新提取 |
| no-RT 与 NTC 都阳性 | 可能 qPCR 配液污染 | 先解决污染，再判断 DNA |
| 只有内参 no-RT 阳性 | 内参引物容易扩增 gDNA | 换内参引物或设计跨剪接位点 |
| DNase 后 RNA 质量下降 | DNase 处理或纯化不当 | 优化处理时间和清除步骤 |

## 小结

no-RT 是 RT-qPCR 中判断基因组 DNA 污染的关键对照。只设置 NTC 而不设置 no-RT，会让 DNA 污染这个问题漏检。
