# 阴性对照

Negative control（阴性对照）是理论上不应产生目标信号的对照，用于判断实验体系是否存在假阳性、[非特异性结合](非特异性结合.md)、污染、背景过高或判读阈值不合理。

## 一句话理解

阴性对照回答的是：“没有目标或没有预期反应时，实验会不会也显示阳性？”

MIQE 指南要求 qPCR 实验报告阴性对照和 no-template control（无模板对照）等信息；ELISA 和其他免疫检测中也需要阴性样本、空白和背景控制来判断信号可信度。参考：[MIQE guidelines, Clinical Chemistry 2009](https://academic.oup.com/clinchem/article/55/4/611/5631762)；[Thermo Fisher Overview of ELISA](https://www.thermofisher.com/us/en/home/life-science/protein-biology/protein-biology-learning-center/protein-biology-resource-library/pierce-protein-methods/overview-elisa.html)。

## 阴性对照能发现什么

| 问题 | 阴性对照表现 |
| --- | --- |
| 非特异性结合 | 阴性样本也有信号 |
| 污染 | 无目标样本出现目标扩增或检测信号 |
| 背景过高 | 阴性和阳性差异小 |
| 阈值设置不当 | 阴性被判为阳性 |
| 样本基质干扰 | 阴性真实样本比空白高很多 |

## 常见类型

| 场景 | 阴性对照例子 | 检查重点 |
| --- | --- | --- |
| RT-qPCR | [无模板对照](无模板对照.md)、[无逆转录对照](无逆转录对照.md) | 污染、引物二聚体、基因组 DNA |
| ELISA | 已知阴性样本、zero standard、blank | 背景和非特异结合 |
| 免疫荧光 | 去除一抗、阴性细胞系 | 二抗背景和非特异染色 |
| Western blot | 不表达目标的样本 | 抗体特异性 |
| 小分子处理 | [溶剂对照](溶剂对照.md) | 溶剂本身效应 |

## 阴性对照 vs 空白对照

| 项目 | 阴性对照 | [空白对照](空白对照.md) |
| --- | --- | --- |
| 是否含真实样本基质 | 通常有 | 通常没有目标和样本 |
| 主要检查 | 假阳性和样本背景 | 仪器/试剂/系统本底 |
| 例子 | 阴性血清、未处理细胞、no-RT | 只加 buffer、水或底物 |
| 风险 | 选错阴性样本 | 低估真实样本背景 |

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 阴性对照高 | 非特异结合、污染或基质效应 | 优化封闭/洗涤，排查污染 |
| 阴性和阳性接近 | 信噪比低或阳性体系失败 | 检查阳性对照和背景 |
| 阴性样本选择不合适 | 阴性本身可能含目标 | 换经过验证的阴性样本 |
| 只用空白不用阴性 | 低估真实样本基质背景 | 加入基质匹配阴性样本 |

## 小结

阴性对照是防止假阳性的底线。一个实验如果阴性对照不干净，即使阳性样本信号很强，也不能直接解释为目标真实存在。
