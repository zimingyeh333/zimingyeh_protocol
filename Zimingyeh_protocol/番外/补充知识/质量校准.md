# 质量校准

Mass calibration（质量校准）是用已知 m/z 的 calibrant ions（校准离子）修正质谱仪质量轴，使实测 m/z 尽可能接近理论值的过程。它直接影响 [准确质量](准确质量.md)、[质量误差](质量误差.md) 和数据库搜索/靶向定量的可信度。

图源：Image2 生成的质谱仪器类型参考图。高分辨准确质量平台如 Orbitrap 和 Q-TOF 尤其依赖稳定的质量校准。

## 为什么需要校准

质谱仪测量的是离子的行为：飞行时间、振荡频率、轨迹稳定性或其他物理信号。仪器需要把这些信号换算成 m/z。温度、真空、电压、离子源状态、电子元件漂移和维护状态都会让质量轴发生变化，因此需要定期校准。

Thermo Fisher 的 mass spectrometry technology overview 将质量分析器描述为分离/过滤离子的核心模块；Orbitrap 页面则强调 HRAM（high-resolution accurate-mass，高分辨准确质量）能力。要让 HRAM 数据可信，质量轴稳定和校准状态是基础。参考：[Thermo Fisher Mass Spectrometry Technology Overview](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/mass-spectrometry-learning-center/mass-spectrometry-technology-overview.html)、[Thermo Fisher Orbitrap LC-MS](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/liquid-chromatography-mass-spectrometry-lc-ms/lc-ms-systems/orbitrap-lc-ms.html)

## 常见校准方式

| 方式 | 含义 | 用途 |
| --- | --- | --- |
| External calibration（外标校准） | 用校准液单独跑校准 | 日常维护、批次前校准 |
| Internal calibration（内标校准） | 在样本中加入已知质量内标 | 提高样本运行中的准确性 |
| Lock mass（锁质量） | 利用持续出现的参考离子修正质量轴 | 长队列或高准确质量实验 |
| Tune / calibration routine | 仪器软件的调谐和校准流程 | 平台维护和性能检查 |

不同仪器和平台的校准流程差异很大，应按厂商 SOP 和平台规范执行，不要把一个仪器的校准液或参数直接迁移到另一个仪器。

## 校准状态怎么影响结果

| 表现 | 可能原因 |
| --- | --- |
| PPM 误差整体偏正或偏负 | 质量轴系统性偏移 |
| 鉴定数下降 | 搜索容差与实际质量误差不匹配 |
| 小分子候选变多 | 准确质量约束变弱 |
| 同一 QC 批次漂移 | 长时间运行中质量轴不稳定 |
| 靶向方法保留时间正常但 m/z 偏移 | LC 正常，MS 质量轴需要检查 |

## 实验记录中要写什么

建议记录：

- 校准日期和时间。
- 校准液或校准标准品名称、货号、批号。
- 校准模式：positive / negative ion mode。
- m/z 校准范围。
- 仪器软件版本和校准方法。
- 校准后质量误差或校准报告是否合格。
- QC 样本的质量误差分布。

这类记录很实用：当几周后发现某一批数据质量误差偏移，可以回头判断是仪器漂移、校准失败、方法变更还是样本问题。

## 常见错误

| 错误 | 后果 |
| --- | --- |
| 校准过期仍继续跑大批样本 | 整批数据可能出现系统性质量偏移 |
| 只看校准通过，不看 QC | 校准液正常但真实样本表现可能差 |
| 正负离子模式混用校准结论 | 不同模式质量轴表现可能不同 |
| 改方法后不验证质量误差 | 新扫描范围或分辨率下误差可能变化 |
| 忽略弱峰误差 | 低信噪比目标可能误差更大 |

## 小结

质量校准是质谱准确质量的基础维护动作。它不直接提升样本质量，也不能修复差的前处理，但能确保仪器把离子信号正确映射到 m/z。做高分辨发现、DIA、PRM 或小分子 HRAM 时，校准记录和 QC 质量误差分布都应成为数据可信度的一部分。
