# 质谱分辨率

Mass resolution / resolving power（质谱分辨率 / 分辨本领）描述质谱系统区分两个非常接近 m/z 峰的能力。它不是“信号强不强”，也不是“质量准不准”，而是“两个相邻峰能不能被看成两个峰”。

## 基本概念

实际质谱报告里常见写法是：

```text
Resolving power = m / Δm
```

其中 m 是目标峰的 m/z，Δm 是某种定义下的峰宽或两个峰能被区分的最小间距。许多仪器参数会写成 “resolution at m/z 200” 或 “FWHM at m/z 200”。FWHM（full width at half maximum，半峰宽）是最常用的峰宽定义之一。

Thermo Fisher 的质谱技术概览指出，质量分析器会根据离子的质量和电荷进行分离/过滤，不同分析器适合不同功能；同一页面也把 Orbitrap、TOF、四极杆等列为常见质量分析器。参考：[Thermo Fisher Mass Spectrometry Technology Overview](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/mass-spectrometry-learning-center/mass-spectrometry-technology-overview.html)

## 分辨率解决什么问题

| 问题 | 高分辨的价值 |
| --- | --- |
| 两个 m/z 非常接近的离子重叠 | 把它们分成更清楚的峰 |
| 同位素峰挤在一起 | 更准确解析同位素分布 |
| 共洗脱干扰 | 降低错误鉴定和错误定量风险 |
| 修饰肽段质量差异小 | 帮助区分近似质量的候选解释 |
| 复杂样本背景高 | 提高从背景中识别目标峰的能力 |

高分辨不是“自动正确”。如果样本前处理差、色谱差、数据库搜索参数错，高分辨数据仍然可能解释错误。

## 分辨率 vs 准确质量 vs 灵敏度

| 概念 | 问的问题 | 例子 |
| --- | --- | --- |
| 质谱分辨率 | 两个峰能不能分开 | m/z 500.200 和 500.205 能不能分成两个峰 |
| [准确质量](准确质量.md) | 测到的 m/z 离真实值有多近 | 质量误差是 2 ppm 还是 20 ppm |
| 灵敏度 | 低丰度离子能不能检测到 | 低丰度肽段是否有足够信号 |
| 动态范围 | 高低丰度能否同时测 | 高丰度蛋白是否掩盖低丰度蛋白 |

这四个指标经常一起出现，但不能互相替代。高分辨仪器可能仍然对低丰度目标不够灵敏；高灵敏三重四极杆也不一定能提供高分辨全扫描信息。

## 在不同仪器中的表现

| 仪器 | 分辨率特点 | 实验影响 |
| --- | --- | --- |
| [Orbitrap](<../../材(实验耗材工具篇)/Orbitrap.md>) | 高分辨准确质量能力强 | 适合复杂蛋白组、PTM、小分子 HRAM |
| [Q-TOF](<../../材(实验耗材工具篇)/Q-TOF.md>) | 兼顾速度和准确质量 | 适合 DDA/DIA、筛查和结构解析 |
| [三重四极杆质谱仪](<../../材(实验耗材工具篇)/三重四极杆质谱仪.md>) | 重点不是高分辨全扫描 | 强在 transition 靶向定量 |
| [MALDI-TOF](<../../材(实验耗材工具篇)/MALDI-TOF.md>) | 依型号和模式而定 | 常用于快速指纹和板上分析 |

## 常见错误

| 错误理解 | 更好的说法 |
| --- | --- |
| 分辨率越高越好 | 高分辨通常牺牲扫描速度或灵敏度，需要和 LC 峰宽匹配 |
| 分辨率高就一定鉴定正确 | 鉴定还依赖 MS/MS、保留时间、数据库、FDR 和样本质量 |
| 只看厂家最高分辨率 | 要看实际方法中的分辨率、扫描速度和目标 m/z |
| 分辨率等于准确质量 | 分辨率是分开峰，准确质量是测得准 |

## 实验记录中怎么写

质谱方法或结果中建议记录：

- MS1 resolution / resolving power。
- MS2 resolution / resolving power。
- 报告分辨率所对应的 m/z。
- 峰宽定义，例如 FWHM。
- 是否使用 lock mass 或质量校准。
- 实际 QC 中质量误差和峰形是否正常。

## 小结

质谱分辨率决定“相近的离子能不能分开”。它对复杂样本、修饰鉴定、同位素峰解析和背景干扰控制很重要，但不能替代准确质量、灵敏度和良好样本前处理。看分辨率时一定要看定义、m/z 位置和实际方法，而不是只看宣传数字。
