# 前体离子

Precursor ion（前体离子，也常称 parent ion，母离子）是在 [串联质谱](串联质谱.md) 中被选中、隔离并送去碎裂的离子。它通常来自 MS1 扫描中的某个 m/z 峰，随后在 MS/MS 中产生 [产物离子](产物离子.md) 或 fragment ions（碎片离子）。

## 在 MS/MS 里的位置

Thermo Fisher 的 mass spectrometry technology overview 将 tandem mass spectrometry（MS/MS）描述为先选择一个 ion（离子），使其 fragmentation（碎裂），再分析 fragments（碎片）。在这个流程中，被先选中的离子就是前体离子。参考：[Thermo Fisher Mass Spectrometry Technology Overview](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/mass-spectrometry-learning-center/mass-spectrometry-technology-overview.html)

```text
MS1 中出现一个目标 m/z 峰
-> 该峰被选作 precursor ion
-> 隔离窗口选择这个离子
-> 碰撞或其他碎裂方式
-> 生成 product ions / fragment ions
-> 进入 MS2 谱图或 transition 监测
```

## 为什么前体离子重要

| 场景 | 前体离子的意义 |
| --- | --- |
| DDA | 仪器根据 MS1 强度选择哪些前体离子做 MS/MS |
| DIA | 一段 m/z 窗口内的多个前体离子一起被碎裂 |
| PRM | 预先指定目标前体离子，采集其碎片全谱 |
| SRM/MRM | Q1 选择前体离子，Q3 选择产物离子 |
| 肽段鉴定 | 前体 m/z、保留时间和 MS/MS 谱图共同支持鉴定 |

前体离子选错，后续碎片谱就会“从源头错”。这也是为什么复杂样本里共洗脱、同位素峰选择、电荷态判断和隔离窗口设置都很重要。

## 前体离子需要记录或判断的属性

| 属性 | 含义 | 为什么重要 |
| --- | --- | --- |
| m/z | 质荷比 | 决定选中哪个离子 |
| Charge state（电荷态） | 离子带几个电荷 | 影响质量换算和碎片解释 |
| Intensity（强度） | MS1 信号强弱 | 影响是否被 DDA 选中和 MS/MS 质量 |
| Retention time（保留时间） | LC 中洗脱时间 | 帮助区分同 m/z 干扰 |
| Isotope pattern（同位素分布） | 同位素峰形态 | 帮助判断电荷态和分子组成 |
| Isolation window（隔离窗口） | 被选中的 m/z 范围 | 影响共隔离干扰 |

## 常见误解

| 误解 | 更准确的理解 |
| --- | --- |
| 前体离子就是完整分子 | 它是进入质谱后带电的离子形式，可能有不同电荷态或加合物 |
| 同一个分子只有一个前体 m/z | ESI 中常有多个电荷态，盐加合或修饰也会改变 m/z |
| 强度最高的前体一定最有价值 | 高丰度不一定代表目标；低丰度修饰肽段可能更关键 |
| 前体质量准就足够鉴定 | 还需要 MS/MS、保留时间、FDR、数据库或标准品支持 |

## 和产物离子的关系

前体离子像“被拿去拆解的对象”，产物离子像“拆出来的片段”。在靶向定量中，一个前体离子和一个产物离子的组合叫 [transition](transition.md)。

```text
前体离子：肽段 678.3452, z=2
产物离子：y7, 845.4123
transition：678.3452 -> 845.4123
```

## 小结

前体离子是 MS/MS 的起点。它决定碎裂对象是谁，也决定后续谱图、transition 和数据库搜索能否解释正确。判断前体离子时，不要只看 m/z，还要同时看电荷态、保留时间、同位素分布、隔离窗口和共洗脱干扰。
