# 熔解曲线

Melt curve（熔解曲线，也称 melting curve）是在 qPCR 扩增结束后逐步升高温度、监测双链 DNA 解链导致荧光变化的分析方法，常用于 [SYBR Green qPCR Master Mix](<../../材(实验耗材工具篇)/SYBR Green qPCR Master Mix.md>) 体系中判断扩增产物是否单一。

## 一句话理解

熔解曲线回答的是：“这个 Cq 信号是不是来自一个主要 PCR 产物？”

MIQE 指南要求 qPCR 实验报告扩增特异性验证信息；对于 SYBR 这类双链 DNA 染料体系，熔解曲线是最常见的特异性检查之一。参考：[MIQE guidelines, Clinical Chemistry 2009](https://academic.oup.com/clinchem/article/55/4/611/5631762)。

## 基本原理

SYBR Green 等染料和 double-stranded DNA（双链 DNA）结合后荧光增强。qPCR 扩增结束后，仪器逐步升高温度，PCR 产物逐渐解链为单链 DNA，染料释放，荧光下降。软件常把荧光变化的一阶导数画成峰图，峰顶对应 [Tm值](Tm值.md)（melting temperature，熔解温度）。

| 曲线特征 | 常见含义 |
| --- | --- |
| 单一尖峰 | 可能是单一主要扩增产物 |
| 多个峰 | 可能有非特异扩增或多个产物 |
| 低温小峰 | 常见于 [引物二聚体](引物二聚体.md) |
| 宽峰或肩峰 | 产物异质、非特异产物或分析参数不佳 |
| NTC 有峰 | 污染或引物二聚体 |

## 为什么 SYBR 体系特别需要熔解曲线

SYBR Green 识别的是所有双链 DNA，而不是特定序列。因此目标扩增产物、非特异 PCR 产物和引物二聚体都可能产生荧光。Thermo Fisher 和 Bio-Rad 的 qPCR 指南都将熔解曲线作为 SYBR 体系判断产物特异性的重要步骤。参考：[Thermo Fisher real-time PCR basics](https://www.thermofisher.com/cn/zh/home/life-science/pcr/real-time-pcr/real-time-pcr-learning-center/real-time-pcr-basics.html)；[Bio-Rad Real-Time PCR Applications Guide](https://www.bio-rad.com/en-us/applications-technologies/real-time-pcr-applications-guide)。

| 检测体系 | 是否依赖熔解曲线 | 原因 |
| --- | --- | --- |
| SYBR Green | 高度依赖 | 所有双链 DNA 都会发光 |
| EvaGreen | 高度依赖 | 同样是双链 DNA 染料 |
| [TaqMan探针](<../../材(实验耗材工具篇)/TaqMan探针.md>) | 通常不作为主要判断 | 探针提供额外序列特异性 |
| HRM | 不是普通熔解曲线 | 用更精细熔解差异分析变异或甲基化等 |

## 如何读熔解曲线

| 判断点 | 理想情况 | 风险提示 |
| --- | --- | --- |
| 峰数量 | 单一主峰 | 多峰说明产物不单一 |
| 峰位置 | 同一引物对样本间 Tm 接近 | Tm 大幅变化可能是不同产物 |
| 峰形 | 尖锐、重复性好 | 宽峰/肩峰提示混合产物 |
| NTC | 无峰或无明显目标峰 | 出现低温峰常见引物二聚体 |
| 阳性样本 | 主峰明显 | 若只有低温峰，目标扩增可能失败 |

熔解曲线只能说明“产物熔解行为是否一致”，不能直接证明序列完全正确。关键实验可以用 [琼脂糖凝胶电泳](<../../用(实验流程内容篇)/琼脂糖凝胶电泳.md>)、测序或探针法进一步确认。

## 常见异常与原因

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 多峰 | 非特异扩增、引物设计不佳、退火温度低 | 提高 [退火温度](退火温度.md)，重新设计引物 |
| 低温峰 | 引物二聚体 | 降低引物浓度，优化 3' 端互补性 |
| NTC 有目标峰 | 污染 | 重新配体系，分区操作，更换水和 mix |
| 样本间 Tm 不一致 | 非特异产物、剪接异构体或样本污染 | 做胶图或测序验证 |
| 峰很宽 | 产物混杂、仪器采集参数或盐浓度差异 | 优化反应体系和分析设置 |

## 和 Cq 的关系

| 情况 | Cq 是否可信 |
| --- | --- |
| Cq 正常，熔解曲线单峰 | 初步可信 |
| Cq 正常，熔解曲线多峰 | 不应直接用于定量 |
| Cq 很晚，只有低温峰 | 多半是引物二聚体或非特异信号 |
| NTC 有 Cq 且有峰 | 需要先排查污染或引物二聚体 |

对于 SYBR 体系，Cq 和熔解曲线必须一起看。只报告 Cq，不报告熔解曲线，无法判断信号来自目标产物还是非目标双链 DNA。

## 小结

熔解曲线是 SYBR qPCR 的基本质控。一个漂亮的 Cq 如果对应多峰或 NTC 峰，不能直接解释为目标表达；先确认产物单一，再谈定量。
