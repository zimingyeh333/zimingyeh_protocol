# 扩增曲线

Amplification curve（扩增曲线）是 qPCR 或 [RT-qPCR](<../../用(实验流程内容篇)/RT-qPCR.md>) 中荧光信号随 PCR 循环数变化形成的曲线，用于判断反应是否正常扩增、何时越过阈值、是否存在异常背景或平台效应。

## 一句话理解

扩增曲线是 qPCR 的“实时过程记录”，[Cq值](Cq值.md) 只是这条曲线上的一个读数点。

Thermo Fisher 对实时 PCR 的基础说明中强调，real-time PCR 会在扩增过程中持续读取荧光信号，并用阈值循环数反映起始模板量差异。参考：[Thermo Fisher: Understanding Ct values](https://www.thermofisher.com/us/en/home/life-science/pcr/real-time-pcr/real-time-pcr-learning-center/real-time-pcr-basics/real-time-pcr-understanding-ct.html)。

## 扩增曲线的阶段

| 阶段 | 英文 | 主要特征 | 说明 |
| --- | --- | --- | --- |
| 基线期 | Baseline phase | 荧光接近背景 | 模板少，信号还未明显高于背景 |
| 指数期 | Exponential phase | 信号快速上升 | 最适合定量，Cq 应落在这个区域 |
| 线性期 | Linear phase | 上升变慢 | 反应组分开始限制 |
| 平台期 | Plateau phase | 信号趋于平稳 | 不适合用终点信号直接定量 |

qPCR 的核心优势在于读取指数扩增阶段，而不是只看最终产物量。终点产物多不等于起始模板一定多，因为平台期会受到酶活、dNTP、引物、产物竞争和抑制物影响。

## 曲线形状怎么看

| 曲线表现 | 可能含义 | 处理建议 |
| --- | --- | --- |
| 典型 S 形曲线 | 反应过程正常 | 结合 Cq、熔解曲线和对照判断 |
| 起始基线漂移 | 蒸发、气泡、光学读数或基线校正问题 | 检查孔位、气泡和 [基线校正](基线校正.md) |
| 曲线很晚才上升 | 模板低、逆转录差或 PCR 抑制 | 检查 RNA/cDNA 和 [PCR抑制剂](PCR抑制剂.md) |
| 曲线不进入平台 | 反应效率差或循环数不足 | 优化引物和体系 |
| NTC 出现曲线 | 污染或 [引物二聚体](引物二聚体.md) | 看 [熔解曲线](熔解曲线.md) 和 NTC 峰 |
| 复孔曲线分散 | 移液误差、气泡、低拷贝随机性 | 检查板图和操作重复性 |

## 扩增曲线和阈值线

[阈值线](阈值线.md) 应设置在背景信号以上、平台期以下，并穿过指数扩增区域。阈值线太低会受噪声影响，太高可能接近非指数区域，都会影响 Cq 的可比性。

| 阈值设置 | 风险 |
| --- | --- |
| 太低 | 背景噪声被误判为扩增 |
| 太高 | Cq 偏晚，可能偏离指数期 |
| 每块板随意手动调整 | 板间不可比 |
| 统一但不适合当前数据 | 可能掩盖异常曲线 |

## 和熔解曲线的区别

| 项目 | 扩增曲线 | 熔解曲线 |
| --- | --- | --- |
| 横轴 | PCR 循环数 | 温度 |
| 回答问题 | 什么时候扩增起来 | 产物是否单一 |
| 主要读数 | Cq、曲线形状 | Tm、峰数 |
| 常见异常 | 基线漂移、晚扩增、复孔分散 | 多峰、低温峰 |

扩增曲线正常只能说明反应有扩增过程，不能证明产物特异。SYBR 体系必须结合熔解曲线一起看。

## 小结

扩增曲线能告诉你 qPCR 反应过程是否像一个正常扩增反应。解释 Cq 前，应该先看曲线形状、基线、阈值、复孔一致性和阴性对照。
