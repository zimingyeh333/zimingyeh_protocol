# 串联质谱

Tandem mass spectrometry（串联质谱，MS/MS 或 MS2）是在一次质谱分析中先选择或隔离某个 [前体离子](前体离子.md)，再使其碎裂，随后分析生成的 [产物离子](产物离子.md) 或 fragment ions（碎片离子）的技术。它的核心价值是从“只有一个质量峰”进一步得到“这个离子碎裂后长什么样”的结构信息。

图源：Image2 生成的质谱仪器类型参考图。Q-TOF 和三重四极杆模块都体现了“选择前体离子 -> 碰撞碎裂 -> 检测产物离子”的串联质谱逻辑。

## 基本流程

```text
MS1：观察或选择前体离子
-> isolation：隔离目标 m/z 或窗口
-> fragmentation：碰撞或其他方式碎裂
-> MS2：检测碎片离子谱图
-> interpretation：数据库搜索、谱库匹配、结构解析或定量
```

Thermo Fisher 的 mass spectrometry technology overview 将 tandem mass spectrometry（MS/MS）描述为用两个或多个质量分析步骤进行分析：第一步选择 ion（离子），随后使其 fragmentation（碎裂），再分析 fragments（碎片）。参考：[Thermo Fisher Mass Spectrometry Technology Overview](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/mass-spectrometry-learning-center/mass-spectrometry-technology-overview.html)

## 为什么 MS/MS 重要

| 场景 | MS/MS 的作用 |
| --- | --- |
| 肽段鉴定 | 碎片离子提供肽段序列信息 |
| PTM 定位 | 判断修饰质量偏移落在哪个片段 |
| 小分子结构解析 | 用碎片模式支持结构候选 |
| 靶向定量 | 用 precursor/product transition 提高选择性 |
| DIA 数据解析 | 通过碎片离子和保留时间识别目标 |

如果只有 MS1 准确质量，常常只能缩小候选范围；有 MS/MS 谱图后，才更容易把候选分子、肽段或结构区分开。

## 常见碎裂方式

| 方式 | 英文 | 特点 | 常见用途 |
| --- | --- | --- | --- |
| [碰撞诱导解离](碰撞诱导解离.md) | collision-induced dissociation，CID | 通过碰撞气使离子碎裂 | 三重四极杆、离子阱、Q-TOF 等 |
| HCD | higher-energy collisional dissociation，高能碰撞解离 | Orbitrap 平台常见，适合 reporter ion | TMT、DDA、DIA |
| ETD | electron-transfer dissociation，电子转移解离 | 较保留易碎修饰 | PTM、带多电荷肽段 |
| EThcD | ETD + HCD 组合 | 兼顾不同碎片类型 | 糖肽、修饰肽段 |

## MS/MS 采集策略

| 策略 | 基本逻辑 | 适合场景 |
| --- | --- | --- |
| [DDA](DDA.md) | 根据 MS1 中的强峰选择前体离子碎裂 | 发现型蛋白组学 |
| [DIA](DIA.md) | 按固定窗口系统性碎裂一段 m/z 范围 | 大规模一致性定量 |
| [PRM](PRM.md) | 选择目标前体，采集其高分辨碎片全谱 | 靶向肽段验证 |
| [SRM-MRM](SRM-MRM.md) | 监测固定前体-产物离子 transition | 三重四极杆靶向定量 |

## 常见误解

| 误解 | 更准确的理解 |
| --- | --- |
| 有 MS/MS 就一定能鉴定 | 谱图质量、数据库、FDR 和搜索参数仍然关键 |
| MS2 峰越多越好 | 过度碎裂或噪声也会干扰解释 |
| 所有碎裂方式结果一样 | CID/HCD/ETD 会偏向不同碎片类型 |
| DIA 就是把所有东西都测完 | DIA 数据仍依赖窗口设计、谱库/算法和 LC 稳定性 |

## 小结

串联质谱是把“质量测量”推进到“结构和序列证据”的关键技术。它让蛋白质谱、小分子结构解析和靶向定量都有了更高选择性。理解 MS/MS，就能理解 DDA、DIA、PRM 和 MRM 为什么只是不同的采集策略，而不是完全无关的实验。
