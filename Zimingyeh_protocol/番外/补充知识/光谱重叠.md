# 光谱重叠

## 一句话定义

Spectral overlap（光谱重叠）是指不同 [荧光染料](<../../材(实验耗材工具篇)/荧光染料.md>) 的激发或发射光谱相互重叠，导致一个染料的信号被另一个通道收集，常表现为 bleed-through（串色）或 spillover（溢出）。

光谱重叠是多通道 [免疫荧光](<../../用(实验流程内容篇)/免疫荧光.md>)、[荧光显微镜](<../../材(实验耗材工具篇)/荧光显微镜.md>) 成像和 [流式细胞术](<../../用(实验流程内容篇)/流式细胞术.md>) 中必须考虑的问题。Thermo Fisher SpectraViewer、BD Spectrum Viewer 和 BioLegend Fluorophore Guide 都提供染料光谱比较工具，用于预估和减少光谱重叠。[参考：Thermo Fisher Fluorescence SpectraViewer](https://www.thermofisher.com/order/fluorescence-spectraviewer)；[参考：BD Spectrum Viewer](https://www.bdbiosciences.com/en-us/resources/bd-spectrum-viewer)；[参考：BioLegend Fluorophore Guide](https://www.biolegend.com/en-us/fluorophore-guide)

## 为什么会发生

荧光染料不是只发出一个波长，而是发出一段发射光谱：

```text
染料A主要发绿光
但尾部可能延伸到黄/橙通道
如果显微镜或流式检测窗口收到了这部分光
就会在其他通道出现假信号
```

因此“绿色、红色、远红”只是粗略分类，不能替代实际光谱检查。

## 在显微镜和流式中的表现

| 平台 | 常见表现 | 处理方式 |
| --- | --- | --- |
| 荧光显微镜 | 一个通道的结构出现在另一个通道 | 单染对照、顺序采集、换滤光片/染料 |
| 共聚焦 | 激光交叉激发或发射窗口重叠 | sequential scanning（顺序扫描） |
| 流式 | 一个染料信号进入其他 detector | [荧光补偿](荧光补偿.md) |
| 光谱流式 | 光谱指纹混合 | spectral unmixing（光谱拆分） |

显微镜里常叫 bleed-through/crosstalk；流式里常叫 spillover，并通过 compensation matrix 处理。

## 常见高风险组合

| 组合 | 风险 |
| --- | --- |
| FITC 与 GFP/AF488 | 基本同通道，不能当两个颜色 |
| TRITC、Cy3、AF555/568 | 光谱接近，容易互相冲突 |
| Cy5 与 AF647 | 通道接近，不能独立分辨 |
| PE 与 PE串联染料 | PE donor 泄漏和串联降解影响补偿 |
| DAPI 与 Hoechst | 都是蓝色核染，通常不要同时作为独立通道 |

## 预防策略

| 策略 | 说明 |
| --- | --- |
| 设计前查光谱 | 使用 SpectraViewer 或仪器软件 |
| 拉开颜色距离 | 蓝、绿、红、远红优于相邻颜色堆叠 |
| 使用单染对照 | 判断每个染料进入哪些通道 |
| 顺序扫描 | 共聚焦中减少交叉激发和串色 |
| 窄带滤光片 | 降低通道间泄漏，但可能牺牲信号 |
| 远红染料 | 避开很多自发荧光和绿色/橙色拥挤通道 |

## 注意事项

- 光谱重叠不能靠后期改颜色解决。
- 图像合并图的伪彩色不代表真实光谱。
- 流式补偿不能消除 spreading error（扩散误差）。
- 单染对照必须和实验中的染料/抗体尽量一致。
- 串联染料批号和处理条件变化会改变光谱表现。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 两个通道结构完全一样 | 串色或重复检测同一染料 | 做单染对照，换染料 |
| 共定位看起来很高 | 光谱重叠造成假共定位 | 顺序扫描并检查单染 |
| 流式阴性群变宽 | Spillover 和 spreading error | 优化 panel，重新补偿 |
| 远红通道也有绿色结构 | 发射窗口或滤光片不合适 | 检查滤光片和光谱 |
| 换批号后补偿变了 | 串联染料光谱变化 | 每批实验重做单染补偿 |

## 小结

光谱重叠是所有多色荧光实验的基本限制。好的多色实验不是后期把颜色调开，而是在设计阶段选择合适染料、通道、滤光片和对照。凡是涉及多色 IF 或多色流式，都必须记录单染对照和光谱处理策略。
