# 多反应监测

Multiple reaction monitoring（MRM，多反应监测）是在 [三重四极杆质谱仪](<../../材(实验耗材工具篇)/三重四极杆质谱仪.md>) 上同时监测多个 precursor-to-product transition（[前体离子](前体离子.md) 到 [产物离子](产物离子.md) 的 [transition](transition.md)）的靶向定量策略。它是药物、小分子、代谢物和靶向肽段定量中最常见的质谱模式之一。

![蛋白质组学常用质谱仪类型概览](../../z_asset/材/质谱仪器/mass-spectrometry-instrument-types-reference.png)

图源：Image2 生成的质谱仪器类型参考图。三重四极杆模块显示了 MRM 的基本硬件路径：Q1 选择前体，Q2 碰撞，Q3 选择产物。

## MRM 的基本流程

```text
确定目标分子/肽段
-> 选择前体离子
-> 选择 2 个或更多产物离子
-> 优化碰撞能量和保留时间窗口
-> 建立 transition 列表
-> 用标曲和内标进行定量
```

Thermo Fisher 的 Triple Quadrupole LC-MS 页面强调，三重四极杆适合 targeted compound detection and quantitation（靶向化合物检测和定量），并支持 SRM assay table 和高选择性定量。参考：[Thermo Fisher Triple Quadrupole LC-MS](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/liquid-chromatography-mass-spectrometry-lc-ms/lc-ms-systems/triple-quadrupole-lc-ms.html)

## MRM 和 SRM 的区别

| 项目 | [SRM](选择反应监测.md) | MRM |
| --- | --- | --- |
| 关注点 | 一个 selected reaction / transition | 多个 transition |
| 实际使用 | 常用于描述单个监测逻辑 | 常用于描述整套靶向方法 |
| 数据输出 | 一个目标 transition 峰 | 多个目标和确认 transition 峰 |
| 文献用法 | 常与 MRM 混用 | 常作为三重四极杆靶向定量总称 |

实际读文献或仪器软件时，不必过度纠结 SRM/MRM 名字。更重要的是看 transition 列表、保留时间、离子比、内标和定量验证。

## 定量 transition 和确认 transition

| 类型 | 作用 |
| --- | --- |
| Quantifier transition（定量 transition） | 峰面积用于计算浓度或相对丰度 |
| Qualifier transition（确认 transition） | 辅助确认目标身份 |
| Internal standard transition（内标 transition） | 修正进样、离子化和基质效应 |

一个成熟 MRM 方法通常不会只看一个峰。定量 transition 给出数值，确认 transition 和保留时间帮助判断这个峰是不是目标。

## 在靶向蛋白质谱中的意义

在靶向蛋白质谱里，MRM 不是直接测完整蛋白，而是选择能代表目标蛋白的 proteotypic peptide（代表性肽段），再监测该肽段的多个 transition。常见路线是：

```text
发现型蛋白质谱筛出候选蛋白
-> 选择代表性肽段
-> 合成标准肽或同位素内标
-> 建立 MRM transition
-> 在大批样本中验证
```

## 常见错误

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 假阳性 | transition 不特异，基质中有共洗脱峰 | 增加确认 transition，检查离子比 |
| 假阴性 | 保留时间漂移，窗口太窄 | 使用保留时间校正或扩大窗口 |
| 定量漂移 | 内标加入不稳定或基质效应 | 使用 [同位素内标](同位素内标.md)，检查回收率 |
| transition 太多 | dwell time 太短，峰采样不足 | 分段/调度 MRM，减少不必要目标 |
| 方法转移失败 | 仪器、柱子、梯度或源参数变化 | 重新优化 CE、RT window 和积分规则 |

## 小结

MRM 的核心是“同时盯住多个已知 transition”。它不是发现未知目标的工具，而是把已知目标测得准、测得稳、测得低的工具。它的质量取决于 transition 选择、内标、保留时间、基质验证和定量范围。
