# 端粒酶

端粒酶（telomerase）是一种 ribonucleoprotein reverse transcriptase（核糖核蛋白逆转录酶），可用自身携带的 RNA 模板在 [端粒](端粒.md) 3′ 末端添加 TTAGGG 重复序列，从而抵消线性染色体复制带来的末端缩短。

## 为什么会发现端粒酶

线性染色体复制存在 end-replication problem（末端复制问题）：普通 DNA polymerase（DNA 聚合酶）不能完全复制染色体最末端。Greider 和 Blackburn 在 Tetrahymena extract（四膜虫提取物）中发现一种能向端粒引物添加重复序列的酶活性，并把它命名为 telomere terminal transferase，后来发展为端粒酶概念。参考：[Greider and Blackburn, Cell, 1985](https://doi.org/10.1016/0092-8674(85)90170-9)。

这个发现解释了一个关键问题：如果端粒会因复制逐渐缩短，生殖系、干细胞和许多肿瘤细胞如何长期维持染色体末端。

## 核心组成

### TERT

TERT（telomerase reverse transcriptase，端粒酶逆转录酶）是端粒酶的催化蛋白亚基。它像逆转录酶一样读取 RNA 模板，并把 DNA 碱基加到端粒 3′ 末端。

在许多体细胞中，TERT 表达受严格限制；在很多癌细胞中，TERT 重新表达或调控增强，是端粒酶活性恢复的重要原因之一。

### TERC

TERC（telomerase RNA component，端粒酶 RNA 组分，也常称 hTR）提供 RNA template（RNA 模板）和结构支架。端粒酶用 TERC 的模板区指导 TTAGGG 重复序列添加。

TERC 不是普通“引物 RNA”，而是端粒酶复合体的一部分。TERC 稳定性、成熟加工和结合蛋白会影响端粒酶活性。

### 辅助因子和端粒招募

端粒酶还依赖 dyskerin complex（dyskerin 复合体）、TCAB1 等装配和定位因子，并受到 [shelterin complex（端粒保护蛋白复合物）](Shelterin.md)调控。TPP1-POT1 等端粒结合蛋白既可保护端粒，又能帮助端粒酶正确进入染色体末端。

端粒酶是否能“看到”端粒通常具有 [细胞周期](细胞周期.md)依赖性，尤其与 S 期端粒复制和端粒末端状态有关。端粒酶活性存在，不等于它在每个端粒、每个时间点都能延长。

## 端粒酶如何延长端粒

### 结合端粒 3′ overhang

端粒酶识别端粒富 G 链的 3′ overhang，并让端粒末端与 TERC 模板区配对。这个配对决定了新加重复序列的顺序。

### 添加 TTAGGG 重复序列

TERT 按照 TERC 模板把 dNTP 加到端粒末端，合成新的 G-rich telomeric repeat（富 G 端粒重复序列）。添加一个重复单元后，端粒酶可 translocate（移位）并继续下一轮添加，这种能力称为 repeat addition processivity（重复添加过程性）。

### C-rich strand 补齐

端粒酶主要延长 G-rich strand；互补 C-rich strand（富 C 链）需要由常规复制/填补机制完成。也就是说，端粒酶不是独自完成整个端粒复制，而是参与端粒末端维护的一部分。

## 在哪些细胞中常见

| 细胞类型或状态 | 常见端粒酶状态 | 解释 |
| --- | --- | --- |
| 生殖细胞 | 较高 | 维持跨代染色体末端完整性 |
| 胚胎干细胞和部分成体干/祖细胞 | 可检测或受调控 | 支持长期增殖，但仍受分化状态影响 |
| 多数成熟体细胞 | 很低或不可检测 | 限制无限增殖，端粒逐渐缩短 |
| 活化免疫细胞 | 可短暂上调 | 支持克隆扩增，但不等于完全永生化 |
| 多数癌细胞 | 常重新激活 | 为持续增殖提供端粒维持能力 |
| ALT 阳性肿瘤 | 可阴性，也可与端粒酶标志并存 | 端粒维持机制可能混合，不能只看一个指标 |

Kim 等在 1994 年报道，端粒酶活性与永生化细胞和癌症高度相关，而多数正常体细胞中较少检测到。参考：[Kim et al., Science, 1994](https://doi.org/10.1126/science.7605428)。

## 端粒酶与癌症的关系

端粒酶重新激活是肿瘤细胞获得 replicative immortality（复制性永生）的常见路径之一。它允许细胞绕开端粒缩短带来的复制性衰老和 crisis，但端粒酶本身不是“致癌开关”的全部。

更准确地说：

- 端粒酶可支持长期增殖，但还需要其他肿瘤相关改变共同作用。
- 端粒酶活性高不一定说明细胞已经恶性转化。
- 端粒酶阴性也不排除细胞通过 [ALT](ALT.md) 维持端粒。
- 端粒酶治疗或抑制策略需要考虑正常干细胞、免疫细胞和造血系统风险。

## 怎么检测端粒酶

### TRAP assay

[TRAP assay](<../../用(实验流程内容篇)/TRAP assay.md>)（telomeric repeat amplification protocol，端粒重复扩增实验）是检测端粒酶活性的经典方法。它先让样本中的端粒酶延长人工底物，再用 PCR 扩增延长产物。

TRAP 的优点是灵敏、适合多样本筛查；缺点是容易受 PCR inhibitor（PCR 抑制剂）、样本提取质量、蛋白降解和热灭活对照设置影响。TRAP 阳性表示样本中存在可检测端粒酶活性，不等于每个细胞、每个端粒都正在被延长。

### TERT/TERC 表达

RT-qPCR、RNA-seq 或蛋白检测可评估 TERT/TERC 表达。但表达不完全等同于活性：装配、定位、端粒招募和复合体稳定性都可能限制功能。

### 端粒长度随传代变化

端粒酶功能最终要看端粒是否能在长期传代中被维持。端粒长度可通过 [端粒长度检测](端粒长度检测.md)相关方法分析，包括 TRF Southern blot、qPCR、Flow-FISH、qFISH 或长读长测序等。

## 端粒酶维持与 ALT 对比

| 特征 | 端粒酶维持 | ALT 维持 |
| --- | --- | --- |
| 核心分子 | TERT + TERC + 辅助因子 | 重组/复制因子、APB、端粒模板 |
| 模板来源 | TERC RNA 模板 | 姐妹端粒、其他端粒或染色体外端粒 DNA |
| 端粒长度分布 | 常较集中，但依细胞而变 | 常高度不均一 |
| 典型检测 | TRAP、TERT/TERC 表达、端粒长度维持 | C-circle、APB、T-SCE、端粒异质性 |
| 主要风险 | 支持异常细胞持续增殖 | 端粒重组和基因组不稳定 |
| 是否可并存 | 可以 | 可以 |

## 与端粒缩短、衰老和疾病的关系

端粒酶不足或端粒维护缺陷可导致 telomere biology disorders（端粒生物学障碍），包括骨髓衰竭、肺纤维化、肝病和其他组织再生不足相关表现。Armanios 和 Blackburn 将这些由端粒维护缺陷相关的临床状态总结为 telomere syndromes（端粒综合征）。参考：[Armanios and Blackburn, Nature Reviews Genetics, 2012](https://doi.org/10.1038/nrg3246)。

反过来，端粒酶重新激活又可帮助癌细胞避免端粒危象。因此端粒酶处在一个非常微妙的位置：太低会限制组织更新，太高或错误激活会支持异常增殖。

## 常见误读

| 说法 | 更准确的理解 |
| --- | --- |
| 端粒酶就是让细胞不老的酶 | 它能维护端粒，但衰老还受 DNA 损伤、表观遗传、代谢和炎症等影响 |
| TERT 高就一定 TRAP 阳性 | TERT 表达还要经过装配、定位和端粒招募才能形成有效活性 |
| TRAP 阳性说明端粒一定变长 | TRAP 是体外活性读出，仍需长期端粒长度追踪 |
| 端粒酶阳性就排除 ALT | 两者可在部分背景中并存，需联合 C-circle、APB 和端粒长度分布 |
| 抑制端粒酶会立刻杀死癌细胞 | 许多效应依赖端粒逐渐缩短，时间尺度可能较长 |

## 小结

端粒酶是用 RNA 模板延长端粒的核糖核蛋白逆转录酶。它解决线性染色体末端复制损失问题，也支持许多癌细胞持续增殖。实验上应把端粒酶活性、TERT/TERC 表达、端粒长度变化和 ALT 标志分开看，避免把“有端粒酶”直接等同于“端粒一定稳定”或“细胞一定永生”。
