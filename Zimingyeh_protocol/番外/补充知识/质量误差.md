# 质量误差

Mass error（质量误差）是质谱实测 m/z 与理论 m/z 或校准参考 m/z 之间的偏差，常用 ppm（parts per million，百万分之一）表示。它是判断 [准确质量](准确质量.md) 是否可靠的关键指标。

![蛋白质组学常用质谱仪类型概览](../../z_asset/材/质谱仪器/mass-spectrometry-instrument-types-reference.png)

图源：Image2 生成的质谱仪器类型参考图。Orbitrap 和 Q-TOF 都常用于 accurate-mass 数据，质量误差是评价这类数据是否可信的核心指标之一。

## 怎么计算

常见公式：

```text
ppm error = (measured m/z - theoretical m/z) / theoretical m/z × 1,000,000
```

例子：

```text
理论 m/z = 500.0000
实测 m/z = 500.0025
质量误差 = 5 ppm
```

如果用 Da 表示绝对误差：

```text
absolute error = measured m/z - theoretical m/z
```

ppm 的好处是可以把不同 m/z 范围的误差放在同一尺度上比较。

## 质量误差说明什么

| 观察 | 可能含义 |
| --- | --- |
| 误差集中在 0 附近 | 质量轴校准状态较好 |
| 整体正偏或负偏 | 存在系统性校准偏差 |
| 高 m/z 区域误差更大 | 质量轴拟合或校准范围可能不合适 |
| 弱峰误差更散 | 信噪比低，峰中心不稳 |
| 某些峰误差异常 | 共洗脱干扰、选错同位素峰或误匹配 |

Thermo Fisher 的 Orbitrap 页面将 Orbitrap 系统定位为 high-resolution accurate-mass（高分辨准确质量，HRAM）平台；在这类数据中，质量误差通常是判断 HRAM 数据是否可信的基础 QC 指标。参考：[Thermo Fisher Orbitrap LC-MS](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/liquid-chromatography-mass-spectrometry-lc-ms/lc-ms-systems/orbitrap-lc-ms.html)

## 影响质量误差的因素

| 因素 | 影响 |
| --- | --- |
| [质量校准](质量校准.md) | 校准过期或不当会造成系统偏移 |
| lock mass / internal calibration | 可修正运行中的质量轴漂移 |
| 峰信噪比 | 弱峰中心更难准确定位 |
| 峰重叠 | 共洗脱峰会拉偏 m/z |
| 同位素峰选择 | 单同位素峰选错会产生明显误差 |
| 电荷态判断 | 电荷态错会导致质量解释错 |
| 数据处理参数 | 去同位素、峰提取和搜索容差都会影响结果 |

## 在蛋白质谱中的用法

在 [蛋白质谱](<../../用(实验流程内容篇)/蛋白质谱.md>) 中，常见检查包括：

- PSM（peptide-spectrum match，肽段-谱图匹配）的前体离子质量误差分布。
- 碎片离子质量误差分布。
- 目标肽段是否落在搜索容差内。
- 质量误差是否随保留时间漂移。
- 异常批次是否有系统性质量偏移。

如果质量误差分布很宽或偏离 0，先检查校准、仪器状态、搜索参数和样本污染，而不是直接相信鉴定结果。

## 常见误解

| 误解 | 更准确的理解 |
| --- | --- |
| 质量误差小就一定鉴定正确 | 还需要 MS/MS、FDR、保留时间和同位素分布支持 |
| ppm 阈值越小越严格越好 | 阈值过窄可能漏掉真实峰，需匹配仪器和方法 |
| 质量误差只由仪器决定 | 样本、峰重叠、信噪比和软件都会影响 |
| 所有 m/z 的误差都一样 | 不同质量范围和信号强度误差表现可能不同 |

## 小结

质量误差是 accurate mass 的“偏差读数”。它可以帮助判断仪器质量轴、峰匹配和数据库搜索是否可信，但不能单独证明结构或肽段身份。好的质谱结果通常要求质量误差分布合理、MS/MS 谱图可信、保留时间一致，并通过 FDR 或标准品验证。
