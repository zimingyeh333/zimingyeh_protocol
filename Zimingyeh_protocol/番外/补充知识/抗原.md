# 抗原

Antigen（抗原）是能够被 [抗体](抗体.md)、B cell receptor（BCR，B 细胞受体）或 T cell receptor（TCR，T 细胞受体）特异性识别的分子或分子结构；在实验语境中，抗原通常指抗体检测、免疫反应或疫苗设计中被识别的目标对象。

图：抗体识别基础示意。抗原是被识别的整体对象，表位是抗体实际接触的局部结构；夹心 ELISA 需要捕获抗体和检测抗体识别不重叠表位。本图复用项目内 Image2 / image-generation model 生成图，用于个人学习笔记示意。

## 一句话理解

抗原不是“整个病原体”这么粗糙的概念，而是能被免疫识别系统抓住的分子对象。

Janeway Immunobiology 对抗体识别的解释强调，抗体的 antigen-binding site（抗原结合位点）与抗原上的具体表面结构结合，这些被结合的局部结构称为 epitope（[表位](表位.md)）。参考：[NCBI Bookshelf: Antigen recognition by B-cell and T-cell receptors](https://www.ncbi.nlm.nih.gov/books/NBK27160/)。

## 抗原、免疫原和表位

| 概念 | 英文 | 中文 | 重点 |
| --- | --- | --- | --- |
| Antigen | Antigen | 抗原 | 被抗体/BCR/TCR 识别的对象 |
| [免疫原](免疫原.md) | Immunogen | 免疫原 | 能诱导免疫反应的抗原 |
| Epitope | Epitope / antigenic determinant | 表位 / 抗原决定簇 | 抗体实际接触的局部结构 |
| Hapten | Hapten | [半抗原](半抗原.md) | 可被识别但通常需载体才强免疫原性 |

一个抗原可以有多个表位；一支抗体通常识别其中一个或一类表位。抗原是否能诱导免疫反应，还取决于大小、复杂性、外源性、加工呈递和宿主免疫状态。

## 实验中常见抗原类型

| 抗原类型 | 例子 | 实验意义 |
| --- | --- | --- |
| Protein antigen（蛋白抗原） | 细胞因子、受体、酶 | 抗体实验最常见 |
| Peptide antigen（肽抗原） | 10-20 aa 合成肽 | 常用于制备或验证抗体 |
| Carbohydrate antigen（糖类抗原） | 细菌荚膜多糖、血型抗原 | 结构重复，免疫特性不同 |
| Lipid antigen（脂质抗原） | 某些脂质或糖脂 | 常需特殊呈递系统 |
| Small molecule antigen（小分子抗原） | 药物、激素、毒素 | 常需竞争法或半抗原策略 |
| Recombinant antigen（重组抗原） | [重组蛋白](<../../材(实验耗材工具篇)/重组蛋白.md>) | 可作标准品、免疫原或验证材料 |

在 [ELISA](<../../用(实验流程内容篇)/ELISA.md>) 中，抗原可以是待测目标物，也可以是包被在板上的捕获对象，具体取决于直接、间接、夹心或竞争 ELISA 的设计。

## 抗原形态为什么重要

同一个蛋白可以以多种形态出现：

- 天然构象蛋白。
- 变性蛋白。
- 片段或结构域。
- 带标签重组蛋白。
- 糖基化或磷酸化修饰蛋白。
- 多聚体或复合物。

抗体识别的是具体表位，因此抗原形态变化可能导致抗体识别能力变化。例如 Western blot 中蛋白被变性，适合识别 linear epitope（线性表位）的抗体；免疫荧光或夹心 ELISA 更依赖 native/conformational epitope（天然/构象表位）。

## 和 ELISA 的关系

不同 ELISA 中抗原位置不同：

| ELISA 类型 | 抗原的位置 | 关键变量 |
| --- | --- | --- |
| [直接ELISA](<../../用(实验流程内容篇)/直接ELISA.md>) | 抗原包被在板上 | 包被效率和表位暴露 |
| [间接ELISA](<../../用(实验流程内容篇)/间接ELISA.md>) | 抗原包被，检测样本抗体 | 抗原纯度和非特异背景 |
| [夹心ELISA](<../../用(实验流程内容篇)/夹心ELISA.md>) | 样本抗原被捕获抗体夹住 | 抗原需有两个可同时识别表位 |
| [竞争ELISA](<../../用(实验流程内容篇)/竞争ELISA.md>) | 样本抗原与标记抗原或抗体竞争 | 适合小分子或单表位目标 |

夹心 ELISA 对抗原大小和表位数量要求更高；小分子或半抗原通常难以同时容纳两支抗体，因此更常用竞争法。

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 抗体能识别重组蛋白但不识别样本 | 重组抗原和天然抗原构象/修饰不同 | 换抗体或使用天然样本验证 |
| Western blot 有条带但 IF 无信号 | 抗体只识别线性表位 | 选择验证过 IF 的抗体 |
| 夹心 ELISA 无曲线 | 抗原没有两个可同时结合表位 | 更换 [配对抗体](<../../材(实验耗材工具篇)/配对抗体.md>) |
| 背景高 | 抗原不纯或非特异吸附 | 提高抗原纯度，优化封闭和洗涤 |
| 标准品和样本不一致 | 标准抗原与样本抗原形态不同 | 做 spike-and-recovery 和稀释线性 |

## 小结

抗原是免疫识别的目标对象，但真正决定实验表现的是它的表位、构象、修饰和样本中的存在状态。做抗体实验时，不要只问“抗体是否 anti-X”，还要问“它识别的是 X 的哪种形态和哪个表位”。
