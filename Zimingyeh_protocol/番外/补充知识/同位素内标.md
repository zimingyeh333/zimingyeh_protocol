# 同位素内标

Stable isotope-labeled internal standard（稳定同位素标记内标，常简称同位素内标）是在质谱定量中加入的、与目标物化学性质高度相似但质量不同的标准物。它常用于 LC-MS/MS、MRM/SRM、PRM 和生物分析方法中，用来校正样本处理损失、进样波动、[LC-MS基质效应](LC-MS基质效应.md) 和离子化差异。

## 一句话理解

同位素内标回答的是：“目标物在样本处理和质谱检测过程中损失了多少、信号被抑制了多少，我如何校正？”

理想同位素内标和目标物几乎一起经历全过程：

```text
加入样本
-> 提取/消化/净化
-> LC 分离
-> ESI 离子化
-> MS/MS 检测
-> 用 analyte / internal standard 峰面积比定量
```

ICH M10 生物分析方法验证指南把 internal standard response、matrix effects、calibration curve、accuracy、precision 等作为 LC-MS/MS 等生物分析方法可靠性的关键内容。参考：[ICH M10 Bioanalytical Method Validation](https://database.ich.org/sites/default/files/M10_Guideline_Step4_2022_0524.pdf)

## 常见类型

| 类型 | 说明 | 适合场景 |
| --- | --- | --- |
| 稳定同位素小分子内标 | 目标小分子的 D、13C、15N 标记版本 | 药物、代谢物定量 |
| 同位素标记肽段 | 合成 heavy peptide | 靶向蛋白质谱、PRM/MRM |
| 同位素标记蛋白 | heavy protein 或 QconCAT | 更接近完整前处理流程 |
| SILAC 内标 | 细胞中代谢掺入 heavy amino acids | 细胞蛋白组相对定量 |
| 同位素标记标准曲线 | 多浓度内标/标准物组合 | 绝对定量和方法验证 |

## 为什么同位素内标比普通内标强

| 项目 | 同位素内标 | 普通结构类似物内标 |
| --- | --- | --- |
| 化学性质 | 与目标物几乎相同 | 相似但不完全一致 |
| 保留时间 | 通常非常接近 | 可能有偏差 |
| 离子化行为 | 更能模拟目标物 | 基质效应校正较弱 |
| 质量区分 | m/z 不同，可独立检测 | 依赖结构差异 |
| 成本 | 高 | 通常较低 |

同位素内标最适合高准确度定量，但并不总是必须。早期筛查或相对比较可以先用外标或 label-free；正式验证和绝对定量则更推荐同位素内标。

## 在靶向蛋白质谱中的使用

靶向蛋白质谱常用 heavy peptide（重标记肽段）作为内标：

```text
选择目标蛋白代表性肽段
-> 合成 heavy peptide
-> 加入样本或酶切后样本
-> 监测 light peptide 和 heavy peptide transitions
-> 用 light/heavy 峰面积比定量
```

需要注意：如果 heavy peptide 在酶切后才加入，它只能校正 LC-MS 进样和离子化差异，不能校正蛋白提取和酶切效率。如果要校正更完整流程，需要更早加入同位素标记蛋白或类似全流程内标。

## 同位素内标 vs TMT

| 项目 | 同位素内标 | [TMT](TMT.md) |
| --- | --- | --- |
| 主要目的 | 校正和绝对/靶向定量 | 多样本相对定量 |
| 加入方式 | 每个样本加入内标 | 不同样本分别标记后混合 |
| 数据读数 | analyte/internal standard 比值 | reporter ion 通道比例 |
| 常见平台 | 三重四极杆、PRM、LC-MS/MS | Orbitrap TMT workflow |
| 优势 | 定量准确度和校正能力强 | 多样本通量高 |

## 常见错误

| 错误 | 后果 |
| --- | --- |
| 内标加入太晚 | 不能校正前处理损失 |
| 内标浓度不合适 | 峰面积比不在线性范围内 |
| 只用内标不做标准曲线 | 无法可靠绝对定量 |
| heavy peptide 不代表目标蛋白 | 不能反映蛋白水平 |
| 忽略内标纯度和批号 | 长期项目批次差异增加 |

## 小结

同位素内标是质谱定量的“随行参照物”。它通过与目标物几乎相同的化学行为和不同的质量，实现对损失、离子抑制和进样波动的校正。越接近正式验证、绝对定量和大队列检测，同位素内标越重要。
