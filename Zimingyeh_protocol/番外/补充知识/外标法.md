# 外标法

External standard method（外标法）是用一组已知浓度的标准品单独建立 [标准曲线](标准曲线.md)，再把未知样本的检测信号代入曲线计算浓度的定量方法。它是最直观的定量思路，但对样本基质和前处理一致性要求很高。

图源：Image2 生成的 LC-MS 定量策略示意图。外标法与内标法、同位素稀释同属于“把信号放进校准体系”的定量策略，但校正能力不同。

## 核心逻辑

外标法的流程是：

```text
已知浓度标准品
-> 建立信号-浓度标准曲线
-> 测未知样本信号
-> 代入曲线
-> 得到样本浓度
```

它假设标准品和未知样本在检测体系中的响应关系一致。如果标准品在干净溶剂里，真实样本在血浆、组织匀浆或培养基里，这个假设就可能不成立。

## 适合什么场景

| 场景 | 为什么适合 |
| --- | --- |
| 基质简单的样本 | 标准品和样本响应差异小 |
| 前处理很少或很稳定 | 样本损失不明显 |
| 常规比色或荧光定量 | 例如纯化蛋白、酶活产物、简单溶液 |
| 初筛实验 | 快速建立浓度-信号关系 |
| 商业 kit 已验证体系 | 说明书规定的标准曲线常属于外标逻辑 |

## 和内标法、标准加入法的区别

| 方法 | 标准品在哪里 | 校正能力 | 适合情况 |
| --- | --- | --- | --- |
| 外标法 | 标准品单独配制 | 弱，主要依赖曲线 | 基质简单、流程稳定 |
| [内标法](内标法.md) | 每个样本和标准品都加内标 | 中到强，可校正进样和部分前处理波动 | LC-MS/HPLC/GC-MS 常用 |
| [标准加入法](标准加入法.md) | 标准品直接加到真实样本中 | 强，可处理基质效应 | 空白基质难获得、样本复杂 |
| [同位素稀释](同位素稀释.md) | 同位素内标加到样本中 | 很强，尤其适合 LC-MS | 高准确度绝对定量 |

## 关键风险

| 风险 | 后果 | 处理 |
| --- | --- | --- |
| 基质效应 | 样本信号和标准品信号不可比 | 使用基质匹配标准曲线、内标或标准加入法 |
| 前处理回收率不稳定 | 样本浓度被低估或变异大 | 加入过程控制或改用内标法 |
| 标准品配制错误 | 全部未知样本一起错 | 记录批号、复溶、稀释链和有效期 |
| 超出线性范围 | 曲线外推导致假浓度 | 稀释样本进入 [线性范围](线性范围.md) |
| 仪器漂移 | 早晚样本响应不同 | 插入 QC 样本或重复校准 |

## 实验判断

如果外标法得到的结果和样本稀释倍数不一致，或加标回收率很差，说明样本背景正在影响定量。此时继续优化拟合模型通常不够，需要改成基质匹配曲线、标准加入法或内标法。

## 小结

外标法简单、直观、成本低，是很多定量实验的起点。它的弱点也很清楚：它默认标准品和样本“响应一致”。一旦真实样本基质复杂或前处理损失明显，外标法就容易给出看似精确但实际偏差很大的浓度。
