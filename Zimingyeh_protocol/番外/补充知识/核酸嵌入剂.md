# 核酸嵌入剂

核酸嵌入剂（nucleic acid intercalator）是能插入 DNA 或 RNA 碱基对之间的小分子。实验中最经典的例子是 [EB](<../../材(实验耗材工具篇)/EB.md>)（ethidium bromide，溴化乙锭），它插入双链核酸后荧光增强，因此长期用于核酸凝胶条带可视化。

![Nucleic acid intercalating stain reference](../../z_asset/番外/补充知识/核酸嵌入剂/nucleic-acid-intercalating-stain-reference.png)

图源：Image2 生成的核酸跑胶试剂组参考图；EtBr 被作为 classic intercalating stain（经典嵌入型染料）示意，提醒它和安全替代染料、成像光源、安全管理是同一个体系问题。

## 核心机制

核酸双螺旋的碱基对像一叠片状结构，某些平面芳香小分子可以插入碱基对之间。插入后分子周围环境改变，荧光可能增强；同时这种插入也可能干扰 DNA 复制、转录或修复，因此很多 intercalating agents（嵌入剂）具有 mutagenic（致突变）风险。

Thermo Fisher 的 Ethidium Bromide 页面说明，EtBr 作为 DNA intercalator 插入 DNA 双螺旋碱基之间，并在 UV 照射下发出橙红色荧光；同时页面提醒 EtBr 是 potent mutagen。参考：[Thermo Fisher Ethidium Bromide Stain](https://www.thermofisher.cn/cn/en/home/life-science/dna-rna-purification-analysis/nucleic-acid-gel-electrophoresis/dna-stains/etbr.html)。

## 在实验中的位置

| 场景 | 嵌入剂的角色 |
| --- | --- |
| 琼脂糖凝胶电泳 | 让 DNA/RNA 条带可视化 |
| 细胞核染色 | 某些核酸染料结合 DNA 后显示细胞核 |
| 药物机制研究 | 部分抗肿瘤药物或化合物可通过 DNA intercalation 产生生物效应 |
| 安全管理 | 需要警惕潜在致突变性和污染扩散 |

在 [琼脂糖凝胶电泳](<../../用(实验流程内容篇)/琼脂糖凝胶电泳.md>) 里，嵌入剂相关问题主要集中在“能否看见条带、是否影响迁移、是否损伤 DNA、如何处理废物”。

## 嵌入剂不等于所有核酸染料

| 类别 | 例子 | 说明 |
| --- | --- | --- |
| 经典嵌入剂 | EB/EtBr | 插入碱基对，UV 下荧光增强 |
| 安全替代核酸染料 | SYBR Safe、GelRed/GelGreen | 机制、细胞通透性和安全测试不同，不能简单等同 EB |
| 细胞核染料 | DAPI、Hoechst、PI | 可能通过小沟结合、嵌入或其他方式结合 DNA |

因此，写 protocol 时最好用具体染料名称，不要笼统写“加 DNA dye”。不同染料的激发/发射、成像设备、迁移影响和安全处理都不同。

## 注意事项

- “能染 DNA”不代表适合所有下游实验。
- 嵌入型染料可能影响 DNA 迁移，预染胶尤其需要注意。
- 安全替代染料也要按化学品管理，不要因为“safer”就裸手操作。
- 需要胶回收时，成像光源和照射时间往往比染料名字本身更关键。

## 小结

核酸嵌入剂是理解 EB 风险和核酸染色机制的核心概念。它解释了为什么某些染料能让 DNA 发光，也解释了为什么这些试剂不能当作普通颜色染料随意处理。
