# 免疫原

Immunogen（免疫原）是能够诱导机体产生免疫反应的物质；在抗体制备语境中，它通常指用于免疫动物或刺激免疫系统、从而获得特异性 [抗体](抗体.md) 的抗原材料。

![Antibody recognition basics](../../z_asset/番外/补充知识/抗体识别基础/antibody-recognition-basics-reference.png)

图：抗体识别基础示意。免疫原决定免疫系统最初“看见”的结构，而实验中的目标抗原可能是天然蛋白、变性蛋白、固定组织中的蛋白或包被在板上的蛋白，两者不完全等同。

## 一句话理解

免疫原回答的是：“当初用什么东西训练免疫系统产生这支抗体？”

不是所有 [抗原](抗原.md) 都是好免疫原。抗原强调“能被抗体或受体识别”，免疫原则强调“能诱导免疫反应”。例如小分子 [半抗原](半抗原.md) 可以被抗体识别，但单独使用通常免疫原性不足，常需要连接 [载体蛋白](载体蛋白.md) 后再免疫。

## 免疫原和抗原的关系

| 概念 | 英文 | 核心问题 | 例子 |
| --- | --- | --- | --- |
| 抗原 | Antigen | 能不能被抗体识别 | 蛋白、肽段、多糖、小分子 |
| 免疫原 | Immunogen | 能不能诱导免疫反应 | 全长蛋白、蛋白片段、偶联肽 |
| 半抗原 | Hapten | 小分子能不能被识别但免疫原性不足 | 药物小分子、毒素小分子 |
| 表位 | Epitope | 抗体实际识别哪一小段结构 | 线性肽段或构象表面 |

简单说：免疫原通常也是抗原，但抗原不一定是有效免疫原。

## 影响免疫原性的因素

| 因素 | 影响逻辑 | 实验含义 |
| --- | --- | --- |
| 分子大小 | 太小的分子难以诱导强免疫反应 | 小肽或半抗原常要偶联载体蛋白 |
| 结构复杂度 | 结构越复杂，可被识别的表位越多 | 蛋白通常比短肽更容易产生多样抗体 |
| 外源性 | 与宿主自身越不同，免疫反应越容易发生 | 保守蛋白可能免疫原性较低 |
| 可降解性 | 抗原需要被处理并呈递 | 过于稳定或不可处理可能影响免疫 |
| 剂量和途径 | 影响免疫强度和抗体谱 | 皮下、腹腔、肌肉等路线会影响结果 |
| [佐剂](佐剂.md) | 增强免疫刺激 | 常用于提高抗体滴度 |
| 宿主种属 | 不同动物对同一免疫原反应不同 | rabbit、mouse、goat 等结果可能不同 |

Janeway Immunobiology 在讲抗原识别时强调，抗体识别依赖抗体结合位点和抗原表面之间的互补性。免疫原的结构会影响最终产生哪些抗体克隆，因此也会影响后续实验的特异性和适用场景。参考：[NCBI Bookshelf: Antigen recognition by B-cell and T-cell receptors](https://www.ncbi.nlm.nih.gov/books/NBK27160/)。

## 常见免疫原形式

| 形式 | 优点 | 风险或限制 | 适合场景 |
| --- | --- | --- | --- |
| 全长重组蛋白 | 表位多，较接近蛋白整体结构 | 纯化难，标签或折叠可能影响抗体谱 | 希望获得多表位抗体或夹心 ELISA 抗体库 |
| 蛋白片段 | 聚焦特定区域，表达较容易 | 可能缺少天然构象 | 针对结构域或特定区域制备抗体 |
| 合成肽 | 设计灵活，能避开同源区域 | 常需载体蛋白，可能只适合线性表位 | WB、特定位点、磷酸化位点抗体 |
| 全细胞或膜组分 | 保留部分天然表面结构 | 成分复杂，特异性筛选困难 | 表面抗原、细胞分型抗体开发 |
| 小分子偶联物 | 可产生抗小分子抗体 | 偶联方式影响识别方向 | 药物、激素、毒素检测 |

## 设计免疫原时要想清楚什么

| 问题 | 为什么重要 |
| --- | --- |
| 实验最终检测的是天然蛋白还是变性蛋白 | WB 常检测变性线性表位，flow/IF/IHC 更依赖构象或固定后表位 |
| 目标蛋白是否有同源家族 | 免疫原要尽量避开高度同源区域，减少交叉反应 |
| 是否需要区分 isoform | 免疫原应覆盖差异区域 |
| 是否需要检测翻译后修饰 | 磷酸化、乙酰化等抗体要围绕修饰位点设计 |
| 是否用于夹心 ELISA | 最好产生能识别不同表位的抗体组合 |
| 免疫原是否带标签 | 抗体可能意外识别 tag 或载体污染 |

免疫原设计不等于简单挑一段序列。它决定了抗体将来能不能识别真实样本中的目标，也决定了抗体在不同实验之间是否能迁移使用。

## 和抗体选择的关系

购买抗体时，说明书中的 immunogen 信息非常值得看。它可以帮助判断：

- 抗体可能识别蛋白的哪一区域。
- 是否可能识别所有 isoform 或只识别部分 isoform。
- 是否可能与同源蛋白交叉反应。
- 是否适合变性样本或天然构象样本。
- 如果样本中目标区域被剪切、突变或修饰，抗体是否还可能识别。

如果一个抗体说明书没有公开免疫原信息，不能说它一定不好，但排查问题时会少一个关键线索。

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 抗体只能用于 WB，不能用于 IF | 免疫原是线性肽段，抗体不识别天然构象 | 换经 IF 验证的抗体 |
| 抗体识别多个同源蛋白 | 免疫原区域太保守 | 查看免疫原序列同源性，换特异区域抗体 |
| 目标剪切后信号消失 | 免疫原对应区域被剪掉 | 换 N 端或 C 端不同区域抗体 |
| 小分子抗体特异性差 | 半抗原偶联方向或筛选不足 | 优化偶联策略和交叉反应筛选 |
| 夹心 ELISA 配对失败 | 抗体识别同一或互相遮挡的表位 | 重新筛选捕获/检测抗体组合 |

## 小结

免疫原是理解抗体来源和实验表现的入口。看懂免疫原，才能判断一支抗体为什么能识别某个目标、为什么可能不适合某个实验，以及为什么同一个目标的不同抗体表现会差很多。
