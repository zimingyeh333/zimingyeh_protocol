# 内参基因

Reference gene（参考基因，常被称为内参基因）是在 RT-qPCR 相对定量中用于归一化样本输入量、RNA 质量、逆转录效率和总体技术波动的基因；理想内参基因应在当前样本类型和处理条件下稳定表达。

## 一句话理解

内参基因不是“永远稳定的管家基因”，而是“在你这次实验条件下经过验证的归一化参照”。

MIQE 指南强调 reference gene 的选择和验证应被报告，不能只默认使用 GAPDH、ACTB 等常见 housekeeping genes（管家基因）。参考：[MIQE guidelines, Clinical Chemistry 2009](https://academic.oup.com/clinchem/article/55/4/611/5631762)。

## 为什么需要内参基因

RT-qPCR 中样本之间可能存在很多非生物学差异：

- RNA 起始量略有不同。
- RNA 完整性不同。
- 逆转录效率不同。
- 移液和反应体系有小误差。
- 总细胞数或组织输入量不同。

内参基因用于把目标基因的 Cq 放到同一个参照尺度上，降低这些技术变量对表达比较的影响。

## 好内参的标准

| 标准 | 说明 |
| --- | --- |
| 当前条件下稳定 | 不随处理、时间、组织或细胞状态明显变化 |
| 表达量适中 | Cq 不应过高或过低，最好和目标基因量级接近 |
| 扩增效率合理 | 应和目标基因效率接近 |
| 特异扩增 | 熔解曲线单峰，NTC 干净 |
| 生物学相关性低 | 不应被实验处理直接调控 |
| 可重复 | 技术重复和生物学重复中波动小 |

Vandesompele 等人提出，用多个内参基因的几何平均值进行归一化，通常比单一内参更稳健。参考：[Vandesompele et al., Genome Biology 2002](https://pubmed.ncbi.nlm.nih.gov/12184808/)。

## 常见内参基因的风险

| 常见基因 | 风险 |
| --- | --- |
| GAPDH | 受代谢、缺氧、增殖状态影响 |
| ACTB | 受细胞骨架、迁移、分化状态影响 |
| 18S rRNA | 表达极高，和 mRNA 逆转录/降解行为不完全一致 |
| RPLP0/RPL13A | 核糖体相关处理可能影响表达 |
| HPRT1/TBP | 某些细胞类型或处理条件下也会波动 |

这些基因不是不能用，而是不能未经验证就默认稳定。

## 如何验证内参基因

| 步骤 | 目的 |
| --- | --- |
| 选择 3-6 个候选基因 | 避免把希望寄托在单个常见基因上 |
| 覆盖所有处理组和样本类型 | 稳定性必须在真实条件下验证 |
| 检查 Cq 分布 | 排除太高、太低或波动大的候选 |
| 检查扩增效率和熔解曲线 | 确认候选基因技术上可靠 |
| 用稳定性算法或经验筛选 | geNorm、NormFinder 或综合 CV 判断 |
| 必要时使用多个内参 | 用几何平均值降低单一内参风险 |

## 和 Cq、ΔCq 的关系

常见相对定量逻辑：

```text
ΔCq = Cq(target gene) - Cq(reference gene)
```

如果内参基因在处理组中也发生变化，ΔCq 会把内参变化误认为目标基因变化的一部分，导致方向错误或幅度错误。

| 内参问题 | 可能造成的假象 |
| --- | --- |
| 处理组内参升高 | 目标表达被低估 |
| 处理组内参降低 | 目标表达被高估 |
| 内参复孔差异大 | ΔCq 重复性变差 |
| 内参与目标效率不一致 | fold change 计算偏差 |

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 目标基因趋势不稳定 | 内参本身波动 | 换内参或使用多个内参 |
| 所有目标归一化后都变化 | 内参被处理影响 | 检查原始 Cq 和候选内参稳定性 |
| 内参 Cq 很低 | 表达过高，和目标不匹配 | 换表达量更接近目标的内参 |
| 内参 Cq 很高 | 表达太低，随机性大 | 换更稳定高表达候选 |
| 不同细胞类型结果矛盾 | 同一内参跨细胞不稳定 | 分细胞类型验证内参 |

## 小结

内参基因决定 RT-qPCR 相对定量的地基。任何处理、细胞状态或组织类型变化明显的实验，都应该验证内参稳定性，而不是直接套用 GAPDH 或 ACTB。
