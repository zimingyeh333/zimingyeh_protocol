# 造血祖细胞

造血祖细胞（hematopoietic progenitor cells，HPC）是 hematopoietic stem and progenitor cell（HSPC，造血干/祖细胞）体系中已经具有一定分化方向、但仍保留增殖和生成血液谱系细胞能力的细胞群。实验中常以 [CD34](CD34.md)+ enriched cells（CD34 阳性富集细胞）作为人源造血干/祖细胞相关样本入口。

图源：Image2 生成的关键细胞群概览图；造血祖细胞位于右侧，重点是 CD34+ 富集、谱系潜能和 CFU readout。

## 核心定位

造血祖细胞位于 hematopoietic stem cells（HSC，造血干细胞）和成熟血细胞之间。HSC 更强调长期自我更新和多谱系重建能力；HPC 通常更偏短期扩增和特定谱系输出。实际体外实验里，很多样本并不会严格只含“纯 HPC”，而是 HSC、multipotent progenitors（多能祖细胞）和 lineage-biased progenitors（谱系偏向祖细胞）的混合。

STEMCELL Technologies 的 MethoCult 资料将 colony-forming unit assay（CFU assay，集落形成单位实验）作为检测 hematopoietic progenitor cells 的功能方法之一。参考：[STEMCELL Technologies MethoCult](https://www.stemcell.com/products/brands/methocult.html)。

## 来源与常见样本

| 来源 | 常见特点 | 记录重点 |
| --- | --- | --- |
| 骨髓 | 经典造血组织来源 | 供体、处理时间、抗凝剂、分离方法 |
| 脐血 | CD34+ 细胞常见来源 | 采集和冻存流程、细胞数、活率 |

| iPSC/hESC分化产物 | 体外造血分化模型 | 分化 protocol、时间点、marker panel |
| 细胞库或商业细胞 | 标准化程度较高 | 供应商、货号、批号、复苏后 QC |

## 常见marker与功能读数

| 指标 | 英文 | 含义 |
| --- | --- | --- |
| CD34 | Cluster of Differentiation 34 | 人源 HSPC 富集常用 marker，但不是功能定义本身 |
| CD38 | Cluster of Differentiation 38 | 常与 CD34 联合区分更原始或更成熟群体 |
| CD45 | Leukocyte common antigen | 白细胞/造血来源细胞常用 marker |
| CFU-GM | Colony-Forming Unit-Granulocyte/Macrophage | 粒/巨噬方向集落形成能力 |
| BFU-E | Burst-Forming Unit-Erythroid | 红系祖细胞相关集落 |
| CFU-GEMM | Colony-Forming Unit-Granulocyte/Erythrocyte/Macrophage/Megakaryocyte | 多谱系集落形成能力 |

CD34+ 不等于“所有细胞都是造血干细胞”。CD34 是富集和表型入口，真正的功能状态还需要 CFU assay、长期培养、移植模型或更复杂的功能检测来支持。

## 造血干细胞 vs 造血祖细胞

| 项目 | 造血干细胞 HSC | 造血祖细胞 HPC |
| --- | --- | --- |
| 自我更新 | 强，尤其长期 HSC | 有限或较弱 |
| 分化潜能 | 多谱系、长期重建 | 更偏短期扩增和谱系输出 |
| 实验定义 | 需要功能性长期重建证据 | 常用 marker + CFU/体外功能检测 |
| 常见读数 | 移植重建、长期多谱系贡献 | CFU-GM、BFU-E、CFU-GEMM 等 |

在日常体外实验里，如果只是 CD34+ 富集细胞或 CFU assay，写成 HSPC/HPC 往往比直接宣称“造血干细胞”更稳妥。

## 常见用途

| 场景 | 用途 |
| --- | --- |
| CFU assay | 评估祖细胞集落形成能力和谱系潜能 |
| 药物毒性 | 检测药物是否抑制造血祖细胞功能 |
| 基因编辑 | 检查编辑后 CD34+ 细胞是否保留功能 |
| iPSC造血分化 | 验证体外分化产物是否具有造血祖细胞样功能 |
| 冻存/复苏优化 | 比较冻存液、降温流程和复苏后功能 |
| 细胞治疗研究 | 作为质量控制和功能评估的一部分 |

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| CD34+比例高但CFU少 | 细胞活率低、功能受损、分选或冻存损伤 | 同时记录活率和 CFU，优化处理流程 |
| CFU类型偏移 | cytokine cocktail、分化状态或样本来源不同 | 固定 [MethoCult](<../../材(实验耗材工具篇)/MethoCult.md>) 版本和培养天数 |
| 流式marker解释过度 | marker 不能完全代表功能 | 结合 [集落形成单位实验](<../../用(实验流程内容篇)/集落形成单位实验.md>) 或其他功能 readout |
| 供体差异大 | 生物学差异真实存在 | 增加供体数并按 donor 配对分析 |
| 复苏后功能下降 | 冻存液、DMSO暴露、复苏洗涤或休整不合适 | 优化 [CryoStor](<../../材(实验耗材工具篇)/CryoStor.md>) 版本和复苏流程 |

## 小结

造血祖细胞是连接造血干细胞和成熟血细胞的重要功能群体。实验中不要把 CD34+、HSPC、HSC、HPC 完全混用；CD34 是表型入口，CFU assay 等功能 readout 才能帮助判断祖细胞功能是否真的存在。
