# 保留时间窗口

Retention time window（保留时间窗口，RT window）是在 LC-MS 或 LC-MS/MS 方法中规定目标峰应出现的时间范围。它常用于 MRM/SRM、PRM、DIA 靶向提取和定量分析，用来限制搜索或积分范围，减少错误峰和背景干扰。

图源：Image2 生成的 MS/MS 碎裂方式示意图。MRM 模块展示了 transition 监测逻辑；实际 MRM 方法通常还需要配合保留时间窗口，才能稳定识别目标峰。

## 为什么需要 RT window

在液相色谱-质谱中，同一个 transition 或相近 m/z 的信号可能在不同时间出现。保留时间窗口限制目标只在合理时间段内被监测或积分。

```text
目标肽段预期保留时间：32.5 min
RT window：31.5-33.5 min
只在这个范围内寻找和积分目标峰
```

Thermo Fisher 的 Triple Quadrupole LC-MS 页面强调三重四极杆用于靶向检测和定量，并支持 SRM assay table。实际 SRM/MRM 方法开发中，目标的 retention time、transition 和离子比共同决定峰识别可信度。参考：[Thermo Fisher Triple Quadrupole LC-MS](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/liquid-chromatography-mass-spectrometry-lc-ms/lc-ms-systems/triple-quadrupole-lc-ms.html)

## RT window 解决什么问题

| 问题 | RT window 的作用 |
| --- | --- |
| 背景峰干扰 | 限制只在目标时间段寻找峰 |
| MRM transition 太多 | scheduled MRM 可以只在目标时间段监测，增加 dwell time |
| 保留时间轻微漂移 | 给目标峰留出合理容忍范围 |
| 自动积分错误 | 减少软件在错误时间段选峰 |
| DIA/PRM 提取 | 配合 fragment ion traces 和谱库保留时间确认目标 |

## 窗口太宽或太窄的后果

| 设置 | 可能后果 |
| --- | --- |
| 太宽 | 背景峰、错误峰和积分错误增加 |
| 太窄 | 保留时间漂移时漏掉真实峰 |
| 固定不变 | 长队列中后段样本可能偏离窗口 |
| 不做 QC | 无法判断漂移是 LC 问题还是样本问题 |

## 影响保留时间的因素

| 因素 | 影响 |
| --- | --- |
| 色谱柱状态 | 老化、堵塞或更换柱子都会改变保留时间 |
| 流动相 | 配制误差、pH、添加剂和有机相比例影响梯度 |
| 流速和压力 | 泵状态和系统泄漏会导致漂移 |
| 柱温 | 温度变化影响保留行为 |
| 样本基质 | 盐、去污剂和复杂基质可能改变峰形 |
| 梯度方法 | 梯度斜率和延迟体积决定洗脱时间 |

## 在 MRM/SRM 中怎么用

MRM 方法中常见做法是 scheduled MRM（调度 MRM）：每个 transition 只在预期保留时间附近打开监测。这样可以减少同一时间需要监测的 transition 数量，提高每个 transition 的采样点数和 dwell time。

```text
目标 A：10.0 min，RT window 2 min
目标 B：18.5 min，RT window 2 min
目标 C：31.0 min，RT window 3 min
```

## 常见错误

| 错误 | 结果 |
| --- | --- |
| 不记录 RT window | 方法难复现，峰识别标准不清 |
| 用单次样本确定窗口 | 不足以覆盖批次和柱状态变化 |
| 忽略 QC 漂移 | 长队列后段可能大量错峰 |
| 换柱后不重建窗口 | 旧窗口可能不适用 |
| 只看 RT 不看离子比 | 错峰仍可能落在窗口内 |

## 小结

保留时间窗口是 LC-MS 靶向分析中的“时间坐标”。它不能单独确认目标，但能显著减少错误峰和背景积分。可靠的目标确认通常需要同时满足：transition、保留时间窗口、离子比、峰形和内标行为。
