# 阳性对照

Positive control（阳性对照）是理论上应产生明确目标信号的对照，用于证明实验体系、试剂、仪器和分析流程有能力检测到目标。

## 一句话理解

阳性对照回答的是：“如果目标真的存在，这套实验能不能检测出来？”

MIQE 指南强调 qPCR 需要报告实验设计、对照、扩增效率和检测下限等信息；免疫检测中，阳性对照也常用于确认抗体、标准品或检测体系本身没有失效。参考：[MIQE guidelines, Clinical Chemistry 2009](https://academic.oup.com/clinchem/article/55/4/611/5631762)；[BioLegend sandwich ELISA protocol](https://www.biolegend.com/en-us/protocols/sandwich-elisa-protocol)。

## 阳性对照能发现什么

| 问题 | 阳性对照表现 |
| --- | --- |
| 试剂失效 | 阳性对照无信号或信号变弱 |
| 操作失败 | 阳性和样本一起失败 |
| 仪器/程序错误 | 全板或全批读数异常 |
| 检测灵敏度不足 | 弱阳性对照检测不到 |
| 标准曲线问题 | 标准品或阳性 QC 不在预期范围 |

## 常见类型

| 场景 | 阳性对照例子 | 检查重点 |
| --- | --- | --- |
| RT-qPCR | 已知表达目标基因的 cDNA | 引物和 qPCR 体系是否工作 |
| ELISA | kit positive control、已知浓度标准品 | 抗体和显色体系是否正常 |
| Western blot | 目标蛋白高表达裂解液 | 抗体是否能识别目标 |
| 免疫荧光 | 已知阳性细胞或组织 | 染色和成像是否有效 |
| 小分子处理 | 已知有效浓度处理 | 药物或通路响应是否存在 |

## 强阳性和弱阳性

| 类型 | 用途 | 风险 |
| --- | --- | --- |
| 强阳性 | 证明体系能工作 | 不能证明低水平目标可检测 |
| 弱阳性 | 监控灵敏度和检测下限附近表现 | 更容易受背景和批间差异影响 |
| 标准品阳性 | 定量和曲线拟合 | 不一定代表真实样本基质 |
| 真实样本阳性 | 更接近应用场景 | 来源和稳定性要记录 |

好的实验常同时有强阳性和接近临界值的弱阳性。只有强阳性很漂亮，仍可能漏掉真实低丰度样本。

## 阳性对照 vs 标准曲线

| 项目 | 阳性对照 | [标准曲线](标准曲线.md) |
| --- | --- | --- |
| 主要作用 | 证明体系可检测目标 | 建立信号和浓度关系 |
| 是否定量 | 可以但不一定 | 是 |
| 常见形式 | 阳性样本、阳性 lysate、kit control | 系列浓度标准品 |
| 风险 | 太强阳性掩盖灵敏度问题 | 标准品不等于真实样本 |

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 阳性对照无信号 | 试剂失效、程序错误、目标降解 | 检查试剂、程序和储存 |
| 阳性对照弱 | 稀释错误、冻融、显色不足 | 重配阳性对照，检查孵育时间 |
| 阳性正常但样本无信号 | 样本目标低或样本制备失败 | 检查样本质量和处理条件 |
| 阳性过强饱和 | 浓度过高 | 稀释阳性对照，避免平台区 |
| 阳性波动大 | 分装/储存不稳定 | 使用 aliquot 并减少冻融 |

## 小结

阳性对照证明实验体系有检测能力。没有阳性对照时，样本无信号无法区分是真阴性，还是试剂、程序或仪器失败。
