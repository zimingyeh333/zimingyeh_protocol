# CD34

CD34（Cluster of Differentiation 34，分化簇 34）是一种细胞表面跨膜糖蛋白，也是人源 hematopoietic stem and progenitor cells（HSPC，造血干/祖细胞）研究中最常用的富集和检测 marker 之一。实验语境中常见写法包括 CD34+ cells（CD34 阳性细胞）、CD34+ HSPCs（CD34 阳性造血干/祖细胞）和 CD34-enriched cells（CD34 富集细胞）。

## 核心定位

CD34 最大的实用价值是“把稀有的造血干/祖细胞相关群体从复杂样本里找出来或富集出来”。STEMCELL Technologies 的 HSPC 资料将 CD34 描述为识别人源 HSPC 最常用的细胞表面 marker，因为它表达在 HSC（hematopoietic stem cell，造血干细胞）、多能祖细胞和更分化的血液谱系祖细胞上。参考：[STEMCELL Sources of Hematopoietic Stem & Progenitor Cells](https://cdn.stemcell.com/hematopoietic-cd34-cell-sources)。

但 CD34 不是“造血干细胞”本身。CD34+ 群体通常是混合群，包括更原始的 HSC、multipotent progenitors（多能祖细胞）和 lineage-biased progenitors（谱系偏向祖细胞）。综述文章也强调，CD34 不应被理解为只属于某一种 stem cell，而是一个可用于选择多类 progenitor subpopulation（祖细胞亚群）的 marker。参考：[Sidney et al., 2014, Stem Cells](https://pmc.ncbi.nlm.nih.gov/articles/PMC4260088/)。

## 常见样本来源

| 来源 | 常见写法 | 特点 |
| --- | --- | --- |
| 骨髓 | bone marrow CD34+ cells | 经典 HSPC 来源，常用于造血研究 |
| 脐血 | cord blood CD34+ cells | 新生儿来源，常见于移植和基础研究 |
| 动员外周血 | mobilized peripheral blood CD34+ cells | G-CSF 或其他动员后 HSPC 进入外周血 |
| hPSC 分化产物 | hPSC-derived CD34+ cells | 体外造血/内皮方向分化模型 |
| 病理样本 | CD34+ blasts 或 CD34+ neoplastic cells | 需要结合临床、形态和完整 marker panel |

不同来源的 CD34+ 细胞不能直接视为同一种细胞。骨髓 CD34+、脐血 CD34+、动员外周血 CD34+ 和 hPSC-derived CD34+ 的组成、成熟度和功能潜力都可能不同。

## CD34+ 不等于 HSC

| 概念 | 代表什么 | 不能忽略的限制 |
| --- | --- | --- |
| CD34+ cells | 表达 CD34 的细胞群 | 可能包含多种祖细胞和非造血 CD34+ 细胞 |
| CD34+ HSPCs | CD34+ 富集的造血干/祖细胞 | 是富集概念，不是纯 HSC |
| HSC | 具有长期自我更新和多谱系重建能力的造血干细胞 | 需要功能证据，不能只靠 CD34 |
| HPC | 造血祖细胞，偏短期扩增和谱系输出 | 可用 CFU 等体外功能检测支持 |

因此，在记录和写作时，如果只是做了 CD34 阳性分选，稳妥写法是“CD34+ enriched cells”或“CD34+ HSPC-enriched population”。除非有移植重建、长期培养或其他功能证据，不建议直接写成“纯 HSC”。

## 常见检测和富集策略

| 方法 | 能回答的问题 | 注意事项 |
| --- | --- | --- |
| 流式检测 CD34 | 样本中 CD34+ 比例是多少 | 需要合适 gating、同型/阴性对照和死活染 |
| CD34 磁珠阳性选择 | 富集 CD34+ 细胞用于培养或功能实验 | 可能带来细胞损失、激活或纯度/回收率权衡 |
| CD34 联合 marker panel | 区分更原始或更成熟亚群 | 常结合 CD38、CD45、CD90、CD133、EPCR 等 |
| CFU assay | 评估造血祖细胞功能输出 | CD34+ 比例高不代表 CFU 一定高 |
| 转录组/单细胞测序 | 解析异质性 | 仍需功能验证支撑生物学解释 |

## 常见 marker 组合思路

| 组合 | 常见用途 | 解释提醒 |
| --- | --- | --- |
| CD34 + CD45 | 判断造血/白细胞相关群体 | CD45 阴性 CD34+ 也可能提示非造血或特殊分化产物 |
| CD34 + CD38 | 粗略区分更原始与更成熟 HSPC 亚群 | CD34+CD38- 更富集原始细胞，但不是纯 HSC |
| CD34 + CD90/CD133/EPCR | 进一步富集更原始 HSPC | 不同物种、来源和平台阈值不同 |
| CD34 + lineage markers | 排除成熟谱系细胞 | panel 设计比单 marker 更可靠 |

## 常见错误与 troubleshooting

| 现象/误区 | 可能原因 | 处理思路 |
| --- | --- | --- |
| CD34+ 比例高但 CFU 少 | 细胞活率低、功能受损、来源差异或处理损伤 | 同时记录活率、纯度和 [集落形成单位实验](<../../用(实验流程内容篇)/集落形成单位实验.md>) 结果 |
| 分选后细胞数损失大 | 起始样本少、磁珠/抗体条件不合适、洗涤过度 | 同时记录 input、output、purity 和 recovery |
| 流式 CD34 背景高 | gating 不稳、死细胞多、非特异结合 | 使用死活染、FMO/阴性对照，优化抗体浓度 |
| 把 CD34+ 写成 HSC | marker 被过度解释 | 使用 HSPC/HPC wording，并补功能证据 |
| 不同批次结果差异大 | 供体、来源、运输、冻存复苏或分选平台不同 | 按来源和批次分层记录与分析 |

## 小结

CD34 是人源造血干/祖细胞研究中非常重要的表面 marker，适合用于富集、计数、流式 panel 和后续功能实验入口。但 CD34+ 不是一个功能定义，也不等于纯造血干细胞。实验记录中要同时写清来源、分选方法、纯度、回收率、活率、联合 marker 和功能 readout。
