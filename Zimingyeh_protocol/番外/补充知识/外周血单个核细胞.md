# 外周血单个核细胞

外周血单个核细胞（Peripheral Blood Mononuclear Cells，PBMC）是从 peripheral blood（外周血）中分离得到的一类具有 single round nucleus（单个圆形细胞核）的细胞混合群，主要包括 T cells（T 细胞）、B cells（B 细胞）、NK cells（Natural Killer cells，自然杀伤细胞）、monocytes（单核细胞）和少量 dendritic cells（树突状细胞）。

## 核心定位

PBMC 不是一种单一细胞，而是外周血免疫细胞的混合输入样本。它常用于 immunology（免疫学）、infection model（感染模型）、vaccine response（疫苗反应）、T cell/NK cell culture（T/NK 细胞培养）、flow cytometry（流式细胞术）、single-cell RNA-seq（单细胞 RNA 测序）和 cytokine stimulation（细胞因子刺激）实验。

PBMC 的关键特点是 donor variability（供体差异）很强：年龄、性别、疾病状态、用药、采血时间、抗凝剂、运输时间、冻存复苏和 [density gradient centrifugation（密度梯度离心）](<../../用(实验流程内容篇)/密度梯度离心.md>) 等分离方法都会改变细胞组成和状态。STEMCELL Technologies 的 PBMC 分离资料也将 PBMC isolation（PBMC 分离）作为免疫细胞实验的重要前处理步骤，并强调后续可进入细胞分选、培养或分析。参考：[STEMCELL PBMC Isolation](https://www.stemcell.com/peripheral-blood-mononuclear-cell-isolation.html)。

## 常见组成

| 细胞类型 | 英文 | 常见用途 |
| --- | --- | --- |
| T细胞 | T cells | T cell activation、细胞因子刺激、CAR-T/TCR-T 相关研究 |
| B细胞 | B cells | 抗体反应、BCR 信号、免疫表型 |
| NK细胞 | Natural Killer cells | 杀伤实验、先天免疫、肿瘤免疫 |
| 单核细胞 | Monocytes | 巨噬细胞/树突状细胞诱导、炎症刺激 |
| 树突状细胞 | Dendritic cells | 抗原呈递、免疫刺激，通常比例较低 |

PBMC 中不应大量包含 granulocytes（粒细胞）或 erythrocytes（红细胞）。如果分离后红细胞、粒细胞或血小板残留很多，说明样本处理或密度梯度分离可能需要优化。

## 新鲜PBMC vs 冻存PBMC

| 项目 | 新鲜PBMC | 冻存PBMC |
| --- | --- | --- |
| 优点 | 状态更接近采血后原始状态，功能实验更敏感 | 便于批量实验、跨时间点统一检测 |
| 局限 | 受采血和运输时间影响大，排期压力高 | 复苏损伤、亚群比例和功能可能改变 |
| 适合 | 即时刺激、功能检测、短流程实验 | 大队列、批次统一、回顾性样本 |
| 记录重点 | 采血时间、抗凝剂、运输温度、分离时间 | 冻存液、冻存密度、复苏活率、休整时间 |

如果做 cytokine release（细胞因子释放）、T cell activation 或 NK killing assay，冻存复苏后是否需要 rest（休整）要按实验目的验证。

## PBMC vs 全血 vs 分选亚群

| 样本 | 优点 | 局限 | 适合场景 |
| --- | --- | --- | --- |
| 全血 | 处理少，保留更多体内背景 | 红细胞/血浆/粒细胞影响大 | 临床流式、快速检测 |
| PBMC | 去除大部分红细胞和粒细胞，适合免疫细胞分析 | 仍是混合群，供体差异大 | 免疫刺激、流式、分选前输入 |
| 分选亚群 | 细胞组成更清楚 | 处理带来损伤或激活风险 | T/NK/B/单核细胞特定功能实验 |

## 常见质量指标

| 指标 | 代表什么 | 注意事项 |
| --- | --- | --- |
| 活率 | 样本是否适合下游实验 | 复苏 PBMC 尤其要记录 |
| 总细胞数 | 实验输入量 | PBMC 容易沉降，计数前要混匀 |
| 亚群比例 | T/B/NK/单核细胞组成 | 供体和处理方式都会影响 |
| 红细胞残留 | 分离质量 | 高残留会影响计数和流式 |
| 血小板残留 | 样本洁净度 | 可能增加背景和细胞聚集 |
| 运输/处理时间 | 细胞状态 | 延迟处理会改变活化状态和功能 |

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 活率低 | 采血后放置太久、冻存/复苏不当、离心过猛 | 缩短处理时间，优化冻存复苏 |
| 红细胞污染多 | 密度梯度层扰动、吸取界面不准 | 练习分层和吸取，必要时红细胞裂解 |
| 细胞团聚 | DNA释放、血小板残留、死亡细胞多 | 过滤、温和处理，必要时加 DNase |
| 流式背景高 | [Fc受体](Fc受体.md)、死细胞、血小板或非特异结合 | 加 Fc block、死活染，优化洗涤 |
| 不同供体差异大 | 生物学差异是真实变量 | 增加供体数，按 donor 配对分析 |

## 小结

PBMC 是外周血免疫细胞混合群，不是单一细胞类型。它的实验价值很高，但供体差异、分离方法、冻存复苏和下游分选都会显著影响结果。任何 PBMC 实验都应该记录样本来源、处理时间、活率、亚群组成和后续用途。
