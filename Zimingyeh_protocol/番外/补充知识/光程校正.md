# 光程校正

Pathlength correction（光程校正）是指对吸光度读数中由 pathlength（光程）差异造成的影响进行校正，使不同液体高度或不同孔体积下的读数更接近同一光程条件下的结果。

![Absorbance OD450 pathlength](../../z_asset/番外/吸光度与OD450/absorbance-od450-pathlength.png)

图：吸光度、OD450 和光程的关系。微孔板孔内液体高度不同，会导致光穿过样本的距离不同，从而影响吸光度。本图由 Image2 / image-generation model 生成，用于个人学习笔记示意。

## 一句话理解

光程校正回答的是：“同一浓度的样本，如果液面高度不同，读数能不能被修正到可比较？”

根据 [比尔-朗伯定律](比尔-朗伯定律.md)，吸光度与浓度和光程相关。比色皿通常有固定 1 cm 光程，而 [酶标板](<../../材(实验耗材工具篇)/酶标板.md>) 的光程取决于孔型和每孔液体体积。IUPAC 对 absorbance（吸光度）的定义也体现了入射光和透射光之间的关系。参考：[IUPAC Gold Book: absorbance](https://goldbook.iupac.org/terms/view/A00028)。

## 为什么微孔板需要考虑光程

在传统分光光度计中，比色皿的光程通常固定，因此浓度和吸光度关系更直接。微孔板中，100 uL、150 uL、200 uL 的液柱高度不同，光走过样本的距离也不同。

```text
同一浓度
体积更大 → 液柱更高 → 光程更长 → 吸光度可能更高
体积更小 → 液柱更低 → 光程更短 → 吸光度可能更低
```

这对核酸/蛋白直接吸收法、酶活动力学和某些需要绝对吸光度比较的实验尤其重要。

## 在 ELISA 中是否总要光程校正

不一定。

在常规 endpoint [ELISA](<../../用(实验流程内容篇)/ELISA.md>) 中，所有标准品和样本通常在同一块板、相同体积、相同底物和同一 [标准曲线](标准曲线.md) 下读取，因此不一定需要把 OD450 校正到 1 cm 光程。只要标准品和样本体积一致，曲线已经把当前光程条件纳入了换算。

但如果存在以下情况，光程或体积差异就会变得重要：

- 不同孔体积不一致。
- 不同板或不同孔型之间比较原始吸光度。
- 使用微孔板做 A260、A280、酶活或化学定量。
- 需要把微孔板读数换算到 1 cm 比色皿等效值。
- 孔内气泡、蒸发或边缘效应导致液面差异。

## 光程校正 vs 参考波长

| 项目 | 光程校正 | [参考波长](参考波长.md) |
| --- | --- | --- |
| 英文 | Pathlength correction | Reference wavelength correction |
| 校正对象 | 液柱高度/光程不同 | 光学背景、板底、气泡、浑浊 |
| 主要依据 | 吸光度与光程相关 | 目标产物在参考波长吸收较少 |
| 常见用途 | 核酸/蛋白直接吸收、酶活、微孔板定量 | ELISA OD450 背景扣除 |
| 是否等价 | 不等价 | 不等价 |

OD450-570 这类读数不是光程校正，而是参考波长背景扣除。

## 使用注意事项

如果仪器或软件提供 pathlength correction，应记录：

- 是否开启校正。
- 校正算法或仪器模式。
- 每孔体积。
- 板型和孔底形状。
- 温度条件。
- 是否有气泡。
- 是否用于最终报告。

不同厂家的光程校正实现方式可能不同，跨仪器比较时不能只写“已校正”，还要记录仪器型号和软件设置。

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 同一样本不同体积读数不同 | 光程不同 | 固定体积或开启光程校正 |
| ELISA 复孔差异大 | 气泡、加样体积不同、边缘蒸发 | 检查移液和板图，不要只怪曲线 |
| OD450-570 被误称为光程校正 | 混淆参考波长和光程 | 记录为 reference wavelength correction |
| 1 cm 等效值不稳定 | 板型、体积或算法不匹配 | 使用仪器推荐体积和板型 |
| 光程校正后反而更乱 | 样本浑浊、气泡或散射严重 | 先解决样本和孔内状态 |

## 小结

光程校正的核心是：吸光度不仅受浓度影响，也受光穿过样本的距离影响。ELISA 通常更关心同板同体积下的标准曲线换算；而微孔板直接吸收测定、酶活和跨体积比较时，光程校正就会变成关键变量。
