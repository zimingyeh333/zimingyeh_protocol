# 扩增子

Amplicon（扩增子）是 PCR 或 qPCR 反应中由一对引物扩增出来的特定 DNA 片段；在 [RT-qPCR](<../../用(实验流程内容篇)/RT-qPCR.md>) 中，扩增子的长度、位置和特异性会直接影响 [扩增效率](扩增效率.md)、[熔解曲线](熔解曲线.md) 和结果解释。

## 一句话理解

扩增子就是“这对引物真正复制出来的那一段 DNA”。

IDT 的 qPCR primer design 资料和 Thermo Fisher 的 qPCR assay design 资料都强调，qPCR 扩增片段通常设计得较短，并需要验证特异性和扩增效率。参考：[IDT qPCR Primer Design](https://www.idtdna.com/pages/education/decoded/article/designing-qpcr-assays)；[Thermo Fisher qPCR assay design](https://www.thermofisher.com/us/en/home/life-science/pcr/real-time-pcr/real-time-pcr-learning-center/real-time-pcr-basics/real-time-pcr-assay-design.html)。

## 扩增子设计看什么

| 参数 | 常见思路 | 为什么重要 |
| --- | --- | --- |
| 长度 | RT-qPCR 常见短片段 | 短片段更容易高效扩增 |
| 位置 | 目标转录本特异区域 | 避免扩增非目标 isoform |
| 是否跨外显子连接 | 表达检测常优先考虑 | 降低基因组 DNA 干扰 |
| GC 含量 | 避免过高或过低 | 影响扩增效率和熔解曲线 |
| 同源性 | BLAST 检查特异性 | 避免同源基因或伪基因 |
| 产物 Tm | 熔解曲线判断基础 | 区分目标峰和非特异峰 |

## 扩增子长度为什么重要

| 扩增子过短 | 扩增子过长 |
| --- | --- |
| 可能接近引物二聚体大小，不易区分 | 扩增效率下降 |
| 特异性可能不足 | 对 RNA 降解更敏感 |
| 熔解峰可能低 | Cq 可能偏高 |
| 需要更严格设计 | 不适合快速 qPCR |

普通 RT-qPCR 常倾向于较短扩增子，是因为 RNA 可能部分降解，且短片段更容易在每个循环内完成高效扩增。

## 扩增子和基因组 DNA

表达检测中，扩增子最好能区分 cDNA 和 genomic DNA（基因组 DNA）。

| 设计方式 | 优点 | 局限 |
| --- | --- | --- |
| 跨 exon-exon junction | 只匹配剪接后的 cDNA | 不是所有基因都容易设计 |
| 两引物跨长 intron | gDNA 产物过长，不易扩增 | 短 intron 时效果有限 |
| 引物在同一 exon | 设计容易 | 更容易受 [基因组DNA污染](基因组DNA污染.md) 影响 |
| 探针跨剪接位点 | 特异性高 | 成本更高 |

即使扩增子设计跨剪接位点，也不能完全替代 [无逆转录对照](无逆转录对照.md) 和 DNase 处理。

## 如何验证扩增子

| 方法 | 能回答什么 |
| --- | --- |
| 熔解曲线 | 产物熔解行为是否单一 |
| [琼脂糖凝胶电泳](<../../用(实验流程内容篇)/琼脂糖凝胶电泳.md>) | 产物大小是否符合预期 |
| Sanger 测序 | 产物序列是否正确 |
| 标准曲线 | 扩增效率是否合格 |
| NTC/no-RT | 是否有污染或 gDNA 扩增 |

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 熔解曲线多峰 | 多个扩增子或非特异扩增 | 重设计引物，做胶图 |
| 胶图条带大小不对 | 扩增了非目标区域 | BLAST 检查，重设计 |
| no-RT 阳性 | 扩增子无法区分 gDNA | 跨 exon junction 或 DNase 处理 |
| 扩增效率低 | 扩增子太长或二级结构复杂 | 缩短扩增子或换区域 |
| 不同 isoform 混在一起 | 扩增子位于共有区域 | 设计 isoform-specific amplicon |

## 小结

扩增子是 qPCR 引物设计的实际产物。好的扩增子应该短、特异、效率合理，并尽量避免基因组 DNA 和非目标转录本干扰。
