# 绝对定量

Absolute quantification（绝对定量）是指把检测信号换算为实际浓度、质量、摩尔量、拷贝数或细胞数等有单位的结果。它回答的问题是：“这个样本里目标物到底有多少？”

![LC-MS 定量策略概览](../../z_asset/番外/补充知识/LC-MS定量策略/lcms-quantification-strategies-zh.png)

图源：Image2 生成的 LC-MS 定量策略示意图。绝对定量通常需要标准曲线、内标或同位素稀释体系，而不是只比较组间峰面积。

## 一句话理解

绝对定量的结果带有明确单位，例如：

```text
IL-6 = 38.5 pg/mL
Drug A = 122 ng/mL
Target DNA = 1.2 × 10^4 copies/uL
Protein X = 45 fmol/ug total protein
```

如果只说“实验组是对照组 2 倍”，那是 [相对定量](相对定量.md)，不是绝对定量。

## 常见实现方式

| 方法 | 核心逻辑 | 常见应用 |
| --- | --- | --- |
| [标准曲线](标准曲线.md) | 用已知浓度标准品建立信号-浓度关系 | ELISA、qPCR、酶活、小分子检测 |
| [外标法](外标法.md) | 标准品单独建曲线，样本直接代入 | 基质简单、前处理稳定的分析 |
| [内标法](内标法.md) | 目标物/内标信号比建曲线 | LC-MS、GC-MS、HPLC |
| [同位素稀释](同位素稀释.md) | 使用稳定同位素内标校正损失和基质效应 | 靶向 LC-MS 高准确度定量 |
| [标准加入法](标准加入法.md) | 向真实样本中加入不同量标准品外推原始浓度 | 空白基质难获得、基质效应明显的样本 |

ICH M10 将 calibration curve（校准曲线）、quality control samples（质控样本）、accuracy（准确度）、precision（精密度）和 matrix effect（基质效应）作为生物分析方法验证的重要内容。参考：[ICH M10 Bioanalytical Method Validation](https://database.ich.org/sites/default/files/M10_Guideline_Step4_2022_0524.pdf)。

## 适合什么场景

| 场景 | 为什么需要绝对定量 |
| --- | --- |
| 临床或转化检测 | 结果需要和阈值、参考范围或指南比较 |
| 药物浓度监测 | 需要 ng/mL、AUC、Cmax 等实际浓度 |
| 细胞因子 ELISA | 需要报告 pg/mL 或 ng/mL |
| qPCR 拷贝数分析 | 需要 copies/uL 或 copies/cell |
| 靶向蛋白质组学 | 需要 fmol、pmol 或浓度级别结果 |

## 和相对定量的关系

| 问题 | 更适合相对定量 | 更适合绝对定量 |
| --- | --- | --- |
| 药物处理后蛋白是否上调 | 是 | 不一定 |
| 血浆药物浓度是多少 | 否 | 是 |
| 某个细胞因子是否高于临床阈值 | 否 | 是 |
| 多组蛋白质组筛选差异蛋白 | 是 | 通常不是第一步 |
| 验证候选 biomarker 是否达到报告浓度 | 不够 | 是 |

绝对定量并不天然比相对定量“更高级”。它只是回答的问题不同，而且对标准品、基质匹配、回收率和方法验证要求更高。

## 关键质量要求

| 要求 | 说明 |
| --- | --- |
| 标准品可靠 | 需要明确纯度、赋值、批号和保存条件 |
| 曲线覆盖样本范围 | 样本应落在 LLOQ 和 ULOQ 之间 |
| 基质匹配或校正 | 真实样本背景不能和标准品体系差太多 |
| 回收率可接受 | 前处理不能造成不可控损失 |
| 精密度和准确度合格 | 重复测定不能只“看起来差不多” |
| 稀释完整性 | 高浓度样本稀释后仍应回算合理 |

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 标准曲线很好但样本偏低 | 基质抑制、回收率低 | 做 spike-and-recovery、稀释线性或同位素内标 |
| 高浓度样本回算不准 | 超出 ULOQ、平台效应或 Hook effect | 稀释进入曲线中段 |
| 不同批次结果不可比 | 标准品批次、曲线范围或仪器状态不同 | 使用桥接 QC 和固定 SOP |
| 内标校正后仍不稳定 | 内标不共流出或加入太晚 | 换更匹配内标，提前加入 |
| 结果单位混乱 | 稀释倍数、体积或质量归一化错误 | 保留计算链和原始记录 |

## 小结

绝对定量的核心是把信号放进一个可追溯的校准体系里。它适合需要实际单位和临床/方法学解释的场景，但比相对定量更依赖标准品、曲线、基质验证和质控样本。
