# 分子量标准

分子量标准（molecular weight standard）是由一组已知大小或已知分子量的分子组成的参照物，用于电泳、色谱、质谱或其他分离检测中估算未知样本的位置和大小。在实验室日常语境中，核酸电泳里常叫 [DNA Ladder](<../../材(实验耗材工具篇)/DNA Ladder.md>) 或 DNA marker；蛋白电泳里常叫 [蛋白Marker](<../../材(实验耗材工具篇)/蛋白Marker.md>) 或 protein ladder。

## 为什么需要分子量标准

电泳结果本质上是“迁移距离”的图像。如果没有分子量标准，你只能说样本条带跑到了某个位置，却很难判断它大约是多少 bp、kb 或 kDa。分子量标准把迁移距离转换成可解释的大小参照。

NEB 的 DNA markers and ladders 页面将 DNA ladders 定位为覆盖不同片段范围的 electrophoresis size standards，用于 agarose gel electrophoresis 中的大小估算。参考：[NEB DNA Markers and Ladders](https://www.neb.com/en/products/markers-and-ladders)。

## 常见类型

| 类型 | 英文 | 常见用途 |
| --- | --- | --- |
| DNA ladder | DNA 分子量标准 | PCR、酶切、质粒鉴定、胶回收 |
| RNA ladder | RNA 分子量标准 | RNA 变性胶、Northern blot、RNA 片段分析 |
| Protein ladder | 蛋白分子量标准 | SDS-PAGE、Western blot |
| Prestained protein ladder | 预染蛋白 marker | 跑胶和转膜时肉眼观察 |
| PFG marker | Pulsed-field gel marker | 超大 DNA 片段 PFGE |

Thermo Fisher 的 DNA ladders 页面也按片段大小范围、预混上样和特定用途组织不同 DNA ladder，说明选择 ladder 时要匹配目标片段范围。参考：[Thermo Fisher DNA Ladders](https://www.thermofisher.com/us/en/home/life-science/dna-rna-purification-analysis/nucleic-acid-gel-electrophoresis/dna-ladders.html)。

## 选择逻辑

| 问题 | 选择建议 |
| --- | --- |
| 目标片段大概多大 | ladder 范围必须覆盖目标，并且目标附近条带要足够密 |
| 是 DNA、RNA 还是蛋白 | 使用对应分子类型的标准 |
| 是否需要肉眼观察转膜 | 蛋白实验可选择 prestained ladder |
| 是否要粗略估算含量 | 选择有已知条带质量说明的 ladder |
| 是否要发表图 | 保留 ladder lane 和说明，不要只裁样本条带 |

## 与定量标准的区别

| 标准类型 | 回答的问题 |
| --- | --- |
| 分子量标准 | “这个条带大概多大？” |
| 浓度标准 | “这个样本大概多少量？” |
| 标准曲线 | “读数和真实浓度之间是什么关系？” |
| 内参/housekeeping control | “不同样本是否可比较？” |

分子量标准主要解决大小坐标问题，不天然等于准确浓度标准。部分 ladder 每条带质量已知，可以粗略估算样本量，但不能替代 Qubit、BCA 或标准曲线。

## 常见错误

- 用 1 kb ladder 判断 80 bp 片段，目标附近没有足够参考条带。
- 把质粒超螺旋条带直接按线性 DNA ladder 估算真实大小。
- WB 图裁掉 marker，后续无法判断目标条带是否在预期分子量附近。
- 不记录 ladder 品牌和版本，导致不同实验之间不能复核。

## 小结

分子量标准是分离实验的坐标尺。它不负责证明目标身份，也不一定负责定量，但它让“条带位置”变成可以讨论和复核的大小信息。
