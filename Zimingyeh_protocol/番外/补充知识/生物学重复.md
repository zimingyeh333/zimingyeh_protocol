# 生物学重复

Biological replicate（生物学重复）是指来自独立 biological unit（生物学单位）或 independent experimental unit（独立实验单位）的重复样本，用来估计真实生物差异，并支持统计推断。

图：生物学重复用于估计真实生物差异，技术重复用于估计同一样本的操作和检测误差。本图由 Image2 / image-generation model 生成，用于个人学习笔记示意。

## 一句话理解

生物学重复回答的是：“如果我重新取一个独立样本，结论是否仍然成立？”

它不是同一个样本多测几次，也不是同一孔拍很多张图。真正的生物学重复必须能代表实验想要推断的 population（总体）差异。

## 不同实验中的例子

| 实验场景 | 常见生物学重复 | 常见误判 |
| --- | --- | --- |
| 细胞实验 | 独立传代、独立铺板、独立处理得到的样本 | 同一孔分装到多个 qPCR 孔 |
| 动物实验 | 不同个体，或按研究问题定义的独立动物单位 | 同一只动物取多个切片当作 n |
| 患者样本 | 不同患者或独立临床样本 | 同一患者多个技术测量当作 n |
| [RT-qPCR](<../../用(实验流程内容篇)/RT-qPCR.md>) | 独立提取 RNA 的不同生物样本 | 同一 cDNA 上多个复孔 |
| [Western blot](<../../用(实验流程内容篇)/Western blot.md>) | 独立培养/处理/裂解的样本 | 同一裂解液跑多条泳道 |
| [ELISA](<../../用(实验流程内容篇)/ELISA.md>) | 独立个体或独立培养上清 | 同一样本多个孔 |

NCBI Assay Guidance Manual 对非临床 assay 报告也区分 technical replicates 和 independent replicates：technical replicates 是同一样本在同一实验中的重复测量，independent replicates 是不同样本制备的测量。参考：[NCBI Assay Guidance Manual](https://www.ncbi.nlm.nih.gov/sites/books/NBK550206/)。

## 为什么统计通常看生物学重复

统计检验一般要估计组内真实变异。如果你有 3 个独立培养样本，每个样本做 3 个 qPCR 技术复孔，那么生物学重复数通常是 n = 3，不是 n = 9。

Bell 在 BMC Biology 的短文中强调，实验报告需要明确 replicates 是 biological replicates 还是 technical replicates；把技术重复当作生物学重复会夸大 n，导致错误显著性判断。参考：[Bell, Replicates and repeats, 2016](https://link.springer.com/article/10.1186/s12915-016-0254-5)。

## 和技术重复的区别

| 项目 | 生物学重复 | [技术重复](技术重复.md) |
| --- | --- | --- |
| 来源 | 独立样本、独立处理、独立个体 | 同一样本重复测量 |
| 主要估计 | 生物变异 | 操作和检测误差 |
| 能否直接增加统计 n | 通常可以 | 通常不可以 |
| 最常见用途 | 统计推断、组间差异 | 检查移液、仪器、检测稳定性 |
| 如果缺失 | 结论泛化能力弱 | 数据质量难判断 |

## 设计时怎么判断 n

关键问题是：处理或分组真正作用在哪个单位上？

- 如果药物加到不同培养皿，每个培养皿独立处理，培养皿通常是实验单位。
- 如果药物只加到同一个培养皿，然后从里面分出多个孔检测，这些孔不是独立生物学重复。
- 如果不同动物接受不同处理，动物通常是实验单位。
- 如果一只动物中取多个组织切片，这些切片通常嵌套在同一动物内，不能简单当成多个独立动物。

Nature Reviews Methods Primers 关于 genuine replication and pseudoreplication（真实重复与伪重复）的文章强调，错误定义 N 会人为放大样本量，并增加假阳性或假阴性风险。参考：[Lazic, 2022](https://www.nature.com/articles/s43586-022-00114-w)。

## 常见错误与调整

| 错误 | 后果 | 调整方向 |
| --- | --- | --- |
| 把同一样本的多个复孔当作 n | 人为缩小误差，p 值偏乐观 | 先平均技术复孔，再以生物学重复为单位统计 |
| 多张显微图片当作独立样本 | 忽略同一培养孔或同一动物的相关性 | 以孔、动物或患者作为统计单位 |
| 只做一次独立实验 | 难以判断是否可重复 | 至少增加独立重复或明确为预实验 |
| 生物学重复来源不平衡 | 组间方差和偏倚难控制 | 尽量平衡设计，记录批次和来源 |
| 不说明 n 的定义 | 读者无法判断统计是否合理 | 方法部分写清 n 代表什么 |

## 小结

生物学重复是实验结论能否推广的核心。技术重复可以提高测量稳定性，但不能替代独立样本。每次写实验设计时，先问“我的 n 到底代表什么”，这一步比后面选择哪种统计检验更重要。
