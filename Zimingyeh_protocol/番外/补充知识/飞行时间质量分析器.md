# 飞行时间质量分析器

Time-of-flight mass analyzer（飞行时间质量分析器，TOF）是一类根据离子飞过固定距离所需时间来推断 m/z 的 [质量分析器](质量分析器.md)。在相同加速条件下，m/z 较小的离子飞得更快，m/z 较大的离子飞得更慢，因此可以通过飞行时间得到质量信息。

图源：Image2 生成的质谱仪器类型参考图。Q-TOF 和 MALDI-TOF 模块都包含 TOF，但它们的离子源和前端选择逻辑不同。

## 基本原理

TOF 的直觉很简单：给离子相似的动能，让它们在真空管里飞行。轻的或低 m/z 的离子更早到达检测器，重的或高 m/z 的离子更晚到达。仪器把到达时间换算成 m/z。

Thermo Fisher 的质谱技术概览将 time-of-flight（TOF）列为常见质量分析器类型；SCIEX 的 QTOF systems 页面强调 QTOF 技术具备高速采集、宽质量范围和准确质量能力；Bruker 的 MALDI-TOF 页面则说明 MALDI-TOF 常通过 MALDI 离子源和 TOF 分析器进行快速、高通量分析。参考：[SCIEX QTOF Systems](https://sciex.com/products/mass-spectrometers/qtof-systems)、[Bruker MALDI-TOF/TOF](https://www.bruker.com/en/products-and-solutions/mass-spectrometry/maldi-tof.html)

## 常见组合

| 组合 | 前端逻辑 | 典型用途 |
| --- | --- | --- |
| [Q-TOF](<../../材(实验耗材工具篇)/Q-TOF.md>) | 四极杆选择/碎裂 + TOF 准确质量检测 | DDA、DIA、未知物筛查、肽图 |
| [MALDI-TOF](<../../材(实验耗材工具篇)/MALDI-TOF.md>) | MALDI 板上点样 + TOF 快速检测 | 微生物鉴定、指纹谱、MALDI imaging |
| MALDI-TOF/TOF | TOF 选择和碎裂后再 TOF 分析 | 结构确认、肽段碎片分析 |

## TOF 的优势

| 优势 | 意义 |
| --- | --- |
| 扫描速度快 | 适合窄 LC 峰、DIA 和高通量 |
| 质量范围宽 | 可检测较宽 m/z 区间 |
| 全谱采集 | 适合未知物筛查和回看数据 |
| 与 MALDI 兼容 | 支持板上点样和快速指纹 |
| 与四极杆组合灵活 | Q-TOF 可兼顾选择、碎裂和准确质量 |

## TOF vs Orbitrap

| 项目 | TOF / Q-TOF | [Orbitrap](<../../材(实验耗材工具篇)/Orbitrap.md>) |
| --- | --- | --- |
| 强项 | 速度快、全谱、适合高通量 MS/MS | 高分辨准确质量能力强 |
| 典型组合 | Q-TOF、MALDI-TOF | Q-Orbitrap、Tribrid |
| 常见用途 | 筛查、DIA、肽图、MALDI 指纹 | 深度蛋白组、PTM、TMT、HRAM |
| 选择逻辑 | 需要速度和全谱时很有优势 | 需要更高分辨时常有优势 |

二者没有绝对高低。Q-TOF 的速度和灵活性很适合很多筛查和 DIA 场景；Orbitrap 在更高分辨准确质量和复杂样本解析中常有优势。

## 常见误解

| 误解 | 更准确的理解 |
| --- | --- |
| TOF 只是 MALDI-TOF 的一部分 | TOF 也广泛用于 LC-MS 的 Q-TOF |
| TOF 只适合定性 | Q-TOF 可以做定性，也可以做一定定量和靶向/半靶向方法 |
| 飞行时间越短就越好 | 关键是时间测量精度、离子包聚焦和校准 |
| TOF 和 Q-TOF 是同一件事 | Q-TOF 是四极杆和 TOF 的组合平台 |

## 小结

TOF 的关键词是“用飞行时间测 m/z”。它速度快、质量范围宽，既能和 MALDI 组成快速指纹平台，也能和四极杆组成 Q-TOF 做准确质量 MS/MS。理解 TOF，有助于区分 Q-TOF 和 MALDI-TOF 为什么同样叫 TOF，却服务于不同实验逻辑。
