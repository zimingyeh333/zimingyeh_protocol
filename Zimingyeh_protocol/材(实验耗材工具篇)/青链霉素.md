# 青链霉素

Penicillin-Streptomycin（青霉素-链霉素，常简称青链霉素或 Pen-Strep）是细胞培养中常见的抗生素组合。Penicillin（青霉素）主要抑制细菌细胞壁合成，Streptomycin（链霉素）主要抑制细菌蛋白合成，组合后常用于降低革兰阳性和革兰阴性细菌污染风险。

## 核心用途

| 用途 | 作用 | 注意事项 |
| --- | --- | --- |
| 常规细胞培养 | 降低细菌污染扩增风险 | 不能替代无菌操作 |
| 新手训练或高风险操作 | 给培养体系增加一层保护 | 可能掩盖轻微污染 |
| 外来细胞短期隔离 | 降低带入细菌扩增 | 不能解决支原体、真菌和细胞交叉污染 |
| 无抗培养对照 | 检查操作是否真正无菌 | 更容易暴露无菌问题 |

Thermo Fisher 的细胞培养抗生素页面明确提醒：抗生素应以合适浓度使用，但不应替代 sterile practice（无菌操作）；某些抗生素/抗真菌剂对特定细胞有毒性，因此应先做剂量反应测试。[参考：Thermo Fisher Antibiotics for Cell Culture](https://www.thermofisher.com/us/en/home/life-science/cell-culture/mammalian-cell-culture/media-supplements/antibiotics.html)

## 常见配方

| 常见 stock | 常见 1× 终浓度 | 说明 |
| --- | --- | --- |
| 100× Pen-Strep | 100 U/mL penicillin + 100 µg/mL streptomycin | 最常见 |
| 10,000 U/mL penicillin + 10,000 µg/mL streptomycin | 1:100 稀释成 1× | 许多商业产品采用 |
| Penicillin-Streptomycin-Glutamine | 同时含 L-glutamine | 注意不要重复补充谷氨酰胺 |
| Penicillin-Streptomycin-GlutaMAX | 同时含稳定谷氨酰胺替代物 | 注意与培养基已有成分叠加 |

Thermo Fisher 的产品表说明，Penicillin-Streptomycin 溶液中 penicillin 抑制细胞壁合成，streptomycin 抑制蛋白合成，产品可有 5,000 U/mL 或 10,000 U/mL 等规格。[参考：Thermo Fisher Antibiotics for Cell Culture](https://www.thermofisher.com/us/en/home/life-science/cell-culture/mammalian-cell-culture/media-supplements/antibiotics.html)

## 青链霉素不能解决什么

| 问题 | 青链霉素是否适合 | 原因 |
| --- | --- | --- |
| 普通细菌污染 | 可降低风险，但不能挽救严重污染 | 细菌量大时仍会失控 |
| 真菌污染 | 不适合 | 需要抗真菌剂，如 amphotericin B |
| 支原体污染 | 不适合常规解决 | 支原体缺乏细胞壁，且常规青链不能可靠清除 |
| 细胞系交叉污染 | 完全无效 | 这是细胞身份问题 |
| 无菌操作差 | 只能掩盖，不能解决 | 会让问题延迟暴露 |

在 [细胞培养](<../用(实验流程内容篇)/细胞培养.md>) 中，长期依赖抗生素可能让实验室误以为体系干净。真正的无菌质量应该通过规范操作、隔离外来细胞、定期 [支原体检测](<../用(实验流程内容篇)/支原体检测.md>) 和污染记录建立。

## 是否应该常规加青链霉素

| 策略 | 优点 | 风险 |
| --- | --- | --- |
| 长期常规加 | 降低细菌污染扩增风险，适合初学者或高风险环境 | 掩盖污染、改变细胞状态、可能影响某些实验 |
| 只在复苏/隔离期加 | 外来细胞早期更安全 | 后续仍需无抗培养验证 |
| 完全无抗培养 | 最能暴露无菌问题，适合严格实验 | 对操作要求更高 |
| 实验前无抗培养一段时间 | 减少抗生素对结果影响 | 需要提前规划 |

我建议在正式 protocol 中不要只写“加抗生素”，而要写清楚为什么加、加多久、终浓度、是否有无抗对照。

## 使用策略

**怎么做**：常见 100× stock 按 1:100 加入完全培养基，混匀后使用。具体浓度以产品说明书和细胞耐受性为准。

**为什么**：抗生素浓度太低不能有效抑菌，太高可能影响细胞生长、代谢和下游实验。

**注意事项**：

- 不要反复冻融 stock，建议分装。
- 加入含抗生素培养基后记录开封日期和配制日期。
- 对原代细胞、干细胞和敏感细胞，先验证毒性。
- 不要用抗生素“治疗”已经明显污染的常规细胞。

**替代方案**：

- 抗真菌需求：考虑 [两性霉素B](两性霉素B.md) 或 antibiotic-antimycotic（抗生素-抗真菌混合液）。
- 特定选择压力：使用 [筛选抗生素](筛选抗生素.md)，如 puromycin、G418、hygromycin 等。
- 严格无菌训练：无抗培养更能暴露问题。

**出错后果**：污染被掩盖、细胞状态改变、实验结果受抗生素影响。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理策略 |
| --- | --- | --- |
| 加了青链仍然污染 | 真菌、支原体、抗性细菌或污染量太大 | 隔离废弃，查污染源，不要继续传代 |
| 细胞生长变慢 | 抗生素毒性、浓度过高、细胞敏感 | 降低浓度，做无抗对照 |
| 支原体阳性 | 青链不能可靠清除支原体 | 优先废弃并从阴性库存复苏 |
| 实验重复性差 | 有抗/无抗条件不一致 | 固定抗生素策略并记录 |
| 转染效率下降 | 抗生素或细胞状态影响 | 转染前换无抗培养基并优化条件 |
| 培养基配方重复添加 | 使用含抗生素商品培养基又额外加 stock | 检查标签和配方 |

## 购买建议

选择 cell culture tested、sterile-filtered 的 Pen-Strep 产品。常见供应商包括 [Gibco](<../番外/试剂厂商/Gibco.md>)、[Sigma-Aldrich](<../番外/试剂厂商/Sigma-Aldrich.md>)、[Merck](<../番外/试剂厂商/Merck.md>)、[Thermo Scientific](<../番外/试剂厂商/Thermo Scientific.md>)、[碧云天](<../番外/试剂厂商/碧云天.md>)、[索莱宝](<../番外/试剂厂商/索莱宝.md>) 等。购买时重点看 stock 浓度、是否含 glutamine/GlutaMAX、储存条件、是否适合细胞培养。

## 小结

青链霉素是细胞培养中常用的抗细菌组合，但它不是无菌操作的替代品，也不能解决支原体、真菌和细胞系交叉污染。越是关键实验，越要记录是否使用抗生素、使用浓度和使用阶段。
