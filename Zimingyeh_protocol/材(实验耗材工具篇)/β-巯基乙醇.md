# β-巯基乙醇

β-mercaptoethanol（β-巯基乙醇，常写 β-ME 或 2-mercaptoethanol）是一种还原剂，在 RNA 提取中常加入含 guanidinium salt（胍盐）的裂解液，例如 RLT buffer，用于还原蛋白二硫键、帮助变性蛋白并抑制 RNase 活性。它气味强、挥发性和毒性都需要严肃对待。

## 在 RNA 提取中的作用

很多柱式 RNA 提取试剂盒的裂解液需要临用前加入 β-巯基乙醇。它与胍盐共同增强蛋白变性和 RNase 失活，从而保护 RNA。Qiagen RNeasy 系列手册中，Buffer RLT 通常需要加入 β-mercaptoethanol 后使用，以支持样本裂解和 RNase 失活。[参考：Qiagen RNeasy Mini Handbook](https://www.qiagen.com/us/resources/resourcedetail?id=14e7cf6e-521a-4cf7-8cbc-bf9f6fa33e24)

## 核心作用

| 作用 | 实验意义 |
| --- | --- |
| 还原二硫键 | 破坏蛋白结构，帮助裂解 |
| 抑制 RNase | RNase 蛋白结构被破坏后活性下降 |
| 配合胍盐裂解 | 提高复杂样本 RNA 保护能力 |
| 改善 RNA 回收 | 降低 RNA 在裂解早期被降解的风险 |

## β-巯基乙醇 vs DTT

| 还原剂 | 特点 | 常见用途 |
| --- | --- | --- |
| β-巯基乙醇 | 挥发、气味强、常加到 RNA 裂解液 | RNA 提取裂解 buffer |
| [DTT](DTT.md) | 气味小一些，常用于酶反应 buffer | 逆转录、蛋白实验、酶保护 |
| TCEP | 稳定、无硫醇气味 | 部分蛋白/化学体系 |

不同还原剂不能随意替换。RNA 提取试剂盒要求 β-巯基乙醇时，应按说明执行；如果想替换成 DTT，必须查试剂盒是否允许。

## 使用 protocol

### 加入裂解液

**怎么做**：在通风橱中按说明把 β-巯基乙醇加入指定裂解液，混匀后标注加入日期。部分 buffer 加 β-ME 后有使用期限。

**为什么**：β-巯基乙醇挥发且气味强，必须在通风橱处理；加入后裂解液对 RNase 的抑制能力更完整。

**注意事项**：

- 必须遵守 [通风橱使用规范](<../实验室安全/通风橱使用规范.md>) 和 [SDS与GHS标签](<../实验室安全/SDS与GHS标签.md>)。
- 不要在开放台面加 β-ME。
- 使用合适手套并避免吸入。
- 加入后的裂解液要清楚标注。

### 裂解样本

**怎么做**：将含 β-ME 的裂解液直接加入样本并充分混匀。

**为什么**：RNA 提取最危险的时间点是样本刚裂解但 RNase 尚未完全失活时；强变性裂解液和 β-ME 要尽快接触样本。

**注意事项**：

- 裂解液加样量不足会降低 RNase 失活能力。
- 复杂组织需要充分匀浆。

## 安全注意

β-巯基乙醇有强烈刺激性气味和毒性风险，应放在通风橱或合规储存位置，按 [危险化学品储存](<../实验室安全/危险化学品储存.md>) 管理。废液按含有机/有毒化学废液处理，不应倒入水槽。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| RNA 降解 | 忘加 β-ME、裂解不充分、样本处理慢 | 新配含 β-ME 裂解液，快速裂解 |
| 气味很大 | 在开放台面操作或容器密封差 | 转到通风橱，检查瓶盖和二级容器 |
| 试剂盒表现不稳定 | 加入后裂解液放太久 | 按说明重新加入或新配 |
| 安全投诉/暴露 | 操作不规范 | 停止操作，通风橱处理，按安全流程报告 |

## 小结

β-巯基乙醇在 RNA 提取中是保护 RNA 的强力还原剂，但也是安全负担很高的试剂。它应当在通风橱中按说明加入裂解液，清楚记录加入日期，并和 TRIzol、氯仿一样认真对待废液和暴露风险。
