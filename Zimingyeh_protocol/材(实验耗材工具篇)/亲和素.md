# 亲和素

## 一句话定义

Avidin（亲和素，也常指 egg-white avidin，卵白亲和素）是一种能高亲和力结合 [生物素](生物素.md) 的蛋白，常用于 avidin-biotin system（亲和素-生物素系统）中的信号放大、捕获或固定化。

现代免疫检测中更常使用 [链霉亲和素](链霉亲和素.md)（streptavidin），因为它通常非特异背景更低；但 avidin-biotin complex（ABC，亲和素-生物素复合物）仍然是经典 [免疫组化](<../用(实验流程内容篇)/免疫组化.md>) 放大体系之一。Thermo Fisher 和 Vector Laboratories 都将 avidin/streptavidin-biotin 体系作为常见高亲和力标记平台介绍。[参考：Thermo Fisher Biotin-Binding Proteins](https://www.thermofisher.com/us/en/home/life-science/protein-biology/protein-labeling-crosslinking/biotinylation/biotin-binding-proteins.html)；[参考：Vector Laboratories Avidin-Biotin System](https://vectorlabs.com/pages/avidin-biotin-system)

## 核心特点

| 特点 | 说明 |
| --- | --- |
| 高亲和力 | 与 biotin 结合非常强 |
| 四聚体结构 | 可结合多个 biotin 分子 |
| 来源 | 常见为鸡蛋白来源 |
| 糖基化和碱性 | 可能增加与组织或细胞成分的非特异结合 |
| 经典ABC体系 | IHC 中曾广泛用于信号放大 |

亲和素本身不识别抗原，它只识别生物素标签。实验中特异性来自抗体或探针，avidin/biotin 体系负责连接和放大。

## Avidin vs Streptavidin

| 维度 | Avidin | Streptavidin |
| --- | --- | --- |
| 中文 | 亲和素/卵白亲和素 | 链霉亲和素 |
| 来源 | 鸡蛋白 | 细菌 |
| 糖基化 | 通常有 | 通常无 |
| 等电点 | 偏碱性 | 较接近中性 |
| 非特异背景 | 可能较高 | 通常较低 |
| 常见用途 | 传统 ABC/IHC 体系 | 现代 ELISA、IF、磁珠、检测体系 |

如果只是选择一个低背景 biotin 结合试剂，streptavidin 通常是更常见的默认选择；如果 protocol 明确使用 ABC kit，则要按 avidin-biotin complex 的说明执行。

## 常见用途

- IHC ABC 放大体系。
- 生物素化抗体或探针检测。
- 生物素阻断步骤中的 avidin blocking。
- 捕获生物素化分子。
- 与 HRP/AP/荧光标签配合进行读出。

## 生物素阻断中的作用

在某些组织中，endogenous biotin（内源性生物素）会造成背景。常见 blocking 思路是：

```text
先用 avidin 占据内源性 biotin
再用 biotin 占据残余 avidin 结合位点
然后进入生物素化抗体/streptavidin 检测体系
```

具体顺序和时间应以所用 blocking kit 说明书为准。

## 注意事项

- Avidin 可能带来较高非特异背景，尤其在带负电的组织或细胞组分中。
- 使用 avidin-biotin 体系时，必须设置阴性对照。
- 内源性生物素丰富的组织应考虑 biotin blocking。
- 不要把 avidin、streptavidin、neutravidin 视为完全相同的试剂。
- 与 HRP/AP/荧光读出连接时，要确认标签和底物/仪器匹配。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| IHC 背景高 | 内源性 biotin 或 avidin 非特异结合 | 做 biotin blocking，改用 streptavidin 或 polymer 系统 |
| 无信号 | 抗体未生物素化或 detection reagent 不匹配 | 检查 biotinylated reagent 和读出标签 |
| 组织普遍着色 | ABC 体系过浓或洗涤不足 | 降低浓度，增加洗涤 |
| 批次差异 | 试剂盒或组织处理差异 | 固定 kit 批号和 protocol |
| 阻断后信号消失 | 阻断步骤影响检测链条 | 按 kit 说明优化 avidin/biotin blocking |

## 小结

亲和素是生物素体系里的经典结合蛋白，但现代实验中常被 streptavidin 替代以降低背景。它在 IHC ABC 放大和内源性 biotin 阻断中仍有重要位置。使用 avidin 相关体系时，要特别注意内源性 biotin、非特异背景和对照设计。
