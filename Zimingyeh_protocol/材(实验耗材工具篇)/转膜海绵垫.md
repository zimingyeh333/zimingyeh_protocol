# 转膜海绵垫

## 一句话定义

Transfer sponge pad（转膜海绵垫，也叫 foam pad、fiber pad）是 Western blot 湿转夹层中的弹性支撑材料，用来压紧凝胶、膜和 [滤纸](滤纸.md)，并维持夹层内 [转膜缓冲液](转膜缓冲液.md) 的流通。

在 [Western blot](<../用(实验流程内容篇)/Western blot.md>) 湿转中，海绵垫通常位于夹层最外侧，与滤纸、凝胶、[PVDF膜](PVDF膜.md) 或 [NC膜](NC膜.md) 共同组成 transfer sandwich（转膜夹层）。Bio-Rad 和 Thermo Fisher 的转膜说明都将 sponge/fiber pad 作为湿转夹层的重要组成部分。[参考：Bio-Rad Western Blotting Guide](https://www.bio-rad.com/applications-technologies/western-blotting-immunodetection-techniques?ID=PQEEPOBWLN4A)；[参考：Thermo Fisher Western Blot Protocols](https://www.thermofisher.com/uk/en/home/life-science/protein-biology/protein-biology-learning-center/protein-gel-electrophoresis-information/western-blot-protocols.html)

![Western blot膜、转膜缓冲液、Ponceau S与ECL示意图](<../z_asset/材/Western blot膜和检测/wb-membrane-transfer-detection-reference-zh.png>)

## 核心作用

| 作用 | 解释 |
| --- | --- |
| 提供弹性压力 | 让凝胶和膜紧密接触 |
| 支撑夹层 | 防止凝胶、膜和滤纸在转膜槽中移位 |
| 保持缓冲液通路 | 海绵孔隙可容纳转膜缓冲液 |
| 减少局部空隙 | 与滤纸配合降低气泡和不平整 |

海绵垫的作用不是“填充空间”这么简单。压得太松会接触不良，压得太紧可能导致凝胶变形、条带扭曲或夹层难以均匀导液。

## 常见湿转夹层

从负极到正极常见顺序为：

```text
负极侧
转膜海绵垫
滤纸
凝胶
PVDF膜或NC膜
滤纸
转膜海绵垫
正极侧
```

蛋白在 SDS 体系中整体向正极迁移，因此膜必须放在凝胶靠正极的一侧。海绵垫通常不决定方向，但它决定夹层是否贴合和受力是否均一。

## 新旧海绵垫的差别

| 状态 | 可能影响 | 建议 |
| --- | --- | --- |
| 新海绵垫 | 弹性好，但可能有保存液或粉尘 | 使用前充分浸洗和平衡 |
| 反复使用 | 可能变薄、变硬、变形 | 定期检查厚度和弹性 |
| 被污染 | 可能带入蛋白、抗体或化学残留 | 严重污染时更换 |
| 局部破损 | 造成夹层压力不均 | 不再用于关键实验 |

如果同一个实验室的某台转膜槽总是出现固定位置的转膜不均，除了电极和夹层方向，也应该检查海绵垫是否已经变形。

## 使用 protocol

1. 使用前用水或转膜缓冲液充分浸泡海绵垫。
2. 挤压几次排出内部空气，让海绵垫完全吸液。
3. 组装夹层时保持海绵垫平整覆盖滤纸。
4. 合上转膜夹时确认没有明显偏斜或异常受力。
5. 转膜结束后用水充分冲洗，按实验室要求保存或晾干。

不要把干海绵垫直接夹入转膜夹层。干区会造成电流不均、局部发热和转膜失败。

## 注意事项

- 海绵垫应与转膜槽型号匹配，厚度不合适会影响夹层压力。
- 不同品牌转膜槽的海绵垫不可随意混用。
- 海绵垫反复使用后要检查压缩变形。
- 接触过抗体或显色试剂的垫子不应再用于转膜。
- 若做低丰度蛋白或定量 WB，建议使用状态一致的干净海绵垫。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 转膜局部失败 | 海绵垫未浸透或有气泡 | 充分浸泡并挤压排气 |
| 条带弯曲 | 夹层压力不均或垫子变形 | 更换海绵垫，重新组装夹层 |
| 转膜效率低 | 夹层太松，凝胶和膜接触差 | 检查垫子厚度和转膜夹闭合 |
| 凝胶破裂 | 夹层过紧或操作粗暴 | 使用匹配厚度垫子，轻柔组装 |
| 背景污染 | 海绵垫残留试剂或蛋白 | 使用干净垫子，必要时更换 |

## 小结

转膜海绵垫是 WB 湿转中容易被忽略的变量。它的弹性、厚度、洁净度和浸润状态会直接影响凝胶与膜的接触质量。遇到固定区域转膜不均时，不要只查抗体和膜，也要查海绵垫。
