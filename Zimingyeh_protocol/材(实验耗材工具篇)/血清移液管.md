# 血清移液管

Serological pipette（血清移液管 / 血清学移液管）是一种一次性或玻璃制的大体积刻度移液管，常与 [电动助吸器](电动助吸器.md) 或手动助吸器配合，用于转移 1-50 mL 级别液体。在细胞培养中，它主要用于吸取和加入 [培养基](培养基.md)、[PBS](PBS.md)、[DPBS](DPBS.md)、细胞悬液和其他无菌溶液。

## 核心用途

| 用途 | 为什么用血清移液管 | 注意事项 |
| --- | --- | --- |
| 大体积培养基转移 | 比移液枪更适合 5-50 mL | 体积精度低于微量移液枪 |
| 换液 | 可快速吸走旧液、加入新液 | 避免刮到细胞层 |
| 传代重悬 | 适合温和吹打细胞悬液 | 吹打过猛会损伤细胞 |
| 分装缓冲液 | 适合无菌大体积分装 | 注意无菌包装和滤塞 |
| 制备细胞悬液 | 可混匀较大体积 | 细胞会沉降，需边混边分装 |

## 常见规格与颜色

| 规格 | 常见颜色标识 | 适合体积 | 注意事项 |
| --- | --- | --- | --- |
| 1 mL | 常见黄色或品牌特定 | 小体积但需要较长管体操作 | 精度不如微量移液枪 |
| 2 mL | 常见绿色或品牌特定 | 1-2 mL 范围 | 适合小瓶、小皿操作 |
| 5 mL | 常见蓝色 | 2-5 mL | 细胞培养常用 |
| 10 mL | 常见橙色 | 5-10 mL | 换液、分装常用 |
| 25 mL | 常见红色 | 10-25 mL | T75/T175 换液常用 |
| 50 mL | 常见紫色 | 大体积转移 | 管体长，BSC 内操作要稳 |

不同品牌颜色和刻度细节可能不同，颜色只能辅助识别，不能替代读刻度。

## 结构与质量要点

| 结构/参数 | 英文 | 作用 |
| --- | --- | --- |
| 刻度 | Graduations | 粗略读体积 |
| 负刻度 | Negative graduations | 允许超过标称体积短时吸取 |
| 滤塞 | Plug / filter plug | 减少液体或气溶胶进入助吸器 |
| 无菌包装 | Sterile wrapping | 适合细胞培养无菌操作 |
| 材料 | Polystyrene / glass | 一次性塑料最常用 |
| 无热原 | Non-pyrogenic | 对细胞和敏感实验更重要 |

Corning 和 Thermo Fisher 的 serological pipette 产品资料都强调无菌、独立包装、滤塞、刻度清晰和多规格选择。[参考：Corning Stripette Serological Pipets](https://www.corning.com/worldwide/en/products/life-sciences/products/liquid-handling/pipets/serological-pipets.html)；[参考：Thermo Fisher Serological Pipettes](https://www.thermofisher.com/us/en/home/life-science/lab-plasticware-supplies/lab-plasticware-supplies-products/pipettes-pipette-tips/serological-pipettes.html)

## 使用 protocol

### 开包与安装

**怎么做**：在 [BSC生物安全柜](BSC生物安全柜.md) 内从助吸器端打开包装，避免手接触管尖。将移液管尾端插入电动助吸器，确认密封稳定。

**为什么**：管尖是进入培养基或细胞悬液的部分，污染管尖就等于污染液体。

**注意事项**：

- 不要把移液管尖端碰到包装外侧、手套或台面。
- 装入助吸器时不要用力过猛导致管尾开裂。
- 若滤塞被液体打湿，应更换移液管并检查助吸器。

**替代方案**：小体积精密加样用 [移液枪](移液枪.md)；重复等量分液可用 [连续分液器](连续分液器.md)。

**出错后果**：污染、漏气、吸液不稳或助吸器内部污染。

### 吸液

**怎么做**：将管尖浸入液面下方，缓慢吸液到目标刻度以上或目标刻度处，再按需要调整到准确刻度。保持管体垂直读数。

**为什么**：血清移液管的读数依赖 meniscus（弯月面）和刻度。倾斜读数会造成体积误差。

**注意事项**：

- 不要吸入过快造成泡沫。
- 不要让液体吸到滤塞。
- 细胞悬液吸取前要轻柔混匀。

**替代方案**：黏稠或易起泡液体降低吸液速度。

**出错后果**：体积不准、泡沫、细胞损伤或助吸器污染。

### 排液与混匀

**怎么做**：沿容器壁缓慢排液。混匀细胞时可轻柔吹打，但不要直接高速冲击细胞层或产生大量泡沫。

**为什么**：细胞培养中，大体积液流会显著影响贴壁细胞和悬浮细胞状态。气泡也会影响细胞活率和接种均匀性。

**注意事项**：

- 对贴壁细胞换液时沿壁加入培养基。
- 对悬浮细胞分装时边混匀边分装，避免细胞沉降。
- 不要用同一支移液管跨样本接触不同瓶口或细胞。

**替代方案**：敏感细胞用更宽口径、低剪切方式，或减少吹打次数。

**出错后果**：贴壁细胞脱落、细胞团聚、分装细胞数不一致。

## 血清移液管 vs 移液枪 vs 瓶口分液器

| 工具 | 优点 | 局限 | 适合 |
| --- | --- | --- | --- |
| 血清移液管 + 电动助吸器 | 大体积无菌转移方便 | 精度有限，依赖手法 | 细胞培养换液、分装培养基 |
| [移液枪](移液枪.md) | 微量精确 | 大体积效率低 | PCR、qPCR、精确加样 |
| [电动移液器](电动移液器.md) | 稳定重复移液 | 成本较高 | 多孔板重复加样 |
| [瓶口分液器](瓶口分液器.md) | 快速分装固定体积 | 不适合所有无菌细胞操作 | 大量 buffer 或培养基分装 |

## 购买建议

细胞培养优先选择 sterile（无菌）、individually wrapped（独立包装）、带滤塞、刻度清晰、无热原的血清移液管。常见品牌包括 [Corning](<../番外/试剂厂商/Corning.md>)、[Thermo Scientific](<../番外/试剂厂商/Thermo Scientific.md>)、[Greiner Bio-One](<../番外/试剂厂商/Greiner Bio-One.md>)、[Sarstedt](<../番外/试剂厂商/Sarstedt.md>)、[NEST](<../番外/试剂厂商/NEST.md>)、[BRAND](<../番外/试剂厂商/BRAND.md>) 等。

购买时看：

- 规格是否覆盖 1、2、5、10、25、50 mL。
- 包装是否适合无菌操作。
- 是否有滤塞和清晰正负刻度。
- 与本实验室电动助吸器是否适配。
- 管体硬度和刻度印刷是否容易读。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理策略 |
| --- | --- | --- |
| 吸液不稳 | 管尾未密封、助吸器滤膜堵塞 | 重新安装，检查助吸器 |
| 液体进滤塞 | 吸液过快或超过容量 | 降低速度，更换移液管 |
| 细胞被冲掉 | 加液太快，直接冲击细胞层 | 沿壁缓慢加液 |
| 分装不均 | 细胞沉降、未混匀 | 分装中定期轻柔混匀 |
| 污染 | 管尖碰到非无菌表面或重复接触瓶口 | 更换移液管，规范无菌动作 |

## 小结

血清移液管是细胞培养中最常用的大体积无菌转移耗材。它的重点不是极限精度，而是无菌、顺手、读数清楚、与助吸器配合稳定，以及在换液和重悬时尽量减少污染和细胞损伤。
