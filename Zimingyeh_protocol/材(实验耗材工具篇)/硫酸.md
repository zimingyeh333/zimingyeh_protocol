# 硫酸

## 一句话定义

Sulfuric acid（硫酸，H2SO4）是一种强酸、强腐蚀性化学品，在生命科学实验中常见于酸性终止液、清洗/消解体系或某些化学反应体系。

在 [ELISA](<../用(实验流程内容篇)/ELISA.md>) 中，稀硫酸常作为 [TMB](TMB.md) 显色反应的 stop solution（终止液），使蓝色氧化产物转为黄色，并在 450 nm 读取吸光度。PubChem 和 OSHA 都将 sulfuric acid 归为高腐蚀性危险化学品，使用时必须遵守 SDS 和实验室安全规范。[参考：PubChem Sulfuric Acid](https://pubchem.ncbi.nlm.nih.gov/compound/Sulfuric-Acid)；[参考：OSHA Sulfuric Acid](https://www.osha.gov/chemicaldata/640)

## 常见用途

| 用途 | 说明 |
| --- | --- |
| ELISA 终止液 | 终止 TMB-HRP 显色并稳定读数窗口 |
| pH 调整 | 少数强酸条件需要 |
| 化学清洗/消解 | 特定仪器或化学流程 |
| 实验室标准酸 | 滴定或配制酸性溶液 |

本项目里最常见的语境是 ELISA TMB 终止液。浓硫酸的实验风险远高于常规缓冲液，不能把它当普通酸处理。

## 浓硫酸 vs 稀硫酸

| 类型 | 风险理解 |
| --- | --- |
| 浓硫酸 | 强腐蚀、强脱水性，稀释强烈放热 |
| 稀硫酸 | 仍有腐蚀性，浓度越高风险越大 |
| ELISA stop solution | 通常为厂家配制或实验室稀释的酸性终止液 |

稀释硫酸时必须遵循“酸入水”原则：将酸缓慢加入水中并混匀散热，不要把水倒入浓硫酸中。

## ELISA中作为终止液

TMB 显色过程通常是：

```text
HRP + TMB
→ 蓝色产物
→ 加硫酸终止
→ 黄色产物
→ 450 nm 读数
```

加入终止液后，应轻轻混匀并在说明书规定时间内读板。不同孔终止时间差异太大，会影响 OD 值可比性。

## 安全注意事项

- 操作浓硫酸或配制稀硫酸应在通风橱内进行。
- 必须佩戴合适 [个人防护装备](<../实验室安全/个人防护装备.md>)，包括护目镜、实验服和耐酸手套。
- 稀释时将酸缓慢加入水，边加边冷却/混匀。
- 硫酸接触皮肤或眼睛需立即按实验室应急流程冲洗并报告。
- 硫酸废液按 [实验室废弃物处理](<../实验室安全/实验室废弃物处理.md>) 要求分类，不得随意倒入水槽。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| ELISA 孔间差异大 | 加终止液节奏不一致 | 使用多道移液器，固定加样顺序和时间 |
| 读数异常偏高 | 显色过久或终止太晚 | 缩短显色时间，统一终止 |
| 终止后颜色不均 | 混匀不足或气泡 | 轻拍混匀，读板前去除气泡 |
| 配酸时发热剧烈 | 稀释顺序错误或加酸太快 | 酸入水，缓慢加入并冷却 |
| 安全标签不清 | 二次容器未标浓度 | 立即补充标签和日期 |

## 小结

硫酸在 ELISA 中常作为 TMB 终止液，但它本质上是强腐蚀性危险化学品。实验记录中应写清浓度、用途、加入体积和读板时间；安全上必须遵守酸入水、通风橱、PPE 和废液分类。
