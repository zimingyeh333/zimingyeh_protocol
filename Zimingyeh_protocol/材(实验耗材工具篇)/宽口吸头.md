# 宽口吸头

Wide-bore pipette tip（宽口移液枪吸头）是末端开口比普通吸头更大的 [移液枪吸头](移液枪吸头.md)。它的核心价值是降低液体通过狭窄末端时产生的剪切力和堵塞风险，常用于细胞悬液、类器官、细胞团块、基因组 DNA、高黏度液体和易碎样本。

## 为什么需要宽口

普通吸头末端很细，适合精确定量，但对细胞团块、长链 DNA、黏稠样本或易碎细胞来说，狭窄开口会增加剪切、堵塞和样本损失。宽口吸头通过扩大末端开口，让样本通过时更温和。

Eppendorf 和 Rainin 等吸头供应商都提供 wide bore / wide orifice tip（宽口/大孔径吸头）产品线，用于减少剪切力或处理黏稠、含颗粒和易碎样本。[参考：Eppendorf Pipette Tips](https://www.eppendorf.com/us-en/Laboratory-Consumables/Pipette-Tips/)；[参考：Rainin Wide-Orifice Tips](https://www.mt.com/us/en/home/products/pipettes/pipette-tips/wide-orifice-tips.html)

## 常见用途

| 样本 | 为什么用宽口 |
| --- | --- |
| 细胞悬液 | 降低剪切力，减少细胞破裂 |
| 原代细胞和干细胞 | 对机械应激更敏感 |
| 类器官、细胞团块、球体 | 减少堵塞和团块破碎 |
| 高分子量 genomic DNA（基因组 DNA） | 避免长链 DNA 被剪切 |
| 高黏度液体 | 降低吸排阻力和气泡 |
| beads / resin（磁珠/树脂） | 减少颗粒堵塞 |

## 宽口吸头 vs 剪口吸头

| 方式 | 优点 | 缺点 |
| --- | --- | --- |
| 商业宽口吸头 | 开口一致、无菌等级可控、重复性好 | 成本更高 |
| 自剪吸头 | 临时方便、成本低 | 开口不一致，可能有毛边、污染和体积误差 |
| 普通吸头 | 定量精度好、便宜 | 易剪切、易堵塞 |

对于正式 protocol，优先使用商业宽口吸头；自剪吸头只能作为临时方案，并且要记录剪口方式和是否无菌。

## 使用 protocol

### 选择吸头

**怎么做**：根据样本体积和颗粒/细胞团大小选择合适量程的宽口吸头。细胞培养和原代样本使用无菌版本；分子实验使用无核酸酶版本。

**为什么**：开口太小仍会剪切或堵塞，开口太大可能降低小体积移液准确性。

**注意事项**：

- 宽口吸头不一定适合极小体积精确定量。
- 关键实验固定品牌和型号。
- 细胞样本不要过度吹打。

### 吸排细胞或团块

**怎么做**：缓慢吸液和排液，避免产生泡沫。对类器官或细胞团块，尽量减少通过吸头的次数。

**为什么**：宽口降低剪切，但反复机械吹打仍会破坏细胞和结构。

**注意事项**：

- 不要为了“完全打散”而牺牲活率。
- 如果样本仍然堵塞，说明团块过大或吸头口径不够。
- 类器官传代要根据目标选择保留团块还是单细胞化。

### 高分子 DNA 或黏稠样本

**怎么做**：使用宽口吸头缓慢吸排，不要 vortex 或剧烈吹打。

**为什么**：长链 DNA 很容易被机械剪切；黏稠样本高速吸排会造成体积误差和气泡。

**替代方案**：对非常黏稠或易挥发液体，可考虑 [正置换移液器](正置换移液器.md)。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 仍然堵塞 | 团块太大、吸头口径不够 | 先沉降/过滤/温和分散，换更大口径 |
| 细胞活率低 | 吹打次数太多、速度太快 | 减少次数，降低速度 |
| 体积不准 | 开口大且液体黏稠，小体积不适合 | 换合适量程，预润湿，考虑正置换 |
| 污染风险 | 自剪吸头不无菌或有毛边 | 用商业无菌宽口吸头 |

## 购买与记录建议

购买时看 volume range（量程）、wide-bore / wide-orifice 标注、是否 sterile、是否 filtered、是否 low-retention、是否 RNase/DNase-free。常见供应商包括 [Eppendorf](<../番外/试剂厂商/Eppendorf.md>)、[Rainin](<../番外/试剂厂商/Rainin.md>)、[Thermo Scientific](<../番外/试剂厂商/Thermo Scientific.md>)、[Sartorius](<../番外/试剂厂商/Sartorius.md>) 等。

推荐记录：

```text
Wide-bore tip, volume range, opening/orifice type, sterile yes/no, brand, catalog number, lot number, sample type
```

## 小结

宽口吸头解决的是“样本通过吸头时太挤”的问题。它特别适合细胞、类器官、长链 DNA 和黏稠样本，但不适合所有小体积精确定量场景。
