# 折光仪

Refractometer（折光仪/折射仪）是用于测量 refractive index（RI，折光率）的仪器。它常用于快速估算某些溶液浓度、验证 sucrose gradient（[蔗糖](蔗糖.md)梯度）或 iodixanol/iohexol density gradient（碘克沙醇/碘海醇密度梯度）是否接近目标，是密度梯度和溶液配制中的常见质控工具。

## 定义与命名

折光仪的英文是 refractometer。它测量的是 [refractive index（RI，折光率）](<../番外/补充知识/折光率.md>)，也就是光在样品中传播速度和方向相对于真空/空气的变化。IUPAC Gold Book 将 refractive index 定义为光在真空中的速度与光在特定介质中的速度之比。参考：[IUPAC Gold Book refractive index](https://goldbook.iupac.org/terms/view/R05240/pdf)。

常见记录写法：

```text
RI = nD 1.3330 at 20°C
Instrument = refractometer
Temperature compensation = yes/no
Calibration = water / standard solution
```

如果仪器显示 Brix（白利度），那通常是糖溶液浓度相关标尺，不应直接当作所有溶液的通用浓度。

## 常见类型

| 类型 | 特点 | 适合场景 |
| --- | --- | --- |
| Handheld digital refractometer（手持数字折光仪） | 小巧、上样少、读数快 | 常规溶液和教学/现场测量 |
| Benchtop digital refractometer（台式数字折光仪） | 精度、温控和数据管理更好 | 质控、批记录、较严谨实验 |
| Abbe refractometer（阿贝折光仪） | 经典光学结构，可观察明暗界面 | 教学、基础测量、部分老 SOP |
| Inline/process refractometer（在线折光仪） | 接入生产或流路 | 工业/连续生产过程控制 |

生命科学实验室最常见的是手持数字折光仪和台式数字折光仪。密度梯度实验如果要求更高一致性，应优先选择有温控、校准记录和足够精度的型号。

## 主要用途

| 场景 | 为什么用折光仪 | 记录重点 |
| --- | --- | --- |
| [密度梯度离心](<../用(实验流程内容篇)/密度梯度离心.md>) | 用 RI 辅助确认梯度层是否配对 | RI、温度、标准曲线、介质批号 |
| [OptiPrep](OptiPrep.md) 梯度 | iodixanol 溶液 RI 可辅助判断浓度/密度 | 稀释液、RI、density、osmolality |
| [Nycodenz](Nycodenz.md) 梯度 | 自配储备液时可做快速质控 | 称量、终体积、RI、温度 |
| [Percoll](Percoll.md) 梯度 | 可结合密度关系判断梯度 | Percoll 百分比、RI、离心条件 |
| 蔗糖梯度 | 常用 RI 或 Brix/浓度表辅助判断 | 蔗糖浓度、温度、RI |
| 溶液批间质控 | 判断配方是否偏离历史批次 | 标准曲线、仪器、校准液 |

折光仪的价值是“快速、少量、可重复”。但它不能告诉你细胞是否真的健康，也不能替代 marker 检测或功能读数。

## 基本操作流程

不同型号细节不同，通用流程如下：

```text
确认仪器干净、干燥：
用纯水或标准液校准：
记录校准温度：
混匀样品：
滴加足量样品覆盖棱镜/测量面：
避免气泡、颗粒和蒸发：
等待读数稳定：
记录 RI/nD、温度、仪器、校准液和样品批号：
用适当方式清洁测量面：
必要时按标准曲线换算浓度或密度：
```

测高盐、高糖、高蛋白或含有颗粒的样品时，读数可能受污染、浑浊、气泡和样品残留影响。密度梯度 fraction 测量前要保证取样方式一致，否则不同层之间会互相污染。

## 温度和校准

折光率对 temperature（温度）敏感。同一个样品在不同温度下 RI 会不同，所以“1.350”这种孤立数字信息量不够。

| 变量 | 为什么重要 | 建议 |
| --- | --- | --- |
| 温度 | 影响 RI | 记录 20°C、25°C 或实际温度 |
| 波长/标尺 | nD、Brix 等不是同一表达 | 写清仪器显示的是 RI 还是 Brix |
| 校准液 | 决定基线 | 常用纯水或厂家标准液 |
| 标准曲线 | RI 到浓度/密度的转换依赖体系 | 只用对应溶质和温度的表 |
| 样品清洁度 | 颗粒和气泡会干扰光路 | 澄清样品并避免气泡 |

很多数字折光仪有 automatic temperature compensation（ATC，自动温度补偿）。即便如此，也建议记录是否启用 ATC，因为不同仪器的补偿模型可能不同。

## 和其他仪器对比

| 仪器 | 测什么 | 折光仪不能替代它的原因 |
| --- | --- | --- |
| [渗透压仪](渗透压仪.md) | osmolality，mOsm/kg | RI 不能精确反映所有渗透活性粒子 |
| [pH计](pH计.md) | pH | RI 不反映酸碱状态 |
| [电导率仪](电导率仪.md) | conductivity（电导率） | RI 不专门反映可导电离子 |
| [密度计](密度计.md) | density（密度） | RI 可和密度建表，但不是直接称量密度 |
| [分光光度计](分光光度计.md) | absorbance（吸光度） | RI 不等于光吸收或浓度通用检测 |

例如非离子碘化介质能显著改变 RI 和密度，但电导率变化可能不明显；盐溶液电导率明显，但 RI 到浓度的关系又需要专门校准。

## 选购建议

选择折光仪时，优先看使用场景：

| 需求 | 关注参数 |
| --- | --- |
| 密度梯度质控 | RI 精度、温控、标准曲线支持 |
| 常规教学和粗略判断 | 操作简单、易清洁 |
| 多人共用平台 | 数据导出、用户管理、校准记录 |
| 小体积样品 | 最小上样体积 |
| 高黏度或腐蚀性样品 | 棱镜材质和清洁方案 |

代表性供应商可参考 [Mettler Toledo](<../番外/试剂厂商/Mettler Toledo.md>)、[ATAGO](<../番外/试剂厂商/ATAGO.md>)、[Reichert](<../番外/试剂厂商/Reichert.md>) 等。购买时应确认仪器显示 RI/nD、Brix、density 或 concentration 的哪一种标尺，以及是否能导出原始 RI。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 读数偏离理论值 | 温度不同、校准错误、配制浓度错误 | 重新校准，统一温度，复核称量和定容 |
| 重复性差 | 棱镜残留、气泡、样品不均一 | 清洁测量面，重新混匀和取样 |
| 用 Brix 误判非糖溶液 | 把糖度标尺当通用浓度 | 使用 RI 原始读数或专用标准曲线 |
| RI 正常但细胞状态差 | osmolality、pH 或毒性问题 | 同时测渗透压和 pH，做生物学验证 |
| 梯度 fraction 读数混乱 | 取样污染或层间混合 | 固定取样体积和位置，必要时重做梯度 |
| 仪器漂移 | 校准液污染或棱镜损伤 | 更换标准液，检查仪器维护状态 |

## 小结

折光仪适合快速检查溶液浓度和密度梯度一致性，尤其适合 OptiPrep、Nycodenz、Percoll 和蔗糖梯度相关工作。它的关键不是读出一个漂亮数字，而是把温度、校准液、标尺、标准曲线、样品批号和清洁状态记录完整。
