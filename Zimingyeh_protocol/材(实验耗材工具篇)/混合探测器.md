# 混合探测器

## 一句话定义

Hybrid detector（混合探测器）是一类结合多种光电转换和电子放大技术优势的高灵敏显微探测器，常用于共聚焦显微镜中提高弱信号检测、动态范围和信噪比。

在 Leica 系统中，HyD detector（Hybrid Detector，混合探测器）是较常见的命名；其他厂商也有类似高灵敏 detector 方案。混合探测器常被用于替代或补充传统 [光电倍增管](光电倍增管.md)，尤其在弱信号、低激光功率和定量成像中有价值。[参考：Leica HyD Detectors](https://www.leica-microsystems.com/products/confocal-microscopes/p/hyd-detectors/)

## 为什么需要混合探测器

传统 PMT 灵敏，但在某些弱光或定量场景中噪声、QE 和动态范围可能受限。混合探测器的目标是：

| 目标 | 意义 |
| --- | --- |
| 提高灵敏度 | 用更低激光功率获得可用信号 |
| 降低噪声 | 提高弱信号信噪比 |
| 扩大动态范围 | 同时记录强弱信号 |
| 支持 photon counting | 某些模式可用于更精确计数 |
| 降低光毒性 | 对活细胞有帮助 |

## 与PMT和sCMOS的关系

| 探测器 | 常见位置 | 特点 |
| --- | --- | --- |
| PMT | 共聚焦/流式 | 经典快速点探测器 |
| 混合探测器 | 高端共聚焦 | 高灵敏、低噪声、可支持计数 |
| [sCMOS相机](sCMOS相机.md) | 宽场/转盘共聚焦 | 面阵成像，大视野 |
| [EMCCD相机](EMCCD相机.md) | TIRF/单分子 | 极弱面阵成像 |

混合探测器不是相机，它通常仍属于扫描显微镜的 detector。

## 适合用途

- 共聚焦弱信号成像。
- 活细胞低光毒成像。
- 需要降低激光功率的样本。
- 定量荧光强度比较。
- 共定位和三维成像中提高信噪比。

## 使用注意事项

- 不同 detector 模式下图像强度不能随意比较。
- Photon counting 模式要注意计数饱和。
- 高灵敏 detector 更容易暴露背景染色问题。
- 定量实验应固定 detector、gain、laser、pinhole 和扫描参数。
- 不要把 detector 增益提高当作真实信号增强。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 图像过曝 | detector 太灵敏或 laser 太高 | 降低激光或 gain |
| 背景也更明显 | 染色背景被高灵敏探测器记录 | 优化封闭和洗涤 |
| 定量不可比 | detector 模式不同 | 固定模式和参数 |
| 计数模式饱和 | photon rate 太高 | 降低光强或缩短 dwell time |
| 弱信号仍差 | 样本制备或染料限制 | 优化抗体/染料，而不是只调 detector |

## 小结

混合探测器是高端共聚焦系统中提高弱信号和低光照成像质量的重要工具。它能帮助降低光毒性和提高信噪比，但不能替代正确染色、对照和参数记录。定量成像时必须写清 detector 类型和模式。
