# 移液枪吸头

Pipette tips（移液枪吸头）是连接在 [移液枪](移液枪.md) 前端的一次性耗材，用于吸取、分配和转移液体。吸头看起来简单，但它直接影响体积准确性、污染风险、样品损失、气溶胶控制和珍贵样本回收率。

![qPCR板、封板膜和吸头参考图](../z_asset/材/实验耗材参考图/qPCR-plate-sealing-film-pipette-tip-reference.png)

图源：Image2 生成的实验耗材对照参考图；从左到右为 qPCR 板、光学封板膜、滤芯吸头、低吸附吸头、宽口吸头。

## 基本结构

| 部位 | 作用 | 选择时看什么 |
| --- | --- | --- |
| 连接口 | 与移液器锥体密封 | 是否适配对应品牌和量程 |
| 吸头主体 | 容纳液体并维持液柱 | 是否透明、刻度是否清楚、是否低吸附 |
| 末端开口 | 决定液体进出阻力 | 常规、细口或宽口 |
| 滤芯 | 阻挡气溶胶进入移液器 | 分子实验、细胞污染控制、感染性样本 |

Eppendorf 的吸头资料强调，吸头与移液器系统匹配会影响准确性、重复性和密封性；Thermo Scientific 的 ART barrier tips 也把气溶胶屏障用于防止样品和移液器污染作为核心卖点。[参考：Eppendorf Pipette Tips](https://www.eppendorf.com/us-en/Laboratory-Consumables/Pipette-Tips/)；[参考：Thermo Scientific ART barrier tips](https://www.thermofisher.com/us/en/home/life-science/lab-plasticware-supplies/pipette-tips/art-barrier-tips.html)

## 常见类型对比

| 类型 | 英文 | 核心价值 | 典型场景 |
| --- | --- | --- | --- |
| 普通吸头 | Standard pipette tip | 成本低，适合常规液体转移 | 缓冲液、培养基、普通试剂 |
| [滤芯吸头](滤芯吸头.md) | Filter tip / barrier tip | 降低气溶胶和移液器污染 | PCR、qPCR、RNA、细胞污染控制 |
| [低吸附吸头](低吸附吸头.md) | Low-retention tip | 减少液体残留和样品损失 | 酶、蛋白、核酸、表面活性剂体系 |
| [宽口吸头](宽口吸头.md) | Wide-bore tip | 降低剪切力和堵塞 | 细胞、类器官、DNA、高黏度样本 |
| 加长吸头 | Extended-length tip | 触及深管底部，减少污染 | 深孔板、15/50 mL 管取样 |
| 无菌吸头 | Sterile tip | 降低微生物污染 | 细胞培养、无菌操作 |
| 无核酸酶吸头 | RNase/DNase-free tip | 降低核酸降解和污染 | RNA、PCR、测序前处理 |

## 选择逻辑

| 需求 | 推荐选择 | 理由 |
| --- | --- | --- |
| 常规水样或缓冲液 | 普通吸头 | 便宜且足够 |
| PCR/qPCR 体系 | 滤芯、无 DNA/RNase/DNase、低吸附可选 | 防止气溶胶污染和样品残留 |
| RNA 实验 | 滤芯、RNase-free | 降低 RNase 和交叉污染 |
| 细胞悬液 | 宽口吸头或剪口吸头 | 降低剪切力和细胞团堵塞 |
| 蛋白/酶/低体积样品 | 低吸附吸头 | 减少壁面残留 |
| 高黏度液体 | 宽口吸头、正置换移液器可选 | 降低阻力和体积误差 |

## 使用 protocol

### 装吸头

**怎么做**：选择匹配量程和移液器品牌的吸头，垂直插入吸头盒，轻轻压紧形成密封。

**为什么**：密封不好会漏气，直接导致移液体积偏低或重复性差。

**注意事项**：

- 不要用力猛戳吸头盒，可能磨损移液器锥体。
- 多道移液枪要检查每个通道是否都装紧。
- 关键定量实验固定吸头品牌和型号。

### 预润湿

**怎么做**：吸取并排出目标液体 2-3 次，再正式吸取。

**为什么**：预润湿可以让吸头内壁达到更稳定的液膜和蒸气平衡，减少小体积误差。

**注意事项**：挥发性液体、黏稠液体和小体积移液尤其需要预润湿。

### 吸液和排液

**怎么做**：吸液时让吸头末端进入液面下方合适深度，缓慢释放按钮；排液时贴壁或悬空按实验要求完成第一档、第二档。

**为什么**：插入过深会带入外壁液滴，过浅会吸入气泡；速度太快会造成气溶胶、泡沫和体积误差。

**注意事项**：

- 不同液体黏度不同，吸排速度要调整。
- 吸头外壁液滴要避免带入下一管。
- PCR/qPCR 加样时尽量避免气泡。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 体积不准 | 吸头不适配、密封差、未预润湿 | 换匹配吸头，检查移液器，预润湿 |
| 有气泡 | 吸液太快、吸头进入液面太浅 | 降低速度，控制浸入深度 |
| 样品残留多 | 液体低表面张力或吸头材料吸附 | 使用低吸附吸头 |
| 细胞破碎或团块堵塞 | 开口太细、吹打太猛 | 使用宽口吸头，降低吹打强度 |
| PCR 污染 | 气溶胶回流、重复使用或操作区污染 | 使用滤芯吸头，分区操作 |

## 小结

移液枪吸头不是“随便一个塑料头”。普通吸头解决常规转移，滤芯吸头解决污染控制，低吸附吸头解决残留损失，宽口吸头解决剪切和堵塞。越是小体积、珍贵样本、PCR/RNA 或细胞样本，越要认真选择吸头。
