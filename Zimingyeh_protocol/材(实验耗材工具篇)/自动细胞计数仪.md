# 自动细胞计数仪

Automated cell counter（自动细胞计数仪）是利用图像识别、明场/荧光检测或阻抗等方式自动计算细胞浓度和活率的设备。它常用于 [细胞计数](<../用(实验流程内容篇)/细胞计数.md>)、细胞接种、传代、冻存和药物处理前的样本标准化。

![Automated cell counter reference image](https://assets.thermofisher.com/TFS-Assets/CCG/product-images/A49859-650x600.jpg-650.jpg)

图源：[Thermo Fisher Countess 3 Automated Cell Counter](https://www.thermofisher.com/order/catalog/product/A49859)

## 核心用途

| 用途 | 输出 | 注意事项 |
| --- | --- | --- |
| 细胞浓度计算 | cells/mL | 需要细胞悬液均匀、无明显团块 |
| 活率评估 | viability（活率） | 常依赖 [台盼蓝](台盼蓝.md) 或荧光死活染 |
| 接种计算 | 目标体积和细胞数 | 结果要结合稀释倍数 |
| 冻存前 QC | 活率和冻存密度 | 活率低时不适合建立关键库存 |
| 图像留档 | 原始计数图像 | 异常样本必须看图，不只看数字 |

Thermo Fisher 的 Countess 系列资料把自动细胞计数仪定位为快速测量细胞数量、浓度和活率的设备，常与 trypan blue（台盼蓝）或荧光试剂配合使用。[参考：Thermo Fisher Countess 3](https://www.thermofisher.com/order/catalog/product/A49859)

## 工作逻辑

常见自动计数仪并不是“真正懂细胞”，而是按图像和阈值识别颗粒，再根据算法判断细胞边界、大小、圆度、染色状态和背景。因此它比人工快，但也会被碎片、气泡、团块、异常形态和背景污染误导。

常见检测方式：

| 方式 | 原理 | 优点 | 局限 |
| --- | --- | --- | --- |
| 明场 + 台盼蓝 | 识别未染和蓝染细胞 | 便宜、接近日常手动计数 | 死细胞碎片和团块会干扰 |
| 荧光染色 | 识别特定活/死细胞染料 | 背景低，特异性更好 | 试剂和设备成本更高 |
| 图像明场无染 | 根据形态识别细胞 | 不加染料，速度快 | 活率判断有限 |
| 阻抗/库尔特原理 | 细胞通过孔道改变电阻 | 对悬浮颗粒计数稳定 | 设备类型和样本限制更多 |

## 与血球计数板的区别

| 项目 | [血球计数板](血球计数板.md) | 自动细胞计数仪 |
| --- | --- | --- |
| 速度 | 慢，依赖人工 | 快，适合多样本 |
| 成本 | 设备低，人工时间高 | 设备和耗材成本高 |
| 可追溯性 | 主要靠记录 | 通常可保存图像和报告 |
| 主观性 | 人为判断明显 | 算法一致，但参数会影响结果 |
| 异常样本 | 人可以灵活判断 | 需要人工复核图像 |
| 教学价值 | 能理解计数原理 | 容易只看结果不看图 |

## 使用 protocol

### 准备细胞悬液

**怎么做**：细胞充分但轻柔混匀，必要时吹散团块或通过 [细胞过滤器](细胞过滤器.md)。取样前再次混匀。

**为什么**：自动计数仪的前提是样本代表整体。细胞沉降和团块会造成浓度和活率同时失真。

**注意事项**：

- 不要用含大量气泡的样本上机。
- 团聚严重的细胞要先优化消化或过滤。
- 计数前记录稀释倍数。

**替代方案**：复杂样本用手动血球计数板复核，或用流式计数。

**出错后果**：接种密度、冻存密度和实验输入量全部偏差。

### 染色和上样

**怎么做**：按设备说明把细胞和台盼蓝或专用染料混合，加入一次性计数板或计数片。避免气泡、过量加样和样本外溢。

**为什么**：计数腔体体积、焦平面和染色时间都会影响算法识别。

**注意事项**：

- 不同品牌计数板通常不能随意替代。
- 台盼蓝染色后不要放太久。
- 低浓度或高浓度样本可能超出仪器最佳范围。

**替代方案**：样本过浓时稀释后重测；样本过稀时增加浓度或改用更合适方法。

**出错后果**：仪器报错、识别失败、活率偏低或浓度偏差。

### 查看图像和结果

**怎么做**：不要只抄最终数字。检查原始图像中细胞边界、团块、碎片、气泡和蓝染判定是否合理，再记录 total cells、viable cells、viability 和 dilution factor。

**为什么**：自动计数仪提高的是效率，不是免除判断。异常样本的错误通常在图像上能看到。

**注意事项**：

- 保存代表性图像，尤其是关键实验和异常结果。
- 不同细胞大小差异大时要调整参数或选择专用模式。
- 同一项目尽量固定设备、染料、计数板和参数。

**替代方案**：重要批次用血球计数板或流式方法交叉验证。

**出错后果**：看起来精确的数字反而掩盖错误识别。

## 购买建议

常见品牌和产品线包括 [Thermo Scientific](<../番外/试剂厂商/Thermo Scientific.md>) / [Invitrogen](<../番外/试剂厂商/Invitrogen.md>) Countess、[Bio-Rad](<../番外/试剂厂商/Bio-Rad.md>) TC20、[Logos Biosystems](<../番外/试剂厂商/Logos Biosystems.md>) LUNA、[DeNovix](<../番外/试剂厂商/DeNovix.md>) CellDrop、[NanoEnTek](<../番外/试剂厂商/NanoEnTek.md>) 等。选择时重点看细胞大小范围、浓度范围、是否支持荧光、计数板成本、图像导出、数据记录、清洁维护和是否适合团聚细胞。

如果实验室细胞类型单一、样本少，血球计数板已经够用；如果样本多、多人协作、需要图像留档或高通量接种计算，自动计数仪的价值会明显增加。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理策略 |
| --- | --- | --- |
| 计数忽高忽低 | 细胞沉降、混匀不充分、团块多 | 上样前混匀，优化消化，必要时过滤 |
| 活率异常低 | 染色时间过长、碎片被识别为死细胞 | 缩短等待时间，查看图像并调整参数 |
| 活率异常高 | 死细胞碎片被忽略、染料失效 | 检查染料和图像，手动复核 |
| 仪器无法识别 | 气泡、样本太浓/太稀、计数板不匹配 | 重新上样，调整稀释倍数 |
| 不同设备结果不同 | 算法和阈值不同 | 同一项目固定设备，建立交叉验证 |

## 小结

自动细胞计数仪的优势是速度、可追溯和减少人工疲劳；它的风险是让人误以为“机器结果一定正确”。高质量自动计数依然依赖单细胞悬液、正确染色、合适浓度、图像复核和固定参数。
