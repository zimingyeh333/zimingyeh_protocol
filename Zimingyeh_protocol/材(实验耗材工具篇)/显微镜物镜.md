# 显微镜物镜

## 一句话定义

Microscope objective（显微镜物镜）是显微镜中最靠近样本、决定放大倍率、分辨率、收光能力和成像质量的核心光学部件。

在 [荧光显微镜](荧光显微镜.md) 中，物镜不仅决定“放大多少”，更决定能收集多少荧光、能分辨多细的结构、是否适合活细胞、共聚焦、TIRF 或厚样本成像。Nikon MicroscopyU、Leica 和 Olympus/Evident 的显微资料都强调 numerical aperture（NA，[数值孔径](../番外/补充知识/数值孔径.md)）和物镜校正类型对分辨率和亮度的关键影响。[参考：Nikon MicroscopyU Objectives](https://www.microscopyu.com/microscopy-basics/objective-lenses)；[参考：Leica Objectives](https://www.leica-microsystems.com/science-lab/life-science/objectives/)

## 物镜标签怎么读

常见物镜标签可能类似：

```text
Plan Apo 60x/1.40 Oil
```

含义：

| 字段 | 说明 |
| --- | --- |
| Plan | 平场校正，视野边缘更平 |
| Apo | 复消色差校正，色差控制好 |
| 60x | 放大倍率 |
| 1.40 | 数值孔径 NA |
| Oil | 需要 [浸油](浸油.md) |

只看 60× 不够。两个 60× 物镜，如果 NA、校正等级、浸没介质不同，成像质量可能完全不同。

## 核心参数

| 参数 | 英文 | 影响 |
| --- | --- | --- |
| 放大倍率 | Magnification | 物体在相机上的大小 |
| 数值孔径 | Numerical aperture, NA | 分辨率和收光能力 |
| 工作距离 | Working distance | 样本到物镜前端距离 |
| 浸没介质 | Immersion medium | 空气、水、油、硅油等 |
| 色差校正 | Chromatic correction | 多通道重合和颜色偏移 |
| 平场校正 | Flat-field correction | 视野边缘清晰度 |
| 盖玻片校正 | Cover glass correction | 对盖玻片厚度敏感样本很重要 |

## NA为什么重要

NA 越高，理论分辨率越高，收集荧光的能力也越强。荧光成像中，高 NA 物镜通常比单纯高倍数更重要。

| 需求 | 物镜选择思路 |
| --- | --- |
| 看整体细胞分布 | 10×/20×，视野大 |
| 常规细胞定位 | 20×/40×，中等 NA |
| 细胞器细节 | 60×/63×，高 NA |
| 单分子/TIRF | 高 NA 油镜，通常 NA ≥1.40 |
| 厚样本活细胞 | 水镜或长工作距离物镜 |

## 浸没介质

| 介质 | 英文 | 适合场景 | 注意点 |
| --- | --- | --- | --- |
| 空气 | Air | 低倍、常规观察 | NA 较低 |
| 油 | Oil | 高分辨固定样本、TIRF | 需匹配浸油，清洁重要 |
| 水 | Water | 活细胞、厚样本、水环境 | 蒸发和折射率匹配 |
| 硅油 | Silicone oil | 活细胞和深层成像 | 成本高，设备要求 |

不要把油镜直接用于不适合的样本，也不要把油留在物镜上。浸油错误或清洁不当会明显影响图像。

## 物镜与成像方式

| 成像方式 | 物镜重点 |
| --- | --- |
| 宽场荧光 | 视野、NA、平场校正 |
| 共聚焦 | NA、色差校正、工作距离 |
| TIRF | 极高 NA 油镜，角度控制 |
| 活细胞 | 工作距离、温控、浸没介质和低光毒 |
| 多通道共定位 | 色差校正和通道配准 |

## 注意事项

- 物镜倍率不是分辨率的唯一指标，NA 更关键。
- 盖玻片厚度不匹配会造成球差，尤其高 NA 物镜。
- 油镜使用后要按设备 SOP 清洁。
- 多通道共定位需要考虑色差和通道配准。
- 低倍大视野和高倍高分辨是不同需求，不能互相替代。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 高倍仍不清楚 | NA 不够、盖玻片不匹配、对焦差 | 换高 NA 物镜，确认盖玻片 |
| 图像边缘模糊 | 非平场物镜或样本不平 | 使用 Plan 物镜，改善制片 |
| 多通道位置偏移 | 色差校正不足 | 使用 Apo 物镜或做配准 |
| 油镜图像发雾 | 浸油错误或物镜脏 | 更换匹配浸油并清洁 |
| 活细胞状态差 | 油镜/光照/温度不适合 | 使用水镜或环境控制 |

## 小结

显微镜物镜决定荧光成像的分辨率、亮度和样本兼容性。选择物镜时不要只看倍率，要同时看 NA、浸没介质、工作距离、色差校正和盖玻片要求。高质量定量成像必须记录具体物镜参数。
