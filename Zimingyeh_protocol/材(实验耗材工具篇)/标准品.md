# 标准品

Standard（标准品；在定量试剂盒中也常称 calibrator，校准品）是具有已知浓度或活性单位的参考物，用于建立 [标准曲线](<../番外/补充知识/标准曲线.md>) 并把样本信号换算为浓度。在 [ELISA](<../用(实验流程内容篇)/ELISA.md>) 中，标准品通常是与检测目标对应的 [重组蛋白](重组蛋白.md)、纯化抗原、抗体、激素或小分子。

## 核心作用

ELISA 的 OD450 不是浓度本身。标准品的作用是建立“已知浓度 -> 信号”的对应关系：

```text
已知浓度标准品
-> 系列稀释
-> ELISA读数
-> 4PL/5PL标准曲线
-> 样本浓度换算
```

如果标准品配错，整块板的结果都会系统性错误。R&D Systems 和 BioLegend 的 ELISA protocol 都将 standard preparation（标准品准备）作为核心步骤之一。参考：[R&D Systems ELISA protocols](https://www.rndsystems.com/resources/protocols)；[BioLegend sandwich ELISA protocol](https://www.biolegend.com/en-us/protocols/sandwich-elisa-protocol)。

## 标准品常见形式

| 形式 | 特点 | 注意 |
| --- | --- | --- |
| 冻干粉 | 稳定，运输方便 | 复溶体积必须准确，需静置充分溶解 |
| 液体标准品 | 使用方便 | 保存和冻融更敏感 |
| 浓缩标准品 | 需要稀释到起始浓度 | 稀释错误会影响整条曲线 |
| 国际单位标准品 | 用 IU/mL 等单位 | 不能随意换算为质量浓度 |
| kit-specific calibrator | 与特定 kit 绑定 | 不应跨 kit 随意使用 |

标准品不是“任何同名蛋白”都能替代。不同厂家标准品的纯度、构象、糖基化、标签、校准体系和单位可能不同。

## 系列稀释

ELISA 标准品通常做 serial dilution（系列稀释），例如 2 倍、3 倍、4 倍或 10 倍梯度。稀释液最好使用说明书推荐的 standard diluent 或 sample diluent。

### 为什么要充分混匀

系列稀释是连续传递误差。第一管混匀不足，后面所有浓度都会错。低体积、高浓度蛋白和粘稠基质尤其容易造成梯度不准。

### 为什么要换吸头

不换吸头会造成 carryover（带入污染），尤其在高浓度到低浓度连续稀释时，会让低浓度标准孔偏高。

### 为什么标准曲线不能只做两点

ELISA 标准曲线通常是 S 形，需要多个点覆盖低、中、高范围。两点线性拟合无法描述平台区和非线性区，容易错误换算样本浓度。

## 标准品和样本的关系

| 问题 | 判断 |
| --- | --- |
| 样本 OD 高于最高标准 | 样本应稀释后重测 |
| 样本 OD 低于最低可靠标准 | 结果低于 LOQ，不适合精确定量 |
| 样本稀释后浓度不成比例 | 可能有基质效应 |
| 标准曲线好但样本异常 | 标准品体系没问题，重点查样本处理 |
| 标准曲线差 | 整板结果通常不可信 |

样本浓度最好落在曲线中段。靠近上下平台的结果，即使软件能算出数字，也不一定可靠。

## 标准品 vs 阳性对照

| 类型 | 作用 |
| --- | --- |
| 标准品 | 建立浓度-信号关系，用于定量 |
| 阳性对照 | 证明实验体系能检测到目标 |
| QC样本 | 监控批间和板间一致性 |
| spike control | 评估样本基质中的回收率 |

标准品不等同于阳性对照。标准品通常是纯化参考物，而阳性对照更像“已知会阳性”的样本或体系。长期项目最好同时有标准品和 QC 样本。

## 使用注意事项

- 按说明书加入准确复溶体积。
- 复溶后轻柔混匀，避免剧烈起泡。
- 需要静置时不要省略。
- 分装避免反复冻融。
- 使用同一批实验的标准品和稀释液。
- 记录标准品起始浓度、稀释倍数、单位和批号。

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 标准曲线不单调 | 稀释顺序错、孔位错、移液误差 | 重做标准品梯度 |
| 低浓度点偏高 | carryover、污染、背景高 | 换吸头，检查 blank |
| 高浓度点平台化 | 超出检测范围或显色过度 | 缩短显色时间或调整范围 |
| 整条曲线偏低 | 标准品复溶错误或失活 | 换新标准品 |
| 样本换算结果离谱 | 样本超范围或基质效应 | 做稀释预实验和 spike recovery |
| 不同 kit 结果不可比 | 标准品和校准体系不同 | 不跨 kit 直接合并 |

## 总结

标准品是 ELISA 定量的尺子。标准品复溶、稀释、单位、批号和曲线拟合任何一步出错，都会让整板样本浓度失去意义。做 ELISA 时，标准品不是附属步骤，而是定量可信度的中心。
