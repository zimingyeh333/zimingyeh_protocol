# 二向色镜

## 一句话定义

Dichroic mirror（二向色镜，也叫 dichroic beamsplitter，二向色分光镜）是荧光显微镜中的关键光学元件，用于按波长反射一部分光、透过另一部分光，从而分离 excitation light（激发光）和 emission light（发射光）。

在典型 [荧光显微镜](荧光显微镜.md) 中，二向色镜把短波长激发光反射到样本，同时让较长波长荧光发射光透过并进入检测器。Chroma、Nikon 和 Leica 等显微/光学资料都把 dichroic mirror 作为荧光滤光片组的核心部件之一。[参考：Chroma Fluorescence Filters](https://www.chroma.com/)；[参考：Nikon MicroscopyU Fluorescence Filters](https://www.microscopyu.com/microscopy-basics/fluorescence-filters)

## 在光路中的位置

```text
激发光源
→ 激发滤光片
→ 二向色镜反射激发光
→ 物镜
→ 样本发射荧光
→ 物镜收集发射光
→ 二向色镜透过发射光
→ 发射滤光片
→ 相机/检测器
```

二向色镜是激发路径和发射路径的分叉点。如果它的 cut-on/cut-off 波长不合适，信号和背景都会出问题。

## 核心参数

| 参数 | 说明 |
| --- | --- |
| 反射波段 | 哪些波长被反射到样本 |
| 透过波段 | 哪些波长能进入检测器 |
| 截止波长 | 反射和透过转换的波长附近 |
| 入射角 | 常见按 45° 使用，角度会影响光谱表现 |
| 多带二向色镜 | 可同时支持多个激发/发射通道 |

二向色镜通常和 [荧光滤光片](荧光滤光片.md) 成套设计。单独更换一个部件可能破坏整个通道匹配。

## 单带 vs 多带二向色镜

| 类型 | 英文 | 适合场景 | 注意点 |
| --- | --- | --- | --- |
| 单带二向色镜 | Single-band dichroic | 单一染料、信号纯净 | 多通道切换慢 |
| 双带/三带二向色镜 | Dual/triple-band dichroic | 多通道快速成像 | 串色和滤光片匹配更复杂 |
| 多激光共聚焦二向色镜 | Multi-laser dichroic | 共聚焦多激光系统 | 需按激光线和发射窗口选择 |

活细胞快速多通道成像可能需要多带二向色镜；高质量单通道成像可能更适合专用单带组合。

## 选择逻辑

| 需求 | 选择建议 |
| --- | --- |
| FITC/GFP 成像 | 匹配 488 激发和绿色发射 |
| DAPI + FITC + TRITC 多通道 | 使用合适多带二向色镜或切换 filter cube |
| 远红 Cy5/Alexa Fluor 647 | 确保远红发射透过效率高 |
| 共聚焦多激光 | 匹配激光线和检测窗口 |
| 低串色定量 | 优先精确匹配和单染验证 |

## 注意事项

- 二向色镜表面镀膜敏感，不能随意擦拭。
- 装反或角度不对会显著影响光谱表现。
- 多通道图像串色可能来自二向色镜、滤光片或染料组合。
- 更换 filter cube 后应重新确认通道名称和染料匹配。
- 记录显微镜配置时，dichroic 参数和滤光片参数同样重要。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 信号弱 | 二向色镜不匹配染料 | 查 filter set 参数 |
| 背景高 | 激发光泄漏到发射路径 | 检查二向色镜和发射滤光片 |
| 串色严重 | 多带镜和染料组合重叠 | 使用单染对照，换滤光片组 |
| 通道名和实际不符 | filter cube 被更换但软件未更新 | 校准并记录配置 |
| 图像出现反常颜色 | 伪彩色或通道映射错误 | 核对原始通道和伪彩设置 |

## 小结

二向色镜是荧光显微镜中分离激发光和发射光的关键分光部件。它通常和激发/发射滤光片成套工作。遇到信号弱、背景高或串色时，除了抗体和染料，也要检查二向色镜与滤光片组是否匹配。
