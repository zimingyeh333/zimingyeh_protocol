# 二抗

## 一句话定义

Secondary antibody（二抗，二级抗体）是识别一抗来源物种免疫球蛋白的抗体，常带有 HRP、AP、fluorophore（荧光团）等标记，用于把 [一抗](一抗.md) 的结合位置转化为可检测信号。

在 [Western blot](<../用(实验流程内容篇)/Western blot.md>) 中，最常见的是 [HRP标记二抗](HRP标记二抗.md) 配合 [ECL发光液](<ECL发光液.md>)；在 [免疫荧光](<../用(实验流程内容篇)/免疫荧光.md>) 中，则常用 [荧光二抗](荧光二抗.md)。Thermo Fisher、CST、Bio-Rad 和 Abcam 的 WB protocol 都将二抗孵育和后续检测作为一抗后面的信号放大步骤。[参考：Thermo Fisher Western Blot Protocols](https://www.thermofisher.com/uk/en/home/life-science/protein-biology/protein-biology-learning-center/protein-gel-electrophoresis-information/western-blot-protocols.html)；[参考：CST Western Blot Protocol](https://www.cellsignal.com/learn-and-support/protocols/protocol-western)

## 二抗识别逻辑

二抗的命名通常包含三层信息：

```text
宿主 species + anti-一抗物种 + 标记方式
```

例如：

```text
Goat anti-rabbit IgG-HRP
山羊抗兔 IgG-HRP 二抗
```

意思是：这支二抗由山羊产生，识别兔源一抗的 IgG，并带有 HRP 标记。它适合搭配 rabbit primary antibody（兔源一抗），不适合直接搭配 mouse primary antibody（鼠源一抗）。

## 常见标记方式

| 二抗类型 | 英文 | 检测方式 | 适合场景 |
| --- | --- | --- | --- |
| [HRP标记二抗](HRP标记二抗.md) | HRP-conjugated secondary antibody | 化学发光/显色 | 常规 WB、ELISA |
| AP标记二抗 | AP-conjugated secondary antibody | AP 发光或显色 | 特殊 WB/ELISA/染色 |
| [荧光二抗](荧光二抗.md) | Fluorophore-conjugated secondary antibody | 荧光成像 | IF、多重 WB、定量成像 |
| Biotinylated secondary antibody | 生物素化二抗 | Streptavidin 系统放大 | IHC/特殊检测体系 |

二抗类型必须和检测底物、仪器和实验目的匹配。HRP 二抗不能用 AP 底物，荧光二抗也不需要 ECL。

## 选择标准

| 检查项 | 说明 |
| --- | --- |
| 一抗宿主 | rabbit、mouse、goat、rat 等，二抗必须识别它 |
| 二抗宿主 | goat、donkey 等，影响交叉反应和多重染色设计 |
| Isotype | IgG、IgM、IgG subclass 等，必要时要精确匹配 |
| Cross-adsorbed | 是否经过交叉吸附，降低非目标物种反应 |
| Fragment | whole IgG、F(ab')2 fragment 等，影响 Fc 介导背景 |
| Label | HRP、AP、fluorophore、biotin 等 |
| Application | 是否适合 WB、IF、IHC、ELISA |

多重免疫荧光或多物种样本中，cross-adsorbed secondary antibody（交叉吸附二抗）尤其重要，可以减少二抗识别非目标物种免疫球蛋白带来的背景。

## WB使用 protocol

1. 一抗孵育结束后，用 [TBST](TBST.md) 洗膜。
2. 按说明书稀释二抗，常见稀释范围为 1:2000-1:10000，具体取决于产品和目标信号。
3. 室温轻摇孵育，常见 30-60 min。
4. 用 TBST 充分洗膜，常见 5-10 min × 3-5 次。
5. 根据标记方式进入 ECL、AP 底物或荧光成像。

二抗浓度是 WB 背景最常见的变量之一。二抗过浓会让整膜背景、非特异条带和亮点明显增加；过稀则会导致弱信号。

## 二抗与封闭体系的关系

| 条件 | 影响 |
| --- | --- |
| [脱脂奶粉](脱脂奶粉.md) | 便宜、常用，但可能影响磷酸化抗体或 biotin/avidin 体系 |
| [BSA](BSA.md) | 更适合磷酸化蛋白和某些敏感抗体 |
| 正常血清 | 在 IF/IHC 中常用于降低 Fc 相关背景 |
| 洗膜不足 | 未结合二抗残留会显著抬高背景 |

如果一抗表现很好，但二抗一上就整膜发亮，优先降低二抗浓度、延长洗膜，并检查封闭体系。

## 注意事项

- 二抗必须匹配一抗宿主，而不是样本物种。
- 做多重检测时，不同二抗的荧光通道要与仪器和滤光片匹配。
- HRP 二抗避免与 [叠氮钠](叠氮钠.md) 或不兼容保存液混用。
- 荧光二抗需要避光保存和避光孵育。
- 不同批号二抗背景可能不同，定量实验应记录 lot number。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 无信号 | 二抗不匹配一抗宿主、标记方式错误 | 检查 primary host 和 secondary anti-species |
| 整膜高背景 | 二抗过浓、洗膜不足、封闭不足 | 降低二抗浓度，增加 TBST 洗膜 |
| 非特异条带多 | 二抗交叉反应、一抗特异性差 | 使用交叉吸附二抗，优化一抗 |
| 多重染色串色 | 荧光通道选择不当 | 选择光谱分离更好的荧光二抗 |
| ECL无信号 | 用了非 HRP 二抗或 ECL 失效 | 确认 HRP 标签和 ECL 活性 |

## 小结

二抗负责把一抗的识别结果放大并转化为信号。选择二抗时最先确认一抗宿主和标记方式，再考虑交叉吸附、稀释度、封闭体系和成像方式。WB 高背景问题里，二抗浓度和洗膜条件经常是最值得先动的旋钮。
