# 辣根过氧化物酶

## 一句话定义

HRP（Horseradish peroxidase，辣根过氧化物酶）是一种常用酶标记物，能催化过氧化物参与的氧化反应，并把底物转化为可检测的颜色、荧光或化学发光信号。

在 [Western blot](<../用(实验流程内容篇)/Western blot.md>) 中，HRP 最常见的形式是 HRP-conjugated secondary antibody（HRP 标记二抗）。它与 [ECL发光液](<ECL发光液.md>) 配合，将抗体结合的位置转化为 chemiluminescence（化学发光）信号。Thermo Fisher、CST 和 Bio-Rad 的 WB protocol 都把 HRP-ECL 作为常规检测方案之一。[参考：Thermo Fisher Western Blot Protocols](https://www.thermofisher.com/uk/en/home/life-science/protein-biology/protein-biology-learning-center/protein-gel-electrophoresis-information/western-blot-protocols.html)；[参考：CST Western Blot Protocol](https://www.cellsignal.com/learn-and-support/protocols/protocol-western)

## 核心原理

HRP 使用 hydrogen peroxide（过氧化氢）或类似过氧化物作为氧化剂，催化底物发生氧化反应。不同底物会给出不同读出方式：

| 底物/体系 | 读出 | 常见应用 |
| --- | --- | --- |
| [Luminol](Luminol.md) 类 ECL 底物 | 化学发光 | Western blot |
| [TMB](TMB.md) | 显色/吸光度 | [ELISA](<../用(实验流程内容篇)/ELISA.md>) |
| [DAB](DAB.md) | 棕色沉淀 | [免疫组化](<../用(实验流程内容篇)/免疫组化.md>) |

因此 HRP 不是一种“单独发光”的酶。它必须和合适底物、合适检测设备、合适抗体体系一起使用。

## 在WB中的位置

常规 HRP-WB 的检测链条是：

```text
膜上目标蛋白
一抗识别目标蛋白
HRP标记二抗识别一抗
ECL底物被HRP催化发光
化学发光成像仪记录信号
```

如果没有 HRP 标记二抗，ECL 发光液通常不会产生目标条带。反过来，如果使用的是 fluorescent secondary antibody（荧光二抗），就不应该再用 ECL，而应使用荧光成像通道。

## HRP vs AP

| 维度 | HRP | [碱性磷酸酶](碱性磷酸酶.md) |
| --- | --- | --- |
| 英文全称 | Horseradish peroxidase | Alkaline phosphatase |
| 中文 | 辣根过氧化物酶 | 碱性磷酸酶 |
| 常见WB底物 | ECL 发光液 | AP 化学发光或显色底物 |
| 反应速度 | 通常较快 | 往往较慢但可较持久 |
| 常见优势 | 灵敏、便宜、产品体系成熟 | 背景体系不同，适合部分特殊场景 |
| 常见限制 | 易过曝，受叠氮钠等抑制 | 试剂选择和优化经验相对少 |

现代 Western blot 最常用的是 HRP-ECL，因为抗体、底物、成像仪和经验体系都非常成熟。AP 更适合在 HRP 背景不理想、需要替代酶体系或特定显色流程时考虑。

## 关键影响因素

| 因素 | 影响 |
| --- | --- |
| 二抗稀释度 | 过浓会高背景，过稀会弱信号 |
| ECL 灵敏度 | 高灵敏底物更容易过曝 |
| 洗膜强度 | 洗膜不足会保留非特异 HRP |
| 封闭液 | 不合适的封闭液会增加非特异结合 |
| 防腐剂 | [sodium azide](叠氮钠.md)（叠氮钠）可抑制 HRP，不能与 HRP 标记抗体体系随意混用 |

## 使用注意事项

- HRP 标记抗体应按说明书避光、低温保存，避免反复冻融。
- 使用 [二抗](二抗.md) 时要确认宿主来源和识别对象，例如 goat anti-rabbit IgG-HRP 不能随意替代 goat anti-mouse IgG-HRP。
- 抗体稀释液中若含叠氮钠，需确认是否会抑制 HRP。
- HRP-WB 定量时要保留未饱和曝光图，过曝条带不能可靠比较。
- 若整膜高背景，优先检查二抗浓度、封闭和 [TBST](TBST.md) 洗膜，而不是只更换 ECL。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 无信号 | 二抗不是 HRP 标记、抗体宿主不匹配、ECL 失效 | 检查二抗标签和 host species，使用阳性对照 |
| 整膜发亮 | 二抗过浓、洗膜不足、ECL 太灵敏 | 降低二抗浓度，增加洗膜，换标准型 ECL |
| 非特异条带多 | 二抗交叉反应或一抗特异性不足 | 换交叉吸附二抗，优化封闭和抗体稀释 |
| 信号迅速衰减 | ECL 发光时间短或成像延迟 | 混合 ECL 后及时成像，选择长效底物 |
| 内参过曝 | HRP 信号太强 | 降低上样量、抗体浓度或曝光时间 |

## 小结

HRP 是 WB、ELISA 和免疫组化中极常用的酶标记物。理解 HRP 的重点不是记住一个酶名，而是明确它和底物、抗体、洗膜、曝光之间的配套关系：HRP 负责把“抗体在哪里”转化为“信号在哪里”。
