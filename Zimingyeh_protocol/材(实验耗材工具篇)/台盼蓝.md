# 台盼蓝

Trypan blue（台盼蓝）是一种常用于 trypan blue exclusion assay（台盼蓝拒染实验）的活率染料。它不能进入细胞膜完整的活细胞，但可以进入膜受损的死细胞，因此常用于 [细胞计数](<../用(实验流程内容篇)/细胞计数.md>) 时区分活细胞和死细胞。

## 核心用途

| 用途 | 作用 | 注意事项 |
| --- | --- | --- |
| 手动细胞计数 | 配合血球计数板计算活率和活细胞浓度 | 需要校正稀释倍数 |
| 自动细胞计数 | 部分自动计数仪使用台盼蓝识别死细胞 | 要查看图像，避免碎片误判 |
| 复苏质量评估 | 评估 [细胞复苏](<../用(实验流程内容篇)/细胞复苏.md>) 后活率 | 不能完全预测后续恢复能力 |
| 冻存前质控 | 判断 [细胞冻存](<../用(实验流程内容篇)/细胞冻存.md>) 前细胞是否健康 | 活率低时不适合建立关键库存 |
| 药物毒性初筛 | 快速评估膜完整性受损 | 不等于完整细胞毒性机制分析 |

Thermo Fisher 的 Trypan Blue Exclusion protocol 说明，台盼蓝染死细胞，活细胞因细胞膜完整而不染色；该测试常和 hemocytometer（血球计数板）一起用于 routine subculturing（常规传代）时快速评估活率。[参考：Thermo Fisher Trypan Blue Exclusion](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/cell-culture-protocols/trypan-blue-exclusion.html)

## 实验原理

台盼蓝是 membrane integrity（膜完整性）检测。活细胞膜能排除染料，死细胞或膜受损细胞吸收染料后呈蓝色。

公式：

```text
细胞活率 % = 活细胞数 / 总细胞数 × 100%
```

Thermo Fisher 给出的计算方式也等价于：

```text
% viable cells = [1.00 - (blue cells / total cells)] × 100
```

如果和 0.4% 台盼蓝按 1:1 混合，稀释倍数通常为 2。计算 cells/mL 时必须乘回 dilution factor（稀释倍数）。[参考：Thermo Fisher Trypan Blue Exclusion](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/cell-culture-protocols/trypan-blue-exclusion.html)

## 常见规格

| 规格 | 用途 | 注意事项 |
| --- | --- | --- |
| 0.4% Trypan blue solution | 最常见，常与细胞悬液 1:1 混合 | 记得稀释倍数 |
| 0.2% Trypan blue solution | 部分计数仪或 protocol 使用 | 按设备说明调整 |
| 粉末 | 自行配制 | 需要过滤、储存和安全处理 |
| 自动计数仪配套染料 | 和特定仪器匹配 | 不同品牌不可随意替代 |

## 使用 protocol

### 准备细胞悬液

**怎么做**：把细胞轻柔混匀，必要时吹散团块或过滤。取代表性样本。

**为什么**：计数准确性取决于样本是否代表整体。细胞沉降、团块和碎片都会造成误差。

**注意事项**：

- 计数前后都要混匀。
- 团聚严重时不要直接相信自动计数结果。
- 死细胞多时，碎片可能干扰判断。

**替代方案**：团聚样本可用 [细胞过滤器](细胞过滤器.md) 或优化消化流程。

**出错后果**：活率和浓度同时不准，后续接种和冻存都受影响。

### 染色

**怎么做**：常见做法是 10 µL 细胞悬液 + 10 µL 0.4% 台盼蓝，轻柔混匀后立即上样。Thermo Fisher protocol 也采用 1:1 混合，并建议立即低倍显微镜观察。[参考：Thermo Fisher Trypan Blue Exclusion](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/cell-culture-protocols/trypan-blue-exclusion.html)

**为什么**：染色时间过长可能让细胞状态继续变化，导致边界判断不清。

**注意事项**：

- 记录混合比例。
- 不要放置太久再数。
- 台盼蓝只能判断膜完整性，不能识别所有早期凋亡细胞。

**替代方案**：对精细活率分析，可使用 PI、7-AAD、Annexin V、Calcein-AM 等荧光方法。

**出错后果**：活率偏低或偏高，误判细胞是否适合实验。

### 计数与计算

**怎么做**：在血球计数板或自动细胞计数仪中分别统计蓝色死细胞和未染色活细胞，并计算活率和活细胞浓度。

**为什么**：接种和冻存更应基于 viable cells（活细胞）而不是 total cells（总细胞）。

**注意事项**：

- 要乘稀释倍数。
- 边界细胞计入规则要统一。
- 自动计数仪要查看图像识别是否正确。

**替代方案**：高精度或复杂样本可用流式计数和死活染。

**出错后果**：接种密度错误、冻存密度错误、实验组输入量不一致。

## 台盼蓝 vs 其他活率方法

| 方法 | 优点 | 局限 |
| --- | --- | --- |
| 台盼蓝 | 快速、便宜、直观 | 只看膜完整性，早期凋亡不敏感 |
| PI / 7-AAD | 可用于流式，定量更强 | 需要荧光设备 |
| Annexin V | 可识别早期凋亡 | 流程更复杂 |
| Calcein-AM | 标记活细胞酯酶活性 | 染色条件需优化 |
| ATP/代谢法 | 适合高通量活性检测 | 不直接等于细胞数 |

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理策略 |
| --- | --- | --- |
| 活率异常低 | 染色后放太久、细胞操作损伤、样本本身差 | 缩短染色后等待时间，回查消化和离心 |
| 活率异常高 | 死细胞碎片被忽略、台盼蓝失效、判断标准不一致 | 检查染料、显微镜图像和计数规则 |
| 自动计数不可信 | 团块、碎片、细胞大小异常 | 手动复核，过滤或优化参数 |
| 计算浓度少一半 | 忘记乘 1:1 稀释倍数 | 在记录模板中固定写稀释倍数 |
| 蓝色背景太深 | 染料过量、样本太脏、放置过久 | 重新配比并立即计数 |
| 不同人差异大 | 边界规则和细胞/碎片判断不同 | 建立 SOP 和示例图 |

## 安全与保存

- 台盼蓝为染料，操作时避免皮肤和眼睛接触。
- 按 SDS（safety data sheet，安全数据表）处理废液和污染耗材。
- 避光保存，使用前检查沉淀、污染和有效期。
- 自动计数仪配套染料按厂家说明保存和使用。

## 小结

台盼蓝是快速、低成本的细胞活率判断方法，但它只反映膜完整性。它非常适合日常计数、传代、接种和冻存前质控；但在凋亡、药物机制、复杂样本或高精度分析中，应结合流式或其他活率方法。
