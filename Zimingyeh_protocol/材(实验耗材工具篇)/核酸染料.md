# 核酸染料

Nucleic acid stain（核酸染料）是用于让 DNA 或 RNA 在凝胶、细胞或溶液检测中可视化的染料。本文主要讨论 [琼脂糖凝胶电泳](<../用(实验流程内容篇)/琼脂糖凝胶电泳.md>) 中的 gel stain（凝胶染料），也就是让跑胶条带能在 [凝胶成像系统](凝胶成像系统.md)、蓝光台或 UV 透射仪下显示出来的试剂。

## 一句话理解

核酸染料不是让 DNA/RNA “变多”，而是把原本看不见的核酸条带变成荧光信号。选择染料时要同时看灵敏度、安全性、成像设备、是否需要胶回收、是否影响迁移和废弃物处理。

Thermo Fisher 的 DNA stains selection guide 将凝胶核酸染料定义为结合 DNA 后可在 UV 或蓝光照射下发出荧光的试剂，并用来帮助 DNA 可视化、估算大小和粗略定量。参考：[Thermo Fisher DNA Stains for Gel Electrophoresis](https://www.thermofisher.cn/cn/en/home/life-science/dna-rna-purification-analysis/nucleic-acid-gel-electrophoresis/dna-stains.html)。

## 常见类型

| 类型 | 代表 | 成像方式 | 主要特点 |
| --- | --- | --- | --- |
| 经典嵌入型染料 | EB/EtBr | UV | 便宜、经典、灵敏度够用，但安全和废弃物压力大 |
| 蓝光兼容安全染料 | SYBR Safe、[GelGreen](GelGreen.md) | 蓝光或 UV | 对操作者和后续克隆更友好，依赖匹配滤光片 |
| 红色安全替代染料 | GelRed | UV，通常配 EtBr 滤光片 | 信号强，适合替代 EB，但不同用法会影响迁移 |
| 高灵敏绿色染料 | SYBR Green、SYBR Gold | UV/蓝光/激光，依产品而定 | 灵敏度高，但成本、稳定性和用途不同 |
| 预混上样染料 | GelRed prestain loading dye 等 | 按染料体系 | 上样和染色合并，方便但更需要验证迁移影响 |

这里的“安全染料”不能理解成“可以不用防护”。它通常表示在特定测试和推荐用法下比 EB 更低危，但仍应戴手套、避光、按说明书和实验室制度处理。

## 预染、后染和样本预染

| 用法 | 怎么做 | 优点 | 局限 |
| --- | --- | --- | --- |
| Precast / in-gel staining（预染胶） | 配胶时把染料加入熔化琼脂糖 | 跑完即可成像，流程快 | 某些染料会影响迁移，染料可能跑向与 DNA 相反方向 |
| Post-electrophoresis staining（后染） | 跑完胶后把凝胶浸泡在染液中 | 条带位置更少受染料影响，背景可控 | 多一步操作，耗时，可能扩散 |
| Prestain loading dye（样本预染） | 染料和 loading dye 直接随样本上样 | 最方便，适合快速检查 | 对样本量、片段大小和迁移影响更敏感 |

[SYBR Safe](<SYBR Safe.md>) 可以预染胶或后染，并可用蓝光或 UV 成像；Thermo Fisher 也提醒如果下游要克隆，应避免 UV 暴露。参考：[Thermo Fisher SYBR Safe DNA Gel Stain](https://www.thermofisher.com/us/en/home/life-science/dna-rna-purification-analysis/nucleic-acid-gel-electrophoresis/dna-stains/sybr-safe.html)。

[GelRed](GelRed.md) 和 GelGreen 可用于预染或后染。Biotium 资料强调它们可作为 EB 替代物，GelRed 通常用 UV 和 EtBr 滤光片，GelGreen 可用于蓝光系统；同时不同染色方式会影响条带迁移和适用场景。参考：[Biotium GelRed and GelGreen DNA Gel Stains](https://biotium.com/technology/nucleic-acid-gel-stains/gelred-gelgreen-dna-gel-stains/)。

## 选择逻辑

| 实验目的 | 推荐思路 |
| --- | --- |
| 只看 PCR 有没有条带 | SYBR Safe、GelRed、EB 都可，优先按实验室已有成像系统选 |
| 要切胶回收并克隆 | 优先蓝光兼容染料和 [蓝光成像](<../番外/补充知识/蓝光成像.md>)，减少 UV 损伤 |
| 要最高灵敏度 | 看产品检测限、滤光片和曝光设置，不只看染料名字 |
| 要降低安全管理负担 | 优先考虑 SYBR Safe、GelRed/GelGreen 等 EB 替代方案 |
| 已有老式 UV GelDoc 和 EtBr 滤光片 | EB 或 GelRed 更容易兼容 |
| 要比较不同批次或定量条带 | 固定染料、染色方式、曝光参数和成像设备 |

Thermo Fisher 的 SYBR Safe 页面给出一个很实际的判断：蓝光相较 UV 对 DNA 损伤更小，SYBR Safe 配合蓝光成像在克隆效率上更有利。参考：[Thermo Fisher SYBR Safe FAQ](https://www.thermofisher.com/us/en/home/life-science/dna-rna-purification-analysis/nucleic-acid-gel-electrophoresis/dna-stains/sybr-safe.html)。

## 与 Loading Dye 和 DNA Ladder 的区别

| 名称 | 主要角色 | 是否让核酸发光 |
| --- | --- | --- |
| 核酸染料 | 结合 DNA/RNA，提供荧光信号 | 是 |
| Loading Dye | 增加样本密度并追踪迁移前沿 | 通常不是，除非是含染料的 prestain 产品 |
| DNA Ladder | 已知大小的 DNA 片段标准 | 本身是 DNA，需要被染料显示 |

新手常把“蓝色的 loading dye”和“核酸染料”混在一起。多数传统 loading dye 的颜色只是给肉眼看上样和前沿，不等于 DNA 条带已经被染出来。

## 使用注意事项

- 避光保存和操作，尤其是高浓度染料原液。
- 预染胶、后染和样本预染不要随意混用；换方式后需要重新看迁移和灵敏度。
- 同一个项目不要今天用 EB、明天用 SYBR Safe、后天用 GelRed 再直接比较条带强度。
- 成像时避免曝光饱和；饱和图像不适合半定量。
- 蓝光/UV、滤光片和相机设置必须和染料匹配。
- 所有染料都按实验室安全制度处理；EB 尤其要按潜在致突变危险品管理。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 条带很弱 | 染料浓度不足、滤光片不匹配、DNA 量低、曝光太短 | 检查染料、滤光片、ladder 和曝光 |
| 背景很高 | 染料过量、后染时间过长、胶/缓冲液污染 | 降低染料或缩短染色，换新缓冲液 |
| 条带迁移异常 | 染料预混影响迁移、样本盐高、上样量过大 | 改为后染或降低上样量 |
| 胶回收效率差 | UV 暴露过久、染料或成像方式影响 DNA | 用蓝光、缩短暴露，按试剂盒验证 |
| 不同实验图像不可比 | 换了染料、滤光片或曝光参数 | 固定体系并记录 |

## 购买与记录建议

常见供应商包括 [Invitrogen](<../番外/试剂厂商/Invitrogen.md>) / Thermo Fisher、[Biotium](<../番外/试剂厂商/Biotium.md>)、[Sigma-Aldrich](<../番外/试剂厂商/Sigma-Aldrich.md>)、[NEB](<../番外/试剂厂商/NEB.md>) 等。购买时不要只看“安全染料”几个字，要核对激发/发射、推荐滤光片、预染/后染用法、检测限、是否适合胶回收和废弃物处理要求。

推荐记录字段：

```text
中文：染料名称 / 品牌 / 货号 / 批号 / 浓度或稀释倍数 / 预染或后染 / 成像光源 / 滤光片 / 曝光参数 / 是否胶回收
English: stain name / brand / catalog number / lot number / concentration or dilution / precast or post-stain / excitation source / emission filter / exposure settings / gel extraction yes or no
```

## 小结

核酸染料决定的是“条带如何被看见”。真正选择时要把染料、loading dye、DNA ladder、成像设备和下游用途作为一个系统，而不是孤立地问“哪个染料最好”。
