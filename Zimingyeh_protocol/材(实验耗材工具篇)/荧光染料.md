# 荧光染料

## 一句话定义

Fluorescent dye（荧光染料，也常叫 fluorophore，荧光团）是一类能吸收特定波长光并发射更长波长光的分子，用于把细胞结构、抗体、核酸、蛋白或探针转化为可被显微镜、流式细胞仪或成像系统检测的光信号。

在 [免疫荧光](<../用(实验流程内容篇)/免疫荧光.md>) 中，荧光染料常连接到 [荧光二抗](荧光二抗.md)、直接标记一抗，或作为 [DAPI](DAPI.md)、[Hoechst](Hoechst.md) 等核染料使用。Thermo Fisher 和 Abcam 的荧光/免疫荧光资料都强调选择染料时需要同时考虑激发/发射波长、亮度、光稳定性、样本自发荧光和仪器通道。[参考：Thermo Fisher Fluorescence SpectraViewer](https://www.thermofisher.com/order/fluorescence-spectraviewer)；[参考：Abcam Immunofluorescence Protocol](https://www.abcam.com/en-us/technical-resources/protocols/immunocytochemistry-immunofluorescence-protocol)

## 核心参数

| 参数 | 英文 | 为什么重要 |
| --- | --- | --- |
| 激发波长 | Excitation wavelength | 决定用哪条激光/LED 激发 |
| 发射波长 | Emission wavelength | 决定在哪个检测通道收集信号 |
| 亮度 | Brightness | 弱目标需要更亮染料 |
| 光稳定性 | Photostability | 影响长时间成像和多次扫描 |
| 光谱重叠 | Spectral overlap | 多通道实验中决定串色风险 |
| 自发荧光 | Autofluorescence | 组织、培养基、固定剂或材料可能贡献背景 |

荧光实验的关键不是“颜色好看”，而是染料、样本、显微镜滤光片/激光和实验问题是否匹配。

## 常见染料类别

| 类别 | 例子 | 常见用途 |
| --- | --- | --- |
| 核酸染料 | DAPI、Hoechst、PI | 细胞核、DNA、死细胞检测 |
| 抗体荧光染料 | [FITC](FITC.md)、TRITC、[Alexa Fluor染料](<Alexa Fluor染料.md>)、[Cy染料](Cy染料.md) | IF、流式、荧光 WB |
| 蛋白/细胞染料 | CFSE、CellTrace、phalloidin conjugates | 细胞追踪、骨架染色 |
| 流式染料 | [PE](PE.md)、[APC](APC.md)、PerCP、BV 系列 | [流式细胞术](<../用(实验流程内容篇)/流式细胞术.md>) |
| 功能探针 | ROS、Ca2+、膜电位探针 | 功能状态检测 |

不同平台对染料要求差别很大。显微镜强调定位和光稳定性，流式强调亮度、补偿和通道设计，荧光 WB 强调低背景和线性范围。

## 选择逻辑

| 问题 | 选择建议 |
| --- | --- |
| 目标表达很低 | 选亮度更高、背景更低的染料 |
| 多重染色 | 选择光谱分离足够远的染料组合 |
| 组织自发荧光强 | 尽量避开高自发荧光波段，考虑远红通道 |
| 需要长时间拍摄 | 选高 photostability 染料和 [抗淬灭封片剂](抗淬灭封片剂.md) |
| 做定量比较 | 避免饱和，固定曝光/激光/增益参数 |

多重实验不要只按“蓝绿红远红”粗略搭配。真正要看每个染料的激发峰、发射峰、滤光片带宽和相邻通道串色。

## 荧光染料 vs 酶底物

| 读出体系 | 代表 | 优点 | 局限 |
| --- | --- | --- | --- |
| 荧光染料 | DAPI、Alexa Fluor、FITC | 多重、定位好、动态范围可较宽 | 自发荧光、串色、光漂白 |
| HRP底物 | [TMB](TMB.md)、[DAB](DAB.md)、ECL | 灵敏、成熟、部分体系便宜 | 多重受限、过曝/显色时间影响大 |
| AP底物 | [BCIP-NBT](<BCIP-NBT.md>) | 沉淀稳定，适合 AP 显色 | 反应慢，定量有限 |

如果实验目的是定位和共定位，荧光通常更合适；如果是 ELISA 吸光度或 IHC 明场病理形态，酶底物更常见。

## 使用注意事项

- 染料和荧光标记抗体一般需要避光保存和操作。
- 成像时保留未饱和图像，饱和像素不能用于可靠定量。
- 多通道实验要设置 single-stain controls（单染对照）和 no-primary/secondary-only controls（无一抗/二抗对照）。
- 固定剂、封片剂、培养基和塑料耗材都可能带来背景。
- 活细胞染料要额外考虑毒性、通透性和光毒性。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 信号弱 | 染料不够亮、抗体弱、通道设置不合适 | 换更亮染料，优化抗体和曝光 |
| 背景高 | 自发荧光、二抗过浓、封闭不足 | 设置对照，降低二抗，优化封闭 |
| 串色 | 发射光谱重叠 | 换光谱分离更远的染料或做补偿 |
| 信号很快变暗 | 光漂白 | 避光，降低激发强度，使用抗淬灭封片剂 |
| 颜色看起来有但定量不稳定 | 曝光饱和或参数不一致 | 固定成像参数，避免饱和 |

## 小结

荧光染料是定位、共定位、多重检测和流式分析的核心读出工具。选择染料时要同时看光谱、亮度、光稳定性、样本背景和仪器通道，而不是只看颜色名称。每次荧光实验都应记录染料、通道、曝光参数和对照。
