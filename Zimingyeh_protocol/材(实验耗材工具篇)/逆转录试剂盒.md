# 逆转录试剂盒

Reverse transcription kit / cDNA synthesis kit（逆转录试剂盒/cDNA 合成试剂盒）是把 [逆转录酶](逆转录酶.md)、buffer、[dNTP](dNTP.md)、引物、[RNase抑制剂](RNase抑制剂.md) 或其他增强组分组合在一起的商业化体系，用于把 RNA 转换为 [cDNA](<../番外/补充知识/cDNA.md>)。它比单独购买逆转录酶更标准化，适合 [RT-qPCR](<../用(实验流程内容篇)/RT-qPCR.md>) 和多样本比较。

![逆转录核心材料参考图](../z_asset/材/逆转录核心材料/reverse-transcription-core-materials-reference.png)

图源：Image2 生成的逆转录核心材料参考图；试剂盒可理解为把图中多个核心管整合成标准化反应体系。

## 为什么用试剂盒

逆转录反应变量很多：RNA 投入量、引物策略、dNTP、buffer、温度、RNase 污染、抑制物残留都会影响结果。试剂盒的价值是把部分变量预先优化，减少操作者自己拼体系造成的批间差异。

Thermo Fisher 的 High-Capacity cDNA Reverse Transcription Kit、Takara PrimeScript RT reagent Kit 和 Bio-Rad iScript cDNA Synthesis Kit 都是常见 cDNA 合成体系，通常用于后续 real-time PCR / RT-qPCR 分析。[参考：Thermo Fisher High-Capacity cDNA Reverse Transcription Kit](https://www.thermofisher.com/order/catalog/product/4368814)；[参考：Takara PrimeScript RT reagent Kit](https://www.takarabio.com/products/pcr/real-time-pcr/rt-qpcr/prime-script-rt-reagent-kit)；[参考：Bio-Rad iScript cDNA Synthesis Kit](https://www.bio-rad.com/en-us/sku/1708891-iscript-cdna-synthesis-kit)

## 常见类型

| 类型 | 特点 | 适合场景 |
| --- | --- | --- |
| cDNA synthesis kit | 先逆转录生成 cDNA，再做 qPCR | 常规 RT-qPCR，两步法 |
| RT-qPCR first-strand kit | 更偏 qPCR 下游优化 | 基因表达分析 |
| One-step RT-qPCR kit | 逆转录和 qPCR 在同一管完成 | 病原检测、高通量、减少开盖污染 |
| miRNA reverse transcription kit | 针对 miRNA 的 stem-loop 或 poly(A) 策略 | miRNA 定量 |
| Genomic DNA removal kit | 带 gDNA 去除步骤 | RNA 样本 DNA 污染风险高时 |

## 试剂盒 vs 单独逆转录酶

| 方案 | 优点 | 局限 |
| --- | --- | --- |
| 逆转录试剂盒 | 标准化、方便、重复性好 | 灵活性低，成本较高 |
| 单独逆转录酶 | 可自由优化引物、buffer 和组分 | 更依赖经验，变量更多 |
| One-step kit | 管内完成，污染风险低 | cDNA 不易长期保存和复用 |
| Two-step kit | cDNA 可复用，适合多基因检测 | 多一步操作，开盖污染风险略高 |

## 使用 protocol

### 选择试剂盒

**怎么做**：根据 RNA 类型、下游用途和样本量选择试剂盒。普通 mRNA RT-qPCR 可选常规 cDNA synthesis kit；miRNA、低丰度 RNA 或高通量检测要选择专门体系。

**为什么**：不同试剂盒内置的引物策略和反应 buffer 不同，直接影响能覆盖哪些 RNA。

**注意事项**：

- 确认是否包含 Oligo(dT)、随机引物或二者混合。
- 确认是否有 gDNA removal（基因组 DNA 去除）步骤。
- 确认 cDNA 是否可直接用于 SYBR 或 TaqMan qPCR。

### RNA准备

**怎么做**：使用高质量 RNA，记录提取方法、浓度、A260/280、A260/230、完整性和 DNase 处理情况。

**为什么**：试剂盒不能修复严重降解或被酚、盐、乙醇污染的 RNA。

**注意事项**：

- RNA 加样量保持一致。
- 设置 [No-RT对照](<../番外/补充知识/No-RT对照.md>)。
- 多样本比较不要让 RNA 质量差异太大。

### 配制和反应

**怎么做**：在冰上配制 master mix，加入 RNA 模板，轻柔混匀并短暂离心。按说明进行逆转录温度程序和热灭活。

**为什么**：master mix 可减少移液差异；严格按说明是保证试剂盒性能的基础。

**注意事项**：

- 不要随意改反应体积和 RNA 投入量。
- 需要稀释 cDNA 时统一稀释倍数。
- 反应后 cDNA 避免反复冻融。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 所有基因 Cq 偏高 | RNA 降解、投入量低、逆转录失败 | 检查 RNA 质量和阳性对照 |
| No-RT 有信号 | gDNA 污染 | DNase 处理或使用带 gDNA removal 的 kit |
| 样本间差异大 | RNA 质量/投入量不一致 | 统一 RNA 定量和投入量 |
| 只某些基因失败 | 引物设计或转录本区域问题 | 检查 qPCR 引物和 cDNA 覆盖策略 |
| 重复性差 | 配液误差、混匀不足、冻融 | 使用 master mix，分装保存 |

## 小结

逆转录试剂盒的价值是把复杂反应标准化。做 RT-qPCR 时，比起单独追求“最强逆转录酶”，更重要的是固定 RNA 质量、投入量、引物策略、No-RT 对照和 cDNA 稀释方式。
