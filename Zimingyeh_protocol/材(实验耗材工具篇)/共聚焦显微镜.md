# 共聚焦显微镜

## 一句话定义

Confocal microscope（共聚焦显微镜）是一类通过 pinhole（针孔）或等效光学切片机制抑制焦平面外荧光的 [荧光显微镜](荧光显微镜.md)，常用于厚样本成像、三维重构、共定位分析和低背景高分辨观察。

经典 laser scanning confocal microscope（激光扫描共聚焦显微镜）用激光逐点或逐线扫描样本，并通过针孔只让焦平面附近的信号进入检测器。Leica、Zeiss、Nikon/Olympus 等显微厂商都将 optical sectioning（光学切片）作为共聚焦相对宽场显微镜的核心优势。[参考：Leica Confocal Microscopy](https://www.leica-microsystems.com/science-lab/life-science/confocal-microscopy/)；[参考：Nikon MicroscopyU Confocal Microscopy](https://www.microscopyu.com/techniques/confocal)

## 核心原理

```text
激光聚焦到样本一点
→ 焦点附近荧光被激发
→ 发射光经过针孔
→ 焦外光被阻挡
→ 扫描形成二维图像
→ 多层 Z-stack 可重构三维结构
```

共聚焦的本质优势不是“放大倍数更高”，而是降低焦外背景并提供更好的 Z 方向信息。

## 适合用途

| 场景 | 原因 |
| --- | --- |
| 厚细胞或组织切片 | 抑制焦外荧光 |
| 共定位分析 | 更准确区分不同 Z 层信号 |
| 细胞器定位 | 背景低，定位更清楚 |
| 三维重构 | 可采集 Z-stack |
| 弱信号但背景复杂 | 光学切片提高信噪比 |

## 共聚焦 vs 宽场

| 维度 | 共聚焦显微镜 | [宽场荧光显微镜](宽场荧光显微镜.md) |
| --- | --- | --- |
| 光学切片 | 强 | 弱 |
| 厚样本背景 | 低 | 高 |
| 成像速度 | 通常较慢 | 快 |
| 光毒性 | 可能更高 | 通常较低但取决于条件 |
| 数据量 | 大，尤其 Z-stack | 较小 |
| 操作复杂度 | 高 | 较低 |

如果只是薄层固定细胞、目标强、只需要二维定位，宽场通常足够；如果需要 Z 信息、厚样本和高背景抑制，共聚焦更合适。

## 关键参数

| 参数 | 影响 |
| --- | --- |
| Pinhole size | 光学切片厚度和信号量 |
| Laser power | 信号、光漂白和光毒性 |
| Detector gain | 信号放大和噪声 |
| Scan speed | 成像速度和信噪比 |
| Averaging | 降低噪声但增加光照 |
| Z-step | 三维采样质量 |
| Objective NA | 分辨率和收光能力 |

常见经验是 pinhole 设为约 1 Airy unit（1 个艾里单位）作为起点，但具体取决于染料、物镜、样本厚度和成像目标。

## 使用 protocol

1. 确认染料和激光线匹配。
2. 用低激光功率寻找样本。
3. 设置 pinhole、gain、offset 和扫描速度。
4. 避免饱和像素。
5. 多通道成像时考虑 sequential scanning（顺序扫描）降低串色。
6. 采集 Z-stack 时设置合理 Z-step。
7. 保存原始文件和元数据。

共定位实验建议使用单染对照、阴性对照和避免过曝的原始数据。没有光谱和空间校正的漂亮合并图，不能直接证明共定位。

## 注意事项

- 激光功率过高会造成 [光漂白](../番外/补充知识/光漂白.md) 和 [光毒性](../番外/补充知识/光毒性.md)。
- Detector gain 太高会增加噪声，不能替代真实信号。
- 多通道共聚焦容易出现 bleed-through（串色），弱目标尤其需要单染对照。
- Z-stack 数据很大，保存原始格式和参数很重要。
- 做定量时不能随意改变 laser、gain、pinhole 和后处理。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 信号弱 | 激光低、pinhole 太小、抗体弱 | 增加激光或 gain，优化染色 |
| 背景高 | pinhole 太大、染色背景、串色 | 调整 pinhole，优化封闭和顺序扫描 |
| 图像噪声大 | gain 高、扫描太快 | 降低 gain，增加 averaging |
| 样本很快漂白 | 激光功率高或重复扫描多 | 降低激光，减少扫描次数 |
| 共定位假阳性 | 串色或过曝 | 单染对照，顺序扫描，避免饱和 |

## 小结

共聚焦显微镜的价值在于光学切片和低焦外背景，特别适合厚样本、三维成像和共定位分析。它不是简单“更高清”的宽场显微镜，真正关键是 pinhole、激光、检测器、Z-step 和对照设计。
