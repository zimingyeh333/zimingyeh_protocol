# N2补充剂

N2补充剂（N-2 Supplement，N-2 神经细胞培养补充剂）是用于 serum-free neural culture（无血清神经相关培养）的经典补充剂，常见于 neural progenitor cells（神经前体细胞）、neural stem cells（神经干细胞）、neurosphere（神经球）和部分神经分化体系。

![专用细胞培养基参考图](../z_asset/材/专用细胞培养基/specialized-cell-culture-media-reference.png)

图源：Image2 生成的专用细胞培养基参考图；B27/N2 位于 serum-free step 的神经和干细胞补充剂层。

## 核心定位

Thermo Fisher 的 N-2 Supplement 产品页面说明，N-2 Supplement 是 versatile serum-free cell culture supplement，可支持多种细胞类型的生长和活率；Thermo Fisher 的神经细胞培养补充剂页面进一步说明，N-2 最初由 Jane Bottenstein 用于神经母细胞瘤细胞系无血清培养，也可作为胚胎神经元和神经干细胞培养的 serum substitute。参考：[Gibco N-2 Supplement](https://www.thermofisher.com/order/catalog/product/17502048)；[Thermo Fisher Primary Neural and Neuronal Culture Supplements](https://www.thermofisher.com/ca/en/home/life-science/cell-culture/primary-cell-culture/neuronal-cell-culture/neuronal-cell-culture-supplement.html)。

N2 常和 [B27补充剂](B27补充剂.md)、[DMEM-F12](DMEM-F12.md)、[Neurobasal培养基](Neurobasal培养基.md)、[EGF](EGF.md)、[FGF2](FGF2.md) 等组合使用。

## 典型成分逻辑

不同厂家配方可能不同，但 N2 常围绕这些支持层：

| 组分类型 | 作用 |
| --- | --- |
| Insulin | 代谢和生长支持 |
| Transferrin | 铁转运 |
| Selenium | 抗氧化和微量元素支持 |
| Progesterone | 神经相关培养中的激素支持 |
| Putrescine | 多胺，支持增殖和细胞状态 |

具体成分和浓度以所用产品说明书为准，不建议把不同品牌 N2 当成完全等同。

## N2 vs B27/ITS

| 项目 | N2 | B27 | ITS |
| --- | --- | --- | --- |
| 复杂度 | 中等 | 高 | 低 |
| 核心应用 | 神经前体/神经干细胞/神经球 | 神经元维持、成熟和复杂模型 | 基础低血清/无血清支持 |
| 是否含多种神经支持成分 | 是 | 更多 | 通常较少 |
| 常见组合 | N2 + B27 + EGF/FGF2 | B27 + Neurobasal 或 DMEM/F12 | ITS + 基础培养基 + 生长因子 |

## 使用 protocol

### 加入培养基

**怎么做**：N2 常见为 100X 储液，按 1:100 加入基础培养基得到 1X 终浓度。具体比例以产品说明和 protocol 为准。

**为什么**：N2 是预混补充剂，按推荐倍数使用可以减少配方偏差。

**注意事项**：

- 神经干细胞增殖体系通常还需要 EGF、FGF2 或其他生长因子。
- N2 与 B27 不是互相替代品，很多 protocol 会组合使用。
- 对胰岛素、孕酮、多胺或铁代谢敏感的实验，需要把 N2 作为变量记录。

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 神经球长不起来 | 缺 EGF/FGF2、密度太低或基质/培养基不匹配 | 补齐生长因子并优化接种密度 |
| 分化状态异常 | N2/B27比例或版本不对 | 核对 protocol 与产品货号 |
| 信号实验背景变化 | insulin/progesterone/putrescine 等影响 | 设置补充剂对照 |
| 批间差异 | N2品牌或批号变化 | 固定货号并记录 |

## 小结

N2 是神经相关无血清培养里的基础补充剂，常和 B27、EGF、FGF2 共同构成神经干细胞或神经前体培养体系。它比 ITS 更“神经化”，但比 B27 更简洁。
