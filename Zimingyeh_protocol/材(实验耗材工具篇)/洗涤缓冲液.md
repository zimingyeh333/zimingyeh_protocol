# 洗涤缓冲液

Wash buffer（洗涤缓冲液）是在 [ELISA](<../用(实验流程内容篇)/ELISA.md>) 等免疫检测中用于去除未结合抗体、游离酶标物和弱非特异性吸附物的缓冲液；它看起来只是“洗一洗”，但往往直接决定[背景信号](../番外/补充知识/背景信号.md)、重复性和灵敏度。

## 名称与常见版本

洗涤缓冲液常见英文名称包括 wash buffer、washing buffer、ELISA wash buffer。最常见形式是 [PBS](PBS.md) 或 [TBS](TBS.md) 加非离子表面活性剂，例如 [Tween-20](Tween-20.md)。其中 PBST 通常指 phosphate-buffered saline with Tween-20（含 Tween-20 的磷酸盐缓冲盐水），TBST 通常指 tris-buffered saline with Tween-20（含 Tween-20 的 Tris 缓冲盐水）。

在 ELISA kit（酶联免疫吸附测定试剂盒）里，洗涤缓冲液常以 10×、20× 或更高倍数浓缩液提供，使用前稀释成 1×。不同厂家会把 wash buffer 与 [ELISA试剂盒](ELISA试剂盒.md)、[酶标板](酶标板.md)、抗体体系和底物体系一起优化，因此不建议在关键实验中随意替换。

## 核心作用

洗涤缓冲液的核心作用不是把孔洗得“越干净越好”，而是在保留特异性结合的同时去除弱结合和游离组分。

| 作用 | 对结果的影响 | 如果做得不好 |
| --- | --- | --- |
| 去除未结合抗体和酶标物 | 降低空白孔和阴性孔 OD | 高背景、阴性孔偏高 |
| 去除弱非特异性吸附 | 提高信噪比 | 低浓度样本被背景淹没 |
| 维持稳定 pH 和离子强度 | 减少抗原-抗体结合扰动 | 板间差异变大 |
| 用 Tween-20 降低疏水吸附 | 减少边缘和局部斑点 | 孔间 CV 升高、局部颜色异常 |

BioLegend 的 sandwich ELISA protocol（夹心 ELISA 操作方案）在多次孵育后都安排洗板步骤，并强调去除残余液体；R&D Systems 的 ELISA protocols 也把 washing steps（洗涤步骤）作为标准流程中的关键步骤。参考：[BioLegend sandwich ELISA protocol](https://www.biolegend.com/en-us/protocols/sandwich-elisa-protocol)；[R&D Systems ELISA protocols](https://www.rndsystems.com/resources/protocols)。

## 常见组成

| 成分 | 常见作用 | 注意事项 |
| --- | --- | --- |
| PBS 或 TBS | 提供 pH 和盐浓度背景 | PBS 适合多数 HRP-TMB ELISA；TBS 有时用于特定抗体体系 |
| Tween-20 | 降低非特异性吸附，帮助去除弱结合物 | 过高可能削弱弱亲和力结合或影响某些包被体系 |
| 防腐剂 | 延长储存时间 | 含 [叠氮钠](叠氮钠.md) 的体系可能抑制 horseradish peroxidase（HRP，辣根过氧化物酶），HRP 检测体系要谨慎 |
| 去离子水或超纯水 | 稀释浓缩液 | 水质差会带来沉淀、污染或背景波动 |

很多 1× ELISA 洗涤液使用约 0.05% Tween-20，但具体浓度要以 kit 说明书或已验证 protocol 为准。Thermo Fisher 的 ELISA overview 也将 wash steps 与 blocking、antibody incubation、substrate development 一起列为 ELISA 基本流程的一部分。参考：[Thermo Fisher Overview of ELISA](https://www.thermofisher.com/us/en/home/life-science/protein-biology/protein-biology-learning-center/protein-biology-resource-library/pierce-protein-methods/overview-elisa.html)。

## 和 PBS、PBST、封闭液的区别

| 项目 | 本质 | 主要用途 | 是否能互换 |
| --- | --- | --- | --- |
| PBS | phosphate-buffered saline（磷酸盐缓冲盐水） | 维持等渗和 pH | 可以作为基础缓冲液，但洗板通常不如含 Tween 的 PBST 稳定 |
| PBST | PBS + Tween-20 | ELISA、Western blot 等洗涤 | 常见洗涤液版本，但浓度需匹配体系 |
| 洗涤缓冲液 | 经过实验体系优化的 wash buffer | 去除游离和弱结合组分 | 不等于任意 PBST，尤其是 kit 实验 |
| [封闭液](封闭液.md) | 含蛋白或聚合物的 blocking buffer | 封闭未占据吸附位点 | 不能直接当洗涤液用，可能增加残留蛋白 |
| [样本稀释液](样本稀释液.md) | 控制样本基质和非特异性结合的 diluent | 稀释标准品或样本 | 不适合承担洗板功能 |

简单说，PBS 是基础盐水，PBST 是常见洗液雏形，而 kit 自带 wash buffer 是已经围绕板、抗体、底物和样本类型优化过的工作液。

## 使用策略

手洗和机洗都可以，但变量不同。

手洗适合少量板或条件有限的实验。关键是每孔加液体积要足够，倒扣甩液后要在吸水纸上轻拍，避免孔底残液过多。手洗最大的风险是孔间力度和残液不一致。

[洗板机](洗板机.md) 适合批量和长期 SOP。关键参数包括 dispense volume（加液体积）、aspiration height（吸液高度）、soak time（浸泡时间）、wash cycles（洗涤次数）和 residual volume（残留体积）。洗板机设置不当时，可能出现孔底被刮伤、吸液不完全或交叉污染。

常见 ELISA 洗板逻辑是每步孵育后洗 3-5 次，高背景体系可以增加洗涤次数或加入短暂浸泡，但不应无限增加。过度洗涤可能降低弱信号，尤其是低亲和力抗体、低丰度抗原或包被不稳定体系。

## 现配或稀释 protocol

以下只是通用记录逻辑，具体以产品说明书为准。

| 步骤 | 操作 | 为什么 |
| --- | --- | --- |
| 平衡温度 | 将浓缩洗液和水放至室温 | 冷藏浓缩液可能有盐或表面活性剂析出 |
| 检查沉淀 | 观察是否有结晶，必要时温和回温溶解 | 未完全溶解会导致实际浓度偏低 |
| 按比例稀释 | 例如 10× 洗液按 1:10 稀释成 1× | 浓度错误会改变背景和结合稳定性 |
| 混匀 | 轻柔颠倒或磁力搅拌，不剧烈起泡 | 泡沫会影响加液准确性 |
| 标记 | 写明名称、浓度、日期、操作者 | 便于追踪异常批次 |
| 使用前确认 | 检查澄清度、污染和温度 | 浑浊或污染会增加背景 |

如果自配 PBST，可用 1× PBS 或 1× TBS 加入合适浓度 Tween-20。对正式数据，建议记录 Tween-20 浓度、缓冲液类型、pH、批号和配制日期。

## 常见错误与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 空白孔和阴性孔都偏高 | 洗涤次数不足、残液过多、Tween-20 不足 | 增加洗涤次数，确认每孔吸液彻底，检查 1× 浓度 |
| 孔间 CV 大 | 手洗力度不一致、洗板机吸液高度不合适、边缘孔干燥 | 标准化节奏，校准洗板机，避免板面暴露太久 |
| 低浓度样本信号消失 | 过度洗涤或 Tween-20 太高 | 减少洗涤强度，回到说明书条件 |
| 局部孔颜色很深 | 残留 HRP 标记抗体或污染 | 更换洗液槽，确认洗板针无堵塞 |
| 板上出现泡沫 | 洗液起泡或加液过快 | 降低加液速度，使用前轻柔混匀 |

## 购买建议

如果使用商业 ELISA kit，优先使用 kit 自带或同厂家推荐的 wash buffer，特别是做临床样本、低丰度因子或长期纵向项目时。

如果是自建 ELISA，可以购买通用 ELISA wash buffer 或自配 PBST/TBST。自配更便宜、灵活，但需要记录配方并验证背景、标准曲线和批间一致性。长期项目不建议频繁换 Tween-20 厂家或批号，因为表面活性剂质量差异可能影响背景。

## 小结

洗涤缓冲液是 ELISA 里最容易被当成“普通耗材”的关键变量。背景高、孔间差异大、弱阳性看不见，很多时候不是抗体或样本本身的问题，而是洗涤强度、残液控制和洗液配方没有被稳定记录。
