# 酚红

酚红（phenol red，phenolsulfonphthalein，酚磺酞）是细胞培养基中常见的 pH indicator（酸碱指示剂），可通过培养基颜色粗略提示 pH、CO2 平衡、细胞代谢和污染风险。

![基础细胞培养基组件参考图](../z_asset/材/基础细胞培养基组件/cell-culture-medium-components-reference.png)

图源：Image2 生成的基础细胞培养基组件示意图；底部色带显示酚红在酸性、常规培养 pH 和碱性条件下的颜色变化。

## 核心作用

酚红让培养基成为一个肉眼可见的 pH 粗筛工具。ATCC Animal Cell Culture Guide 说明，phenol red 用于监测培养基 pH；细胞生长产生代谢物会改变 pH，低 pH 时培养基变黄，高 pH 时变紫，多数组织培养工作常见 pH 7.4 附近应呈明亮红色。参考：[ATCC Animal Cell Culture Guide](https://www.atcc.org/resources/culture-guides/animal-cell-culture-guide)。

Sigma-Aldrich phenol red solution 页面也说明，phenol red 可作为培养基 pH 指示剂，在 pH 6.4 或更低时转黄，在 pH 8.2 或更高时转红。参考：[Sigma-Aldrich Phenol Red Solution](https://www.sigmaaldrich.com/US/en/product/sial/p0290)。

## 颜色怎么读

| 颜色 | 常见解释 | 需要做什么 |
| --- | --- | --- |
| 黄 | pH 偏低，酸化 | 检查细胞是否过密、污染、换液不足 |
| 橙红/红 | 多数培养条件较正常 | 结合显微镜判断 |
| 粉红/紫 | pH 偏高，碱化 | 检查 CO2、瓶盖、暴露空气时间 |
| 浑浊伴颜色变化 | 可能污染 | 立即显微镜检查，必要时隔离/丢弃 |

颜色只能作为报警信号，不能替代 pH 计、细胞状态观察或污染检测。

## 什么时候不用酚红

| 场景 | 为什么考虑无酚红培养基 |
| --- | --- |
| 荧光成像 | 酚红可能增加背景或影响信噪比 |
| 流式细胞术样本制备 | 颜色和背景可能干扰检测体系 |
| 激素/雌激素敏感实验 | ATCC 指出酚红可模拟某些 steroid hormones，尤其 estrogen 相关作用 |
| 分泌物、代谢物检测 | 染料可能成为额外背景变量 |
| 无血清敏感体系 | ATCC 提到某些 serum-free formulation 中酚红可能影响离子稳态 |

不是所有实验都必须无酚红。日常维护细胞时，有酚红培养基很有用；真正进入敏感检测时再切换无酚红版本，并设置适应和对照。

## 酚红 vs HEPES/碳酸氢盐

| 项目 | 角色 | 是否缓冲 pH |
| --- | --- | --- |
| 酚红 | 指示 pH | 不是主要缓冲剂 |
| [碳酸氢钠](碳酸氢钠.md) + CO2 | 主要缓冲系统 | 是 |
| [HEPES](HEPES.md) | 有机缓冲剂 | 是 |

酚红只是“颜色表盘”，不是“刹车”。培养基变黄后，颜色提醒你 pH 已经偏了，但它本身不能把 pH 拉回来。

## 使用注意

- 培养基刚从冰箱拿出或刚打开时，颜色可能因温度和 CO2 平衡暂时偏离。
- 不要只因为培养基偏紫就直接丢弃；先确认是否是离开 CO2 环境太久。
- 不要因为培养基仍然红就忽略显微镜下的污染或支原体风险。
- 做成像/激素实验时，应固定是否含酚红，不能同一项目混用。
- 长期培养记录中建议拍照或文字记录颜色变化，和汇合度、换液时间一起看。

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 培养基很快变黄 | 细胞过密、污染、代谢旺盛、换液不足 | 显微镜检查，必要时换液/传代/检测污染 |
| 培养基偏紫 | CO2 不足、开盖太久、瓶盖太紧/太松不合适 | 检查培养箱和瓶盖通气策略 |
| 荧光背景高 | 酚红或血清干扰 | 切换无酚红、低背景培养基 |
| 实验结果受激素影响 | 酚红拟雌激素样作用 | 使用无酚红培养基和去激素血清 |

## 购买与记录建议

多数培养基已预先含或不含酚红，不需要单独购买。真正要记录的是培养基版本。如果单独使用 phenol red solution，应记录浓度、无菌状态和终浓度。

## 小结

酚红是细胞培养里的“颜色报警器”。它能帮助快速发现 pH、CO2、代谢和污染异常，但不能替代显微镜、pH 控制和污染检测；在荧光、激素敏感和成分控制实验中，是否含酚红本身就是实验变量。
