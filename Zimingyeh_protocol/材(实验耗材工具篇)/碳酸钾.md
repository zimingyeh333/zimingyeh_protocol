# 碳酸钾

碳酸钾（potassium carbonate，K2CO3）是一种较强碱性的无机碳酸盐，可作为缓冲或 pH 调节相关成分出现在某些 red blood cell lysis buffer（[红细胞裂解液](红细胞裂解液.md)）商品配方中。它和 [碳酸氢钾](碳酸氢钾.md) 都属于钾盐/碳酸盐体系，但碱性和配方作用不同，不能不经验证直接互换。

![ACK红细胞裂解液组分示意图](../z_asset/材/红细胞裂解液/ack-rbc-lysis-buffer-components.png)

图源：Image2 生成的 ACK 红细胞裂解液组分示意图。K2CO3 更适合理解为某些商品 RBC lysis buffer 中的缓冲/碱性成分，而不是氯化铵的替代物。

## 定义与命名

| 名称 | 说明 |
| --- | --- |
| Potassium carbonate | 碳酸钾 |
| K2CO3 | 化学式 |
| CAS 584-08-7 | 常用登记号 |
| Carbonate buffer component | 碳酸盐缓冲/碱性成分 |

PubChem 将 potassium carbonate 记录为钾盐，分子式为 K2CO3。参考：[PubChem Potassium Carbonate](https://pubchem.ncbi.nlm.nih.gov/compound/Potassium-carbonate)。

## 在红细胞裂解液中的作用

BioLegend 的 10X RBC Lysis Buffer 产品资料写明其含 ammonium chloride、potassium carbonate 和 [EDTA](EDTA.md)，用于红细胞裂解，使用前需稀释为 1X。参考：[BioLegend RBC Lysis Buffer 10X](https://www.biolegend.com/en-us/products/rbc-lysis-buffer-10x-1498)。

在这类体系里，K2CO3 不是主要裂解红细胞的成分；主要裂解效应仍来自 [氯化铵](氯化铵.md) 等组分。K2CO3 更偏向维持合适的缓冲/碱性环境，使裂解过程可控。

## 常见用途

| 用途 | 说明 |
| --- | --- |
| 某些 RBC lysis buffer 商品配方 | 作为缓冲/碱性组分 |
| pH 调节相关配方 | 提供较强碱性环境 |
| 碳酸盐缓冲体系 | 根据特定 SOP 调整缓冲能力 |
| 化学合成或一般实验室配液 | 作为基础无机盐试剂 |

对于细胞实验，K2CO3 的浓度和 pH 影响很大，不应把它当作普通“无害盐”随手加入。

## 与碳酸氢钾的区别

| 项目 | 碳酸钾 K2CO3 | [碳酸氢钾](碳酸氢钾.md) KHCO3 |
| --- | --- | --- |
| 阴离子 | CO3 2- | HCO3- |
| 碱性 | 更强 | 较弱 |
| ACK/RBC 语境 | 某些商品 RBC lysis buffer 可见 | 经典 ACK 自配配方常见 |
| 使用风险 | pH 变化更明显 | 缓冲较温和 |
| 是否可直接互换 | 不建议 | 不建议 |

如果文献、说明书或 SOP 写的是 KHCO3，不要直接换成 K2CO3；反过来也一样。除非重新计算配方、检测 pH/渗透压并验证细胞结果。

## 与 ACK 其他成分的关系

| 成分 | 角色 |
| --- | --- |
| [氯化铵](氯化铵.md) | 红细胞裂解主效应成分 |
| 碳酸钾 | 某些商品配方中的缓冲/碱性成分 |
| [碳酸氢钾](碳酸氢钾.md) | 经典 ACK 自配配方常见缓冲成分 |
| [EDTA](EDTA.md) | 螯合二价离子，减少聚集 |
| [PBS](PBS.md) / [DPBS](DPBS.md) | 终止、稀释或洗涤 |

## 使用注意事项

| 变量 | 为什么重要 | 建议 |
| --- | --- | --- |
| pH | K2CO3 碱性更强，pH 影响明显 | 配制后必须检测并记录 |
| 浓度 | 影响缓冲能力和细胞状态 | 按商品说明书或 SOP，不要凭经验替换 |
| 级别 | 杂质可能影响细胞 | 细胞相关用途需使用合适级别 |
| 吸湿性 | 影响称量准确性 | 使用后及时密封，记录开封时间 |
| 下游兼容性 | 残留可能影响培养或流式 | 处理后充分洗涤 |

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 白细胞活率下降 | K2CO3 相关 pH/渗透压偏离 | 复核整体配方和 pH |
| 自配裂解液批次差异大 | K2CO3 吸湿、称量或保存差异 | 使用新鲜干燥试剂并记录批次 |
| 用 KHCO3/K2CO3 互换后异常 | 碱性不同导致体系改变 | 不直接替换，重新验证 |
| 流式背景升高 | 裂解过强、碎片多或洗涤不足 | 缩短处理、增加洗涤和过滤 |

## 购买建议

如果只是为了红细胞裂解，通常优先购买经过验证的商品 [红细胞裂解液](红细胞裂解液.md)，而不是单独用 K2CO3 自行摸索配方。只有在需要复现某个明确商品或实验室 SOP 时，才单独采购并记录 K2CO3。

## 小结

碳酸钾是某些 RBC lysis buffer 中可见的缓冲/碱性成分，但它不是红细胞裂解的主效应成分，也不能和碳酸氢钾随意互换。使用时最重要的是写清配方来源、浓度、pH、级别、批号和保存条件。
