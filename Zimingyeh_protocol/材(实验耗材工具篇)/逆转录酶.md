# 逆转录酶

Reverse transcriptase（逆转录酶）是一类以 RNA 为模板合成 DNA 的 DNA polymerase（DNA 聚合酶），是把 RNA 转换成 [cDNA](<../番外/补充知识/cDNA.md>)（complementary DNA，互补 DNA）的核心酶。它是 [逆转录](<../用(实验流程内容篇)/逆转录.md>)、[RT-qPCR](<../用(实验流程内容篇)/RT-qPCR.md>)、转录本克隆和 RNA 测序文库构建的关键材料。

## 核心作用

逆转录酶利用 RNA 模板和 primer（引物）合成第一链 cDNA。后续 qPCR 实际扩增的是 cDNA，而不是原始 RNA。因此逆转录效率、引物策略和酶的耐受性会直接影响 RT-qPCR 的 Cq 值和可比性。

Thermo Fisher 的 SuperScript IV、Promega 的 GoScript、NEB 的 ProtoScript II 和 Takara 的 PrimeScript 都是常见逆转录酶或逆转录体系。不同产品在热稳定性、RNase H 活性、抑制物耐受和长片段能力上有差异。[参考：Thermo Fisher SuperScript IV](https://www.thermofisher.com/order/catalog/product/18090010)；[参考：Promega GoScript Reverse Transcriptase](https://www.promega.com/products/pcr/rt-pcr/goscript-reverse-transcriptase/)；[参考：NEB ProtoScript II Reverse Transcriptase](https://www.neb.com/en-us/products/m0368-protoscript-ii-reverse-transcriptase)

## 常见类型

| 类型 | 代表 | 特点 | 适合场景 |
| --- | --- | --- | --- |
| M-MLV derived RT | M-MLV、SuperScript、GoScript | 常见、成熟，改造版本很多 | 常规 cDNA 合成和 RT-qPCR |
| AMV RT | Avian myeloblastosis virus RT | 相对耐高温，历史悠久 | 高二级结构 RNA 或特定旧 protocol |
| RNase H reduced RT | RNase H 活性降低版本 | 减少 RNA 模板降解，提高长 cDNA 合成 | 长转录本或复杂模板 |
| Thermostable RT | 高温逆转录酶或改造酶 | 可在更高温度下处理 RNA 二级结构 | GC-rich 或强二级结构区域 |

## 选择逆转录酶看什么

| 指标 | 为什么重要 |
| --- | --- |
| Temperature tolerance（温度耐受） | 高温有助于打开 RNA 二级结构 |
| RNase H activity（RNase H 活性） | 过高可能降解 RNA 模板，影响长片段 |
| Inhibitor tolerance（抑制物耐受） | RNA 提取残留盐、酚、乙醇会抑制反应 |
| cDNA length capability（长片段能力） | 克隆和全长转录本需要更强长片段能力 |
| qPCR compatibility（qPCR 兼容性） | RT-qPCR 更关注一致性和线性范围 |
| Kit integration（试剂盒集成） | 预混体系更稳定，单酶更灵活 |

## 使用 protocol

### 解冻和准备

**怎么做**：在冰上解冻 buffer、dNTP、引物和 RNA；逆转录酶最后从 -20°C 取出，轻轻混匀后立即放回冰上。

**为什么**：逆转录酶是蛋白酶制剂，反复升温和长时间室温暴露会降低活性；RNA 也极易被 RNase 降解。

**注意事项**：

- 使用 RNase-free 管和滤芯吸头。
- 不要剧烈 vortex 酶液。
- RNA 模板应先评估浓度、纯度和完整性。

### 配反应体系

**怎么做**：按产品说明加入 RNA、引物、dNTP、buffer、DTT 或 enhancer、RNase 抑制剂和逆转录酶。设定 No-RT control（无逆转录酶对照）用于判断基因组 DNA 污染。

**为什么**：逆转录反应中的每个成分都会影响 cDNA 产量和偏倚。No-RT 是 RT-qPCR 判断 DNA 污染的重要控制。

**注意事项**：

- 多样本比较时固定 RNA 投入量。
- 引物策略要与目标 RNA 类型一致。
- 若下游是 qPCR，反应后 cDNA 稀释倍数要统一。

### 反应和保存

**怎么做**：按说明进行退火、逆转录和热灭活。反应结束后 cDNA 可短期 4°C，长期 -20°C 保存。

**为什么**：温度程序决定引物退火、RNA 二级结构解开和酶活性。热灭活是否需要取决于产品和下游。

**注意事项**：

- 不同逆转录酶程序不能随意互换。
- 做 RT-qPCR 时避免 cDNA 反复冻融。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| cDNA 产量低 | RNA 降解、抑制物残留、酶失活 | 重提 RNA，检查 A260/230，换新酶 |
| RT-qPCR Cq 偏高 | 逆转录效率低、RNA 投入少、引物策略不合适 | 固定 RNA 量，优化引物和反应温度 |
| No-RT 有信号 | 基因组 DNA 污染 | DNase 处理，设计跨外显子引物 |
| 重复性差 | 混匀不充分、RNA 质量不一、冻融多 | 做 master mix，统一模板处理 |
| 长片段失败 | RNA 二级结构或酶长片段能力不足 | 选择更高温或长片段 RT |

## 小结

逆转录酶决定 RNA 信息能否稳定转换成 cDNA。RT-qPCR 的很多“qPCR 问题”其实来自逆转录环节，所以酶型号、RNA 投入量、引物策略和 No-RT 对照必须记录清楚。
