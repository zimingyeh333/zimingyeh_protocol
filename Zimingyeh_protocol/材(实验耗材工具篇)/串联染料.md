# 串联染料

## 一句话定义

Tandem dye（串联染料）是一类由 donor fluorophore（供体荧光团）和 acceptor fluorophore（受体荧光团）连接而成的复合荧光标记，常用于 [流式细胞术](<../用(实验流程内容篇)/流式细胞术.md>) 中扩展可用检测通道。

典型例子包括 [PE](PE.md)-Cy7、PE-Cy5、APC-Cy7、PerCP-Cy5.5 等。它们通常由 PE、[APC](APC.md) 或 PerCP 等强供体吸收激发光，再通过 energy transfer（能量转移）让受体染料发出更长波长信号。BioLegend、BD 和 Thermo Fisher 的流式资料都把 tandem dyes 作为多色 panel 设计中的重要工具，同时提醒其稳定性和补偿要求。[参考：BioLegend Fluorophore Guide](https://www.biolegend.com/en-us/fluorophore-guide)；[参考：BD Fluorochrome Guide](https://www.bdbiosciences.com/en-us/resources/bd-spectrum-viewer)；[参考：Thermo Fisher Flow Cytometry Fluorophores](https://www.thermofisher.com/us/en/home/life-science/cell-analysis/flow-cytometry/flow-cytometry-learning-center/flow-cytometry-resource-library/flow-cytometry-methods/fluorescent-dyes-flow-cytometry.html)

## 核心原理

串联染料可以简化理解为：

```text
激光激发供体染料
→ 供体把能量转移给受体染料
→ 受体发出更长波长荧光
→ 流式仪在另一个通道检测
```

例如 PE-Cy7 通常由 PE 吸收 488/561 nm 激发光，再通过 Cy7 相关受体在近红外区域发射信号。这样可以用同一条激光扩展更多颜色。

## 常见串联染料

| 串联染料 | 常见供体 | 常见受体 | 典型用途 |
| --- | --- | --- | --- |
| PE-Cy5 | PE | Cy5 | 多色流式 |
| PE-Cy7 | PE | Cy7 | 近红外通道，高亮但需注意稳定性 |
| PE-CF594 | PE | CF594 | 561 nm 激光常见通道 |
| PerCP-Cy5.5 | PerCP | Cy5.5 | 488 nm 激光通道 |
| APC-Cy7 | APC | Cy7 | 红光激光扩展通道 |
| APC-R700 / APC-Fire 系列 | APC | 远红/近红外受体 | 取决于厂家和仪器 |

同一个“PE-Cy7”在不同品牌、不同抗体克隆和不同批号中表现也可能不同。panel 设计时应该按具体产品和仪器配置判断。

## 为什么使用串联染料

| 需求 | 串联染料的价值 |
| --- | --- |
| 多色 panel | 在有限激光下扩展更多通道 |
| 低表达 marker | PE/APC 作为供体时亮度高 |
| 仪器通道已固定 | 利用已有滤光片组合 |
| 高维免疫表型 | 为更多抗体分配颜色 |

串联染料的代价是稳定性、补偿和批次变量更复杂。它们不是普通单染料的简单替代。

## 串联染料 vs 单一染料

| 维度 | 串联染料 | 单一染料 |
| --- | --- | --- |
| 结构 | 供体 + 受体 | 单一荧光团 |
| 通道扩展 | 强 | 取决于光谱 |
| 补偿复杂度 | 更高 | 通常较低 |
| 批次稳定性 | 可能更敏感 | 通常更稳 |
| 光照/固定影响 | 更需要验证 | 相对简单 |
| 典型应用 | 多色流式 | IF、流式、成像 |

## 使用 protocol

### 流式染色

1. 根据仪器激光和滤光片选择串联染料。
2. 将最亮或最稳定的染料分配给低表达或关键 marker。
3. 每个串联染料都需要对应 single-stain compensation control（单染补偿对照）。
4. 抗体滴定，避免过量抗体造成背景和扩散误差。
5. 染色、洗涤和上机过程避光。
6. 固定/通透前确认串联染料是否兼容。

### 补偿和质控

串联染料必须用同一批或相同光谱表现的补偿材料。尤其是 PE-Cy7、APC-Cy7 等，受光照、固定和降解影响后，供体泄漏和受体发射比例可能改变。

## 注意事项

- 串联染料更容易受光照、固定剂、温度和时间影响。
- PE-Cy7、APC-Cy7 等 Cy7 类串联染料常被认为稳定性更需要关注。
- 每次实验都应使用新鲜、匹配的单染补偿对照。
- 不要把 PE-Cy7 当作“PE 加一个远红通道”简单理解，它有独立补偿行为。
- 串联染料降解可能导致 donor channel（供体通道）信号增加，受体通道信号下降。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 补偿每天变化大 | 串联染料批次、光照或固定影响 | 使用当天单染补偿，避光，固定前验证 |
| PE 通道异常变高 | PE-Cy7 降解，供体信号泄漏 | 更换试剂，缩短处理时间，减少光照 |
| 阴性群变宽 | 串联染料过亮或补偿不准 | 抗体滴定，重新补偿 |
| 某个 marker 分不开 | 染料分配不合理 | 把更亮稳定染料给低表达 marker |
| 固定后信号掉 | 固定剂破坏串联结构 | 选择 fixation-compatible 产品 |

## 小结

串联染料是多色流式的重要扩展工具，能用有限激光获得更多通道，尤其适合高维 panel。但它们比单一染料更依赖补偿、避光、批次记录和固定兼容性验证。使用串联染料时，必须把补偿对照和试剂批号写进 protocol。
