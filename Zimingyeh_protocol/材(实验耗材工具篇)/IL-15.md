# IL-15

IL-15（Interleukin-15，白细胞介素-15）是一种对 NK cells（natural killer cells，自然杀伤细胞）和 memory T cells（记忆 T 细胞）存活、扩增和功能维持很重要的 cytokine（细胞因子），常用于免疫细胞培养、T 细胞/NK 细胞扩增和细胞治疗相关体外体系。

图源：Image2 生成的培养支持分子参考图；IL-15 位于 immune cytokine support 模块，主要支持 NK / memory T cell survival。

## 核心定位

IL-15 与 [IL-2](IL-2.md) 同属 common gamma chain cytokine（共同 γ 链细胞因子）相关家族，常通过 IL-15 receptor（IL-15 受体）和 [JAK-STAT通路](<../番外/补充知识/JAK-STAT通路.md>) 等模块影响免疫细胞存活和功能。R&D Systems 的 Recombinant Human IL-15 页面说明，IL-15 可刺激 T cells 和 NK cells 增殖，并与 IL-2 在受体组成和生物学功能上有相似但不完全相同的特征。参考：[R&D Systems Recombinant Human IL-15](https://www.rndsystems.com/products/recombinant-human-il-15-protein_247-ilb)。

在培养体系里，IL-15 往往比 IL-2 更偏向维持 memory-like T cell（记忆样 T 细胞）和 NK cell 的 survival/function，而不是单纯强扩增。

## 常见用途

| 场景 | IL-15的作用 |
| --- | --- |
| NK细胞扩增 | 支持 NK 生存、活化和功能维持 |
| T细胞长期培养 | 支持 memory-like phenotype |
| CAR-T/TCR-T研究 | 与 IL-2、IL-7 比较或联用，影响表型 |
| 免疫细胞分化体系 | 模拟 γ-chain cytokine niche |
| 细胞治疗工艺开发 | 作为扩增/维持 cytokine 变量 |

## IL-15 vs IL-2/IL-7

| 因子 | 常见培养逻辑 | 风险点 |
| --- | --- | --- |
| IL-15 | NK 和记忆 T 细胞 survival/function | 扩增强度和表型依赖细胞状态 |
| [IL-2](IL-2.md) | 活化 T 细胞扩增 | 可能推动强激活或表型漂移 |
| [IL-7](IL-7.md) | 初始/记忆 T 细胞 survival/homeostasis | 扩增不一定强 |

三者都可能用于 T 细胞体系，但实验意义不同。不要只写“cytokine cocktail”，要逐项记录。

## 使用 protocol

### 重构与保存

**怎么做**：按厂家说明重构，低温小分装，避免反复冻融。低浓度使用时可根据说明选择含 carrier protein 的 buffer 减少吸附损失。

**为什么**：IL-15 用量低，免疫细胞对有效浓度和补加频率非常敏感。

### 加入培养

**怎么做**：按免疫细胞 protocol 设置终浓度、补加频率和联用因子，记录细胞亚群、激活方式和培养密度。

**为什么**：IL-15 的效果强烈依赖细胞是否已被激活、是否与 IL-7/IL-2/IL-21 等联用，以及培养密度和营养状态。

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| NK细胞扩增差 | IL-15失活、缺少联用因子或密度不合适 | 换新分装并优化 cocktail |
| T细胞表型不稳定 | cytokine组合或浓度改变 | 固定 IL-15/IL-7/IL-2 条件 |
| 细胞死亡增加 | 补加频率低、营养不足或刺激过强 | 优化换液和密度 |
| 批间差异 | 活性单位、表达系统或品牌不同 | 记录 lot 和比活 |

## 小结

IL-15 是 NK 细胞和记忆样 T 细胞培养中的关键 cytokine。它和 IL-2、IL-7 都能支持免疫细胞，但偏向的细胞状态不同；因此必须记录联用组合、活性单位、补加频率和细胞亚群。
