# 脱脂奶粉

## 一句话定义

Non-fat dry milk（脱脂奶粉）是一种常用 Western blot 封闭试剂，主要通过奶蛋白占据膜上的非特异吸附位点，降低 [一抗](一抗.md) 和 [二抗](二抗.md) 的背景结合。

在 [Western blot](<../用(实验流程内容篇)/Western blot.md>) 中，脱脂奶粉常配成 5% milk in [TBST](TBST.md)，用于封闭或抗体稀释。CST、Thermo Fisher、Bio-Rad 和 Abcam 的 WB protocol 都将 milk 与 [BSA](BSA.md) 列为常见封闭选择。[参考：CST Western Blot Protocol](https://www.cellsignal.com/learn-and-support/protocols/protocol-western)；[参考：Bio-Rad Western Blotting Guide](https://www.bio-rad.com/applications-technologies/western-blotting-immunodetection-techniques?ID=PQEEPOBWLN4A)

## 核心作用

转膜后的 [PVDF膜](PVDF膜.md) 或 [NC膜](NC膜.md) 仍有大量未被目标蛋白占据的结合位点。脱脂奶粉中的蛋白会先占据这些位点，减少抗体直接吸附到膜上。

可以把封闭理解为：

```text
膜上空位越多 → 抗体越容易乱粘 → 背景越高
封闭蛋白占据空位 → 抗体更集中识别目标 → 背景降低
```

## 主要成分

脱脂奶粉不是单一化学物质，而是混合物，主要包括：

| 成分 | 作用/影响 |
| --- | --- |
| [酪蛋白](酪蛋白.md) | 主要奶蛋白，提供封闭能力 |
| 乳清蛋白 | 参与封闭，批次和来源可能影响背景 |
| 少量糖类和盐类 | 影响溶解性和体系背景 |
| 微量生物素或磷蛋白相关成分 | 可能干扰 biotin/avidin 或 phospho-antibody 检测 |

因此脱脂奶粉便宜好用，但不是“成分完全定义”的封闭剂。对敏感实验，BSA 或商业无蛋白/定义型封闭液可能更可控。

## 脱脂奶粉 vs BSA

| 维度 | 脱脂奶粉 | BSA |
| --- | --- | --- |
| 英文 | Non-fat dry milk | Bovine serum albumin |
| 中文 | 脱脂奶粉 | 牛血清白蛋白 |
| 成分 | 混合奶蛋白 | 单一主蛋白更明确 |
| 成本 | 低 | 较高 |
| 常规 WB | 很常用 | 也常用 |
| 磷酸化蛋白 | 不推荐作为默认首选 | 更常作为首选 |
| Biotin/avidin 体系 | 可能干扰 | 通常更可控 |
| 背景可控性 | 批次差异可能更明显 | 通常更稳定 |

经验规则：普通总蛋白 WB 可以先用脱脂奶粉；磷酸化蛋白、低背景要求高或奶粉背景异常时，优先换 BSA。

## 常见配方

### 5% 脱脂奶粉封闭液

```text
脱脂奶粉：5 g
1× TBST：100 mL
充分溶解后使用
```

也有实验使用 3% 或 10%。封闭浓度不是越高越好，太高可能增加黏稠度、洗不干净或遮挡低丰度信号。

## 使用 protocol

1. 转膜结束后，用 [Ponceau S](<Ponceau S.md>) 检查转膜。
2. TBST 简单洗去 Ponceau S。
3. 加入 5% 脱脂奶粉/TBST，室温轻摇封闭 30-60 min。
4. 倒去封闭液。
5. 根据抗体说明书选择一抗稀释液；可用 milk/TBST 或改用 BSA/TBST。

如果一抗说明书明确要求 BSA，不建议为了方便改用脱脂奶粉。

## 注意事项

- 脱脂奶粉现配现用更稳，长时间保存容易污染或沉淀。
- 配好后若有明显颗粒，可短暂离心或过滤，但不要把未溶颗粒带到膜上。
- 磷酸化抗体检测通常优先用 BSA，因为奶粉中的磷蛋白可能带来背景或竞争影响。
- 生物素-链霉亲和素体系不建议默认使用脱脂奶粉。
- 不同品牌奶粉差异可能很大，严肃项目应记录品牌和批号。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 磷酸化信号弱或背景高 | 奶粉中磷蛋白干扰 | 改用 BSA/TBST |
| 整膜背景高 | 奶粉未溶、封闭不足、抗体过浓 | 充分溶解，过滤/离心，优化抗体 |
| 膜上颗粒斑点 | 奶粉颗粒沉积 | 使用新鲜溶液并充分混匀 |
| 批次表现变化 | 奶粉来源不同 | 固定品牌批号，关键实验做桥接 |
| 低丰度目标弱 | 封闭过强或抗体稀释不合适 | 降低奶粉浓度或换 BSA |

## 购买和记录建议

实验室可以使用分子生物学级 non-fat dry milk，也可以使用经验证的普通脱脂奶粉，但后者批次和成分可控性较差。长期项目建议固定来源。

## 小结

脱脂奶粉是便宜、有效、非常常见的 WB 封闭剂，但它不是所有抗体的默认最佳选择。常规 WB 可以先用 milk；磷酸化蛋白、biotin/avidin 体系和高背景问题，应优先考虑 BSA 或其他定义型封闭液。
