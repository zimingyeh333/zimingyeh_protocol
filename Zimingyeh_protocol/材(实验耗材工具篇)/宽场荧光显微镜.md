# 宽场荧光显微镜

## 一句话定义

Widefield fluorescence microscope（宽场荧光显微镜）是一类一次照亮整个视野并由相机收集荧光信号的 [荧光显微镜](荧光显微镜.md)，常用于常规 [免疫荧光](<../用(实验流程内容篇)/免疫荧光.md>)、细胞定位观察和快速多通道成像。

宽场荧光显微镜的优势是速度快、视野大、操作相对简单、设备成本低于多数 [共聚焦显微镜](共聚焦显微镜.md)；局限是厚样本或高背景样本中，焦平面外荧光会一起进入相机，导致图像背景高、Z 方向分辨率较差。Leica、Thermo Fisher 和 Olympus/Evident 的显微资料都把 widefield fluorescence 作为基础荧光成像形式。[参考：Leica Fluorescence Microscopy](https://www.leica-microsystems.com/science-lab/life-science/fluorescence-microscopy/)；[参考：Thermo Fisher Fluorescence Microscopy](https://www.thermofisher.com/us/en/home/life-science/cell-analysis/cell-imaging/fluorescence-microscopy.html)

## 核心工作逻辑

```text
整片视野被激发光照亮
→ 样本中所有被激发的荧光团发光
→ 物镜收集焦平面内和焦平面外信号
→ 相机形成二维图像
```

这就是宽场显微镜“快”的原因，也是它在厚样本中背景高的原因。

## 适合用途

| 场景 | 原因 |
| --- | --- |
| 固定细胞 IF | 细胞薄，焦外背景通常可接受 |
| 强信号目标 | 不需要极强背景抑制 |
| 多孔板快速扫描 | 视野大、速度快 |
| 细胞计数和核定位 | [DAPI](DAPI.md)/Hoechst 信号容易采集 |
| 常规形态观察 | 操作简单，通量高 |

如果样本是薄层贴壁细胞，目标信号强，宽场往往足够。不要为了“更高级”默认上共聚焦。

## 不适合或需谨慎的情况

| 场景 | 问题 | 替代策略 |
| --- | --- | --- |
| 厚组织切片 | 焦外荧光背景高 | 共聚焦或组织透明/光片 |
| 精细共定位 | Z 方向分辨率不足 | 共聚焦、超分辨或更严格采样 |
| 弱信号目标 | 背景可能淹没信号 | 更亮染料、共聚焦、优化染色 |
| 近膜事件 | 焦外信号干扰膜附近信号 | [TIRF显微镜](TIRF显微镜.md) |
| 三维重构 | Z-stack 背景较多 | 共聚焦或反卷积宽场 |

## 宽场 vs 共聚焦

| 维度 | 宽场荧光显微镜 | 共聚焦显微镜 |
| --- | --- | --- |
| 激发方式 | 整个视野照亮 | 点扫描或线扫描 |
| 焦外信号 | 会被相机收集 | 被 pinhole 或光学切片抑制 |
| 成像速度 | 通常快 | 取决于扫描方式，通常较慢 |
| 光毒性 | 可较低，但取决于光强 | 局部激光强，活细胞需谨慎 |
| 适合样本 | 薄样本、强信号 | 厚样本、三维、共定位 |
| 成本/门槛 | 较低 | 较高 |

宽场和共聚焦不是“低级和高级”的关系，而是不同问题的工具。宽场适合快、薄、亮；共聚焦适合厚、复杂、需要光学切片。

## 使用 protocol

### 成像前

1. 确认样本封片无明显气泡，使用匹配的 [盖玻片](盖玻片.md) 和 [载玻片](载玻片.md)。
2. 根据染料选择合适 [荧光滤光片](荧光滤光片.md) 和通道。
3. 使用低光强寻找视野，减少 [光漂白](../番外/补充知识/光漂白.md)。
4. 设置曝光时间和相机增益，避免饱和。
5. 固定所有组别的成像参数。

### 多通道采集

建议从长波长到短波长或从弱信号到强信号有序采集，具体取决于仪器和染料组合。多通道实验必须设置单染对照，确认 [光谱重叠](../番外/补充知识/光谱重叠.md) 和串色。

## 可调策略

| 问题 | 调整方向 |
| --- | --- |
| 背景高 | 降低曝光，优化封闭，换远红染料，考虑共聚焦 |
| 信号弱 | 增加曝光但避免饱和，换更亮染料，优化抗体 |
| 图像模糊 | 检查对焦、物镜、盖玻片厚度和封片剂 |
| 光漂白快 | 降低光强，缩短曝光，使用 [抗淬灭封片剂](抗淬灭封片剂.md) |
| 厚样本不清 | 用反卷积或共聚焦 |

## 注意事项

- 宽场图像容易包含焦外背景，不能把所有亮点都当作焦平面真实结构。
- 定量实验必须保持曝光、增益、光强和后处理一致。
- 图像不能饱和，饱和像素无法用于定量。
- 活细胞成像需注意光毒性、温度和 CO2 控制。
- 需要三维信息时，Z-stack 步长要合理记录。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 整张图雾蒙蒙 | 焦外荧光或封闭不足 | 换共聚焦/反卷积，优化染色 |
| 细胞边缘亮但定位不清 | 曝光过高或焦平面不对 | 降低曝光，重新对焦 |
| 不同组看似差异大 | 自动曝光或后处理不同 | 固定成像参数 |
| 蓝色通道过曝 | DAPI/Hoechst 太强 | 降低曝光或核染浓度 |
| 活细胞状态变差 | 光毒性或环境控制不足 | 降低光强，使用培养箱载台 |

## 小结

宽场荧光显微镜适合薄样本、强信号和快速成像，是常规 IF 的高效工具。它的主要风险是焦外背景和自动成像参数导致的假差异。使用宽场做定量时，参数一致和不过曝比图像“亮不亮”更重要。
