# 无血清培养基

无血清培养基（serum-free medium，SFM）是指不使用 animal serum（动物血清，例如 [FBS](FBS.md)）作为补充剂的细胞培养体系。它通常用基础培养基、定义补充剂、激素、生长因子、脂质、白蛋白或其他成分来替代血清提供的复杂支持。

## 核心定位

无血清培养基的核心价值是减少血清带来的不确定性。Thermo Fisher 的 serum-free media 页面说明，无血清培养基可以减少血清批次差异、降低外源性蛋白背景、改善下游纯化，并可用于原代细胞、CHO、HEK293、杂交瘤、干细胞和免疫细胞等应用。参考：[Thermo Fisher Serum-Free Media](https://www.thermofisher.com/us/en/home/life-science/cell-culture/mammalian-cell-culture/cell-culture-media/serum-free-media.html)。

但无血清不是“更高级的万能培养基”。它牺牲了 FBS 的容错性，换来更高的成分控制和可重复性。细胞是否能适应，取决于细胞类型、基础培养基、补充剂、基质、接种密度和适应方式。

## 几个容易混淆的概念

| 概念 | 英文 | 含义 | 是否等同 |
| --- | --- | --- | --- |
| 无血清培养基 | Serum-free medium | 不含 serum，但可能含动物来源蛋白或未完全定义成分 | 不等于化学成分明确 |
| [化学成分明确培养基](化学成分明确培养基.md) | Chemically defined medium | 每个成分及浓度相对明确 | 不一定 xeno-free |
| 蛋白无添加培养基 | Protein-free medium | 不含外加蛋白或蛋白水解物 | 不一定适合所有细胞 |
| [Xeno-free培养基](Xeno-free培养基.md) | Xeno-free medium | 不含非人源/异种动物来源成分 | 不一定完全 chemically defined |
| 无动物源培养基 | Animal component-free medium | 不含动物来源组分 | 和 xeno-free 接近但需看厂家定义 |

所以看到“serum-free”时，下一步要问：是否 chemically defined？是否 xeno-free？是否 protein-free？是否含 recombinant albumin、insulin、transferrin 或 animal-derived components？

## 常见组成逻辑

| 组成 | 常见例子 | 作用 |
| --- | --- | --- |
| 基础培养基 | [DMEM-F12](DMEM-F12.md)、[Ham F-12](<Ham F-12.md>)、[α-MEM](α-MEM.md) | 提供盐、糖、氨基酸和维生素 |
| 经典补充剂 | [ITS补充剂](ITS补充剂.md) | 胰岛素、转铁蛋白、硒等基础支持 |
| 神经/干细胞补充剂 | [B27补充剂](B27补充剂.md)、[N2补充剂](N2补充剂.md) | 神经细胞、类器官、干细胞常见 |
| 生长因子 | EGF、FGF、TGF-β、Wnt、Noggin、R-spondin 等 | 控制增殖、分化和谱系状态 |
| 脂质/白蛋白 | albumin、lipid concentrate | 结合疏水分子，提供脂质支持 |
| 基质/包被 | [细胞外基质胶](细胞外基质胶.md)、胶原、laminin | 替代血清中的贴壁和 ECM 信号 |

血清提供的是一个复杂生态；无血清培养要把这个生态拆成可控组件。

## FBS体系 vs 无血清体系

| 项目 | FBS-containing medium | Serum-free medium |
| --- | --- | --- |
| 容错性 | 高，细胞通常容易恢复 | 低，需要适配细胞 |
| 批次差异 | 血清批次影响大 | 补充剂和生长因子仍有批次影响 |
| 成分明确性 | 低 | 较高，可进一步做到 chemically defined |
| 下游纯化 | 血清蛋白背景高 | 背景更低 |
| 成本 | FBS 贵但操作熟悉 | 专用补充剂和因子可能更贵 |
| 适合 | 常规细胞维护、初步实验 | 机制研究、生产、分化、低背景检测 |

## 使用 protocol

### 判断是否适合切换

**怎么做**：先确认细胞是否有公开无血清 protocol 或厂家推荐体系，查清基础培养基、补充剂、包被、接种密度和传代方法。

**为什么**：无血清培养失败最常见原因不是“缺少血清”这句话本身，而是没有补上血清原本提供的生长因子、贴壁因子、脂质和保护性蛋白。

### 逐步适应

**怎么做**：对已经长期用 FBS 培养的细胞，可采用 gradual adaptation（逐步适应）：先用 75% 原完全培养基 + 25% 无血清体系，稳定后逐步过渡到 50%、75%、100%。具体比例和时间按细胞反应调整。

**为什么**：突然去掉血清可能造成贴壁差、死亡、增殖停滞或表型漂移。

**替代方案**：有些 commercial serum-free medium（商业无血清培养基）允许直接适应或直接复苏，但仍需做小规模验证。

### 验证培养状态

**怎么做**：比较形态、倍增时间、活率、marker 表达、功能 readout、污染状态和下游实验结果。

**为什么**：无血清培养成功不是“细胞没死”，而是细胞仍保持目标状态和实验响应。

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 细胞不贴壁 | 缺少 ECM/贴壁因子或包被不合适 | 优化胶原、laminin、基质胶等包被 |
| 增殖停滞 | 缺少关键生长因子或接种密度太低 | 补充因子，提高初始密度 |
| 细胞逐渐漂移 | 无血清体系改变选择压力 | 检查 marker 和功能，不只看增殖 |
| 批间差异仍然存在 | 生长因子、基质或重组蛋白批号变化 | 记录关键批号并做批间验证 |
| 下游信号变强/变弱 | 血清背景被移除，细胞状态改变 | 重新建立对照和基线 |

## 小结

无血清培养基的意义是把血清这个复杂黑箱拆成可控制的培养变量。它可以提高可重复性、降低背景、支持机制研究或生产流程，但前提是完整记录基础培养基、补充剂、生长因子、基质、适应过程和状态验证。
