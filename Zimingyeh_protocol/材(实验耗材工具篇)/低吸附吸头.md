# 低吸附吸头

Low-retention pipette tip（低吸附移液枪吸头）是通过材料、表面处理或模具工艺降低液体在吸头内壁残留的一类 [移液枪吸头](移液枪吸头.md)。它适合低体积、高价值、易吸附或含表面活性剂的样本，例如蛋白、酶、核酸、qPCR master mix 和含甘油/去污剂体系。

图源：Image2 生成的实验耗材对照参考图；从左到右第 4 个为低吸附吸头示意，液滴更容易从内壁滑落。

## 为什么会有残留

液体在普通聚丙烯吸头内壁残留，通常与表面张力、液体黏度、蛋白/核酸吸附、去污剂、甘油和移液速度有关。小体积时，残留液滴占总体积比例更高，所以低吸附吸头的意义更明显。

Eppendorf 的低吸附吸头资料强调，低吸附表面可减少样品在吸头内壁的残留，从而提高样品回收；Rainin 对低吸附吸头的说明也把 low retention 与改善低表面张力液体移液表现联系起来。[参考：Eppendorf epT.I.P.S. LoRetention](https://www.eppendorf.com/us-en/eShop-Products/Liquid-Handling/Pipette-Tips/epT-I-P-S-LoRetention-p-PF-81066)；[参考：Rainin Low Retention Tips](https://www.mt.com/us/en/home/products/pipettes/pipette-tips/low-retention-tips.html)

## 核心用途

| 场景 | 为什么用低吸附 |
| --- | --- |
| qPCR / RT-qPCR | master mix、酶和荧光体系体积小，残留会放大误差 |
| 蛋白和酶 | 蛋白可能吸附在塑料表面 |
| 核酸样本 | 低浓度 DNA/RNA 损失会影响下游 |
| 含去污剂样本 | 低表面张力液体容易形成不规则残留 |
| 珍贵样本 | 减少每次转移的不可见损耗 |

## 低吸附 vs 滤芯 vs 宽口

| 类型 | 解决的主要问题 | 是否可叠加 |
| --- | --- | --- |
| 低吸附吸头 | 样品残留和壁面吸附 | 可与滤芯、无菌等级叠加 |
| [滤芯吸头](滤芯吸头.md) | 气溶胶和移液器污染 | 可有低吸附版本 |
| [宽口吸头](宽口吸头.md) | 剪切力、堵塞、高黏度阻力 | 可有低吸附版本，但不总是默认 |

不要把低吸附理解成“更干净”。它主要解决残留和回收率，不等于无菌、无核酸酶或防污染。

## 使用 protocol

### 选择场景

**怎么做**：在小体积、低浓度、高价值或易吸附样本中优先选择低吸附吸头。普通培养基、PBS 大体积转移不一定需要。

**为什么**：低吸附吸头成本更高，最该用在残留会实质影响结果的步骤。

**注意事项**：

- 关键定量实验固定吸头型号。
- 低吸附工艺不同，不能假设不同品牌表现完全相同。
- 低吸附不替代预润湿。

### 移液操作

**怎么做**：按常规移液规范预润湿，缓慢吸排，排液后可短暂停留并使用第二档排尽。

**为什么**：低吸附表面降低残留，但操作速度、液体黏度和温度仍会影响回收。

**注意事项**：

- 对含甘油或高黏度液体，吸排速度要更慢。
- 低表面张力液体容易挂壁或飞溅，不能快速猛吸猛打。
- 对极小体积 qPCR 加样，优先使用匹配量程的小容量吸头。

**替代方案**：高黏度或挥发性液体可考虑 [正置换移液器](正置换移液器.md)。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 仍有明显残留 | 液体太黏、未预润湿、速度太快 | 预润湿，降低速度，考虑正置换 |
| qPCR 重复孔差异大 | 小体积误差、吸头不适配、气泡 | 使用低吸附滤芯吸头，检查加样和封板 |
| 样品回收率低 | 蛋白/核酸吸附、反复转移 | 减少转移次数，使用低吸附管和吸头 |
| 成本浪费 | 所有普通操作都使用低吸附 | 只在关键低体积或珍贵样本步骤使用 |

## 购买与记录建议

购买时看 volume range（量程）、low-retention 技术、是否 sterile、是否 filtered、是否 RNase/DNase-free、是否适配对应移液器。常见供应商包括 [Eppendorf](<../番外/试剂厂商/Eppendorf.md>)、[Rainin](<../番外/试剂厂商/Rainin.md>)、[Thermo Scientific](<../番外/试剂厂商/Thermo Scientific.md>)、[Gilson](<../番外/试剂厂商/Gilson.md>) 等。

推荐记录：

```text
Low-retention tip, volume range, filter yes/no, sterile yes/no, brand, catalog number, lot number, application
```

## 小结

低吸附吸头的价值在于减少不可见残留，尤其适合小体积、高价值、低浓度和易吸附样本。它解决“留在吸头壁上”的问题，不解决全部污染和剪切问题。
