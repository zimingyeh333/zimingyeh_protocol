# 洗板机

Microplate washer（洗板机，微孔板洗板机）是用于自动向 [酶标板](酶标板.md) 孔内加洗涤液并吸走液体的仪器。在 [ELISA](<../用(实验流程内容篇)/ELISA.md>) 中，洗板决定了未结合抗体、酶标物和样本蛋白能否被充分去除，因此直接影响背景、重复孔 CV 和低浓度样本的可信度。

![ELISA 板、酶标仪和洗板机参考图](../z_asset/材/ELISA设备/elisa-plate-reader-washer-reference.png)

图源：Image2 生成的 ELISA 相关设备参考图；右侧展示 plate washer（洗板机）用 manifold needles（洗板针/洗板头）对 96 孔板进行加液和吸液，并连接废液瓶。

## 核心作用

ELISA 的洗板不是简单“倒掉液体”。它要完成三件事：

```text
加入足量洗涤液
-> 让孔壁和孔底充分接触洗涤液
-> 尽量一致地吸走残液
```

Thermo Fisher 的 ELISA overview 将 washing 作为降低 background（背景）的核心步骤之一；BioLegend sandwich ELISA protocol 也在多步孵育之间设置重复洗板。参考：[Thermo Fisher Overview of ELISA](https://www.thermofisher.com/us/en/home/life-science/protein-biology/protein-biology-learning-center/protein-biology-resource-library/pierce-protein-methods/overview-elisa.html)；[BioLegend sandwich ELISA protocol](https://www.biolegend.com/en-us/protocols/sandwich-elisa-protocol)。

## 洗板机的基本结构

| 部件 | 英文 | 作用 |
| --- | --- | --- |
| 洗板头/洗板针 | manifold / wash needles | 同时向多孔加液和吸液 |
| 洗液瓶 | wash buffer bottle | 存放 PBS/TBS + Tween 等洗涤液 |
| 废液瓶 | waste bottle | 收集废液 |
| 真空/泵系统 | vacuum/pump | 提供吸液和加液动力 |
| 板架 | plate carrier | 固定 96/384 孔板位置 |
| 程序设置 | wash protocol | 控制体积、次数、浸泡、吸液高度 |

洗板机的重点不是“能不能吸液”，而是每个孔是否被一致地洗到、残液量是否稳定、是否避免交叉污染。

## 手动洗板 vs 自动洗板

| 方式 | 优点 | 局限 | 适合场景 |
| --- | --- | --- | --- |
| 手动洗板 | 成本低，灵活 | 孔间差异大，容易残液和溅液 | 小规模、教学、低通量 |
| 多道移液枪洗板 | 比单道稳定 | 操作累，仍有人为差异 | 中小规模 ELISA |
| 洗板机 | 一致性好，通量高 | 需要维护和程序优化 | 常规 ELISA、大批量样本 |
| 自动化平台 | 通量和一致性最高 | 成本高，方法开发复杂 | 高通量筛选、平台实验室 |

如果 ELISA 重复孔 CV 总是偏高，且操作依赖手动洗板，洗板一致性通常是优先排查对象。

## 关键参数

| 参数 | 影响 |
| --- | --- |
| wash volume（洗涤体积） | 体积太低孔壁洗不到，太高可能溢出 |
| wash cycles（洗板次数） | 次数不足背景高，过度洗板可能影响弱结合 |
| soak time（浸泡时间） | 有助于降低背景 |
| aspiration height（吸液高度） | 影响残液量和孔底损伤风险 |
| dispense speed（加液速度） | 太快可能溅液或交叉污染 |
| residual volume（残液量） | 残液多会稀释下一步或增加背景 |
| plate type（板型） | 平底/U底/V底需要不同吸液位置 |

洗板程序应该和板型、洗涤液、实验步骤匹配，不要把一个旧程序默认套到所有 ELISA。

## 洗涤液

ELISA 洗涤液常用 [PBS](PBS.md) 或 TBS 加 0.05% 左右 [Tween-20](Tween-20.md)，具体按试剂盒说明书执行。Tween-20 能降低非特异吸附，但浓度过高可能影响弱结合或后续反应。

洗涤液使用前应检查：

- 是否配方正确。
- 是否有沉淀、絮状物或微生物污染。
- 是否室温平衡。
- 管路是否已经 prime（预充液）且无气泡。

## 使用 protocol

### 使用前

1. 检查洗液瓶和废液瓶。
2. 确认洗涤液配方和体积足够。
3. 运行 prime 程序，排除管路气泡。
4. 检查洗板针是否堵塞。
5. 选择对应板型和洗板程序。

### 洗板时

1. 确认酶标板 A1 方向正确。
2. 运行洗板程序。
3. 观察第一轮加液是否均匀。
4. 洗板结束后检查残液是否一致。
5. 需要时轻拍板底去除残液，但不要让孔干燥。

### 使用后

1. 用水或厂家建议清洗液冲洗管路。
2. 清空或规范处理废液。
3. 按平台要求进行消毒或维护。
4. 记录异常，例如堵针、溢液、残液多。

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 背景高 | 洗板次数不足、残液多、洗板针堵塞 | 增加洗板，检查针头和残液 |
| 重复孔 CV 高 | 加液/吸液不均，板位置不正 | 校准板架，检查洗板头 |
| 某一列异常 | 对应洗板针堵塞或位置偏移 | 清洗/通针，重新校准 |
| 孔间交叉污染 | 加液过快、溢液、吸液飞溅 | 降低速度，优化体积 |
| 信号整体变低 | 洗板过强、吸头刮伤涂层、弱结合被洗掉 | 降低吸液强度，调整次数 |
| 残液明显 | 吸液高度不合适、真空不足 | 调整 aspiration height，检查泵 |
| 废液倒灌风险 | 废液瓶满或管路连接错误 | 立即停机，清理并消毒 |

## 选择和购买

选择洗板机时关注：

- 支持 96 孔还是 384 孔。
- 是否支持 strip plate。
- 残液量指标。
- 洗板头规格：8 道、12 道、16 道等。
- 是否支持 bottom wash / overflow wash。
- 程序可编辑程度。
- 管路清洗和防堵设计。
- 废液瓶和消毒流程是否方便。
- 是否与常用酶标板高度兼容。

常见品牌包括 [Agilent](<../番外/试剂厂商/Agilent.md>) BioTek、[Bio-Rad](<../番外/试剂厂商/Bio-Rad.md>)、[Thermo Fisher Scientific](<../番外/试剂厂商/Thermo Fisher Scientific.md>) 等。Agilent 的 microplate washer 页面将洗板机归入 microplate washers and dispensers，用于微孔板洗涤和液体处理；这类仪器的实际价值主要体现在洗板一致性和高通量重复性。参考：[Agilent microplate washers](https://www.agilent.com/en/product/microplate-instrumentation/microplate-washers-dispensers/microplate-washers)。

## 总结

洗板机是 ELISA 背景控制和重复性控制的关键设备。它的价值不是“帮人省力”这么简单，而是让每个孔经历尽量一致的加液、浸泡和吸液。高背景、CV 高、列异常和边缘异常都可能来自洗板条件；因此洗板程序、板型、洗涤液和仪器维护都应写进实验记录。
