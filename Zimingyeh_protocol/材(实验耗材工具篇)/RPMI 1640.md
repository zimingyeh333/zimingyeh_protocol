# RPMI 1640

RPMI 1640（Roswell Park Memorial Institute 1640 medium，Roswell Park Memorial Institute 1640 培养基）是哺乳动物 [细胞培养](<../用(实验流程内容篇)/细胞培养.md>) 中常用的 basal medium（基础培养基），尤其常见于 immune cells（免疫细胞）、leukemic cells（白血病细胞）和多种 suspension cells（悬浮细胞）培养。

![基础培养基与补充剂参考图](../z_asset/材/基础培养基与补充剂/basal-media-supplements-reference.png)

图源：Image2 生成的基础培养基与补充剂参考图；RPMI 1640 位于基础培养基选择层，常与 FBS、L-glutamine/GlutaMAX、抗生素或细胞特异补充剂组合使用。

## 核心定位

Gibco RPMI 1640 产品页面说明，RPMI 1640 最初用于培养 human leukemic cells（人白血病细胞）的悬浮和单层培养，后来被用于 HeLa、Jurkat、MCF-7、PC-12、PBMC、astrocytes 和 carcinomas 等多种细胞；该页面也说明 RPMI 1640 含 glutathione（谷胱甘肽）和较高浓度维生素，并含 biotin、vitamin B12 和 PABA 等在 MEM 或 DMEM 中没有的成分。参考：[Gibco RPMI 1640 Medium](https://www.thermofisher.com/order/catalog/product/11875093)。

RPMI 1640 和 [DMEM](DMEM.md) 都是基础培养基，但不是简单互换关系。很多免疫细胞和血液来源细胞习惯使用 RPMI 1640；贴壁肿瘤细胞、HEK293/HeLa 等则更常见 DMEM 或其他体系。

## 常见用途

| 细胞/场景 | 为什么常见 |
| --- | --- |
| Jurkat、Raji、THP-1 等血液/免疫相关细胞系 | 历史 SOP 和细胞供应商推荐常基于 RPMI |
| PBMC（peripheral blood mononuclear cells，外周血单个核细胞） | 免疫细胞体外刺激、培养和功能实验常用 |
| 某些悬浮或半悬浮细胞 | 细胞密度管理和补充剂体系成熟 |
| 部分贴壁肿瘤细胞 | 取决于细胞来源说明书 |

## 关键版本变量

| 变量 | 常见选择 | 影响 |
| --- | --- | --- |
| L-glutamine | 含或不含 | 影响快速增殖和氮代谢 |
| HEPES | 含或不含 | 影响离开 CO2 环境时 pH 稳定性 |
| phenol red | 含或不含 | 影响 pH 可视化、荧光/激素敏感实验 |
| sodium pyruvate | 多数标准 RPMI 可不含 | 影响额外碳源和代谢变量 |
| bicarbonate | 通常依赖 CO2 | 需要 5%-10% CO2 维持 pH |

Gibco 页面注明其常见 RPMI 1640 版本含 L-glutamine 和 phenol red，不含 HEPES，不含 sodium pyruvate，并使用 sodium bicarbonate buffer system。参考：[Gibco RPMI 1640 Medium](https://www.thermofisher.com/order/catalog/product/11875093)。

## RPMI 1640 vs DMEM

| 项目 | RPMI 1640 | DMEM |
| --- | --- | --- |
| 常见细胞 | 免疫、血液、悬浮细胞 | 贴壁细胞、肿瘤细胞系、HEK293/HeLa 等 |
| 配方特点 | 维生素较丰富，含 glutathione | 常见高糖/低糖、多种 pyruvate/glutamine 版本 |
| 使用逻辑 | 密度窗口和细胞状态很关键 | 表面、汇合度和传代方式很关键 |
| 不能随意互换的原因 | 细胞长期适应了离子、维生素、代谢底物和缓冲条件 | 同左 |

如果细胞说明书写 RPMI 1640 + 10% [FBS](FBS.md)，不要因为实验室只有 DMEM 就直接替换。培养基改变可能导致生长速度、表型和实验 readout 漂移。

## 使用 protocol

### 配制完全RPMI

常见起点：

```text
RPMI 1640：500 mL
FBS：10% v/v
Penicillin-Streptomycin：1% v/v（可选）
L-glutamine或GlutaMAX：按培养基版本决定是否补加
```

具体细胞必须以 ATCC、DSMZ、ECACC、供应商说明书或本实验室 SOP 为准。

### 悬浮细胞维护

**怎么做**：按细胞说明书维持合适 cell density（细胞密度）窗口，通过补液、稀释、离心重悬或分瓶传代控制密度。

**为什么**：悬浮细胞对“过稀”和“过密”都敏感。过稀可能缺少旁分泌支持；过密会导致营养耗竭、酸化和死亡碎片增加。

**注意事项**：

- 记录活率、密度、传代比例和换液方式。
- 不要只看培养基颜色，悬浮细胞也要显微镜看碎片、团聚和污染。
- 免疫刺激实验中，血清批号和细胞密度本身就是实验变量。

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 细胞突然增殖慢 | 换了 RPMI 版本、FBS 批号或 glutamine 状态 | 核对完整配方 |
| 悬浮细胞团聚 | 密度过高、死亡细胞多、DNA 释放或刺激条件影响 | 调整密度并检查活率 |
| 培养基很快变黄 | 细胞过密、代谢旺盛或污染 | 分瓶、换液并排查污染 |
| 免疫刺激结果漂移 | FBS、密度、刺激剂、培养时间不一致 | 固定并记录所有变量 |

## 小结

RPMI 1640 是免疫和悬浮细胞培养中极常见的基础培养基。它的重点不是“比 DMEM 更高级”，而是适合的细胞谱和配方历史不同；真正可复现的记录必须写清版本、补充剂、血清和细胞密度窗口。
