# 去离子水

Deionized water（DI water，去离子水）是通过 ion-exchange resin（离子交换树脂）去除大部分带电离子的实验用水。它适合许多常规清洗和普通溶液配制，但不能自动等同于 [超纯水](超纯水.md)、[无菌水](无菌水.md) 或 [无核酸酶水](无核酸酶水.md)。

## 基本原理

去离子水的核心处理单元是 [离子交换树脂](离子交换树脂.md)。阳离子交换树脂去除 Na+、K+、Ca2+、Mg2+ 等阳离子，阴离子交换树脂去除 Cl-、SO4 2-、NO3- 等阴离子。树脂失效后，出水 [电导率](<../番外/补充知识/电导率.md>) 会升高，说明离子去除能力下降。

去离子水主要降低离子污染，但对有机物、微生物、内毒素、核酸酶和颗粒物的控制并不一定充分。也就是说，去离子水“低盐”，但不一定“干净到适合所有实验”。

## 常见用途

| 用途 | 是否合适 | 备注 |
| --- | --- | --- |
| 玻璃器皿和塑料耗材冲洗 | 合适 | 常用于普通清洗最后冲洗 |
| 普通盐溶液或清洗液配制 | 通常合适 | 对离子背景要求不高时可用 |
| [pH计](pH计.md) 电极冲洗 | 可用 | 冲洗后应轻触吸干，避免稀释样品 |
| 分析天平移液枪校准用水 | 可用 | 需温度平衡并记录水温 |
| 细胞培养试剂配制 | 不建议直接使用 | 需要无菌、内毒素和细胞培养级要求 |
| PCR、RNA、qPCR | 不建议 | 应使用无核酸酶水 |
| HPLC/LC-MS | 不建议 | 应使用 HPLC grade 或 LC-MS grade water |

## 去离子水 vs 其他实验用水

| 类型 | 核心优势 | 主要限制 |
| --- | --- | --- |
| 去离子水 | 去除大部分离子，成本较低，供应稳定 | 不一定无菌、无核酸酶、低 TOC |
| [反渗透水](反渗透水.md) | 可去除颗粒、微生物和部分离子，是常见预处理水 | 通常仍需后续纯化 |
| [蒸馏水](蒸馏水.md) | 通过蒸发-冷凝去除许多非挥发性杂质 | 能耗高，挥发性污染物可能随水带出 |
| 超纯水 | 离子和有机物背景更低 | 取用和保存更敏感，成本更高 |
| 无菌水 | 微生物风险低 | 不代表低离子或无核酸酶 |

## 使用注意事项

### 不要把去离子水当作万能水

DI water 的名字容易给人“已经纯化过，所以都能用”的错觉。实际上它主要解决离子问题，不解决所有污染问题。分子实验、细胞实验、痕量分析和质谱实验应按对应等级选水。

### 注意树脂失效

如果水系统没有及时维护，树脂耗尽后出水电导率会明显升高。对于普通清洗影响可能不大，但对于缓冲液、电极冲洗或仪器背景控制，会带来系统性误差。

### 避免长期存放

去离子水长时间放在开放容器中会吸收 CO2、溶出容器杂质并增加微生物污染风险。需要较稳定背景时，尽量现取现用。

## 简单质控

日常可记录：

- 取水点。
- 取水日期和时间。
- 电导率或电阻率。
- 水系统维护状态。
- 本次用途。

如果 DI water 用于配制比较关键的 buffer，建议至少记录出水电导率；如果用于细胞或分子体系，则应重新评估是否应该换成更高等级水。

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 配出的 buffer pH 漂移 | DI 水吸收 CO2、离子背景不稳定 | 使用新鲜水，必要时换超纯水 |
| 电导率偏高 | 树脂失效、管路污染、容器残留盐 | 检查水系统，更换容器，重新取水 |
| RNA 或 PCR 实验失败 | DI 水不是无核酸酶水 | 改用无核酸酶水 |
| 细胞状态异常 | 水未无菌或含内毒素/微量污染 | 使用细胞培养级水或成品试剂 |
| 清洗后仪器背景仍高 | 有机物或颗粒污染不是 DI 系统主要控制目标 | 使用超纯水或专用清洗流程 |

## 总结

去离子水适合“降低离子背景”的普通实验场景，是实验室最常用的基础水之一。但它不是超纯水，也不是无菌水或无核酸酶水。判断能不能用 DI water，关键不是看名字，而是看实验是否对离子、有机物、微生物、核酸酶或内毒素敏感。
