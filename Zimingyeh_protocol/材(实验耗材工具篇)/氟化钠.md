# 氟化钠

氟化钠（sodium fluoride，NaF）是一种常见 phosphatase inhibitor（磷酸酶抑制剂）组分，常用于 [Western blot](<../用(实验流程内容篇)/Western blot.md>) 和信号通路样本裂解中，帮助保护 serine/threonine phosphorylation（丝氨酸/苏氨酸磷酸化）等磷酸化信号。

![磷酸酶抑制剂成分参考图](../z_asset/材/磷酸酶抑制剂成分/phosphatase-inhibitor-components-reference.png)

图源：Image2 生成的磷酸酶抑制剂成分参考图；氟化钠位于右上方，主要对应 serine/threonine phosphatases（丝氨酸/苏氨酸磷酸酶）相关抑制。

## 核心作用

NaF 可通过 fluoride ion（氟离子）影响多类磷酸酶活性，因此经常出现在 [磷酸酶抑制剂](磷酸酶抑制剂.md) cocktail 或自配裂解液中。Thermo Scientific Halt Phosphatase Inhibitor Cocktail 页面说明该 cocktail 含 sodium fluoride、sodium orthovanadate、sodium pyrophosphate 和 beta-glycerophosphate，可保护细胞/组织裂解过程中的 serine、threonine 和 tyrosine phosphorylation。参考：[Thermo Fisher Halt Phosphatase Inhibitor Cocktail](https://www.thermofisher.com/order/catalog/product/78420)。

Sigma-Aldrich 的 sodium fluoride S7920 页面显示该产品为 BioXtra 级 NaF，水中可配成 1 M 澄清无色溶液，并列出其可作为 extraction buffer 和 lysis buffer 的组分。参考：[Sigma-Aldrich Sodium fluoride S7920](https://www.sigmaaldrich.com/LC/en/product/sial/s7920)。

## 在裂解液中的位置

| 组分 | 主要功能 |
| --- | --- |
| NaF | 常见丝氨酸/苏氨酸磷酸酶抑制组分 |
| [β-甘油磷酸](β-甘油磷酸.md) | 进一步覆盖 serine/threonine phosphatases |
| [焦磷酸钠](焦磷酸钠.md) | 常作为 phosphate/pyrophosphate 类抑制组分 |
| [原钒酸钠](原钒酸钠.md) | 偏向 tyrosine phosphatases |
| [蛋白酶抑制剂](蛋白酶抑制剂.md) | 保护蛋白完整性，不保护磷酸化状态 |

NaF 很常见，但不要把它当成“磷酸化保护全能试剂”。如果目标是 phospho-tyrosine，仍需要原钒酸钠；如果样本磷酸酶活性很强，商业 cocktail 通常比单独 NaF 更稳。

## 使用 protocol

### 配储液

**怎么做**：常见做法是配成较高浓度水溶液储液，过滤或澄清后分装保存。

**为什么**：NaF 水溶性较好，配成储液后使用方便；但浓度、批号和 pH 环境仍会影响裂解液整体表现。

**注意事项**：

- NaF 有毒，称量和配制时遵守 [SDS与GHS标签](<../实验室安全/SDS与GHS标签.md>)。
- 不要和普通 NaCl 或其他白色粉末混淆。
- 配方中已有商业 phosphatase inhibitor cocktail 时，额外加 NaF 要有明确理由。

### 加入裂解液

**怎么做**：裂解前加入预冷 [RIPA裂解液](RIPA裂解液.md) 或其他裂解液，常与原钒酸钠、β-甘油磷酸、焦磷酸钠合用。

**为什么**：细胞裂解后磷酸酶与底物混合，磷酸化状态可能快速改变；抑制剂应在裂解瞬间存在。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| phospho-ser/thr 信号弱 | NaF 漏加、裂解太慢、刺激条件不稳定 | 现配含抑制剂裂解液，严格计时 |
| phospho-tyrosine 信号仍丢失 | 单独 NaF 覆盖不足 | 加入原钒酸钠或使用广谱 cocktail |
| 同批样本差异大 | 收样顺序和室温暴露时间不同 | 预冷耗材，按固定顺序快速裂解 |
| 安全风险 | NaF 粉末误吸入或误食 | 独立标签、防护称量、专门废液处理 |

## 安全与废液

NaF 属于高风险化学品之一，Sigma-Aldrich S7920 页面和 SDS 标识其具有急性毒性风险。实验中应避免吸入、摄入和皮肤/眼睛接触；含氟废液按实验室化学废液规定处理，不要直接排入水槽。

## 小结

NaF 是 phospho-WB 裂解液里的经典磷酸酶抑制组分，尤其常用于 serine/threonine phosphorylation 保护。但它不等于完整 cocktail，安全风险也不能因为常用而被低估。
