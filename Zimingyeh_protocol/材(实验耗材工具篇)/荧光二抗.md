# 荧光二抗

## 一句话定义

Fluorescent secondary antibody（荧光二抗）是连接了 [荧光染料](荧光染料.md) 的 [二抗](二抗.md)，用于识别一抗并通过特定激发/发射波长产生荧光信号。

荧光二抗常用于 [免疫荧光](<../用(实验流程内容篇)/免疫荧光.md>)、多重免疫染色、fluorescent Western blot（荧光 Western blot）和部分流式/成像实验。与 [HRP标记二抗](HRP标记二抗.md) 不同，荧光二抗不需要 [ECL发光液](<ECL发光液.md>)，而是直接由荧光显微镜或荧光成像仪检测。Thermo Fisher 和 Jackson ImmunoResearch 的二抗选择资料都强调二抗宿主、识别物种、交叉吸附和荧光通道匹配。[参考：Thermo Fisher Secondary Antibody Selection Guide](https://www.thermofisher.com/us/en/home/life-science/antibodies/secondary-antibodies/secondary-antibody-selection-guide.html)；[参考：Jackson ImmunoResearch Secondary Antibody Resource](https://www.jacksonimmuno.com/technical/products/secondary-antibody-resource)

## 命名怎么读

例如：

```text
Donkey anti-mouse IgG Alexa Fluor 488
驴抗小鼠 IgG Alexa Fluor 488 荧光二抗
```

含义是：

| 字段 | 意义 |
| --- | --- |
| Donkey | 二抗由驴产生 |
| anti-mouse | 识别小鼠来源一抗 |
| IgG | 识别 mouse IgG |
| Alexa Fluor 488 | 连接的绿色荧光染料 |

荧光二抗要同时匹配一抗宿主和成像通道。只匹配宿主但通道不合适，仍然无法得到可用图像。

## 常见应用

| 应用 | 说明 |
| --- | --- |
| 免疫荧光 | 检测蛋白在细胞或组织中的定位 |
| 多重染色 | 多个一抗来自不同宿主时，可用不同颜色二抗 |
| 荧光 WB | 多通道检测多个蛋白，动态范围通常更宽 |
| 共定位分析 | 与 [DAPI](DAPI.md)、细胞器标记或其他荧光探针配合 |

## 选择标准

| 检查项 | 说明 |
| --- | --- |
| 一抗宿主 | 二抗必须识别一抗来源物种 |
| 二抗宿主 | 多重实验中常用 donkey/goat 等组合 |
| 荧光染料 | 激发/发射波长要匹配显微镜或成像仪 |
| Cross-adsorbed | 交叉吸附可降低多物种背景 |
| Isotype specificity | 必要时选择 IgG subclass 特异二抗 |
| Brightness and photostability | 亮度和抗淬灭能力影响成像 |
| Species background | 组织来源和内源性 IgG 会影响背景 |

多重 IF 中，不建议多个一抗都来自同一宿主再直接使用普通二抗，否则二抗无法区分不同一抗。除非使用直接标记一抗、序贯染色、Fab fragment block 或其他专门策略。

## 荧光二抗 vs HRP标记二抗

| 维度 | 荧光二抗 | HRP标记二抗 |
| --- | --- | --- |
| 信号来源 | 荧光染料 | 酶催化底物 |
| 是否需要底物 | 不需要 | 需要 ECL/TMB/DAB 等 |
| 多重检测 | 更适合 | 受限 |
| 定量范围 | 通常更宽 | 容易受曝光和底物限制 |
| 保存/操作 | 需要避光 | 关注酶活和底物 |
| 常见问题 | 串色、自发荧光、淬灭 | 高背景、过曝、发光衰减 |

## 使用 protocol

### IF荧光二抗孵育

1. 一抗孵育后，用 PBS 或 PBST 洗涤。
2. 用合适 [抗体稀释液](抗体稀释液.md) 稀释荧光二抗。
3. 室温避光孵育 30-60 min。
4. 避光洗涤 3 次。
5. 需要时加入 DAPI 或其他核染/细胞器标记。
6. 封片并避光保存。

### 荧光WB二抗孵育

1. 使用低荧光膜和适合荧光检测的 [封闭液](封闭液.md)。
2. 二抗孵育全程尽量避光。
3. 洗膜后用荧光成像仪选择对应通道成像。
4. 避免让强通道饱和，以便后续定量。

## 注意事项

- 荧光二抗应避光保存和操作。
- 通道选择要避免 emission bleed-through（发射串色）。
- 多重实验要使用高度交叉吸附二抗。
- 组织样本自发荧光高时，需要设置 unstained、secondary-only 和 autofluorescence controls（自发荧光对照）。
- 荧光 WB 中，奶粉和某些膜可能带来高背景，应选择低荧光体系。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 无荧光 | 二抗不匹配一抗宿主、通道设置错误、荧光淬灭 | 检查二抗命名和显微镜通道 |
| 背景高 | 二抗过浓、封闭不足、组织自发荧光 | 降低二抗，增加封闭，设置对照 |
| 多通道串色 | 荧光染料光谱重叠 | 选择光谱分离更远的染料 |
| 非特异染色 | 二抗交叉反应或 Fc 结合 | 使用交叉吸附二抗和正常血清/Fc block |
| 信号快速变暗 | 光漂白 | 避光操作，使用抗淬灭封片剂 |

## 小结

荧光二抗适合定位、多重检测和更宽动态范围的成像实验。它的关键变量是宿主匹配、荧光通道、交叉吸附、避光操作和对照设计。多重 IF 或荧光 WB 里，二抗设计往往决定实验能不能读得清楚。
