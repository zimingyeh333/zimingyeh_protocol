# 生物素

## 一句话定义

Biotin（生物素，也称 vitamin B7，维生素 B7）是一种小分子维生素，在免疫检测中常被用作标签，因为它能与 [链霉亲和素](链霉亲和素.md) 或 [亲和素](亲和素.md) 发生极高亲和力结合。

在 ELISA、[免疫组化](<../用(实验流程内容篇)/免疫组化.md>)、核酸检测和蛋白检测中，biotin-streptavidin system（生物素-链霉亲和素系统）常用于信号放大、捕获或固定化。Thermo Fisher 和 Vector Laboratories 都把 biotin-avidin/streptavidin 体系作为经典免疫检测和标记平台介绍。[参考：Thermo Fisher Biotin-Binding Proteins](https://www.thermofisher.com/us/en/home/life-science/protein-biology/protein-labeling-crosslinking/biotinylation/biotin-binding-proteins.html)；[参考：Vector Laboratories Avidin-Biotin System](https://vectorlabs.com/pages/avidin-biotin-system)

## 核心特点

| 特点 | 说明 |
| --- | --- |
| 小分子标签 | 对抗体、蛋白、核酸结构影响通常较小 |
| 高亲和力 | 与 streptavidin/avidin 结合非常强 |
| 多价放大 | 一个 streptavidin 可结合多个 biotin |
| 平台丰富 | 可连接 HRP、AP、荧光染料、磁珠或板面 |
| 内源性背景 | 组织或细胞中可能存在内源性 biotin |

生物素体系的优势是灵活和高亲和力，风险是内源性 biotin 和非特异放大也会被一起放大。

## 常见用途

| 用途 | 说明 |
| --- | --- |
| Biotinylated antibody | 生物素化抗体可被 streptavidin-HRP/AP/fluorophore 检测 |
| Biotinylated protein | 用于 pull-down、固定化或相互作用检测 |
| Biotinylated nucleic acid probe | 原位杂交或核酸检测 |
| Streptavidin beads | 用于捕获生物素化分子 |
| ELISA 捕获体系 | biotin-streptavidin 固定化提高方向性和稳定性 |

## 生物素 vs 直接标记

| 方案 | 优点 | 局限 |
| --- | --- | --- |
| 生物素化 + streptavidin 检测 | 灵活、可放大、平台多 | 背景和内源性 biotin 需控制 |
| 直接 HRP/荧光标记抗体 | 步骤少、背景路径少 | 每个抗体都要单独标记 |
| 聚合物检测系统 | IHC 中常见，灵敏度高 | 体系更固定，成本较高 |

如果实验只需要简单 WB 或 IF，直接二抗往往更简单；如果需要捕获、放大或模块化检测，生物素体系更有价值。

## 使用注意事项

- IHC 中很多组织有 endogenous biotin（内源性生物素），可能需要 biotin blocking step（生物素阻断）。
- 生物素化程度过高可能影响抗体或蛋白活性。
- 使用 biotin-streptavidin 体系时，要确认封闭液中没有会干扰体系的成分。
- 某些 [脱脂奶粉](脱脂奶粉.md) 或复杂封闭剂可能不适合 biotin/streptavidin 检测。
- 记录是否使用了 biotinylated reagent（生物素化试剂），否则后续排查背景很困难。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| IHC 背景高 | 内源性 biotin 未阻断 | 加入 biotin/avidin blocking step |
| 信号弱 | 生物素化不足或 streptavidin 试剂失效 | 检查标记效率和阳性对照 |
| 非特异放大 | 洗涤不足或 streptavidin 过浓 | 增加洗涤，降低 streptavidin 试剂浓度 |
| 捕获效率低 | 生物素化位点遮挡或亲和素载体不合适 | 优化标记位点和捕获条件 |
| 批次不可比 | 生物素化程度不同 | 记录 degree of labeling（标记程度） |

## 小结

生物素是免疫检测和分子捕获中的强力标签。它的价值在于和 streptavidin/avidin 的高亲和结合带来灵活放大；它的风险也来自这种放大能力。使用生物素体系时，必须记录生物素化试剂、检测试剂、阻断策略和背景对照。
