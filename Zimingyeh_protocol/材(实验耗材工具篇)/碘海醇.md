# 碘海醇

Iohexol（碘海醇）是一种 non-ionic iodinated compound（非离子碘化化合物），在实验室密度梯度语境中主要对应 [Nycodenz](Nycodenz.md) 这类 iohexol-based density gradient medium（基于碘海醇的密度梯度介质）。它在医学中也是 X-ray contrast agent（X 线造影剂）相关分子，但在本知识库里重点放在它如何支持自定义密度梯度。

![OptiPrep 和 Nycodenz 碘化密度梯度介质示意图](../z_asset/材/密度梯度介质/iodinated-density-gradient-media-optiprep-nycodenz.png)

## 定义与命名

Iohexol 的中文名是碘海醇。PubChem 将其列为 non-ionic, water-soluble contrast agent（非离子、水溶性造影剂），分子式为 C19H26I3N3O9，分子量约 821.1 g/mol。参考：[PubChem Iohexol](https://pubchem.ncbi.nlm.nih.gov/compound/Iohexol)。

在密度梯度实验中，碘海醇最常见的商品入口是 Nycodenz。Serumwerk/Axis-Shield 的 Nycodenz 产品页说明 Nycodenz 是 off-white powder（类白色粉末），可自由溶于水，可配制高浓度溶液，并用于分离细胞、亚细胞细胞器、膜、蛋白复合物和病毒等材料。参考：[Serumwerk Nycodenz](https://diagnostic.serumwerk.com/products/nycodenz/)。

## 为什么能做密度梯度

| 结构/性质 | 对密度梯度的意义 |
| --- | --- |
| 分子含 3 个 iodine atoms（碘原子） | 提供较高溶液密度 |
| 非离子 | 对离子强度干扰较小 |
| 多个羟基和酰胺基 | 增强水溶性，便于配制水相梯度 |
| 形成 true solution（真溶液） | 与颗粒型介质不同，后续移除方式更灵活 |
| 可自配浓度 | 适合特殊密度窗口和方法开发 |

碘海醇/Nycodenz 的核心优势是可自定义。它适合想主动设计梯度的人，而不是想使用固定密度即用液的人。

## 和 Nycodenz 的关系

| 名称 | 本质 | 使用层级 |
| --- | --- | --- |
| 碘海醇 | 化学成分/分子 | 理解密度、溶解性和化学性质 |
| Nycodenz | 碘海醇相关商业密度梯度介质 | 采购、称量和配制 |
| Nycodenz gradient | 按目标密度配出的连续或不连续梯度 | 具体 protocol 条件 |

实验记录中最好写 Nycodenz 的产品信息，而不是只写“iohexol”。因为密度梯度实验依赖商品规格、批号、称量、储备液浓度、buffer 和实际密度。

## 主要用途

| 用途 | 典型场景 |
| --- | --- |
| [密度梯度离心](<../用(实验流程内容篇)/密度梯度离心.md>) | 制备自定义连续或不连续梯度 |
| [细胞器分离](<../用(实验流程内容篇)/细胞器分离.md>) | 分离细胞器、膜组分或亚细胞颗粒 |
| [病毒纯化](<../用(实验流程内容篇)/病毒纯化.md>) | 按浮力密度富集病毒颗粒 |
| 蛋白复合物或核糖核蛋白分离 | 利用密度差异进行颗粒级分离 |
| 文献复现 | 某些经典 protocol 指定 Nycodenz 梯度 |

如果实验目标是常规 peripheral blood mononuclear cells（PBMC，外周血单个核细胞）分离，碘海醇/Nycodenz 通常不是最省心的选择；它更适合需要自定义梯度的分离问题。

## 碘海醇 vs 碘克沙醇

| 项目 | 碘海醇 | [碘克沙醇](碘克沙醇.md) |
| --- | --- | --- |
| 英文名 | iohexol | iodixanol |
| 分子类型 | 单体非离子碘化分子 | 二聚体非离子碘化分子 |
| 分子式 | C19H26I3N3O9 | C35H44I6N6O15 |
| 分子量 | 约 821.1 g/mol | 约 1550.2 g/mol |
| 密度梯度商品 | Nycodenz | OptiPrep |
| 常见实验形态 | 粉末/自配储备液 | 60% w/v 无菌储备液 |
| 使用感 | 更灵活，但配制变量更多 | 更方便，适合快速建立等渗梯度 |

不要因为二者都是非离子碘化介质，就把 OptiPrep 的百分比直接套到 Nycodenz 上。相同百分比不代表相同密度、黏度、渗透压或分离效果。

## 配制与使用注意事项

| 注意点 | 原因 | 建议 |
| --- | --- | --- |
| 称量和定容要准确 | 直接决定最终密度 | 记录粉末质量、终体积和计算浓度 |
| 完全溶解后再使用 | 未溶解颗粒会造成局部密度异常 | 充分混匀，必要时过滤 |
| 关注渗透压 | 活细胞和细胞器敏感 | 关键实验记录 [osmolality（渗透压）](<../番外/补充知识/渗透压.md>) |
| 可用折光率辅助判断密度 | Nycodenz 密度可通过折光率估算 | 记录 [refractive index（RI，折光率）](<../番外/补充知识/折光率.md>)、温度和参考表 |
| 区分临床制剂和实验介质 | 临床 iohexol 注射液不等于 Nycodenz 粉末 | 密度梯度实验使用标注用途的实验产品 |
| 记录去除方式 | 残留可能影响下游检测 | 设计 dialysis、ultrafiltration、gel filtration 或洗涤步骤 |

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 梯度密度不稳定 | 称量错误、定容不准、未完全溶解 | 重新配制并记录质量/体积 |
| band 模糊 | 层间混合、离心条件不合适 | 缓慢分层，优化 x g、时间和 brake |
| 活细胞状态差 | 渗透压或 pH 不适合 | 复核 buffer，必要时测渗透压 |
| 文献复现差 | 没写清 Nycodenz 来源和配制方式 | 补全货号、批号、浓度、buffer、转子 |
| 下游测定异常 | 介质残留或 fraction 污染 | 增加换液、透析或分段 marker 检测 |
| 误替代 OptiPrep | 把 iohexol 和 iodixanol 当成同一物 | 重新按 Nycodenz 条件设计梯度 |

## 小结

碘海醇是理解 Nycodenz 的核心。它提供非离子、含碘、水溶和可自配密度梯度的化学基础，适合方法开发和特殊颗粒分离。使用时不要只记录“iohexol”或“Nycodenz”，而要写清粉末质量、储备液浓度、buffer、密度、渗透压、折光率和离心条件。
