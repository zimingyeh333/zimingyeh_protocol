# B27补充剂

B27补充剂（B-27 Supplement，B-27 神经细胞培养补充剂）是经典 serum-free neuronal culture supplement（无血清神经细胞培养补充剂），常用于 primary neurons（原代神经元）、neural stem cells（神经干细胞）、PSC-derived neurons（多能干细胞来源神经元）和部分 3D culture（3D 培养）体系。

![专用细胞培养基参考图](../z_asset/材/专用细胞培养基/specialized-cell-culture-media-reference.png)

图源：Image2 生成的专用细胞培养基参考图；B27/N2 位于 serum-free step 的神经和干细胞补充剂层。

## 核心定位

Thermo Fisher 的 B-27 Supplement 页面说明，B-27 supplement 最初由 Gregory Brewer 设计并优化，用于提高原代神经元体外培养存活；Gibco B-27 成为首个商业化无血清神经元培养补充剂，并被广泛用于神经干细胞、PSC-derived neurons、3D 培养和疾病模型。参考：[Thermo Fisher B-27 Supplement](https://www.thermofisher.com/us/en/home/brands/gibco/gibco-b-27-supplement.html)。

B27 通常与 [Neurobasal培养基](Neurobasal培养基.md)、[DMEM-F12](DMEM-F12.md)、[N2补充剂](N2补充剂.md)、[生长因子](生长因子.md) 和特定基质共同使用。它不是普通细胞培养里的“增强版 FBS”，而是为神经相关体系设计的复杂 supplement。

## 常见版本

| 版本 | 常见用途 | 选择逻辑 |
| --- | --- | --- |
| B-27 Supplement | 神经元分化、维持和成熟 | 标准起点 |
| B-27 Plus | 长期神经元培养、成熟和网络活动 | 更偏优化系统 |
| B-27 without Vitamin A | 神经干细胞增殖、避免维 A 诱导分化 | neurosphere/NSC 常见 |
| B-27 without insulin | 胰岛素信号或胰岛素受体相关研究 | 避免 insulin 干扰 |
| B-27 without antioxidants | 氧化应激、自由基损伤研究 | 避免抗氧化成分掩盖效应 |
| CTS B-27 XenoFree | 细胞治疗和转化研究 | 更强调 xeno-free/GMP 逻辑 |

Thermo Fisher 的 B-27 页面列出不同 B-27 版本与 primary neurons、neural stem cells、PSC-derived neurons、oxidative stress、insulin receptor 和 electrophysiology 等应用的选择关系。参考：[Thermo Fisher B-27 Supplement](https://www.thermofisher.com/us/en/home/brands/gibco/gibco-b-27-supplement.html)。

## B27 vs N2

| 项目 | B27 | N2 |
| --- | --- | --- |
| 复杂度 | 更复杂 | 相对更简单 |
| 历史设计 | 原代神经元长期存活 | 神经母细胞瘤和神经相关无血清培养 |
| 常见用途 | 神经元维持、成熟、PSC-derived neurons、3D 模型 | neural progenitor、neurosphere、与 B27 组合 |
| 变量风险 | 版本很多，成分复杂 | 成分较少但仍影响信号 |

许多神经和类器官 protocol 会同时使用 N2 + B27，因为两者承担的支持层不完全相同。

## 使用 protocol

### 加入培养基

**怎么做**：B27 常见为 50X 储液，按 1:50 加入基础培养基。具体比例以产品说明书和 protocol 为准。

**为什么**：B27 是复杂混合物，厂家预设浓度和比例；自行拆分或稀释偏差会影响细胞状态。

**注意事项**：

- 按说明 2-8°C 保存，避免反复温度波动。
- 选择版本时先看实验目的：增殖、分化、成熟、氧化应激、胰岛素信号不是同一逻辑。
- B27 含复杂蛋白、维生素、脂肪酸和抗氧化相关成分；做代谢、WB、分泌物或氧化应激实验时要把它当作变量。

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| NSC提前分化 | 使用含 vitamin A 版本或生长因子条件不合适 | 使用 without Vitamin A 版本并检查 EGF/FGF2 |
| 氧化应激结果被压低 | B27 抗氧化成分干扰 | 选择 without antioxidants 版本 |
| 胰岛素信号异常 | B27 中 insulin 影响 readout | 使用 without insulin 版本 |
| 神经元存活差 | B27版本、基质或培养基不匹配 | 核对 Neurobasal/DMEM-F12 和包被 |

## 小结

B27 是神经相关无血清培养里非常核心的补充剂，但它不是单一成分。选择 B27 时要看清版本，因为 vitamin A、insulin 和 antioxidants 这些成分会直接改变分化、信号和应激 readout。
