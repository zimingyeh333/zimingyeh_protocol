# 重组蛋白

Recombinant protein（重组蛋白）是通过 recombinant DNA technology（重组 DNA 技术）在细胞或无细胞表达系统中生产的蛋白，常用作 [ELISA](<../用(实验流程内容篇)/ELISA.md>) 的 [标准品](标准品.md)、抗体筛选抗原、功能实验刺激因子或阳性对照。

## 常见用途

| 用途 | 例子 | 关键要求 |
| --- | --- | --- |
| ELISA 标准品 | 用已知浓度重组细胞因子建立标准曲线 | 浓度准确、稳定、与抗体识别一致 |
| 抗体筛选 | 测试抗体是否识别目标抗原 | 构象和表位暴露要合理 |
| 免疫原 | 用于制备抗体 | 纯度、免疫原性和标签位置要考虑 |
| 功能实验 | 作为细胞刺激因子或配体 | 生物活性、内毒素水平、载体蛋白很重要 |
| 阳性对照 | 验证检测体系能工作 | 浓度范围和批间稳定性要清楚 |

R&D Systems 和 BioLegend 的 ELISA protocol 都把标准品梯度作为定量 ELISA 的核心步骤；很多标准品本质上就是厂家校准过的 recombinant protein 或相关校准品。参考：[R&D Systems ELISA protocols](https://www.rndsystems.com/resources/protocols)；[BioLegend sandwich ELISA protocol](https://www.biolegend.com/en-us/protocols/sandwich-elisa-protocol)。

## 表达系统差异

重组蛋白不是一个统一质量等级。表达系统会影响折叠、糖基化、修饰、内毒素和功能。

| 表达系统 | 优点 | 风险 |
| --- | --- | --- |
| E. coli（大肠杆菌） | 成本低、产量高、无哺乳动物糖基化 | 包涵体、缺少糖基化、内毒素风险 |
| yeast（酵母） | 可分泌表达，有部分真核修饰 | 糖基化模式和哺乳动物不同 |
| insect cells（昆虫细胞） | 适合复杂蛋白，折叠较好 | 糖基化仍不同于哺乳动物 |
| mammalian cells（哺乳动物细胞） | 更接近天然修饰和构象 | 成本高，批间控制更重要 |
| cell-free system（无细胞表达） | 快速，适合特殊蛋白 | 产量和修饰有限 |

如果重组蛋白用于标准曲线，最重要的是“被当前抗体体系稳定识别”；如果用于功能刺激，最重要的是“具有正确生物活性”。

## 标签和构建形式

常见标签包括 His-tag、Fc-tag、GST-tag、FLAG-tag 等。标签能帮助纯化和检测，但也可能改变蛋白构象、聚集状态或受体结合。

| 构建形式 | 优点 | 注意事项 |
| --- | --- | --- |
| tag-free protein | 更接近天然蛋白 | 纯化和检测可能更难 |
| His-tag protein | 纯化方便，标签较小 | 标签位置可能影响表位 |
| Fc fusion protein | 稳定性高，半衰期长 | 二聚化和 Fc 受体结合可能影响功能 |
| GST fusion protein | 可提高可溶性 | 标签较大，可能影响构象 |
| truncated protein | 表达容易，适合特定结构域 | 可能缺失天然表位或功能域 |

在 [配对抗体](配对抗体.md) 筛选时，如果抗体识别的表位位于标签附近，标签位置可能导致假阴性或假阳性判断。

## 作为 ELISA 标准品的注意事项

标准品用途下，重组蛋白的浓度和复溶比“看起来有蛋白”更重要。

关键点：

- 按说明书用指定液体复溶，不要随意用纯水或 PBS 替代。
- 复溶后给足静置时间，让冻干粉完全水合。
- 分装保存，避免反复冻融。
- 使用低吸附管，尤其是低浓度细胞因子。
- 做标准曲线时逐级稀释并充分混匀。
- 不同厂家标准品不能随意替换，因为校准、纯度、构象和赋值方法可能不同。

如果标准曲线正常但真实样本回收率差，需要考虑 recombinant standard 与天然样本中的目标物是否存在基质、修饰或复合物状态差异。

## 作为功能实验试剂的注意事项

功能实验更关心 biological activity（生物活性）和 endotoxin level（内毒素水平）。

例如细胞刺激实验中，低质量重组蛋白可能因为内毒素污染诱导炎症反应，使结果看起来像目标蛋白有效；也可能因为折叠或修饰不正确而没有活性。用于免疫细胞、干细胞或受体信号实验时，要优先选择标注低内毒素、活性单位和验证体系的产品。

## 和天然蛋白、合成肽的区别

| 材料 | 优点 | 局限 |
| --- | --- | --- |
| 重组蛋白 | 可规模化、浓度可控、适合标准品 | 不一定有天然修饰或天然构象 |
| purified native protein（纯化天然蛋白） | 更接近真实生物状态 | 来源有限、批间差异和杂质风险 |
| synthetic peptide（合成肽） | 适合线性表位和短片段 | 不代表完整蛋白构象 |
| cell lysate（细胞裂解液） | 含天然复合物背景 | 成分复杂，不适合作绝对标准品 |

## 常见异常与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 标准曲线低或无信号 | 复溶错误、蛋白降解、抗体不识别该构建 | 换复溶条件，检查标签/物种/片段 |
| 低浓度点波动大 | 吸附损失或混匀不足 | 使用载体蛋白和低吸附管，逐级稀释 |
| 功能实验无效 | 蛋白无活性、错误修饰、受体不表达 | 换表达系统，加入阳性对照 |
| 功能实验假阳性 | 内毒素污染或载体成分影响 | 使用低内毒素产品，设载体对照 |
| 不同批次差异大 | 赋值、纯度或活性不同 | 做批次桥接，不直接混用标准曲线 |

## 购买建议

用于 ELISA 标准品时，优先使用 kit 配套标准品；如果必须外购重组蛋白，选择与抗体 pair 同厂家或明确验证兼容的产品。

用于细胞功能实验时，重点看表达系统、物种、活性单位、纯度、内毒素水平、复溶方案和载体成分。对于细胞因子、生长因子等敏感实验，不要只按价格选择。

## 小结

重组蛋白是标准曲线和抗体筛选里非常好用的材料，但它不是天然蛋白的完美替身。做定量时关注赋值和稳定性，做功能实验时关注活性和内毒素，做抗体筛选时关注构象、表位和标签位置。
