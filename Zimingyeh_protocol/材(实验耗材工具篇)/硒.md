# 硒

硒（selenium，Se；细胞培养中常以 sodium selenite，亚硒酸钠形式加入）是细胞培养中的 trace element（微量元素），也是 [ITS补充剂](ITS补充剂.md) 的核心成分之一。它常用于无血清和定义培养体系，支持抗氧化和细胞存活相关功能。

![培养支持分子参考图](../z_asset/材/培养支持分子/culture-support-molecules-reference.png)

图源：Image2 生成的培养支持分子参考图；硒位于 ITS core components 模块，代表微量元素支持。

## 核心作用

硒是多种 selenoproteins（硒蛋白）的组成元素，其中包括 glutathione peroxidases（谷胱甘肽过氧化物酶）等抗氧化相关酶。细胞培养中通常不直接加入元素硒，而是加入 sodium selenite 或通过 ITS 预混液提供。Thermo Fisher 的 ITS-G Select Supplement User Guide 将 sodium selenite 列为 ITS-G 组分之一，并作为 100X supplement 用于基础培养基补充。参考：[Gibco ITS-G Select Supplement User Guide](https://assets.thermofisher.com/TFS-Assets/LSG/manuals/MAN1000664-InsulinTransferrinSeleniumSelectSupplement-UG.pdf)。

硒是“需要很少，但过量有风险”的成分。记录时应写终浓度或所用 ITS 倍数，而不是只写“加了微量元素”。

## 常见形式

| 形式 | 英文 | 说明 |
| --- | --- | --- |
| Sodium selenite | 亚硒酸钠 | 细胞培养中最常见硒来源 |
| ITS中的selenium | ITS selenium component | 方便、比例固定 |
| Trace element mix | 微量元素混合物 | 常见于 defined medium 或 CHO/生产体系 |

## 为什么要注意剂量

| 情况 | 可能影响 |
| --- | --- |
| 缺硒 | 抗氧化支持不足，细胞状态下降 |
| 适量硒 | 支持硒蛋白、抗氧化和细胞存活 |
| 过量硒 | 可能产生毒性或改变氧化还原背景 |
| 未记录硒来源 | 无法解释 ROS、代谢和存活差异 |

## 与胰岛素/转铁蛋白的关系

| 成分 | 主要作用 |
| --- | --- |
| [胰岛素](胰岛素.md) | 代谢和生长信号 |
| [转铁蛋白](转铁蛋白.md) | 铁转运 |
| 硒 | 微量元素和抗氧化相关支持 |

ITS 的三个成分解决的是不同问题，不能互相替代。

## 使用 protocol

### 通过ITS补加

**怎么做**：使用 ITS 按推荐倍数加入培养基。

**为什么**：多数无血清体系中，硒通过 ITS 固定比例提供，减少单独配制微量硒的误差。

### 单独补加

**怎么做**：若使用 sodium selenite 单品，应按 protocol 配制高倍储液，再按微量加入，避免称量和稀释误差。

**为什么**：硒类化合物有效浓度低，过量风险明显。

**注意事项**：

- 单独配制 sodium selenite 时要按 [化学品安全](<../实验室安全/化学品安全.md>) 和 SDS 操作。
- 不要把不同 trace element mix 直接等同。
- 做氧化应激、ROS、线粒体或代谢实验时，硒是背景变量。

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 无血清体系细胞状态差 | 缺少 ITS/selenium 支持 | 补充 ITS 或微量元素 |
| 细胞毒性 | sodium selenite 过量或稀释错误 | 重新配制，设置剂量梯度 |
| ROS实验不可重复 | 硒来源或浓度变化 | 固定 ITS/selenium 条件 |
| 配方记录不清 | 只写 trace element | 写清 selenium 来源和浓度 |

## 小结

硒是无血清和定义培养基里的微量但重要变量。它通常通过 ITS 或微量元素混合物加入，关键在于剂量、来源和是否影响氧化还原背景。
