# 甘氨酸

Glycine（甘氨酸）是最简单的氨基酸，也是 [SDS-PAGE](<../用(实验流程内容篇)/SDS-PAGE.md>) 运行缓冲液和 [Western blot](<../用(实验流程内容篇)/Western blot.md>) 转膜缓冲液中的经典组分之一。它在这里不是营养成分，而是参与离子迁移和电泳分离逻辑的 buffer component（缓冲体系组分）。

![WB缓冲体系基础试剂参考图](../z_asset/材/WB缓冲体系基础试剂/wb-buffer-core-reagents-reference.png)

图源：Image2 生成的 WB/SDS-PAGE 缓冲体系基础试剂参考图；Glycine 位于上排第二瓶，底部示意它主要进入 running buffer（运行缓冲液）和 transfer buffer（转膜缓冲液）。

## 在SDS-PAGE中的角色

经典 Laemmli SDS-PAGE 使用 discontinuous buffer system（不连续缓冲系统）。在 stacking gel（浓缩胶）阶段，氯离子作为 leading ion（前导离子），甘氨酸在较低 pH 下迁移较慢，样本蛋白被压缩成窄带；进入 resolving gel（分离胶）后，pH 升高，甘氨酸带负电并加速迁移，蛋白开始按分子量分离。

这就是为什么 running buffer 中甘氨酸浓度配错时，条带会变宽、拖尾、跑歪或分辨率下降。

Bio-Rad 的 buffer formulation 资料列出常见 10x SDS-PAGE running buffer 为 250 mM Tris、1.92 M glycine、1% SDS，pH 8.3；稀释到 1x 后用于常规 Tris-Glycine SDS-PAGE。参考：[Bio-Rad Buffer Formulations PDF](https://www.bio-rad.com/webroot/web/pdf/lsr/literature/Bulletin_6199.pdf)。

## 在转膜中的角色

在 [转膜缓冲液](转膜缓冲液.md) 中，甘氨酸和 [Tris](Tris.md) 提供电转移需要的离子环境，[甲醇](甲醇.md) 则影响膜结合、凝胶收缩和 SDS 去除。Cell Signaling Technology 的 Tris-Glycine Transfer Buffer 页面给出 1 L 1x 转膜缓冲液的典型配法：100 mL 10x transfer buffer、200 mL methanol、700 mL ddH2O，并说明用于蛋白从 SDS-PAGE 胶转移到 NC 或 PVDF 膜。参考：[CST Tris-Glycine Transfer Buffer](https://www.cellsignal.com/products/buffers-dyes/tris-glycine-transfer-buffer-10x/12539)。

## 甘氨酸 vs Tris vs SDS

| 组分 | 主要作用 | 缺失或错误时的常见后果 |
| --- | --- | --- |
| [Tris](Tris.md) | 建立 pH 和缓冲环境 | 迁移异常、pH 不对、转膜效率变化 |
| 甘氨酸 | 不连续电泳体系中的 trailing ion（尾随离子），也参与转膜导电 | 条带压缩差、分辨率差、转膜异常 |
| [SDS](十二烷基硫酸钠.md) | 使蛋白变性并带负电 | 蛋白迁移不按分子量、条带异常 |
| [甲醇](甲醇.md) | 转膜中帮助蛋白固定到膜并影响 SDS 去除 | 小/大蛋白转移效率改变 |

## 使用与配制要点

### 配SDS-PAGE running buffer

**怎么做**：常见 10x stock 为 Tris/Glycine/SDS，使用前稀释到 1x。也可分别称量 Tris、甘氨酸和 SDS 自配。

**为什么**：running buffer 的离子强度直接影响电流和发热；过浓会发热，过稀会跑得慢或分离差。

**注意事项**：

- 不要把 Tris/Glycine buffer 和 Tris/Glycine/SDS buffer 混淆。
- 用于 native PAGE（天然胶）时通常不加 SDS。
- 10x stock 若出现明显沉淀、污染、pH 异常，应谨慎使用。

### 配transfer buffer

**怎么做**：按对应系统说明书稀释 Tris-Glycine transfer buffer，再加入规定比例甲醇。

**为什么**：转膜 buffer 的甘氨酸浓度、电导和甲醇比例共同影响蛋白迁移。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 条带很宽 | 甘氨酸/Tris running buffer 配错，浓缩效果差 | 换新 running buffer |
| 电泳发热明显 | 10x 稀释不足或离子强度过高 | 重新配 1x，降低电压 |
| native PAGE 跑成变性条件 | 误用了含 SDS 的 Tris/Glycine/SDS | 核对 buffer 标签 |
| 转膜弱 | transfer buffer 配方不对或甲醇漏加 | 按说明书重配 |

## 小结

甘氨酸在 WB 相关实验里最重要的身份是“电泳和转膜缓冲体系的迁移控制者”。它看起来普通，但一旦配错，最先表现出来的往往就是条带不锐、发热、电泳速度异常或转膜效率不稳定。
