# E-64

E-64（trans-epoxysuccinyl-L-leucylamido(4-guanidino)butane，反式环氧琥珀酰-L-亮氨酰胺基(4-胍基)丁烷）是一种不可逆 cysteine protease inhibitor（半胱氨酸蛋白酶抑制剂），常用于抑制 papain-like cysteine proteases（木瓜蛋白酶样半胱氨酸蛋白酶）和 cathepsin B/H/L 等组织蛋白酶。

![蛋白酶抑制剂成分参考图](../z_asset/材/蛋白酶抑制剂成分/protease-inhibitor-components-reference.png)

图源：Image2 生成的蛋白酶抑制剂成分参考图；E-64 位于下方中央，主要对应 cysteine proteases（半胱氨酸蛋白酶）。

## 核心作用

E-64 的 epoxide（环氧基）可与半胱氨酸蛋白酶活性中心的半胱氨酸反应，形成不可逆抑制。它常用于细胞裂解、组织样本处理、溶酶体/自噬相关研究和蛋白酶机制实验。

Sigma-Aldrich 的 E-64 产品资料将其描述为 irreversible cysteine protease inhibitor（不可逆半胱氨酸蛋白酶抑制剂），可抑制 papain、cathepsin B、cathepsin H、cathepsin L 等。参考：[Sigma-Aldrich E-64 E3132](https://www.sigmaaldrich.com/US/en/product/sigma/e3132)。

## 和Leupeptin的关系

| 项目 | E-64 | Leupeptin |
| --- | --- | --- |
| 抑制类型 | 不可逆 | 多为可逆 |
| 主要靶点 | 半胱氨酸蛋白酶 | 半胱氨酸蛋白酶 + 部分丝氨酸蛋白酶 |
| 适合用途 | cysteine protease 靶向保护或机制实验 | 广谱 cocktail 成分 |
| 不能覆盖 | 丝氨酸/天冬氨酸/金属蛋白酶 | 天冬氨酸/金属蛋白酶 |

如果只想做常规 WB 样本保护，Leupeptin 和 E-64 往往作为 cocktail 的一部分出现；如果研究 cathepsin 或 cysteine protease 相关机制，E-64 的不可逆抑制特性更有价值。

## 常见使用场景

| 场景 | 用途 | 注意点 |
| --- | --- | --- |
| [Western blot](<../用(实验流程内容篇)/Western blot.md>) 裂解 | 减少 cysteine protease 降解 | 仍需和其他抑制剂合用 |
| 溶酶体/自噬研究 | 抑制 cathepsin 相关降解 | 可能改变通路状态，实验设计要谨慎 |
| 组织匀浆 | 保护易被 cathepsin 剪切的蛋白 | 低温快速处理仍必要 |
| 蛋白酶机制实验 | 选择性抑制 cysteine protease | 需要设置阴性/阳性对照 |

## 使用 protocol

### 配储液

**怎么做**：按说明书用水、DMSO 或合适 buffer 配成 stock solution，小分装低温保存。

**为什么**：不同 E-64 产品盐形式、溶解性和推荐储存条件可能不同；按厂家说明比凭经验更可靠。

**注意事项**：

- 记录是否为 E-64、E-64d 或其他细胞通透性衍生物。
- 体外裂解保护和活细胞处理不是同一个实验逻辑。
- 若用于活细胞，需确认细胞通透性和毒性。

### 加入裂解液

**怎么做**：裂解前加入预冷 [RIPA裂解液](RIPA裂解液.md) 或其他裂解液，常与 [PMSF](PMSF.md)、[Aprotinin](Aprotinin.md)、[Leupeptin](Leupeptin.md)、[Pepstatin A](<Pepstatin A.md>) 合用。

**为什么**：E-64 只覆盖半胱氨酸蛋白酶，不能替代完整 protease inhibitor cocktail。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| WB 仍有降解碎片 | 蛋白酶类型不止 cysteine protease | 加广谱 cocktail |
| 活细胞实验无效 | 使用的是不适合细胞进入的形式 | 确认是否需要 E-64d 等衍生物 |
| 结果影响通路解释 | E-64 改变溶酶体降解过程 | 设置处理对照和时间梯度 |
| 储液不稳定 | 保存条件或溶剂不合适 | 按说明书小分装保存 |

## 小结

E-64 是半胱氨酸蛋白酶方向的强力补充，尤其适合 cathepsin 相关样本保护或机制实验。但做常规 WB 时，它通常是 cocktail 中的一块拼图，而不是单独解决所有蛋白降解问题的答案。
