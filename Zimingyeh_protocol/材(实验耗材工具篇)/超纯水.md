# 超纯水

Ultrapure water（UPW，超纯水）是经过多级纯化、离子和有机物背景极低的实验用水。生物实验里常说的 Milli-Q water（Milli-Q 水）通常指由 [MilliporeSigma](<../番外/试剂厂商/MilliporeSigma.md>) / Merck 的 Milli-Q 系统制备的 Type I ultrapure water（I 级超纯水），其典型电阻率可达 18.2 MΩ·cm at 25°C。

## 核心概念

超纯水的核心不是“看起来干净”，而是尽量降低离子、有机物、颗粒、微生物和实验抑制物背景。不同实验关心的污染类型不同：

| 指标 | 英文 | 为什么重要 |
| --- | --- | --- |
| 电阻率 / 电导率 | resistivity / [conductivity](<../番外/补充知识/电导率.md>) | 反映离子污染水平 |
| 总有机碳 | total organic carbon, [TOC](<../番外/补充知识/总有机碳.md>) | 反映有机物背景，影响 LC-MS、细胞和痕量分析 |
| 微生物 | bacteria / bioburden | 影响细胞培养、保存和污染风险 |
| 内毒素 | [endotoxin](<../番外/补充知识/内毒素.md>) | 免疫细胞、原代细胞和炎症实验尤其敏感 |
| 核酸酶 | DNase / RNase | 影响 RNA、PCR、qPCR 和测序建库 |
| 颗粒物 | particles | 影响仪器、过滤、色谱和显微操作 |

Merck 对 Milli-Q 超纯水系统的介绍中，将 Type I 超纯水和 18.2 MΩ·cm at 25°C 作为核心水质指标之一。参考：[Merck Milli-Q ultrapure water systems](https://www.sigmaaldrich.com/US/en/products/lab-water-systems/ultrapure-water-systems)。

## 超纯水 vs 常见实验用水

| 类型 | 重点 | 常见用途 | 不能默认替代的场景 |
| --- | --- | --- | --- |
| 超纯水 | 极低离子和有机背景 | 缓冲液配制、仪器冲洗、痕量分析 | 不等于无菌、无内毒素或无核酸酶 |
| [去离子水](去离子水.md) | 去除大部分离子 | 常规清洗、普通溶液 | 痕量分析、RNA、细胞敏感实验 |
| [蒸馏水](蒸馏水.md) | 通过蒸馏降低盐和杂质 | 普通试剂配制、清洗 | 高纯度分析或无核酸酶实验 |
| [反渗透水](反渗透水.md) | 预纯化水 | 水系统前端、清洗 | 通常不是终端实验水 |
| [无菌水](无菌水.md) | 微生物风险低 | 无菌配液、细胞相关操作 | 不一定低离子、低 TOC 或无核酸酶 |
| [无核酸酶水](无核酸酶水.md) | DNase/RNase 风险低 | RNA、PCR、qPCR、引物复溶 | 不一定适合电化学或痕量分析 |

最常见的误区是把“超纯水”“无菌水”“无核酸酶水”当成同一个东西。它们的质控目标不同，选择时应该从实验风险倒推，而不是只看名字。

## 主要用途

### 缓冲液和试剂配制

配制 [PBS](PBS.md)、[pH缓冲液](pH缓冲液.md)、盐溶液、染色液和普通生化 buffer 时，超纯水可以降低离子和有机背景。若后续用于细胞或无菌体系，还需要过滤除菌、高压灭菌或直接购买无菌级产品。

### 仪器冲洗和背景控制

[pH计](pH计.md)、[电导率仪](电导率仪.md)、分光光度计 cuvette、色谱瓶和痕量分析容器常用超纯水冲洗。冲洗的意义不是“消毒”，而是减少前一个样品的离子、有机物或颗粒残留。

### 分子生物学

PCR、qPCR、逆转录、RNA 溶解和引物复溶通常应优先使用无核酸酶水，而不是水系统刚接出来的普通超纯水。即使超纯水离子很低，也不能保证没有 RNase、DNase 或外源 DNA 污染。

### 细胞培养相关操作

配制 [培养基](培养基.md)、平衡盐溶液或细胞处理液时，需要关注无菌、内毒素和适用等级。超纯水可以作为配制前端水源，但最终用于细胞的液体通常还需要经过无菌过滤、灭菌或直接购买 cell culture grade（细胞培养级）产品。

### 色谱和质谱

HPLC（high-performance liquid chromatography，高效液相色谱）和 LC-MS（liquid chromatography-mass spectrometry，液相色谱-质谱联用）非常关心 TOC、离子和颗粒背景。普通超纯水不一定等同于 LC-MS grade water（LC-MS 级水），正式实验应按方法要求购买专用级别水或溶剂。

## 使用和取水 protocol

### 取水前

- 确认水系统状态正常，电阻率、TOC 或维护提示没有异常。
- 若系统长时间未使用，按平台要求先放水冲洗管路。
- 使用洁净、匹配用途的容器；痕量分析、细胞实验和分子实验不要混用同一类瓶子。

### 取水时

1. 打开出水口，先排出一小段水。
2. 避免容器口接触出水口。
3. 需要低 TOC 或低离子背景时，尽量现取现用。
4. 取完后立即盖紧容器。
5. 在记录中写明水源、取水时间、使用用途和是否经过后续灭菌。

### 取水后

超纯水暴露在空气中会吸收 CO2，使电导率升高、pH 读数漂移；长时间存放还可能出现容器析出、微生物增长或颗粒污染。因此一般不建议把超纯水长期存放后用于敏感实验。

## 为什么超纯水的 pH 不好测

超纯水离子强度极低，缓冲能力几乎没有。它接触空气后会快速吸收 CO2，形成少量碳酸，使 pH 向酸性方向漂移。同时，由于导电离子少，普通玻璃电极在超纯水中响应慢、读数不稳定。

所以看到“超纯水 pH 不是 7”并不一定代表水质严重异常。判断超纯水质量时，电阻率、电导率、TOC、微生物和应用测试通常比直接测 pH 更有意义。

## 选择和购买

如果实验室自己有水系统，记录重点应包括：

- 水系统品牌和型号。
- 终端滤芯、UV lamp、RO membrane、polishing cartridge 的维护状态。
- 出水电阻率或电导率。
- TOC 读数或定期检测结果。
- 是否有无菌、无内毒素或无核酸酶终端过滤配置。

如果购买瓶装水，选择逻辑应按用途来：

| 用途 | 建议选择 |
| --- | --- |
| PCR、qPCR、RNA | nuclease-free water 或 molecular biology grade water |
| 细胞培养 | sterile cell culture grade water，必要时低内毒素 |
| HPLC/LC-MS | HPLC grade 或 LC-MS grade water |
| 常规缓冲液 | 超纯水或去离子水，取决于实验敏感度 |
| 电化学低背景测量 | 新鲜超纯水，配合合适探头和容器 |

常见相关供应商包括 [MilliporeSigma](<../番外/试剂厂商/MilliporeSigma.md>) / Merck、[Thermo Fisher Scientific](<../番外/试剂厂商/Thermo Fisher Scientific.md>)、[Sigma-Aldrich](<../番外/试剂厂商/Sigma-Aldrich.md>) 等。

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 超纯水电阻率低于预期 | 滤芯耗尽、管路污染、取水容器污染、CO2 溶入 | 检查系统维护状态，换容器，现取现用 |
| 用超纯水做 RNA 实验失败 | 水不一定无 RNase，容器或操作污染 | 改用无核酸酶水，使用 RNase-free 耗材 |
| 细胞状态异常 | 水未灭菌、内毒素或微量污染物影响 | 使用细胞培养级水或购买成品试剂 |
| pH 读数漂移 | 超纯水低离子强度、吸收 CO2、电极不适配 | 不把 pH 作为主要水质指标，使用低离子水专用方法 |
| 电导率测量异常偏高 | 容器残留盐、探头污染、暴露空气过久 | 用新容器，冲洗探头，缩短暴露时间 |
| HPLC/LC-MS 背景高 | TOC 或有机残留不符合方法要求 | 使用 LC-MS grade water，检查瓶子和管路 |

## 总结

超纯水是很多实验的共同背景，真正重要的是“背景是否足够低、是否符合用途”。它可以是缓冲液配制和仪器冲洗的高质量水源，但不能自动等同于无菌水、无核酸酶水、低内毒素水或 LC-MS 级水。越是敏感实验，越应该把水当成一个有等级、有记录、有风险的试剂。
