# 硫酸铜

硫酸铜在蛋白定量语境中通常指 copper(II) sulfate（硫酸铜，CuSO4）或 copper(II) sulfate pentahydrate（五水硫酸铜，CuSO4·5H2O）。在 [BCA蛋白定量试剂盒](BCA蛋白定量试剂盒.md) 中，它提供 Cu2+，随后 Cu2+ 被蛋白还原为 Cu+，再与 [Bicinchoninic acid](<Bicinchoninic acid.md>)（BCA，二喹啉甲酸/双喹啉羧酸）形成紫色络合物。

## 在BCA中的作用

BCA assay（bicinchoninic acid assay，BCA 蛋白定量法）不是单靠 BCA 一个分子完成的。铜离子是反应核心：

| 成分 | 作用 |
| --- | --- |
| Cu2+ | 被蛋白在碱性条件下还原为 Cu+ |
| BCA | 与 Cu+ 络合，形成紫色复合物 |
| 碱性缓冲体系 | 提供双缩脲反应条件 |
| [BSA标准品](BSA标准品.md) | 建立标准曲线 |

Thermo Fisher Pierce BCA 用户指南说明，该方法把 Cu2+ 到 Cu+ 的还原反应与 BCA 对 Cu+ 的显色检测结合，紫色络合物在 562 nm 有强吸收。参考：[Pierce BCA Protein Assay Kit User Guide](https://www.thermofisher.com/TFS-Assets/LSG/manuals/MAN0011430_Pierce_BCA_Protein_Asy_UG.pdf)。

## 常见形式

| 形式 | 外观/特点 | 常见用途 |
| --- | --- | --- |
| 五水硫酸铜固体 | 蓝色晶体 | 自配铜试剂、教学实验 |
| 无水硫酸铜 | 白色或灰白色，吸水后变蓝 | 干燥剂或化学用途，生物实验较少直接用 |
| 4% copper(II) sulfate solution | 厂商预配溶液 | BCA 工作液组分 |
| BCA kit 中铜试剂 | 套装内小瓶试剂 | 与 BCA solution 按比例混合 |

Merck/Sigma 的 BCA 方法资料中，4% Copper(II) Sulfate Pentahydrate Solution 常与 Bicinchoninic Acid Solution 按 1:49 配成蛋白测定工作液。参考：[Merck Protein Determination by the BCA Method](https://www.merckmillipore.com/CV/en/technical-documents/protocol/protein-biology/protein-quantitation/protein-determination-by-the-bicinchoninic-acid-bca-method)。

## 和其他铜盐/铜试剂的区别

| 试剂 | 是否适合替代 BCA 铜试剂 | 说明 |
| --- | --- | --- |
| Copper(II) sulfate pentahydrate | 可以，但要按方法准确配制 | 最常见来源 |
| Copper(II) sulfate solution | 可以，需确认浓度和等级 | 方便、稳定性更好 |
| Copper chloride | 不建议随意替代 | 阴离子、配位环境和方法兼容性不同 |
| 未知铜试剂 | 不建议 | 会改变背景和线性范围 |

BCA 是定量实验，不是普通显色小实验。即使“都是铜离子”，也不应随意换盐、换浓度或换 buffer。

## 配制与使用注意

### 自配铜试剂

**怎么做**：根据分子量和水合状态准确计算称量量，使用分析天平和纯水配制，必要时过滤。记录是否为 pentahydrate（五水合物）。

**为什么**：无水硫酸铜和五水硫酸铜分子量不同，称量同样质量得到的 Cu2+ 浓度不同。

### 与BCA溶液混合

**怎么做**：按说明书比例配成 working reagent（工作液），当天使用。

**为什么**：铜试剂比例影响背景、灵敏度和线性范围。铜过量可能增加非特异背景；铜不足会让高浓度样本显色不足。

### 避免干扰物

**怎么做**：查试剂盒兼容表，特别注意 [EDTA](EDTA.md)、[EGTA](EGTA.md)（ethylene glycol tetraacetic acid，乙二醇双(2-氨基乙基醚)四乙酸）、[DTT](DTT.md)、[β-巯基乙醇](β-巯基乙醇.md)、[TCEP](TCEP.md)（tris(2-carboxyethyl)phosphine，三(2-羧乙基)膦）等。

**为什么**：螯合剂会抓走铜离子，还原剂会改变铜氧化态，都会让 BCA 读数失真。

## 安全与废液

硫酸铜属于需要按 [SDS与GHS标签](<../实验室安全/SDS与GHS标签.md>) 管理的化学品，尤其要注意眼睛、皮肤和环境危害。实验室中不要把含铜废液直接倒入普通下水；应按 [化学品安全](<../实验室安全/化学品安全.md>) 和 [实验室废弃物处理](<../实验室安全/实验室废弃物处理.md>) 要求收集。

Sigma-Aldrich 的 C2284 4% copper(II) sulfate solution 页面将该产品标注为适合 total protein determination（总蛋白测定），并提供 SDS 入口；正式使用前应查看对应批次 SDS。参考：[Sigma-Aldrich Copper(II) sulfate solution C2284](https://www.sigmaaldrich.com/US/en/product/sigald/c2284)。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| BCA 全板显色弱 | 铜试剂漏加、比例错误、试剂过期 | 重新配工作液 |
| blank 很高 | 铜试剂或 BCA 溶液污染 | 换新试剂和纯水 |
| 样本读数异常偏高 | 样本含还原剂 | 稀释样本或换兼容 kit |
| 样本读数异常偏低 | 样本含螯合剂 | buffer exchange 或换方法 |
| 结果批间漂移 | 铜试剂浓度/批号变化 | 固定批号并记录 |

## 小结

在 BCA 里，硫酸铜不是配角小瓶，而是把蛋白浓度转换成颜色信号的铜源。它的浓度、水合状态、配比和干扰物兼容性都会直接影响定量结果。
