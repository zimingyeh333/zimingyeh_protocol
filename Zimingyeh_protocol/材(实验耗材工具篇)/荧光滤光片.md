# 荧光滤光片

## 一句话定义

Fluorescence filter（荧光滤光片）是 [荧光显微镜](荧光显微镜.md) 中用于选择特定波长光的光学元件，负责控制激发光进入样本和发射光进入检测器。

一个典型荧光 filter set（滤光片组）通常包括 excitation filter（激发滤光片）、[二向色镜](二向色镜.md) 和 emission filter（发射滤光片）。Chroma、Semrock/IDEX、Nikon 和 Leica 等光学/显微厂商都把滤光片组与荧光染料光谱匹配作为荧光成像的核心。[参考：Chroma Fluorescence Filters](https://www.chroma.com/)；[参考：Nikon MicroscopyU Fluorescence Filters](https://www.microscopyu.com/microscopy-basics/fluorescence-filters)

## 三类核心滤光元件

| 元件 | 英文 | 作用 |
| --- | --- | --- |
| 激发滤光片 | Excitation filter | 只让适合激发染料的光通过 |
| 二向色镜 | Dichroic mirror | 反射激发光，透过发射光 |
| 发射滤光片 | Emission filter / barrier filter | 只让目标荧光发射波段进入相机 |

如果滤光片选择不匹配，即使染色成功，也可能出现信号弱、背景高、串色或看不到目标信号。

## 与荧光染料的关系

| 染料 | 常见通道 | 滤光片选择重点 |
| --- | --- | --- |
| [DAPI](DAPI.md) / Hoechst | 蓝色 | UV/405 激发与蓝色发射 |
| [FITC](FITC.md) / Alexa Fluor 488 | 绿色 | 488 附近激发，绿光发射 |
| TRITC / Cy3 / Alexa Fluor 555 | 橙红 | 与绿色和红色通道分离 |
| Cy5 / Alexa Fluor 647 | 远红 | 远红发射，降低自发荧光背景 |

滤光片不是“蓝、绿、红”这么粗略。每个滤光片都有中心波长和带宽，带宽越宽收光越多，但串色风险也可能更高。

## 常见滤光片标记

滤光片可能写成类似：

```text
Ex 470/40
Em 525/50
```

含义是：

| 标记 | 解释 |
| --- | --- |
| 470/40 | 中心 470 nm，带宽 40 nm |
| 525/50 | 中心 525 nm，带宽 50 nm |
| Long-pass | 允许高于某波长的光通过 |
| Band-pass | 只允许某范围波长通过 |
| Short-pass | 允许低于某波长的光通过 |

## 选择逻辑

| 需求 | 选择建议 |
| --- | --- |
| 信号弱 | 适当宽带滤光片或更亮染料 |
| 多色成像 | 窄带或更好分离的 filter set |
| 高自发荧光 | 避开背景强的波段，考虑远红 |
| 定量成像 | 固定滤光片组和曝光参数 |
| 新染料 | 先查光谱与滤光片匹配 |

## 注意事项

- 滤光片老化、污染或装错方向会影响成像。
- 多通道实验要设置单染对照，检查串色。
- 宽带滤光片信号强，但更容易收进不想要的光。
- 荧光蛋白和化学染料即使颜色相似，也不一定适合同一个滤光片。
- 购买或记录时应写清 ex/em/dichroic 参数，而不是只写“绿色滤光片”。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 某染料看不到 | 激发或发射滤光片不匹配 | 查染料光谱和滤光片参数 |
| 背景很高 | 发射带宽太宽或自发荧光 | 换窄带滤光片或远红染料 |
| 多通道串色 | 通道光谱重叠 | 用单染检查，换滤光片组 |
| 信号比以前弱 | 滤光片污染/老化或光源变化 | 清洁检查，记录设备状态 |
| 图像颜色混乱 | 软件伪彩色与真实通道不一致 | 记录通道和伪彩设置 |

## 小结

荧光滤光片决定显微镜到底激发什么光、收集什么光。染料和滤光片不匹配时，实验可能看起来像“抗体失败”，其实是光路设置错误。记录时应写清 excitation、emission 和 dichroic 参数。
