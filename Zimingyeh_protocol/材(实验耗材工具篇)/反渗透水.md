# 反渗透水

Reverse osmosis water（RO water，反渗透水）是通过 [反渗透膜](反渗透膜.md) 在压力驱动下去除颗粒、微生物、部分有机物和大量离子的预纯化水。它常作为实验室水系统的前端水源，但通常不是直接用于敏感实验的终端水。

## 基本原理

Reverse osmosis（RO，反渗透）利用半透膜和压力，让水分子通过膜，同时截留许多溶解盐、颗粒、微生物和大分子污染物。它常和 pretreatment（预处理）、activated carbon（活性炭）、softener（软化）、[离子交换树脂](离子交换树脂.md)、UV lamp（紫外灯）和 [终端过滤器](终端过滤器.md) 组合成完整水系统。

RO 的价值在于把原水负担降下来，让后续 DI、polishing 和超纯水系统更稳定、更省耗材。

## 常见用途

| 用途 | 是否合适 | 备注 |
| --- | --- | --- |
| 水系统前端供水 | 很合适 | RO 常作为 Type I/II 水系统前处理 |
| 清洗玻璃器皿或普通耗材 | 可用 | 视实验级别决定是否需要 DI/超纯水终洗 |
| 高压灭菌锅、清洗机供水 | 常见 | 可减少水垢和盐沉积 |
| 普通缓冲液配制 | 谨慎 | 应看水质和实验敏感度 |
| 分子生物学、细胞培养 | 不建议直接使用 | 需要无菌、无核酸酶或更高水质 |
| HPLC/LC-MS | 不建议 | RO 水不是终端分析级水 |

## RO 水在水系统中的位置

实验室水系统通常可以理解为：

```text
自来水 / feed water
-> 预处理
-> RO water
-> DI / Type II pure water
-> ultrapure water / Type I water
-> 终端过滤或专用应用等级
```

RO 水不是“低等级所以没用”，而是它的角色不同。它更像水系统的前处理平台：降低后续系统压力，延长树脂、滤芯和 polishing cartridge 的寿命。

## 反渗透水 vs 其他实验用水

| 类型 | 主要功能 | 与 RO 水的关系 |
| --- | --- | --- |
| [去离子水](去离子水.md) | 去除带电离子 | 常位于 RO 后端 |
| [蒸馏水](蒸馏水.md) | 蒸发-冷凝去除非挥发杂质 | 机制不同，可用于部分普通场景 |
| [超纯水](超纯水.md) | 极低离子和有机背景 | 通常需要 RO/DI 等多级预处理 |
| [无菌水](无菌水.md) | 控制微生物污染 | 是应用等级，不等于 RO 纯化阶段 |

## 使用注意事项

### 不要把 RO 水当终端高纯水

RO 水可能已经比自来水干净很多，但它仍可能含有残余离子、有机物、CO2、微生物和膜后管路污染。敏感实验不应直接用 RO 水替代超纯水或无核酸酶水。

### 注意膜状态和回收率

RO 膜会因水垢、氯、微生物膜和颗粒堵塞而性能下降。膜状态变差时，后端 DI 树脂消耗会加快，水系统出水质量也会波动。

### 储水箱是常见污染点

RO 水常被储存在 tank（储水箱）中。储水箱如果不清洁，可能形成微生物膜，导致后端系统负担增加。长期项目记录水质异常时，不能只看终端仪表，也要考虑前端水箱。

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 后端超纯水系统耗材更换变频繁 | RO 膜性能下降或预处理失效 | 检查 RO rejection rate（截留率）和前处理 |
| 水系统有异味或微生物问题 | 储水箱污染、管路生物膜 | 清洁储水箱，按平台 SOP 消毒 |
| 清洗后仍有水垢 | RO 去盐不充分或硬度高 | 检查预处理软化和 RO 状态 |
| 用 RO 水配 buffer 结果不稳定 | 离子和有机背景未被充分控制 | 换 DI 或超纯水，并记录水源 |
| 细胞或分子实验异常 | RO 水不等于无菌/无核酸酶 | 使用对应应用等级水 |

## 总结

反渗透水是实验室纯水系统里的“前处理主力”。它的重要性在于保护后端系统、降低水垢和基础污染负担，而不是直接承担所有敏感实验。只要记住 RO water 是纯化流程的一环，不是最终应用等级，就不容易误用。
