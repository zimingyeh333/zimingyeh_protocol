# 抗体稀释液

## 一句话定义

Antibody diluent（抗体稀释液）是用于稀释 [一抗](一抗.md) 或 [二抗](二抗.md) 的缓冲体系，目的是提供合适的 pH、盐浓度、蛋白保护和低背景环境，让抗体在孵育期间稳定且尽量特异地结合目标。

在 [Western blot](<../用(实验流程内容篇)/Western blot.md>) 中，抗体稀释液常由 [TBST](TBST.md) 加 [BSA](BSA.md) 或 [脱脂奶粉](脱脂奶粉.md) 构成；在 [免疫荧光](<../用(实验流程内容篇)/免疫荧光.md>) 和 [免疫组化](<../用(实验流程内容篇)/免疫组化.md>) 中，抗体稀释液常包含 [PBS](PBS.md)、BSA、[正常血清](正常血清.md)、少量去污剂或商业稀释液。CST、Thermo Fisher 和 Abcam 的 protocol 都会给出抗体孵育 buffer 或 antibody dilution buffer 的建议。[参考：CST Western Blot Protocol](https://www.cellsignal.com/learn-and-support/protocols/protocol-western)；[参考：Abcam Western Blot Protocol](https://www.abcam.com/en-us/technical-resources/protocols/western-blot)

## 它和封闭液的区别

| 项目 | [封闭液](封闭液.md) | 抗体稀释液 |
| --- | --- | --- |
| 使用时机 | 抗体孵育前 | 抗体孵育时 |
| 主要目的 | 占据非特异结合位点 | 稀释并稳定抗体，控制背景 |
| 蛋白浓度 | 常较高，如 5% milk/BSA | 常可较低，如 1-5% BSA/milk |
| 是否必须相同 | 不一定 | 可与封闭液不同 |
| 影响 | 背景底色 | 信号强度、非特异结合、抗体稳定性 |

很多实验把封闭液直接作为抗体稀释液使用，这可以简化流程，但并不总是最佳。某些抗体在 BSA 中更好，某些抗体在奶粉中背景更低，必须根据实验结果调整。

## 常见组成

| 成分 | 作用 |
| --- | --- |
| TBS/TBST 或 PBS/PBST | 提供 pH 和离子强度 |
| BSA、脱脂奶粉、酪蛋白或正常血清 | 降低非特异结合并稳定抗体 |
| Tween-20 或 Triton X-100 | 降低背景，增加洗涤/通透性 |
| 防腐剂 | 延长保存，但可能影响 HRP 或细胞实验 |
| 商业稳定剂 | 提高抗体保存和重复使用稳定性 |

含 [叠氮钠](叠氮钠.md) 的抗体稀释液可用于某些一抗保存，但不适合与 [辣根过氧化物酶](辣根过氧化物酶.md) 反应体系随意混用，因为叠氮钠会抑制 HRP。

## 按实验选择

| 实验 | 常见抗体稀释液 | 注意事项 |
| --- | --- | --- |
| 常规 WB | TBST + 5% 脱脂奶粉或 1-5% BSA | 根据背景和目标信号优化 |
| 磷酸化 WB | TBST + 5% BSA | 避免脱脂奶粉或 casein |
| 荧光 WB | 低荧光商业稀释液或 BSA/TBST | 避免自发荧光和通道背景 |
| IF | PBS + BSA + 正常血清 + 低浓度 detergent | 注意细胞通透性和背景 |
| IHC | TBS/PBS + 正常血清或商业稀释液 | 组织背景和 Fc 结合更重要 |
| ELISA | PBS/TBS + BSA/casein/Tween | 注意板孔背景和信噪比 |

## WB使用 protocol

### 一抗稀释

1. 查抗体说明书推荐稀释范围。
2. 根据目标丰度和样本量选择起始浓度。
3. 用合适抗体稀释液配制一抗。
4. 4°C 过夜或室温短孵育。
5. 孵育后用 TBST 洗膜。

### 二抗稀释

1. 根据二抗说明书和检测方式选择稀释比例。
2. HRP 二抗常在 TBST + milk 或 TBST + BSA 中稀释。
3. 室温孵育 30-60 min。
4. 二抗后洗膜要充分，避免 [ECL发光液](<ECL发光液.md>) 整膜背景。

## 可调策略

| 问题 | 调整方向 |
| --- | --- |
| 背景高 | 增加蛋白封闭剂、降低抗体浓度、增加 Tween-20 或洗膜 |
| 信号弱 | 降低封闭剂浓度、减少 Tween-20、提高抗体浓度 |
| 磷酸化信号异常 | 使用 BSA/TBST，避免 milk/casein |
| 荧光背景高 | 换低荧光稀释液，避光操作 |
| 抗体重复使用效果下降 | 使用商业抗体保存/稀释液，减少污染 |

## 注意事项

- 抗体稀释液不是纯水，不能用水直接稀释抗体。
- 稀释液 pH、盐浓度、去污剂和蛋白成分都会影响抗体结合。
- 一抗稀释液和二抗稀释液可以不同。
- 对长期项目，抗体稀释液的配方必须写入实验记录。
- 重复使用一抗时，需评估污染和效价下降风险。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 信号很弱 | 抗体稀释过度、稀释液封闭过强 | 提高抗体浓度，降低 BSA/milk 浓度 |
| 背景高 | 抗体太浓、稀释液蛋白不足、洗膜不足 | 降低抗体浓度，增加蛋白或 Tween-20 |
| HRP 体系无信号 | 稀释液含叠氮钠抑制 HRP | 避免 HRP 反应阶段使用叠氮钠 |
| 荧光背景高 | 稀释液自发荧光或二抗过浓 | 换低荧光稀释液，降低二抗 |
| 批次重复性差 | 稀释液配方不固定 | 固定配方并记录配制日期 |

## 小结

抗体稀释液是抗体实验中很容易被低估的变量。它不只是“把抗体稀释到某个比例”，而是在信号强度、背景、抗体稳定性和重复性之间做平衡。每次优化抗体，都应该同时记录稀释液配方。
