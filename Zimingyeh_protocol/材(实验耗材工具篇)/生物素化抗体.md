# 生物素化抗体

Biotinylated antibody（生物素化抗体）是通过化学方法连接了 biotin（生物素）标签的抗体，常用于 [ELISA](<../用(实验流程内容篇)/ELISA.md>)、Western blot、免疫组化和流式检测中与 [链霉亲和素-HRP](链霉亲和素-HRP.md) 或荧光链霉亲和素结合，实现信号检测或放大。

## 基本原理

Biotinylation（生物素化）通常把小分子生物素共价连接到抗体的 lysine（赖氨酸）或其他可反应基团上。生物素本身很小，通常不会像大型酶或荧光蛋白那样显著改变抗体体积；随后 streptavidin（链霉亲和素）可以高亲和力结合生物素，从而把 HRP、AP 或荧光团带到抗体识别的位置。

在 BioLegend 的 sandwich ELISA protocol 中，detection antibody 后面接 avidin-HRP，再加入 TMB substrate；这就是典型的“生物素化检测抗体 + 亲和素/链霉亲和素酶标物”路线。参考：[BioLegend sandwich ELISA protocol](https://www.biolegend.com/en-us/protocols/sandwich-elisa-protocol)。

## 为什么不用直接 HRP 标记抗体

直接 HRP 标记抗体可以减少步骤，但生物素-链霉亲和素体系有几个优点：

| 方案 | 优点 | 风险 |
| --- | --- | --- |
| 生物素化抗体 + streptavidin-HRP | 灵活、信号放大强、同一 streptavidin-HRP 可配多种抗体 | 多一步孵育和洗涤，背景控制更重要 |
| 直接 HRP 标记抗体 | 步骤少，体系简单 | 每支抗体都要单独标记，酶标可能影响结合 |
| 未标记抗体 + HRP 二抗 | 通用性高 | 物种背景和交叉反应风险更高 |
| 荧光标记抗体 | 可多重检测 | 需要荧光读数设备，避光和光漂白问题 |

如果是高灵敏度 sandwich ELISA，生物素化检测抗体很常见；如果是快速筛选或步骤极简，直接 HRP 标记抗体可能更方便。

## 关键质量指标

生物素化抗体最重要的不是“有没有生物素”，而是 biotin-to-antibody ratio（生物素/抗体标记比例）是否合适。

| 指标 | 太低会怎样 | 太高会怎样 |
| --- | --- | --- |
| 标记比例 | streptavidin-HRP 结合少，信号弱 | 抗体亲和力下降、聚集、背景升高 |
| 纯度 | 非特异性背景增加 | 同左 |
| 游离生物素残留 | 竞争 streptavidin-HRP，信号下降 | 同左 |
| 保存稳定性 | 批间漂移 | 冻融后聚集或活性下降 |
| 验证应用 | 体系不匹配 | 标注 WB/IHC 不代表适合 ELISA |

商业生物素化抗体通常已经完成纯化和功能验证；自标记抗体需要去除游离生物素，并重新验证结合活性和背景。

## 在 ELISA 中的使用

常见流程是：捕获抗体包被板面，加入标准品/样本，加入生物素化检测抗体，洗涤后加入 streptavidin-HRP，再加入 TMB 显色并终止读数。Thermo Fisher 的 ELISA overview 将 antibody incubation、enzyme conjugate 和 substrate development 作为 ELISA 的核心步骤；生物素化抗体通常处在 detection antibody 这一层。参考：[Thermo Fisher Overview of ELISA](https://www.thermofisher.com/us/en/home/life-science/protein-biology/protein-biology-learning-center/protein-biology-resource-library/pierce-protein-methods/overview-elisa.html)。

使用时要注意：

- 按说明书稀释，不要只凭“常用 1:1000”经验处理。
- 稀释后尽量当天使用，避免长时间室温放置。
- 不要把含游离生物素的缓冲液带入检测步骤。
- 如果样本或培养基含较多生物素，可能干扰 streptavidin 结合。
- 加入 streptavidin-HRP 前要充分洗去未结合的生物素化抗体。

## 和检测抗体的关系

[检测抗体](检测抗体.md) 是功能角色，生物素化抗体是一种标记形式。一支生物素化抗体可以作为检测抗体，也可以在其他实验中作为捕获或示踪抗体使用，具体取决于实验设计。

| 说法 | 含义 |
| --- | --- |
| biotinylated detection antibody | 生物素化检测抗体，常用于夹心 ELISA |
| biotinylated capture antibody | 生物素化捕获抗体，可用于链霉亲和素包被板体系 |
| unlabeled detection antibody | 未标记检测抗体，可能需要二抗或后续标记 |
| HRP-conjugated detection antibody | HRP 直接标记检测抗体 |

## 常见异常与 troubleshooting

| 异常 | 可能原因 | 调整方向 |
| --- | --- | --- |
| 信号弱 | 标记比例低、抗体浓度低、streptavidin-HRP 失活 | 提高检测抗体浓度，检查 HRP/TMB，换新抗体 |
| 背景高 | 检测抗体过量、洗涤不足、标记后聚集 | 降低浓度，增加洗涤，离心去除聚集 |
| 曲线平台低 | streptavidin-HRP 成为限制因素 | 优化 streptavidin-HRP 浓度 |
| 复孔差异大 | 加液混匀差或孵育时间不一致 | 使用多道移液枪，统一节奏 |
| 批次变化 | 标记比例或纯度变化 | 记录批号，做桥接质控 |

## 购买建议

如果用于成熟 ELISA，优先购买厂家已配对验证的 biotinylated detection antibody。自标记适合特殊靶点、特殊克隆或预算受限时使用，但要把标记、纯化、浓度测定和功能验证都算进工作量。

购买时重点看应用验证、克隆号、抗原物种、宿主物种、保存缓冲液、是否含叠氮钠、推荐稀释比例和是否与目标配对抗体同套验证。

## 小结

生物素化抗体的价值在于把抗体识别和链霉亲和素检测体系分开，让检测更灵活、信号更容易放大。但它也引入了标记比例、游离生物素和额外洗涤步骤这些变量。
