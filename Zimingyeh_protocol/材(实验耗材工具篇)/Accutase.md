# Accutase

Accutase（细胞温和解离液；常按商品名直接称 Accutase）是一种 ready-to-use（即用型）细胞解离试剂，常用于比 [Trypsin-EDTA](Trypsin-EDTA.md) 更温和地解离贴壁细胞、干细胞、神经细胞、内皮细胞和需要保留表面 marker 的细胞样本。它不是单一化学成分，而是商业化酶解离体系。

[STEMCELL Technologies](<../番外/试剂厂商/STEMCELL Technologies.md>) 的 Accutase 说明将其定位为不含哺乳动物或细菌来源成分的即用型细胞解离试剂，可用于温和分离贴壁细胞；[Merck](<../番外/试剂厂商/Merck.md>) / [Sigma](<../番外/试剂厂商/Sigma.md>) 的 Accutase 页面也强调其适用于从标准塑料培养容器和黏附包被表面上解离细胞。[参考：STEMCELL Accutase](https://www.stemcell.com/products/accutase.html)；[参考：Sigma Accutase](https://www.sigmaaldrich.com/US/en/product/sigma/a6964)

## 核心特点

| 特点 | 实验意义 |
| --- | --- |
| 相对温和 | 更适合表面蛋白敏感或应激敏感的细胞 |
| 即用型 | 不需要现配，减少配制误差 |
| 常用于单细胞化 | 适合流式、细胞计数、部分干细胞和原代细胞流程 |
| 可减少传统胰酶变量 | 对不想使用强胰酶消化的体系有价值 |

Accutase 的实际优势取决于细胞类型和下游目的。它不是“永远更好”，而是适合在细胞活率、表面 marker 保留和解离效率之间做更温和的折中。

## 常见用途

- 常规贴壁细胞的温和传代。
- 流式细胞术前制备单细胞悬液，尽量降低表面抗原损伤。
- 干细胞、神经细胞、内皮细胞等对胰酶敏感的细胞处理。
- 从 [细胞外基质胶](细胞外基质胶.md)、[胶原](胶原.md)、[明胶](明胶.md) 或其他包被表面上解离细胞。
- 需要后续重新贴壁、克隆形成或功能实验的细胞收集。

## Accutase vs TrypLE vs Trypsin-EDTA

| 试剂 | 温和程度 | 优势 | 局限 |
| --- | --- | --- | --- |
| Accutase | 温和到中等 | 常用于保护表面 marker 和敏感细胞 | 对强贴壁细胞可能慢 |
| [TrypLE](TrypLE.md) | 中等到强 | 无动物源重组胰酶样体系，适合替代 trypsin | 仍可能影响部分表面蛋白 |
| Trypsin-EDTA | 强 | 便宜、快速、成熟 | 对敏感细胞和表面蛋白更有风险 |
| [EDTA](EDTA.md)-only | 最温和 | 非酶，保护蛋白 | 解离能力有限 |

如果下游是常规扩增，TrypLE 或 Trypsin-EDTA 往往足够；如果下游是流式检测、单细胞实验或敏感细胞恢复，Accutase 更值得优先测试。

## 使用 protocol

### 准备

**怎么做**：按说明保存和预温 Accutase；准备无 Ca2+/Mg2+ 的 [PBS](PBS.md) 或 [DPBS](DPBS.md)、完全培养基、离心管和目标培养容器。

**为什么**：温度影响解离效率；无钙镁洗液可先削弱黏附并去除血清。

**注意事项**：

- Accutase 即用，不要随意稀释后长期保存。
- 记录批号、开封日期和储存条件。
- 第一次用于新细胞时，做时间梯度更稳。

### 洗涤并加入 Accutase

**怎么做**：吸去培养基，轻洗细胞层，加入覆盖细胞层的 Accutase。室温或 37°C 处理到细胞变圆、松动，再轻柔吹打。

**为什么**：Accutase 虽然温和，但仍是酶体系；过度暴露仍可能影响活率和下游表面结构。

**注意事项**：

- 不要只按固定时间消化，显微镜观察更可靠。
- 对干细胞，需根据目标是小团块传代还是单细胞传代调整吹打强度。
- 如果细胞非常容易脱落，缩短处理时间。

**替代方案**：解离不足时，可延长时间、轻敲培养瓶或改用 TrypLE；表面 marker 极敏感时可评估 EDTA-only。

### 终止、稀释和下游处理

**怎么做**：达到终点后加入培养基或目标缓冲液稀释，必要时离心去除 Accutase，再重悬计数或接种。

**为什么**：降低残留酶活性，避免继续作用到细胞表面。

**注意事项**：

- 流式实验前要确认缓冲液、血清/BSA、EDTA 和染色体系兼容。
- 单细胞实验前可配合细胞过滤器减少团块。
- 下游需要严格无血清时，不要用含血清培养基终止后直接进入检测。

## 选择建议

优先选择 Accutase 的情况：

- 胰酶后细胞恢复慢或死亡率高。
- 表面 marker 是下游检测重点。
- 细胞来自原代、干细胞、神经或内皮体系。
- 需要更温和地从包被表面解离细胞。

不一定需要 Accutase 的情况：

- 常规细胞系传代已被 Trypsin-EDTA 稳定支持。
- 只做普通扩增，预算和成本更敏感。
- 需要快速强力解离强贴壁细胞。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 解离太慢 | 细胞贴壁强、温度低、包被较强 | 延长时间，轻柔吹打，比较 TrypLE |
| 细胞团块多 | 处理不足或吹打不足 | 延长观察，增加温和吹打，过滤 |
| 活率下降 | 处理过久、机械吹打过强、细胞状态差 | 缩短时间，降低吹打强度，优化传代窗口 |
| 流式背景高 | 死细胞增加或缓冲体系不合适 | 加入死细胞排除染料，优化洗涤和过滤 |

## 小结

Accutase 是细胞解离里非常实用的“温和选项”。它尤其适合敏感细胞、表面 marker 相关实验和单细胞悬液制备，但仍需要按细胞类型优化时间和机械强度。
