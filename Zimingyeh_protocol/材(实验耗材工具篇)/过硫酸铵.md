# 过硫酸铵

过硫酸铵（ammonium persulfate，APS；也称 ammonium peroxydisulfate，过二硫酸铵）是聚丙烯酰胺凝胶聚合的 radical initiator（自由基引发剂）。在手灌 [SDS-PAGE凝胶](SDS-PAGE凝胶.md) 时，APS 与 [TEMED](TEMED.md) 配合启动 [丙烯酰胺](丙烯酰胺.md) 和 [双丙烯酰胺](双丙烯酰胺.md) 的自由基聚合。

![SDS-PAGE聚合与电源参考图](../z_asset/材/SDS-PAGE聚合与电源/sds-page-polymerization-power-reference.png)

图源：Image2 生成的 SDS-PAGE 聚合与电源参考图；APS 位于 Acrylamide/Bis 与 TEMED 之间，底部第二步示意加入 APS/TEMED 后启动聚合。

## 核心作用

APS 在 TEMED 催化下产生硫酸根自由基，进而引发 acrylamide/bis-acrylamide 聚合。Sigma-Aldrich 的 Ammonium persulfate A3678 页面将其应用描述为 acrylamide gel polymerization 的 catalyst，并说明其用于制备 polyacrylamide gels 和 acrylamide hydrogels，且经过 acrylamide polymerization 用途测试。参考：[Sigma-Aldrich Ammonium persulfate A3678](https://www.sigmaaldrich.com/US/en/product/sigma/a3678)。

## 为什么APS常要新鲜

APS 水溶液会逐渐分解，尤其是在室温、反复冻融或污染条件下。APS 失效是“胶不凝”最常见原因之一。

| 状态 | 稳定性 | 建议 |
| --- | --- | --- |
| 干粉 | 相对稳定 | 干燥、避光、按说明书保存 |
| 10% APS 水溶液 | 稳定性有限 | 小分装，低温短期保存 |
| 加入胶液后 | 立即开始聚合过程 | 加完尽快灌胶 |

很多实验室习惯当天现配 10% APS；若使用冻存分装，也要记录配制日期并定期更换。

## APS vs TEMED

| 组分 | 角色 | 出错后表现 |
| --- | --- | --- |
| APS | 自由基来源/引发剂 | 胶不凝或聚合很慢 |
| TEMED | 加速 APS 产生自由基 | 漏加时聚合极慢或不凝 |
| 丙烯酰胺/Bis | 单体和交联剂 | 浓度/比例决定孔径和强度 |

APS 和 TEMED 是一对，不是互相替代。只加 APS 可能很慢，只加 TEMED 几乎不能启动聚合。

## 使用 protocol

### 配10% APS

**怎么做**：称取 APS 粉末，用纯水配成 10% w/v 溶液，轻轻混匀，分装低温保存或当天使用。

**为什么**：10% APS 是手灌胶常见储液浓度，便于按微升级加入配方。

**注意事项**：

- APS 是氧化剂，避免接触可燃物和还原剂。
- 配制日期必须写在管上。
- 如果胶突然变得难凝，优先换新 APS。

### 加入胶液

**怎么做**：分离胶或浓缩胶其他组分混好后，最后加入 APS 和 TEMED，轻轻混匀后立即灌胶。

**为什么**：自由基聚合启动后窗口有限，拖延会导致气泡、局部聚合和胶面不平。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 胶长时间不凝 | APS 失效、TEMED 漏加、氧气干扰 | 现配 APS，检查 TEMED |
| 胶凝得太快 | APS/TEMED 加太多、温度高 | 降低用量或缩短操作时间 |
| 胶面不平 | 加 APS/TEMED 后拖太久或有气泡 | 加完立刻灌胶并排泡 |
| 条带变形 | 聚合不均 | 重配胶，检查 APS 新鲜度 |

## 安全与废液

APS 是氧化性化学品，粉末可刺激皮肤、眼睛和呼吸道。配制和称量时按 [SDS与GHS标签](<../实验室安全/SDS与GHS标签.md>) 操作，佩戴手套、护目镜和实验服。APS 残液和未聚合胶液按化学废液处理。

## 小结

APS 是手灌胶聚合的“点火器”。胶不凝时，先不要怀疑整套配方，优先检查 APS 是否新鲜、TEMED 是否漏加，以及是否加完后拖太久。
