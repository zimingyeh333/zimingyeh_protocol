# 滤纸

## 一句话定义

Filter paper（滤纸）是一类由纤维材料制成的多孔片材，在生命科学实验中用于过滤、吸附、转移液体或作为电转夹层材料。

在 [Western blot](<../用(实验流程内容篇)/Western blot.md>) 转膜中，滤纸位于凝胶/膜两侧，负责承载 [转膜缓冲液](转膜缓冲液.md)、让电流和离子均匀通过，并帮助夹层保持平整。Bio-Rad 和 Thermo Fisher 的 WB 转膜资料都强调转膜夹层中滤纸、膜、凝胶和海绵垫的正确组装。[参考：Bio-Rad Western Blotting Guide](https://www.bio-rad.com/applications-technologies/western-blotting-immunodetection-techniques?ID=PQEEPOBWLN4A)；[参考：Thermo Fisher Western Blot Protocols](https://www.thermofisher.com/uk/en/home/life-science/protein-biology/protein-biology-learning-center/protein-gel-electrophoresis-information/western-blot-protocols.html)

![Western blot膜、转膜缓冲液、Ponceau S与ECL示意图](<../z_asset/材/Western blot膜和检测/wb-membrane-transfer-detection-reference-zh.png>)

## 在WB转膜中的作用

| 作用 | 解释 |
| --- | --- |
| 均匀导液 | 让转膜缓冲液均匀分布在凝胶和膜周围 |
| 均匀导电 | 降低局部电流不均造成的转膜斑块 |
| 支撑夹层 | 让凝胶和膜贴合平整 |
| 吸收气泡和多余液体 | 帮助减少局部空白区 |

滤纸不是随便夹进去的纸。厚度、尺寸、是否完全浸润、是否有气泡，都会影响转膜均一性。

## 常见类型

| 类型 | 适合场景 | 注意点 |
| --- | --- | --- |
| 预切 WB 滤纸 | 标准 mini gel 或 midi gel 转膜 | 尺寸匹配，减少裁剪误差 |
| 普通实验滤纸 | 临时替代或非标准尺寸 | 需确认厚度、灰分和纯度是否适合 |
| 厚滤纸 | 半干转或特定设备 | 缓冲液容量大，但夹层厚度需匹配 |
| 低荧光/低背景材料 | 荧光 WB 或特殊成像 | 成本更高，需确认兼容性 |

对于常规 WB，推荐使用与转膜设备匹配的预切滤纸。随便拿一张过滤用滤纸替代，可能造成夹层厚度不合适、导电不均或背景污染。

## 使用 protocol

### 转膜前准备

1. 按凝胶尺寸准备滤纸，尺寸应略大于凝胶和膜。
2. 将滤纸完全浸入转膜缓冲液。
3. 轻轻晃动或用镊子压入液面，确保没有干区。
4. 组装夹层时让滤纸平整贴合凝胶和膜。
5. 用滚轮、移液管或镊子边缘轻轻赶除气泡。

### 常见湿转夹层

```text
负极侧
转膜海绵垫
滤纸
凝胶
PVDF膜或NC膜
滤纸
转膜海绵垫
正极侧
```

蛋白从凝胶迁移到膜上，所以膜的位置必须在凝胶靠正极的一侧。滤纸放错通常不会改变方向，但夹层不平会造成局部转膜失败。

## 注意事项

- 滤纸不能有折痕、颗粒、灰尘或破损。
- 不要让滤纸边缘卷入凝胶和膜之间。
- 半干转中滤纸含液量更关键，太干会局部过热，太湿可能短路或信号扩散。
- 使用自裁滤纸时，尺寸要一致，避免夹层边缘受力不均。
- 与化学发光或荧光检测相关的滤纸/衬垫应避免污染 HRP、抗体或荧光染料。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 局部无条带 | 滤纸有气泡或干区 | 充分浸润并赶气泡 |
| 转膜不均 | 滤纸厚度不一致或夹层歪斜 | 使用匹配设备的预切滤纸 |
| 半干转发热 | 滤纸含液不足 | 增加缓冲液浸润，按设备要求组装 |
| 背景斑点 | 滤纸污染或纤维碎屑 | 使用洁净滤纸，避免重复使用 |
| 边缘信号异常 | 滤纸尺寸不合适 | 裁切至略大于凝胶和膜 |

购买时优先确认设备型号、凝胶尺寸、转膜方式和滤纸厚度。Bio-Rad、Thermo Fisher 等转膜系统通常有对应尺寸耗材，标准化耗材能减少很多不必要变量。

## 小结

滤纸在 WB 转膜里看起来普通，但它决定夹层是否平整、液体是否均匀、电流是否稳定。转膜不均时，滤纸和气泡应该和膜、缓冲液一起被检查。
