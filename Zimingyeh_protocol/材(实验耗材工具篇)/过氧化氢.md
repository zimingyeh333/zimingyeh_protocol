# 过氧化氢

## 一句话定义

Hydrogen peroxide（过氧化氢，H2O2）是一种常见氧化剂，在生命科学实验中可作为酶促显色/发光反应底物、细胞刺激物、消毒剂或化学处理试剂。

在 [ECL发光液](<ECL发光液.md>) 中，过氧化物参与 [辣根过氧化物酶](辣根过氧化物酶.md)（HRP）催化的氧化发光反应；在细胞实验中，低浓度 H2O2 也常被用于 oxidative stress（氧化应激）模型。PubChem 和 OSHA 都将 hydrogen peroxide 归为具有氧化性和刺激性风险的化学品，使用浓度越高，安全风险越高。[参考：PubChem Hydrogen Peroxide](https://pubchem.ncbi.nlm.nih.gov/compound/Hydrogen-peroxide)；[参考：OSHA Hydrogen Peroxide](https://www.osha.gov/chemicaldata/630)

## 常见用途

| 用途 | 说明 |
| --- | --- |
| HRP 底物体系 | 与 luminol 或 TMB 等底物配合，产生发光或显色 |
| 细胞氧化应激 | 用于诱导 ROS 相关刺激，浓度和时间高度依赖细胞类型 |
| 消毒/清洁 | 常见低浓度溶液可用于部分表面处理 |
| 组织/免疫染色 | 可用于抑制 endogenous peroxidase（内源性过氧化物酶）活性 |

不同用途之间浓度差异巨大，不能把“3% 过氧化氢”“30% 过氧化氢”和 ECL 里的过氧化物体系混为一谈。

## 浓度和风险

| 常见形式 | 风险理解 |
| --- | --- |
| 低浓度水溶液 | 仍有刺激性，避免接触眼睛和皮肤 |
| 3% 左右溶液 | 常见消毒相关浓度，但实验室仍需规范标记 |
| 30% 左右浓溶液 | 强氧化性和腐蚀风险明显，配制稀释必须谨慎 |
| 商品 ECL 中的过氧化物组分 | 浓度和稳定剂由厂家控制，按说明书使用 |

浓过氧化氢与有机物、金属污染物或还原性物质接触可能发生剧烈反应或分解放热。处理高浓度 H2O2 时必须查询 SDS（Safety Data Sheet，安全数据表）。

## 在ECL中的理解

ECL 发光不是“过氧化氢越多越亮”。过氧化物、luminol 类底物、增强剂、pH 和 HRP 量都需要平衡。过量氧化剂可能增加背景、加速信号衰减或损伤体系。

对于 WB 用户，通常不需要单独调节商品 ECL 中的过氧化物浓度；真正需要优化的是抗体浓度、洗膜、ECL 类型和曝光时间。

## 配制和保存注意事项

- 高浓度 H2O2 应避光、低温或按厂家要求保存。
- 稀释时使用洁净容器，避免金属污染和有机污染。
- 不要把 H2O2 与易氧化有机物、强还原剂或不明废液混合。
- 处理高浓度溶液时佩戴 [个人防护装备](<../实验室安全/个人防护装备.md>)，包括护目镜、实验服和合适手套。
- 废液按 [实验室废弃物处理](<../实验室安全/实验室废弃物处理.md>) 和本单位 EHS 要求处理。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 氧化应激实验重复性差 | H2O2 分解、细胞密度不同、处理时间不一致 | 现配工作液，控制细胞状态和处理时间 |
| ECL 信号异常 | 商品底物过期或保存不当 | 检查批号、保存条件和阳性对照 |
| 溶液起泡或放热 | 与污染物或不兼容试剂接触 | 停止操作，按安全流程处理 |
| 细胞全部死亡 | 浓度过高或暴露过久 | 做浓度梯度和时间梯度 |

## 小结

过氧化氢既是常见实验试剂，也是需要认真对待的氧化剂。做 ECL 时通常按商品试剂盒使用；做细胞刺激或化学处理时，浓度、时间、保存和安全记录必须写清楚。
