# 电动助吸器

Pipette controller / pipette aid（电动助吸器 / 移液管助吸器）是与 [血清移液管](血清移液管.md) 配合使用的手持电动液体转移工具，用于吸取和排出 1-50 mL 级别液体。它是细胞培养中换液、传代、分装培养基和处理大体积细胞悬液的高频工具。

图源：[Eppendorf Easypet 3 pipette controller](https://www.eppendorf.com/us-en/Products/Liquid-Handling/Manual-Pipettes-Dispensers/Easypet-3-p-PF-48135)

## 核心用途

| 用途 | 典型搭配 | 注意事项 |
| --- | --- | --- |
| 细胞换液 | 10 mL、25 mL 血清移液管 | 避免直接冲击贴壁细胞 |
| 培养基分装 | 5-50 mL 血清移液管 | 保持无菌，避免泡沫 |
| 细胞传代重悬 | 5-25 mL 血清移液管 | 吹打力度要温和 |
| 大体积 PBS/DPBS 转移 | 10-50 mL 血清移液管 | 不用于微量精密加样 |
| 吸走旧液 | 血清移液管或吸引系统 | 污染液体不要倒吸进机身 |

Eppendorf、BRAND 和 Thermo Fisher 的 pipette controller 产品资料都强调可调吸排速度、滤膜保护、人体工学和适配玻璃/塑料移液管等要点。[参考：Eppendorf Easypet 3](https://www.eppendorf.com/us-en/Products/Liquid-Handling/Manual-Pipettes-Dispensers/Easypet-3-p-PF-48135)；[参考：BRAND accu-jet S](https://www.brand.de/en/accu-jet-s-pipette-controller/p/26300)

## 结构组成

| 部分 | 英文 | 作用 | 注意事项 |
| --- | --- | --- | --- |
| 吸液按钮 | Aspirate button | 控制吸液 | 速度过快会吸入滤膜 |
| 排液按钮 | Dispense button | 控制排液 | 可重力排液或电动排液 |
| 速度调节 | Speed control | 调节吸排速度 | 细胞悬液建议慢速 |
| 滤膜 | Hydrophobic filter | 阻止液体进入机身 | 打湿后要更换 |
| 移液管适配器 | Pipette adapter | 固定血清移液管 | 需保持清洁和密封 |
| 电池/充电座 | Battery / charger | 提供动力 | 电量不足会影响速度稳定 |

## 使用 protocol

### 使用前检查

**怎么做**：检查电量、滤膜是否干燥、适配器是否清洁、吸排按钮是否正常。选择合适规格血清移液管并在 BSC 内安装。

**为什么**：滤膜堵塞或适配器漏气会造成吸液不稳；电量不足会让速度变化，影响分装一致性。

**注意事项**：

- 不要使用滤膜潮湿或污染的助吸器。
- 不要把助吸器平放到可能污染的台面区域。
- 细胞培养专用助吸器尽量不要和化学污染操作混用。

**替代方案**：精密小体积加样用 [移液枪](移液枪.md) 或 [电动移液器](电动移液器.md)。

**出错后果**：吸液不稳、污染、液体倒吸进机身。

### 吸液

**怎么做**：将血清移液管尖端浸入液面下，缓慢按吸液按钮。接近目标刻度时降低速度，避免液体冲到滤塞。

**为什么**：电动助吸器吸力较强，尤其配小规格移液管时，过快吸液很容易超过目标体积或打湿滤膜。

**注意事项**：

- 不要吸到移液管滤塞。
- 细胞悬液吸取前轻柔混匀。
- 易起泡液体降低吸液速度。

**替代方案**：对非常敏感的细胞，降低吸排速度并减少吹打次数。

**出错后果**：体积错误、泡沫、细胞损伤、滤膜污染。

### 排液和吹打

**怎么做**：沿容器壁缓慢排液。需要混匀时轻柔吹打，不要把液流直接冲到贴壁细胞层上。分装多个容器时保持一致速度和角度。

**为什么**：助吸器的便利性容易让操作者排液过快。大体积液流带来的剪切力和冲击力会影响细胞状态。

**注意事项**：

- 贴壁细胞换液时沿壁加入新液。
- 分装细胞悬液时定期混匀，避免细胞沉降。
- 不同细胞或不同处理组之间更换移液管。

**替代方案**：多孔板重复加样用多道移液枪、连续分液器或自动化分液。

**出错后果**：细胞脱落、接种不均、交叉污染。

### 维护

**怎么做**：定期更换滤膜，清洁可拆卸适配器，检查电池和充电状态。若发生倒吸，应立即停用、拆下滤膜和适配器清洁或更换，并按设备说明处理。

**为什么**：助吸器内部一旦污染，后续每次吸排都可能带来气溶胶或液体污染风险。

**注意事项**：

- 不能把整个电动助吸器浸泡或高压灭菌，除非说明书允许拆卸部件。
- 共享设备应有清洁和滤膜更换记录。
- 发现吸力下降先检查滤膜和适配器。

**替代方案**：高污染风险废液优先用真空吸引系统，而不是助吸器反复吸废液。

**出错后果**：培养液污染、设备损坏、吸排速度异常。

## 电动助吸器 vs 电动移液器 vs 移液枪

| 工具 | 适合体积 | 优点 | 局限 |
| --- | --- | --- | --- |
| 电动助吸器 + 血清移液管 | 1-50 mL | 大体积无菌转移方便 | 精度有限，不适合微量体系 |
| [电动移液器](电动移液器.md) | µL-mL 级，取决于型号 | 重复加样稳定 | 成本高，需匹配吸头 |
| [移液枪](移液枪.md) | µL 级为主 | 精度高，适合小体积 | 大体积效率低 |
| [瓶口分液器](瓶口分液器.md) | mL 级重复分装 | 快速、重复性好 | 无菌细胞操作需谨慎 |

## 购买建议

选择电动助吸器时重点看吸排速度控制、手感重量、滤膜更换方便性、适配 1-50 mL 移液管能力、电池续航、是否可单手操作和是否容易清洁。常见品牌包括 [Eppendorf](<../番外/试剂厂商/Eppendorf.md>)、[BRAND](<../番外/试剂厂商/BRAND.md>)、[Sartorius](<../番外/试剂厂商/Sartorius.md>)、[Thermo Scientific](<../番外/试剂厂商/Thermo Scientific.md>)、[Corning](<../番外/试剂厂商/Corning.md>) 等。

细胞培养房建议固定专用助吸器，并准备备用滤膜和适配器。不要只买一支助吸器让所有污染风险操作混用。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理策略 |
| --- | --- | --- |
| 吸不上液 | 滤膜堵塞、移液管未插紧、电量低 | 更换滤膜，重新安装，充电 |
| 液体进入滤膜 | 吸液过快、超过刻度、移液管倾斜 | 停用并更换滤膜，降低速度 |
| 排液太冲 | 速度设置过高 | 降低速度，沿壁排液 |
| 分装细胞数不均 | 细胞沉降、混匀不足 | 分装中轻柔混匀 |
| 反复污染 | 适配器或滤膜污染 | 拆洗/更换，建立维护记录 |

## 小结

电动助吸器是细胞培养里“顺手但容易被忽视”的设备。它真正的风险不在于能不能吸液，而在于吸排速度、滤膜污染、倒吸和大体积液流对细胞的影响。好的习惯是慢、稳、清洁、专用、可追踪。
