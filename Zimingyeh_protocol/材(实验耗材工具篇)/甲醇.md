# 甲醇

Methanol（甲醇，methyl alcohol）是一种挥发性、易燃、有毒的有机溶剂。在 [Western blot](<../用(实验流程内容篇)/Western blot.md>) 中，它最常见的用途是加入 [转膜缓冲液](转膜缓冲液.md)，影响蛋白从 [SDS-PAGE凝胶](SDS-PAGE凝胶.md) 转移到 [PVDF膜](PVDF膜.md) 或 [NC膜](NC膜.md) 的效率。

## 在转膜中的作用

| 作用 | 解释 |
| --- | --- |
| 帮助蛋白结合膜 | 甲醇可促进蛋白从 SDS-蛋白复合物状态转向膜结合 |
| 去除部分 SDS | 降低 SDS 对膜结合的干扰 |
| 使凝胶收缩 | 有助于某些转膜体系，但可能让大蛋白更难出来 |
| 活化 PVDF | PVDF 膜疏水，通常需先用甲醇润湿 |

Cell Signaling Technology 的 Tris-Glycine Transfer Buffer 官方页面给出常见 1x 转膜缓冲液配法：100 mL 10x transfer buffer、200 mL methanol、700 mL ddH2O，即 20% methanol。参考：[CST Tris-Glycine Transfer Buffer](https://www.cellsignal.com/products/buffers-dyes/tris-glycine-transfer-buffer-10x/12539)。

## 什么时候调整甲醇比例

| 情况 | 可能策略 | 理由 |
| --- | --- | --- |
| 常规 20-100 kDa 蛋白 | 10%-20% 甲醇 | 经典湿转条件 |
| 大蛋白 >150 kDa | 降低甲醇，适当加 SDS 或延长转膜 | 减少凝胶收缩，帮助大蛋白出来 |
| 小蛋白 <20 kDa | 维持或提高甲醇，缩短时间 | 降低穿膜风险，提高膜结合 |
| PVDF膜 | 先用 100% 甲醇短暂活化 | PVDF 需要润湿 |
| NC膜 | 通常不需甲醇活化 | NC 膜亲水性更好 |

Bio-Rad 的样本制备/转膜资料也给出将 100 mL 10x Tris/Glycine premixed buffer、700 mL 水和 200 mL methanol 配成 1x transfer buffer 的示例，并说明 PVDF 使用前需先用 100% 甲醇短暂活化。参考：[Bio-Rad Sample Preparation PDF](https://www.bio-rad.com/webroot/web/pdf/lsr/literature/Bulletin_6048B.pdf)。

## 甲醇 vs 乙醇 vs 无醇转膜

| 方案 | 优点 | 局限 | 适合场景 |
| --- | --- | --- | --- |
| 甲醇 | 经典、膜结合稳定、文献和说明书多 | 有毒、易燃，对大蛋白不友好 | 常规 WB |
| 乙醇 | 毒性和气味相对不同，部分体系可替代 | 条件需重新验证 | 甲醇受限时的优化方案 |
| 无醇/低醇 | 对大蛋白转出更友好 | 小蛋白可能穿膜，膜结合可能下降 | 大蛋白或特殊转膜体系 |

不要在正式实验中随意把甲醇替换成乙醇。替换后至少需要用 [Ponceau S](<Ponceau S.md>) 或总蛋白染色检查转膜效率，并记录条件。

## 使用 protocol

### PVDF膜活化

**怎么做**：将 PVDF 膜短暂浸入 100% 甲醇至完全润湿，再转入水或转膜缓冲液平衡。

**为什么**：未活化的 PVDF 局部不润湿，会造成转膜空斑或不均一。

**注意事项**：

- 不要让膜在后续步骤中干掉。
- 用镊子夹边缘，避免手直接接触结合区域。

### 配转膜缓冲液

**怎么做**：按体系加入规定比例甲醇，混匀并预冷。

**为什么**：转膜过程会发热；甲醇挥发且易燃，预冷和密闭保存更安全也更稳定。

## 安全重点

甲醇是高度易燃且有系统毒性的溶剂。NIOSH/CDC 的 methanol emergency response card 说明甲醇可通过吸入、皮肤吸收或摄入造成毒性，且代谢产物可导致 metabolic acidosis（代谢性酸中毒）、失明甚至死亡；其蒸气和空气混合物也有爆炸风险。参考：[NIOSH Methanol Emergency Response Card](https://www.cdc.gov/niosh/ershdb/emergencyresponsecard_29750029.html)。

实验室使用时：

- 远离火源、热源和电火花。
- 在通风良好环境中操作，必要时使用通风橱。
- 佩戴合适 [实验手套](实验手套.md)、护目镜和实验服。
- 大量含甲醇废液按 [实验室废弃物处理](<../实验室安全/实验室废弃物处理.md>) 收集，不得直接倒入水槽。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| PVDF 膜局部无信号 | 甲醇活化不足或膜干过 | 重新规范活化和平衡 |
| 大蛋白转膜弱 | 甲醇比例过高导致凝胶收缩 | 降低甲醇，延长转膜或优化 SDS |
| 小蛋白丢失 | 转膜太强或膜结合不足 | 缩短时间，优化甲醇和膜孔径 |
| 背景异常 | 甲醇或 buffer 污染，膜处理不一致 | 换新 buffer，统一活化时间 |
| 安全风险 | 开放容器、靠近火源 | 密闭、通风、远离点火源 |

## 小结

甲醇在 WB 中既是有用的转膜调节因子，也是必须认真管理的危险溶剂。它的比例会改变蛋白转膜效率，尤其影响大蛋白和小蛋白；因此不要只写“transfer buffer”，要写清楚甲醇比例。
