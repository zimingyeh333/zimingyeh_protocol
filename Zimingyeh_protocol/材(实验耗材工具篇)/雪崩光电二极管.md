# 雪崩光电二极管

## 一句话定义

APD（Avalanche photodiode，雪崩光电二极管）是一种通过 avalanche multiplication（雪崩倍增）放大光电信号的半导体光探测器，常用于弱光、单光子、荧光寿命和某些扫描显微系统。

在显微和光子检测中，APD 常作为高灵敏点探测器，与 [光电倍增管](光电倍增管.md) 或混合探测器一起出现在共聚焦、单分子或光子计数系统中。Hamamatsu 等光探测器厂家将 APD 作为高速、高灵敏半导体光探测器介绍。[参考：Hamamatsu APD](https://www.hamamatsu.com/us/en/product/optical-sensors/apd.html)

## 核心原理

```text
光子进入半导体
→ 产生电子-空穴对
→ 高电场导致雪崩倍增
→ 电信号被放大
→ 输出检测信号
```

APD 的优势是体积小、响应快、灵敏；局限是噪声、暗计数、温度依赖和工作电压需要控制。

## 常见用途

| 场景 | 说明 |
| --- | --- |
| 单光子检测 | 特定 APD 或 SPAD 可用于 photon counting |
| 荧光寿命成像 | 快速响应有价值 |
| 共聚焦点检测 | 部分系统使用 APD 类探测器 |
| 光子相关/单分子实验 | 需要高速弱光检测 |

普通实验室用户更多是“使用含 APD 的设备”，而不是单独购买 APD。真正需要记录的是设备 detector 类型和设置。

## APD vs PMT vs sCMOS

| 维度 | APD | PMT | sCMOS |
| --- | --- | --- | --- |
| 检测方式 | 点探测/光子计数 | 点探测/扫描 | 面阵成像 |
| 响应速度 | 快 | 快 | 取决于帧率 |
| 弱光能力 | 高 | 高 | 高，但面阵 |
| 常见场景 | 单光子、寿命、单分子 | 共聚焦、流式 | 宽场、活细胞 |
| 使用复杂度 | 设备级参数多 | 设备级参数多 | 用户更常直接调曝光 |

## 注意事项

- APD 对温度和工作电压敏感，通常由设备控制。
- 强光可能造成饱和或损伤，避免错误光路设置。
- 光子计数模式下要关注 dead time（死时间）和 saturation（饱和）。
- 不同 detector 之间强度值不能直接比较。
- 做定量时记录 detector 类型、gain、计数模式和采集设置。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 计数饱和 | 光太强或增益过高 | 降低激光或中性密度滤光 |
| 暗计数高 | 温度、器件噪声或设置问题 | 检查冷却和背景 |
| 信号不稳定 | 光路漂移或 detector 设置变化 | 固定设置并校准 |
| 与PMT数据不可比 | 探测器响应不同 | 不直接比较绝对灰度 |
| 弱信号无改善 | 样本/染料限制 | 优化染色和光路 |

## 小结

雪崩光电二极管是高速弱光和单光子检测的重要探测器。多数生物实验中它隐藏在共聚焦、寿命成像或单分子设备内部。使用这类设备时，记录 detector 类型、计数模式和饱和状态比只写“共聚焦拍摄”更可靠。
