# 氯仿

Chloroform（氯仿，化学式 CHCl3）是一种挥发性卤代有机溶剂，在 RNA 提取中最常见的用途是配合 [TRIzol](TRIzol.md) 或类似 phenol/guanidinium（酚/胍盐）裂解液进行 [相分离](<../番外/补充知识/相分离.md>)。加入氯仿后，离心可形成上层水相、中间层和下层有机相，使 RNA 与 DNA、蛋白和有机相杂质分开。

## 在 RNA 提取中的作用

| 作用 | 实验意义 |
| --- | --- |
| 促进相分离 | 让水相、有机相和中间层清楚分开 |
| 帮助分离 RNA 与蛋白/DNA | RNA 主要留在上层水相 |
| 去除部分疏水组分 | 将酚和蛋白等更多留在有机相 |

Invitrogen TRIzol 使用说明中，氯仿是相分离步骤的关键组分；加入氯仿、混匀并离心后，RNA 位于无色上层水相中。[参考：Invitrogen TRIzol User Guide](https://assets.thermofisher.com/TFS-Assets/LSG/manuals/trizol_reagent.pdf)

## 使用 protocol

### 加入氯仿

**怎么做**：在通风橱中按 TRIzol 说明比例加入氯仿，盖紧管盖，充分混匀，室温放置后离心。

**为什么**：混匀不足会导致相分离不完全；混匀过后需要足够离心形成清晰界面。

**注意事项**：

- 氯仿挥发且有毒，必须遵守 [通风橱使用规范](<../实验室安全/通风橱使用规范.md>)。
- 使用耐有机溶剂的管和密封良好的管盖。
- 离心后移动样本要轻，避免扰动中间层。

### 吸取水相

**怎么做**：只吸取上层水相，避免碰到白色中间层。宁可少取水相，也不要带入中间层。

**为什么**：中间层含 DNA 和蛋白，带入会降低 RNA 纯度并影响下游。

**注意事项**：

- 不要用宽口吸头吸水相。
- 吸取时保持管角度稳定。
- 相界面不清楚时重新离心。

## 安全注意

氯仿属于需要严肃对待的危险化学品。操作时应使用通风橱、合适手套、护目镜和实验服，并按 [危险化学品储存](<../实验室安全/危险化学品储存.md>)、[SDS与GHS标签](<../实验室安全/SDS与GHS标签.md>)、[实验室废弃物处理](<../实验室安全/实验室废弃物处理.md>) 要求处理。

不要把含氯仿、酚或 TRIzol 的废液倒入水槽。含卤代有机溶剂废液通常需要单独收集。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 相分离不清楚 | 混匀不足、离心条件不够、样本过量 | 重新充分混匀并离心，减少样本量 |
| RNA 有 DNA/蛋白污染 | 吸到中间层 | 更保守吸水相，必要时重新纯化 |
| 下游反应受抑制 | 氯仿/酚残留 | 增加洗涤或柱纯化 |
| 管盖泄漏 | 管不耐有机溶剂或盖不紧 | 使用合适离心管并确认密封 |

## 小结

氯仿在 TRIzol RNA 提取中负责把体系推向清晰相分离。它是有效但危险的有机溶剂：实验上要避免扰动中间层，安全上必须通风橱操作并按卤代有机废液处理。
