# 封闭液

## 一句话定义

Blocking buffer（封闭液）是在免疫检测中用于占据非特异结合位点的缓冲体系，目的是降低抗体、酶标物或荧光标记物对膜、细胞、组织或板孔表面的背景吸附。

在 [Western blot](<../用(实验流程内容篇)/Western blot.md>) 中，封闭液用于覆盖转膜后 [PVDF膜](PVDF膜.md) 或 [NC膜](NC膜.md) 上未被蛋白占据的结合位点；在 [免疫荧光](<../用(实验流程内容篇)/免疫荧光.md>)、[免疫组化](<../用(实验流程内容篇)/免疫组化.md>) 和 [ELISA](<../用(实验流程内容篇)/ELISA.md>) 中，封闭液用于降低抗体与细胞、组织切片或板孔的非特异结合。CST、Thermo Fisher、Bio-Rad 和 Abcam 的 WB protocol 都将 blocking 作为抗体孵育前的关键步骤。[参考：CST Western Blot Protocol](https://www.cellsignal.com/learn-and-support/protocols/protocol-western)；[参考：Thermo Fisher Western Blot Protocols](https://www.thermofisher.com/uk/en/home/life-science/protein-biology/protein-biology-learning-center/protein-gel-electrophoresis-information/western-blot-protocols.html)

## 为什么需要封闭

转膜后的膜、固定后的细胞或包被后的板孔表面仍然有很多“空位”。这些空位会吸附抗体或检测酶，造成背景。

可以简化理解为：

```text
未封闭表面
→ 抗体既结合目标，也乱粘表面
→ 背景高、假阳性、条带不干净

合适封闭
→ 封闭蛋白先占据空位
→ 抗体更集中识别目标
→ 背景降低、信噪比提高
```

封闭的目标不是让信号越低越好，而是让非特异背景下降，同时保留特异性目标信号。

## 常见封闭成分

| 成分 | 英文 | 适合场景 | 主要注意点 |
| --- | --- | --- | --- |
| [脱脂奶粉](脱脂奶粉.md) | Non-fat dry milk | 常规 WB、总蛋白检测 | 可能影响磷酸化抗体和 biotin/avidin 体系 |
| [BSA](BSA.md) | Bovine serum albumin | 磷酸化 WB、背景敏感抗体 | 成本较高，不同等级差异大 |
| [酪蛋白](酪蛋白.md) | Casein | ELISA、部分 WB、商业封闭液 | 本身是磷蛋白，磷酸化检测需谨慎 |
| [正常血清](正常血清.md) | Normal serum | IF/IHC 中降低二抗和 Fc 相关背景 | 血清物种要与二抗宿主匹配 |
| [鱼明胶](鱼明胶.md) | Fish gelatin | 部分荧光检测和低哺乳动物背景体系 | 不同产品差异大 |
| 商业封闭液 | Commercial blocking buffer | 高重复性、荧光 WB、疑难背景 | 成本高，配方未必公开 |

## 按实验选择封闭液

| 实验 | 常见选择 | 选择逻辑 |
| --- | --- | --- |
| 常规 WB 总蛋白 | 5% 脱脂奶粉/TBST | 便宜、封闭强、经验多 |
| 磷酸化 WB | 5% BSA/TBST | 避免奶粉中磷蛋白带来的干扰 |
| 荧光 WB | 低荧光商业封闭液或 BSA/TBST | 降低膜和封闭剂自发荧光 |
| IF/IHC | BSA、正常血清、鱼明胶 | 降低组织/细胞背景和 Fc 介导结合 |
| ELISA | BSA、casein、商业 ELISA blocker | 关注板孔封闭和低背景 |
| Biotin/streptavidin 体系 | 避免含生物素风险的封闭剂 | 防止生物素相关假信号 |

如果抗体说明书明确推荐某种封闭液，应优先遵循说明书。封闭液是抗体体系的一部分，不能只按习惯替换。

## WB封闭 protocol

### 常规封闭

1. 转膜后用 [Ponceau S](<Ponceau S.md>) 检查转膜。
2. 用 [TBST](TBST.md) 洗去 Ponceau S。
3. 加入足量封闭液，完全覆盖膜。
4. 室温轻摇 30-60 min，或按抗体说明书执行。
5. 倒去封闭液，进入 [一抗](一抗.md) 孵育。

### 封闭液体积

膜必须完全浸没，并且轻摇时能自由移动。液体太少会造成局部封闭不足，后续表现为边缘背景、斑块或不均一条带。

## 可调策略

| 问题 | 可调方向 |
| --- | --- |
| 背景高 | 延长封闭、换 BSA/商业封闭液、降低抗体浓度、加强洗膜 |
| 信号弱 | 缩短封闭、降低封闭剂浓度、换封闭剂、优化一抗 |
| 磷酸化背景异常 | 避免脱脂奶粉，优先 BSA |
| 荧光背景高 | 使用低荧光膜和低荧光封闭液 |
| IF/IHC 背景高 | 增加正常血清或 Fc receptor block（Fc 受体阻断） |

## 注意事项

- 封闭液和 [抗体稀释液](抗体稀释液.md) 可以相同，也可以不同，应按抗体说明书和预实验结果选择。
- 封闭过强会降低弱信号，封闭不足会提高背景。
- 不同膜材对封闭液响应不同，PVDF 背景通常更需要认真优化。
- 长时间保存的蛋白封闭液容易污染，浑浊或异味应弃用。
- 发表或长期项目中，应记录封闭液品牌、配方、浓度、时间和温度。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 整膜背景高 | 封闭不足、抗体过浓、洗膜不足 | 延长封闭，降低抗体浓度，增加 TBST 洗膜 |
| 信号整体变弱 | 封闭过强或封闭剂不合适 | 降低封闭剂浓度，换 BSA/奶粉/商业封闭液 |
| 磷酸化条带异常 | 使用了脱脂奶粉或 casein | 改用 BSA/TBST |
| 荧光图背景高 | 封闭液或膜自发荧光 | 换低荧光封闭液和低荧光膜 |
| 局部斑点 | 封闭液颗粒、膜未完全浸没 | 新鲜配制并充分溶解，使用足量液体 |

## 小结

封闭液决定免疫检测的背景底色。常规 WB 可以从脱脂奶粉开始，磷酸化和敏感目标优先考虑 BSA，荧光和 IF/IHC 则更需要低背景、低自发荧光和合适血清体系。封闭液不是固定配方，而是需要和抗体、膜、检测方式一起优化。
