# 无血清冻存液

Serum-free freezing medium（无血清冻存液）是不含 serum（血清）的细胞冻存介质，用于减少血清批次差异、动物源成分和未知组分对 [细胞冻存液](细胞冻存液.md) 的影响。它常用于原代细胞、干细胞、免疫细胞、细胞治疗相关研究或任何需要更高配方一致性的项目。

无血清不等于无 [DMSO](DMSO.md)。很多无血清冻存液仍然含 DMSO，只是把 [FBS](FBS.md) 或其他血清成分从体系中去掉。

## 名词边界

| 名词 | 英文 | 含义 | 需要注意 |
| --- | --- | --- | --- |
| 无血清 | Serum-free | 不含血清 | 可能仍含动物来源蛋白或 DMSO |
| 无动物源成分 | Animal component-free, ACF | 不含动物来源成分 | 不一定完全化学定义明确 |
| 无异种成分 | Xeno-free | 不含异种动物来源成分 | 人源成分可能存在 |
| 化学成分明确 | Chemically defined | 每种成分明确 | 成本高，适用范围需验证 |
| 无蛋白 | Protein-free | 不含蛋白 | 对部分细胞保护不足，需专用配方 |
| 无 DMSO | DMSO-free | 不含 DMSO | 不是所有细胞都适合，必须验证 |

STEMCELL Technologies 的 CryoStor 系列和 Thermo Fisher 的 Synth-a-Freeze 等产品都把 serum-free（无血清）、defined（成分明确）或 animal origin-free（无动物源）作为标准化冻存的重要卖点。[参考：STEMCELL CryoStor](https://www.stemcell.com/products/brands/cryostor.html)；[参考：Thermo Fisher Synth-a-Freeze](https://www.thermofisher.com/order/catalog/product/A1254201)

## 为什么要用无血清冻存液

| 需求 | 无血清冻存液的价值 |
| --- | --- |
| 降低批次差异 | 避免 FBS 批次改变导致复苏率和状态变化 |
| 减少动物源变量 | 对临床转化、GMP-like 项目和敏感细胞更友好 |
| 提高记录清晰度 | 商业产品通常有明确货号、批号和质量文件 |
| 保护敏感细胞 | 部分专用产品针对 stem cell、PBMC、T cell 等优化 |
| 简化配制 | 即用型产品减少自配误差 |

## 常见类型

| 类型 | 特点 | 适合场景 | 风险点 |
| --- | --- | --- | --- |
| 通用无血清冻存液 | 不含血清，常含 DMSO | 常规细胞系、初步标准化 | 不一定适合所有细胞 |
| 干细胞专用冻存液 | 面向 hPSC、MSC 等敏感细胞 | 干细胞培养、分化前库存 | 需要验证复苏后表型 |
| 免疫细胞冻存液 | 面向 PBMC、T cell、NK cell 等 | 流式、功能实验、细胞治疗研究 | 复苏后功能恢复可能需要休整 |
| DMSO-free 冻存液 | 用其他保护体系替代 DMSO | DMSO 敏感或临床特殊需求 | 不能默认优于含 DMSO 配方 |
| GMP-grade / cGMP-compatible | 质量文件更完整 | 转化研究、生产前开发 | 成本高，采购和记录要求更严 |

ATCC 的 Serum-Free Cell Freezing Medium 页面明确把 serum-free 作为避免血清变量的冻存产品方向之一。[参考：ATCC Serum-Free Cell Freezing Medium](https://www.atcc.org/products/30-2600)

## 与传统冻存液的区别

| 项目 | 传统含血清冻存液 | 无血清冻存液 |
| --- | --- | --- |
| 主要保护来源 | FBS + DMSO + 培养基 | DMSO 或替代保护剂 + 定义更清楚的保护组分 |
| 批次变量 | FBS 批次影响明显 | 批次通常更可控，但仍需记录 |
| 成本 | 通常较低 | 通常较高 |
| 配方透明度 | 自配可控，但血清复杂 | 商业产品常不完全公开 |
| 适用性 | 常规细胞系经验多 | 敏感细胞和标准化项目更常用 |
| 验证要求 | 仍需复苏验证 | 更需要按细胞类型验证 |

## 使用策略

### 初次替换时

**怎么做**：不要直接把整个细胞库都换成无血清冻存液。先用同一批健康细胞平行冻存传统配方和无血清配方，至少比较复苏后 24 h 活率/贴壁、3-7 天增殖恢复、形态和关键功能指标。

**为什么**：无血清冻存液减少了血清变量，但不保证对每一种细胞都更好。

**注意事项**：

- 对干细胞要观察 pluripotency marker（多能性标志物）或分化能力。
- 对免疫细胞要观察复苏后活率和功能恢复，不只看当天活率。
- 对原代细胞要注意复苏后是否更易衰老或失去表型。

**替代方案**：如果无血清配方复苏率略低但状态更稳定，可以根据项目目标取舍。

**出错后果**：盲目替换会造成整批细胞库复苏变差，且很难判断是细胞状态问题还是冻存液问题。

### 日常冻存时

**怎么做**：按产品说明书处理冻存液，控制细胞密度、DMSO 暴露时间和降温速率。分装后立即进入 [程序降温盒](程序降温盒.md) 或程序降温仪。

**为什么**：即使用了更高级的冻存液，控制降温和起始细胞质量仍然是冻存成功的核心。

**注意事项**：

- 无血清冻存液通常不建议随意添加 FBS 或培养基稀释。
- 产品开封后保存时间和冻融次数按说明书记录。
- 不同品牌无血清冻存液不能视为等价替换。

**替代方案**：对高价值细胞使用程序降温仪，并建立小规模复苏 QC。

**出错后果**：复苏率低、细胞功能变化、批间差异被误认为实验处理效应。

## 购买建议

优先选择有明确细胞类型适配范围、质量文件和批号追踪的产品。常见选择包括 [STEMCELL Technologies](<../番外/试剂厂商/STEMCELL Technologies.md>) 的 CryoStor / mFreSR 相关产品、[Gibco](<../番外/试剂厂商/Gibco.md>) 的 Synth-a-Freeze / Recovery 系列、[ATCC](<../番外/试剂厂商/ATCC.md>) 的细胞冻存介质，以及 [Sigma-Aldrich](<../番外/试剂厂商/Sigma-Aldrich.md>) / [Merck](<../番外/试剂厂商/Merck.md>) 的相关冻存产品。

采购时重点看：

- 是否 serum-free。
- 是否 animal component-free 或 xeno-free。
- 是否含 DMSO，浓度是多少。
- 是否适合你的细胞类型。
- 是否需要 2-8°C、-20°C 或 -80°C 保存。
- 是否有 sterility（无菌）、endotoxin（内毒素）或 mycoplasma（支原体）相关质控说明。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理策略 |
| --- | --- | --- |
| 复苏率低于含血清配方 | 细胞不适配该产品，密度或降温条件不合适 | 平行比较不同冻存液，优化密度和降温 |
| 复苏当天活率可以，后续生长差 | 冻存应激未完全恢复，培养条件或基质不匹配 | 延长恢复期，优化接种密度和培养表面 |
| 干细胞复苏后分化增加 | 单细胞压力、冻存液不适配、复苏支持不足 | 使用专用冻存液，按需加入 ROCK inhibitor（ROCK 抑制剂） |
| 免疫细胞功能变弱 | 复苏后未休整，冻存密度或 DMSO 条件不合适 | 设计复苏后恢复时间，验证功能指标 |
| 不同批次结果差异 | 产品批号、开封时间或保存条件不同 | 固定批号，记录开封和保存条件 |

## 小结

无血清冻存液的价值在于减少血清变量、提升标准化和适配敏感细胞，但它不是“更贵所以一定更好”。最重要的判断标准仍然是同一细胞在相同冻存、降温和复苏流程下的实际表现。
