# 酪蛋白

## 一句话定义

Casein（酪蛋白）是牛奶中的主要蛋白组分之一，在实验中常作为 blocking reagent（封闭剂）用于 Western blot、ELISA 和其他免疫检测，帮助降低抗体或检测分子对固相表面的非特异吸附。

酪蛋白是 [脱脂奶粉](脱脂奶粉.md) 里重要的封闭成分之一，也可作为定义更明确的 casein blocking buffer（酪蛋白封闭液）单独使用。Thermo Fisher、Bio-Rad 和多种免疫检测 protocol 都把 casein、BSA、milk 等列为常见封闭体系。[参考：Thermo Fisher Western Blot Protocols](https://www.thermofisher.com/uk/en/home/life-science/protein-biology/protein-biology-learning-center/protein-gel-electrophoresis-information/western-blot-protocols.html)；[参考：Bio-Rad Western Blotting Guide](https://www.bio-rad.com/applications-technologies/western-blotting-immunodetection-techniques?ID=PQEEPOBWLN4A)

## 核心特点

| 特点 | 说明 |
| --- | --- |
| 封闭能力强 | 能有效占据膜、板孔或组织中的非特异结合位点 |
| 常用于商业封闭液 | 许多 ELISA/WB blocker 以 casein 为基础 |
| 可能降低背景 | 对某些抗体体系比 BSA 或奶粉更干净 |
| 本身为磷蛋白 | phospho-antibody 检测时需要谨慎 |
| 批次和配方影响明显 | 不同 casein blocker 表现可能不同 |

酪蛋白的关键矛盾是：它封闭能力很好，但作为 phosphoprotein（磷蛋白）可能干扰 phospho-specific antibody（磷酸化特异性抗体）检测。

## 与其他封闭剂对比

| 封闭剂 | 优势 | 局限 |
| --- | --- | --- |
| 酪蛋白 | 封闭强，常用于 ELISA 和商业 blocker | 磷酸化检测需谨慎 |
| [BSA](BSA.md) | 成分更明确，适合磷酸化 WB | 成本较高，封闭强度可能不足 |
| 脱脂奶粉 | 便宜，常规 WB 好用 | 混合成分，可能干扰 phospho/biotin 体系 |
| [正常血清](正常血清.md) | IF/IHC 降低二抗宿主背景 | 成分复杂，不适合所有 WB |
| 蛋白-free blocker | 背景低，适合特殊体系 | 成本高，需验证兼容性 |

## 常见用途

- ELISA 板孔封闭。
- WB 膜封闭。
- 抗体稀释液中的背景降低组分。
- 商业 blocking buffer 的主要成分。
- 部分 lateral flow 或免疫层析体系。

## 使用策略

### WB中使用

1. 若常规 milk 或 BSA 背景不理想，可测试 casein blocker。
2. 用同一张膜或相同样本比较背景和目标信号。
3. 对磷酸化目标，避免把 casein 作为默认首选。
4. 记录具体产品，因为商业 casein blocker 配方差异较大。

### ELISA中使用

ELISA 对板孔背景非常敏感，casein blocker 常用于降低空白孔和阴性孔背景。选择时要关注是否与 [HRP标记二抗](HRP标记二抗.md)、[TMB](TMB.md)、[生物素](生物素.md)-[链霉亲和素](链霉亲和素.md) 系统兼容。

## 注意事项

- Casein 是磷蛋白，检测磷酸化蛋白或 phospho-specific antibody 时应谨慎。
- 不同厂家 casein blocker 可能含去污剂、防腐剂或稳定剂，不能只看“casein”这个名字。
- 乳源成分可能影响某些抗体或生物素相关体系。
- 商业 blocker 换品牌或换批号后，背景和信号可能改变。
- 若用于定量实验，应做封闭剂比较和线性范围确认。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 磷酸化 WB 背景高 | Casein 作为磷蛋白干扰 | 改用 BSA/TBST |
| ELISA 空白孔高 | 封闭不足或 blocker 不兼容 | 增加封闭时间，比较 BSA/casein |
| WB 信号弱 | 封闭过强或抗体受影响 | 降低浓度或换封闭剂 |
| 批次差异 | 商业 blocker 配方或批号变化 | 固定品牌货号并记录批号 |
| 生物素体系异常 | 乳源成分或 blocker 与体系不兼容 | 换专用 biotin-free blocker |

## 小结

酪蛋白是强力且常见的免疫检测封闭成分，尤其在 ELISA 和商业封闭液中常见。它不是 BSA 或脱脂奶粉的简单替代品：做磷酸化检测、biotin/streptavidin 体系或定量实验时，需要先验证兼容性。
