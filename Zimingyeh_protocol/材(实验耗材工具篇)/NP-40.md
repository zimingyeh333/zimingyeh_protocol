# NP-40

NP-40（Nonidet P-40，壬基酚聚氧乙烯醚类非离子去污剂）在实验语境中通常指温和 nonionic detergent（非离子去污剂）体系，用于细胞裂解、蛋白提取和 [免疫共沉淀](<../用(实验流程内容篇)/免疫共沉淀.md>)。需要注意的是，原始 Nonidet P-40 已不常作为同一产品销售，很多“NP-40”配方实际使用 IGEPAL CA-630、Tergitol-type NP-40 或其他替代品。

图源：Image2 生成的裂解去污剂与甘油参考图；NP-40 位于左下方，图中把它和 [Triton X-100](<Triton X-100.md>) 一起归为 mild nonionic detergents（温和非离子去污剂）。

## 核心作用

NP-40 类去污剂能溶解脂质膜并释放胞质和部分膜相关蛋白，通常比 [SDS](十二烷基硫酸钠.md) 温和，更适合需要保留部分蛋白互作或构象的实验。Thermo Fisher 的 RIPA buffer 产品资料列出其成分包括 1% NP-40、1% sodium deoxycholate、0.1% SDS、25 mM Tris-HCl、150 mM NaCl 和 EDTA，说明 NP-40 是经典 RIPA 强裂解体系中的非离子去污剂组分之一。参考：[Thermo Fisher RIPA Buffer](https://www.thermofisher.com/order/catalog/product/89900)。

Sigma-Aldrich 的 IGEPAL CA-630 I8896 SDS/产品资料可作为常见 NP-40 替代品线索；在实验记录中应写清到底使用了 “NP-40”、IGEPAL CA-630 还是其他替代品。参考：[Sigma-Aldrich IGEPAL CA-630 I8896 SDS](https://www.sigmaaldrich.com/US/en/sds/SIGMA/I8896)。

## NP-40命名为什么容易混乱

| 记录写法 | 可能真实含义 | 风险 |
| --- | --- | --- |
| NP-40 | 原始 Nonidet P-40 或广义 NP-40 类去污剂 | 不同实验室可能不是同一化学品 |
| IGEPAL CA-630 | 常见 NP-40 substitute（替代品） | 与原始 NP-40 物性不完全相同 |
| NP-40 Alternative/Substitute | 厂商替代产品 | 需看具体货号和说明书 |
| 只写“1% NP-40” | 信息不足 | 无法复现品牌、货号和替代关系 |

因此，正式记录时不要只写“NP-40 lysis buffer”，而应写清品牌、货号、是否为 substitute，以及最终浓度。

## 常见用途

| 场景 | 作用 | 注意点 |
| --- | --- | --- |
| 温和细胞裂解 | 释放胞质蛋白和部分膜相关蛋白 | 裂解核/强膜蛋白能力有限 |
| IP-WB | 相对温和，利于保留蛋白互作 | 去污剂浓度过高仍会破坏互作 |
| [RIPA裂解液](RIPA裂解液.md) | 作为非离子去污剂组分 | 与脱氧胆酸钠/SDS 合用后体系更强 |
| 核/胞质提取 | 可帮助破膜 | 需按分级 protocol 控制浓度 |

## NP-40 vs Triton X-100

| 比较点 | NP-40 类 | Triton X-100 |
| --- | --- | --- |
| 类型 | 非离子去污剂 | 非离子去污剂 |
| 常见用途 | 温和裂解、IP、RIPA | 温和裂解、透化、IP |
| 命名风险 | 原始产品和替代品混用严重 | 相对明确，但也有替代/限制问题 |
| 替换建议 | 不建议无记录地 1:1 替换 | 替换需重新验证裂解和互作 |

如果某个 protocol 写 “NP-40”，先确认其原文/实验室实际使用的货号；如果无法确认，建议从成熟商业裂解液或本实验室固定配方开始。

## 使用 protocol

### 配NP-40裂解液

**怎么做**：常见温和裂解液可含 0.1%-1% NP-40 类去污剂、[Tris](Tris.md) 或 [HEPES](HEPES.md)、[氯化钠](氯化钠.md)、[EDTA](EDTA.md)，现用前加入蛋白酶/磷酸酶抑制剂。

**为什么**：NP-40 提供破膜能力，盐和 buffer 调节蛋白溶解与互作稳定性，抑制剂保护样本。

**注意事项**：

- 用于 IP 时先从温和条件开始。
- 用于总蛋白 WB 时，如果目标难提取，可改用 RIPA 或更强裂解液。
- 黏稠样本常来自 DNA 释放，可通过澄清离心或轻微剪切处理。

### 替换Triton X-100

**怎么做**：如果要把 NP-40 替换为 Triton X-100，至少做平行比较：总蛋白量、目标蛋白信号、背景、IP pull-down 效率。

**为什么**：同为非离子去污剂不代表生物学结果完全相同，尤其是膜蛋白和蛋白复合物。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 不同实验室结果不一致 | “NP-40”实际产品不同 | 记录货号，固定品牌 |
| 目标蛋白提取低 | 裂解太温和 | 增加浓度、延长裂解或换 RIPA |
| IP 互作丢失 | 去污剂/盐浓度过高 | 降低 NP-40 或改更温和体系 |
| BCA 数据异常 | 去污剂浓度超出兼容范围 | 查 BCA 兼容表或稀释样本 |

## 小结

NP-40 的最大问题不是难用，而是“名字太容易写得不清楚”。它是温和裂解和 IP 中很有用的非离子去污剂，但每次都要记录真实产品、货号和终浓度，否则复现实验时很容易踩坑。
