# β-甘油磷酸

β-甘油磷酸（beta-glycerophosphate，β-GP；常用形式为 beta-glycerophosphate disodium salt hydrate，β-甘油磷酸二钠盐水合物）是一种常见 serine/threonine phosphatase inhibitor（丝氨酸/苏氨酸磷酸酶抑制剂）组分，常加入裂解液以保护磷酸化蛋白信号。

![磷酸酶抑制剂成分参考图](../z_asset/材/磷酸酶抑制剂成分/phosphatase-inhibitor-components-reference.png)

图源：Image2 生成的磷酸酶抑制剂成分参考图；β-甘油磷酸位于左下方，和 [氟化钠](氟化钠.md)、[焦磷酸钠](焦磷酸钠.md) 一起主要用于 serine/threonine phosphatase 相关保护。

## 核心作用

β-甘油磷酸常作为 phosphate analog/substrate-like inhibitor（磷酸盐类似物/底物类似抑制组分）加入裂解液，帮助抑制部分丝氨酸/苏氨酸磷酸酶，从而减少样本制备过程中的去磷酸化。

Thermo Scientific Halt Phosphatase Inhibitor Cocktail 页面说明该 cocktail 含 sodium fluoride、sodium orthovanadate、sodium pyrophosphate 和 beta-glycerophosphate，并可保护 serine、threonine 和 tyrosine phosphorylation。参考：[Thermo Fisher Halt Phosphatase Inhibitor Cocktail](https://www.thermofisher.com/order/catalog/product/78420)。

Sigma-Aldrich 的 β-glycerophosphate G9422 页面列出其为 BioUltra 级 beta-glycerophosphate disodium salt hydrate，可用于生化和细胞相关实验配方。参考：[Sigma-Aldrich β-Glycerophosphate G9422](https://www.sigmaaldrich.com/US/en/product/sigma/g9422)。

## 常见用途

| 场景 | 为什么会用到 |
| --- | --- |
| phospho-WB 裂解液 | 抑制部分 serine/threonine phosphatases |
| kinase assay（激酶实验）buffer | 维持磷酸化相关反应环境 |
| 信号通路样本收集 | 降低裂解后去磷酸化 |
| 自配 phosphatase inhibitor mix | 与 NaF、原钒酸钠、焦磷酸钠互补 |

## β-甘油磷酸 vs NaF vs 焦磷酸钠

| 试剂 | 常见定位 | 备注 |
| --- | --- | --- |
| [氟化钠](氟化钠.md) | 广泛用于 serine/threonine phosphatase 抑制 | 有毒，常配高浓度水溶液 |
| β-甘油磷酸 | 常作为 serine/threonine phosphatase 抑制组分 | 常见于 kinase/phosphatase buffer |
| [焦磷酸钠](焦磷酸钠.md) | phosphate/pyrophosphate 类抑制组分 | 可影响金属离子和 buffer 环境 |
| [原钒酸钠](原钒酸钠.md) | tyrosine phosphatase 抑制 | 偏向 phospho-tyrosine 保护 |

这些组分常常不是互相替代，而是共同构成覆盖更广的 phosphatase inhibitor cocktail。

## 使用 protocol

### 配储液

**怎么做**：按目标配方称量 β-甘油磷酸二钠盐水合物，溶于水或合适 buffer，必要时过滤后分装。

**为什么**：不同水合状态和盐形式会影响质量-摩尔浓度换算；记录形式可以减少重复实验误差。

**注意事项**：

- 写清楚是 beta-glycerophosphate 还是 alpha/beta 混合物。
- 写清楚是否为 disodium salt hydrate（二钠盐水合物）。
- 不要只写“加 β-GP”，要写终浓度和储液形式。

### 加入裂解液

**怎么做**：裂解前加入预冷裂解液，常与 NaF、原钒酸钠、焦磷酸钠和 [蛋白酶抑制剂](蛋白酶抑制剂.md) 同时使用。

**为什么**：磷酸化状态变化快，抑制剂必须在裂解开始时已经存在。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| phospho-ser/thr 信号不稳定 | β-GP 漏加或终浓度不一致 | 固定储液和终浓度 |
| 和文献配方不一致 | 盐形式/水合状态不同 | 重新按分子量换算 |
| 样本 buffer 离子强度变化 | β-GP 浓度较高或和其他盐叠加 | 检查最终配方总盐浓度 |
| 只保护部分位点 | 抑制谱不够 | 使用商业广谱 cocktail |

## 小结

β-甘油磷酸是 phospho-WB 裂解液中很常见的 serine/threonine phosphatase 抑制组分。它不应被孤立理解，而应和 NaF、焦磷酸钠、原钒酸钠一起看成“覆盖不同磷酸酶活动”的组合。
