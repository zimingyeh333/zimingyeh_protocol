# 丙烯酰胺

丙烯酰胺（acrylamide）是制备 polyacrylamide gel（聚丙烯酰胺凝胶）的单体，是手灌 [SDS-PAGE凝胶](SDS-PAGE凝胶.md) 的核心原料之一。它通常与 [双丙烯酰胺](双丙烯酰胺.md)（N,N'-methylenebisacrylamide，N,N'-亚甲基双丙烯酰胺）共同聚合，形成用于蛋白分离的凝胶网络。

## 核心作用

丙烯酰胺负责形成凝胶主体，双丙烯酰胺作为交联剂。两者在 [过硫酸铵](过硫酸铵.md)（ammonium persulfate，APS）和 [TEMED](TEMED.md)（N,N,N',N'-tetramethylethylenediamine，四甲基乙二胺）催化下发生自由基聚合，形成具有一定孔径的聚丙烯酰胺凝胶。

凝胶孔径决定蛋白迁移阻力：丙烯酰胺总浓度越高，凝胶孔径越小，更适合小分子量蛋白；总浓度越低，孔径越大，更适合大分子量蛋白。

Bio-Rad 的 Acrylamide/Bis-acrylamide solutions 页面说明，预混 acrylamide/bis-acrylamide 溶液可用于制备聚丙烯酰胺凝胶，并提供 29:1、37.5:1 等交联比例选择。参考：[Bio-Rad Acrylamide/Bis-acrylamide Solutions](https://www.bio-rad.com/en-us/category/acrylamide-bis-acrylamide-solutions)。

## Acrylamide/Bis比例是什么意思

| 比例 | 含义 | 常见理解 |
| --- | --- | --- |
| 29:1 | acrylamide:bis-acrylamide = 29:1 | 常见 SDS-PAGE 手灌胶比例 |
| 37.5:1 | acrylamide:bis-acrylamide = 37.5:1 | 交联剂相对更少，孔径/弹性略有差异 |
| 19:1 | 交联剂比例更高 | 某些特殊凝胶体系 |

记录时不要只写“30% acrylamide”，还要写清是 29:1、37.5:1 还是其他比例。比例不同，凝胶机械强度、孔径和分离效果都会变化。

## 常见浓度选择

| 目标蛋白大小 | 常见胶浓度 | 说明 |
| --- | --- | --- |
| >150 kDa | 6%-8% | 大孔径利于大蛋白进入 |
| 30-150 kDa | 8%-12% | 常规 WB 最常见范围 |
| <30 kDa | 12%-15% | 小孔径提高小蛋白分辨率 |
| 多目标宽范围 | 梯度胶 | 手灌较复杂，预制梯度胶更稳 |

## 手灌胶 vs 预制胶

| 方案 | 优点 | 局限 |
| --- | --- | --- |
| 手灌胶 | 成本低，浓度和体系可自定义 | 丙烯酰胺毒性高，批间变异大 |
| 预制胶 | 稳定、省时、安全暴露少 | 成本高，依赖厂商体系 |
| 梯度预制胶 | 分离范围宽 | 价格更高 |

对于刚建立 WB 条件、目标蛋白分子量不确定或需要高重复性的数据，预制胶通常更省心。手灌胶更适合预算有限、需要特殊浓度或已有成熟操作经验的实验室。

## 使用 protocol

### 配胶前检查

**怎么做**：确认 acrylamide/bis 溶液浓度、比例、有效期、保存条件、是否有沉淀或变色。

**为什么**：旧溶液、污染或比例错误会导致聚合慢、胶软、分离差。

**注意事项**：

- 未聚合丙烯酰胺有神经毒性，必须戴手套、护目镜、实验服，并避免皮肤接触。
- 手灌胶废液和残液按化学危害废液处理。
- 不要用口头“老配方”代替详细记录。

### 聚合

**怎么做**：按分离胶/浓缩胶配方加入 buffer、SDS、水、acrylamide/bis 溶液，最后加入 APS 和 TEMED，混匀后立即灌胶。

**为什么**：APS/TEMED 加入后聚合开始，拖延会导致胶未灌好就局部聚合。

**可能出错的结果**：

- APS 失效：胶长时间不凝。
- TEMED 漏加：几乎不聚合。
- 氧气干扰：胶面不平或聚合不完全。
- 丙烯酰胺比例错：条带分辨率异常。

## 安全重点

未聚合 acrylamide 是手灌胶中最需要重视的安全点。Sigma-Aldrich acrylamide SDS 将其列出多种健康危害，包括急性毒性、皮肤吸收风险和神经系统相关危害；正式操作必须查看本实验室所用产品 SDS。参考：[Sigma-Aldrich Acrylamide A9099](https://www.sigmaaldrich.com/US/en/product/sigma/a9099)。

聚合后的 polyacrylamide gel 风险显著低于单体溶液，但仍可能残留少量单体和染料/样本污染，因此废胶也应按实验室规定收集。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 胶不凝 | APS/TEMED 漏加或失效，丙烯酰胺太旧 | 换新 APS/TEMED 和 acrylamide |
| 胶太软 | 总浓度低、交联比例不合适 | 核对配方和 acrylamide/bis 比例 |
| 条带歪斜 | 灌胶不平、漏液、聚合不均 | 重新装板并排查漏液 |
| 小蛋白分辨率差 | 胶浓度太低 | 提高胶浓度 |
| 大蛋白进胶差 | 胶浓度太高 | 降低胶浓度或用梯度胶 |

## 小结

丙烯酰胺决定手灌 SDS-PAGE 胶的孔径和分离窗口，也是安全风险最高的 WB 前处理试剂之一。使用时既要写清浓度和 Acrylamide:Bis 比例，也要把 APS、TEMED、聚合时间和安全处理记录下来。
