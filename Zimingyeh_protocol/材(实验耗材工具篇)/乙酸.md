# 乙酸

## 一句话定义

Acetic acid（乙酸，CH3COOH）是一种常见弱酸和有机酸，在生命科学实验中常用于配制酸性染色液、固定/脱色体系、缓冲体系或清洗体系。

在 [Ponceau S](<Ponceau S.md>) 染色液中，乙酸常用于提供酸性环境，帮助丽春红 S 与膜上蛋白形成可逆染色。PubChem 收录了 acetic acid 的基本化学信息；浓乙酸和冰乙酸具有腐蚀性和挥发刺激性，处理时需要参考 SDS 和实验室安全要求。[参考：PubChem Acetic Acid](https://pubchem.ncbi.nlm.nih.gov/compound/Acetic-Acid)

## 常见形式

| 名称 | 英文 | 理解 |
| --- | --- | --- |
| 乙酸 | Acetic acid | 泛指乙酸本身或水溶液 |
| 冰乙酸 | Glacial acetic acid | 高浓度乙酸，通常接近无水，腐蚀性和刺激性更强 |
| 稀乙酸 | Dilute acetic acid | 按比例稀释后的水溶液 |

实验记录中不要只写“加乙酸”。应写清楚是冰乙酸、百分比浓度、体积比还是最终浓度。

## 常见用途

| 用途 | 说明 |
| --- | --- |
| Ponceau S 染色液 | 常见酸性染色环境 |
| 蛋白胶染色/脱色 | 某些 Coomassie staining（考马斯染色）和 destaining（脱色）体系会用到 |
| 固定体系 | 与甲醇等配合用于部分凝胶或组织处理 |
| pH 调整 | 小范围酸化或缓冲体系组分 |

乙酸是常用试剂，但不同实验里的作用不同：有时是提供酸性环境，有时是帮助固定，有时是参与脱色。不能只靠名称推断功能。

## 配制注意事项

- 稀释冰乙酸时，应在通风橱内操作，避免吸入刺激性蒸气。
- 按实验室安全培训要求佩戴 [个人防护装备](<../实验室安全/个人防护装备.md>)。
- 需要精确浓度时，用容量瓶或校准移液器配制。
- 标签写清楚浓度、配制日期、配制人和用途。
- 含乙酸废液按 [实验室废弃物处理](<../实验室安全/实验室废弃物处理.md>) 要求分类。

## Ponceau S中的作用

Ponceau S 常见自配配方可写作：

```text
0.1% Ponceau S
5% acetic acid
ddH2O
```

这里乙酸的作用是形成酸性染色环境，使总蛋白在膜上出现可见红色条带，同时保持染色可逆。染色后通常用水或 TBST 洗去背景，再进入封闭。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 配方不可重复 | 只记录“乙酸”但没记录浓度 | 写清冰乙酸体积、终浓度和总体积 |
| 刺激性气味明显 | 通风不足或开盖时间太长 | 在通风橱中操作，缩短暴露时间 |
| 染色背景异常 | 乙酸比例或染料浓度错误 | 重配染色液，核对百分比算法 |
| 标签不清 | 二次容器未标明浓度 | 重新贴标签，写明配制日期和风险 |

## 小结

乙酸是非常常见的基础化学试剂，但越常见越容易记录含糊。涉及乙酸的 protocol 应写清楚“哪种乙酸、什么浓度、用于什么目的”，尤其是 Ponceau S、考马斯染色和固定/脱色体系。
