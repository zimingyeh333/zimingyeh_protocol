# 电泳电源

电泳电源（electrophoresis power supply）是为 [电泳槽](电泳槽.md)、转膜系统或其他电泳设备提供可控电压、电流和功率输出的设备。在 [SDS-PAGE](<../用(实验流程内容篇)/SDS-PAGE.md>) 中，它决定蛋白分离时的电场条件；在 [Western blot](<../用(实验流程内容篇)/Western blot.md>) 转膜中，它也常用于控制湿转或半干转膜条件。

## 核心作用

电泳电源把普通交流电转换为实验所需的直流输出，并允许设置 constant voltage（恒压）、constant current（恒流）或 constant power（恒功率）模式。Bio-Rad PowerPac Basic Power Supply 官方页面说明，该电源适用于水平和 mini vertical gel electrophoresis（小型垂直胶电泳）等基础应用，可提供 timer control（计时控制）以及 constant-voltage 或 constant-current output（恒压或恒流输出）。参考：[Bio-Rad PowerPac Basic Power Supply](https://www.bio-rad.com/en-us/product/powerpac-basic-power-supply?ID=bea5dea1-cef0-43ad-8af5-b2c0287f6e07)。

Thermo Fisher 的 PowerEase Touch power supplies 页面也列出不同功率电源可用于蛋白胶、核酸胶和转膜，并支持 constant voltage、constant current 和 constant power 等模式。参考：[Thermo Fisher Electrophoresis Power Supplies](https://www.thermofisher.com/us/en/home/life-science/protein-biology/protein-gel-electrophoresis/power-supplies-protein-electrophoresis.html)。

## 恒压、恒流、恒功率怎么选

| 模式 | 英文 | 逻辑 | 常见场景 |
| --- | --- | --- | --- |
| 恒压 | Constant voltage | 电压固定，电流随体系电阻变化 | SDS-PAGE 最常见 |
| 恒流 | Constant current | 电流固定，电压随电阻变化 | 某些转膜或特殊电泳 |
| 恒功率 | Constant power | 功率固定，电压/电流自动调节 | 高级电源和特定 protocol |

日常 SDS-PAGE 通常按 protocol 设置恒压，例如 stacking gel 低电压、resolving gel 较高电压。湿转则常见恒流或恒压条件，具体取决于设备和膜/胶体系。

## 关键参数

| 参数 | 为什么要记录 |
| --- | --- |
| 电压 V | 决定电场强度和迁移速度 |
| 电流 mA | 反映体系电导和发热情况 |
| 功率 W | 与发热直接相关 |
| 时间 | 决定分离或转膜程度 |
| 起始/结束电流 | 帮助判断 buffer、漏液、短路或发热 |
| 同时连接槽数 | 影响总电流和安全 |

如果只记录“跑 90 min”，没有记录电压/电流，后续很难复现实验。

## 使用 protocol

### 连接设备

**怎么做**：确认电泳槽盖好，红线接正极、黑线接负极，导线插牢，再启动电源。

**为什么**：电泳和转膜的方向依赖极性。接反可能导致样本跑出胶、蛋白转错方向或完全失败。

**注意事项**：

- 不要开盖通电。
- 不要让 buffer 溢到电源或导线接口。
- 不要超过电泳槽、电源和导线的额定范围。

### 设置运行条件

**怎么做**：按胶体系和 protocol 设置恒压/恒流/恒功率、时间和上限参数；运行前记录预期条件，运行中观察电流是否异常。

**为什么**：电流突然过高可能提示短路或 buffer 太浓；电流为零可能提示断路、没盖好或 buffer 没接通。

**替代策略**：

- 条带笑脸或发热明显：降低电压、减少同时运行胶数或改善散热。
- 小蛋白跑出：缩短时间或降低电压。
- 大蛋白分离不足：适当延长时间或优化胶浓度，而不是盲目拉高电压。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 电流为零 | 盖子未闭合、导线松、buffer 未连通 | 检查盖子、导线和液面 |
| 电流过高 | buffer 过浓、短路、漏液 | 停止运行，检查 buffer 和槽体 |
| 电源报警 | 过载、短路、无负载、安全联锁触发 | 按说明书排查，不要强行继续 |
| 条带笑脸 | 电压过高或发热 | 降低电压，控制温度 |
| 多槽同时跑结果不同 | 负载不均或连接方式不同 | 分开运行或统一槽和胶条件 |

## 安全重点

电泳电源同时涉及电和液体，安全优先级很高。不要湿手操作电源，不要在电源附近放置开放 buffer，运行中不要打开电泳槽盖。出现漏液、焦味、异常发热或电源报错时，先断电再处理。

现代电源通常有 no-load detection（无负载检测）、overload/short-circuit detection（过载/短路检测）等安全功能，但这些功能不是违规操作的替代品。

## 小结

电泳电源是 SDS-PAGE 和转膜条件的“控制台”。只记录时间远远不够；真正可复现的记录要包括模式、电压、电流、功率、运行时间和异常报警。
