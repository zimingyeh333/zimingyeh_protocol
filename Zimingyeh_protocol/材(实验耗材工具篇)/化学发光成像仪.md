# 化学发光成像仪

化学发光成像仪（chemiluminescence imager / chemiluminescent western blot imaging system）是用于记录 [ECL发光液](ECL发光液.md) 等化学发光信号的成像设备，常用于 [Western blot](<../用(实验流程内容篇)/Western blot.md>) 中 HRP-ECL 检测体系的图像采集和定量分析。

![SDS-PAGE运行与成像参考图](../z_asset/材/SDS-PAGE运行与成像/sds-page-running-imaging-reference.png)

图源：Image2 生成的 SDS-PAGE 运行与成像参考图；右侧为化学发光成像仪，底部第四步示意 ECL image capture（ECL 图像采集）。

## 核心作用

化学发光成像仪通过暗箱、镜头和高灵敏相机记录 ECL 反应产生的光信号。相比 X-ray film（X 光胶片），数字成像仪更容易保留线性范围、曝光参数和原始图像文件，适合定量和重复分析。

Bio-Rad ChemiDoc Imaging System 官方资料说明，该系统可用于 chemiluminescent western blotting（化学发光 Western blot）、fluorescent western blotting（荧光 Western blot）以及凝胶/膜成像。参考：[Bio-Rad ChemiDoc Imaging System](https://www.bio-rad.com/en-us/product/chemidoc-imaging-system)。

## 主要部件

| 部件 | 作用 | 对结果的影响 |
| --- | --- | --- |
| 暗箱 | 阻断环境光 | 漏光会增加背景 |
| 镜头 | 聚焦和收集光 | 污染/失焦会让条带模糊 |
| [CCD相机](CCD相机.md) 或 [sCMOS相机](sCMOS相机.md) | 记录弱光信号 | 灵敏度、噪声和动态范围决定成像质量 |
| 托盘/样品台 | 放置膜或胶 | 摆放不平会影响对焦 |
| 软件 | 曝光、饱和提示、定量 | 原始数据保存和分析流程很关键 |

## 成像策略

| 策略 | 目的 | 说明 |
| --- | --- | --- |
| 多曝光 | 找到未饱和图像 | 同一张膜采集短、中、长曝光 |
| 自动曝光 | 快速获得可见图像 | 仍需检查是否饱和 |
| 手动曝光 | 固定批次比较 | 适合重复实验统一参数 |
| ROI 定量 | 计算条带强度 | 必须避免饱和并统一背景扣除 |
| 保存原始文件 | 保留分析证据 | 不只保存截图或压缩图 |

用于定量的 WB 图像不能饱和。条带“很黑”或“很亮”并不等于数据好；一旦超过相机线性范围，条带强度就不能可靠比较。

## 化学发光成像 vs 胶片 vs 荧光成像

| 方式 | 优点 | 局限 |
| --- | --- | --- |
| 化学发光成像仪 | 数字化、可多曝光、便于定量 | 依赖 ECL 发光持续时间和相机灵敏度 |
| X-ray film | 传统、成本低、视觉直观 | 动态范围窄，定量差，暗室/显影麻烦 |
| 荧光成像仪 | 多通道、动态范围较宽 | 需要荧光二抗和对应设备 |

如果实验目标是发表级定量，数字成像仪通常优于胶片；如果要多蛋白同膜检测，荧光 Western blot 可能更适合。

## 使用 protocol

### 成像前准备

**怎么做**：完成 ECL 孵育后去除多余液体，将膜蛋白面朝上平放在托盘或保护膜上，避免气泡、液滴和褶皱。

**为什么**：液滴会造成亮斑或反光，褶皱会导致局部失焦。

**注意事项**：

- 不要让膜干掉，除非 protocol 特别允许。
- 每次成像前检查托盘洁净。
- 强信号样本先短曝光。

### 采集图像

**怎么做**：先采集短曝光，再逐步延长；或使用自动曝光后检查饱和提示。保存原始格式和导出图。

**为什么**：ECL 信号会随时间变化，多曝光能兼顾强弱条带并避免过曝。

**替代策略**：

- 低丰度蛋白可用高灵敏 ECL 或更长曝光。
- 高丰度蛋白可降低抗体浓度、减少上样量或使用标准 ECL。
- 若背景高，不要只缩短曝光，要回到封闭、洗膜、抗体浓度排查。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 条带饱和 | 曝光太久、ECL 太灵敏、抗体太浓 | 使用短曝光，降低抗体或上样量 |
| 图像有亮点 | 膜面液滴、灰尘、托盘污染 | 去除液滴，清洁托盘 |
| 背景不均 | ECL 覆盖不均、膜褶皱、成像台不洁 | 重新均匀覆盖并平放膜 |
| 信号衰减快 | ECL 已过峰值或膜干燥 | 加 ECL 后及时成像 |
| 无信号 | 抗体/ECL/转膜问题或曝光太短 | 检查阳性对照和 [Ponceau S](Ponceau S.md) |
| 定量结果不可信 | 使用了饱和图或只保存截图 | 保留未饱和原始文件 |

## 小结

化学发光成像仪不是简单的“拍照机器”，而是 WB 定量链条的一部分。可靠成像需要未饱和曝光、原始文件保存、统一参数和清楚的背景扣除策略。
