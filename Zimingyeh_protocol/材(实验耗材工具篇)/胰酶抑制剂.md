# 胰酶抑制剂

Trypsin inhibitor（胰蛋白酶抑制剂，简称胰酶抑制剂）是一类能抑制 trypsin（胰蛋白酶）活性的试剂，细胞培养中最常见的是 soybean trypsin inhibitor（SBTI，大豆胰蛋白酶抑制剂）。它常用于在无血清或低血清流程中终止 [Trypsin-EDTA](Trypsin-EDTA.md) 对细胞的继续消化。

Thermo Fisher 的 trypsin inhibitor 产品说明将其用于 neutralization（中和）trypsin，尤其适合不希望用血清终止胰酶的细胞培养体系。[参考：Thermo Fisher Trypsin Inhibitor](https://www.thermofisher.com/order/catalog/product/R007100)

## 为什么需要胰酶抑制剂

常规细胞传代里，很多人直接用含 [FBS](FBS.md)（Fetal bovine serum，胎牛血清）的完全培养基终止胰酶，因为血清中有多种蛋白和蛋白酶抑制成分。但在以下场景，血清终止并不理想：

- 无血清培养体系，不希望引入 FBS。
- 原代细胞、干细胞或临床前规范化流程，希望减少未定义成分。
- 后续实验对血清蛋白敏感，例如部分蛋白检测、分泌因子检测或表面结合实验。
- 希望更明确记录终止胰酶的试剂和条件。

## 核心作用

| 作用 | 实验意义 |
| --- | --- |
| 抑制 trypsin 活性 | 防止胰酶继续切割细胞表面蛋白 |
| 替代血清终止 | 支持无血清或低血清体系 |
| 降低消化过度风险 | 对敏感细胞和表面 marker 更友好 |
| 让流程更可记录 | 比“加一点血清培养基”更可控 |

胰酶抑制剂主要用于 trypsin；对于 [TrypLE](TrypLE.md)、[Accutase](Accutase.md) 等商业解离液，是否需要或适合使用胰酶抑制剂应按产品说明和细胞类型判断。

## 胰酶抑制剂 vs 血清终止

| 方式 | 优点 | 缺点 |
| --- | --- | --- |
| 含血清培养基终止 | 方便、便宜、常规细胞够用 | 成分复杂，引入血清变量 |
| 胰酶抑制剂终止 | 更定义化，适合无血清体系 | 需要额外试剂和浓度验证 |
| 离心换液去除胰酶 | 不依赖抑制剂或血清 | 多一步操作，可能损失细胞 |
| 稀释降低酶活 | 简单 | 对强酶残留控制不够明确 |

如果是普通细胞系传代，含血清培养基通常足够；如果是无血清、敏感细胞或需要严格记录的流程，胰酶抑制剂更有价值。

## 使用 protocol

### 选择和准备

**怎么做**：选择细胞培养级 soybean trypsin inhibitor 或商业 trypsin neutralizing solution。按说明配制、过滤除菌或解冻保存。

**为什么**：胰酶抑制剂会直接接触细胞，细胞培养用途应保证无菌、合适 pH 和渗透压。

**注意事项**：

- 不同产品单位和推荐用量不同，不能只按体积照搬。
- 开封后记录日期和储存条件。
- 如果下游是蛋白定量或蛋白酶相关实验，考虑抑制剂残留影响。

### 终止 Trypsin-EDTA

**怎么做**：细胞达到消化终点后，加入足量胰酶抑制剂或 trypsin neutralizing solution，轻轻混匀，再离心或直接重悬进入下游流程。

**为什么**：终止越及时，细胞表面蛋白继续被切割的风险越低。

**注意事项**：

- 先确认目标产品是否设计用于细胞培养。
- 不要在细胞还没脱落时过早加入抑制剂。
- 需要完全去除残留时，终止后离心换液。

**替代方案**：可用含血清培养基终止；无血清体系可用商业 trypsin neutralizer；对非胰酶类解离液按说明稀释或洗去。

### 下游兼容性

**怎么做**：终止后根据下游需求决定是否离心洗涤。流式、蛋白检测、分泌因子检测或功能实验前尤其要考虑残留蛋白影响。

**为什么**：胰酶抑制剂本身是蛋白，可能影响某些检测背景或反应体系。

**注意事项**：

- 如果要测细胞分泌蛋白，避免把外源蛋白带入培养上清。
- 如果要做无血清功能实验，终止后通常需要换成目标培养基。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 传代后细胞恢复差 | 终止太晚，胰酶过度作用 | 缩短消化时间，提前准备抑制剂 |
| 仍有酶残留影响 | 抑制剂不足或混匀不充分 | 按单位重新计算，充分混匀后换液 |
| 下游背景高 | 抑制剂蛋白残留 | 终止后离心洗涤，换成目标缓冲液 |
| 无血清体系状态波动 | 抑制剂、洗液或培养基不匹配 | 固定品牌批号，做小规模兼容性测试 |

## 小结

胰酶抑制剂不是每次传代都必须用，但它是无血清、低血清、敏感细胞和高可控 SOP 中很有用的“明确终止工具”。它解决的是血清终止不够定义化的问题。
