# 光电倍增管

## 一句话定义

PMT（Photomultiplier tube，光电倍增管）是一种高灵敏光电探测器，能把微弱光信号转换成电子并通过倍增过程放大，常用于 [共聚焦显微镜](共聚焦显微镜.md)、流式细胞术和其他弱光检测系统。

PMT 的优势是灵敏度高、响应快，适合扫描式检测；局限是动态范围、线性、量子效率和噪声表现取决于具体型号和设置。Hamamatsu 是 PMT 主要厂家之一，其资料将 PMT 描述为通过光电阴极和多级 dynode（打拿极）实现光电子倍增的探测器。[参考：Hamamatsu Photomultiplier Tubes](https://www.hamamatsu.com/us/en/product/optical-sensors/pmt.html)；[参考：Nikon MicroscopyU PMT](https://www.microscopyu.com/microscopy-basics/photomultipliers)

## 工作原理

```text
光子进入PMT
→ 光电阴极释放电子
→ 电子撞击多级打拿极
→ 电子数量倍增
→ 阳极收集电流
→ 转换为检测信号
```

PMT 不是相机，它通常不直接形成二维图像，而是在扫描系统中逐点记录强度，再由扫描位置重建图像。

## 常见用途

| 场景 | 为什么用PMT |
| --- | --- |
| 激光扫描共聚焦 | 点扫描信号弱，需要快速灵敏检测 |
| 流式细胞术 | 单细胞高速通过，信号短暂 |
| 荧光寿命/光子计数 | 需要快速响应 |
| 弱光检测 | 电子倍增提供高灵敏度 |

现代设备也可能使用 hybrid detector（混合探测器）、GaAsP PMT、APD 或 sCMOS 等。不能只看“PMT”三个字，要看具体探测器类型。

## PMT vs sCMOS相机

| 维度 | PMT | [sCMOS相机](sCMOS相机.md) |
| --- | --- | --- |
| 检测方式 | 点/线扫描检测 | 面阵成像 |
| 常见设备 | 共聚焦、流式 | 宽场、转盘共聚焦、高通量 |
| 时间响应 | 很快 | 取决于帧率 |
| 图像形成 | 依赖扫描重建 | 相机直接成像 |
| 适合 | 弱光点扫描、高速流式 | 大视野、快速二维成像 |

## PMT vs APD/HyD

| 探测器 | 特点 |
| --- | --- |
| PMT | 经典、灵敏、快速 |
| [雪崩光电二极管](雪崩光电二极管.md) | APD，适合某些单光子或高灵敏检测 |
| [混合探测器](混合探测器.md) | Hybrid detector，结合不同探测技术优势 |

共聚焦设备上不同 detector 的信噪比和线性表现可能差异很大，做定量成像时应记录具体 detector。

## 关键设置

| 设置 | 影响 |
| --- | --- |
| PMT voltage / gain | 信号放大和噪声 |
| Offset / black level | 背景基线 |
| Laser power | 激发强度和光漂白 |
| Pinhole | 光学切片和信号量 |
| Scan speed | 信噪比和光照剂量 |

提高 PMT gain 可以让图像看起来更亮，但也可能放大噪声。不要用 detector gain 替代好的染色和合适激光设置。

## 注意事项

- PMT 可能被过强光损伤，避免强光直射和设置错误。
- 图像饱和后不能用于定量。
- 不同 PMT gain 下的强度值不能直接比较。
- 多通道共聚焦要考虑 [光谱重叠](../番外/补充知识/光谱重叠.md) 和串色。
- 记录 detector 类型、gain、offset、laser power 和扫描参数。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 图像噪声很大 | gain 太高、信号太弱 | 降低 gain，增加真实信号或 averaging |
| 信号饱和 | gain 或 laser 太高 | 降低设置，检查 histogram |
| 不同组不可比 | detector 设置不同 | 固定 PMT/gain/laser 参数 |
| 背景高 | offset/gain 不合适或染色背景 | 调整设置并优化染色 |
| 某通道无信号 | detector/滤光片/激光不匹配 | 检查光路和通道配置 |

## 小结

光电倍增管是共聚焦和流式等弱光检测系统中的经典探测器。它能让弱信号被放大，但也会放大噪声和设置差异。定量实验必须固定并记录 PMT/gain/offset/laser 等参数。
