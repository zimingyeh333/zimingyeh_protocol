# 正常血清

## 一句话定义

Normal serum（正常血清）是来自未免疫动物的血清，常用于 [免疫荧光](<../用(实验流程内容篇)/免疫荧光.md>) 和 [免疫组化](<../用(实验流程内容篇)/免疫组化.md>) 中作为封闭成分，降低二抗、Fc receptor（Fc 受体）和组织背景导致的非特异染色。

正常血清不是胎牛血清或细胞培养补充剂的同义词。它在免疫染色中的核心用途是 blocking（封闭），通常应选择与二抗宿主相同的物种血清，例如 donkey secondary antibody 常搭配 normal donkey serum（正常驴血清）。Jackson ImmunoResearch 和 Thermo Fisher 的二抗/免疫染色指南都强调封闭血清和二抗物种匹配的重要性。[参考：Jackson ImmunoResearch Secondary Antibody Resource](https://www.jacksonimmuno.com/technical/products/secondary-antibody-resource)；[参考：Thermo Fisher Secondary Antibody Selection Guide](https://www.thermofisher.com/us/en/home/life-science/antibodies/secondary-antibodies/secondary-antibody-selection-guide.html)

## 它解决什么问题

| 背景来源 | 正常血清的作用 |
| --- | --- |
| 二抗非特异吸附 | 用同物种血清蛋白预先占据非特异位点 |
| Fc 相关结合 | 降低免疫细胞上 [Fc受体](../番外/补充知识/Fc受体.md) 造成的背景 |
| 组织/细胞黏附背景 | 血清蛋白提供额外封闭 |
| 多重染色交叉背景 | 与交叉吸附二抗配合降低串扰 |

正常血清不能替代所有背景控制。组织自发荧光、内源性酶活、抗体特异性差、二抗串色等问题仍需要独立处理。

## 选择原则

| 场景 | 推荐思路 |
| --- | --- |
| IF/IHC 用 goat secondary antibody | 优先 normal goat serum |
| 使用 donkey secondary antibody | 优先 normal donkey serum |
| 多重二抗来自同一宿主 | 使用对应宿主正常血清 |
| 样本本身来自 goat/donkey 等物种 | 谨慎选择，避免二抗与内源性 IgG 交叉 |
| Fc 背景很强 | 正常血清 + Fc receptor blocking reagent |

血清一般匹配二抗宿主，而不是一抗宿主，也不是样本物种。这一点和二抗匹配逻辑类似，容易被搞反。

## 常见配方

### IF/IHC封闭液

```text
PBS 或 TBS
5-10% normal serum
1-3% BSA 可选
0.1-0.3% Triton X-100 可选，取决于是否需要通透
```

实际浓度要根据样本、抗体和 protocol 调整。膜蛋白或表面抗原染色时，Triton X-100 可能破坏膜结构或改变定位，应谨慎。

## 使用 protocol

1. 固定和通透后，用 PBS/TBS 洗样本。
2. 加入含正常血清的 [封闭液](封闭液.md)。
3. 室温孵育 30-60 min。
4. 一抗可直接用含较低浓度血清/BSA 的 [抗体稀释液](抗体稀释液.md) 稀释。
5. 后续二抗孵育时继续避光并设置 secondary-only control（二抗单独对照）。

## 正常血清 vs BSA

| 维度 | 正常血清 | [BSA](BSA.md) |
| --- | --- | --- |
| 成分 | 混合血清蛋白和免疫球蛋白 | 主要为牛血清白蛋白 |
| 常见用途 | IF/IHC 封闭 | WB、IF、ELISA、抗体稀释 |
| 优势 | 更适合降低二抗宿主相关背景 | 成分更简单、可控 |
| 局限 | 批次复杂，可能引入内源性 IgG | 对 Fc 背景不一定足够 |
| 选择逻辑 | 组织/细胞染色背景高时常用 | WB 和定义型体系更常用 |

## 注意事项

- 正常血清应来自未免疫动物，不能使用抗血清或免疫血清替代。
- 选择血清时优先匹配二抗宿主。
- 多重染色中要避免血清与二抗产生意外交叉反应。
- 血清需要分装保存，避免反复冻融和污染。
- 对定量 IF/IHC，记录血清来源、批号和浓度很重要。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 二抗背景高 | 血清物种不匹配或封闭不足 | 使用与二抗宿主匹配的正常血清 |
| 免疫细胞背景强 | Fc 受体介导结合 | 增加 Fc block 或优化血清浓度 |
| 多重染色串扰 | 二抗交叉反应 | 使用高度 cross-adsorbed 二抗 |
| 批次表现差异 | 血清批号不同 | 固定批号并做桥接测试 |
| 目标信号弱 | 封闭过强或抗体浓度低 | 降低血清浓度，优化抗体 |

## 小结

正常血清是 IF/IHC 中非常重要的背景控制工具，尤其适合降低二抗宿主相关和 Fc 相关背景。它的核心选择规则是匹配二抗宿主，并结合交叉吸附二抗、合适封闭液和必要对照一起使用。
