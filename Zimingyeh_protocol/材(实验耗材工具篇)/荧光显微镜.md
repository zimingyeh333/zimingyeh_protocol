# 荧光显微镜

## 一句话定义

Fluorescence microscope（荧光显微镜）是一类利用特定波长激发 [荧光染料](荧光染料.md)，并收集其发射光来观察样本结构和分子定位的显微成像设备。

在 [免疫荧光](<../用(实验流程内容篇)/免疫荧光.md>) 中，荧光显微镜用于检测 [DAPI](DAPI.md)、Hoechst、FITC、Alexa Fluor、Cy 染料等信号，从而判断目标蛋白在细胞或组织中的定位、强度和共定位关系。Thermo Fisher、Leica 和 Olympus/Evident 的显微成像资料都强调荧光显微镜的核心由激发光源、滤光片、二向色镜、物镜和检测器共同决定。[参考：Thermo Fisher Fluorescence Microscopy](https://www.thermofisher.com/us/en/home/life-science/cell-analysis/cell-imaging/fluorescence-microscopy.html)；[参考：Leica Science Lab Fluorescence Microscopy](https://www.leica-microsystems.com/science-lab/life-science/fluorescence-microscopy/)

## 核心组成

| 部件 | 英文 | 作用 |
| --- | --- | --- |
| 激发光源 | Excitation light source | 提供激发荧光染料的光 |
| [荧光滤光片](荧光滤光片.md) | Fluorescence filter | 选择激发光和发射光波段 |
| [二向色镜](二向色镜.md) | Dichroic mirror | 反射激发光，透过发射光 |
| [显微镜物镜](显微镜物镜.md) | Objective lens | 决定分辨率、亮度、放大倍率和数值孔径 |
| 检测器 | Detector | 相机、PMT 或其他探测器收集信号 |
| 载物台和控制系统 | Stage and control system | 控制样本位置和多维采集 |

荧光显微镜不是“普通显微镜加灯”。它的成像质量由光谱匹配、光路效率、物镜、相机、样本制备和成像参数共同决定。

## 基本光路

```text
激发光源
→ 激发滤光片
→ 二向色镜反射
→ 物镜照射样本
→ 荧光染料发射更长波长光
→ 发射光通过物镜返回
→ 二向色镜透过
→ 发射滤光片
→ 相机/检测器成像
```

关键是 excitation（激发）和 emission（发射）必须被区分开。滤光片和二向色镜选择不合适，会导致信号弱、背景高或串色。

## 常见类型

| 类型 | 英文 | 特点 | 适合场景 |
| --- | --- | --- | --- |
| [宽场荧光显微镜](宽场荧光显微镜.md) | Widefield fluorescence microscope | 结构简单、速度快、成本较低 | 固定细胞、强信号、常规 IF |
| [共聚焦显微镜](共聚焦显微镜.md) | Confocal microscope | 光学切片、背景低、空间分辨更好 | 厚样本、共定位、三维成像 |
| [TIRF显微镜](TIRF显微镜.md) | Total internal reflection fluorescence microscope | 只激发表面附近薄层 | 膜附近事件、单分子/近膜成像 |
| 高内涵成像系统 | High-content imaging system | 自动化、多孔板、高通量分析 | 药筛、表型分析 |

不要把“荧光显微镜”当成一个固定设备。不同类型显微镜解决的问题不同，成像参数也不能直接互相套用。

## 关键参数

| 参数 | 影响 |
| --- | --- |
| 激发光强 | 信号强度、光漂白和光毒性 |
| 曝光时间 | 图像亮度和饱和风险 |
| 物镜 NA | 分辨率和收光能力 |
| 像素大小 | 是否满足采样要求 |
| 滤光片带宽 | 信号收集和串色 |
| 相机增益 | 信号放大和噪声 |
| Z-step | 三维成像采样 |

定量成像时，曝光、激光强度、增益、物镜和后处理必须一致。自动增强的“漂亮图”不等于可比数据。

## 与染料选择的关系

| 染料/标记 | 常见通道 | 注意点 |
| --- | --- | --- |
| DAPI / Hoechst | 蓝色通道 | UV/405 激发，注意光毒性 |
| [FITC](FITC.md) / Alexa Fluor 488 | 绿色通道 | 常见 GFP/FITC 滤光片可用 |
| TRITC / Cy3 / Alexa Fluor 555 | 橙红通道 | 避免与相近红色染料串色 |
| Alexa Fluor 647 / Cy5 | 远红通道 | 背景低，适合弱信号 |

染料选择必须和显微镜光源、滤光片和检测器匹配。没有对应通道，再好的抗体也可能看不到。

## 使用 protocol

### 成像前检查

1. 确认样本封片完成并无明显气泡。
2. 根据染料选择正确通道。
3. 先用低光强寻找视野。
4. 逐通道设置曝光，避免饱和。
5. 固定所有样本的成像参数。
6. 采集阴性对照、单染对照和实验样本。

### 定量成像

定量实验应使用线性范围内的原始图像，不应依赖后期自动拉伸亮度。需要记录 exposure time（曝光时间）、laser power（激光功率）、gain（增益）、objective（物镜）和 binning（像素合并）等参数。

## 注意事项

- 强光会造成 [光漂白](../番外/补充知识/光漂白.md)，活细胞中还会造成 [光毒性](../番外/补充知识/光毒性.md)。
- 多通道成像要设置单染对照，检查通道串色。
- 荧光样本尽量避光保存和成像。
- 相同实验组之间不要使用不同曝光或增益做定量比较。
- 图像处理应保留原始文件，后处理参数应一致并可追溯。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 看不到信号 | 通道不匹配、抗体/染料失败、曝光太低 | 检查染料光谱和阳性对照 |
| 背景很高 | 自发荧光、封闭不足、滤光片不合适 | 设置阴性对照，换通道或优化染色 |
| 图像很快变暗 | 光漂白 | 降低光强，缩短曝光，使用抗淬灭封片剂 |
| 多通道串色 | 光谱重叠 | 用单染检查，调整通道和染料组合 |
| 定量不可比 | 曝光/增益不同或图像饱和 | 固定参数，避免饱和 |
| 细胞状态变差 | 光毒性、温度/CO2 控制不足 | 降低光照并使用活细胞成像环境控制 |

## 小结

荧光显微镜把染料光谱、样本制备、光学部件和相机参数连成一个系统。真正可靠的荧光图像不是“调亮看到信号”，而是染料匹配、对照完整、参数一致、不过曝，并保留原始数据。
