# 程序降温盒

Controlled-rate freezing container / freezing container（程序降温盒 / 控速降温盒）是细胞冻存时用于把 [冻存管](冻存管.md) 以近似可控速率降温的工具。它通常配合 -80°C 冰箱使用，让 [细胞冻存液](细胞冻存液.md) 中的细胞避免“直接急冻”造成的严重冰晶损伤。

Thermo Fisher 的细胞冻存 protocol 建议使用 controlled-rate freezer（程序降温仪）或 freezing container（降温盒）实现约 -1°C/min 的降温；ATCC 也强调多数动物细胞需要受控降温。[参考：Thermo Fisher Freezing Cells](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/cell-culture-protocols/freezing-cells.html)；[参考：ATCC Cryogenic Storage of Animal Cells](https://www.atcc.org/resources/technical-documents/cryogenic-storage-of-animal-cells)

## 为什么需要程序降温

冷冻过程中，降温太快容易形成 intracellular ice（细胞内冰晶），直接破坏细胞结构；降温太慢会让细胞长时间暴露在高渗环境和 [DMSO](DMSO.md) 中，也会降低复苏率。程序降温盒的意义就是把这个过程变得更接近可重复的物理条件。

它不能替代好的冻存液，也不能拯救状态很差的细胞。它解决的是“降温速率不受控”这个变量。

## 常见类型

| 类型 | 代表逻辑 | 优点 | 局限 |
| --- | --- | --- | --- |
| 异丙醇式降温盒 | 盒体内加入 [异丙醇](异丙醇.md)，利用热容量缓冲降温 | 经典、便宜、经验多 | 需要维护异丙醇，存在挥发、污染和更换问题 |
| 无醇式降温盒 | 依靠固体热缓冲材料或绝热结构 | 维护简单，不用异丙醇 | 成本较高，不同品牌性能不同 |
| 程序降温仪 | 主动控制降温曲线 | 可记录曲线，适合高价值细胞 | 设备贵，需要培训和维护 |
| 简易泡沫盒 | 依靠粗略保温 | 成本极低 | 重复性差，不适合标准化冻存 |

Thermo Scientific Nalgene Mr. Frosty 是典型异丙醇式降温容器；Corning CoolCell 是常见无醇式降温容器，产品页面可作为外观和结构参考。[参考：Thermo Scientific Nalgene Mr. Frosty](https://www.thermofisher.com/order/catalog/product/5100-0001)；[参考：Corning CoolCell](https://www.corning.com/worldwide/en/products/life-sciences/products/cell-culture/cell-culture-cryogenic-storage/coolcell.html)

## 选择要点

| 参数 | 为什么重要 |
| --- | --- |
| 适配冻存管规格 | 常见 1.8-2.0 mL cryovial（冻存管），但不同容器孔径和高度不同 |
| 可容纳管数 | 影响一批冻存规模，也影响温度均一性 |
| 降温曲线 | 是否接近目标降温速率，是否有厂商验证数据 |
| 是否需要异丙醇 | 决定维护方式和污染风险 |
| 与 -80°C 冰箱适配 | 盒体体积、预冷方式和放置位置影响降温 |
| 标识和记录便利性 | 同批冻存需要追踪盒号、时间和位置 |

## 使用 protocol

### 使用前检查

**怎么做**：确认降温盒型号、容量、是否需要异丙醇、适配冻存管规格和是否已按说明预处理。异丙醇式降温盒要检查液位、清洁度和使用次数；无醇式降温盒按说明确认是否需要恢复到室温或预冷。

**为什么**：不同降温盒的工作逻辑不同。错误预冷、异丙醇不足或盒体未恢复状态，都会让实际降温速率偏离预期。

**注意事项**：

- 不要把不同规格冻存管混乱塞入不适配孔位。
- 异丙醇浑浊、污染或液位不足时要更换。
- 同批冻存尽量使用同一种降温盒和同一台 -80°C 冰箱。

**替代方案**：高价值批次使用程序降温仪，并保存降温曲线。

**出错后果**：同批冻存复苏率不一致，或者整体复苏率下降。

### 放入冻存管

**怎么做**：细胞与冻存液混合后，尽快分装到冻存管并放入降温盒。记录放入时间、盒号、冻存批次和预计转入液氮时间。

**为什么**：含 DMSO 的冻存液加入细胞后，时间就是变量。降温盒的目标是尽快进入可控降温，而不是让细胞在室温等待。

**注意事项**：

- 分装后确认管盖拧紧，但不要暴力拧坏密封结构。
- 盒内孔位尽量均衡使用，避免只在一侧放管。
- 冻存管标签要耐低温，不能只写在管盖上。

**替代方案**：小批量珍贵细胞可用不同孔位做预实验，比较复苏率是否存在位置差异。

**出错后果**：DMSO 暴露过久、标签丢失、冻存管漏液或同批差异大。

### -80°C 过夜降温

**怎么做**：将降温盒放入 -80°C 冰箱中，通常过夜后转入 [液氮罐](液氮罐.md) 长期保存。具体放置时间按冻存方案、盒体说明和细胞类型执行。

**为什么**：-80°C 过夜是常见的过渡降温步骤，但不是长期保存策略。ATCC 建议长期保存应低于 -130°C。[参考：ATCC Cryogenic Storage of Animal Cells](https://www.atcc.org/resources/technical-documents/cryogenic-storage-of-animal-cells)

**注意事项**：

- 不要把降温盒长期遗忘在 -80°C。
- 不要频繁开关冰箱门干扰降温过程。
- 不同盒体不要堆叠到影响散热的位置。

**替代方案**：如果无法次日转液氮，应记录延迟时间，并尽快转入长期储存。

**出错后果**：长期 -80°C 保存导致复苏率逐渐下降，库存质量不可控。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理策略 |
| --- | --- | --- |
| 复苏率低 | 降温速率不合适、盒体使用错误、细胞状态差 | 按说明使用降温盒，优化冻存前状态 |
| 同批不同管差异大 | 孔位使用不均、细胞沉降、分装时间过长 | 分装中混匀，均衡孔位，缩短操作时间 |
| 异丙醇式盒效果变差 | 异丙醇老化、液位不足、污染 | 定期更换异丙醇并记录 |
| 冻存管卡住或破裂 | 管型不适配，装液过满或盖子受力 | 选择适配冻存管，控制装液量 |
| 次日忘记转液氮 | 记录和提醒系统不足 | 建立冻存转移提醒和库存表 |

## 购买建议

常规细胞培养实验室可以选择成熟的异丙醇式降温盒；如果冻存频率高、希望减少维护和挥发风险，可以考虑无醇式降温盒。高价值细胞、细胞库或转化相关项目更适合程序降温仪。

常见品牌和供应方向包括 [Thermo Scientific](<../番外/试剂厂商/Thermo Scientific.md>) / Nalgene、[Corning](<../番外/试剂厂商/Corning.md>) CoolCell、[Eppendorf](<../番外/试剂厂商/Eppendorf.md>) 等。选择时要确认适配冻存管规格、可容纳数量、是否有降温曲线验证资料，以及是否适配本实验室 -80°C 冰箱空间。

## 小结

程序降温盒是细胞冻存里很容易被低估的工具。它的价值不是“盒子本身高级”，而是把降温速率从随缘变量变成可重复条件。冻存失败时，不要只怀疑冻存液，也要检查降温盒类型、维护状态、-80°C 放置时间和是否及时转入液氮。
