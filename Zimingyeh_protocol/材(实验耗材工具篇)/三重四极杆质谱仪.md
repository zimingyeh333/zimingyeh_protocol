# 三重四极杆质谱仪

Triple quadrupole mass spectrometer（三重四极杆质谱仪，TQ 或 QqQ）是由三个四极杆功能区串联组成的质谱仪，最经典用途是 SRM（selected reaction monitoring，[选择反应监测](<../番外/补充知识/选择反应监测.md>)）或 MRM（multiple reaction monitoring，[多反应监测](<../番外/补充知识/多反应监测.md>)）靶向定量。它非常适合“已经知道要测什么”的高灵敏、高重复性定量实验。

## 核心原理

典型三重四极杆由 Q1、Q2、Q3 组成：

```text
Q1：选择目标前体离子
Q2：碰撞诱导解离，产生碎片
Q3：选择目标碎片离子
检测器：记录 transition 信号
```

Thermo Fisher 的 Triple Quadrupole LC-MS 页面将这类系统定位于 targeted compound detection and quantitation（靶向化合物检测和定量），强调高灵敏度、线性动态范围、选择性和 SRM assay table 等靶向数据采集。参考：[Thermo Fisher Triple Quadrupole LC-MS](https://www.thermofisher.com/us/en/home/industrial/mass-spectrometry/liquid-chromatography-mass-spectrometry-lc-ms/lc-ms-systems/triple-quadrupole-lc-ms.html)

## 适合什么实验

| 场景 | 为什么适合 |
| --- | --- |
| 靶向小分子定量 | transition 明确，灵敏度高 |
| 药代/毒理/食品/环境检测 | 需要稳定、可验证的定量方法 |
| 靶向蛋白质谱 | 监测特定肽段 transition |
| 生物标志物验证 | 适合从发现阶段转向验证阶段 |
| 大队列固定目标分析 | 方法成熟后通量和重复性好 |

在蛋白质谱里，三重四极杆通常不是第一步发现工具，而是“发现后验证”的工具。先用 Orbitrap/Q-TOF 发现候选蛋白或肽段，再用 MRM/SRM 对固定目标做高重复性定量，是很常见的路线。

## 和 Orbitrap/Q-TOF 的区别

| 项目 | 三重四极杆 | [Orbitrap](Orbitrap.md) / [Q-TOF](Q-TOF.md) |
| --- | --- | --- |
| 实验逻辑 | 先知道目标，再监测 transition | 可以做未知发现和全扫描 |
| 数据输出 | 目标峰面积/峰高 | 全谱、MS/MS 谱图、鉴定结果 |
| 优势 | 高灵敏、线性好、重复性强 | 信息量大、适合发现 |
| 限制 | 不能轻松回看未知物 | 靶向定量稳健性通常不如 QqQ |
| 典型用途 | 验证、检测、定量 | 发现、鉴定、结构解析 |

## 使用要点

**怎么做**：为每个目标选择 precursor ion（前体离子）和 product ion（产物离子）组成 transition，优化 collision energy（碰撞能量）、dwell time（驻留时间）、保留时间窗口和内标策略。

**为什么重要**：三重四极杆的可靠性来自 transition 的选择性和方法优化。错误 transition 会让背景峰被误认为目标，或让真实目标被漏检。

**注意事项**：

- 每个目标最好至少有定量 transition 和确认 transition。
- 复杂基质中必须评估基质效应和离子抑制。
- 定量实验应使用稳定同位素内标或合适外标曲线。
- 方法转移时要重新验证保留时间和离子比。
- 不要把 MRM 的“有峰”直接等同于结构确认。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 假阳性峰 | transition 不够特异，基质干扰 | 增加确认 transition，优化 LC 分离 |
| 线性不好 | 标曲范围不合适，离子抑制 | 重新做标曲，稀释样本或换内标 |
| 重复性差 | 进样、峰积分、内标加入不稳定 | 规范加样和积分参数 |
| 目标无信号 | CE 不合适、离子源条件差、样本损失 | 重新优化 CE 和离子源 |
| 峰形差 | LC 分离或流动相问题 | 检查 [纳升液相色谱仪](纳升液相色谱仪.md) 或常规 LC 系统 |

## 购买和平台建议

三重四极杆采购时重点看：

- 目标应用是小分子、药物、食品环境还是肽段定量。
- 灵敏度、线性动态范围和极性切换速度。
- 方法开发软件是否方便 transition 优化。
- 与 LC 系统、自动进样器和数据系统的兼容性。
- 服务工程师和本地方法支持能力。

常见供应商包括 [SCIEX](<../番外/试剂厂商/SCIEX.md>)、[Thermo Scientific](<../番外/试剂厂商/Thermo Scientific.md>)、[Waters](<../番外/试剂厂商/Waters.md>)、[Agilent](<../番外/试剂厂商/Agilent.md>)、[Shimadzu](<../番外/试剂厂商/Shimadzu.md>) 和 [Bruker](<../番外/试剂厂商/Bruker.md>)。

## 小结

三重四极杆的核心不是“看得最多”，而是“对已知目标看得准、看得稳、看得低”。它非常适合验证和定量，不适合作为无目标发现的主力。判断是否选择它，要先问：我的目标是不是已经明确？是否需要稳定定量而不是发现新东西？
