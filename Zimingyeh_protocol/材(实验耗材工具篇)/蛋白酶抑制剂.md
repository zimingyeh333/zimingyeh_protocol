# 蛋白酶抑制剂

## 一句话定义

Protease inhibitor（蛋白酶抑制剂）是一类用于抑制 protease（蛋白酶）活性的试剂，常在细胞或组织裂解时加入，防止目标蛋白在样本制备过程中被降解。它是 [Western blot](<../用(实验流程内容篇)/Western blot.md>)、IP-WB 和蛋白质谱前处理中的基础保护组分。

细胞裂解后，胞内不同 compartment（亚细胞区室）的蛋白酶会混合释放，目标蛋白可能在几分钟到几十分钟内被剪切或降解。因此 WB 样本制备通常要求低温、快速操作，并现用加入蛋白酶抑制剂。[参考：CST Western Blot Protocol](https://www.cellsignal.com/learn-and-support/protocols/protocol-western)

## 常见抑制对象

| 蛋白酶类型 | 英文 | 常见抑制剂 | 说明 |
| --- | --- | --- | --- |
| 丝氨酸蛋白酶 | Serine proteases | [PMSF](PMSF.md)、[Aprotinin](Aprotinin.md) | PMSF 不稳定，常需现用现加 |
| 半胱氨酸蛋白酶 | Cysteine proteases | [E-64](E-64.md)、[Leupeptin](Leupeptin.md) | 参与多种蛋白降解过程 |
| 天冬氨酸蛋白酶 | Aspartic proteases | [Pepstatin A](<Pepstatin A.md>) | 常用于更广谱 cocktail |
| 金属蛋白酶 | Metalloproteases | [EDTA](EDTA.md) | EDTA 通过螯合金属离子抑制部分酶，但会影响金属依赖实验 |

商业 protease inhibitor cocktail（蛋白酶抑制剂混合物）通常覆盖多类蛋白酶。不同产品可能分为 EDTA-free（无 EDTA）和含 EDTA 版本。若后续需要金属依赖酶活、His-tag purification（His 标签纯化）或某些金属蛋白研究，EDTA-free 版本更合适。

## 什么时候必须加

- 制备 WB 全蛋白样本。
- 处理组织样本、原代样本或蛋白酶活性高的样本。
- 检测易降解蛋白、剪切蛋白或低丰度蛋白。
- 做 [免疫共沉淀](<../用(实验流程内容篇)/免疫共沉淀.md>) 或蛋白复合物分析。
- 样本处理时间较长，或需要多轮离心/超声/匀浆。

## 使用原则

### 现用现加

很多抑制剂在水溶液中稳定性有限，尤其 PMSF（Phenylmethylsulfonyl fluoride，苯甲基磺酰氟）在水溶液中会水解。商业说明书通常建议在裂解液使用前加入 1× 工作浓度。[参考：Thermo Fisher Protease Inhibitor Tablets](https://www.thermofisher.com/order/catalog/product/A32963)

### 低温配合

抑制剂不是温度控制的替代品。裂解、离心和转移尽量在冰上或 4°C 进行。低温降低蛋白酶活性，也给抑制剂提供更稳定的工作条件。

### 根据下游实验选择

| 下游实验 | 选择建议 |
| --- | --- |
| WB | 常规广谱 cocktail 通常足够 |
| IP-WB | 避免破坏抗体结合和蛋白互作，选择兼容裂解体系 |
| 金属依赖蛋白研究 | 避免含 EDTA 抑制剂 |
| 磷酸化蛋白 WB | 还要加入 [磷酸酶抑制剂](磷酸酶抑制剂.md) |
| 蛋白质谱 | 注意抑制剂是否干扰 MS（Mass spectrometry，质谱） |

## 常见错误

| 错误 | 后果 | 建议 |
| --- | --- | --- |
| 忘记加入抑制剂 | 条带降解、低分子量碎片增加 | 裂解液现配清单中单独勾选 |
| 抑制剂提前加入后放很久 | 抑制效率下降 | 使用前现加 |
| 只有蛋白酶抑制剂，没有磷酸酶抑制剂 | 磷酸化信号丢失 | 检测 phospho-protein 时两类都加 |
| 不区分 EDTA-free | 影响金属依赖步骤 | 根据下游实验选版本 |
| 样本反复冻融 | 抑制剂也救不了降解 | 分装保存，避免冻融 |

## 小结

蛋白酶抑制剂的意义是保护样本制备瞬间的真实蛋白状态。它必须和低温、快速处理、减少冻融一起使用。对于 WB，忘记加蛋白酶抑制剂常常表现为目标条带变弱、出现碎片条带或重复性变差。
