# 转膜缓冲液

## 一句话定义

Transfer buffer（转膜缓冲液，也叫电转缓冲液）是 [Western blot](<../用(实验流程内容篇)/Western blot.md>) 转膜步骤中承载电流、维持离子环境，并帮助蛋白从凝胶迁移到膜上的缓冲体系。

最经典的湿转体系是 Tris-Glycine-Methanol transfer buffer（Tris-甘氨酸-甲醇转膜缓冲液），常用于从 [SDS-PAGE](<../用(实验流程内容篇)/SDS-PAGE.md>) 胶转移到 [PVDF膜](PVDF膜.md) 或 [NC膜](NC膜.md)。Bio-Rad、Thermo Fisher、CST 和 Abcam 的 WB protocol 都采用相近的转膜缓冲液逻辑。[参考：Bio-Rad Western Blotting Guide](https://www.bio-rad.com/applications-technologies/western-blotting-immunodetection-techniques?ID=PQEEPOBWLN4A)；[参考：Thermo Fisher Western Blot Protocols](https://www.thermofisher.com/uk/en/home/life-science/protein-biology/protein-biology-learning-center/protein-gel-electrophoresis-information/western-blot-protocols.html)

![Western blot膜、转膜缓冲液、Ponceau S与ECL示意图](<../z_asset/材/Western blot膜和检测/wb-membrane-transfer-detection-reference-zh.png>)

## 核心成分与作用

| 成分 | 英文 | 常见作用 |
| --- | --- | --- |
| [Tris](Tris.md) | Tris base / Tris(hydroxymethyl)aminomethane | 维持弱碱性缓冲环境 |
| [甘氨酸](甘氨酸.md) | Glycine | 提供离子体系，参与导电和 pH 环境 |
| [甲醇](甲醇.md) | Methanol | 帮助去除部分 SDS、促进蛋白与膜结合、降低凝胶膨胀 |
| [十二烷基硫酸钠](十二烷基硫酸钠.md) | SDS, sodium dodecyl sulfate | 可帮助大蛋白从胶中释放，但会削弱蛋白与膜结合 |

甲醇和 SDS 是最需要理解的两个变量。甲醇有利于蛋白固定到膜上，但可能让凝胶收缩、限制大分子蛋白迁移；SDS 有利于大分子蛋白从胶中出来，但太多会让蛋白更难结合膜，尤其会增加穿膜和背景风险。

## 常见配方

### 经典 1× Tris-Glycine-Methanol 转膜缓冲液

常见 1 L 配方：

```text
Tris base：3.03 g
Glycine：14.4 g
Methanol：200 mL
ddH2O：补足至 1 L
```

这个体系约为 25 mM Tris、192 mM glycine、20% methanol。通常不需要用酸碱主动调 pH，除非具体 protocol 或厂家说明书要求。

### 10× 储液思路

10× Tris-Glycine 储液可先不加甲醇：

```text
Tris base：30.3 g
Glycine：144 g
ddH2O：补足至 1 L
```

使用时再稀释为 1× 并新鲜加入甲醇。甲醇不建议长期混在高倍储液里反复开盖使用，因为挥发、易燃和浓度变化都会影响可重复性。

### 是否加入 SDS

常见选择是 0-0.05% SDS，部分 protocol 会使用更高或更低浓度。一般逻辑如下：

| 情况 | SDS 策略 |
| --- | --- |
| 常规中小蛋白 | 不加或极低 SDS |
| 大分子量蛋白转膜不足 | 可尝试 0.01-0.05% SDS |
| 小蛋白容易穿膜 | 避免加入 SDS |
| 背景偏高或膜结合差 | 降低或去除 SDS |

## 按目标蛋白调整

| 目标 | 可能调整 | 原因 |
| --- | --- | --- |
| 小蛋白 | 0.2 μm 膜、较短转膜、保持或适当提高甲醇、避免 SDS | 减少穿膜 |
| 大蛋白 | 降低甲醇至 5-10%、延长低温湿转、可少量 SDS | 增加从胶中释放和迁移 |
| 磷酸化蛋白 | 全程低温，避免过热 | 减少蛋白降解和信号损失 |
| 高背景 | 减少 SDS，优化膜和封闭条件 | 降低非特异结合 |

## 湿转 vs 半干转

| 类型 | 缓冲液特点 | 适合场景 |
| --- | --- | --- |
| Wet transfer（湿转） | 缓冲液体积大，散热好，条件可调空间大 | 大蛋白、低丰度蛋白、需要稳健转膜 |
| Semi-dry transfer（半干转） | 缓冲液用量少，时间短，对夹层均一性要求高 | 常规快速 WB、中小蛋白 |
| Dry transfer（干转/快速系统） | 使用厂家专用耗材和缓冲体系 | 高通量或标准化流程 |

半干转和快速转膜系统通常不应直接套用湿转配方。不同设备对离子强度、甲醇、膜材和滤纸厚度的要求不同，应以设备说明书为准。

## 使用 protocol

### 现配 1× 转膜缓冲液

1. 称取 Tris 和 glycine，加入约 700 mL ddH2O 溶解。
2. 加入甲醇至目标比例。
3. 如需要，加入低浓度 SDS。
4. ddH2O 补足至 1 L。
5. 使用前预冷，尤其是湿转和长时间转膜。

### 转膜前平衡

1. 凝胶脱模后在转膜缓冲液中平衡 5-15 min。
2. 膜按材质预处理：PVDF 先甲醇激活，NC 直接润湿。
3. [滤纸](滤纸.md) 和 [转膜海绵垫](转膜海绵垫.md) 充分浸透转膜缓冲液。
4. 组装夹层并去除气泡。
5. 转膜结束后用 [Ponceau S](<Ponceau S.md>) 或其他总蛋白染色确认转膜效果。

## 注意事项

- 甲醇易燃、有毒，需按 [化学品安全](<../实验室安全/化学品安全.md>) 和 [实验室废弃物处理](<../实验室安全/实验室废弃物处理.md>) 规范处理。
- 湿转时间长时要注意电转槽发热，必要时冰浴或 4°C 转膜。
- 不要把“高电压更快”当作默认优化方向。过热会导致条带弥散、膜背景升高和蛋白损失。
- 甲醇比例、SDS 比例、膜孔径和转膜时间是联动参数，改变一个参数后应记录并评估。
- 转膜缓冲液重复使用会改变离子强度、pH 和甲醇比例，一般不建议用于严肃定量 WB。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 大蛋白转膜不足 | 甲醇过高、时间短、胶浓度高 | 降低甲醇，延长低温湿转，少量 SDS |
| 小蛋白信号消失 | 小蛋白穿膜、SDS 过高、转膜过强 | 用 0.2 μm 膜，去除 SDS，缩短转膜 |
| 条带弥散 | 过热、电流过大、缓冲液老化 | 预冷缓冲液，降低电流，换新液 |
| 背景高 | SDS 过多、膜选择不合适、封闭不足 | 降低 SDS，优化封闭和洗膜 |
| Ponceau S 显示转膜不均 | 气泡、夹层不平、滤纸未浸透 | 重新组装夹层，确保无气泡 |

## 小结

转膜缓冲液不是背景里的“水”。它直接决定蛋白能不能从胶里出来、能不能留在膜上，以及转膜是否均一。优化转膜时，应把甲醇、SDS、膜孔径、转膜时间和温度作为一组参数一起思考。
