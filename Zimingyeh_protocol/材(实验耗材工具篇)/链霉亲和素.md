# 链霉亲和素

## 一句话定义

Streptavidin（链霉亲和素）是一种来自 Streptomyces avidinii 的生物素结合蛋白，能与 [生物素](生物素.md) 高亲和力结合，常用于免疫检测、分子捕获、磁珠纯化和信号放大体系。

链霉亲和素通常被连接到 HRP、AP、荧光染料、磁珠、琼脂糖或板面，用于检测或捕获生物素化抗体、蛋白、肽或核酸。Thermo Fisher 和 Vector Laboratories 都将 streptavidin-biotin 体系作为高亲和力标记和检测平台。[参考：Thermo Fisher Biotin-Binding Proteins](https://www.thermofisher.com/us/en/home/life-science/protein-biology/protein-labeling-crosslinking/biotinylation/biotin-binding-proteins.html)；[参考：Vector Laboratories Avidin-Biotin System](https://vectorlabs.com/pages/avidin-biotin-system)

## 核心特点

| 特点 | 说明 |
| --- | --- |
| 高亲和力 | 与 biotin 结合非常稳定 |
| 四聚体结构 | 一个 streptavidin 通常可结合多个 biotin |
| 背景较低 | 相比 avidin，通常糖基化和非特异结合更少 |
| 易于偶联 | 可连接 HRP、AP、荧光染料或固相载体 |
| 可放大信号 | 多价结合和酶标体系可增强检测 |

链霉亲和素不是抗体，它不识别抗原；它只识别生物素标签。

## 常见形式

| 形式 | 用途 |
| --- | --- |
| Streptavidin-HRP | ELISA、IHC、blot 中检测生物素化试剂 |
| Streptavidin-AP | AP 显色或发光检测 |
| Streptavidin-fluorophore | IF、流式、成像 |
| Streptavidin magnetic beads | 捕获生物素化蛋白/核酸 |
| Streptavidin-coated plates | ELISA 捕获和固定化 |

## Streptavidin vs Avidin

| 维度 | Streptavidin | [亲和素](亲和素.md) |
| --- | --- | --- |
| 中文 | 链霉亲和素 | 亲和素/卵白素 |
| 来源 | 细菌 | 鸡蛋白 |
| 糖基化 | 通常无糖基化 | 糖基化较多 |
| 等电点 | 较接近中性 | 偏碱性 |
| 非特异背景 | 通常较低 | 可能更高 |
| 常见选择 | 现代免疫检测常用 | 某些传统 avidin-biotin 体系 |

在低背景要求高的 IF/IHC 或 ELISA 中，streptavidin 往往比 avidin 更常用。

## 使用 protocol

### 检测生物素化抗体

1. 完成生物素化一抗或检测抗体孵育。
2. 用 PBST/TBST 充分洗涤。
3. 加入 streptavidin-HRP、streptavidin-AP 或 streptavidin-fluorophore。
4. 按说明书孵育。
5. 充分洗涤。
6. 加入对应底物或直接成像。

### 磁珠捕获

1. 平衡 streptavidin beads。
2. 加入生物素化分子或样本。
3. 孵育结合。
4. 磁分离并洗涤。
5. 洗脱或直接进入下游检测。

## 注意事项

- Streptavidin 的检测标签必须和读出体系匹配：HRP 用 TMB/DAB/ECL，AP 用 BCIP-NBT 或 AP 底物，荧光版本用荧光成像。
- 内源性生物素会造成背景，IHC 中尤其需要注意。
- Streptavidin 试剂浓度过高会增加非特异背景。
- 磁珠类产品不能剧烈涡旋到破坏珠子或产生不可控泡沫。
- Streptavidin-biotin 结合非常强，常规温和条件下不易解离。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 背景高 | 内源性 biotin、streptavidin 过浓、洗涤不足 | 做 biotin blocking，降低浓度，增加洗涤 |
| 无信号 | 试剂未生物素化、streptavidin 标签不匹配 | 检查 biotinylation 和检测标签 |
| 捕获后洗不掉背景 | 多价结合或非特异吸附 | 增加盐/去污剂，优化封闭 |
| IF 串色 | 荧光 streptavidin 通道不合适 | 选择合适荧光染料和滤光片 |
| ELISA 空白高 | 板封闭不足或 streptavidin-HRP 过浓 | 优化封闭和稀释度 |

## 小结

链霉亲和素是生物素体系的核心“连接器”。它能把生物素化分子接到酶、荧光、磁珠或固相表面上。使用时最重要的是确认生物素化试剂、streptavidin 标签、读出体系和内源性 biotin 背景控制。
