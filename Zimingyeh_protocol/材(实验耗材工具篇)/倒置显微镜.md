# 倒置显微镜

Inverted microscope（倒置显微镜）是物镜位于样本下方、从培养容器底部观察细胞的显微镜。它是细胞培养房最常用的观察设备，因为贴壁细胞通常生长在培养瓶、培养皿或培养板底部，倒置结构可以在不开盖、不取出细胞的情况下观察形态、密度、污染和贴壁状态。

## 核心用途

| 用途 | 观察重点 | 对应实验 |
| --- | --- | --- |
| 日常细胞状态观察 | 形态、密度、漂浮细胞、颗粒、污染 | [细胞培养](<../用(实验流程内容篇)/细胞培养.md>) |
| 判断汇合度 | confluency（汇合度）和空间分布 | [贴壁细胞培养](<../用(实验流程内容篇)/贴壁细胞培养.md>)、[细胞传代](<../用(实验流程内容篇)/细胞传代.md>) |
| 复苏后评估 | 贴壁、死亡细胞、恢复速度 | [细胞复苏](<../用(实验流程内容篇)/细胞复苏.md>) |
| 接种均匀性检查 | 细胞是否集中到边缘或中央 | [细胞接种](<../用(实验流程内容篇)/细胞接种.md>) |
| 手动计数辅助 | 观察 [血球计数板](血球计数板.md) 网格 | [细胞计数](<../用(实验流程内容篇)/细胞计数.md>) |

## 为什么细胞培养常用倒置显微镜

正置显微镜从上方观察，更适合玻片、组织切片或薄样本。细胞培养容器通常有较厚的塑料壁、较高的液面和不同底部厚度，倒置显微镜从下方观察更方便，也更少干扰无菌状态。

倒置显微镜常配合 phase contrast microscopy（[相差显微镜](<../番外/补充知识/相差显微镜.md>) / 相差成像）使用。相差能增强透明活细胞的轮廓，不需要染色就能看到细胞边界、伪足、细胞团和碎片。Nikon MicroscopyU 将 phase contrast 介绍为观察未染色透明样本的重要技术。[参考：Nikon MicroscopyU Phase Contrast](https://www.microscopyu.com/techniques/phase-contrast)

## 关键结构

| 结构 | 作用 | 注意事项 |
| --- | --- | --- |
| 物镜 | 决定放大倍数、分辨率和工作距离 | 细胞培养常用低倍和长工作距离物镜 |
| 载物台 | 放置培养瓶、培养皿或培养板 | 需要适配不同容器和孔板 |
| 聚光器 | 提供透射光照明 | 相差观察需匹配相差环 |
| 相差环 | 形成相差成像效果 | 物镜和聚光器环位需匹配 |
| 光源 | 明场/相差照明 | 亮度过高会影响观察舒适度 |
| 相机 | 拍照记录 | 需要统一曝光和比例尺 |

关于物镜参数可参考 [显微镜物镜](显微镜物镜.md)，尤其是 working distance（工作距离）、numerical aperture（数值孔径）和校正类型。

## 观察策略

### 日常观察细胞

**怎么做**：先低倍扫视整体密度、污染和培养基状态，再提高倍率观察细胞形态。观察时尽量缩短细胞离开 [CO2培养箱](CO2培养箱.md) 的时间。

**为什么**：低倍能判断整体，较高倍率能看细节。细胞离开培养箱后温度和 pH 会变化，尤其是无 HEPES 的培养基。

**注意事项**：

- 先看容器边缘和液面颗粒，再看细胞层。
- 观察污染时不要只看一个视野。
- 拍照记录时写清细胞名、传代数、时间和倍率。

**替代方案**：长时间观察用活细胞成像系统，而不是让细胞长时间停在普通显微镜上。

**出错后果**：漏掉早期污染、误判汇合度、细胞长时间离箱导致应激。

### 判断汇合度

**怎么做**：多视野观察细胞覆盖面积，不只看最密或最稀的区域。贴壁细胞传代前常需要判断是否达到适合传代的 confluency。

**为什么**：传代时机影响细胞状态。过低密度传代可能恢复慢，过度汇合会改变增殖、分化、基因表达和药物反应。

**注意事项**：

- 不同细胞形态不同，汇合度不是简单数细胞个数。
- 细胞团聚、边缘聚集会干扰判断。
- 新手应保留示例图建立内部标准。

**替代方案**：用图像分析软件或自动成像系统定量 confluency。

**出错后果**：传代节律不稳定，实验批次差异增加。

### 检查污染

**怎么做**：观察培养基中快速移动小点、丝状结构、真菌菌丝、漂浮絮状物、细胞周围颗粒和细胞形态异常。疑似污染时隔离并复查。

**为什么**：倒置显微镜能发现很多可见污染，但不能可靠排除 mycoplasma（支原体）。支原体需要专门检测。

**注意事项**：

- 不要在显微镜旁打开培养瓶盖。
- 疑似污染不要继续放回公共培养箱扩散。
- 记录照片方便追踪。

**替代方案**：支原体用 [支原体检测](<../用(实验流程内容篇)/支原体检测.md>)；细菌/真菌污染按实验室污染处理流程。

**出错后果**：污染扩散到培养箱和其他细胞，实验数据失效。

## 倒置显微镜 vs 正置显微镜 vs 荧光显微镜

| 类型 | 主要用途 | 优点 | 局限 |
| --- | --- | --- | --- |
| 倒置显微镜 | 活细胞培养观察 | 不开盖观察培养容器底部细胞 | 常规型号多为明场/相差 |
| 正置显微镜 | 玻片、组织切片、染色样本 | 适合薄样本和切片 | 不适合高壁培养容器 |
| [荧光显微镜](荧光显微镜.md) | 荧光染色和定位 | 可看标记分子 | 光毒性、光漂白和设备成本更高 |
| 活细胞成像系统 | 长时间动态观察 | 控温控气，自动拍摄 | 维护复杂，成本高 |

## 购买建议

细胞培养房的基础倒置显微镜优先看相差质量、物镜工作距离、容器适配、操作耐用性、是否方便拍照和维护成本。常见品牌包括 [Nikon](<../番外/试剂厂商/Nikon.md>)、[Evident](<../番外/试剂厂商/Evident.md>) / [Olympus](<../番外/试剂厂商/Olympus.md>)、[Leica](<../番外/试剂厂商/Leica.md>)、[Zeiss](<../番外/试剂厂商/Zeiss.md>) 等。

如果只是日常培养观察，不一定需要高端荧光模块；清晰可靠的低倍相差成像往往更重要。若需要成像记录，建议配相机并统一比例尺和命名规则。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理策略 |
| --- | --- | --- |
| 看不清细胞轮廓 | 相差环不匹配、聚光器位置不对、底部太厚 | 调整相差环，使用适合容器和物镜 |
| 误判污染 | 灰尘、气泡、塑料划痕被当成微生物 | 多视野观察，拍照复查，必要时做污染检测 |
| 细胞离箱太久 | 观察前没有计划，显微镜旁讨论太久 | 先计划视野和拍照目标，缩短观察时间 |
| 图片难以比较 | 曝光、倍率、视野和命名不统一 | 建立拍照记录规范 |
| 汇合度判断差异大 | 不同人标准不一致 | 建立细胞系示例图和内部判定标准 |

## 小结

倒置显微镜是细胞培养里的“日常体检工具”。它最重要的价值不是拍漂亮图，而是快速判断细胞是否健康、是否该传代、是否污染、接种是否均匀。可靠的相差观察和统一的记录习惯，往往比昂贵配置更能提高日常培养质量。
