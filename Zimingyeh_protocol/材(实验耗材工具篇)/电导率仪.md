# 电导率仪

Conductivity meter（电导率仪）是测量 solution conductivity（[溶液电导率](<../番外/补充知识/电导率.md>)）的仪器，常用单位包括 µS/cm 和 mS/cm。它反映溶液中可移动离子的导电能力，适合用于水质、缓冲液、盐溶液、清洗残留和配方一致性质控，但不能直接替代 pH、渗透压或折光率。

## 定义与命名

电导率的英文是 conductivity 或 electrolytic conductivity。它表示溶液传导电流的能力，主要由离子种类、浓度、迁移率、温度和溶剂环境决定。IUPAC Gold Book 对 electrolytic conductivity 的定义强调它和 conductance（电导）、cell constant（电导池常数）及测量几何有关。参考：[IUPAC Gold Book electrolytic conductivity](https://goldbook.iupac.org/terms/view/E01927/pdf)。

实验记录中建议写：

```text
Conductivity = 1413 µS/cm at 25°C
Instrument = conductivity meter
Cell constant = K = 1.0 cm^-1
Calibration = KCl standard
Temperature compensation = automatic/manual/none
```

如果仪器显示 resistivity（电阻率，MΩ·cm），常见于超纯水系统；它和 conductivity 是倒数关系相关的表达，但记录时不要混用单位。

## 电导率仪测量的是什么

| 组成/变量 | 作用 |
| --- | --- |
| Conductivity cell（电导池） | 提供固定几何结构的电极系统 |
| Cell constant（电导池常数） | 把电导换算为电导率 |
| 温度探头 | 做温度补偿和记录 |
| 标准液 | 校准电导池常数和仪器响应 |
| 主机 | 显示 µS/cm、mS/cm、resistivity、TDS 等读数 |

电导率对温度非常敏感，很多水溶液温度升高时电导率也会上升。因此 25°C 标准化读数和实际温度读数要区分清楚。

## 主要用途

| 场景 | 为什么测电导率 | 记录重点 |
| --- | --- | --- |
| [超纯水](超纯水.md) / 纯水系统 | 判断离子污染或水质变化 | µS/cm 或 MΩ·cm、温度、取样点 |
| [PBS](PBS.md) 等盐溶液 | 快速判断盐浓度是否明显偏离 | 配方、温度、批号 |
| 缓冲液配制 | 检查离子强度和批间一致性 | buffer、盐浓度、温度 |
| 清洗验证 | 判断离子残留是否洗净 | 清洗流程、最后冲洗液电导率 |
| 细胞培养相关液体 | 辅助判断盐和无机离子异常 | 不能替代 osmolality |
| 电泳缓冲液 | 检查重复使用或稀释错误 | 使用次数、稀释倍数 |

电导率仪特别适合发现“盐类相关错误”，例如 PBS 少加盐、纯水被污染、缓冲液稀释倍数错误。但它对非离子溶质不敏感，例如葡萄糖、[蔗糖](蔗糖.md)、[DMSO](DMSO.md) 或非离子碘化密度梯度介质可能显著改变渗透压/折光率，却不一定显著改变电导率。

## 基本操作流程

不同仪器和探头按说明书执行，通用流程如下：

```text
检查探头是否清洁、无气泡：
选择合适量程和电导池常数：
用标准液校准：
记录标准液批号和温度：
用超纯水或待测样品预润洗探头：
将探头浸入样品并轻轻搅拌：
避免气泡附着在电极表面：
等待温度和读数稳定：
记录电导率、温度、单位、校准液和样品批号：
测后冲洗并按说明保存探头：
```

测低电导率样品时，容器污染、空气中 CO2 溶入、手套粉尘和残留离子都会造成读数上升。测高盐样品时，要注意探头量程和清洗。

## 单位和换算

| 单位 | 常见场景 | 备注 |
| --- | --- | --- |
| µS/cm | 纯水、低盐溶液 | 1 mS/cm = 1000 µS/cm |
| mS/cm | 缓冲液、盐溶液 | PBS 等常见盐溶液通常在 mS/cm 级别 |
| MΩ·cm | 超纯水电阻率 | 18.2 MΩ·cm 约对应 25°C 高品质超纯水 |
| TDS | 水处理/环境检测 | total dissolved solids（总溶解固体）估算，不适合严谨配方记录 |
| Salinity | 盐度 | 多用于水质/海水等场景 |

写 protocol 时，优先记录原始 conductivity 单位和温度。TDS、salinity 这类换算值依赖模型，不建议作为生物实验缓冲液的唯一记录。

## 校准与标准液

电导率仪常用 [氯化钾](氯化钾.md) 标准液校准，例如 84 µS/cm、1413 µS/cm、12.88 mS/cm 等规格。选择标准液时，应让标准液电导率接近样品范围。

| 样品范围 | 常见标准液选择 |
| --- | --- |
| 超纯水/低离子水 | 低电导标准液，注意污染控制 |
| 常规实验缓冲液 | 1413 µS/cm 或 12.88 mS/cm 等 |
| 高盐溶液 | 更高电导率标准液 |
| 宽范围样品 | 多点校准或按样品范围分段校准 |

标准液开封后会受蒸发、污染和 CO2 影响。日常记录要写清标准液批号、开封日期和有效期。

## 电导率 vs pH/渗透压/折光率

| 参数 | 主要反映什么 | 电导率不能替代它的原因 |
| --- | --- | --- |
| pH | 氢离子活度相关酸碱状态 | 电导率高低不等于酸碱合适 |
| [渗透压](<../番外/补充知识/渗透压.md>) | 所有渗透活性粒子总效应 | 非离子溶质也会贡献渗透压 |
| [折光率](<../番外/补充知识/折光率.md>) | 光学性质，可与浓度/密度建表 | 非离子高密度介质可能 RI 高但电导低 |
| [离子强度](<../番外/补充知识/离子强度.md>) | 离子浓度和电荷综合效应 | 电导率受离子迁移率影响，不等同离子强度 |
| density（密度） | 单位体积质量 | 电导率不能直接说明密度 |

例如 [OptiPrep](OptiPrep.md) 和 [Nycodenz](Nycodenz.md) 属于非离子碘化密度梯度介质，密度和 RI 变化很明显，但电导率不是主要质控指标；而 PBS 的盐浓度错误则很可能会反映在电导率上。

## 选购建议

| 需求 | 关注参数 |
| --- | --- |
| 超纯水监测 | 低电导范围、温度补偿、电阻率显示 |
| 常规缓冲液质控 | 量程、校准方便性、探头耐盐 |
| 多人平台 | 数据导出、校准记录、探头 ID |
| 小体积样品 | 微量电导池或小体积探头 |
| 高盐/腐蚀性样品 | 探头材质和清洁方案 |
| GLP/GMP | 审计追踪、用户管理、校准追溯 |

代表性供应商可参考 [Mettler Toledo](<../番外/试剂厂商/Mettler Toledo.md>)、[Thermo Fisher Scientific](<../番外/试剂厂商/Thermo Fisher Scientific.md>)、[Metrohm](<../番外/试剂厂商/Metrohm.md>) 和 [Hanna Instruments](<../番外/试剂厂商/Hanna Instruments.md>)。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 低电导样品读数偏高 | 容器污染、CO2 溶入、探头残留 | 更换洁净容器，缩短暴露，充分冲洗 |
| 同一样品读数不稳 | 气泡附着、温度未平衡、搅拌不一致 | 去除气泡，等待温度稳定，统一搅拌 |
| 校准失败 | 标准液污染/过期、探头污染、量程不合适 | 更换标准液，清洁探头，选择合适标准液 |
| PBS 电导率异常 | 稀释倍数或盐称量错误 | 复核配方和定容体积 |
| 细胞状态差但电导率正常 | 非离子溶质、pH、毒性或污染问题 | 同时检查 pH、渗透压和污染 |
| 电导率正常但功能读数差 | 电导率只能反映离子导电能力 | 做生物学功能和批号验证 |

## 小结

电导率仪是判断水质、盐溶液和缓冲液离子状态的快速工具。它很适合发现配方稀释错误、纯水污染或盐残留，但不能替代 pH 计、渗透压仪、折光仪或生物学读数。记录时要把单位、温度、标准液、电导池常数和样品批号写清。
