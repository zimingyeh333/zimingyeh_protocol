# 苏木精

## 一句话定义

Hematoxylin（苏木精）是一种经典组织学核染试剂，常与 eosin（伊红）组成 H&E staining（苏木精-伊红染色），也常在 [免疫组化](<../用(实验流程内容篇)/免疫组化.md>) 中作为 counterstain（复染）显示细胞核和组织结构。

在 DAB-IHC 中，[DAB](DAB.md) 产生棕色目标信号后，苏木精常用于把细胞核染成蓝紫色，帮助判断阳性信号位于哪类细胞或组织区域。Abcam、Thermo Fisher 和 Vector Laboratories 的 IHC 资料都把 hematoxylin counterstain 作为常见步骤。[参考：Abcam IHC Protocols](https://www.abcam.com/en-us/technical-resources/protocols)；[参考：Thermo Fisher IHC](https://www.thermofisher.com/us/en/home/life-science/antibodies/immunohistochemistry-ihc.html)

## 它在IHC里的作用

| 作用 | 说明 |
| --- | --- |
| 显示细胞核 | 帮助定位阳性信号属于哪些细胞 |
| 提供组织结构背景 | 让切片更容易解释 |
| 配合 DAB | 棕色 DAB + 蓝紫色苏木精是常见明场 IHC 组合 |
| 质量判断 | 可看到组织是否完整、细胞形态是否保留 |

苏木精复染不是越深越好。过深会遮盖弱 DAB 信号，过浅则组织结构不清楚。

## 常见类型

| 类型 | 英文 | 特点 |
| --- | --- | --- |
| Harris hematoxylin | Harris 苏木精 | 经典组织学染色常见 |
| Mayer hematoxylin | Mayer 苏木精 | 常用于较温和核染 |
| Gill hematoxylin | Gill 苏木精 | 细胞学和组织学常见 |
| Commercial ready-to-use hematoxylin | 即用型苏木精 | 方便、批间更稳定 |

不同苏木精配方染色强度和时间差异很大。protocol 中不能只写“苏木精染一下”，要写清产品和时间。

## IHC复染 protocol

1. DAB 显色完成并终止反应。
2. 用水充分冲洗切片。
3. 加入苏木精复染，常见为数十秒到数分钟，按产品和目标强度优化。
4. 水洗。
5. 进行 bluing（返蓝）步骤，使核染由红紫转为蓝紫。
6. 根据流程脱水、透明、封片。

返蓝步骤常使用弱碱性水或专用 bluing reagent（返蓝液）。如果返蓝不足，细胞核颜色可能偏红紫，影响阅片。

## 苏木精 vs DAPI

| 维度 | 苏木精 | [DAPI](DAPI.md) |
| --- | --- | --- |
| 读出方式 | 明场显微镜 | 荧光显微镜 |
| 常见颜色 | 蓝紫色核染 | 蓝色荧光核染 |
| 常见应用 | H&E、DAB-IHC 复染 | IF/IHC-F 核染 |
| 样本保存 | 适合明场永久切片 | 依赖荧光保存条件 |
| 主要注意点 | 染色/返蓝/脱水 | 避光、抗淬灭、曝光 |

IHC 明场常用苏木精；免疫荧光常用 DAPI 或 Hoechst。两者不是互相替代的普通“核染”，而是适配不同成像体系。

## 注意事项

- 苏木精染色时间要与 DAB 强度匹配。
- 复染过深会掩盖弱阳性信号。
- 不同批号或不同品牌苏木精染色速度可能不同。
- 脱水和封片流程会影响最终颜色。
- 某些苏木精配方可能含金属盐或氧化剂，按 [化学品安全](<../实验室安全/化学品安全.md>) 处理。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 核染太深 | 苏木精时间过长 | 缩短复染时间或分化处理 |
| 核染太浅 | 时间太短或试剂老化 | 延长时间或更换新试剂 |
| 核颜色偏红紫 | 返蓝不足 | 增加返蓝时间 |
| DAB 信号被遮盖 | 复染过强 | 降低苏木精时间 |
| 切片颜色不一致 | 批次、时间或水洗不同 | 固定同一 SOP 和计时 |

## 小结

苏木精是 IHC 明场图像中帮助理解组织结构和细胞核位置的关键复染试剂。它不是越深越好，而是要与 DAB 信号强度、组织类型和阅片需求匹配。记录时要写清产品、复染时间、返蓝条件和封片流程。
