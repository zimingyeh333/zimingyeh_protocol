# 抗淬灭封片剂

## 一句话定义

Antifade mounting medium（抗淬灭封片剂）是一类用于荧光显微成像的封片试剂，能固定盖玻片位置、保护样本，并减缓 fluorescent signal photobleaching（荧光信号光漂白）。

在 [免疫荧光](<../用(实验流程内容篇)/免疫荧光.md>) 中，抗淬灭封片剂通常在染色和洗涤完成后加入，用于保存 [荧光染料](荧光染料.md)、[荧光二抗](荧光二抗.md)、[DAPI](DAPI.md) 或 Hoechst 信号。Thermo Fisher、Abcam 和多家显微成像试剂厂家都将 antifade mounting media 作为荧光样本保存和成像的重要组成部分。[参考：Thermo Fisher Mounting Media](https://www.thermofisher.com/us/en/home/life-science/cell-analysis/cell-structure/mounting-media.html)；[参考：Abcam Immunofluorescence Protocol](https://www.abcam.com/en-us/technical-resources/protocols/immunocytochemistry-immunofluorescence-protocol)

## 核心作用

| 作用 | 说明 |
| --- | --- |
| 减缓光漂白 | 降低反复曝光时荧光衰减 |
| 保护样本 | 保持样本和盖玻片结构 |
| 改善成像 | 减少干燥、折射率不匹配和气泡影响 |
| 长期保存 | 部分 hard-set 封片剂固化后适合长期保存 |
| 核染整合 | 有些产品预含 DAPI 或其他核染料 |

抗淬灭封片剂不能把已经漂白的信号恢复回来，它只能在成像和保存过程中减慢信号损失。

## 常见类型

| 类型 | 英文 | 适合场景 |
| --- | --- | --- |
| 非固化型 | Non-hardening mounting medium | 快速成像、短期保存 |
| 固化型 | Hard-set mounting medium | 长期保存、切片归档 |
| 含 DAPI 型 | Mounting medium with DAPI | 简化核染步骤 |
| 不含核染型 | Without counterstain | 已完成核染或不需要核染 |
| 特定染料优化型 | Dye-specific antifade | 对某些荧光团保护更好 |

是否选择含 DAPI 的封片剂取决于实验设计。如果已经用 Hoechst 或 DAPI 单独染过，再使用含 DAPI 封片剂可能导致核信号过强。

## 使用 protocol

1. 完成荧光染色和最后一次 PBS 洗涤。
2. 尽量去除多余液体，但不要让样本完全干燥。
3. 在样本上滴加适量抗淬灭封片剂。
4. 缓慢放下盖玻片，避免气泡。
5. 按产品说明书等待固化或直接成像。
6. 避光保存样本，记录保存温度和时间。

封片时的气泡、样本干燥和封片剂过量/不足，都会影响最终成像质量。

## 选择逻辑

| 场景 | 选择建议 |
| --- | --- |
| 需要长期保存切片 | hard-set 抗淬灭封片剂 |
| 当天快速成像 | 非固化型也可 |
| 已有 DAPI/Hoechst 染色 | 选择不含 DAPI 的封片剂 |
| 弱荧光目标 | 优先高效 antifade，减少曝光 |
| 多通道成像 | 确认封片剂不会增加某通道背景 |

## 注意事项

- 封片剂可能影响某些荧光染料亮度或光谱，换产品后要重新验证。
- 避免产生气泡，气泡会造成局部失焦和暗区。
- 含 DAPI 封片剂要避免和其他蓝色核染重复过量。
- 固化型封片剂固化前不要移动盖玻片。
- 不同封片剂折射率不同，对高倍油镜和共聚焦成像有影响。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 成像时信号快速变暗 | 封片剂抗淬灭效果不足或曝光过强 | 换 antifade，降低激发强度 |
| 大量气泡 | 盖玻片放置太快或封片剂体积不合适 | 缓慢放片，调整体积 |
| 核信号过强 | 已染 DAPI 又用含 DAPI 封片剂 | 改用不含核染封片剂 |
| 背景升高 | 封片剂与样本/染料不兼容 | 换产品并做阴性对照 |
| 盖玻片滑动 | 非固化型未封边或样本太湿 | 等待固化或封边 |

## 小结

抗淬灭封片剂是荧光成像的最后一道保护步骤。它影响光漂白、长期保存、背景和图像清晰度。选择封片剂时要考虑是否固化、是否含 DAPI、染料兼容性和成像时间。
