# 测序级胰蛋白酶

Sequencing-grade trypsin（测序级胰蛋白酶，也常称 MS-grade trypsin，质谱级胰蛋白酶）是经过纯化、修饰和质量控制后用于蛋白质谱样本酶切的 trypsin（胰蛋白酶）。它的核心任务是把蛋白按相对可预测的规则切成适合 [蛋白质谱](<../用(实验流程内容篇)/蛋白质谱.md>) 和 [液相色谱-质谱联用](<../用(实验流程内容篇)/液相色谱-质谱联用.md>) 分析的 [肽段](<../番外/补充知识/肽段.md>)。

## 为什么质谱要用测序级胰蛋白酶

普通胰蛋白酶也能消化蛋白，但质谱前处理更强调 digestion specificity（酶切特异性）、autolysis（自切）控制、外源蛋白污染低和批次稳定。Thermo Fisher 的 MS-grade proteases 页面说明，蛋白鉴定和定量始于高效、可重复的蛋白酶切；trypsin 是蛋白酶切中最常用的 protease of choice（首选蛋白酶），可特异性切割 lysine（赖氨酸，K）和 arginine（精氨酸，R）残基羧基端，并且常通过 TPCK 处理和化学修饰降低非目标活性与自切。参考：[Thermo Fisher Mass Spectrometry Grade Proteases](https://www.thermofisher.com/order/catalog/product/90057)

测序级胰蛋白酶的价值不是“切得越碎越好”，而是生成长度、带电状态和碎裂行为都更适合 LC-MS/MS 的肽段，同时降低由酶本身造成的背景峰。

## 核心作用

| 作用 | 对质谱的意义 | 注意点 |
| --- | --- | --- |
| 在 K/R 后切割蛋白 | 生成较容易带正电的肽段 | proline 等邻近序列会影响切割 |
| 降低蛋白复杂度 | 完整蛋白转成可分离的小肽段 | 酶切不完全会增加错切位点 |
| 提高数据库搜索可预测性 | 软件能按 trypsin 规则生成理论肽段 | 酶切规则要和搜索参数一致 |
| 支持定量比较 | 酶切效率稳定有助于样本可比 | 不同样本基质会影响效率 |

## 常见版本

| 类型 | 特点 | 适用场景 |
| --- | --- | --- |
| Modified trypsin（修饰胰蛋白酶） | 降低自切，提高稳定性 | 常规 bottom-up proteomics |
| Trypsin/Lys-C mix（胰蛋白酶/Lys-C 混合物） | 减少 [错切位点](<../番外/补充知识/错切位点.md>)，提高酶切完整性 | 复杂样本、尿素体系、需要更稳酶切 |
| Immobilized trypsin（固定化胰蛋白酶） | 便于快速酶切和去除酶 | 快速前处理或自动化流程 |
| Alternative proteases（替代蛋白酶） | Lys-C、Glu-C、Asp-N、chymotrypsin 等 | 提高 [肽段覆盖率](<../番外/补充知识/肽段覆盖率.md>) 或补充特定区域 |

Thermo Fisher 页面也指出，Lys-C 可以和 trypsin 顺序或组合使用，以降低 tryptic missed cleavages（胰蛋白酶错切），并改善蛋白序列覆盖。

## 和普通胰蛋白酶的区别

| 项目 | 测序级/质谱级胰蛋白酶 | 普通胰蛋白酶 |
| --- | --- | --- |
| 纯度 | 更关注非目标蛋白酶污染和自切背景 | 可能不适合 MS 背景要求 |
| 批次记录 | 通常有更完整 COA 和 MS 用途说明 | 多用于细胞消化或普通生化 |
| 自切控制 | 常经过修饰降低 autolysis | 自切峰可能更明显 |
| 价格 | 更贵 | 更便宜 |
| 用途 | LC-MS/MS、肽图、蛋白鉴定 | 细胞消化、一般蛋白水解 |

不要用 [Trypsin-EDTA](Trypsin-EDTA.md) 这类细胞消化液替代测序级胰蛋白酶。细胞消化液含 EDTA、盐和其他背景，且纯度/用途完全不同。

## 使用要点

**怎么做**：按平台 SOP 或产品说明书复溶、分装和保存。常见流程是在蛋白完成还原和烷基化后加入胰蛋白酶，按酶:蛋白比例和缓冲条件进行酶切。

**为什么重要**：酶切效率决定后续 peptide-spectrum match（PSM，肽段-谱图匹配）、蛋白鉴定数、定量一致性和数据库搜索质量。

**注意事项**：

- 避免反复冻融，复溶后小体积分装。
- 酶切缓冲液 pH 通常需要接近中性到弱碱性，具体按产品说明。
- 尿素、SDS、盐、有机溶剂和 pH 都会影响酶活。
- 酶切时间过短会错切多；过长可能增加非特异切割和样本损失。

**替代策略**：

- 难消化蛋白可先 Lys-C 后 trypsin。
- 想覆盖不同肽段区域，可尝试 Glu-C、Asp-N 或 chymotrypsin。
- 胶切条带可使用 in-gel digestion（胶内酶切）流程；溶液样本用 in-solution digestion（溶液酶切）。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 错切位点多 | 酶量不足、时间短、变性剂浓度高、蛋白未展开 | 优化酶:蛋白比例、延长酶切或加入 Lys-C |
| 自切峰明显 | 酶质量差、酶量过多、孵育过久 | 使用 MS-grade modified trypsin，减少酶量 |
| 鉴定数低 | 酶切差、脱盐差、样本污染或上机问题 | 检查酶切 QC、C18 回收和 LC-MS 状态 |
| 肽段太短/太长 | 酶选择不合适或非特异切割 | 调整酶种类和搜索参数 |
| 定量重复性差 | 酶切效率批间不一致 | 统一酶批号、反应条件和处理顺序 |

## 购买建议

购买时优先选择明确标注 MS grade、sequencing grade、proteomics grade 或 LC-MS/MS sample preparation 的产品。需要记录品牌、货号、批号、形式、储存条件和复溶日期。常见供应商包括 [Thermo Scientific](<../番外/试剂厂商/Thermo Scientific.md>)、[Promega](<../番外/试剂厂商/Promega.md>)、[Sigma-Aldrich](<../番外/试剂厂商/Sigma-Aldrich.md>) 等。

如果是正式蛋白组学项目，尽量不要频繁更换胰蛋白酶品牌和批号；如果必须更换，最好用 QC 样本比较酶切效率和 missed cleavage 变化。

## 小结

测序级胰蛋白酶是 bottom-up 蛋白质谱的“剪刀”。它的核心价值是特异、稳定、低背景和可重复。酶切失败会从源头影响肽段覆盖率、蛋白鉴定数、定量一致性和 FDR 控制，因此它不是普通消耗品，而是质谱样本质量的关键试剂。
