# 捕获抗体

Capture antibody（捕获抗体）是在 [夹心ELISA](<../用(实验流程内容篇)/夹心ELISA.md>)、免疫沉淀、抗原捕获和部分亲和检测中用于固定目标分子的抗体。在 ELISA 中，它通常先被包被到 [酶标板](酶标板.md) 表面，负责从复杂样本中“抓住”目标抗原。

![ELISA kit 组件参考图](../z_asset/材/ELISA试剂盒/elisa-kit-components-reference.png)

图源：Image2 生成的 ELISA kit 组件参考图；图中 capture antibody 位于夹心结构底部，负责把 antigen（抗原）固定到 well surface（孔面）上。

## 核心作用

在 sandwich ELISA 中，捕获抗体决定第一层特异性：

```text
捕获抗体固定在板面
-> 样本中的目标抗原被捕获
-> 检测抗体识别另一个表位
-> HRP/TMB产生信号
```

如果捕获抗体不合适，后面的检测抗体、TMB、酶标仪都救不回来。标准品和样本都会出现低信号、背景高或曲线不稳定。

## 捕获抗体和检测抗体的区别

| 维度 | 捕获抗体 | [检测抗体](检测抗体.md) |
| --- | --- | --- |
| 位置 | 固定在板面或固相载体 | 溶液中加入后结合抗原 |
| 作用 | 抓住目标抗原 | 提供第二重识别和信号入口 |
| 标记 | 通常不带酶标 | 可带 biotin、HRP 或被二抗识别 |
| 关键要求 | 稳定包被、保持结合能力 | 不与捕获抗体竞争表位 |
| 常见问题 | 包被不足、方向性差、表位被遮挡 | 背景高、交叉反应、酶标物过强 |

捕获抗体和检测抗体不是随便两支同靶标抗体就能组合。它们需要构成 matched antibody pair（[配对抗体](配对抗体.md)），识别目标抗原上可以同时暴露的不同表位。

## 选择标准

### 表位不竞争

捕获抗体和检测抗体最好识别不同 epitope（表位）。如果两者竞争同一位点，目标抗原被捕获后，检测抗体就无法再结合，标准曲线会很差甚至没有信号。

### 能稳定包被

捕获抗体需要在板面上保持足够的结合能力。不同抗体在不同 coating buffer、pH、盐浓度和板面类型下表现不同。

### 适合样本物种和目标形式

如果目标蛋白有前体、成熟体、剪切片段、糖基化形式或物种差异，捕获抗体可能只识别其中一部分。购买时要看 species reactivity（物种反应性）和 immunogen（免疫原）。

### 与样本基质兼容

血清、血浆、组织裂解液和细胞上清中的蛋白、脂质、盐和干扰抗体可能影响捕获效率。正式实验最好查看 kit 或 antibody pair 是否验证过对应样本类型。

## 常见形式

| 形式 | 用途 |
| --- | --- |
| unconjugated capture antibody | 直接包被板面 |
| biotinylated capture antibody | 固定到 streptavidin-coated plate |
| antibody pair 中的 capture antibody | 与指定 detection antibody 配套 |
| pre-coated plate 上的 capture antibody | 已固定，用户无需包被 |

[生物素化抗体](生物素化抗体.md) + streptavidin-coated plate 可以改善方向性和固定效率，但也要注意内源性 biotin、封闭体系和链霉亲和素背景。

## 使用注意事项

### 包被浓度需要优化

捕获抗体浓度太低会灵敏度不足；太高可能增加非特异背景或浪费抗体。自建 ELISA 时常需要做 checkerboard titration（棋盘滴定），同时优化捕获抗体和检测抗体浓度。

### 避免反复冻融

抗体反复冻融可能聚集或活性下降。长期使用应分装保存，并记录冻融次数。

### 不要随意换 clone

同一靶标的不同 clone 可能识别不同表位。换 clone 等于换 assay 结构，不能只看“都是 anti-IL-6 antibody”就直接替代。

### 记录缓冲液和板型

捕获抗体包被效果依赖 coating buffer 和 plate surface。记录里应写清酶标板型号、包被缓冲液、抗体浓度、时间和温度。

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 标准曲线整体低 | 捕获抗体包被不足或活性下降 | 提高浓度，换新抗体或换板 |
| 标准品无信号 | 捕获/检测抗体不配对 | 使用厂家推荐抗体对 |
| 背景高 | 捕获抗体过浓、板面封闭不足 | 降低包被量，优化封闭 |
| 样本有信号但回收率差 | 基质影响捕获 | 做 spike recovery，调整稀释液 |
| 批间差异大 | 抗体批号或板批号变化 | 同项目固定批号，加 QC |

## 购买建议

优先购买已验证 matched antibody pair 或商业 ELISA kit 中配套的捕获抗体。常见供应商包括 [R&D Systems](<../番外/试剂厂商/R&D Systems.md>)、[BioLegend](<../番外/试剂厂商/BioLegend.md>)、[Thermo Fisher Scientific](<../番外/试剂厂商/Thermo Fisher Scientific.md>)、[Abcam](<../番外/试剂厂商/Abcam.md>) 等。购买单支捕获抗体时，要确认是否推荐用于 ELISA capture，而不只是 WB、flow 或 IF 验证。

## 总结

捕获抗体是夹心 ELISA 的地基。它决定目标抗原能否从样本中被稳定、特异地抓到板面。做自建 ELISA 或替换 kit 组件时，最不能随意换的就是捕获抗体和检测抗体的配对关系。
