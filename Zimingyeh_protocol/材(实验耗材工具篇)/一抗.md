# 一抗

## 一句话定义

Primary antibody（一抗，一级抗体）是直接识别目标抗原或目标蛋白特定 epitope（表位）的抗体，是 [Western blot](<../用(实验流程内容篇)/Western blot.md>)、[免疫荧光](<../用(实验流程内容篇)/免疫荧光.md>)、[免疫组化](<../用(实验流程内容篇)/免疫组化.md>) 和 [ELISA](<../用(实验流程内容篇)/ELISA.md>) 等免疫检测实验中决定特异性的核心试剂。

在 WB 中，一抗结合膜上的目标蛋白，随后由 [二抗](二抗.md) 识别一抗并带来 HRP、AP 或荧光信号。CST、Thermo Fisher、Bio-Rad 和 Abcam 的 WB protocol 都把一抗孵育、洗膜和二抗检测作为免疫检测阶段的关键步骤。[参考：CST Western Blot Protocol](https://www.cellsignal.com/learn-and-support/protocols/protocol-western)；[参考：Thermo Fisher Western Blot Protocols](https://www.thermofisher.com/uk/en/home/life-science/protein-biology/protein-biology-learning-center/protein-gel-electrophoresis-information/western-blot-protocols.html)

## 一抗决定什么

| 决定因素 | 对结果的影响 |
| --- | --- |
| 特异性 | 是否只识别目标蛋白，而不是一堆非特异条带 |
| 灵敏度 | 低丰度目标能不能被检测到 |
| 应用兼容性 | WB 可用的一抗不一定适合 IF/IHC/ELISA |
| 物种反应性 | 人、小鼠、大鼠等样本能否被识别 |
| 表位位置 | 目标蛋白剪切、修饰或构象改变后是否还能识别 |

一抗不是“买一个抗体就能检测一个蛋白”这么简单。真正要判断的是：它识别哪个蛋白、哪个表位、在哪种应用里被验证过、在你的样本物种中是否有效。

## 常见类型

| 类型 | 英文 | 特点 | 适合场景 |
| --- | --- | --- | --- |
| [单克隆抗体](../番外/补充知识/单克隆抗体.md) | Monoclonal antibody | 识别单一表位，批次一致性好 | 定量 WB、长期项目、需要高一致性 |
| [多克隆抗体](../番外/补充知识/多克隆抗体.md) | Polyclonal antibody | 识别多个表位，信号可能更强 | 低丰度蛋白、探索阶段 |
| [重组抗体](../番外/补充知识/重组抗体.md) | Recombinant antibody | 序列定义明确，可重复生产 | 高可重复性、长期稳定供应 |
| Phospho-specific antibody | 磷酸化特异性抗体 | 识别特定位点磷酸化状态 | 信号通路、激酶活性研究 |
| Tag antibody | 标签抗体 | 识别 FLAG/HA/Myc/GFP 等标签 | 过表达、构建验证 |

如果实验要长期维护或发表，优先选择验证信息完整、批次稳定、引用和产品资料透明的一抗。探索阶段可以用多克隆抗体提高命中率，但后续最好用独立抗体验证关键结论。

## 选择标准

| 检查项 | 该看什么 |
| --- | --- |
| Application | 是否明确验证 WB、IF、IHC 或 ELISA |
| Species reactivity | 是否支持你的样本物种 |
| Host species | 一抗宿主决定二抗选择，例如 rabbit/mouse/goat |
| Clonality | 单克隆、多克隆、重组抗体 |
| Immunogen | 免疫原区域是否可能与目标 isoform 区分相关 |
| Molecular weight | WB 条带是否接近理论分子量 |
| Validation | 是否有 KO/KD、过表达、肽竞争或多抗体验证 |
| Storage | 是否含甘油、BSA、叠氮钠，保存温度如何 |

抗体说明书里的 WB 图片只能说明“在某个条件下出现过条带”，不等于你的样本必然可用。最可靠的选择是：目标蛋白、样本物种、实验应用、分子量和验证证据都匹配。

## WB使用 protocol

### 孵育前准备

1. 完成转膜、[Ponceau S](<Ponceau S.md>) 检查和 [封闭液](封闭液.md) 封闭。
2. 按说明书或预实验结果选择一抗稀释比例。
3. 使用合适的 [抗体稀释液](抗体稀释液.md)，常见为 [TBST](TBST.md) 加 [BSA](BSA.md) 或 [脱脂奶粉](脱脂奶粉.md)。
4. 若检测 phospho-protein（磷酸化蛋白），通常优先用 BSA 而不是脱脂奶粉。

### 一抗孵育

常见条件：

```text
4°C overnight
或
室温 1-2 h
```

4°C 过夜通常更适合低丰度目标、亲和力一般的一抗或需要提高灵敏度的检测。室温短孵育更快，但更容易需要优化抗体浓度和背景。

### 洗膜

一抗孵育后通常用 TBST 洗膜，例如：

```text
TBST 5-10 min × 3 次
```

洗膜的目的不是“把抗体全洗掉”，而是去除未结合和弱非特异结合的一抗。洗膜不足会导致背景升高；洗膜过强或条件不合适可能降低弱目标信号。

## 注意事项

- 一抗第一次使用时不要只做一个稀释度，建议做 1:500、1:1000、1:2000 等小范围优化。
- 一抗冻融会影响活性，常见做法是分装保存。
- 含 [叠氮钠](叠氮钠.md) 的一抗可抑制 [辣根过氧化物酶](辣根过氧化物酶.md)，不要直接与 HRP 反应体系混用。
- 不同批号一抗可能表现不同，长期项目应记录 lot number。
- 检测内参时也要避免过曝，参考 [内参蛋白](../番外/补充知识/内参蛋白.md) 的选择逻辑。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 建议 |
| --- | --- | --- |
| 无条带 | 一抗不适用于 WB、样本无表达、抗原降解 | 查 application，做阳性对照，检查裂解和转膜 |
| 非特异条带多 | 一抗特异性不足、浓度过高、封闭不合适 | 降低浓度，换封闭液，选择验证更好的抗体 |
| 条带分子量不对 | 修饰、剪切、isoform、非特异识别 | 查蛋白 isoform 和修饰，使用 KO/KD 对照 |
| 背景高 | 一抗过浓、洗膜不足、膜材背景高 | 稀释一抗，增加 TBST 洗膜，优化封闭 |
| 批次变化大 | 抗体 lot 差异 | 记录批号，关键项目做新旧批号桥接测试 |

## 购买和记录建议

购买一抗时优先选择资料完整的产品：应用验证图、物种反应性、免疫原、克隆号、批号、引用、KO/KD 验证和推荐稀释度都应尽量明确。CST、Abcam、Proteintech、Thermo Fisher、Bio-Rad 等厂家都提供大量抗体产品，但具体抗体质量仍需逐个判断，不能只看品牌。

## 小结

一抗是免疫检测的特异性核心。真正可靠的一抗记录应包括品牌、货号、批号、克隆号、宿主、应用、样本物种、稀释度和验证证据。WB 出问题时，一抗是必须重点排查的变量，但不能脱离样本、转膜、封闭和二抗单独判断。
