# 滤芯吸头

Filter tip / barrier tip（滤芯吸头/屏障吸头）是在普通 [移液枪吸头](移液枪吸头.md) 上方加入多孔滤芯的一类吸头，用于降低 aerosol（气溶胶）和液体倒吸进入移液器内部的风险。它尤其适合 [PCR](<../用(实验流程内容篇)/PCR.md>)、[RT-qPCR](<../用(实验流程内容篇)/RT-qPCR.md>)、RNA 实验、细胞培养污染控制和潜在感染性样本。

## 核心作用

| 作用 | 为什么重要 |
| --- | --- |
| 阻挡气溶胶 | 降低 DNA/RNA、细胞污染物或病原体进入移液器 |
| 保护移液器内部 | 减少液体倒吸造成的腐蚀和交叉污染 |
| 降低样本间 carryover | 对 PCR/qPCR 和低拷贝检测尤其重要 |
| 支持无菌和洁净操作 | 细胞培养、RNA 和微量样本更稳 |

Thermo Scientific 对 ART barrier tips 的说明强调，屏障吸头用于防止 aerosol 和 liquid contamination（气溶胶和液体污染）进入移液器，从而保护样品和移液器。[参考：Thermo Scientific ART Barrier Tips](https://www.thermofisher.com/us/en/home/life-science/lab-plasticware-supplies/pipette-tips/art-barrier-tips.html)

## 什么时候必须优先用

- PCR、qPCR、RT-qPCR、测序文库构建等扩增前体系。
- RNA 提取、逆转录和低拷贝核酸检测。
- 细胞培养中的无菌加样、感染性样本或污染风险较高样本。
- 移取强腐蚀、易挥发或不希望进入移液器内部的液体。
- 多人共用移液器时的污染防护。

普通缓冲液、培养基大体积转移不一定必须使用滤芯吸头；但涉及扩增反应、核酸模板或污染后果严重的样本时，滤芯吸头的成本通常值得。

## 滤芯吸头 vs 普通吸头

| 项目 | 普通吸头 | 滤芯吸头 |
| --- | --- | --- |
| 成本 | 低 | 高 |
| 防气溶胶 | 弱 | 强 |
| 适合 PCR/RNA | 不推荐作为默认 | 推荐 |
| 适合细胞培养 | 可用 | 更适合关键无菌操作 |
| 最大吸液风险 | 倒吸污染移液器 | 滤芯可降低但不能无限防护 |

滤芯不是“免疫污染护盾”。如果吸液超过量程、液体进入滤芯或吸头外壁带液，污染风险依然存在。

## 使用 protocol

### 选择吸头

**怎么做**：选择与移液器量程匹配、无菌或 RNase/DNase-free 的滤芯吸头。PCR/qPCR 优先选择无 DNA、无核酸酶等级。

**为什么**：滤芯只解决气溶胶/倒吸风险，不能替代无核酸酶等级和规范操作。

**注意事项**：

- 不同滤芯材料、位置和死体积会影响最大吸液体积。
- 小体积定量实验尽量固定同一品牌型号。
- 多道移液器要确认吸头排布和适配性。

### 吸液

**怎么做**：缓慢吸液，避免超过吸头额定体积；不要让液体接触滤芯。

**为什么**：液体接触滤芯后，滤芯可能形成阻力、影响体积，并把污染物留在吸头上方区域。

**注意事项**：

- 不要横放带液吸头。
- 挥发性液体更容易产生压力和体积误差。
- 一旦液体进入滤芯，弃用吸头并检查移液器是否污染。

### PCR/qPCR 加样

**怎么做**：在专门的 PCR clean area（PCR 洁净区）使用滤芯吸头，模板、引物、master mix 分区操作。加样后及时更换吸头。

**为什么**：PCR/qPCR 的最大风险之一是扩增产物或模板微量污染，滤芯吸头能降低气溶胶回流风险，但仍需要区域管理。

**替代方案**：高通量体系可使用滤芯自动化吸头或预装滤芯吸头盒。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 体积偏低 | 滤芯受潮、吸液太快、吸头不适配 | 换新吸头，降低速度，验证适配 |
| qPCR 阴性孔有信号 | 模板/扩增产物污染、吸头外壁带液 | 分区操作，换滤芯吸头，清洁操作台 |
| 移液器被污染 | 液体超过量程或进入滤芯 | 送检清洁，后续控制吸液体积 |
| 成本过高 | 所有普通操作都用滤芯 | 按风险分层使用，高风险流程固定使用 |

## 购买与记录建议

购买时关注：量程、是否 sterile（无菌）、是否 RNase/DNase-free（无核酸酶）、是否 non-pyrogenic（无热原）、是否 low-retention（低吸附）、是否适配对应移液器。常见供应商包括 [Thermo Scientific](<../番外/试剂厂商/Thermo Scientific.md>)、[Eppendorf](<../番外/试剂厂商/Eppendorf.md>)、[Rainin](<../番外/试剂厂商/Rainin.md>)、[Sartorius](<../番外/试剂厂商/Sartorius.md>) 等。

推荐记录：

```text
Filter tip, volume range, sterile, RNase/DNase-free, brand, catalog number, lot number, application
```

## 小结

滤芯吸头最重要的价值是污染控制，尤其是核酸扩增和无菌样本。它不能替代好习惯，但能让高风险移液流程更可控。
