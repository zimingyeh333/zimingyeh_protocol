# 脱氧胆酸钠

脱氧胆酸钠（sodium deoxycholate，deoxycholic acid sodium salt，脱氧胆酸钠盐）是一种胆汁酸盐类 ionic detergent（离子型去污剂），常作为 [RIPA裂解液](RIPA裂解液.md) 的核心组分之一，用于增强膜结构破坏和膜相关蛋白溶解能力。

![裂解去污剂与甘油参考图](../z_asset/材/裂解去污剂与甘油/lysis-detergents-glycerol-reference.png)

图源：Image2 生成的裂解去污剂与甘油参考图；脱氧胆酸钠位于右上方，图中把它归为 stronger RIPA component（更强的 RIPA 裂解组分）。

## 核心作用

脱氧胆酸钠比 Triton X-100/NP-40 更强，能帮助溶解膜脂和部分膜相关蛋白，并使 RIPA 从“温和破膜”转向“较强全蛋白裂解”。Thermo Fisher RIPA Buffer 产品资料列出的经典配方中含 1% NP-40、1% sodium deoxycholate 和 0.1% SDS，说明脱氧胆酸钠是 RIPA 强裂解能力的重要来源之一。参考：[Thermo Fisher RIPA Buffer](https://www.thermofisher.com/order/catalog/product/89900)。

Sigma-Aldrich 的 Sodium deoxycholate D6750 产品页面列出其同义名包括 3α,12α-dihydroxy-5β-cholanic acid sodium salt，并给出 CAS 302-95-4、分子量 414.55 等信息。参考：[Sigma-Aldrich Sodium deoxycholate D6750](https://www.sigmaaldrich.com/US/en/product/sial/d6750)。

## 在RIPA中的位置

| 成分 | 类型 | 主要贡献 |
| --- | --- | --- |
| [Triton X-100](<Triton X-100.md>) 或 [NP-40](NP-40.md) | 非离子去污剂 | 温和破膜和蛋白溶解 |
| 脱氧胆酸钠 | 离子型胆汁酸盐 | 增强膜相关蛋白溶解 |
| [SDS](十二烷基硫酸钠.md) | 强阴离子去污剂 | 强变性和强裂解 |
| [Tris](Tris.md)/[氯化钠](氯化钠.md)/[EDTA](EDTA.md) | buffer/盐/螯合剂 | pH、离子强度和酶抑制环境 |

RIPA 的强度来自这些去污剂叠加。脱氧胆酸钠不是单独万能，但缺少它时，RIPA 对部分膜结构和膜相关蛋白的提取能力可能下降。

## 适合与不适合

| 场景 | 是否适合 | 理由 |
| --- | --- | --- |
| 常规 WB 总蛋白 | 适合 | 裂解能力强，适合多数组分 |
| 膜相关蛋白检测 | 可能有帮助 | 比温和非离子去污剂更强 |
| IP-WB | 谨慎 | 可能破坏蛋白互作或抗体结合 |
| 酶活实验 | 通常不适合 | 去污剂可能破坏天然活性 |
| 蛋白复合物分析 | 谨慎 | 过强裂解可能拆散复合物 |

## 使用 protocol

### 自配RIPA

**怎么做**：按配方加入脱氧胆酸钠，常见终浓度约 0.5%-1%，配合 NP-40/Triton X-100 和少量 SDS。

**为什么**：脱氧胆酸钠增强膜溶解，但浓度过高可能增加蛋白变性、沉淀或下游干扰。

**注意事项**：

- 脱氧胆酸钠粉末可能刺激眼睛和呼吸道，按 [SDS与GHS标签](<../实验室安全/SDS与GHS标签.md>) 操作。
- 配液时确保完全溶解，必要时温和混匀。
- 加入抑制剂后的 RIPA 不建议长期保存。

### 用于膜蛋白优化

**怎么做**：如果目标膜蛋白 RIPA 提取仍不理想，可比较 RIPA、含 [CHAPS](CHAPS.md)/[洋地黄皂苷](洋地黄皂苷.md) 的温和体系或专用膜蛋白提取试剂。

**为什么**：不同膜蛋白对去污剂高度敏感，强裂解不一定等于高质量提取。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| IP 信号消失 | 脱氧胆酸钠/SDS 破坏互作 | 换温和 NP-40/Triton 裂解液 |
| 蛋白沉淀或浑浊 | 去污剂浓度、盐或温度不合适 | 降低浓度、优化盐和澄清步骤 |
| BCA 定量异常 | 去污剂组合干扰定量 | 查兼容表，稀释样本或换定量法 |
| 目标膜蛋白仍低 | 去污剂体系不匹配 | 尝试专用膜蛋白提取体系 |
| 背景高 | 裂解过强释放复杂组分 | 增加澄清、优化洗涤和上样量 |

## 小结

脱氧胆酸钠是 RIPA 从温和裂解走向强裂解的重要推手。它能提高膜相关组分提取能力，但也会增加破坏蛋白互作、干扰定量和改变样本复杂度的风险。
