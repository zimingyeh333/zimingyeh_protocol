# 化学成分明确培养基

化学成分明确培养基（chemically defined medium，CDM；也称 defined medium，成分明确培养基）是指培养基中每个成分及其浓度尽可能已知、可控、可记录的细胞培养体系。它常用于减少 [FBS](FBS.md) 和复杂提取物带来的未知变量。

![专用细胞培养基参考图](../z_asset/材/专用细胞培养基/specialized-cell-culture-media-reference.png)

图源：Image2 生成的专用细胞培养基参考图；chemically defined 位于 serum-free 之后，代表比普通无血清更高的成分控制层级。

## 核心定位

普通 [无血清培养基](无血清培养基.md) 只说明“不含 serum”，不一定说明所有成分都完全明确。Chemically defined medium 更进一步，强调配方中氨基酸、维生素、盐、脂质、重组蛋白、生长因子和其他小分子都尽量以明确浓度加入。

Thermo Fisher 的 Serum-Free Media 页面把 serum-free、chemically defined 和 protein-free formulations 放在不同选择维度中，说明无血清培养基可进一步根据成分定义程度和是否含蛋白分类。参考：[Thermo Fisher Serum-Free Media](https://www.thermofisher.com/us/en/home/life-science/cell-culture/mammalian-cell-culture/cell-culture-media/serum-free-media.html)。

## 和相关概念的区别

| 概念 | 含义 | 关键区别 |
| --- | --- | --- |
| Serum-free medium | 不含血清 | 可能仍有成分不完全明确 |
| Chemically defined medium | 成分和浓度尽量明确 | 不一定无动物源 |
| Protein-free medium | 不加蛋白或蛋白水解物 | 不一定适合贴壁/复杂细胞 |
| [Xeno-free培养基](Xeno-free培养基.md) | 不含异种动物来源成分 | 不一定每个成分都 chemically defined |
| Animal component-free | 不含动物来源组分 | 需看厂家定义和 COA |

一句话：serum-free 解决“没有血清”，chemically defined 解决“知道里面有什么”，xeno-free 解决“来源是不是异种动物”。

## 常见组成逻辑

| 层级 | 例子 | 记录重点 |
| --- | --- | --- |
| 基础营养 | DMEM/F-12、RPMI、α-MEM 定义版本 | 基础培养基货号和 formulation |
| 微量元素 | selenium、iron、zinc 等 | 来源和浓度 |
| 结合/载体 | recombinant albumin、transferrin | 是否重组、人源/动物源 |
| 脂质 | lipid concentrate、cholesterol | 是否 chemically defined |
| 生长因子 | EGF、FGF2、TGF-β、Wnt 等 | 物种、活性、批号、重构方式 |
| 基质 | recombinant laminin、defined matrix | 是否 xeno-free，是否 animal-derived |

## 什么时候优先考虑

| 场景 | 原因 |
| --- | --- |
| 干细胞和分化体系 | 成分可控，减少批次漂移 |
| 类器官培养 | 生长因子和 Wnt/R-spondin 等通路变量需明确 |
| 蛋白/外泌体/代谢物检测 | 减少血清蛋白和未知背景 |
| 生物生产和转化研究 | 更利于质量控制和放大 |
| 机制研究 | 减少“血清里未知因子”的解释问题 |

## 使用 protocol

### 设计或选择CDM

**怎么做**：优先选择已验证的商业 chemically defined medium 或文献 protocol；如果自配，需要逐项列出成分、供应商、纯度、终浓度和储存条件。

**为什么**：CDM 的优势来自可控性，若只写“defined medium”，不写成分，优势就消失了。

### 验证

**怎么做**：用 FBS-containing 或原培养体系作为对照，比较细胞形态、活率、增殖、marker、分化能力和关键 readout。

**为什么**：成分明确不等于细胞状态正确。CDM 可能改变选择压力和表型。

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 细胞状态变好但实验结论变了 | 移除了血清背景或改变了信号输入 | 重新建立对照和基线 |
| 细胞死亡或贴壁差 | 缺少基质、脂质或保护蛋白 | 补充 defined matrix、albumin/lipid |
| 批间差异仍存在 | 生长因子或基质批次差异 | 记录活性单位、批号和重构方式 |
| 以为CDM一定xeno-free | CDM可能含动物来源蛋白 | 查看 COA 和来源声明 |

## 小结

化学成分明确培养基的价值是把培养体系从“黑箱支持”推向“可解释变量”。它适合严肃机制研究、干细胞分化、类器官、生产和低背景检测，但必须通过完整配方记录和细胞状态验证来兑现这个优势。
