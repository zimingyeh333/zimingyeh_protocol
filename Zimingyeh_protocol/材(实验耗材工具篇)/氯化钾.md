# 氯化钾

Potassium chloride（KCl，氯化钾）是一种由 K+ 和 Cl- 组成的无机盐。在常规生物实验中，它常作为强电解质、离子强度调节组分、[电导率](<../番外/补充知识/电导率.md>) 标准液来源，以及 [pH计](pH计.md) 电极填充液或保存液的常见成分。

## 为什么 KCl 常被用于测量系统

KCl 在水中形成一价阳离子 K+ 和一价阴离子 Cl-，行为相对简单、溶解性好、配制方便，因此适合作为电解质标准体系。电导率仪常用的标准液很多是基于 KCl 溶液标定或制备的，例如 84 μS/cm、1413 μS/cm、12.88 mS/cm 等不同范围的 conductivity standard（电导率标准液）。

在电导率校准中，标准液的电导率应接近样品范围。用高电导标准液去校准后直接测超纯水，或用低电导标准液去覆盖高盐样品，都可能增加误差。

参考：[Mettler Toledo Conductivity Theory Guide](https://www.mt.com/us/en/home/library/guides/lab-analytical-instruments/conductivity-theory-guide.html)。

## 主要用途

### 电导率标准液

[电导率仪](电导率仪.md) 需要用已知电导率的标准液确定 cell constant（电导池常数）或验证探头状态。KCl 标准液是最常见的电导率校准体系之一。

实际使用中，不建议为了省钱随手称 KCl 自配“校准标准液”。电导率标准对水质、温度、称量、定容、容器洁净度和 CO2 暴露都敏感。普通实验记录可以自配参考液做粗略检查，但正式校准应优先使用商业 certified standard（认证标准液）。

### pH 电极填充液或保存液

许多复合玻璃 pH 电极使用 KCl 溶液作为 internal filling solution（内充液）或 storage solution（保存液）的一部分，常见浓度包括 3 M KCl 或饱和 KCl。具体是否能补液、用什么浓度、是否含 AgCl，要以电极说明书为准。

不要把 pH 电极长期放在 [超纯水](超纯水.md) 中。超纯水离子强度极低，可能破坏电极水合层、稀释参比系统或导致响应变差。电极保存通常需要厂家指定的 KCl 保存液或专用电极保存液。

### 缓冲液和生理盐体系组分

KCl 也是 [PBS](PBS.md) 等平衡盐溶液里的少量组分之一，用来提供钾离子，使溶液离子环境更接近生理状态。相比 NaCl，KCl 的浓度通常低得多，因为细胞外液中 K+ 浓度远低于 Na+。

### 调整离子强度

在部分蛋白、核酸或电化学实验中，KCl 可用于调整 [离子强度](<../番外/补充知识/离子强度.md>)。但 KCl 不是“惰性背景盐”，高浓度 K+ 或 Cl- 可能影响蛋白构象、酶活、核酸结构、细胞膜电位或电极读数。

## KCl vs 常见相似盐

| 对比对象 | 相同点 | 关键区别 |
| --- | --- | --- |
| NaCl（sodium chloride，氯化钠） | 都是一价强电解质 | NaCl 更常用于模拟细胞外主要盐环境；KCl 更适合补充 K+ 或电极/标准液体系 |
| MgCl2（magnesium chloride，氯化镁） | 都提供 Cl- | Mg2+ 是二价离子，对离子强度、酶反应和核酸结构影响更强 |
| K2HPO4/KH2PO4（磷酸氢二钾/磷酸二氢钾） | 都含 K+ | 磷酸盐还能提供缓冲能力，KCl 本身基本不提供 pH 缓冲能力 |
| 商业电导率标准液 | 常以 KCl 体系为基础 | 标准液有认证值、温度表和批号追溯，自配 KCl 不能默认等同 |

## 配制示例：1 M KCl 储液

这个配方适合普通缓冲液或非校准用途，不适合作为正式电导率认证标准液。

### 计算

1 M KCl = 1 mol/L。KCl 分子量约 74.55 g/mol，因此配制 1 L 1 M KCl 需要约 74.55 g KCl。

### 操作

1. 称取 74.55 g KCl。
2. 加入约 800 mL 超纯水或去离子水溶解。
3. 转入 1 L 容量瓶或合适容器，定容至 1 L。
4. 混匀后根据用途过滤除菌或高压灭菌。
5. 标记浓度、日期、操作者、是否无菌、保存条件。

### 注意

- 用于细胞或无菌体系时，应使用合适等级的水和无菌处理。
- 用于电极保存液时，不要自行替代厂家指定配方，尤其是含 Ag/AgCl 参比系统的电极。
- 用于电导率校准时，优先购买商业标准液。

## 选择和购买

KCl 购买时要按用途选择等级：

| 用途 | 建议等级 |
| --- | --- |
| 常规缓冲液 | analytical grade（分析纯）或以上 |
| 分子生物学体系 | molecular biology grade（分子生物学级） |
| 细胞相关体系 | cell culture tested、sterile 或低内毒素版本，视实验而定 |
| 电导率校准 | 商业 conductivity standard，不建议普通粉末自配替代 |
| pH 电极维护 | 厂家指定 filling/storage solution |

常见供应商包括 [Sigma-Aldrich](<../番外/试剂厂商/Sigma-Aldrich.md>) / [Merck](<../番外/试剂厂商/Merck.md>)、[Thermo Fisher Scientific](<../番外/试剂厂商/Thermo Fisher Scientific.md>)、[Mettler Toledo](<../番外/试剂厂商/Mettler Toledo.md>)、[Hanna Instruments](<../番外/试剂厂商/Hanna Instruments.md>) 等。粉末 KCl 和 KCl 标准液不是同一类采购逻辑：前者看纯度和等级，后者看认证值、温度表、批号和有效期。

## 常见错误与 troubleshooting

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 电导率校准后样品仍漂移 | 标准液污染、温度未平衡、探头气泡或 cell constant 异常 | 换新标准液，等温度稳定，排气泡，重新校准 |
| 自配 KCl 标准液与商业标准差异大 | 称量、水质、定容、CO2、容器污染、温度校正不一致 | 正式校准用商业认证标准液 |
| pH 电极保存后响应变慢 | 错把电极放在水中或错误 KCl 浓度中 | 按说明书用电极保存液恢复，必要时更换电极 |
| 细胞实验异常 | KCl 浓度过高，改变渗透压和膜电位 | 检查终浓度，优先按成熟配方使用 |
| 蛋白/酶反应改变 | 离子强度或特定离子效应改变 | 做梯度优化，不能只按“盐浓度”粗略替换 |

## 总结

KCl 的实验价值不只在“提供钾离子”。在 pH 电极、电导率校准和离子强度控制中，它经常承担测量系统和溶液体系之间的连接角色。使用时要先判断它是普通试剂、校准标准，还是电极维护液；三者的质量要求和替代风险完全不同。
