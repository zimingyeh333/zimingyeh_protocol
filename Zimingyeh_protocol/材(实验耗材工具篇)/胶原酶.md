# 胶原酶

Collagenase（胶原酶）是一类能降解 collagen（胶原）的酶，常用于组织消化、原代细胞分离、类器官或 ECM 丰富样本的解离。它不是常规贴壁细胞传代的默认试剂，而是处理组织结构和细胞外基质时非常重要的工具。

[Worthington](<../番外/试剂厂商/Worthington.md>) 的组织解离指南强调，胶原酶常用于从组织中释放细胞，因为 collagen 是许多组织细胞外基质的重要成分；不同 collagenase type（胶原酶类型）和不同组织之间需要优化。[参考：Worthington Collagenase](https://www.worthington-biochem.com/tools-resources/tissue-dissociation-guide/dissociating-enzymes-collagenase)

## 胶原酶在做什么

组织不是一团松散细胞，而是细胞、胶原、基底膜、蛋白多糖和其他 ECM 共同构成的结构。胶原酶通过降解胶原网络，让目标细胞更容易从组织中释放出来。

| 作用对象 | 实验意义 |
| --- | --- |
| Collagen I/II/III 等胶原结构 | 释放间质、腺体、脂肪、骨软骨等组织中的细胞 |
| ECM scaffold（细胞外基质支架） | 降低组织块硬度，促进机械吹打释放细胞 |
| 组织片段 | 与剪碎、摇晃、过滤配合形成单细胞或小团块悬液 |

Worthington 也提醒，组织解离常不是单一酶完成，而是 collagenase、neutral protease、DNase 和机械处理共同影响最终产量与活率。[参考：Worthington Tissue Dissociation Guide](https://www.worthington-biochem.com/tools-resources/tissue-dissociation-guide)

## 常见类型

不同厂商的 collagenase type 命名和活性定义并不完全等价，不能只看“Type I/II/IV”就跨厂家替换。

| 类型 | 常见理解 | 典型场景 |
| --- | --- | --- |
| Collagenase Type I | 常用于上皮、肺、脂肪、肾上腺等多种组织 | 通用组织消化起点 |
| Collagenase Type II | 常用于心脏、骨、软骨、肝等组织 | 组织较致密或胶原丰富时常见 |
| Collagenase Type IV | 相对更常用于胰岛、免疫细胞或希望减少胰蛋白酶样活性的场景 | 对细胞表面蛋白更敏感的流程 |
| Purified collagenase blends | 纯化混合体系，常配合中性蛋白酶 | 对批次一致性和可控性要求更高的原代分离 |

这张表只能作为入门理解，真正实验应优先参考目标组织的成熟 protocol 或细胞库/厂商推荐。

## 胶原酶 vs Dispase vs Trypsin

| 试剂 | 主要解决的问题 | 更适合 |
| --- | --- | --- |
| 胶原酶 | 胶原丰富 ECM 难以拆开 | 组织消化、原代细胞分离 |
| [Dispase](Dispase.md) | 基底膜、片层和温和组织层分离 | 上皮层、干细胞团块、组织层解离 |
| [Trypsin-EDTA](Trypsin-EDTA.md) | 细胞从培养表面脱落 | 常规贴壁细胞传代 |
| [Accutase](Accutase.md) | 温和单细胞化和表面 marker 保护 | 流式、敏感细胞、干细胞 |

如果样本是普通培养瓶中的贴壁细胞，通常不需要胶原酶；如果样本是组织块、类器官、胶原凝胶或 ECM 很厚的培养体系，胶原酶才进入核心选择。

## 使用 protocol

### 设计条件

**怎么做**：根据组织类型、目标细胞、样本大小和下游用途选择 collagenase 类型、浓度、温度、时间、是否加入 Dispase 或 DNase I。第一次做应设置小规模条件梯度。

**为什么**：胶原酶消化的窗口很窄。消化不足产量低，消化过度会损伤细胞、改变表面抗原或选择性杀伤脆弱细胞。

**注意事项**：

- 不同批次活性差异可能很明显。
- 记录活性单位比只记录质量浓度更可靠。
- 组织越大，机械剪碎越重要。

### 组织预处理

**怎么做**：在无菌条件下去除明显坏死、脂肪或非目标组织，剪碎成适合消化的小片段，再加入预温胶原酶工作液。

**为什么**：酶只能从组织表面向内作用，组织块太大时外层过度消化而内部仍未释放。

**注意事项**：

- 剪碎过程要避免样本干燥。
- 保持样本来源、时间和保存条件一致。
- 人体或动物组织必须遵守对应生物安全与伦理规范。

### 消化、混匀和终止

**怎么做**：在推荐温度下温和振荡或定时轻柔吹打，观察组织块变小和细胞释放情况。达到终点后用含血清培养基或目标缓冲液稀释/终止，过滤去除残渣。

**为什么**：温和机械力可以提高释放效率；及时终止可降低过度消化损伤。

**注意事项**：

- 不要把组织“完全消失”作为唯一终点。
- 需要流式或单细胞测序时，控制死细胞和团块比追求最高产量更重要。
- DNA 黏连明显时可评估 [DNase I](DNase I.md)。

### 洗涤、计数和下游

**怎么做**：离心洗去酶液，重悬后过滤、计数、评估活率，并根据下游进行培养、流式、分选或冻存。

**为什么**：残留胶原酶和组织碎片会影响贴壁、染色、计数和下游分析。

**注意事项**：

- 低速离心条件要按细胞类型优化，避免丢失脆弱细胞。
- 过滤孔径会影响回收率和团块残留。
- 下游培养时可设置短暂恢复期。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 细胞产量低 | 组织块太大、酶活低、时间不足、类型不合适 | 剪更小，换批或换类型，做时间梯度 |
| 活率低 | 消化太久、机械力太强、组织处理延迟 | 缩短时间，降低吹打，优化取材到处理时间 |
| 团块多 | ECM 未充分消化、DNA 黏连、过滤不足 | 联合 Dispase/DNase I，优化过滤 |
| 批次不稳定 | 胶原酶 crude mixture 批差大 | 固定供应商和 lot，换批做桥接验证 |
| 表面 marker 弱 | 酶处理过强或时间过长 | 缩短消化，换温和组合，先做 marker 兼容性测试 |

## 小结

胶原酶是组织和 ECM 场景的核心工具。它的难点不是“会不会用”，而是如何在产量、活率、单细胞比例、表面 marker 和批次一致性之间找到适合目标组织的窗口。
