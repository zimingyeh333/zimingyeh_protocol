# 溴酚蓝

溴酚蓝（bromophenol blue，BPB）是一种 pH indicator dye（pH 指示染料）和 tracking dye（迁移追踪染料），在 [SDS-PAGE](<../用(实验流程内容篇)/SDS-PAGE.md>) 中常作为 [Laemmli上样缓冲液](Laemmli上样缓冲液.md) 的染料组分，用于观察上样、确认样本是否进入泳道，以及判断电泳前沿位置。

## 核心作用

溴酚蓝本身不是蛋白染料，也不是 WB 检测信号。它的主要作用是“告诉你电泳跑到哪里了”。在 SDS-PAGE 中，溴酚蓝迁移速度通常接近小分子前沿，跑到胶底附近时提示可以停止电泳，避免小蛋白跑出。

Bio-Rad 的 Laemmli Sample Buffer 产品资料列出其成分包括 Tris-HCl、[SDS](十二烷基硫酸钠.md)、bromophenol blue、[甘油](甘油.md) 和 β-mercaptoethanol（β-巯基乙醇），说明溴酚蓝是经典蛋白上样缓冲液的可视追踪组分。参考：[Bio-Rad Laemmli Sample Buffer](https://www.bio-rad.com/en-us/sku/1610747-laemmli-sample-buffer-4x?ID=1610747)。

## 在上样缓冲液中的位置

| 组分 | 作用 |
| --- | --- |
| [Tris](Tris.md)-HCl | 提供 pH 环境 |
| SDS | 蛋白变性并赋予负电荷 |
| [DTT](DTT.md) 或 [β-巯基乙醇](β-巯基乙醇.md) | 还原二硫键 |
| 甘油 | 增加样本密度，使样本沉入泳道 |
| 溴酚蓝 | 追踪电泳前沿 |

如果样本没有蓝色，不代表没有蛋白；如果蓝色很深，也不代表蛋白很多。溴酚蓝只能辅助观察上样和迁移。

## 溴酚蓝 vs 考马斯亮蓝 vs Ponceau S

| 染料 | 主要用途 | 是否用于蛋白定量/检测 |
| --- | --- | --- |
| 溴酚蓝 | 电泳追踪染料 | 不用于蛋白检测 |
| [考马斯亮蓝](考马斯亮蓝.md) | 凝胶总蛋白染色 | 可用于蛋白条带可视化 |
| [Ponceau S](<Ponceau S.md>) | 转膜后膜上总蛋白快速染色 | 用于转膜质控 |
| ECL | HRP 化学发光检测 | 用于 WB 目标蛋白检测 |

这几个蓝/红/发光信号常被新手混淆。溴酚蓝只负责“跑到哪里”，不负责“蛋白在哪里”。

## 使用 protocol

### 配样本缓冲液

**怎么做**：按配方加入少量溴酚蓝，充分溶解并混匀。

**为什么**：染料浓度过低不易观察，过高可能增加背景或影响小分子前沿判断。

**注意事项**：

- 商品 sample buffer 已经含溴酚蓝时不要重复添加。
- 如果做某些特殊小蛋白或肽分析，追踪染料跑到胶底时小目标可能已经接近跑出，需要提前停止。
- 溴酚蓝颜色受 pH 影响，异常颜色可能提示 buffer pH 或配方问题。

### 电泳判断

**怎么做**：观察蓝色前沿位置，根据目标蛋白大小决定停止时间。

**为什么**：目标蛋白大小不同，最佳停止位置不同。为了大蛋白可以跑久一点；为了小蛋白要避免前沿跑出太远。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 看不到蓝色前沿 | sample buffer 未加染料或稀释太多 | 换新上样缓冲液 |
| 蓝色扩散严重 | 样本盐分高、孔内溢出、上样不稳 | 降低盐分，改善上样操作 |
| 前沿歪斜 | 电泳槽装配不平、buffer 不均、胶问题 | 检查 [电泳槽](电泳槽.md) 和胶 |
| 小蛋白信号弱 | 前沿跑太久，小蛋白可能跑出 | 缩短电泳时间或用高浓度胶 |
| 误认为蓝色是蛋白 | 概念混淆 | 用 Ponceau S、考马斯或 WB 检测蛋白 |

## 小结

溴酚蓝是 SDS-PAGE 的“跑步进度条”。它帮助判断上样和电泳前沿，但不代表蛋白量，也不能替代蛋白染色或 WB 检测。
