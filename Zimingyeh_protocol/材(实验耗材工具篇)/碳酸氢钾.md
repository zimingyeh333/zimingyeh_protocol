# 碳酸氢钾

碳酸氢钾（potassium bicarbonate，KHCO3）是一种弱碱性无机盐，在实验室中常用于缓冲体系、pH 调节相关配方，以及经典 ACK lysis buffer（ammonium-chloride-potassium lysis buffer，ACK 裂解液）的缓冲成分之一。它在 [红细胞裂解液](红细胞裂解液.md) 中通常不是主裂解成分，而是帮助维持合适的缓冲环境。

## 定义与命名

| 名称 | 说明 |
| --- | --- |
| Potassium bicarbonate | 碳酸氢钾 |
| KHCO3 | 化学式 |
| CAS 298-14-6 | 常用登记号 |
| ACK buffer component | 经典 ACK 配方中常见缓冲成分 |

PubChem 将 potassium bicarbonate 记录为钾盐，分子式为 KHCO3。参考：[PubChem Potassium Bicarbonate](https://pubchem.ncbi.nlm.nih.gov/compound/Potassium-bicarbonate)。

## 在 ACK 裂解液中的作用

经典 ACK 体系常由 [氯化铵](氯化铵.md)、碳酸氢钾和 [EDTA](EDTA.md) 组成。氯化铵负责主要红细胞裂解效应，碳酸氢钾提供弱缓冲和离子环境支持，EDTA 螯合二价阳离子并帮助减少细胞聚集。

碳酸氢钾的重点不是“裂解红细胞”，而是让裂解过程发生在较合适的缓冲条件下，降低对 leukocytes（白细胞）的额外损伤。配方中的 KHCO3 浓度、pH 和渗透压都会影响裂解效率和白细胞保留。

## 常见用途

| 用途 | 说明 |
| --- | --- |
| ACK/RBC 裂解液 | 作为缓冲成分之一 |
| pH 相关配方 | 提供弱碱性碳酸氢根缓冲环境 |
| 细胞处理缓冲液 | 少数特定配方中用于离子和缓冲环境 |
| 化学试剂储备 | 用于实验室配液、标准化配方 |

## 与碳酸钾的区别

| 项目 | 碳酸氢钾 KHCO3 | [碳酸钾](碳酸钾.md) K2CO3 |
| --- | --- | --- |
| 阴离子 | HCO3- | CO3 2- |
| 碱性 | 较弱 | 更强 |
| ACK 语境 | 经典 ACK 自配配方常见 | 某些商品 RBC lysis buffer 可见 |
| 能否直接替换 | 不建议 | 不建议 |
| 关键记录 | 浓度、pH、配制日期 | 浓度、pH、配制日期 |

KHCO3 和 K2CO3 都与碳酸盐缓冲有关，但碱性和配方效果不同，不能只按“都是钾盐/碳酸盐”随意互换。

## 与 ACK 其他成分的关系

| 成分 | 角色 |
| --- | --- |
| [氯化铵](氯化铵.md) | 红细胞裂解主效应成分 |
| 碳酸氢钾 | 缓冲体系成分，帮助维持适合白细胞保留的环境 |
| [EDTA](EDTA.md) | 螯合 Ca2+/Mg2+，减少聚集 |
| [PBS](PBS.md) / [DPBS](DPBS.md) | 终止、稀释或洗涤 |

## 配制注意事项

| 变量 | 为什么重要 | 建议 |
| --- | --- | --- |
| 级别 | 杂质可能影响细胞活率 | 细胞实验使用 cell culture/molecular biology 级别或经验证批次 |
| pH | 影响裂解效率和细胞状态 | 配制后按 SOP 检测 |
| 浓度 | 决定缓冲能力和离子环境 | 不要用质量体积比代替摩尔浓度记录 |
| 灭菌 | 自配用于细胞实验需控制污染 | 通常过滤除菌并记录滤膜规格 |
| 保存 | 碳酸氢盐体系可能受 CO2/密封影响 | 按 SOP 保存，避免长期不明条件存放 |

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| ACK 批次裂解效果不稳定 | KHCO3 称量、pH 或保存条件变化 | 建立配制记录和 pH 记录 |
| 白细胞活率下降 | pH/渗透压不合适或暴露时间过长 | 复核整体 ACK 配方，不只看 NH4Cl |
| 用 K2CO3 替代 KHCO3 后异常 | 碱性和缓冲环境改变 | 不要直接替换，需重新验证 |
| 溶液污染或沉淀 | 灭菌/保存不当或配方问题 | 重新配制并过滤除菌 |

## 购买建议

如果只是用于常规红细胞裂解，购买商品 [红细胞裂解液](红细胞裂解液.md) 通常更省心。只有在实验室已有成熟 ACK 自配 SOP、需要大体积低成本试剂，或要严格控制配方时，才建议单独购买碳酸氢钾用于自配。

购买和记录时建议写清：

```text
Potassium bicarbonate, supplier, catalog number, lot number, grade, storage condition
```

而不是只写：

```text
KHCO3
```

## 小结

碳酸氢钾在 ACK/RBC 裂解体系中主要是缓冲和离子环境成分，不是主裂解成分。它和碳酸钾名字相近，但碱性和配方效果不同；自配时必须记录浓度、pH、级别、批号和配制条件。
