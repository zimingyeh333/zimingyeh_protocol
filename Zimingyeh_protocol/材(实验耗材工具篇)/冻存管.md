# 冻存管

Cryogenic vial / cryovial（冻存管 / 低温保存管）是用于保存细胞、菌株、病毒样本、蛋白或其他低温样本的小体积容器。在细胞培养中，它通常用于装载含 [细胞冻存液](细胞冻存液.md) 的细胞悬液，并在 [程序降温盒](程序降温盒.md) 降温后转入 [液氮罐](液氮罐.md) 长期保存。

冻存管看起来像普通小管，但它不是普通离心管。它必须能耐受超低温、密封可靠、标签可追踪，并适配液氮或气相液氮储存条件。

## 基本结构

| 部分 | 英文 | 作用 | 选择要点 |
| --- | --- | --- | --- |
| 管体 | Tube body | 装载样本 | 常见为 polypropylene（聚丙烯），需标明 cryogenic use |
| 螺旋盖 | Screw cap | 密封样本 | 关注内旋/外旋、是否带 O-ring |
| 密封圈 | O-ring / gasket | 提高密封性 | 低温下材料仍需可靠 |
| 标记区 | Writing area | 写细胞名、日期、传代数 | 需耐乙醇、耐低温、可配合低温标签 |
| 底部 | Round / self-standing bottom | 放入冻存盒或架子 | 自立式更方便操作，但要看盒子适配 |
| 条码 | Linear / 2D barcode | 自动化库存管理 | 适合大型细胞库或高通量样本 |

Corning 和 Thermo Fisher 的 cryogenic vial 产品资料都把管型、螺纹、容量、无菌、可追踪标签和低温适用性作为核心参数。[参考：Corning Cryogenic Vials](https://www.corning.com/worldwide/en/products/life-sciences/products/cell-culture/cell-culture-cryogenic-storage/cryogenic-vials.html)；[参考：Thermo Scientific Nunc CryoTube Vials](https://www.thermofisher.com/order/catalog/product/375418)

## 关键规格

| 参数 | 常见选择 | 对实验的影响 |
| --- | --- | --- |
| 容量 | 1.8 mL、2.0 mL、5.0 mL | 细胞冻存常见每管约 1 mL，容量过大不一定更好 |
| 螺纹 | Internal thread（内旋）/ external thread（外旋） | 外旋管常减少样本接触螺纹；内旋管更节省空间 |
| 灭菌 | Sterile（无菌） | 细胞冻存必须用无菌冻存管 |
| 无热原/低内毒素 | Non-pyrogenic / endotoxin tested | 原代、免疫和转化项目更重要 |
| 储存温度 | Vapor phase LN2 / liquid nitrogen compatible | 必须匹配实际储存方式 |
| 条码 | 无 / 线性码 / 2D 码 | 决定库存可追溯性和自动化程度 |

## 液氮相与气相储存

| 储存方式 | 优点 | 风险 | 使用建议 |
| --- | --- | --- | --- |
| 液相液氮 | 温度更接近 -196°C | 液氮可能进入管内，升温时有爆管风险；也有交叉污染讨论 | 只有在冻存管明确适用且实验室有规范时使用 |
| 气相液氮 | 降低液氮进入管内和交叉污染风险 | 温度受罐体、液位和位置影响 | 细胞库常用，需监测温度和液氮液位 |
| -80°C 冰箱 | 操作方便 | 不适合多数动物细胞长期保存 | 主要作为程序降温过渡 |

ATCC 建议动物细胞长期保存保持低于 -130°C；Thermo Fisher 的复苏说明也提醒，从液氮取出的 cryovial 解冻时存在爆裂风险，应佩戴防护。[参考：ATCC Cryogenic Storage of Animal Cells](https://www.atcc.org/resources/technical-documents/cryogenic-storage-of-animal-cells)；[参考：Thermo Fisher Thawing Cells](https://www.thermofisher.com/us/en/home/references/gibco-cell-culture-basics/cell-culture-protocols/thawing-cells.html)

## 使用 protocol

### 选择冻存管

**怎么做**：细胞冻存选择 sterile（无菌）、cryogenic storage（低温储存）适用、容量合适的冻存管。若进入液氮气相或液相，确认产品说明中的适用范围。

**为什么**：普通微量离心管、PCR 管或不明来源小管不一定能承受低温、密封和温度变化。

**注意事项**：

- 不要把普通 EP 管当冻存管使用。
- 不要使用破损、盖子松动或密封圈异常的冻存管。
- 大型库存优先考虑条码管或 2D 管。

**替代方案**：高价值样本可使用双重标识：管身低温标签 + 库存表位置记录。

**出错后果**：漏液、爆管、标签脱落、样本无法追溯。

### 分装与标记

**怎么做**：按冻存方案把细胞悬液分装入冻存管，常见装液量约为管体标称容量的一部分，不要装满。管身标记至少包含细胞名、传代数、日期、操作者和编号。

**为什么**：液体冻结会膨胀，装液过满增加漏液或破裂风险。只写管盖会在盒内换盖、脱落或旋转后造成样本混乱。

**注意事项**：

- 分装前持续轻柔混匀细胞悬液。
- 标签和笔迹需要耐低温、耐乙醇。
- 管盖拧紧即可，不要用力过猛损坏螺纹或密封圈。

**替代方案**：大型细胞库使用 2D barcode 管并配合电子库存系统。

**出错后果**：同批细胞密度差异、冻存管漏液、复苏时无法确认样本身份。

### 取出与复苏

**怎么做**：从液氮罐取出冻存管时佩戴面屏、低温手套和实验服，快速核对标签后进入复苏流程。外壁擦拭消毒后再在 BSC 中开盖。

**为什么**：冻存管外壁可能接触液氮罐和水浴环境；液氮进入冻存管后升温还可能造成压力风险。

**注意事项**：

- 取管时不要长时间把整盒暴露在室温。
- 冻存管从液氮取出后不要直接对着脸观察。
- 疑似破裂或漏液的冻存管按污染和低温风险处理。

**替代方案**：重要库存可分散存放，避免一次取出整批关键样本。

**出错后果**：复苏率下降、污染、冻伤或爆管伤害。

## 购买建议

细胞冻存优先选择 [Corning](<../番外/试剂厂商/Corning.md>)、[Thermo Scientific](<../番外/试剂厂商/Thermo Scientific.md>) / Nunc、[Eppendorf](<../番外/试剂厂商/Eppendorf.md>)、[Sartorius](<../番外/试剂厂商/Sartorius.md>) 等有明确低温储存说明和质量文件的冻存管。不要只按价格选择，低质量冻存管一旦出问题，损失通常远高于耗材差价。

物品识别时，可以查看厂商页面图片，重点观察：螺旋盖结构、O-ring、管身标记区、底部形状、容量刻度和是否有 2D 码。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理策略 |
| --- | --- | --- |
| 冻存管破裂 | 装液过满、管材不适合液氮、液氮进入管内 | 使用合格冻存管，控制装液量，优先气相储存 |
| 复苏时喷溅或爆管 | 液氮渗入后快速升温 | 戴面屏，按规范快速但谨慎解冻 |
| 标签脱落 | 标签不耐低温或只写管盖 | 使用低温标签，管身和库存表双记录 |
| 找不到样本 | 位置记录不完整 | 记录液氮罐、架、盒、格、管号 |
| 同批管细胞数差异大 | 分装时细胞沉降 | 分装期间轻柔混匀，缩短分装时间 |

## 小结

冻存管是细胞库可靠性的第一道物理边界。选择冻存管时要同时考虑低温兼容性、密封、安全、标签和库存管理。能不能冻进去只是最低要求；未来能不能安全取出、准确识别并成功复苏，才是冻存管真正要服务的目标。
