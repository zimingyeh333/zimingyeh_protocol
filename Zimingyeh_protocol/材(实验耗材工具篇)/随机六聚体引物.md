# 随机六聚体引物

Random hexamer primer（随机六聚体引物）是一组随机序列的 6 nt 短引物混合物，可在 RNA 模板的多个位置随机退火并启动 [逆转录](<../用(实验流程内容篇)/逆转录.md>)。它常用于 total RNA（总 RNA）逆转录、降解 RNA 样本、非 poly(A) RNA 或希望获得更均匀转录本覆盖的场景。

图源：Image2 生成的逆转录核心材料参考图；彩色小管代表不同逆转录组分，其中包含 Oligo(dT) 引物和随机六聚体引物。

## 工作原理

随机六聚体由多种 6 碱基组合构成，理论上可以在 RNA 模板的许多位置退火。与 [Oligo(dT)引物](<Oligo(dT)引物.md>) 只依赖 poly(A) tail 不同，随机六聚体不要求目标 RNA 有 poly(A) 尾，因此覆盖范围更广。

Thermo Fisher 的 cDNA synthesis 资料将 random primers 描述为可在 RNA 模板多个位置起始 cDNA 合成，适合获得更均匀的 cDNA 代表性；NEB 也把 random primers 作为 cDNA synthesis 常见引物策略之一。[参考：Thermo Fisher cDNA Synthesis Basics](https://www.thermofisher.com/us/en/home/references/ambion-tech-support/rtpcr-analysis/general-articles/cdna-synthesis.html)；[参考：NEB cDNA Synthesis](https://www.neb.com/en-us/applications/cdna-synthesis)

## 核心用途

| 场景 | 为什么用随机六聚体 |
| --- | --- |
| RNA 部分降解 | 不依赖完整 3' poly(A) 到目标区域的连续模板 |
| 非 poly(A) RNA | 可覆盖 rRNA、部分 lncRNA、病毒 RNA 或其他非 poly(A) 目标 |
| 长转录本 | 更容易覆盖转录本不同区域 |
| 总 RNA 逆转录 | 生成更广泛的 cDNA pool |
| RT-qPCR 多靶标 | 不同基因区域覆盖更均衡 |

## 优点和限制

| 优点 | 限制 |
| --- | --- |
| 覆盖范围广 | 会逆转录大量 rRNA 和非目标 RNA |
| 对降解 RNA 更友好 | mRNA 特异性不如 Oligo(dT) |
| 5' 端目标更容易被覆盖 | 可能产生短 cDNA 片段 |
| 适合多类型 RNA | 背景复杂，低丰度 mRNA 可能被稀释 |

## 随机六聚体 vs Oligo(dT)

| 策略 | 更适合 | 不适合 |
| --- | --- | --- |
| 随机六聚体 | 降解 RNA、长转录本、非 poly(A) RNA、总 RNA | 只想富集 mRNA 时 |
| Oligo(dT) | 完整 mRNA、常规 poly(A)+ 表达分析 | 降解 RNA、非 poly(A) 目标 |
| 混合策略 | 常规 RT-qPCR，希望兼顾覆盖和 mRNA 选择性 | 需要严格解释 cDNA 来源时要固定配方 |

## 使用 protocol

### 选择策略

**怎么做**：如果目标 RNA 类型复杂、样本可能降解或 qPCR 引物位于转录本较靠 5' 的区域，可优先考虑随机六聚体或随机六聚体 + Oligo(dT) 混合策略。

**为什么**：随机起始能减少单纯 3' 起始造成的覆盖偏倚。

**注意事项**：

- 同一项目固定引物策略。
- 如果目标是 mRNA 定量，随机引物会把大量 rRNA 也逆转录进去。
- 不同试剂盒中 random primer 浓度和配比可能不同。

### 退火和逆转录

**怎么做**：按逆转录酶或试剂盒说明，把随机六聚体与 RNA、dNTP 预退火，再加入 buffer、酶和 RNase 抑制剂完成反应。

**为什么**：随机六聚体短，退火温度和条件会影响起始效率和偏倚。

**注意事项**：

- 不要随意提高退火温度，短引物可能结合不稳。
- 低 RNA 投入量时更需要严格避免 RNase 污染。

## 常见错误与 troubleshooting

| 问题 | 可能原因 | 处理 |
| --- | --- | --- |
| 低丰度 mRNA Cq 偏高 | 大量 rRNA/非目标 RNA 被逆转录 | 提高 RNA 质量，考虑 Oligo(dT) 或混合策略 |
| cDNA 片段偏短 | 随机起始 + 反应条件不适 | 优化酶和温度，选择长片段 RT |
| 项目结果前后不一致 | 中途更换了引物策略 | 固定 Oligo(dT)/random/mixed 方案 |
| non-poly(A) 目标无信号 | 引物策略、RNA 质量或 qPCR 引物问题 | 确认目标 RNA 类型和 qPCR 设计 |

## 小结

随机六聚体引物适合“更广泛地复制 RNA 信息”，尤其是非 poly(A) RNA、降解 RNA 和长转录本覆盖。但它也会带来 rRNA/非目标背景，因此要和 Oligo(dT) 的 mRNA 选择性做取舍。
